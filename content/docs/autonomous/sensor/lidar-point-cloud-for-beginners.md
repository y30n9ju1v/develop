## LiDAR가 뭔가요?

카메라는 빛의 밝기를 픽셀로 기록합니다. 카메라만으로는 물체가 **얼마나 멀리 있는지** 알기 어렵습니다. 같은 크기로 찍혀도 가까운 작은 물체일 수도, 멀리 있는 큰 물체일 수도 있기 때문입니다.

**LiDAR(Light Detection And Ranging)**는 이 문제를 해결합니다. 레이저 빛을 쏜 뒤 반사되어 돌아오는 시간을 측정해서 **거리를 직접** 잽니다. 수만 개의 레이저를 사방으로 쏘아 만들어진 거리 측정값의 집합이 **포인트 클라우드(Point Cloud)**입니다.

```
        레이저 발사
LiDAR ──────────────→ 물체
      ←──────────────
        반사광 수신

거리 = (빛의 속도 × 왕복 시간) / 2
```

자율주행 차량이 도로와 주변 물체를 3D로 인식하는 데 LiDAR가 핵심인 이유가 여기 있습니다.

## 포인트 클라우드의 구조

LiDAR 한 번 회전(스캔)으로 수만~수십만 개의 점이 생성됩니다. 각 점은 다음 4개 값으로 이루어집니다.

| 필드 | 의미 | 단위 |
|---|---|---|
| **x** | 센서 기준 앞/뒤 거리 | m |
| **y** | 센서 기준 좌/우 거리 | m |
| **z** | 센서 기준 위/아래 거리 | m |
| **intensity** | 반사 강도 (반사율) | 0.0 ~ 1.0 (또는 0~255) |

```
포인트 클라우드 예시 (N × 4 배열)

   x      y      z    intensity
[ 5.12,  0.03,  0.21,  0.82 ]   # 전방 5m, 차선 페인트(반사율 높음)
[ 8.44, -1.23, -0.45,  0.31 ]   # 전방 8m, 아스팔트(반사율 낮음)
[12.01,  2.17,  1.83,  0.74 ]   # 전방 12m, 표지판
...
```

> **intensity란?** 레이저가 물체에 맞고 얼마나 많이 돌아왔는지를 나타냅니다. 차선 도색, 반사판처럼 밝은 표면은 intensity가 높고, 검은 아스팔트나 유리는 낮습니다. 일부 LiDAR는 `x, y, z, intensity` 외에도 어떤 레이저 채널에서 나온 점인지를 나타내는 `ring` 번호나 다중 반사 여부(`return_type`)를 추가 필드로 기록합니다.

### Python으로 포인트 클라우드 읽기

자율주행에서는 포인트 클라우드를 주로 `.bin`(Velodyne KITTI 형식) 또는 `.pcd` 파일로 저장합니다.

```python
import numpy as np

# KITTI 형식 .bin 파일 읽기 (x, y, z, intensity)
points = np.fromfile("000000.bin", dtype=np.float32).reshape(-1, 4)

print(f"총 포인트 수: {len(points)}")
print(f"x 범위: {points[:, 0].min():.1f} ~ {points[:, 0].max():.1f} m")
print(f"y 범위: {points[:, 1].min():.1f} ~ {points[:, 1].max():.1f} m")
print(f"z 범위: {points[:, 2].min():.1f} ~ {points[:, 2].max():.1f} m")
```

```python
import open3d as o3d

# .pcd 파일 읽기 및 시각화
pcd = o3d.io.read_point_cloud("scan.pcd")
o3d.visualization.draw_geometries([pcd])
```

## LiDAR의 종류: 채널 수가 핵심

LiDAR의 성능은 주로 **채널(Channel) 수**, 즉 동시에 발사하는 레이저 빔의 수로 결정됩니다.

| 채널 수 | 대표 제품 | 포인트 밀도 | 용도 |
|---|---|---|---|
| 16채널 | Velodyne VLP-16 | 낮음 | 연구, 저가 시스템 |
| 32채널 | Velodyne HDL-32E | 중간 | 일반 자율주행 |
| 64채널 | Velodyne HDL-64E | 높음 | 고급 자율주행 |
| 128채널+ | Ouster OS2, Livox | 매우 높음 | 최신 자율주행 |

채널이 많을수록 수직 방향 해상도가 높아져 작은 물체(보행자, 자전거)를 더 잘 인식합니다. 32채널 LiDAR로 찍은 보행자는 채널 간격 때문에 점이 몇 개 안 찍히지만, 128채널이면 훨씬 풍부하게 찍힙니다.

```
16채널 (수직 단면)       64채널 (수직 단면)

    ·                       · · · · ·
    ·     보행자             · · ·ㅁ· ·
    ·                       · · · · ·
────·──────── 지면        ────······──── 지면
```

## 포인트 클라우드 처리의 핵심: Voxel Grid

포인트 클라우드는 점의 수가 너무 많아서 그대로 쓰기 어렵습니다. 128채널 LiDAR는 초당 수백만 개의 점을 생성합니다. 이를 줄이는 가장 기본적인 방법이 **Voxel Grid 다운샘플링**입니다.

### Voxel이란?

**Voxel(Volume + Pixel)**은 3D 공간의 작은 정육면체 단위입니다. 2D 이미지의 픽셀을 3D로 확장한 개념입니다.

```
3D 공간을 격자로 나눔 (각 격자 = Voxel)

┌───┬───┬───┐
│ · │·· │   │  ← 각 Voxel 안의 점들을
├───┼───┼───┤     대표 점 1개로 줄임
│   │ · │·· │
└───┴───┴───┘
```

### Voxel Grid 다운샘플링

각 Voxel 안에 있는 모든 점의 **무게 중심(centroid)**을 계산해서 대표 점 1개로 줄입니다.

```python
import open3d as o3d

pcd = o3d.io.read_point_cloud("scan.pcd")
print(f"원본 포인트 수: {len(pcd.points)}")

# Voxel 크기 0.1m (10cm) 단위로 다운샘플링
downsampled = pcd.voxel_down_sample(voxel_size=0.1)
print(f"다운샘플 후: {len(downsampled.points)}")
```

Voxel 크기를 키울수록 점이 더 많이 줄어들지만 세부 형상이 뭉개집니다. 자율주행에서는 보통 **0.05m ~ 0.2m** 사이를 씁니다.

> **왜 Voxel Grid인가?** 단순히 N개 중 1개를 랜덤 샘플링하는 것보다 공간적으로 균등하게 점을 유지할 수 있습니다. 랜덤 샘플링은 점이 밀집한 가까운 구역이 과대 대표되고 먼 구역은 과소 대표되는 문제가 생깁니다.

## 지면 제거 (Ground Removal)

자율주행에서 LiDAR 포인트 대부분은 **지면(도로)**에서 반사됩니다. 장애물 인식을 위해서는 지면 포인트를 먼저 제거해야 합니다. 가장 간단한 방법은 **높이 임계값**으로 자르는 것입니다.

```python
import numpy as np

# z 좌표가 -0.3m 이하인 점을 지면으로 간주하고 제거
# (LiDAR가 차량 위 1.8m에 장착된 경우, 지면은 z ≈ -1.8m)
points = np.fromfile("000000.bin", dtype=np.float32).reshape(-1, 4)

ground_threshold = -1.5  # m (LiDAR 높이에 따라 조정 필요)
non_ground = points[points[:, 2] > ground_threshold]

print(f"전체: {len(points)} → 지면 제거 후: {len(non_ground)}")
```

실무에서는 RANSAC 평면 피팅이나 PATCHWORK++ 같은 알고리즘으로 경사로, 과속방지턱 등 불균일한 지면도 정확하게 제거합니다. 단순 높이 임계값은 경사로에서 지면을 제대로 제거하지 못한다는 한계가 있습니다.

## LiDAR는 왜 날씨에 취약한가?

LiDAR의 가장 큰 약점은 **악천후**입니다. 레이저가 빛이기 때문에 빛을 흡수하거나 산란시키는 물질에 영향을 받습니다.

| 날씨 | 영향 | 이유 |
|---|---|---|
| **폭우** | 빗방울이 레이저를 직접 반사해 수백 개의 허위 포인트 생성 | 빗방울 표면에서 후방 산란이 일어나 물체가 아닌 빗방울 위치에 점이 찍힘 |
| **짙은 안개** | 유효 측정 거리가 수십 m로 줄어듦 | 수분 입자가 레이저를 산란·흡수 |
| **눈** | 눈송이에서 반사된 포인트가 지면·물체와 혼재 | 눈의 불규칙한 형태가 반사를 예측 불가능하게 만듦 |
| **강한 햇빛** | 노이즈 증가 | 태양광이 수광부를 포화(Saturation)시킴 |

> **1550nm vs 905nm**: 고급 LiDAR는 905nm 대신 **1550nm** 파장을 씁니다. 1550nm는 안개 속에서 감쇠가 적고, 인체 눈 안전 기준(Eye Safety)이 더 높아 출력을 높일 수 있어 악천후 성능이 유리합니다. 단점은 수광 소자 비용이 높다는 것입니다.

이 취약성 때문에 자율주행 시스템은 LiDAR 단독이 아닌 카메라, RADAR와 **센서 퓨전**을 통해 악천후 대응 능력을 높입니다. RADAR는 전파를 사용해 비/눈에 강하고, 카메라는 색상·질감 정보로 LiDAR가 잡지 못하는 패턴을 보완합니다.

## LiDAR 좌표계

좌표계 글에서 언급했듯이, LiDAR 좌표계는 로봇공학 관례를 따릅니다.

- **X축**: 센서 전방
- **Y축**: 센서 왼쪽
- **Z축**: 위쪽

센서에서 가까운 점일수록 밀집하고, 멀어질수록 점이 희박해집니다. 30m 거리의 물체는 5m 거리의 물체보다 포인트가 훨씬 적게 찍힙니다. 이를 **거리에 따른 밀도 감소**라고 하며, 딥러닝 모델 설계 시 반드시 고려해야 하는 특성입니다.

## 정리

| 개념 | 한 줄 요약 |
|---|---|
| **포인트 클라우드** | LiDAR 스캔으로 얻은 3D 점들의 집합. 각 점은 (x, y, z, intensity) |
| **intensity** | 레이저 반사 강도. 차선 도색·반사판은 높고, 아스팔트·유리는 낮음 |
| **채널 수** | 동시 발사 레이저 수. 많을수록 수직 해상도 높음 |
| **Voxel Grid** | 3D 공간을 격자로 나눠 포인트를 대표점으로 줄이는 다운샘플링 |
| **지면 제거** | 장애물 인식 전처리. 높이 임계값 또는 RANSAC 평면 피팅 |
| **날씨 취약성** | 비·안개·눈이 레이저를 산란시켜 허위 포인트 또는 측정 거리 감소 |
