## 1. 소개

단일 사진에서는 착시 현상이 일어나기 쉽습니다. 피사의 사탑을 한 사람이 손으로 떠받치는 듯한 기념사진이 대표적입니다. 하지만 단 10cm만 옆으로 비켜나 두 번째 앵글에서 바라본다면(다중 뷰), 사탑과 사람의 거리 차이가 확연해지며 착시는 즉시 깨집니다. 

다중 뷰 컴퓨터 비전에서는 여러 카메라가 존재할 때 성립하는 강력한 기하학적 약속이 있으며, 그 출발점이 바로 **에피폴라 기하학**입니다.

## 2. 에피폴라 기하학 (Epipolar Geometry)

### 2.1 시선 레이저 제약 (Epipolar Constraint)

> 🔦 **친절한 비유 (시선 레이저 쇼)**
> 
> 어두운 방에서 두 사람(카메라 1, 카메라 2)이 3D 공간 속 날아가는 파리 한 마리($P$)를 관찰하고 있습니다.
> 
> 카메라 1이 파리를 바라봅니다. 카메라 1의 렌즈 중심($O_1$)에서 파리($P$)를 잇는 연장선은 우주 끝까지 뻗어나가는 곧은 **"시선 레이저 광선"**이 됩니다.
> 
> 이때 옆에 서 있는 카메라 2가 카메라 1을 바라보면 무엇이 보일까요? 카메라 1이 쏘아 올린 시선 레이저 광선이 **카메라 2의 뷰파인더(이미지 평면) 상에 한 줄기 붉은 '선'**으로 길게 투영되는 것이 보입니다.
> 
> 카메라는 파리가 그 광선의 어느 깊이에 있는지 알 수 없지만, 확실히 약속할 수 있는 규칙이 있습니다. **"카메라 2의 센서 위에 맺히는 파리의 상($p'$)은, 카메라 1의 시선 레이저가 그리는 그 빨간 선 위에 100% 무조건 놓여 있어야만 한다."**
> 
> 이 단순하고도 강력한 약속을 **에피폴라 제약**이라 부르며, 이 덕분에 2차원 평면 전체를 뒤질 필요 없이 **선 한 줄만 훑어보아도 대응점 매칭(Stereo Matching)을 해결**할 수 있습니다.

### 2.2 기하 구조 시각화 (ASCII Art)

에피폴라 기하학의 핵심 용어들은 아래의 입체 다이어그램을 통해 기하학적 감각으로 완벽하게 파악됩니다.

```
                  [ 3D 실제 점 P ]
                       /  \
                      /    \
                     /      \  에피폴라 평면 ∏
                    /        \ (O1, O2, P 세 점이 이루는 공간 삼각형)
                   /          \
  [이미지 평면 1]  /            \  [이미지 평면 2]
     /──────────/──────────────/──────────\
    /          /              /            \
   /      p  *               * p'           \   ℓ' 에피폴라 선
  /         /               / \              \  (시선 레이저가 찍힌 선)
 /   e     /  ℓ            /   \      e'      \
/────*────/───────────────/─────*─────*────────\
     │   /               /     /     /
     │  /               /     /     /
     │ /               /     /     /
     │/               /     /     /
    [카메라 1 중심 O1] ═══════════════[카메라 2 중심 O2]
                         기준선 Baseline
```

- **기준선 (Baseline)**: 두 카메라의 광학 중심 $O_1$과 $O_2$를 곧게 잇는 연결선입니다.
- **에피폴라 평면 (Epipolar Plane, $\Pi$)**: 3D 실제 점 $P$와 두 카메라 중심 $O_1$, $O_2$ 세 점이 만드는 공간 속 삼각형 평면입니다.
- **에피폴 (Epipole, $e, e'$)**: 기준선이 각 이미지 평면과 정면으로 충돌하는 교점입니다. 상대 카메라 중심($O_2$)이 내 이미지 평면에 찍힌 그림자라고 볼 수 있습니다.
- **에피폴라 선 (Epipolar Lines, $\ell, \ell'$)**: 에피폴라 평면이 각 이미지 평면과 교차해서 만드는 교선입니다. 모든 에피폴라 선은 예외 없이 **에피폴($e$ 또는 $e'$)**을 무조건 통과합니다.

## 3. 본질 행렬 (Essential Matrix)

에피폴라 기하학을 선형대수 수식으로 바꾸어 봅시다. 첫 번째 카메라 중심을 원점 $(0,0,0)$으로 삼고, 두 번째 카메라가 첫 번째 카메라로부터 회전 $R$과 이동 $T$만큼 떨어져 있다고 가정합니다.

### 3.1 정규 카메라 가정 (Canonical Cameras)
수식을 단순하게 만들기 위해 내부 파라미터를 보정하여 $K = K' = I$로 만든 **정규 카메라**에서 시작합니다. 이 상태에서 투영되는 좌표 $p, p'$는 3D 실제 좌표와 스칼라 스케일 인자 $\lambda$배 차이만 납니다.

두 번째 카메라의 좌표계 기준에서 첫 번째 카메라가 관측한 $p$의 방향은 회전과 이동을 거쳐 $R^T(p_c - T)$가 됩니다. 에피폴라 평면 위의 세 공간 벡터(두 카메라 중심을 잇는 변위 $T$, 3D 점으로의 방향 $p$, $Rp'$)는 **완벽하게 동일한 평면 위에 누워있습니다.** 

수학적으로 세 벡터가 한 평면 위에 누워있으면, **세 벡터의 외적과 내적을 섞은 스칼라 삼중곱(Scalar Triple Product)이 완벽히 $0$**이 됩니다.

$$p^T \cdot [T \times (Rp')] = 0 \tag{1}$$

### 3.2 외적의 행렬 변환과 본질 행렬의 유도
외적 연산($T \times$)은 벡터를 곱해주는 반대칭 행렬 $[T_\times]$로 완벽히 치환됩니다.

$$[T_\times] = \begin{bmatrix} 0 & -T_z & T_y \\ T_z & 0 & -T_x \\ -T_y & T_x & 0 \end{bmatrix}$$

이를 식 (1)에 반영하면 다음과 같은 에피폴라 제약 공식이 도출됩니다.

$$p^T [T_\times] R p' = 0 \quad \Rightarrow \quad p^T E p' = 0 \tag{2}$$

여기서 **$E = [T_\times] R$**을 **본질 행렬(Essential Matrix)**이라 부릅니다.

> 📌 **본질 행렬 $E$의 기하학적 성질**
> - **자유도**: 5개 (회전 3개 + 이동 방향 3개이나 스케일이 무시되므로 $6 - 1 = 5$)
> - **행렬 랭크**: **랭크 2** (반대칭 행렬 $[T_\times]$의 랭크가 2이므로, 곱으로 구성된 $E$의 랭크도 항상 2가 됨. 이는 특이값 분해 시 마지막 특이값이 무조건 $0$이 됨을 뜻함).
> - **물리적 방향성**: 
>   - $\ell' = E^T p$ : 첫 번째 이미지의 점 $p$에 의해 유도되는 두 번째 이미지 상의 에피폴라 선
>   - $\ell = E p'$ : 두 번째 이미지의 점 $p'$에 의해 유도되는 첫 번째 이미지 상의 에피폴라 선

## 4. 기본 행렬 (Fundamental Matrix)

### 4.1 기본 행렬의 유도: 물리 세계와 디지털 세계의 다리

현실 세계에서 우리가 관측하는 픽셀 좌표 $p_{pixel}, p'_{pixel}$에는 카메라의 고유 내부 정보 $K, K'$가 끼어있습니다. 실제 픽셀 좌표와 정규화된 카메라 좌표의 관계 $p = K^{-1}p_{pixel}$을 식 (2)에 대입하면 다음과 같습니다.

$$(K^{-1}p_{pixel})^T E (K'^{-1}p'_{pixel}) = 0 \quad \Rightarrow \quad p_{pixel}^T (K^{-T} E K'^{-1}) p'_{pixel} = 0 \tag{3}$$

여기서 가운데 샌드위치처럼 끼어있는 $3 \times 3$ 행렬 **$F = K^{-T} E K'^{-1}$**을 **기본 행렬(Fundamental Matrix)**이라 부릅니다.

| 특징 | 본질 행렬 $E$ | 기본 행렬 $F$ |
|---|---|---|
| **카메라 조건** | 보정된 정규 카메라 ($K=I$) | 미보정 카메라 (디지털 픽셀) |
| **자유도 (DoF)** | 5개 | **7개** |
| **행렬 랭크** | 랭크 2 | **랭크 2** |
| **핵심 가치** | 기하학적 변위 분석 ($R, T$ 추출) | 이미지 픽셀 매칭점 찾기 |

---

### 4.2 8점 알고리즘 (The Eight-Point Algorithm)

카메라 내부 정보나 움직임을 전혀 모르는 상태에서, 오직 사진 속 **8쌍의 대응점**만으로 기본 행렬 $F$를 완전하게 구해내는 알고리즘입니다.

각 매칭점 쌍 ($p_i \leftrightarrow p'_i$)에 대해 $p_i^T F p'_i = 0$ 식을 성분별로 길게 늘어뜨려 쓰면 하나의 선형 제약 방정식을 얻습니다.

$$\begin{bmatrix} u_i u'_i & v'_i u_i & u_i & u'_i v_i & v_i v'_i & v_i & u'_i & v'_i & 1 \end{bmatrix} f = 0 \tag{4}$$

8쌍 이상의 매칭점이 있다면 거대한 방정식 $Wf = \mathbf{0}$을 세우고, Ch.1 캘리브레이션과 마찬가지로 **SVD(특이값 분해)**를 이용해 대수적 오차를 최소화하는 초기 해 $\hat{F}$를 복원해냅니다.

#### ⚠️ 대수적 풀이의 맹점: 랭크-2 강제(Singular Value Constraint)
SVD로 구한 초기 해 $\hat{F}$는 측정 노이즈 때문에 랭크가 3이 되어버릴 수 있습니다. 기본 행렬의 랭크가 3이 되면, **"모든 에피폴라 선이 하나의 에피폴($e$)에서 만난다"는 물리적 규칙이 깨지며 공중에 떠버리는 모순**이 생깁니다.

이 모순을 차단하기 위해, $\hat{F}$의 특이값 $\text{diag}(\sigma_1, \sigma_2, \sigma_3)$ 중 **가장 미세한 마지막 특이값 $\sigma_3$를 강제로 $0$으로 날려버리는** 투영 기하학의 마법을 부려 랭크-2를 강제합니다.

$$F = U \begin{bmatrix} \sigma_1 & 0 & 0 \\ 0 & \sigma_2 & 0 \\ 0 & 0 & 0 \end{bmatrix} V^T \tag{5}$$

### 4.3 정규화 8점 알고리즘 (Normalized Eight-Point Algorithm)

> 🏃 **친절한 비유 (픽셀의 고르지 못한 밸런스 운동장)**
> 
> 표준 8점 알고리즘은 실제 고해상도 카메라 이미지에서 돌리면 오차가 심해 못 쓸 지경이 됩니다.
> 
> 현대 카메라는 해상도가 $1920 \times 1080$ 정도로 픽셀 값의 단위가 아주 큽니다. 대응점을 방정식 행렬에 넣으면 $u_i u'_i$ 항은 무려 $1920 \times 1920 \approx 3.6 \times 10^6$ 단위까지 치솟는 반면, 동차 차원의 $1$은 계속 $1$로 남아있습니다.
> 
> 미지수의 크기 밸런스가 수백만 배 차이나는 **"불평등한 운동장"**이 되어, 컴퓨터 연산 시 작은 수치들이 잘려 나가는 불량조건(Ill-conditioned) 상태가 됩니다.
> 
> 이를 해결하기 위해, 모든 픽셀 좌표를 **평균 0, 평균 거리가 원점으로부터 $\sqrt{2}$**가 되도록 아담한 정규화 운동장으로 스케일링하는 **좌표 정규화** 훈련을 거칩니다.

정규화 변환 $T, T'$를 거쳐 정규화된 기본 행렬 $F_q$를 안정적으로 푼 뒤, 마지막에 역정규화(De-normalization)를 취해주어 왜곡 없는 강건한 진짜 기본 행렬 $F$를 복원해냅니다.

$$F = T'^T F_q T \tag{6}$$

## 5. 이미지 정류 (Image Rectification)

> 👓 **친절한 비유 (평행하게 눈높이 맞추기)**
> 
> 두 개의 카메라가 각각 다른 각도로 삐딱하게 세상을 바라보고 있다면, 에피폴라 선들이 사선 방향으로 비스듬히 흐릅니다. 대응점을 찾으려면 이미지 평면을 위아래 사선으로 온통 스캔해야 해서 컴퓨터 연산이 매우 힘들어집니다.
> 
> **이미지 정류**는 두 카메라의 가상 이미지 평면을 마치 정면에 평행하도록 가상으로 비틀어주는 기하학적 보정입니다. 
> 
> 보정이 완료되면 **"에피폴라 선들이 수평선과 완벽하게 수평"**을 이루며, 한 이미지의 픽셀 $p(u, v)$에 대응하는 점 $p'$는 두 번째 이미지의 **완벽하게 똑같은 가로 줄(v좌표가 동일한 $v'=v$)** 상에 놓이게 됩니다.
> 
> 2D 평면 매칭 탐색이 단 한 줄의 **1D 스캔라인(Scanline) 서치**로 차원이 축소되는 기적이 일어납니다.

```
       [ 정류 전 (사선 스캔) ]                          [ 정류 후 (수평 스캔) ]

       카메라 1            카메라 2                    카메라 1             카메라 2
      ┌──────────┐        ┌──────────┐                ┌──────────┐         ┌──────────┐
      │   /  /   │        │   \  \   │                │──────────│         │──────────│
      │  /  /    │        │    \  \  │   =======>     │   p *    │ ──────> │    * p'  │
      │ /  /     │        │     \  \ │                │──────────│         │──────────│
      └──────────┘        └──────────┘                └──────────┘         └──────────┘
```

### 5.1 정류 파이프라인
이미지 정류는 카메라의 기하학적 파라미터가 없어도, 기본 행렬 $F$로부터 구해지는 두 호모그래피 변환 $H_1, H_2$ 만으로 유도할 수 있어 응용 범위가 매우 넓습니다.

1. **에피폴 추정**: 이미지 픽셀 매칭점들을 활용해 $Fe' = 0$ 및 $F^T e = 0$ 식으로부터 두 에피폴 $e, e'$를 SVD로 정밀하게 풀어냅니다.
2. **$H_2$ 계산 (두 번째 이미지 평행화)**: 두 번째 에피폴 $e'$를 이미지 중심 원점 근처의 수평축 무한대 $(f, 0, 0)$로 순간 이동시키는 변환 $H_2$를 설계합니다.
3. **$H_1$ 계산 (첫 번째 이미지 왜곡 최소화)**: 두 이미지의 대응점 간 왜곡을 최소화하면서 $H_2$와 기하학적 짝을 이루는 첫 번째 이미지의 호모그래피 변환 $H_1$을 최소제곱법을 이용해 계산합니다.

정류 변환이 완료된 두 이미지는 인간의 좌우 눈과 동일한 완벽한 **평행 스테레오 시스템(Parallel Stereo System)**이 되어, 다음 챕터에서 다룰 깊이 복원(Disparity Map) 파이프라인으로 곧바로 매끄럽게 연결됩니다.
