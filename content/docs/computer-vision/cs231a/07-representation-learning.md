> 💡 **질문**: **"우리가 사진을 볼 때 눈으로 마주하는 것은 단순한 픽셀(Pixel)들의 나열일 뿐입니다. 그런데 어떻게 우리 머릿속은 그 혼돈의 숫자 배열에서 '달리는 보행자', '붉은 사과', '깊이감'이라는 고차원적 개념을 순식간에 인지하는 걸까요?"**
>
> 컴퓨터가 원시 데이터(Raw Data)로부터 의미 있는 핵심 정보만을 추출해 알맞은 형태로 담아내는 마법, 그것이 바로 **표현(Representation)과 표현 학습(Representation Learning)**의 핵심입니다.

## 1. 동적 시스템과 상태 추정

### 1.1 상태(State)와 표현(Representation)

동적 시스템의 **상태(State)**란, **"시스템의 미래 거동이나 특정 시점의 상황을 완벽하게 정의하기 위해 필요한 최소한의 핵심 정보 요약본"**입니다. 

*   **예시**: 수직 평면을 걷고 있는 보행 로봇
    *   **시간에 따라 변하는 물리량 (Dynamic State)**: 로봇의 현재 위치 $(x, y)$, 각 관절의 각도 $(\theta_1, \theta_2)$, 진행 속도 및 각속도.
    *   **변하지 않는 고정 파라미터 (Static Parameters)**: 다리 길이, 각 부품의 질량, 관절의 최대 마찰계수.

이러한 물리적 상태는 우리가 **어떻게 정의하느냐(표현)**에 따라 완전히 다른 형태로 변환될 수 있습니다.

| 대상 물리량 | 표현 방식 A | 표현 방식 B | 표현 방식 C |
|:---:|:---:|:---:|:---:|
| **회전/방향 (Orientation)** | 오일러 각 (Euler Angles)<br>*(직관적이나 짐벌락 위험)* | 축-각도 (Axis-Angle)<br>*(3D 회전축과 각도)* | 쿼터니언 (Quaternion)<br>*(4차원 벡터, 보간에 유리)* |
| **위치 (Position)** | 직교 좌표계 $(x, y, z)$ | 극좌표계 $(r, \theta, \phi)$ | 원통 좌표계 $(\rho, \phi, z)$ |

> 📌 **핵심**: "절대적으로 우월한 표현은 없습니다." 3D 그래픽스 보간이 목표라면 쿼터니언이 최선이지만, 사람이 직관적으로 제어하기에는 오일러 각이 훨씬 쉽습니다. 즉, **풀고자 하는 다운스트림 태스크에 가장 알맞은 요약 방식을 선택하는 것**이 표현의 본질입니다.

### 1.2 마르코프 성질 (Markov Property)

시간에 따라 끊임없이 변화하는 동적 시스템의 상태를 다룰 때, 수학자들은 엄청난 계산적 비효율에 직면합니다. *"미래 상태를 예측하기 위해 태초부터 지금까지의 모든 과거 기록을 전부 훑어봐야 할까?"* 

이 고민을 단칼에 해결해 주는 구원투수가 바로 **마르코프 성질(Markov Property)**입니다.

> ♟️ **친절한 비유 (체스판과 영화의 100번째 프레임)**
> 
> 1. **체스판의 비유**: 체스 경기 도중 잠시 화장실에 다녀왔습니다. 판 위에는 말들이 복잡하게 놓여 있습니다. 다음 번에 내가 둘 최선의 수($x_{t+1}$)를 결정하기 위해, 상대방과 내가 1턴부터 99턴까지 말을 어떻게 움직여왔는지(과거사 $x_1, \dots, x_{t-1}$) 복기할 필요가 있을까요? **전혀 없습니다.** 오직 **"지금 눈앞에 놓여 있는 체스판의 말 배치(현재 상태 $x_t$)"**만 보면 다음 수를 완벽히 결정할 수 있습니다.
> 
> 2. **영화 프레임의 비유**: 공이 날아가는 영화를 보고 있습니다. 101번째 프레임에서의 공의 위치($x_{101}$)를 예측하고 싶습니다. 이때 1번째부터 99번째 프레임까지의 궤적을 전부 알 필요는 없습니다. 바로 직전인 **100번째 프레임($x_{100}$)**에서의 공의 위치와 순간 속도(현재 상태)만 정확히 안다면 물리 법칙에 의해 다음 위치는 완벽히 결정됩니다.

이처럼 **"현재 상태가 주어지면, 미래 상태는 과거 상태와는 무관하게 오직 현재에만 의존한다"**는 가정을 마르코프 성질이라고 합니다.

$$P(x_{t+1} \mid x_t, x_{t-1}, \ldots, x_2, x_1) = P(x_{t+1} \mid x_t) \tag{1}$$

*   $x_t$: 시각 $t$에서의 시스템의 진짜 상태 (State)
*   $P(x_{t+1} \mid x_t)$: 현재 상태 $x_t$가 주어졌을 때 다음 상태 $x_{t+1}$이 결정될 조건부 확률

이 성질 덕분에 우리는 복잡한 역사적 데이터를 다 지우고, 다음 상태로 넘어가는 전이 함수 $f(\cdot)$를 심플하게 정의할 수 있게 됩니다.

$$f(x_t) = x_{t+1}$$

### 1.3 은닉 마르코프 모델 (HMM)과 상태 추정

현실 세계의 컴퓨터 비전은 그리 녹록지 않습니다. 로봇의 정확한 위치나 물체의 3D 물리적 상태 $x_t$를 눈으로 직접 들여다볼 수 없기 때문입니다. 우리는 오직 카메라나 센서가 노이즈와 함께 뱉어내는 **관측 데이터 $z_t$ (이미지 픽셀, LiDAR 포인트 클라우드 등)**만을 가질 뿐입니다.

이렇게 진짜 상태는 안개 속에 감춰져 있고, 불완전한 관측만을 통해 시스템을 추론해야 하는 모델을 **은닉 마르코프 모델(Hidden Markov Model, HMM)**이라고 합니다.

```
[ 은닉 마르코프 모델 (HMM) 구조 ]

  진짜 상태 (은닉)     x_{t-1} ───────>  x_t  ───────> x_{t+1}   (눈에 안 보임!)
                         │               │               │
                         │ 관측          │ 관측          │ 관측
                         v               v               v
  센서 데이터 (관측)   z_{t-1}          z_t            z_{t+1}   (눈에 보임!)
```

> ☔ **친절한 비유 (지하 연구실의 연구원과 우산)**
> 
> 창문이 하나도 없는 지하 연구실에 갇혀 연구를 하고 있습니다. 바깥 날씨가 비가 오는지, 해가 쨍쨍한지(은닉 상태 $x_t$)를 알고 싶지만 직접 볼 수 없습니다.
> 
> 대신 엘리베이터를 타고 내려오는 연구원들이 **"우산을 들고 있는지, 선글라스를 끼고 있는지(관측 데이터 $z_t$)"**를 관찰할 수 있습니다. 어떤 사람이 축축하게 젖은 우산을 들고 나타났다면, 우리는 비록 창밖을 보지 못했어도 *"아, 지금 밖에 비가 오는구나($x_t = \text{Rain}$)"*라고 합리적으로 추정할 수 있습니다.

이때 관측 데이터 $z_t$ 역시 마르코프 성질을 따라, **과거의 모든 경로와 상관없이 오직 현재의 진짜 상태 $x_t$에만 영향을 받는다**고 약속합니다.

$$P(z_t \mid x_t, x_{t-1}, \ldots, x_1) = P(z_t \mid x_t) \tag{2}$$

이 관측 과정을 수학적 함수로 표현한 것이 **관측 모델(Observation Model)** $h(\cdot)$입니다.

$$h(x_t) = z_t$$

*   **자율주행 자동차 예시**:
    *   $x_t$ (은닉 상태): 주변 차량들의 실제 3D 경계 상자(Bounding Box), 정확한 속도 및 미래 주행 경로.
    *   $z_t$ (관측): 자율주행 차에 달린 스테레오 카메라가 찍은 2D 이미지 프레임, LiDAR가 찍은 흐릿한 점군.
    *   **목표**: $z_t$로부터 베이즈 필터나 칼만 필터(Ch.10에서 상세히 다룸) 등을 가동해 감춰진 진짜 상태 $x_t$를 정확하게 복원하는 것.

### 1.4 생성 모델(Generative) vs 판별 모델(Discriminative)

관측 $z$에서 숨겨진 진짜 상태 $x$를 알아내는 데는 크게 두 가지 철학이 격돌합니다.

```
       [ 생성 모델 (Generative) ]                      [ 판별 모델 (Discriminative) ]
         
          "어떻게 생겨났는지 그린다"                      "경계선만 칼같이 자른다"
          
          사전분포 P(x) ──> 관측생성 P(z|x)                관측 z ──> 상태 P(x|z) 직접 매핑
          (설계도를 완벽히 이해함)                        (핵심 차이점에만 집중함)
```

#### 1. 생성 모델 (Generative Model)
*   **핵심 개념**: 상태 $x$와 관측 $z$가 동시에 일어나는 **결합 확률 분포 $P(z, x)$**를 모델링합니다. 
*   **원리**: 데이터가 만들어지는 **우주적인 인과관계(설계도)**를 배우는 것입니다. 
    $$P(z, x) = P(z \mid x)P(x)$$
    먼저 세상에 물체 상태 $x$가 존재할 확률(사전 확률 $P(x)$)을 정의하고, 그 상태에서 어떤 센서 이미지 $z$가 찍힐지(우도 $P(z \mid x)$)를 시뮬레이션한 뒤, 실제 관측 이미지와 가장 가깝게 맞아떨어지는 $x$를 찾아내는 방식입니다.
*   **⚖️ 미술가 비유**: 명품 가방의 가죽 질감, 바느질 기법, 로고의 미세한 굴곡(설계 구조)을 완벽하게 터득하여 진짜와 똑같은 가방을 스스로 창조할(샘플링) 수 있는 **"최고 기술의 위작 복제 화가"**와 같습니다.

#### 2. 판별 모델 (Discriminative Model)
*   **핵심 개념**: 관측 $z$가 주어졌을 때 상태 $x$가 될 **조건부 확률 $P(x \mid z)$**를 직접 계산합니다.
*   **원리**: 복잡한 물리 법칙이나 이미지 생성 과정 같은 설계도는 관심 없습니다. 오직 입력 이미지 $z$를 넣으면 물체의 상태 $x$가 튀어나오도록 수식을 직접 이어 붙이는(Mapping) 방식입니다. 
    *   *예: 2D 이미지 $z$를 입력하면 타겟 6D 자세 $x$를 다이렉트로 예측하는 CNN 구조(PoseCNN 등).*
*   **⚖️ 미술가 비유**: 이 가방이 진짜 명품인지 가짜인지 구별하기 위해 오직 로고의 폰트 두께와 바느질 개수(결정적 특징)만 매섭게 노려보고 감정하는 **"미술품 감정사"**와 같습니다.

| 비교 항목 | 생성 모델 (Generative) | 판별 모델 (Discriminative) |
|:---:|:---|:---|
| **수학적 대상** | 결합 확률 분포 $P(z, x)$ | 조건부 확률 $P(x \mid z)$ |
| **작동 방식** | 상태에서 관측을 시뮬레이션한 뒤 매칭 | 관측에서 상태로 곧바로 추론 (신경망 매핑) |
| **대표적 장점** | 물리 기하학적 해석이 명확하고, 예외적인 상황(Out-of-distribution)에 강함 | 데이터가 많을 때 압도적으로 빠르고 높은 정확도를 자랑함 |
| **대표적 단점** | 고차원 이미지에 대한 우도 분포 $P(z \mid x)$를 완벽히 수학적으로 쓰기가 불가능에 가까움 | 블랙박스 모델인 경우가 많아 오작동 시 왜 틀렸는지 디버깅이 어려움 |

## 2. 표현 학습 (Representation Learning)

### 2.1 컴퓨터 비전에서의 세 가지 표현 레이어

원시 센서 데이터가 입력되어 최종 제어 명령이 떨어지기까지, 데이터는 다음의 세 단계로 형태를 바꿉니다.

```
 [원시 데이터 입력]                 [요약 및 압축]                [최종 의사결정]
  입력 표현 (Input)  ───────────>  중간 표현 (Latent) ───────────>  출력 표현 (Output)
  (2D 이미지 픽셀)                (핵심 정보 요약 벡터)             (물체 분류, 6D 자세)
```

1.  **입력 표현 (Input Representation)**: 
    *   센서가 날것 그대로 받아들인 고차원의 데이터입니다. 
    *   *예: $1920 \times 1080$ 해상도의 RGB 픽셀 값들 (약 600만 차원의 거대한 행렬).*
2.  **중간 표현 (Intermediate / Latent Representation)**:
    *   이 장의 주인공입니다. 쓸모없는 노이즈를 다 걷어내고 물체의 기하적 구조, 색상 요약, 텍스처 등 본질만 쏙 뽑아내어 차원을 극도로 낮춘 **"알짜배기 임베딩 벡터"**입니다.
3.  **출력 표현 (Output Representation)**:
    *   최종 태스크에서 요구하는 정답 포맷입니다. 
    *   *예: "이 사진은 멸종위기 물고기 흰동가리입니다"라는 클래스 레이블, 혹은 "앞 차와의 거리 2.5m"라는 제어값.*

#### 🌟 훌륭한 중간 표현이 갖추어야 할 5대 골든 룰 (Bengio, 2013)
*   **간결성 (Compact)**: 수백만 개의 픽셀 데이터를 단 128개나 256개의 차원으로 획기적으로 압축해야 합니다.
*   **설명력 (Explanatory)**: 압축했음에도 불구하고, 원본이 가진 물리적 특징(형태, 조명, 각도)을 복원할 수 있을 만큼 핵심 정보를 보존해야 합니다.
*   **분리성 (Disentangled)**: 물체의 '색상'을 담당하는 변수와 '회전 각도'를 담당하는 변수가 서로 꼬이지 않고 독립적으로 물리적 의미를 담고 있어야 합니다.
*   **계층성 (Hierarchical)**: 저수준의 단순한 정보(엣지, 코너)가 결합되어 고수준의 추상적 정보(얼굴, 자동차 바퀴)를 이루는 단계별 피라미드 구조를 지녀야 합니다.
*   **다운스트림 최적화 (Downstream Utility)**: 이 요약 벡터를 최종 분류기나 제어기에 넘겨주었을 때 복잡한 연산 없이도 최고의 성능을 내야 합니다.

### 2.2 전통적 컴퓨터 비전: 장인이 한 땀 한 땀 깎아 만든 표현 (~2012년)

딥러닝 혁명 이전, 선배 엔지니어들은 중간 표현을 만들기 위해 인생을 바쳐 수학적 필터를 설계했습니다. 이를 **수공 설계 특징(Hand-crafted Features)**이라고 합니다.

```
 [ 전통적인 특징 추출 파이프라인 ]

  원본 이미지 ───> [ 엣지(Edge) 검출 ] ───> [ 기하학적 텍스처 ] ───> 선형 분류기 ───> "흰동가리"
                   [ 색상 히스토그램 ]       [ SIFT / HOG 특징 ]
                          ^
                  (사람 장인이 설계한 필터)
```

*   **장점 (해석 가능한 투명함)**: 사람이 직접 "소벨 필터(Sobel Filter)"나 "SIFT 특징점"을 코딩했기 때문에, 시스템이 왜 오작동했는지 수학적으로 100% 추적하고 해석할 수 있었습니다. 의료나 사법 도메인처럼 설명 가능성(Explainability)이 절실한 곳에서는 엄청난 장점입니다.
*   **단점 (지독한 확장성의 한계)**: 조명 조건이 조금만 바뀌거나 카메라 렌즈가 달라지면 사람이 필터의 임계값(Threshold)을 다시 튜닝해야 했습니다. 수천 명의 박사들이 평생 동안 수동 필터를 설계하는 지치고 기나긴 작업이었습니다.

### 2.3 현대 컴퓨터 비전: 스스로 진화하는 합성곱 신경망 (2012년~현재)

딥러닝의 등장과 함께, 귀찮은 수동 설계 과정은 **"학습된 중간 표현 (Learned Representation)"**으로 패러다임이 통째로 전환됩니다. 대표 주자가 바로 **합성곱 신경망 (CNN)**입니다.

> 🎨 **친절한 비유 (사람 장인의 돋보기 vs 스스로 굴곡을 깎는 AI 렌즈)**
> 
> *   **전통적 CV**: 장인이 돋보기의 두께와 각도를 자로 재어 정교하게 깎아 고정해 둔 상태입니다. 조명이 어두워지면 이 돋보기는 아무 쓸모가 없어집니다.
> *   **현대 CNN**: 렌즈 유리를 기계에 넣어두고, 수백만 장의 사진을 보여주며 눈을 찌푸리게 만듭니다. 신경망은 역전파(Backpropagation)라는 도구로 오차를 줄이기 위해 **스스로 렌즈 표면의 굴곡(가중치 $W$)을 깎아나가며 최적의 초점을 찾아냅니다.**

#### 🔍 신경망 속을 들여다본 거장들: Zeiler & Fergus (2014)
사람들은 신경망을 "안이 보이지 않는 깜깜한 블랙박스"라고 비판했습니다. 이에 Zeiler와 Fergus는 CNN 내부의 각 레이어가 어떤 이미지 조각에 가장 격렬하게 반응(활성화)하는지 시각화하는 멋진 연구를 수행했습니다.

그 결과는 놀랍게도 **인간이 설계했던 계층적 중간 표현과 정확히 일치**하고 있었습니다!

```
[ CNN이 스스로 학습한 인지적 계층 구조 ]

  Layer 1 (저수준) : 가로/세로 엣지, 대각선 선분, 기본 색상 경계선 추출
  Layer 2 (중수준) : 엣지들이 엮인 원형 텍스처, 스트라이프 패턴, 격자 모양 인지
  Layer 3 (고수준) : 특정 동물의 귀 모양, 타이어 휠, 꽃잎 등 구체적인 부분(Part) 포착
  Layer 4-5 (최고) : 강아지 전체 실루엣, 부엌 배경 등 고차원적 개념 완성
```

#### 🗺️ 수만 차원의 지도를 2D로 펼치기: t-SNE 시각화
신경망이 완성한 중간 표현 벡터는 대개 512차원이나 2048차원의 고차원 공간에 둥둥 떠다닙니다. 사람은 이를 눈으로 볼 수 없습니다. 이때 차원을 2차원으로 예쁘게 압축해 평면에 흩뿌려주는 기술이 **t-SNE(t-distributed Stochastic Neighbor Embedding)**입니다.

*   **수학적 목표**: 고차원에서 서로 친했던(유사했던) 벡터들끼리는 2D 평면에서도 다정하게 뭉쳐 있게 만들고, 안 친한 녀석들은 멀리 찢어놓는 것입니다. (이를 위해 두 공간 분포 사이의 **KL 발산(Kullback-Leibler Divergence)**을 0에 가깝게 최소화합니다.)
*   t-SNE 결과물을 보면, 클래스 레이블 정보를 전혀 주지 않고 이미지들만 뭉쳐 놓았음에도 **"스스로 고양이 사진끼리, 트럭 사진끼리 옹기종기 모여 있는 아름다운 대륙 지도"**가 펼쳐지는 것을 목격할 수 있습니다.

### 2.4 비지도 학습(Unsupervised)과 자기지도 학습(Self-Supervised)

지도 학습(Supervised Learning)은 강력하지만, 데이터 한 장 한 장에 정답 라벨을 붙여주는 "인간 라벨러들의 눈물겨운 수작업"이 필요합니다. 

*"정답 라벨이 없는 수십억 장의 유튜브 이미지로도 스스로 똑똑해질 수 있는 방법은 없을까?"* 이 질문에서 탄생한 것이 **오토인코더**와 **자기지도 학습**입니다.

#### 1. 오토인코더 (Autoencoder) : 모래시계의 병목 마법
오토인코더의 단 하나의 철학은 **"나를 그대로 복제하라"**입니다. 입력 데이터 $\mathbf{X}$를 고스란히 정답 $\mathbf{X}$로 사용하여 학습합니다.

```
 [ 오토인코더 (Autoencoder) 구조 ]

   입력 X (High-dim)                                출력 X̂ (Reconstructed)
   ┌──────────────┐                                ┌──────────────┐
   │  ■ ■ ■ ■ ■   │  인코더 (Encoder)              │  ■ ■ ■ ■ ■   │
   │   ■ ■ ■ ■    ├────────────┐      ┌────────────┤   ■ ■ ■ ■    │
   │    ■ ■ ■     │            │      │            │    ■ ■ ■     │
   └──────────────┘            v      v            └──────────────┘
                       병목 구간 (Bottleneck)
                       중간 표현 z (Low-dim)
                       ┌──────────────┐
                       │    ■ ■ ■     │
                       └──────────────┘
```

1.  **인코더 (Encoder)**: 수만 차원의 입력 이미지 $\mathbf{X}$를 아주 좁은 **병목 구간 (Bottleneck)**인 중간 표현 $\mathbf{z}$로 사정없이 억누르며 압축합니다.
2.  **디코더 (Decoder)**: 억눌린 좁은 문을 통과한 가느다란 끈 $\mathbf{z}$만을 보고, 다시 풍성한 원본 해상도의 이미지 $\mathbf{X̂}$로 복원해 냅니다.

$$\arg\min_{\mathcal{F}} \mathbb{E}_{\mathbf{X}} [||\mathcal{F}(\mathbf{X}) - \mathbf{X}||^2] \tag{3}$$

*   $\mathbf{X}$: 입력 이미지
*   $\mathcal{F}(\mathbf{X})$: 인코더와 디코더를 모두 통과하여 재구성된 출력 이미지
*   $||\mathcal{F}(\mathbf{X}) - \mathbf{X}||^2$: 원본과 재구성 이미지 사이의 픽셀 단위 차이인 **재구성 손실 (Reconstruction Loss)**

> ⏳ **친절한 비유 (해리포터 요약본과 스파이의 암호문)**
> 
> 친구에게 1,000페이지짜리 소설책 <해리포터와 마법사의 돌>을 그대로 타이핑해서 메신저로 전송하라는 미션을 받았습니다. 하지만 데이터 용량이 모자라 단 5페이지 분량의 **요약 요점 정리(중간 표현 $\mathbf{z}$)**만 보낼 수 있습니다.
> 
> 만약 친구가 그 5페이지의 핵심 요점 정리만 읽고도, 1,000페이지 분량의 세부 대사와 묘사를 원래대로 완벽하게 되살려 적어낼 수 있다면(디코더의 복원)? 그 5페이지 요약본은 소설책의 엑기스 중의 엑기스(가장 강력한 상태 표현)를 담고 있음을 방증하는 것입니다.

#### 2. 자기지도 학습 (Self-Supervised Learning) : 정답지 없이 스스로 푸는 빈칸 채우기
자기지도 학습은 데이터를 구하기 쉽다는 장점을 극대화하기 위해, **"입력 데이터의 일부분을 스스로 가리고(Masking), 가려진 빈칸을 채워 넣는 정답지로 삼아 학습"**하는 영리한 전략입니다.

```
 [ 자기지도 학습의 빈칸 채우기 예시 ]

   원본 이미지 X                                  네트워크 입력               스스로 푸는 문제
   ┌──────────────┐                              ┌──────────────┐            ┌──────────────┐
   │  ┌───────┐   │  임의로                      │  ┌───────┐   │            │   ???????    │
   │  │ (얼굴)│   │  얼굴 영역을                 │  │ (펑크)│   │  ────────> │   (얼굴)     │
   │  └───────┘   │  까맣게 구멍 뚫음             │  └───────┘   │            │   정답 복원!  │
   └──────────────┘                              └──────────────┘            └──────────────┘
```

*   **📝 친절한 비유 (영어 문제집 빈칸 메우기)**
    영어를 전혀 못 하는 아이에게 문법 정답 해설지(라벨)를 주지 않고 영어 소설책을 통째로 쥐여 줍니다. 그리고 소설책 속 임의의 단어들을 까맣게 지워버린 시험지(Masked Input)를 풀게 만듭니다.
    
    *"I went to the [  ?  ] to buy some milk."*
    
    아이는 문장에 들어갈 단어가 `store`나 `mart`라는 것을 유추하기 위해 주변 문맥을 뼈저리게 분석할 수밖에 없습니다. 이 빈칸 채우기 훈련을 수억 번 반복하면, 정답 해설지 없이도 **영어 단어 간의 완벽한 문맥적 구조와 의미 표현을 스스로 마스터하게 됩니다.**

*   **실제 다운스트림 활용 시나리오**:
    1.  **비지도 단계**: 정답이 없는 수백만 장의 풍부한 무상 이미지들로 오토인코더나 자기지도 빈칸 채우기 학습을 돌려, 뼈대가 굵고 튼튼한 **인코더 네트워크**를 완성합니다.
    2.  **전이 학습 단계**: 이제 인코더 뒷단에 아주 가벼운 분류기(Classifier) 한 장만 가볍게 얹어줍니다.
    3.  **미세 조정 단계**: 우리가 가진 **극소량의 진짜 비싼 정답 라벨 데이터**만을 사용해 분류기를 살짝 훈련(Fine-tuning)시킵니다. 이미 인코더가 우주의 물리적 형태와 이미지를 마스터해 둔 상태이므로, 단 1%의 데이터만으로도 지도 학습으로만 처음부터 훈련한 모델을 가볍게 뛰어넘는 고품질의 정확도를 확보할 수 있습니다.
