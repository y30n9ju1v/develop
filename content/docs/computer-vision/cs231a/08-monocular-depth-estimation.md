> 👁️ **질문**: **"사람은 한쪽 눈만 감고 세상을 바라보아도 어느 물체가 멀리 있고 어느 물체가 가까이 있는지 꽤 정확하게 짐작해 냅니다. 카메라도 렌즈가 단 하나뿐인 상황(단안, Monocular)에서, 값비싼 LiDAR나 양안 스테레오 카메라 도움 없이 공간의 깊이(Depth)를 알아낼 수 있을까요?"**
>
> 3D 공간을 2D 이미지 평면으로 투영하는 순간, 깊이 방향의 정보는 수학적으로 완전히 소실됩니다. 이 파괴적인 손실을 지적 직관과 정교한 기하학적 제약 조건으로 극복해내는 **단안 깊이 추정**과, 시퀀스 속에서 끈질기게 픽셀을 따라가는 **특징 추적**의 세계를 해부합니다.

## 1. 에피폴라 기하학과 시차(Disparity)의 수학적 기초

3D 점 $P(X, Y, Z)$가 수평으로 나란히 정류된(Rectified) 두 대의 카메라 이미지 평면에 투영될 때, 투영된 2D 픽셀 위치 사이의 수평 거리를 **시차(Disparity, $d$)**라고 합니다.

```
       [ 시차(Disparity)와 깊이(Depth)의 삼각측량 기하학 ]

                   3D 점 P (X, Y, Z)
                         /\
                        /  \
                       /    \ <─── 깊이 Z (우리가 찾고자 하는 값!)
                      /      \
                     /        \
       ─────────────/──────────\───────────── 이미지 평면
                   *            *
               p_u (왼쪽)     p'_u (오른쪽)
               └─── 시차 d ────┘
                    
       [카메라 CL] ────────────────── [카메라 CR]
                     기준선 b (Baseline)
```

두 카메라의 광학 중심 간의 물리적 거리인 **기준선(Baseline) $b$**와 카메라의 **초점 거리(Focus Length) $f$**가 주어졌을 때, 유사 삼각형의 비례 관계에 의해 깊이 $Z$와 시차 $d$는 완벽한 **역비례 관계**를 이룹니다.

$$\frac{d}{b} = \frac{f}{Z} \implies Z = \frac{f \cdot b}{d} \tag{1}$$

*   **시차 $d = p'_u - p_u$**: 왼쪽 이미지의 투영 좌표와 오른쪽 이미지의 투영 좌표 간의 픽셀 차이.
*   **교훈**: **시차 $d$가 클수록** 물체는 바로 눈앞에 있고(**깊이 $Z$가 작음**), **시차 $d$가 $0$에 수렴할수록** 저 멀리 있는 별처럼 아득한 위치에 존재합니다(**깊이 $Z$가 무한히 큼**).

> ⚠️ **고전 기하학의 한계**:
> 전통적인 기하학에서는 왼쪽 이미지의 픽셀과 짝을 이루는 오른쪽 이미지의 대응점(Correspondence)을 에피폴라 선 상에서 매칭했습니다. 하지만 텍스처가 없는 단색 벽면, 반복되는 체크무늬 패턴, 물체에 가려진 영역(Occlusion)에서는 매칭이 완전히 터져버렸습니다.

## 2. 단안 깊이 추정 (Monocular Depth Estimation)

단안 깊이 추정은 한 장의 RGB 입력 이미지 $I$로부터 각 픽셀별 깊이 맵 $D$를 만들어내는 신비로운 태스크입니다. 정보가 누락된 **미결정 문제(Underconstrained Problem)**이지만, 딥러닝은 원근감, 물체의 표준 크기, 조명의 명암, 가림 관계 등의 단서(Monocular Cues)를 데이터로부터 스스로 학습해 냅니다.

---

### 2.1 지도 학습 기반 추정 (Supervised Learning)

*   **구조**: RGB 이미지를 CNN 인코더-디코더에 통과시켜 픽셀별 시차/깊이 맵을 다이렉트로 예측합니다.
*   **손실 함수**: 예측 깊이와 LiDAR 등으로 측정한 진짜 깊이(Ground Truth)의 직접적인 오차를 최소화합니다.
*   **한계**: LiDAR 장비를 단 자율주행 차량이 대규모로 돌아다니며 촬영한 도시 도로처럼, **실측 깊이 라벨을 수집하기 극도로 용이한 특수 도메인에서만 작동**합니다. 일반 실내나 심해, 숲속 이미지에는 지도 학습을 적용하기가 불가능합니다.

---

### 2.2 비지도 학습 기반 추정 (Unsupervised Learning)

실측 깊이 데이터(Ground Truth)가 한 장도 없는 상황에서, 오직 **정류된 스테레오 카메라 시스템에서 찍힌 좌/우 이미지 쌍 $(I^l, I^r)$**만을 이용하여 깊이를 학습하는 극적인 방법입니다 (Godard et al., 2017).

> 💡 **핵심 아이디어: "이미지 재구성 (Image Reconstruction)"**
> 
> "내가 예측한 깊이(시차)가 정확하다면, 그 시차 정보를 이용해 오른쪽 이미지를 픽셀 단위로 뜯어다가 왼쪽 이미지로 완벽히 리모델링(재구성)해낼 수 있을 것이다!"

```
  [ 비지도 학습 이미지 재구성 파이프라인 ]

  입력 왼쪽 이미지 I^l ───> [ CNN 인코더-디코더 ] ───> 왼쪽 정렬 시차 d^l 예측
                                                    │
                                                    v
  재구성 이미지 Ĩ^l  <─── [ 이중선형 샘플러 ] <────────┘ (오른쪽 이미지 I^r을 d^l만큼 당김)
        │
        v
  [ 손실 계산 ] <─── 원본 왼쪽 이미지 I^l과 재구성 이미지 Ĩ^l 비교 (L1 + SSIM)
```

CNN은 오직 왼쪽 이미지 $I^l$만 입력받아 시차 맵 $d^l$을 출력합니다. 그 다음 **미분 가능한 이중선형 샘플러(Differentiable Bilinear Sampler)**를 통해 오른쪽 이미지 $I^r$의 픽셀들을 $d^l$만큼 횡이동시켜 왼쪽 이미지를 복제해 냅니다.

$$\tilde{I}^l(u, v) = I^r(u - d^l(u, v), v) \tag{2}$$

만약 예측한 시차 $d^l$이 틀렸다면, 재구성된 이미지 $\tilde{I}^l$은 원본 $I^l$과 심하게 뭉개지거나 다르게 나타나 오차(Loss)가 치솟게 됩니다.

#### 🛠️ 학습을 지탱하는 3가지 마법의 손실 함수 (Loss Functions)

$$\mathcal{C}_s = \alpha_{ap}(\mathcal{C}^l_{ap} + \mathcal{C}^r_{ap}) + \alpha_{ds}(\mathcal{C}^l_{ds} + \mathcal{C}^r_{ds}) + \alpha_{lr}(\mathcal{C}^l_{lr} + \mathcal{C}^r_{lr}) \tag{3}$$

##### ① 외관 매칭 손실 ($\mathcal{C}_{ap}$) : "내 눈에 똑같이 보이는가?"
단순한 픽셀 단위 절댓값 차이($L1$)뿐만 아니라, 인간의 시각적 인지 구조와 유사하게 이미지의 대비와 휘도를 평가하는 **SSIM(Structural Similarity Index)**를 결합하여 고품질의 재구성을 유도합니다.

$$\mathcal{C}^l_{ap} = \frac{1}{N}\sum_{i,j} \alpha \frac{1 - \text{SSIM}(I^l_{ij}, \tilde{I}^l_{ij})}{2} + (1-\alpha)\|I^l_{ij} - \tilde{I}^l_{ij}\|_1 \tag{4}$$

*   보통 $\alpha = 0.85$로 지정하여 구조적 유사도(SSIM)에 더 강력한 무게중심을 둡니다.

##### ② 엣지 인식 평활화 손실 ($\mathcal{C}_{ds}$) : "부드럽게 잇되, 절벽은 인정하라"
기본적으로 물체의 깊이는 매끄럽게 이어집니다. 하지만 물체와 배경이 만나는 절벽 같은 엣지(Edge) 경계면에서는 깊이가 급격하게 변해야 합니다.

$$\mathcal{C}^l_{ds} = \frac{1}{N}\sum_{i,j} \left| \partial_x d^l_{ij} \right| e^{-\| \partial_x I^l_{ij} \|} + \left| \partial_y d^l_{ij} \right| e^{-\| \partial_y I^l_{ij} \|} \tag{5}$$

*   **🛡️ 친절한 비유 (단절을 막는 고무줄과 절단선 칼자국)**
    깊이 맵 위에 가상의 **팽팽한 고무줄**을 설치해 서로 급격히 튀지 않고 스무스하게 이어지도록 묶어둡니다($|\partial d|$ 페널티). 
    단, 원본 이미지에 뚜렷한 칼자국(강한 색상 엣지 $|\partial I|$가 크면 $e^{-\|\partial I\|}$가 0으로 수렴)이 그어져 있는 곳에서는 고무줄을 **툭 끊어줍니다**. 덕분에 물체의 테두리 선에서는 깊이 맵이 흐리멍덩하게 번지지 않고, 칼로 자른 듯 날카로운 경계면을 보존하게 됩니다.

##### ③ 좌우 일관성 손실 ($\mathcal{C}_{lr}$) : "올 때와 갈 때가 같아야 한다"
네트워크가 왼쪽 시차 $d^l$과 오른쪽 시차 $d^r$을 동시에 뱉어내도록 구조를 확장한 뒤, 서로 크로스체크를 시킵니다.

$$\mathcal{C}^l_{lr} = \frac{1}{N}\sum_{i,j} \left| d^l_{ij} - d^r_{ij + d^l_{ij}} \right| \tag{6}$$

*   **🔄 친절한 비유 (번역과 역번역 일관성)**
    한국어 문장(`왼쪽 픽셀`)을 영어로 번역(`오른쪽 픽셀로 매칭 이동`)했다가, 그 영어 문장을 다시 한국어로 재번역(`오른쪽 시차만큼 컴백`)했을 때 원래 문장과 토씨 하나 틀리지 않고 똑같이 복원되어야 번역이 완벽히 되었다고 볼 수 있습니다. 이 유기적인 제약을 통해 가려진 영역(Occlusion)에서 허깨비 시차를 찍어내는 오작동을 원천 봉쇄합니다.

### 2.3 자기지도 학습 기반 추정 (Self-Supervised from Video)

스테레오 카메라도 필요 없습니다. 오직 **단일 렌즈 카메라로 찍은 연속적인 비디오 프레임 시퀀스**만을 학습 신호로 사용하는 기적의 기법입니다 (Monodepth2, Godard et al., 2019).

*   **타겟 이미지**: $t$ 시점의 컬러 프레임 $I_t$
*   **소스 이미지**: 시간적으로 인접한 직전/직후 프레임 $I_{t'} \in \{I_{t-1}, I_{t+1}\}$

#### ⚙️ 투톱 엔진: DepthNet과 PoseNet의 환상적인 콜라보

```
  [ Monodepth2 자기지도 학습 재투영 과정 ]

                 3D 공간으로 역투영                 카메라 모션 이동 (PoseNet)
  (1) 픽셀 u ───────────────────────> (2) 3D 점 P ───────────────────────────> (3) 변환된 3D 점 P'
      (입력 I_t의 좌표)                 (DepthNet의 D_t 이용)                      (T_{t ──> t'} 적용)
                                                                                  │
                                                                                  │ 새로운 2D 평면 투영
                                                                                  v
                                                                             (4) 픽셀 u'
                                                                                 (소스 I_t'의 좌표)
```

1.  **DepthNet (깊이 망)**: 현재 프레임 $I_t$만 보고 픽셀별 깊이 맵 $D_t$를 예견합니다.
2.  **PoseNet (자세 망)**: 두 프레임 $I_t$와 $I_{t'}$를 동시에 먹고, 카메라가 그 사이 동안 공간상에서 어떻게 기하학적으로 기어갔는지 상대 변환 행렬 **$T_{t \to t'}$ (Rotation, Translation)**을 예측합니다.
3.  **3D 재투영 (Reprojection)**:
    이 두 가지 정보($D_t$, $T_{t \to t'}$)와 카메라 고유 행렬 $K$가 결합되면, 현재 화면의 픽셀 $u$가 다음 화면 $I_{t'}$의 어떤 2D 좌표 $u'$로 순간이동했을지 완벽한 3D 투영 매핑 방정식을 세울 수 있게 됩니다!

$$u' \sim K \cdot T_{t \to t'} \cdot D_t(u) \cdot K^{-1} u \tag{7}$$

*   $K^{-1} u$: 2D 픽셀 좌표를 3D 카메라 레이저 광선 방향으로 복원.
*   $D_t(u)$: 깊이 값을 곱해 진짜 3D 점의 위치 $P$로 안착.
*   $T_{t \to t'}$: 카메라의 움직임을 반영하여 이웃 카메라 시점의 3D 공간 좌표로 워핑.
*   $K$: 이웃 카메라의 2D 이미지 평면 위 좌표 $u'$로 투영.

이 수학적 기하학 관계를 엔드투엔드로 미분 가능하게 엮어, **"재투영하여 합성해낸 영상과 실제 비디오 프레임 사이의 광도 오차(Photometric Error)를 최소화"**하도록 학습을 공략합니다.

## 3. 특징 추적과 학습된 밀집 서술자 (Dense Descriptors)

**특징 추적(Feature Tracking)**은 동영상 스트림 속에서 특정 관심 영역이나 물리적 점들이 프레임마다 어디로 요리조리 튀었는지 끈질기게 추적하는 엔진입니다. 

카메라 이동으로 인한 일시적 가림, 그림자로 인한 외형의 드라마틱한 변화 속에서도 흔들리지 않는 **강인한 기술자(Descriptor, $D$)**를 뽑아내는 것이 최종 병기입니다.

---

### 3.1 픽셀-대조 손실 (Pixel-Contrastive Loss)의 혁명

과거 SIFT 특징점 등은 사람이 수동으로 수학 공식을 짜서 만들었으나, Florence 등(2018)은 입력 이미지의 **모든 픽셀(W × H)**에 대해 고유한 물리적 아이덴티티를 내포한 $D$차원 조밀 벡터를 통째로 생성해내는 CNN 인코더-디코더 모델을 제안했습니다.

이 거대한 신경망은 **픽셀-대조 손실(Pixel-Contrastive Loss)**이라는 채찍으로 학습됩니다.

```
                  [ 픽셀-대조 손실의 물리적 인력/척력 작용 ]

                  진짜 동일한 3D 공간상의 점 (Matches)
                  D(I_a, u_a)  <─── 철컥! 자석처럼 서로 끌어당겨 ───>  D(I_b, u_b)
                                    (거리 L_matches 최소화)

                  서로 전혀 다른 물리적 영역 (Non-matches)
                  D(I_a, u_a)  <─── 저리 가! 서로 강하게 밀쳐냄 ───>  D(I_b, u_c)
                                    (거리 L_non-matches 최대화)
```

$$\mathcal{L}(I_a, I_b) = \mathcal{L}_{\text{matches}}(I_a, I_b) + \mathcal{L}_{\text{non-matches}}(I_a, I_b) \tag{8}$$

#### ① 매칭 손실 ($\mathcal{L}_{\text{matches}}$) : "우린 같은 몸이야!"
서로 다른 각도에서 찍은 두 이미지 $I_a, I_b$가 있을 때, 완벽히 동일한 물리적 3D 지점을 찍은 두 픽셀 $u_a, u_b$의 기술자 값은 기술자 공간에서 **거리를 0에 가깝도록 강력하게 잡아당깁니다.**

$$\mathcal{L}_{\text{matches}} = \frac{1}{N}\sum \| D(I_a, u_a) - D(I_b, u_b) \|^2 \tag{9}$$

#### ② 비매칭 손실 ($\mathcal{C}_{\text{non-matches}}$) : "너랑은 1%도 엮이기 싫어"
서로 다른 물리적 지점을 찍은 픽셀들에 대해서는 기술자 공간에서 일정 거리 마진 $M$ 이상으로 **서로를 거세게 밀어내 도망치게 만듭니다.**

$$\mathcal{L}_{\text{non-matches}} = \frac{1}{N}\sum \max\left( 0, M - \| D(I_a, u_a) - D(I_b, u_c) \|^2 \right) \tag{10}$$

---

### 3.2 로봇 팔을 이용한 자율 데이터 수집 시스템

이 어마어마한 양의 픽셀 대조 정답 쌍(Ground Truth Matches)을 사람이 눈으로 보며 클릭하는 것은 불가능합니다. 저자들은 이를 해결하기 위해 **로봇 팔(Robot Arm) 기하학**을 영리하게 결합했습니다.

```
       [ 로봇 팔 기반 자율 데이터 생성 아키텍처 ]

                /▒▒▒\  <── 로봇 팔 (Forward Kinematics로 실시간 자세 T_camera 파악)
               [카메라]
                 │   \
                 │    \  서로 다른 시점에서 캡처
                 v     v
              ┌─────────┐
              │ 물체 O  │ ───> 다각도 사진 촬영 ───> 3D 점군 재구성 (P_3D)
              └─────────┘
```

1.  **자세 추출**: 로봇 팔 끝단에 카메라를 달아 물체를 3D로 스캔합니다. 로봇 관절 모터 센서를 통해 카메라의 3D 공간상 절대 자세($T_{\text{camera}}$)를 정밀하게 실시간 계산합니다.
2.  **3D 재구성**: 촬영된 다각도 사진들을 던져 물체의 고정밀 3D 매시 모델을 만듭니다.
3.  **정답 매칭 무한 복사**: 카메라 자세와 3D 모델 구조를 완벽하게 알기 때문에, 임의의 $I_a$ 속 픽셀 $u_a$가 3D 공간의 어디를 터치하고 다른 이미지 $I_b$의 몇 번 픽셀 $u_b$로 가는지 **수학적으로 100% 무결점 정답 매칭을 무한대로 복사·생성(Auto-labeling)**해내며 기계식 학습을 성취합니다.

### 3.3 교차-객체 손실(Cross-Object Loss)과 클래스 일관성

*   **🚨 단일 대상의 덫**: 한 개의 신발만 가지고 학습을 하면, 네트워크는 그냥 신발의 흰색 픽셀과 검은색 픽셀을 구분하는 아주 쉬운 꼼수를 씁니다. 만약 다른 종류의 신발(신발 B)을 보여주면 기술자가 완전히 뒤엉켜버리는 참사가 일어납니다.
*   **💡 해결책: 교차-객체 손실 (Cross-Object Loss)**
    전혀 다른 물체 간(예: 파란색 모자와 빨간색 모자)의 모든 픽셀 쌍에 대해서는 아예 무조건 비매칭(Non-match)으로 분류하여 기술자 공간 상에서 거대한 담벼락을 쳐 분리시킵니다.
*   **🎉 얻어지는 효과: 클래스 일관적 기술자 (Class-Consistent Descriptors)**
    이 교차-객체 손실을 듬뿍 먹여 학습을 끝내면, 네트워크는 기적을 보여줍니다. 빨간 모자든, 파란 모자든, 줄무늬 모자든 상관없이 **"모자의 챙 끝부분"**에 해당하는 픽셀들은 기술자 공간 속의 **항상 동일한 챙 영역(Cluster)**에 모여 포지셔닝됩니다. 
    이 클래스 일관성 덕분에 로봇은 살면서 단 한 번도 보지 못한 미지의 새 모자를 마주하더라도 정확히 챙 부위를 짚어 들어 올리는 놀라운 정교함을 가지게 됩니다.

| 카테고리 | 지도 학습 (Supervised) | 스테레오 비지도 (Unsupervised) | 단안 자기지도 (Self-Supervised) |
|:---:|:---|:---|:---|
| **필요 센서** | RGB + LiDAR 등 활성 센서 | 캘리브레이션된 좌우 스테레오 카메라 | 단 한 대의 단안 비디오 카메라 |
| **정답 라벨** | 픽셀 단위 실제 깊이값 (GT) | 없음 (이미지 자체가 정답이 됨) | 없음 (미래/과거 프레임이 정답이 됨) |
| **핵심 손실** | LiDAR 깊이와 예측값 $L2$ 오차 | 좌측 이미지 재구성 오차 ($L1$ + SSIM)<br>좌우 일관성 손실 ($C_{lr}$) | 자세 예측 PoseNet을 활용한<br>인접 프레임 재투영 광도 오차 ($L_p$) |
