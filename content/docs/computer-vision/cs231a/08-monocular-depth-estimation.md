## 1. 개요

깊이 추정(depth estimation)과 특징 추적(feature tracking)은 모두 **대응점 문제(correspondence problem)**의 특수한 경우입니다. 물리적 3D 점이 여러 2D 이미지에 투영되는 위치를 찾는 것이 핵심입니다.

- **깊이 추정**: 한 장(단안) 또는 여러 장(스테레오)의 이미지에서 각 픽셀의 깊이(z좌표) 복원
- **특징 추적**: 이미지 시퀀스에서 2D 점들의 위치를 프레임마다 추적

## 2. 단안 깊이 추정 (Monocular Depth Estimation)

### 2.1 배경

깊이 추정은 3D 재구성, 로봇 파지, 자율주행 등 복잡한 과제의 핵심 구성 요소입니다. 구조광 스테레오나 LiDAR 같은 능동 방법도 있지만, 이 노트에서는 특수 하드웨어 없이 실외에서도 잘 동작하는 **수동(passive) 깊이 추정**에 집중합니다.

#### 에피폴라 기하학과 시차

정류된(rectified) 스테레오 설정에서 에피폴라 선은 수평이 됩니다. **시차(disparity)**는 두 대응점 사이의 수평 거리로 정의합니다.

$$d = p'_u - p_u, \quad p_u + d = p'_u$$

유사 삼각형 관계로부터 깊이 $z$와 시차 $d$ 사이의 역비례 관계를 얻습니다.

$$\frac{d}{b} = \frac{f}{z} \implies z = \frac{fb}{d}$$

여기서 $f$는 초점 거리, $b$는 두 카메라 사이의 기준선(baseline) 길이입니다. 기준선 $b$와 내부 파라미터 $K$를 알면, 정류된 두 이미지에서 대응점을 찾아 시차를 구하면 깊이를 알 수 있습니다.

단순한 1D 탐색(에피폴라 선을 따라 픽셀/패치 유사도 비교)은 가림(occlusion), 반복 패턴, 균일 영역(텍스처 없음)에서 실패합니다. 현대 표현 학습 방법을 사용합니다.

### 2.2 지도 학습 기반 추정

**단안(single-view) 깊이 추정**: 테스트 시 이미지 한 장만 사용하며 장면 내용에 대한 가정을 하지 않습니다.

단안 깊이 추정은 기하학적으로 **미결정(underconstrained)** 문제입니다. 하지만 인간은 원근법, 스케일, 조명, 가림 등의 단서를 이용해 한 눈으로도 깊이를 추정합니다. 컴퓨터도 이 단서들을 학습하면 가능합니다.

**완전 지도 방법**: CNN을 학습시켜 픽셀별 시차를 예측합니다.
- 입력: RGB 이미지
- 출력: 픽셀별 깊이/시차 맵
- 손실: 예측 깊이와 실측 깊이의 차이

단안 방법은 스케일까지만(up-to-scale) 깊이를 포착할 수 있으므로, **스케일 불변 오차(scale-invariant error)**를 사용합니다.

**한계**: 대량의 실측 깊이 데이터가 있는 장면 유형에만 사용 가능합니다.

### 2.3 비지도 학습 기반 추정

실측 깊이 데이터 없이 입력 RGB 프레임과 알려진 내부 파라미터를 가진 스테레오 카메라만으로 학습하는 방법입니다 (Godard et al., 2017).

문제를 **이미지 재구성**으로 재정식화합니다. 실측 깊이 차이 대신 입력 참조 이미지와 재구성된 이미지 $\tilde{I}^l$ 사이의 차이를 손실로 사용합니다.

#### 기준선 네트워크

- 입력: 왼쪽 프레임 $I^l$
- CNN이 $I^l$을 왼쪽 정렬 시차 $d^l$로 매핑
- $d^l$을 이용해 오른쪽 이미지 $I^r$을 샘플링하여 $\tilde{I}^l$ 재구성

$$\tilde{I}^l(u, v) = I^r(u - d^l(u, v), v)$$

$d^l(u,v)$가 정수가 아닐 수 있으므로 **미분 가능한 이중선형 샘플러(differentiable bilinear sampler)**를 사용하여 엔드투엔드 학습을 가능하게 합니다.

학습에는 왼쪽·오른쪽 이미지 모두 사용하지만, 테스트 시에는 왼쪽 이미지만으로 깊이를 추론합니다.

#### 개선된 네트워크: 좌우 재구성

CNN이 왼쪽 정렬 시차 $\tilde{d}^l_{i,j}$와 오른쪽 정렬 시차 $\tilde{d}^r_{i,j}$를 모두 출력합니다. 샘플러로 $\tilde{I}^l$과 $\tilde{I}^r$을 모두 재구성하고, 네 이미지(왼쪽·오른쪽 입력 및 재구성) 사이의 손실을 계산합니다.

총 손실은 각 스케일 $s$에서의 손실 합입니다.

$$C = \sum_s C_s$$

$$C_s = \alpha_{ap}(C^l_{ap} + C^r_{ap}) + \alpha_{ds}(C^l_{ds} + C^r_{ds}) + \alpha_{lr}(C^l_{lr} + C^r_{lr}) \tag{1}$$

세 가지 손실 항이 있습니다.

**① 재구성 손실 $C_{ap}$ (Appearance Matching)**

$$C^l_{ap} = \frac{1}{N}\sum_{i,j} \alpha \frac{1 - \text{SSIM}(I^l_{ij}, \tilde{I}^l_{ij})}{2} + (1-\alpha)\|I^l_{ij}, \tilde{I}^l_{ij}\| \tag{2}$$

각 픽셀 $(i,j)$에서 두 가지를 가중 결합합니다.
- **L1 차이**: 재구성 이미지와 실제 이미지의 픽셀별 절대 차이
- **SSIM(Structural Similarity Index)**: 패치의 휘도·대비·구조를 조합한 유사도 측정

논문에서 $\alpha = 0.85$로 SSIM을 L1보다 더 강조합니다.

**② 평활화 손실 $C_{ds}$ (Disparity Smoothness)**

$$C^l_{ds} = \frac{1}{N}\sum_{i,j} |\partial_x d^l_{ij}|e^{-\|\partial_x I^l_{ij}\|} + |\partial_y d^l_{ij}|e^{-\|\partial_y I^l_{ij}\|} \tag{3}$$

시차 맵의 x·y 방향 기울기를 페널티로 주어 시차 맵을 평활하게 만듭니다. 단, 이미지에서 엣지가 감지된 곳(이미지 기울기가 높은 곳)에서는 $e^{-\|\partial I\|}$가 작아져 평활화 페널티가 완화됩니다. 즉, **엣지에서는 큰 시차 변화를 허용**합니다.

**③ 좌우 일관성 손실 $C_{lr}$ (Left-Right Consistency)**

$$C^l_{lr} = \frac{1}{N}\sum_{i,j} |d^l_{ij} - d^r_{ij+d^l_{ij}}| \tag{4}$$

직관: 두 이미지 평면에서 대응 픽셀 사이의 절대 거리(시차)는 왼쪽→오른쪽이든 오른쪽→왼쪽이든 같아야 합니다. 왼쪽 정렬 시차 $d^l_{i,j}$와 대응하는 오른쪽 정렬 시차 $d^r_{i,j+d^l_{ij}}$ 사이의 L1 거리를 페널티로 줍니다.

이 비지도 방식이 기준선 및 기존 완전 지도 방법들을 능가했습니다.

### 2.4 자기지도 학습 기반 추정

비지도 방법에 이어, 깊이 추정을 **새로운 뷰 합성(novel view synthesis)** 문제로 재정식화합니다 (Godard et al., 2019).

**핵심 아이디어**: 목표 이미지가 주어졌을 때, 학습된 파이프라인이 다른 시점에서 장면이 어떻게 보일지 예측합니다. 깊이가 중간 표현으로 사용되어 테스트 시에 추출 가능합니다.

단안 비디오를 지도 신호로 사용합니다.
- 목표 이미지: 시각 $t$의 컬러 프레임 $I_t$
- 소스 뷰: 시간적으로 인접한 프레임 $I_{t'} \in \{I_{t-1}, I_{t+1}\}$

현재 입력에서 미래·과거 입력을 예측하는 것이므로, 전체 원본 입력을 재구성하는 것과 달리 **자기지도 학습**의 예시입니다.

#### 파이프라인

1. **(a) 깊이 네트워크**: 컬러 입력 $I_t$를 합성곱 인코더-디코더에 통과시켜 깊이 맵 $D_t$ 획득
2. **(b) 자세 네트워크**: 소스 프레임 $I_{t'}$을 순회하며 상대 자세 변환 $T_{t \to t'}$ 예측
3. **(c) 재투영**: $K$와 예측 깊이 $D_t$로 2D 좌표 $(u,v)$를 3D 점으로 역투영 → 상대 자세 $T_{t \to t'}$로 소스 뷰의 이미지 평면에 투영 → 2D 좌표 $(u', v')$ 획득

"합성된" 뷰 $\tilde{I}_{t'}(u', v') = I_t(u, v)$와 실제 프레임 $I_{t'}$ 사이의 시각적 유사성을 **광도 오차(photometric error)**로 측정합니다.

$$pe(I_a, I_b) = \frac{\alpha}{2}(1 - \text{SSIM}(I_a, I_b)) + (1-\alpha)\|I_a - I_b\|_1 \tag{5}$$

$$L_p = \sum_{t'} pe(I_t, I_{t' \to t}) \tag{6}$$

광도 오차는 모든 2D 좌표의 재투영 오차 $pe(\tilde{I}_{t'}(u', v'), I_{t'}(u', v'))$를 최소화하는 최적 깊이 맵 $D_t$를 찾습니다.

이 자기지도 방식이 기존 비지도 및 다른 자기지도 방법들을 능가했습니다.

## 3. 특징 추적 (Feature Tracking)

### 동기

이미지 시퀀스가 주어졌을 때, **특징 추적**은 모든 이미지에서 2D 점들의 위치를 추적하는 과제입니다. 이 역시 이미지 시퀀스에 걸쳐 대응점 문제를 푸는 또 다른 사례입니다.

특징 추적으로 장면 속 물체의 움직임을 추적할 수 있습니다. 카메라나 장면 내용에 대한 가정을 하지 않습니다.

**도전 과제**: 카메라 이동(특징 완전 소실), 그림자, 가림 때문에 이미지 특징의 외관이 프레임마다 크게 변할 수 있습니다. 외관 모델이 업데이트되면서 작은 오차가 누적되어 **드리프트(drift)**가 발생할 수 있습니다.

목표: 쉽고 일관되게 추적할 수 있는 **고유한 영역(특징 또는 키포인트)**을 식별하고, 단순한 추적 방법으로 대응점을 지속적으로 찾는 것입니다.

### 기술자 (Descriptor)

픽셀 $k$에 대해 $D$차원 표현 $D(k)$를 기술자라고 합니다(주변 정보를 포함하는 경우가 많음).

$k$와 $k'$가 같은 3D 점에 대응한다면, 서로 다른 시점에서 촬영되어도 시각적으로 유사할 것이므로 기술자도 같아야 합니다.

$$D(k) = D(k')$$

기술자 간의 유사도를 기반으로 서로 다른 프레임의 픽셀을 매칭합니다.

전통적으로는 Harris 코너, SIFT 등 수공 설계 방법으로 특징을 탐지하고 기술자를 만들었습니다. 이 방법들은 **희소(sparse)**하여 이미지 픽셀의 일부에만 기술자를 제공합니다.

## 4. 학습된 밀집 서술자 (Learned Dense Descriptors)

Florence et al. (2018)의 방법을 살펴봅니다.

### 목표

입력 컬러 이미지의 **모든 픽셀**에 대해 $D$차원 기술자를 출력하는 매핑 $f(\cdot)$을 학습합니다.

"밀집(dense)"이란 희소 집합이 아닌 입력 이미지의 모든 점에 기술자가 있다는 의미입니다.

```
입력: RGB 이미지 (W × H × 3)
출력: 기술자 맵 (W × H × D)
f(·): 합성곱 인코더-디코더 아키텍처
```

시각화를 위해 $D$차원 기술자를 차원 축소하여 RGB로 매핑합니다.

### 픽셀-대조 손실 (Pixel-Contrastive Loss)

네트워크는 서로 다른 뷰에서 찍은 같은 물체의 이미지 쌍 $(I_a, I_b)$으로 학습합니다.

**매칭 손실** (대응 점들의 거리 최소화):

$$L_{\text{matches}}(I_a, I_b) = \frac{1}{N_{\text{matches}}} \sum_{N_{\text{matches}}} D(I_a, u_a, I_b, u_b)^2 \tag{7}$$

**비매칭 손실** (비대응 점들의 거리 최대화):

$$L_{\text{non-matches}}(I_a, I_b) = \frac{1}{N_{\text{non-matches}}} \sum_{N_{\text{non-matches}}} \max(0, M - D(I_a, u_a, I_b, u_b)^2) \tag{8}$$

$M$은 최대 거리입니다. max 연산은 거리를 $M$까지만 최대화합니다.

**총 손실**:

$$L(I_a, I_b) = L_{\text{matches}}(I_a, I_b) + L_{\text{non-matches}}(I_a, I_b) \tag{9}$$

### 자율적 데이터 수집

실측 대응점을 대규모로 저렴하게 얻는 것이 과제입니다. 저자들은 **로봇 팔**을 사용하여 자율적·자기지도적 데이터 수집을 제안합니다.

```
데이터 수집 과정:
1. 로봇 팔로 정지 물체의 다양한 자세에서 이미지 캡처
2. 로봇 팔의 순방향 운동학(forward kinematics)을 알기 때문에
   카메라 자세와 대응 뷰를 매칭
3. 모든 뷰로 3D 재구성 → 물체의 3D 모델 획득
4. 카메라 자세·3D 점·이미지로 원하는 만큼 실측 대응점 생성
```

배경 무작위화, 데이터 증강, 어려운 음성 스케일링 등의 기법과 함께 수식 9로 학습합니다.

### 교차-객체 손실 (Cross-Object Loss)

같은 물체 쌍만으로 학습하면, 서로 다른 물체에 대한 학습된 기술자가 겹쳐서 완전히 다른 개체임에도 혼동될 수 있습니다.

**교차-객체 손실**: 서로 다른 두 물체 이미지의 모든 픽셀을 비매칭으로 처리합니다.

교차-객체 손실을 추가하면 기술자 공간에서 물체마다 **뚜렷한 군집**이 형성됩니다.

반대로, 같은 클래스의 물체들은 외관이 달라도 유사한 기술자를 가져야 합니다. 네트워크는 이를 학습할 수 있습니다: 색상과 디자인이 다른 모자들의 기술자가 같은 구조와 색상을 공유합니다 → **클래스 일관 기술자(class-consistent descriptors)**.

## 정리

```
단안 깊이 추정 방법 비교:

지도 학습
├── 입력: RGB + 실측 깊이
├── 손실: 예측 깊이 - 실측 깊이
└── 한계: 대량의 레이블 필요

비지도 학습 (Godard et al., 2017)
├── 입력: 스테레오 RGB (레이블 불필요)
├── 손실: C = α_ap(C_ap) + α_ds(C_ds) + α_lr(C_lr)
│   ├── C_ap: SSIM + L1 재구성 손실
│   ├── C_ds: 엣지 인식 평활화 손실
│   └── C_lr: 좌우 일관성 손실
└── 성능: 기존 지도 방법 능가

자기지도 학습 (Godard et al., 2019)
├── 입력: 단안 비디오 (레이블 불필요)
├── 깊이 네트워크 + 자세 네트워크
├── 손실: 광도 오차 L_p = Σ pe(I_t, I_{t'→t})
└── 성능: 기존 비지도 방법 능가

특징 추적: 학습된 밀집 서술자
├── 모든 픽셀에 D차원 기술자 (밀집)
├── 픽셀-대조 손실: 매칭(거리 최소화) + 비매칭(거리 최대화)
├── 로봇 팔로 자율 데이터 수집
└── 교차-객체 손실로 클래스 일관 기술자 학습
```
