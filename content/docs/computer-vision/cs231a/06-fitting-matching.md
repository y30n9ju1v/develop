> 이때 뒤에서 묵묵히 행렬 연산을 지탱하던 수학적 기술이 바로 **피팅(Fitting)**입니다.
>
> 💡 **질문**: **"실제 카메라 노이즈와 터무니없는 가짜 데이터(Outliers)가 뒤섞인 혼돈 속에서, 어떻게 진짜 물리적 모델 파라미터를 정확하게 뽑아낼 수 있을까?"**

## 1. 개요

현실의 관측 데이터에는 언제나 측정 오차(Noise)와 엉뚱한 매칭 실패로 인한 쓰레기 데이터(Outliers)가 섞여 있습니다. 이 혼돈의 데이터로부터 직선, 원, 혹은 카메라 행렬 같은 수학적 모델을 찾아내는 최적 파라미터 추정 기법들을 비교해 봅니다.

---

## 2. 최소제곱법 (Least-Squares)

### 2.1 일반 최소제곱법 (Ordinary Least Squares)과 한계

> ⚠️ **친절한 비평 (이상한 값 하나에 휘둘리는 무책임함)**
> 
> 일반 최소제곱법은 수많은 2D 점들에 대해 직선 $y = mx + b$를 그릴 때, **"각 점들의 y축 방향 거리 제곱"**의 합을 최소화합니다.
> 
> 제곱 비용($e^2$)을 사용하기 때문에 치명적인 약점이 있습니다. 모델에 완벽히 부합하는 99개의 깨끗한 점들이 있더라도, 저 멀리 엉뚱하게 박힌 **단 1개의 쓰레기 데이터(이상값, Outlier)**가 있다면 제곱 연산($1000^2 = 1,000,000$)에 의해 엄청난 페널티를 받게 됩니다.
> 
> 결국 전체 직선이 그 1개의 이상값에 이끌려 심하게 비틀어지는 **무책임한 결과**를 초래합니다. 또한, 수직선($x = c$, 즉 기울기 $m = \infty$)은 물리적으로 기술할 수 없어 연산이 폭발해 버리는 한계가 있습니다.

---

### 2.2 전체 최소제곱법 (Total Least Squares)

수직선 한계를 깨부수기 위해 직선을 $ax + by + c = 0$ (단, $a^2 + b^2 = 1$)의 법선 형태로 정의합니다. 오차는 이제 $y$축 방향이 아니라, **"각 점들에서 직선까지의 수직 최단(직교) 거리"**가 됩니다.

```
       [ 일반 최소제곱법 ]                         [ 전체 최소제곱법 ]
          y축 방향 오차                              직교 최단거리 오차

              * (x_i, y_i)                              * (x_i, y_i)
              │                                        /
              │ 오차 e_y                              /  직교 오차 d_i
              v                                      v
      ─────────────────────                  ─────────────────────
             직선                                   직선
```

#### 🧠 수학적 직관: 최적의 직선은 무게중심을 지난다
모든 2D 점들의 평균 위치인 **무게중심 $(\bar{x}, \bar{y})$**을 기준으로 데이터 좌표들을 평행 이동시키면, 복잡한 상수 $c$가 소거되어 연립방정식은 극적으로 단순해집니다.

$$E = \sum_{i=1}^N (a(x_i - \bar{x}) + b(y_i - \bar{y}))^2 = \|Xw\|^2 \tag{1}$$

단, $w = \begin{bmatrix} a & b \end{bmatrix}^T$, $\|w\|^2 = 1$ 제약 조건이 붙습니다. 

이 제약 조건 하에서 $\|Xw\|^2$를 최소화하는 해 $w$는 **$X$의 SVD 분해($X = U D V^T$)에서 가장 작은 특이값에 해당하는 우특이벡터 $V$의 마지막 열 벡터**가 됩니다. (Ch.1 캘리브레이션과 완벽한 대칭을 이룹니다!)

---

### 2.3 강건 비용 함수 (Robust Cost Function)
이상값의 과도한 영향력을 억제하기 위해, 잔차 $u$가 커질 때 페널티의 증가폭을 꺾어버리는 **강건 비용 함수**를 씌워줍니다.

$$C(u, \sigma) = \frac{u^2}{\sigma^2 + u^2} \tag{2}$$

- 잔차가 작을 때는 일반 제곱 오차($u^2$)처럼 친절하게 작동합니다.
- 잔차가 아주 거대해지면 비용의 최댓값이 **$1$로 수렴(Saturation)**하여, 아무리 황당한 이상값이 튀어나와도 전체 시스템에 더 이상 민폐를 끼치지 못하게 방어막을 쳐줍니다.

## 3. RANSAC (RANdom SAmple Consensus)

> 🗳️ **친절한 비유 (무작위 표본 추출과 민주주의 선거)**
> 
> 혼돈의 데이터 속에서 진짜 모델을 찾는 가장 쿨한 방법은 **민주적인 투표**입니다.
> 
> 1. **무작위 샘플링**: 주머니 속 수천 개의 점들 중, 직선을 만드는 데 필요한 **단 최소한의 샘플 2개**만 아무렇게나 눈 감고 뽑습니다.
> 2. **가설 피팅**: 두 점을 연결하는 후보 직선 모델을 수립합니다.
> 3. **인라이어 찬성표 투표(Consensus)**: 전체 점들에게 물어봅니다. *"내가 만든 이 직선이랑 거리가 아주 가까운 찬성파(Inliers)들은 손을 드세요!"* 임계값 $\delta$ 이내에 들어오는 찬성표를 세어 득표수를 기록합니다.
> 
> 이 과정을 여러 번($N$번) 무작위로 반복해서, **"가장 압도적인 찬성표(consensus)를 얻어 당선된 최다 득표 직선"**을 최종 진짜 모델로 낙점합니다. 이상값(Outliers)은 찬성표 투표 과정에서 자연스럽게 아웃 오브 안중이 됩니다.

---

### 3.1 최소 반복 횟수 $N$의 수학적 유도

우리는 무한히 반복할 시간이 없습니다. 확률적으로 **"적어도 한 번은 이상값이 단 1개도 섞이지 않은 청정 인라이어들만 뽑아 완벽한 가설을 세울 확률"**을 $p$라 약속할 때, 최소 몇 번($N$)의 루프를 돌면 안심할 수 있을까요?

- $s$: 모델 피팅에 필요한 최소 점 수 (직선은 2, 단응행렬은 4, 기본행렬은 8)
- $e$: 전체 데이터 중 이상값(Outlier)의 비율

1. 무작위로 한 번에 뽑은 $s$개의 점이 전부 깨끗한 인라이어일 확률:  
   $$(1 - e)^s$$
2. 한 번 뽑을 때 불량 데이터가 최소 1개 이상 섞여 실패할 확률:  
   $$1 - (1 - e)^s$$
3. $N$번을 연속으로 뽑았는데 단 한 번도 청정 샘플을 건지지 못하고 비참하게 전부 실패할 확률:  
   $$\left( 1 - (1 - e)^s \right)^N$$
4. 적어도 한 번은 완벽한 샘플링에 성공할 확률 $p$는 전체 $1$에서 실패 확률을 빼서 정의됩니다:  
   $$p = 1 - \left( 1 - (1 - e)^s \right)^N$$

양변에 로그를 취해 우리가 원하는 반복 횟수 **$N$**을 깔끔하게 유도해 냅니다.

$$N = \frac{\log(1 - p)}{\log\left(1 - (1 - e)^s\right)} \tag{3}$$

이 우아한 확률적 타협 덕분에 우리는 실시간 연산 중에도 RANSAC을 매우 안정적이고 가볍게 굴릴 수 있습니다.

## 4. Hough 변환 (Hough Transform)

> 🎟️ **친절한 비유 (기하학적 득표판 기입)**
> 
> 이미지 공간 위에 놓인 점 하나($x_i, y_i$)는 무수히 많은 사방의 직선 후보들을 품고 있습니다. 
> 
> 점 하나가 외칩니다. *"나는 내 위치를 지나는 모든 선 후보들에 $1$표씩을 던지겠어!"*
> 
> 이를 위해 파라미터(기울기 $m$, y절편 $n$)로 구성된 **Hough 득표판(Accumulator Array)**을 만들어 놓습니다. 이미지 공간의 점 하나는 Hough 득표 평면 위에서 **하나의 곧은 '선'**으로 투표 자국을 길게 남깁니다.
> 
> 모든 점들이 자기 직선 위를 쓸어가며 득표 평면에 표를 얹으면, **진짜 점들이 일직선으로 정렬되어 있던 교차점에 표가 산더미처럼 쌓여 거대한 Peak(봉우리)**를 만들게 됩니다. 우리는 이 다득표 봉우리의 파라미터 좌표를 읽기만 하면 직선 피팅이 끝납니다.

```
       [ 이미지 공간 (Image Space) ]                 [ Hough 공간 (Parameter Space) ]
       
            y                                           n (y절편)
            ^                                           ^
            │       * (x1, y1)                          │      \       /
            │      /                                    │       \  *  /  <--- 교차점에
            │     /                                     │        \/ \/        표가 쌓임
            │    /  일직선 상의 점들                     │        /\ /\      (최종 당선 직선!)
            │   * (x2, y2)                              │       /  *  \
            └──────────────────> x                      └──────────────────> m (기울기)
```

### 4.1 좌표계의 쌍대성 (Duality)
- 이미지 공간의 **한 '점'** $\leftrightarrow$ Hough 공간의 **한 '선'**
- 이미지 공간의 **한 '선'** $\leftrightarrow$ Hough 공간의 **한 '점'**

---

### 4.2 극좌표계($\rho, \theta$)의 도입: 무한대 기울기 방어

수식 $y = mx + n$을 그대로 쓰면 수직선일 때 기울기 $m = \infty$가 되어 득표판 배열을 우주 끝까지 만들어야 하는 메모리 파탄이 일어납니다. 

이를 해결하기 위해 각도 $\theta$와 거리 $\rho$로 구성된 **극좌표 형태**로 직선을 정의합니다.

$$x \cos\theta + y \sin\theta = \rho \tag{4}$$

- $\theta$: 원점에서 직선으로 뻗은 법선과 $x$축 사이의 사잇각 ($0 \le \theta < \pi$)
- $\rho$: 원점에서 직선까지의 최단 직교 거리 (이미지 대각선 길이 이내)

이제 이미지 공간의 점 한 개는 무한대로 발산하지 않고, Hough 파라미터 평면($\theta, \rho$) 상에서 **예쁘게 굽이치는 정현파(Sinusoidal Wave, 사인파)**를 그리며 안전하게 한정된 공간 안에서 투표를 완료하게 됩니다.
