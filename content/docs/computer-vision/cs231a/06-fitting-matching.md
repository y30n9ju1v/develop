## 1. 개요

**피팅(fitting)**의 목표는 관측 데이터를 가장 잘 설명하는 파라메트릭 모델을 찾는 것입니다. 데이터와 모델 파라미터 추정값 사이의 **피팅 오차(fitting error)**를 최소화하여 최적 파라미터를 구합니다.

대표적인 예시:
- $(x, y)$ 점들에 직선 피팅
- 서로 다른 이미지의 대응점 집합으로 2D 단응행렬 $H$ 계산
- 8점 알고리즘으로 기본 행렬 $F$ 계산

이 노트에서는 세 가지 피팅 기법을 다룹니다.

| 기법 | 특징 | 이상값 처리 |
|:---:|:---:|:---:|
| **최소제곱법** | 폐쇄형 해, 빠름 | 취약 |
| **RANSAC** | 반복 샘플링 | 강건 |
| **Hough 변환** | 투표 기반 | 중간 |

## 2. 최소제곱법 (Least-Squares)

### 2.1 일반 최소제곱법 (Ordinary Least Squares)

$N$개의 2D 점 $\{(x_i, y_i)\}_{i=1}^N$이 주어졌을 때, $y$ 방향 제곱 오차를 최소화하는 직선 $y = mx + b$를 구합니다.

$$E = \sum_{i=1}^N (y_i - \hat{y}_i)^2 \tag{1}$$

$$= \sum_{i=1}^N (y_i - mx_i - b)^2 \tag{2}$$

모델 파라미터 $w = \begin{bmatrix} m & b \end{bmatrix}^T$를 구하기 위해 행렬 표기로 변환합니다.

$$E = \left\| \begin{bmatrix} y_1 \\ \vdots \\ y_N \end{bmatrix} - \begin{bmatrix} x_1 & 1 \\ \vdots & \vdots \\ x_N & 1 \end{bmatrix} \begin{bmatrix} m \\ b \end{bmatrix} \right\|^2 = \|Y - Xw\|^2 \tag{3-5}$$

잔차를 $r = Y - Xw$로 정의하면

$$\|r\|^2 = r^Tr = (Y - Xw)^T(Y - Xw) = Y^TY - 2Y^TXw + w^TX^TXw \tag{6-8}$$

$w$에 대한 그래디언트를 0으로 놓으면 ($X^TX$는 대칭)

$$\nabla_w \|r\|^2 = -2X^TY + 2X^TXw = 0 \tag{9-10}$$

**정규 방정식(normal equations)**:

$$X^TXw = X^TY \tag{11}$$

$X$가 열 완전 랭크(full rank)이므로 $X^TX$는 가역이고 폐쇄형 해가 존재합니다.

$$w = (X^TX)^{-1}X^TY \tag{12}$$

> **한계**: 수직선($m$이 정의되지 않음) 피팅에는 완전히 실패합니다. $m$이 극단적으로 큰 값이 되어 수치적으로 불안정해집니다.

### 2.2 전체 최소제곱법 (Total Least Squares)

수직선 문제를 해결하기 위해 직선을 $ax + by + c = 0$ 형태로 표현합니다. 이 표현에서 기울기는 $m = -a/b$이며 $b = 0$으로 수직선도 표현할 수 있습니다.

법선 벡터 $\vec{n} = (a, b)$에 의해 직선 방향이 결정됩니다. 임의의 점 $(x_0, y_0)$를 지나는 직선은

$$a(x - x_0) + b(y - y_0) = ax + by + c = 0 \tag{13-15}$$

여기서 $c = -ax_0 - by_0$입니다.

**오차는 이제 $y$축 방향이 아닌 직교 거리**입니다. 2D 점 $P = (x_i, y_i)$에서 직선까지의 거리는

$$d = \frac{|\overrightarrow{QP} \cdot \vec{n}|}{\|\vec{n}\|} = \frac{|ax_i + by_i + c|}{\sqrt{a^2 + b^2}} \tag{16-18}$$

파라미터를 $w = \begin{bmatrix} a & b & c \end{bmatrix}^T$로 설정하고, $\|\vec{n}\|^2 = 1$ 제약으로 분모를 제거하면 새로운 오차는

$$E(a, b, x_0, y_0) = \sum_{i=1}^N (ax_i + by_i + c)^2 \tag{19-20}$$

여기서 $a^2 + b^2 = 1$입니다.

#### 최적선은 데이터 무게중심을 지난다

데이터 무게중심 $(\bar{x}, \bar{y})$를 정의합니다.

$$\bar{x} = \frac{1}{N}\sum_{i=1}^N x_i, \quad \bar{y} = \frac{1}{N}\sum_{i=1}^N y_i \tag{21-22}$$

모든 $\vec{n}$과 점 집합에 대해 $c = -a\bar{x} - b\bar{y}$로 설정할 때 $E$가 최소화됩니다.

$$E(a, b, x_0, y_0) \geq E(a, b, \bar{x}, \bar{y}) \tag{23}$$

**증명**: $w_i = a(x_i - x_0) + b(y_i - y_0)$, $z_i = a(x_i - \bar{x}) + b(y_i - \bar{y})$로 정의하면, $w = z + h\mathbf{1}$ (여기서 $h \in \mathbb{R}$)이고, $z$는 $\mathbf{1}$에 직교합니다.

$$z \cdot \mathbf{1} = a\sum_{i=1}^N(x_i - \bar{x}) + b\sum_{i=1}^N(y_i - \bar{y}) = 0 \tag{29-32}$$

피타고라스 정리에 의해

$$E(a, b, x_0, y_0) = \|w\|^2 = \|z\|^2 + h^2N \geq \|z\|^2 = E(a, b, \bar{x}, \bar{y}) \tag{33-35}$$

따라서 $c = -a\bar{x} - b\bar{y}$로 고정하고 모든 점을 무게중심 기준으로 이동하면

$$E = \sum_{i=1}^N (a(x_i - \bar{x}) + b(y_i - \bar{y}))^2 = \|Xw\|^2 \tag{37-39}$$

여기서 $X = \begin{bmatrix} x_1 - \bar{x} & y_1 - \bar{y} \\ \vdots & \vdots \\ x_N - \bar{x} & y_N - \bar{y} \end{bmatrix}$, $w = \begin{bmatrix} a \\ b \end{bmatrix}$, $\|w\|^2 = 1$입니다.

이는 **제약 있는 최소제곱 문제**입니다. SVD $X = USV^T$를 이용하면

$$\|USV^Tw\| = \|SV^Tw\| \tag{41}$$

$v = V^Tw$로 치환하면 $\|Sv\|$는 $v = \begin{bmatrix} 0 & 1 \end{bmatrix}^T$ (즉 $S$의 대각이 내림차순으로 정렬되어 있으므로 마지막 성분이 최솟값에 대응)일 때 최소화됩니다.

$$w = VV^Tw = Vv$$

따라서 **오차를 최소화하는 $w$는 $V$의 마지막 열**입니다.

#### 최소제곱법의 이상값 취약성

잔차 $u_i = ax_i + by_i + c$와 비용 $C(u_i)$로 일반화된 오차를 쓰면

$$E = \sum_{i=1}^N C(u_i) \tag{44}$$

일반 최소제곱법의 $C(u_i) = u_i^2$는 이차 성장이므로 큰 잔차를 가진 **이상값(outlier)**이 비용에 과도한 영향을 미칩니다.

#### 강건 비용 함수 (Robust Cost Function)

이상값의 영향을 줄이기 위해 다음과 같은 강건 비용 함수를 사용합니다.

$$C(u_i, \sigma) = \frac{u_i^2}{\sigma^2 + u_i^2} \tag{45}$$

- 잔차 $u_i$가 크면 비용이 1에 수렴 → 이상값 기여 제한
- 잔차 $u_i$가 작으면 제곱 오차와 유사

**스케일 파라미터 $\sigma$의 역할**:

| $\sigma$ 값 | 효과 |
|:---:|:---|
| 큰 $\sigma$ | 이차 곡선이 넓어짐 → 이상값을 더 많이 페널티 (원래 최소제곱과 유사) |
| 작은 $\sigma$ | 이차 곡선이 좁아짐 → 이상값을 덜 페널티 |
| 너무 작은 $\sigma$ | 대부분의 잔차를 이상값으로 처리 → 나쁜 피팅 |
| 너무 큰 $\sigma$ | 강건 비용 함수의 이점 없음 → 최소제곱과 동일 |

강건 비용 함수는 비선형이므로 반복 방법으로 최적화합니다. 실제로는 최소제곱 폐쇄형 해를 초기값으로 사용한 뒤, 강건 비선형 비용 함수로 반복 피팅합니다.

## 3. RANSAC

**RANSAC(RANdom SAmple Consensus)**은 이상값과 누락 데이터에 강건한 피팅 방법입니다. 직선 피팅을 예로 설명하지만, 다양한 피팅 상황에 일반화됩니다.

### 알고리즘

```
RANSAC 알고리즘 (직선 피팅):
반복 (M번):
  1. [샘플링] 모델 피팅에 필요한 최소 점 수를 무작위 선택
     - 직선: 2점
     - 기본 행렬 F: 8쌍의 대응점
     - 단응행렬 H ∈ ℝ³ˣ³: 4쌍 (자유도 8, 스케일 제외)
  2. [피팅] 선택된 점으로 모델 파라미터 w 추정
  3. [합의 집합] 전체 데이터에서 인라이어 집합 계산
     P = {(xᵢ, yᵢ) | r((xᵢ, yᵢ), w) < δ}
     (r: 잔차, δ: 임계값)
최대 인라이어 집합을 가진 모델 선택
```

- **인라이어 집합(inlier set)** $P$: 피팅된 모델과 일치하는 점들
- **이상값 집합(outlier set)** $O = X \setminus P$: 모델과 일치하지 않는 점들

### 반복 횟수 계산

모든 가능한 샘플을 시도할 필요는 없습니다. 확률 $p$로 "진짜 이상값이 없는" 샘플을 최소 한 번 얻기 위한 반복 횟수 $n$을 추정할 수 있습니다.

- $s$: 모델 피팅에 필요한 최소 점 수
- $\epsilon \in [0, 1]$: 이상값의 비율

$s$개 점 샘플이 모두 인라이어일 확률: $(1 - \epsilon)^s$

단일 샘플이 이상값을 하나라도 포함할 확률: $1 - (1-\epsilon)^s$

$n$개 샘플 모두 이상값을 포함할 확률: $(1 - (1-\epsilon)^s)^n$

최소 하나의 샘플이 이상값 없을 확률 $p$:

$$1 - p = (1 - (1 - \epsilon)^s)^n \tag{46}$$

$$\log(1-p) = n\log(1 - (1-\epsilon)^s) \tag{47}$$

$$n = \frac{\log(1-p)}{\log(1 - (1-\epsilon)^s)} \tag{48}$$

### RANSAC의 특성

| | 내용 |
|:---|:---|
| **장점** | 간단하고 구현 쉬움, 다양한 피팅에 일반화 가능 |
| **단점** | 샘플 수 $n$과 임계값 $\delta$ 튜닝 필요 |
| **가정** | 충분한 수의 인라이어 존재 |
| **한계** | 반복 횟수에 이론적 상한이 없음 (완전 탐색은 계산 불가) |

## 4. Hough 변환 (Hough Transform)

**Hough 변환**은 또 다른 피팅 방법으로, **투표(voting)** 절차에 기반합니다.

### 기본 아이디어: 쌍대 공간

$y = m'x + n'$ 형태의 직선을 $N$개의 점 $\{(x_i, y_i)\}_{i=1}^N$에 피팅합니다.

**이미지 공간과 파라미터 공간(Hough 공간)의 쌍대 관계**:

| 이미지 공간 | ↔ | Hough 공간(파라미터 공간) |
|:---:|:---:|:---:|
| 직선 $y_i = mx_i + n$ 위의 점 $(x_i, y_i)$ | → | 직선 $n = -x_im + y_i$ |
| 파라미터 $(m, n)$ | → | 직선 $y = mx + n$ |

**핵심 관찰**: Hough 공간에서 직선 $n = -x_im + y_i$는 이미지 공간에서 점 $(x_i, y_i)$를 지나는 모든 가능한 직선을 나타냅니다.

두 점 $(x_1, y_1)$, $(x_2, y_2)$를 모두 지나는 직선 찾기 → Hough 공간에서 두 직선의 교점 $(m', n')$ 찾기.

### 투표 과정

```
Hough 변환 알고리즘:
1. Hough 공간을 너비 w의 격자 셀로 분할
2. A(m, n) = 0으로 초기화 (모든 셀)
3. 각 데이터 점 (xᵢ, yᵢ)에 대해:
   - n = -xᵢm + yᵢ를 만족하는 모든 (m, n)에 A(m, n)++
4. 가장 높은 카운트를 가진 (m, n)이 피팅된 직선
```

각 데이터 점 $(x_i, y_i)$는 이미지 공간의 각 후보 직선 $(m, n)$에 최대 1표를 던집니다 — 이것이 투표 절차입니다.

### 극 좌표 표현

**문제**: 기울기 $m$이 $-\infty < m < \infty$로 무한한 범위를 가지므로 계산 비용과 메모리가 과도합니다.

**해결**: 직선의 극 좌표 표현을 사용합니다.

$$x\cos(\theta) + y\sin(\theta) = \rho \tag{49}$$

- $\rho$: 원점에서 직선까지의 최소 거리 (이미지 크기나 데이터 최대 거리로 경계)
- $\theta$: x축과 직선 법선 벡터 사이의 각도 ($0$과 $\pi$ 사이로 경계)

이 표현을 사용하면, 이미지 공간의 특정 점 $(x_i, y_i)$를 지나는 모든 가능한 직선은 Hough 공간에서 **정현파(sinusoidal) 프로파일**로 나타납니다.

### Hough 변환의 격자 크기

노이즈가 있는 데이터에서는 같은 직선 위의 점들의 정현파가 Hough 공간에서 정확히 한 점에서 교차하지 않을 수 있습니다. 격자 셀 크기 $w$를 늘리면 불완전한 교차에 대한 허용 범위가 증가합니다.

| 격자 크기 | 효과 |
|:---:|:---|
| 작은 $w$ | 노이즈로 인해 직선을 놓칠 수 있음 |
| 큰 $w$ | 서로 다른 직선이 병합될 수 있어 추정 정확도 저하 |

이미지 공간에 균일한 노이즈가 있으면 Hough 공간에서 가짜 피크(spurious peaks)가 나타나 적절한 모델에 대한 명확한 합의가 없게 됩니다.

## 정리

세 가지 피팅 기법을 종합 비교합니다.

```
피팅 방법 비교:

최소제곱법 (Least Squares)
├── 일반: y 방향 오차, 수직선 처리 불가
├── 전체: 직교 거리, SVD로 해 → V의 마지막 열
└── 단점: 이상값에 취약 (이차 비용의 과도한 영향)

RANSAC
├── 무작위 최소 샘플 → 피팅 → 인라이어 집합 계산 반복
├── 반복 횟수: n = log(1-p) / log(1-(1-ε)ˢ)
└── 장점: 이상값에 강건 / 단점: 파라미터 튜닝 필요

Hough 변환
├── 이미지 공간 ↔ 파라미터 공간 쌍대 관계
├── 각 점이 파라미터 공간에 투표
├── 극 좌표 표현: x cos(θ) + y sin(θ) = ρ
└── 단점: 균일 노이즈에 취약, 격자 크기 튜닝 필요
```

| 기법 | 폐쇄형 해 | 이상값 처리 | 노이즈 처리 | 파라미터 |
|:---:|:---:|:---:|:---:|:---:|
| 최소제곱법 | O | 취약 | 양호 | 없음 |
| RANSAC | X (반복) | 강건 | 양호 | $n$, $\delta$ |
| Hough 변환 | X (투표) | 중간 | 격자 크기 의존 | $w$ |
