## 1. 들어가며

전통적인 스테레오에서는 대응점 $p$와 $p'$를 이용해 삼각측량으로 3D 점 $P$의 위치를 추정합니다. 핵심 과제는 **대응점 문제(correspondence problem)**: 어떤 점 $p$가 다른 이미지의 점 $p'$와 실제로 대응한다는 것을 어떻게 알 수 있는가입니다.

이 노트에서는 대응점 문제를 효과적으로 해결하는 두 가지 대안적 기법을 다룹니다.

- **능동 스테레오(Active Stereo)**: 프로젝터로 패턴을 투영하여 대응을 직접 만들어냄
- **체적 스테레오(Volumetric Stereo)**: 대응점 문제를 역전시켜 3D 볼륨에서 일관성 검사로 형상 복원

## 2. 능동 스테레오 (Active Stereo)

### 기본 아이디어

능동 스테레오의 핵심은 두 카메라 중 하나를 **3D 환경과 상호작용하는 장치(프로젝터)**로 교체하는 것입니다. 프로젝터는 두 번째 카메라에서 쉽게 식별할 수 있는 패턴을 물체에 투영합니다.

이 프로젝터-카메라 쌍은 카메라 쌍에서 소개한 것과 동일한 에피폴라 기하학 구조를 정의합니다. 카메라 이미지 평면 대신 **프로젝터 가상 평면(projector virtual plane)**이 사용됩니다.

동작 원리:
1. 프로젝터가 가상 평면의 점 $p$를 3D 공간의 물체에 투영 → 3D 점 $P$ 생성
2. 3D 점 $P$는 두 번째 카메라에서 점 $p'$로 관측
3. 투영하는 내용(가상 평면에서 $p$의 위치, 색상, 강도 등)을 알기 때문에 카메라의 대응 관측 $p'$를 쉽게 찾을 수 있음

### 선 스캔 방식

단일 점 대신 수직 줄무늬 $s$를 투영하는 것이 일반적인 전략입니다.

- 줄무늬 $s$는 3D 공간의 스트라이프 $S$로 투영되고, 카메라에서 선 $s'$로 관측됨
- 프로젝터와 카메라가 평행하거나 정류(rectified)되어 있으면, $s'$와 수평 에피폴라 선의 교점으로 대응점을 찾을 수 있음
- 삼각측량으로 스트라이프 $S$ 위의 모든 3D 점 복원
- 장면 전체를 스캔하면서 반복하면 보이는 모든 물체의 전체 형상 복원 가능

> **보정 필요**: 이 알고리즘이 동작하려면 프로젝터와 카메라가 모두 보정되어야 합니다. 카메라를 먼저 보정한 뒤, 캘리브레이션 리그에 알려진 줄무늬를 투영하고 관측 결과로 프로젝터의 내부/외부 파라미터를 추정합니다.

2000년 Stanford의 Marc Levoy와 학생들은 정밀 레이저 스캐너를 사용하여 미켈란젤로의 피에타 조각상을 **밀리미터 이하의 정밀도**로 복원했습니다.

### 그림자를 이용한 저비용 방식

정밀 프로젝터가 너무 비싸거나 불편한 경우, **그림자**를 능동 패턴으로 활용하는 저비용 대안이 있습니다.

- 알려진 위치의 광원과 물체 사이에 막대를 배치하면 물체에 줄무늬 그림자를 투영하는 효과
- 막대를 이동하면 다른 그림자 줄무늬를 투영하여 물체를 복원

이 방법은 훨씬 저렴하지만, 막대·카메라·광원 사이의 정밀한 보정이 필요하고 막대 그림자의 길이와 두께 간 트레이드오프를 고려해야 합니다.

### 다중 컬러 줄무늬 방식

단일 줄무늬 스캔의 한계: 프로젝터가 물체 전체를 스캔해야 하므로 느리고 실시간 변형 캡처가 불가능합니다.

자연스러운 확장: **단일 프레임으로 물체 전체를 재구성**합니다.

- 여러 색상의 줄무늬 패턴을 물체의 모든 보이는 면에 한 번에 투영
- 줄무늬 색상은 이미지에서 고유하게 식별할 수 있도록 설계
- 이 개념은 최초 버전의 Microsoft Kinect를 포함한 현대 깊이 센서의 기반이 됨
- 실제로는 적외선 레이저 프로젝터를 사용하여 모든 주변광 조건에서 3D 비디오 데이터 캡처 가능

## 3. 체적 스테레오 (Volumetric Stereo)

전통적·능동 스테레오의 대안으로, **체적 스테레오**는 대응점 문제를 역전시킵니다.

**핵심 아이디어**: 추정하려는 3D 점이 알려진 특정 볼륨 안에 있다고 가정합니다. 가설의 3D 점을 보정된 카메라들에 역투영하여 여러 뷰에서 일관성이 있는지 검증합니다.

체적 스테레오는 주로 **특정 물체의 3D 모델 복원**에 사용됩니다(경계가 없는 장면 전체 복원에는 적합하지 않음).

"일관성(consistent)"의 정의에 따라 세 가지 주요 기법이 있습니다.

### 3.1 공간 조각 (Space Carving)

#### 기본 개념

물체의 윤곽선이 형상에 대한 풍부한 기하학적 정보를 제공한다는 관찰에서 출발합니다.

- **실루엣(silhouette)**: 이미지 평면에서 물체의 보이는 부분이 차지하는 픽셀 집합
- **시각 원뿔(visual cone)**: 카메라 중심과 이미지 평면의 물체 윤곽선으로 정의되는 포락면
- 물체는 반드시 시각 원뿔 안에 완전히 포함됨

실루엣 획득 방법: 물체 뒤에 배경을 제어할 수 있으면(예: 그린 스크린) 물체를 배경에서 쉽게 분리할 수 있습니다.

#### 시각 헐 (Visual Hull)

여러 뷰에서 각 시각 원뿔을 계산하고 그 **교집합**을 구합니다. 이 교집합을 **시각 헐(visual hull)**이라고 합니다.

```
공간 조각 알고리즘:
1. 작업 볼륨(working volume)을 복셀(voxel)로 분할
2. 각 복셀을 모든 뷰에 투영
3. 어느 한 뷰의 실루엣에 포함되지 않은 복셀 제거
4. 남은 복셀 = 시각 헐에 포함된 복셀
```

#### 한계

| 한계 | 설명 |
|:---|:---|
| **계산 비용** | 복셀 수에 선형, 해상도에 세제곱 비례 → 옥트리(octree)로 완화 가능 |
| **뷰 수 의존성** | 뷰가 적을수록 느슨한 시각 헐 추정 |
| **실루엣 정확도** | 실루엣이 보수적이면 부정확한 조각, 빠진 픽셀이 있으면 과도한 조각 |
| **오목면 처리 불가** | 오목한 부분을 조각하면 물체 내부까지 잘려나감 (단, 물체를 관통하는 구멍은 처리 가능) |

> 재구성은 항상 **보수적(conservative)**입니다. 즉, 실제 물체는 재구성 결과에 포함되지만 재구성 결과가 실제 물체보다 클 수 있습니다.

### 3.2 그림자 조각 (Shadow Carving)

공간 조각의 오목면 문제를 해결하기 위해 **자기 그림자(self-shadow)**를 추가 일관성 검사로 활용합니다.

#### 자기 그림자

오목한 물체는 오목한 영역에 자기 그림자를 드리웁니다. 이 그림자 정보를 이용해 오목면을 더 잘 추정할 수 있습니다.

#### 설정 및 과정

- 회전대(turntable) 위의 물체를 보정된 카메라로 관측
- 카메라 주변에 위치한 알려진 위치의 조명 배열 — 켜고 끌 수 있음

```
그림자 조각 과정:
1. 공간 조각과 동일하게 초기 복셀 그리드를 트림
2. 각 뷰에서 각 조명을 켜고 끄며 자기 그림자를 생성
3. 이미지 평면에서 그림자를 식별
4. 트림된 복셀 그리드 표면에서 그림자의 시각 원뿔에 있는 표면 복셀 탐색
5. 표면 복셀로 광원과 새로운 시각 원뿔 구성
6. 두 시각 원뿔 모두에 속하는 복셀은 물체의 일부가 아님 → 제거
```

#### 복잡도

복셀 그리드 해상도에 세제곱 비례, 조명 $N$개가 있으면 공간 조각보다 약 $N+1$배 오래 걸립니다(각 복셀을 카메라와 $N$개 조명 모두에 투영해야 하므로).

#### 한계

- 반사성이 높거나 반사율(albedo)이 낮은 영역이 있는 물체에는 적용 불가 (그림자 검출 불가)
- 결과 품질은 뷰 수와 조명 수에 모두 의존

### 3.3 복셀 채색 (Voxel Coloring)

체적 스테레오의 마지막 기법으로, 공간 조각의 **윤곽선 일관성** 대신 **색상 일관성**을 사용합니다.

#### 기본 아이디어

각 복셀에 대해 여러 뷰에서의 투영을 살펴보고 색상을 비교합니다. 색상이 충분히 일치하면 해당 복셀을 물체의 일부로 표시합니다.

> **추가 장점**: 투영의 색상을 복셀에 전달할 수 있어 **색상이 있는 재구성** 가능 (공간 조각에는 없는 장점)

#### 핵심 가정: 람베르시안 물체

색상 일관성 검사가 유효하려면 물체가 **람베르시안(Lambertian)**이어야 합니다. 즉, 물체의 겉보기 밝기가 시점이나 자세에 따라 변하지 않아야 합니다.

반사성이 높은 물체는 실제로 물체 표면인 복셀에서도 색상 일관성 검사가 실패할 수 있습니다.

#### 모호성 문제와 가시성 제약

기본 복셀 채색은 **유일하지 않은 해**를 만들 수 있습니다(모호성 문제). 이를 해결하기 위해 **가시성 제약(visibility constraint)**을 도입합니다.

```
가시성 제약이 있는 복셀 채색 알고리즘:
1. 카메라에 가까운 복셀부터 먼 복셀 순서로 층별로 처리
2. 각 복셀에 대해 색상 일관성 검사 수행
3. 적어도 두 카메라에서 보이는지 확인 (가시성 제약)
   → 두 카메라 미만에서 보이면 가려진 것 → 물체의 일부가 아님
4. 가까운 복셀을 먼저 처리하여 이후 복셀의 가시성 판단에 활용
```

#### 장단점

| | 내용 |
|:---|:---|
| **장점** | 형상과 텍스처를 동시에 캡처, 색상 재구성 가능 |
| **단점 1** | 물체가 람베르시안이어야 함 |
| **단점 2** | 가시성 제약 때문에 특정 카메라 위치 불가 (복셀 처리 순서 제약) |

## 정리

이 노트에서 다룬 3D 재구성 기법들을 비교합니다.

### 능동 스테레오 vs 전통 스테레오

| | 전통 스테레오 | 능동 스테레오 |
|:---:|:---:|:---:|
| **대응점 탐색** | 알고리즘으로 탐색 | 투영 패턴으로 직접 생성 |
| **정확도** | 보통 | 높음 (레이저 스캐너: 밀리미터 이하) |
| **비용** | 낮음 | 프로젝터 필요 |
| **실시간** | 가능 | 단일 프레임 방식만 가능 |

### 세 가지 체적 스테레오 기법 비교

| 기법 | 일관성 기준 | 오목면 처리 | 색상 재구성 | 주요 제약 |
|:---:|:---:|:---:|:---:|:---:|
| **공간 조각** | 실루엣 | 불가 | 불가 | 복셀 수에 세제곱 비례 |
| **그림자 조각** | 실루엣 + 자기 그림자 | 가능 | 불가 | 반사/저반사 물체 불가 |
| **복셀 채색** | 색상 | 가능 | 가능 | 람베르시안 물체만, 카메라 위치 제약 |

```
체적 스테레오 공통 흐름:
1. 알려진 볼륨을 복셀 그리드로 분할
2. 각 복셀을 보정된 카메라들에 투영
3. 일관성 기준에 따라 복셀 유지/제거
4. 남은 복셀 = 물체 추정
```

모든 체적 스테레오 기법의 **재구성은 보수적**입니다. 즉, 실제 물체는 항상 재구성 결과에 포함됩니다.
