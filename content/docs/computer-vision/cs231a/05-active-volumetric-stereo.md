> 이전 편들에서는 두 카메라 간의 대응점(Stereo Matching)을 찾아 3D 구조를 삼각측량하는 기하학적 원리를 다루었습니다. 
> 하지만 아무리 훌륭한 알고리즘이라도 벽지 무늬가 없거나(Textureless), 반대로 체크무늬처럼 반복 패턴이 심한 벽면에서는 매칭점이 어긋나는 **대응점 문제(Correspondence Problem)**라는 근본적인 벽에 부딪힙니다.
>
> 💡 **질문**: **"수학적 매칭 알고리즘의 한계를 뛰어넘어, 물리적으로 대응점을 강제하거나 3차원 공간 자체를 직접 깎아 나가는 새로운 대안은 없을까?"**

---

## 1. 들어가며

대응점 찾기의 무서운 난제를 우회하기 위해, 우리는 완전히 다른 시각에서 접근하는 두 가지 혁신적인 대안을 배웁니다.

- **능동 스테레오(Active Stereo)**: "내가 직접 점을 찍어주마." 프로젝터로 식별하기 쉬운 인공 패턴을 비추어 대응점 문제를 해결하는 기법.
- **체적 스테레오(Volumetric Stereo)**: "처음부터 공간 그리드를 만들어 깎자." 3차원 공간을 미세한 입방체(복셀)들로 쪼갠 뒤, 여러 사진과의 일치 여부를 검사해 깎아 나가는 조각 기법.

---

## 2. 능동 스테레오 (Active Stereo)

### 2.1 프로젝터-카메라 시스템의 직관

> 🔦 **친절한 비유 (어두운 방의 패턴 플래시)**
> 
> 질감이 전혀 없는 밋밋하고 하얀 민무늬 석고상이 어두운 방에 놓여 있습니다. 두 대의 카메라로 아무리 사진을 찍어봤자 대응점을 찾을 수 없어 3D 복원이 불가능합니다.
> 
> 이때, 카메라 한 대를 **격자무늬 패턴을 뿜어내는 스마트 빔프로젝터**로 교체합니다. 
> 
> 프로젝터가 가상의 2D 슬라이드 평면에서 정밀하게 정의된 붉은 점($p$)들을 석고상에 쏘아 올립니다. 그러면 석고상 표면의 높낮이에 따라 붉은 점($P$)들이 비뚤비뚤 맺히고, 남은 카메라 한 대가 이 사진($p'$)을 찍습니다.
> 
> 프로젝터는 자기가 몇 번째 줄, 몇 번째 칸의 점($p$)을 쐈는지 스스로 100% 알고 있기 때문에, 카메라 사진에 찍힌 점($p'$)과의 **대응 매칭이 0.001초 만에 공짜로 해결**됩니다.

```
  [ 빔 프로젝터 (Projector) ]                       [ 3D 물체 (Object) ]
        o (가상 슬라이드 평면 p)                            
         \                                             * P (물체 표면의 반사점)
          \                                           /
           \  패턴 광선 투사                         /
            \                                       /  반사된 광선 검출
             v                                     v
         ============================================= [ 카메라 (Camera) ]
                                                            o (픽셀 이미지 평면 p')
```

### 2.2 선 스캔 및 다중 컬러 줄무늬 방식

1. **선 스캔 (Single Line Scan)**: 단일 점 대신 가느다란 수직 레이저 줄무늬(Line)를 비추는 방식입니다. 카메라 상에 맺힌 굴절된 선을 에피폴라 선과의 교점으로 해석해 삼각측량합니다. 정밀도가 극도로 높아 **밀리미터 이하 단위의 문화재 디지털 복원(디지털 트윈)** 등에 널리 쓰입니다.
2. **다중 컬러 패턴 (Structured Light)**: 선 스캔은 물체 전체를 좌우로 훑어야 해서 움직이는 피사체를 찍을 수 없습니다. 이를 극복하기 위해, **서로 다른 색상이나 미세한 이진 적외선 패턴(Structured Light)을 한 번에 전면에 투사**합니다. 이 방식은 우리에게 친숙한 **Microsoft Kinect 센서** 및 스마트폰의 **Face ID(TrueDepth 카메라)**의 핵심 뼈대 기술입니다.

## 3. 체적 스테레오 (Volumetric Stereo)

체적 스테레오는 매칭점을 찾는 미시적인 접근 대신, 3차원 공간을 복셀 그리드로 가득 채워놓고 외곽에서부터 깎아 들어가는 거시적인 발상의 전환입니다.

### 3.1 공간 조각 (Space Carving)과 시각 헐 (Visual Hull)

> 🗿 **친절한 비유 (미켈란젤로의 조각 기법)**
> 
> 거대한 대리석 블록(복셀 그리드)이 작업실 한가운데 놓여 있습니다.
> 
> 우리는 피사체를 여러 각도에서 촬영한 사진들을 갖고 있습니다. 각 사진에서 배경을 걷어내면 피사체의 외곽선 실루엣이 나옵니다. 
> 
> 카메라 렌즈 중심에서 이 실루엣 외곽선을 따라 3차원 공간으로 길게 뻗어 나가는 **"투명한 깔때기(시각 원뿔, Visual Cone)"**를 상상해 보세요. 피사체는 반드시 이 깔때기 영역 내부에 온전히 존재해야만 합니다.
> 
> 이제 대리석 블록에서 **깔때기 영역 바깥으로 삐져나온 모든 조각들을 정으로 깎아냅니다(Carving).** 
> 360도 전 방향에서 날아오는 깔때기(시각 원뿔)들의 겹치는 알맹이만 남겨놓으면, 실제 물체와 매우 유사한 3D 형상 조각품이 툭 튀어나옵니다. 이 최적의 알맹이 조각을 **시각 헐(Visual Hull)**이라 부릅니다.

### 3.2 공간 조각 시각화 (ASCII Art)

```
        [ 카메라 뷰 1 ]                                [ 카메라 뷰 2 ]
             O1                                             O2
             / \                                             / \
            /   \  시각 원뿔 1                              /   \  시각 원뿔 2
           /     \                                         /     \
   ───────/───────\───────────────────────────────────────/───────\───────
         /  ┌───┐  \                                     /  ┌───┐  \
        /   │ x │   \   <--- 실루엣 바깥 복셀 깎임(Carved)/   │ x │   \
       / ┌──┼───┼──┐ \                                 / ┌──┼───┼──┐ \
      /  │  │ 복│  │  \                               /  │  │ 복│  │  \
     /   │  │ 셀│  │   \                             /   │  │ 셀│  │   \
    /    └──┼───┼──┘    \                           /    └──┼───┼──┘    \
   /        │   │        \                         /        │   │        \
  O1        └───┘        O1                       O2        └───┘        O2
           
                      [ 시각 헐 (Visual Hull)의 완성 ]
                      두 원뿔의 교집합 속에 포함된 복셀만 생존!
```

---

### 3.3 그림자 조각 (Shadow Carving): 오목한 영역의 돌파구

공간 조각(Space Carving)은 심플하고 강력하지만 결정적인 한계가 있습니다. 바구니 안쪽이나 석고상의 들어간 콧망울처럼 **안쪽으로 오목하게 파인 컵 모양의 영역(Concave Surface)은 실루엣 깔때기가 닿지 않아 허공에 뜬 부피로 남아 깎아낼 수 없습니다.**

이 한계를 깨기 위해 **그림자 조각**은 알려진 방향에서 조명을 비추어 드리우는 **자기 그림자(Self-Shadow)**를 일관성 검사에 추가합니다.
- 복셀 표면이 오목하게 파여있다면, 특정 각도의 조명을 비췄을 때 반드시 그림자가 드리웁니다.
- 카메라 이미지에서 어둡게 감출된 그림자 영역과 조명 광선 벡터를 정밀 역산하여, 실루엣 기법으로는 절대 깎을 수 없었던 깊숙한 오목 표면(Concavity)까지 말끔하게 깎아냅니다.

### 3.4 복셀 채색 (Voxel Coloring)

실루엣 외곽선 대신, 카메라 이미지 속 **색상 정보의 일치 여부**를 검사하여 물체의 깊이와 텍스처(색상)를 완벽하게 동시에 복원하는 고급 체적 기법입니다.

#### 람베르시안(Lambertian) 가정
이 기법이 수학적으로 성립하려면, 물체 표면의 한 점이 **"어느 각도에서 바라보아도 완벽하게 동일한 밝기와 색상"**을 유지해야 합니다. 이 이상적인 반사 특징을 람베르시안 반사라고 하며, 유리병이나 거울처럼 번쩍이는 재질(Specular)에서는 색상 검사가 실패할 수 있습니다.

#### 복셀 가시성(Visibility)과 색상 일관성 수학적 검사

```
         [ 복셀 채색의 일관성 판별 메커니즘 ]

          카메라 1 (색상 C1)                  카메라 2 (색상 C2)
                 \                                  /
                  \   가시성(Visibility) 보장        /
                   \                              /
                    v                            v
                  ==================================
                  [ 검사 대상 복셀 V_xyz ]
                  -> 두 이미지 평면에 역투영했을 때 맺히는 색상 비교:
                     검사식: Standard_Deviation(C1, C2) < 임계값 (Threshold)
                  -> 색상이 서로 일치하면 복셀 확정 및 색상 주입!
```

임의의 복셀 $V(x,y,z)$가 실제 3D 물체의 진짜 표면이라면, 해당 복셀을 바라볼 수 있는 모든 보정 카메라 이미지 평면 상에 역투영했을 때 얻어지는 픽셀 색상값들 $C_1, C_2, \ldots, C_k$는 거의 일치해야 합니다.

수학적으로 색상의 일관성(Photoconsistency)은 분산(Variance)이나 표준편차 $\sigma_C$를 기준으로 평가합니다.

$$\sigma_C = \sqrt{\frac{1}{N}\sum_{i=1}^N \|C_i - \bar{C}\|^2} < \tau \tag{1}$$

표준편차가 아주 미세한 임계값 $\tau$보다 작다면 해당 복셀은 합격하여 물체의 표면으로 선언되고, 해당 픽셀의 평균 색상 $\bar{C}$가 복셀에 입혀집니다.

#### 가시성 제약 (Visibility Constraint)의 풀이
더 앞에 있는 복셀에 가려져 뒤쪽 복셀이 카메라에 보이지 않는 **가림(Occlusion) 문제**를 방어하기 위해, 가시성 제약을 도입합니다.
- 복셀 탐색을 임의로 섞어 하지 않고, **카메라들과 가장 가까운 맨 앞쪽 레이어(Plane)부터 출발해 먼 쪽 방향으로 단계적으로 휩쓸며(Sweep) 복셀을 채색**해 나갑니다.
- 이 순서 제약 덕분에, 이미 채색되어 살아남은 맨 앞쪽 복셀들의 불투명한 장벽 정보를 기록해두어 뒤쪽 복셀의 가시성(Visibility)을 완벽하고 엄밀하게 판단할 수 있습니다.
