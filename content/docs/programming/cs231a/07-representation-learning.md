## 1. 개요

### 1.1 상태와 표현

동적 시스템의 **상태(state)**는 시스템의 핵심 측면을 압축한 설명입니다.

예시: 수직 평면을 따라 이동하는 보행 로봇
- **시간에 따라 변하는 양**: 현재 자세(위치·방향), 관절 구성, 속도
- **고정 파라미터**: 팔다리 길이, 각 팔다리 무게, 관절 마찰

동일한 시스템에 대해 수많은 표현이 가능합니다.

| 물리량 | 표현 예시 |
|:---:|:---:|
| 방향 | 오일러 각, 축-각도, 쿼터니언 |
| 위치 | 직교 좌표, 극 좌표 |
| 상태 전체 | 관절 각도, 속도, 위치의 조합 |

어떤 표현을 선택할지는 보통 **당면한 과제**에 달려 있습니다.

### 1.2 마르코프 성질과 동적 시스템

동적 시스템의 상태는 정적이지 않고 시간에 따라 진화합니다. 시각 $t$에서의 상태를 $x_t$로 표기합니다.

**마르코프 성질(Markov property)**: 미래 상태는 현재 상태에만 의존하고 과거 상태에는 의존하지 않습니다.

$$P(x_{t+1}|x_t, x_{t-1}, \ldots, x_2, x_1) = P(x_{t+1}|x_t) \tag{1}$$

마르코프 성질이 성립하면 현재 상태로부터 다음 상태를 예측할 수 있습니다.

$$f(x_t) = x_{t+1}$$

$f(\cdot)$는 비선형 함수일 수 있으며, 단순화를 위해 동역학이 시간에 대해 일정하다고 가정합니다. 이런 시스템을 **마르코프 연쇄(Markov chain)**로 모델링합니다.

```
마르코프 연쇄 (완전 관측 가능):
State: ---- x(t-1) → x(t) → x(t+1) ----

은닉 마르코프 모델 (부분 관측 가능):
State:       ---- x(t-1) → x(t) → x(t+1) ----
                    ↓         ↓        ↓
Observation:      z(t-1)    z(t)    z(t+1)
```

### 1.3 상태 추정과 HMM

현실에서는 시각 $t$의 시스템 상태를 직접 관측할 수 없는 경우가 많습니다. 잡음이 있는 센서 관측으로부터 진짜 상태를 추정하는 과정을 **상태 추정(state estimation)**이라고 합니다.

이런 시스템은 상태가 "숨겨져" 있어 **은닉 마르코프 모델(Hidden Markov Model, HMM)**로 모델링합니다.

시각 $t$의 관측 $z_t$는 해당 시각의 상태 $x_t$에만 의존합니다.

$$P(z_t|x_t, x_{t-1}, \ldots, x_2, x_1) = P(z_t|x_t) \tag{2}$$

관측 모델: $h(x_t) = z_t$

**예시**: 자율주행 자동차의 관점에서 스테레오 이미지, RGB 프레임, LiDAR 데이터로부터 주변 교통 참여자의 3D 위치, 바운딩 박스, 속도를 추정해야 합니다.

> **확장**: 로봇 행동이나 제어 입력 $u_t$를 고려하면 $f(x_t, u_t) = x_{t+1}$로 확장됩니다.
> - 마르코프 연쇄 → **마르코프 결정 프로세스(MDP)**
> - HMM → **부분 관측 가능 MDP(POMDP)**

### 1.4 생성 모델과 판별 모델

관측으로부터 상태를 어떻게 추정할 수 있을까요? RGB 이미지(관측 $z$)에서 물체의 6D 자세(상태 $x$)를 추정하는 예를 생각해봅시다.

#### 생성 모델 (Generative Model)

관측 $z$와 상태 $x$의 **결합 확률 분포** $p(z, x)$를 기술합니다.

$$p(z, x) = p(z|x) \cdot p(x)$$

- 사전 분포 $p(x)$에서 물체 자세 $x^{(i)}$ 샘플링
- 관측 모델로 가능한 관측 $h(x^{(i)}) = z^{(i)}$ 생성
- 실제 관측 $z$와 가설 자세 $x^{(i)}$의 우도 $p(z|x^{(i)})$ 계산

#### 판별 모델 (Discriminative Model)

관측 $z$가 주어졌을 때 상태 $x$의 **조건부 확률** $p(x|z)$를 기술합니다.

예시: PoseCNN — 입력 이미지 $z$를 최적 자세 $x$로 직접 매핑하는 신경망

| | 생성 모델 | 판별 모델 |
|:---:|:---:|:---:|
| **모델링 대상** | $p(z, x)$ | $p(x\|z)$ |
| **접근 방식** | 샘플링 후 우도 평가 | 직접 매핑 |
| **장점** | 해석 가능, 불확실성 표현 | 높은 정확도 |
| **단점** | 복잡한 모델링 필요 | 해석 어려움 |

## 2. 표현 학습 (Representation Learning)

### 2.1 컴퓨터 비전에서의 표현

컴퓨터 비전 파이프라인에는 세 종류의 표현이 있습니다.

```
입력 표현 → 중간 표현 → 출력 표현
(원시 센서 데이터)  (압축 벡터)   (고수준 정보)
```

**입력 표현(input representation)**: 원시 센서 데이터 형식
- 2D 이미지, 깊이 이미지, 포인트 클라우드
- 색상 vs. 흑백, 스테레오 vs. 단안, RGB vs. HSV

**중간 표현(intermediate representation)**: 고차원 입력 데이터를 요약한 압축되고 저차원인 벡터

**출력 표현(output representation)**: 의사결정에 필요한 고수준 핵심 정보
- 생물학자: "물고기" 레이블 또는 종 레이블
- 드론: 물체의 6D 자세와 3D 바운딩 박스

#### 좋은 표현의 요건 (Bengio et al., 2013)

| 요건 | 설명 |
|:---:|:---|
| **간결성(compact)** | 최소한의 정보로 |
| **설명력(explanatory)** | 다양한 입력 구성을 표현하기에 충분히 표현적 |
| **분리성(disentangled)** | 독립적으로 변할 수 있는 설명 요인들이 독립적으로 표현됨 |
| **계층성(hierarchical)** | 추상적인 개념을 덜 추상적인 개념으로 설명 가능, 특징 재사용으로 효율성 향상 |
| **다운스트림 성능** | 이후의 추론·예측·의사결정을 더 쉽게 만들어야 함 |

### 2.2 전통적 CV와 해석 가능한 표현 (≈ 2012년 이전)

전통적 컴퓨터 비전 파이프라인에서 중간 표현은 **수공 설계된(hand-crafted) 특징**들의 조합이었습니다.

```
전통적 파이프라인:
입력 이미지 → [엣지 추출] → [텍스처] → [세그먼트] → 분류기 → "클라운피시"
             [색상 분석]    [부분]
             ↑
          특징 추출기 (수동 설계)
```

저수준 특징(짧은 엣지)이 고수준 특징(부분)으로 그룹화되는 **계층적 중간 표현**의 층이 존재했습니다.

**장점**: 수동으로 설계했기 때문에 왜 특정 출력 표현이 선택되었는지 쉽게 설명 가능한 **해석 가능한 표현**을 만들어냄 → 법률·의료 같은 고위험 다운스트림 작업에 중요

**단점**: 특징 추출기를 만드는 과정이 지루하고 상당한 시간과 도메인 전문 지식이 필요

### 2.3 현대 CV와 학습된 표현 (≈ 2012년-현재)

현대 컴퓨터 비전은 수동 추출 특징을 **학습된 중간 표현**으로 대체합니다.

대표적인 모델 아키텍처: **합성곱 신경망(Convolutional Neural Network, CNN)**
- 이미지에 적용되는 합성곱 필터들의 층으로 구성
- 레이블이 달린 학습 데이터를 이용해 필터를 학습

학습된 표현은 이미지 분류 등 다운스트림 작업에서 수공 특징보다 훨씬 강력합니다.

**단점**: 고전적 표현의 해석 가능성이 부족합니다.

#### 학습된 표현 해석

**Zeiler & Fergus (2014)**: ImageNet으로 학습된 CNN의 각 레이어에서 필터를 가장 강하게 활성화하는 이미지 패치를 분석했습니다. 발견된 학습 표현이 전통적으로 추출된 특징(엣지, 텍스처, 신체 부위)과 유사했습니다.

```
CNN 학습 표현의 계층 구조:
저수준 레이어 → 엣지, 방향성 필터
중간 레이어  → 텍스처, 패턴
고수준 레이어 → 물체 부위, 전체 형태
```

#### tSNE로 표현 시각화

**tSNE(t-distributed Stochastic Neighbor Embedding)**: 고차원 중간 표현을 저차원 공간으로 투영하여 시각화하는 기법입니다.

- 저차원 임베딩과 원래 고차원 표현 사이의 **KL 발산**을 최소화
- 같은 클래스의 데이터 포인트는 공간적으로 가까이 군집할 것으로 기대

tSNE를 이용해 신경망이 실제로 같은 레이블의 이미지를 시각적으로 유사하게 학습했는지 검증할 수 있습니다.

### 2.4 비지도 학습과 자기지도 학습

**지도 학습의 문제점**: 데이터는 풍부하지만 레이블을 얻는 것은 비용이 많이 들고 전문 지식이 필요합니다.

레이블 없이 의미 있는 표현을 학습할 수 있을까요?

#### 오토인코더 (Autoencoder)

오토인코더의 목표는 입력 이미지를 완벽하게 재구성하는 것을 학습하는 것입니다.

$$\arg\min_{\mathcal{F}} \mathbb{E}_{\mathbf{X}} [||\mathcal{F}(\mathbf{X}) - \mathbf{X}||]$$

```
오토인코더 구조:
입력 X → [인코더] → z (병목, 저차원 벡터) → [디코더] → X̂ (재구성)
                     ↑
              중간 표현 (bottleneck)
```

- **재구성 손실(reconstruction loss)**: 입력 데이터 $\mathbf{X}$와 출력 $\mathcal{F}(\mathbf{X})$ 사이의 차이
- **병목(bottleneck)**: 중간 표현 $\mathbf{z}$ — 디코더가 $\mathbf{z}$로부터 입력을 재구성할 수 있다면, $\mathbf{z}$는 입력 데이터의 유용하고 정보적인 압축 버전

오토인코더는 외부 레이블 없이 입력 이미지만으로 학습 → **비지도 학습(unsupervised learning)**

#### 자기지도 학습 (Self-Supervised Learning)

자기지도 학습은 입력의 일부를 마스킹하여 출력 레이블로 사용합니다.

예시: 이미지 대각선 아래 픽셀을 입력으로, 대각선 위 픽셀을 출력으로 사용하여 복원 학습.

**활용 방법**:
1. 대량의 비레이블 데이터로 오토인코더 학습
2. 네트워크의 인코더 절반으로 압축된 중간 표현 $\mathbf{z}$ 획득
3. **소량의 레이블 데이터**로 중간 표현 $\mathbf{z}$ 위에 분류기를 학습하여 출력 표현 예측

오토인코더가 이미 의미 있는 표현 학습의 무거운 작업을 수행했기 때문에, 소량의 레이블 데이터만으로도 정확한 예측이 가능합니다.

## 정리

```
컴퓨터 비전에서 표현의 역할:

동적 시스템
├── 상태 x: 시스템의 압축된 설명
├── 마르코프 성질: P(x_{t+1}|x_t, ...) = P(x_{t+1}|x_t)
├── 완전 관측 가능 → 마르코프 연쇄
└── 부분 관측 가능 → HMM (상태 추정 필요)

상태 추정 접근법
├── 생성 모델: p(z, x) = p(z|x)p(x) → 우도 기반
└── 판별 모델: p(x|z) → 직접 매핑 (PoseCNN 등)

표현의 세 종류
├── 입력 표현: 원시 센서 데이터 (이미지, 포인트 클라우드)
├── 중간 표현: 압축된 저차원 벡터
└── 출력 표현: 고수준 정보 (레이블, 자세, 바운딩 박스)

표현 획득 방법
├── 전통적 (≈2012 이전): 수공 특징 (해석 가능, 느린 개발)
├── 현대적 (≈2012 이후): CNN 학습 표현 (강력, 해석 어려움)
│   └── 시각화: Zeiler & Fergus, tSNE
└── 레이블 없는 학습
    ├── 비지도: 오토인코더 (재구성 손실)
    └── 자기지도: 입력 일부 마스킹 → 복원 학습
```

좋은 표현은 **간결**하고, **설명적**이며, **분리**되고, **계층적**이어야 하며, 궁극적으로 **다운스트림 작업 성능**으로 평가됩니다.
