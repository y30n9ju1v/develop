## 1. 상태 추정

인공 에이전트가 실시간 의사결정을 신뢰성 있게 수행하려면 현재 환경 상태를 알아야 한다. **상태 추정(state estimation)**은 여러 센서 소스의 측정값(멀티모달 지각)을 지속적으로 결합해 시스템의 잠재 상태를 추론하는 것이다.

### 1.1 POMDP 그래픽 모델

이산 시간 동적 시스템을 확률론적 관점에서 **부분 관측 마르코프 결정 과정(POMDP)**으로 모델링한다.

| 변수 | 설명 |
|------|------|
| $x_t \in \mathbb{R}^n$ | 시간 $t$에서의 상태 (위치, 방향, 속도 등) |
| $z_t \in \mathbb{R}^k$ | 시간 $t$에서의 센서 관측값 (카메라, LiDAR 등) |
| $u_t \in \mathbb{R}^m$ | 시간 $t$에 적용된 제어 입력 |

측정값과 제어 입력은 알려져 있지만, 숨겨진 상태 이력 $x_{0:t}$는 미지다.

**상태 추정기의 목표**: 측정값과 제어 입력의 이력이 주어졌을 때 상태의 사후 확률 분포 $p(x_t | z_{1:t}, u_{1:t})$를 계산하는 것. 이를 시간 $t$에서의 **믿음(belief)** $\text{bel}(t)$이라 한다.

### 1.2 완전 상태 가정

POMDP 그래픽 모델은 **상태가 완전하다(state is complete)**는 가정을 전제로 두 가지 핵심 성질을 갖는다.

**전이 모델 (Transition model)**: 현재 상태 $x_t$는 이전 상태 $x_{t-1}$과 제어 입력 $u_{t-1}$에만 의존한다.

$$p(x_t | x_{0:t-1}, z_{1:t-1}, u_{1:t}) = p(x_t | x_{t-1}, u_t) \tag{1}$$

**측정 모델 (Measurement model)**: 현재 관측값 $z_t$는 현재 상태 $x_t$에만 조건부 의존한다.

$$p(z_t | x_{0:t}, z_{1:t-1}, u_{1:t}) = p(z_t | x_t) \tag{2}$$

## 2. 베이즈 필터

**재귀 필터(recursive filter)**는 매 시간 $t$마다 이전 사후 분포 $p(x_{t-1}|z_{1:t-1}, u_{0:t-1})$, 새 제어 입력 $u_{t-1}$, 새 관측값 $z_t$만을 이용해 현재 사후 분포를 갱신한다. 계산 복잡도가 이력 크기에 무관하므로 실시간 추론에 적합하다.

### 2.1 조건부 확률 복습

- 결합 분포 인수분해: $p(A, B) = p(A|B)p(B)$
- 조건부 포함: $p(A, B|C) = p(A|B,C)p(B|C)$
- 주변화: $p(A|C) = \int_B p(A,B|C)\,dB$
- 베이즈 규칙: $p(A|B)p(B) = p(B|A)p(A)$

### 2.2 베이즈 필터 유도

베이즈 규칙과 측정값의 조건부 독립성을 이용하면:

$$p(x_t|z_{1:t}, u_{1:t}) = \frac{p(z_t|x_t)\,p(x_t|z_{1:t-1}, u_{1:t})}{p(z_t|z_{1:t-1}, u_{1:t})} \tag{3, 4}$$

분모(정규화 상수)를 $x_t$에 대해 주변화하면:

$$p(z_t|z_{1:t-1}, u_{1:t}) = \int_{x_t} p(z_t|x_t)\,p(x_t|z_{1:t-1}, u_{1:t})\,dx_t$$

분자의 예측 분포를 $x_{t-1}$에 대해 주변화하고 마르코프 가정을 적용하면:

$$p(x_t|z_{1:t-1}, u_{1:t}) = \int_{x_{t-1}} p(x_t|x_{t-1}, u_t)\,p(x_{t-1}|z_{1:t-1}, u_{1:t-1})\,dx_{t-1}$$

### 2.3 베이즈 필터 알고리즘

베이즈 필터는 두 단계로 구성된다.

**예측 단계 (Prediction step)**

$$\widehat{\text{bel}}(t-1) = \int_{x_{t-1}} p(x_t|x_{t-1}, u_t)\,p(x_{t-1}|z_{1:t-1}, u_{1:t-1})\,dx_{t-1}$$

전이 모델과 이전 사후 분포를 이용해 새 데이터 없이 $x_t$의 분포를 예측한다. $t=1$일 때는 사전 분포 $p(x_0)$를 사용한다.

**갱신 단계 (Update step)**

$$\text{bel}(t) = \frac{p(z_t|x_t)\,\widehat{\text{bel}}(t-1)}{p(z_t|z_{1:t-1}, u_{1:t})}$$

측정 가능도 $p(z_t|x_t)$를 이용해 예측 믿음을 새 관측값으로 정제한다. 분모는 분포의 합이 1이 되도록 하는 정규화 상수다.

> **한계**: 연속 확률변수의 경우 정규화 상수 계산을 위한 적분이 일반적으로 다루기 어렵다(intractable). 베이즈 필터는 구체적인 가정을 추가해 특수화할 수 있는 "확률론적 템플릿"으로 이해하는 것이 유용하다.

### 2.4 이산 베이즈 필터

$X_t$가 $N$개의 값 $\{1,\ldots,N\}$, $Z_t$가 $M$개의 값 $\{1,\ldots,M\}$을 갖는 이산 경우, 믿음 벡터는 다음과 같다.

$$\text{bel}(t) = \begin{pmatrix} p(X_t=1|z_{1:t},u_{1:t}) \\ \vdots \\ p(X_t=N|z_{1:t},u_{1:t}) \end{pmatrix} \tag{5}$$

**예측 단계** (행렬 곱으로 구현):

$$\widehat{\text{bel}}(t-1) = T(u_t)\,\text{bel}(t-1) \tag{6}$$

여기서 전이 행렬 $T(u_t) \in \mathbb{R}^{N \times N}$의 $(i,j)$ 원소는 $p(X_t = i | X_{t-1} = j, u_t)$다.

**갱신 단계** (정규화된 행렬 곱):

$$\text{bel}(t) = \frac{M(z_t)\,\widehat{\text{bel}}(t-1)}{\mathbf{1}^T(M(z_t)\,\widehat{\text{bel}}(t-1))} \tag{9}$$

여기서 측정 모델 행렬 $M(z_t)$의 $(i,j)$ 원소는 $p(Z_t = i | X_t = j)$다.

연속 상태 공간을 유한 개의 구간으로 나누면 **히스토그램 필터**가 된다.

## 3. 칼만 필터

동적 시스템을 동역학 관점에서 보면:

$$x_t = f(x_{t-1}, u_t) + w_{t-1} \tag{11}$$
$$z_t = h(x_t) + v_t \tag{12}$$

여기서 $w_t$는 과정 잡음(process noise), $v_t$는 측정 잡음(measurement noise)이다.

### 3.1 다변량 가우스 분포

$X \in \mathbb{R}^N$이 다변량 가우스 분포를 따를 때 $X \sim \mathcal{N}(\mu, \Sigma)$로 표기한다.

$$p(X) = \frac{1}{\sqrt{(2\pi)^N |\Sigma|}}\exp\!\left(-\frac{1}{2}(x-\mu)^T\Sigma^{-1}(x-\mu)\right) \tag{13}$$

$\Sigma$의 고유벡터는 분포의 축 방향을, 고유값은 각 방향의 분산 크기를 나타낸다. 큰 고유값 → 해당 방향의 높은 불확실성.

### 3.2 선형-가우스 시스템

**칼만 필터**는 베이즈 필터를 **선형-가우스 시스템**에 적용한 것이다. 두 가지 핵심 가정을 한다.

1. 모든 확률 변수(상태, 관측값, 잡음)가 다변량 가우스 분포를 따른다.
2. 동역학 함수 $f(\cdot)$와 측정 함수 $h(\cdot)$가 선형이다.

$$x_t = A_t x_{t-1} + B_t u_t + w_t, \quad w_t \sim \mathcal{N}(0, Q_t) \tag{14}$$
$$z_t = C_t x_t + v_t, \quad v_t \sim \mathcal{N}(0, R_t) \tag{15}$$

초기 조건: $x_0 \sim \mathcal{N}(\mu_{0|0}, \Sigma_{0|0})$.

가우스 분포는 $\mu$와 $\Sigma$만으로 완전히 기술되므로, 전체 분포를 매 단계마다 추적하는 대신 **평균 벡터와 공분산 행렬만 폐쇄형 방정식으로 갱신**하면 된다.

### 3.3 칼만 필터 방정식

**예측 단계**

$$\mu_{t|t-1} = A_t \mu_{t-1|t-1} + B_t u_t \tag{16}$$
$$\Sigma_{t|t-1} = A_{t-1}\Sigma_{t-1|t-1}A_{t-1}^T + Q_{t-1} \tag{17}$$

- 식 (16): 이전 평균을 동역학 모델에 대입. 잡음은 평균이 0이므로 영향 없음.
- 식 (17): $\text{Cov}(Ax) = A\Sigma A^T$ 성질 적용 후 과정 잡음의 공분산 $Q$ 추가. 예측만으로는 불확실성이 증가한다.

**갱신 단계**

$$\mu_{t|t} = \mu_{t|t-1} + K_t(z_t - C_t\mu_{t|t-1}) \tag{18}$$
$$\Sigma_{t|t} = \Sigma_{t|t-1} - K_t C_t \Sigma_{t|t-1} \tag{19}$$
$$K_t = \Sigma_{t|t-1}C_t^T(C_t\Sigma_{t|t-1}C_t^T + R_t)^{-1} \tag{20}$$

- **혁신(innovation)** $z_t - C_t\mu_{t|t-1}$: 예측 측정값과 실제 관측값의 차이.
- **칼만 이득(Kalman Gain)** $K_t$: 혁신을 평균 갱신에 얼마나 반영할지 결정하는 가중치.

### 3.4 칼만 이득의 두 극단

$$K_t = C_t^{-1}\frac{C_t\Sigma_{t|t-1}C_t^T}{C_t\Sigma_{t|t-1}C_t^T + R_t} \tag{21}$$

| 극단 조건 | 의미 | 결과 |
|-----------|------|------|
| $R_t \to 0$ (측정 잡음 없음) | 센서를 완전히 신뢰 | $K_t \to C_t^{-1}$, $\mu_{t|t} = C_t^{-1}z_t$, $\Sigma_{t|t} \to 0$ |
| $\Sigma_{t|t-1} \to 0$ (과정 잡음 없음) | 동역학 모델을 완전히 신뢰 | $K_t \to 0$, $\mu_{t|t} = \mu_{t|t-1}$, 관측값 무시 |

실제에서는 두 극단 사이에서 예측과 관측을 균형 있게 통합한다. **예측 단계는 공분산을 증가**시키고, **갱신 단계는 공분산을 감소**시키며, 전체적으로 공분산은 수렴한다.

## 4. 확장 칼만 필터 (EKF)

선형 사상(mapping)을 가우스 분포에 적용하면 결과도 가우스 분포지만, **비선형 사상**을 적용하면 결과가 비가우스 분포가 되어 표준 칼만 필터 방정식을 적용할 수 없다.

**확장 칼만 필터(EKF)**는 비선형 동역학 함수 $f$와 측정 함수 $g$를 각 시간 $t$마다 현재 추정값 주변에서 **1차 테일러 전개**로 선형화한다.

### 4.1 EKF 방정식

**예측 단계**

$$\mu_{t|t-1} = f(\mu_{t-1|t-1}, u_t) \tag{22}$$
$$\Sigma_{t|t-1} = A_{t-1}\Sigma_{t-1|t-1}A_{t-1}^T + Q_{t-1} \tag{23}$$

**갱신 단계**

$$\mu_{t|t} = \mu_{t|t-1} + K_t(z_t - g(\mu_{t|t-1})) \tag{24}$$
$$\Sigma_{t|t} = \Sigma_{t|t-1} - K_t C_t \Sigma_{t|t-1} \tag{25}$$
$$K_t = \Sigma_{t|t-1}C_t^T(C_t\Sigma_{t|t-1}C_t^T + R_t)^{-1} \tag{26}$$

여기서 $A_t$와 $C_t$는 비선형 함수의 **야코비안(Jacobian)**이다.

$$A_t(\mu_{t-1|t-1}, u_t) = \frac{\partial f(x_t, u_t)}{\partial x_t}\bigg|_{x_t = \mu_{t-1|t-1}} \tag{27}$$

$$C_t(\mu_{t|t-1}, u_t) = \frac{\partial g(x_t, u_t)}{\partial x_t}\bigg|_{x_t = \mu_{t|t-1}} \tag{28}$$

EKF와 KF의 구조적 차이는 다음과 같다.

| | 칼만 필터 (KF) | 확장 칼만 필터 (EKF) |
|-|----------------|----------------------|
| **동역학** | $x_t = A_t x_{t-1} + B_t u_t$ | $x_t = f(x_{t-1}, u_t)$ (비선형) |
| **측정** | $z_t = C_t x_t$ | $z_t = g(x_t)$ (비선형) |
| **선형화** | 불필요 | 야코비안으로 매 단계 선형화 |
| **예측 평균** | $A_t \mu_{t-1|t-1} + B_t u_t$ | $f(\mu_{t-1|t-1}, u_t)$ |
| **갱신 혁신** | $z_t - C_t\mu_{t|t-1}$ | $z_t - g(\mu_{t|t-1})$ |

|------|------|------|
| **베이즈 필터** | POMDP + 마르코프 | 예측(전이 모델) + 갱신(측정 모델); 일반적이나 적분 계산이 어려움 |
| **이산 베이즈 필터** | 유한 이산 상태 | 행렬 곱으로 구현 가능; $T(u_t)\,\text{bel}$ → 정규화 |
| **칼만 필터** | 선형-가우스 | $(\mu, \Sigma)$만 추적; 폐쇄형 갱신; 최소 평균제곱오차 최적 추정 |
| **확장 칼만 필터** | 비선형 + 가우스 근사 | 야코비안으로 매 단계 선형화; 비선형성이 강하면 근사 오류 발생 |
