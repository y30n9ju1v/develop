지난 2편에서는 비결정적 유한 오토마타(NFA)를 배우고, 정규 표현식으로 표현할 수 있는 언어는 모두 유한 오토마타로 변환할 수 있음을 증명했습니다. 

그렇다면 반대로 **"모든 유한 오토마타(DFA/NFA)는 정규 표현식으로 변환될 수 있을까?"**라는 의문이 생깁니다.

이번 3번째 강의와 [강의 슬라이드](file:///Users/yeongjun/Develops/develop/static/references/theory-of-computation/lecture-03-the-regular-pumping-lemma-finite-automata-to-regular-expressions-cfgs.pdf)에서는 이 질문에 답하는 **GNFA 알고리즘**을 배우고, 정규 언어의 근본적인 한계를 밝히는 **펌핑 렘마(Pumping Lemma)**, 그리고 이를 넘어서기 위한 **문맥 자유 문법(CFG)**에 대해 알아보겠습니다.

---

## 1. DFA에서 정규 표현식으로: GNFA (Generalized NFA)

오토마타와 정규 표현식이 완전히 동등한 힘을 가졌음을 보이기 위해, 이번에는 유한 오토마타를 정규 표현식으로 역변환해 봅시다. 이를 위해 **일반화된 NFA (GNFA)**라는 개념을 사용합니다.

**GNFA**는 NFA와 비슷하지만, 화살표 위에 글자 하나나 $\epsilon$ 대신 **'정규 표현식(Regular Expression)'**을 적을 수 있는 오토마타입니다.

### GNFA 상태 제거(State Removal) 알고리즘
$k$개의 상태를 가진 DFA를 정규 표현식으로 바꾸는 과정은 다음과 같습니다.

1. **전처리**: 시작 상태(화살표가 들어오기만 함)와 단 하나의 수락 상태(화살표가 나가기만 함)를 따로 만들어 붙여 GNFA 특수 형태로 정렬합니다.
2. **단계적 상태 제거**: 시작 상태와 수락 상태를 제외한 나머지 상태들을 하나씩 제거해 나갑니다.
3. **경로 복구**: 상태 $x$를 제거할 때, $x$를 거쳐 가던 모든 경로들의 표현식을 하나로 합쳐서 화살표를 업데이트해 줍니다.

상태 $x$를 거쳐서 $q_i$에서 $q_j$로 가던 경로들을 복구하는 수학적 공식은 다음과 같습니다:

$$(R_1)(R_2)^*(R_3) \cup (R_4)$$

- $R_1$: $q_i$에서 $x$로 가는 경로
- $R_2$: $x$에서 제자리로 돌아오는 루프(Loop)
- $R_3$: $x$에서 $q_j$로 가는 경로
- $R_4$: $x$를 거치지 않고 원래 $q_i$에서 $q_j$로 바로 가던 경로

```
[q_i] --(R_1)--> [ x ] --(R_3)--> [q_j]      ===>      [q_i] --( R_1(R_2)*R_3 ∪ R_4 )--> [q_j]
                  ↺ (R_2)
   \_____________(R_4)_____________/
```

이 연산을 반복하여 최종적으로 **[시작 상태] $\xrightarrow{R}$ [수락 상태]**의 2개 상태만 남기면, 화살표 위에 남은 정규 표현식 $R$이 바로 원래 오토마타의 정규 표현식이 됩니다.

이로써 **"DFA $\approx$ NFA $\approx$ 정규 표현식"**의 삼각 동등성이 완전히 입증되었습니다.

## 2. 정규 언어의 한계: 비정규 언어 (Non-Regular Languages)

유한 오토마타는 메모리(상태의 개수)가 **유한**합니다. 따라서 문자열을 읽을 때 무한한 정보를 기억하거나 개수를 세는 일을 할 수 없습니다.

예를 들어, $B = \{0^k 1^k \mid k \ge 0\}$ (0의 개수와 1의 개수가 같은 문자열) 같은 언어는 오토마타가 $0$의 개수를 세기 위해 무한한 상태가 필요하므로 **정규 언어가 아닐 것**이라는 직관이 듭니다.

### 직관의 함정
하지만 직관에만 의존해서는 안 됩니다. 
예를 들어, $C = \{w \mid w \text{는 } 01\text{과 } 10\text{ 서브스트링의 개수가 같음}\}$ 이라는 언어가 있습니다. 이 언어도 무한히 개수를 세어야 할 것 같지만, 놀랍게도 **정규 언어**입니다! (01과 10은 교대로 등장할 수밖에 없으므로 상태 몇 개만으로 판별이 가능합니다.)

따라서 특정 언어가 정규 언어가 아니라는 것을 밝히기 위해서는 **수학적인 증명 도구**가 필요합니다. 그 도구가 바로 **펌핑 렘마(Pumping Lemma)**입니다.

---

## 3. 정규 언어의 판독기: 펌핑 렘마 (Pumping Lemma)

**펌핑 렘마(Pumping Lemma, 펌핑 정리)**는 정규 언어라면 반드시 만족해야 하는 성질을 규정합니다.

> **정규 언어용 펌핑 렘마**
> 어떤 언어 $A$가 정규 언어라면, 특정 상수 $p$(펌핑 길이)가 존재하여 길이가 $p$ 이상인 모든 문자열 $s \in A$ ($|s| \ge p$)는 다음 세 조건을 만족하도록 세 부분 $s = xyz$로 분할할 수 있다.
> 1. 모든 $i \ge 0$에 대해, $xy^i z \in A$ (반복해서 불려 나가도(Pump) 여전히 언어에 속함)
> 2. $|y| > 0$ ($y$는 빈 문자열이 아님)
> 3. $|xy| \le p$ (반복되는 루프 구간이 문자열 앞부분 $p$ 글자 내에 존재함)

### 비둘기집 원리(Pigeonhole Principle)를 이용한 증명 직관
이 정리의 핵심은 **비둘기집 원리**입니다. 
오토마타의 상태 개수가 $p$개인데 길이가 $p$ 이상인 문자열을 읽으려면, 최소한 $p+1$번 상태를 거쳐 가야 하므로 **반드시 어떤 하나의 상태를 최소한 두 번 이상 재방문(루프)하게 됩니다.**

이때 재방문하는 루프 구간을 문자열에서 $y$라고 부릅니다. 이 루프는 몇 번을 돌아도(즉, $y^i$로 펌핑해도) 기계는 수락 상태에 안전하게 도달할 수 있어야 합니다.

## 4. 펌핑 렘마를 이용한 비정규 언어 증명 실전 (귀류법)

펌핑 렘마는 보통 어떤 언어가 **정규 언어가 아님을 증명(귀류법)**할 때 사용합니다. "이 언어가 정규 언어라고 가정하면 펌핑 렘마 모순이 생긴다"는 흐름입니다.

### 예제 1: $D = \{0^k 1^k \mid k \ge 0\}$는 비정규 언어인가?

1. **가정**: $D$가 정규 언어라고 가정해 봅시다. 그러면 펌핑 렘마에 의해 펌핑 길이 $p$가 존재합니다.
2. **문자열 선택**: $s = 0^p 1^p$를 고릅니다. 이 문자열은 당연히 $D$에 속하며 길이는 $2p \ge p$입니다.
3. **분할 검사**: $s$를 $xyz$로 쪼갭니다. 조건 3번에 의해 $|xy| \le p$여야 하므로, 앞부분 $xy$는 오직 **$0$으로만 구성**되어야 합니다. 따라서 $y$ 역시 $0$들로만 이루어진 문자열이 됩니다 ($|y| > 0$).
4. **모순 도출**: $y$를 2번 반복하여 펌핑해 봅니다 ($xy^2 z = xyyz$). 
   - $y$에 들어있던 $0$의 개수만큼 문자열 전체에 $0$의 개수가 늘어납니다. 
   - 결과적으로 $xyyz$는 $0$의 개수가 $1$의 개수보다 많아지므로 더 이상 $D$에 속하지 않습니다 ($xy^2 z \notin D$). 
   - 이는 펌핑 렘마 조건 1번에 모순입니다!
5. **결론**: 따라서 최초의 가정($D$가 정규 언어이다)은 거짓이며, $D$는 **비정규 언어**입니다.

### 예제 2: $F = \{ww \mid w \in \{0, 1\}^*\}$ (데칼코마니 문자열) 증명

이 예제에서는 문자열을 잘 골라야 합니다.
- 만약 $s = 0^p 0^p$를 고르면, $y = 00$으로 잡았을 때 펌핑해도 계속 $ww$ 형태가 유지될 수 있어 모순 증명에 실패합니다.
- 대신 **경계선 역할을 할 문자**를 섞은 $s = 0^p 1 0^p 1$을 선택합니다.
- $|xy| \le p$이므로 $y$는 첫 번째 영역인 $0^p$ 안에서만 구성됩니다.
- $y$를 펌핑하면 첫 번째 $0$들의 개수만 늘어나 좌우 데칼코마니 균형이 깨집니다 ($xy^2 z \notin F$). 모순이 발생하여 정규 언어가 아님이 증명됩니다.

## 5. 정규 언어를 넘어서: 문맥 자유 문법 (Context Free Grammars)

유한 오토마타와 정규 표현식으로 표현하지 못하는 언어(예: 괄호 쌍 맞추기, HTML 태그 짝 맞추기, 혹은 방금 본 $0^k 1^k$)를 표현하기 위해 컴퓨터 과학자들은 더 강력한 도구인 **문맥 자유 문법 (CFG)**을 정의했습니다.

CFG는 규칙에 따라 문자들을 치환해 나가는 **치환 규칙(Substitution Rules)**의 집합입니다.

### CFG의 예시 $G_1$
- 규칙 1: $S \to 0S1$
- 규칙 2: $S \to R$
- 규칙 3: $R \to \epsilon$

이 문법에서 시작 변수 $S$부터 규칙을 적용해 나가면 다음과 같은 문자열을 생성(Derivation)할 수 있습니다:
$$S \xrightarrow{\text{규칙1}} 0S1 \xrightarrow{\text{규칙1}} 00S11 \xrightarrow{\text{규칙2}} 00R11 \xrightarrow{\text{규칙3}} 0011$$

이 문법이 만들어내는 언어는 결국 $L(G_1) = \{0^k 1^k \mid k \ge 0\}$이 되며, 이는 정규 언어가 표현할 수 없던 영역입니다.

### CFG의 구성 요소
1. **변수 (Variables)**: 규칙의 왼쪽에 등장하여 다른 문자로 치환될 수 있는 대문자 기호들 (예: $S, R$)
2. **터미널 (Terminals)**: 더 이상 치환되지 않고 최종 문자열을 구성하는 알파벳 소문자나 숫자들 (예: $0, 1$)
3. **대체 규칙 (Substitution Rules)**: 변수를 어떤 변수와 터미널의 조합으로 바꿀지 선언한 규칙들
4. **시작 변수 (Start Variable)**: 가장 먼저 치환을 시작할 중심 변수

이 CFG는 컴파일러가 소스코드를 분석하여 추상 구문 트리(AST)를 만들거나 프로그래밍 언어의 문법을 정의할 때 핵심적으로 사용되는 아주 중요한 개념입니다.

---

## 요약 및 마치며

- **GNFA**는 상태 제거법을 통해 모든 유한 오토마타를 정규 표현식으로 기계적 변환할 수 있음을 입증합니다.
- **펌핑 렘마**는 유한 오토마타가 가진 메모리의 유한성(비둘기집 원리)에 기초하여, 특정 언어가 **정규 언어가 아님(비정규 언어)**을 증명하는 강력한 수학적 귀류법 도구입니다.
- 정규 언어의 한계를 극복하기 위해 변수 치환 규칙을 사용하는 **문맥 자유 문법(CFG)**이 도입되었으며, 이를 통해 프로그래밍 언어와 같은 복잡한 언어 문법을 표현할 수 있습니다.

정규 언어의 경계를 넘어 새로운 차원인 **문맥 자유 언어(Context-Free Language)**의 세계에 들어섰습니다. 다음 글에서는 문맥 자유 문법을 기계적으로 해석하는 **푸시다운 오토마타(PDA)**에 대해 알아보겠습니다!
