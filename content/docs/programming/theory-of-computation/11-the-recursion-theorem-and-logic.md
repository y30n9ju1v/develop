지난 10편에서는 튜링 머신의 전체 실행 단계를 기록하는 **계산 이력 방법(Computation History)**을 공부하고, 이를 이용해 LBA 공백성, PCP, 그리고 CFG의 전역 수락 문제($ALL_{\text{CFG}}$)들이 전부 계산 불가능함을 밝혔습니다.

이번 11번째 강의와 강의 슬라이드에서는 "자기 복제"라는 생명체의 특성을 기계로 모사하는 **재귀 정리(Recursion Theorem)**와, 수학적 진리와 증명 가능성의 근본적 한계를 입증한 **괴델의 불완전성 정리**를 연결해 보겠습니다.

## 1. 자기 복제 패러독스와 콰인(Quine)

우리는 상식적으로 "스스로를 만들어내는 기계"가 불가능하다고 생각합니다.
- 자동차 공장은 자동차보다 훨씬 복잡해야 합니다. (자동차 설계도, 로봇, 공구 등이 추가로 필요하기 때문입니다.)
- 그렇다면 "공장을 만드는 공장"은 자기 자신보다 더 복잡해야 하므로, 복잡도의 무한 회귀에 빠져 자기 복제 기계는 불가능한 것처럼 보입니다.

하지만 자연계의 생명체들은 스스로를 완벽하게 복제해 냅니다. 컴퓨터 과학에서는 이를 어떻게 해결했을까요?

### 콰인 (Quine) 과 $SELF$ 머신
아무런 입력 없이 오직 **자기 자신의 소스 코드만 출력하는 프로그램**을 **콰인(Quine)**이라고 부릅니다. 튜링 머신 모델에서는 이를 $SELF$라고 칭하며, 다음과 같이 두 부분 $A$와 $B$로 구성해 순환 논증을 우회합니다.

- **Part $A$**: $P_{\langle B \rangle}$ (단순히 $B$라는 기계의 설계도를 출력하는 인쇄기)
- **Part $B$**: 테이프에 적힌 문자열을 읽고 다음 연산을 수행하는 제어기
  1. 테이프 상의 내용($\langle B \rangle$)을 계산 함수 $q$에 넣어 $\langle A \rangle$를 구해낸다. (함수 $q(w)$는 "문자열 $w$를 출력하고 정지하는 기계"의 코드를 생성하는 계산 가능한 함수입니다.)
  2. 얻어낸 $\langle A \rangle$와 원래 적혀있던 $\langle B \rangle$를 이어 붙여 $\langle AB \rangle = \langle SELF \rangle$를 완성한다.
  3. 테이프 위에 $\langle SELF \rangle$를 남겨두고 정지한다.

이 $SELF$ 머신이 가동되면:
1. 먼저 $A$가 가동되어 테이프에 $\langle B \rangle$를 적습니다.
2. 이어서 $B$가 켜져서 테이프 상의 $\langle B \rangle$를 읽고 $\langle A \rangle$를 복원해 냅니다.
3. 최종적으로 두 코드 블록이 합쳐져 자기 자신의 코드인 $\langle AB \rangle$가 출력됩니다.

이 구조는 어떤 프로그래밍 언어로도 동일하게 구현할 수 있는 수학적 사실입니다.

## 2. 클레이니 재귀 정리 (Stephen Kleene's Recursion Theorem)

콰인의 아이디어를 일반화한 수학적 정리가 바로 스티븐 클레이니의 **재귀 정리**입니다.

> **재귀 정리 (Recursion Theorem)**
> 임의의 튜링 머신 $T$에 대해, 모든 입력 $w$ 상에서 $T(\langle w, R \rangle)$와 완전히 동등하게 작동하는 튜링 머신 $R$이 언제나 존재한다.

- **의의**: 우리는 이제 임의의 알고리즘이나 튜링 머신을 묘사할 때 **"자신의 설계도(기계 코드) $\langle R \rangle$를 획득한다"**는 명령어를 아무런 제약 없이 사용할 수 있습니다.

### 재귀 정리를 이용한 $A_{\text{TM}}$ 판정 불가능성 재증명
재귀 정리를 쓰면 지난 8편에서 보았던 귀류법 증명을 단 3줄로 극도로 단순화할 수 있습니다.

1. $A_{\text{TM}}$을 해결하는 판정기 $H$가 존재한다고 가정합시다.
2. 재귀 정리에 의해 다음과 같이 작동하는 튜링 머신 $R$을 만듭니다.
   $$R = \text{"인풋 } w\text{에 대해:}$$
   1. 자신의 기계 코드 $\langle R \rangle$를 획득한다.
   2. 판정기 $H$에 $\langle R, w \rangle$를 대입해 $R$이 $w$를 수락하는지 판정한다.
   3. $H$의 판정 결과와 **반대로 작동**한다 (수락하면 거부, 거부하면 수락)."
3. 이 기계 $R$은 $H$가 맞추는 모든 결과를 일부러 비틀어 버리므로 모순이 발생합니다. 따라서 $H$는 존재할 수 없습니다.

## 3. 프로그램 변환의 고정점 정리 (Fixed-point Theorem)

재귀 정리의 또 다른 놀라운 응용은 소프트웨어 변환의 한계를 규명하는 고정점 정리입니다.

> **고정점 정리 (Fixed-point Theorem)**
> 프로그램 코드를 다른 코드로 바꾸는 임의의 계산 가능한 변환 함수(컴파일러, 난독화 도구 등) $f: \Sigma^* \to \Sigma^*$가 있을 때, **동작(언어)이 전혀 변하지 않는 고정점 프로그램 $R$**이 반드시 존재한다.
> $$L(R) = L(S) \quad (\text{단, } f(\langle R \rangle) = \langle S \rangle)$$

- **증명**: 재귀 정리를 사용하여 다음과 같은 기계 $R$을 정의합니다.
  $$R = \text{"인풋 } w\text{에 대해:}$$
  1. 자신의 기계 코드 $\langle R \rangle$를 획득한다.
  2. 변환 함수를 수행하여 $f(\langle R \rangle) = \langle S \rangle$를 계산한다.
  3. 변환된 기계 $S$를 $w$에 대해 시뮬레이션하여 동일하게 수락/거부한다."
- 이 기계 $R$은 원래 코드가 변환된 기계 $S$의 동작을 그대로 모사하므로 $L(R) = L(S)$가 성립합니다. 따라서 프로그램 구조가 아무리 바뀌더라도 행동 양식은 절대 변하지 않는 프로그램이 무조건 존재합니다.

## 4. 최소 튜링 머신 ($MIN_{\text{TM}}$)의 인식 불가능성

어떤 기능을 하는 프로그램 중 소스 코드의 길이가 가장 짧은 가장 정제된 상태의 프로그램을 **최소 튜링 머신(Minimal TM)**이라고 부릅니다.

$$MIN_{\text{TM}} = \{ \langle M \rangle \mid \text{임의의 기계 } M'\text{에 대해 } |\langle M' \rangle| < |\langle M \rangle| \implies L(M') \neq L(M) \}$$

이 최소 최적화 상태의 프로그램 목록인 $MIN_{\text{TM}}$은 **튜링 인식조차 불가능(Unrecognizable)**합니다.

- **증명 (귀류법)**: 만약 $MIN_{\text{TM}}$을 출력해 주는 열거기(Enumerator) $E$가 존재한다고 가정합시다. 우리는 재귀 정리를 활용해 다음과 같은 튜링 머신 $R$을 만듭니다.
  $$R = \text{"인풋 } w\text{에 대해:}$$
  1. 자신의 설계도 크기인 $|\langle R \rangle|$를 획득한다.
  2. 최소 튜링 머신 열거기 $E$를 실행하여, **코드의 크기가 자신보다 큰 첫 번째 최소 튜링 머신 $B$** ($|\langle R \rangle| < |\langle B \rangle|$)가 출력될 때까지 기다린다.
  3. 찾은 기계 $B$를 가져와 입력 $w$에 대해 시뮬레이션한다."
- 열거기 $E$는 무한한 최소 머신들을 뽑아내므로 결국 자신보다 큰 $B$를 출력하게 됩니다.
- 이때 $R$은 $B$의 동작을 똑같이 모사하므로 $L(R) = L(B)$입니다.
- 하지만 코드 크기는 $R$이 $B$보다 더 작습니다 ($|\langle R \rangle| < |\langle B \rangle|$). 이는 $B$가 최적화의 최소 상태 기계라는 정의에 모순됩니다 ($B \in MIN_{\text{TM}}$이지만 더 작은 $R$이 발견됨).
- 따라서 열거기 $E$는 존재할 수 없으며, $MIN_{\text{TM}}$은 **인식 불가능**합니다.

## 5. 수학의 영원한 한계: 괴델의 제1불완전성 정리 (Gödel's Incompleteness)

쿠르트 괴델(Kurt Gödel)은 1931년 수학계 전체를 충격에 빠뜨린 불완전성 정리를 발표했습니다. 

> **괴델의 제1불완전성 정리 (Gödel's First Incompleteness Theorem)**
> **"모순이 없는(Consistent) 모든 수학적 공리계에는, 참(True)이지만 그 공리계 내에서는 결코 증명할 수 없는(Unprovable) 수학적 문장이 반드시 존재한다."**

계산 이론은 이 불완전성 정리를 다음과 같이 매우 직관적으로 증명해 냅니다.

- **전제 1 (건전성)**: 어떤 공리계 내에서 문장 $\phi$의 증명 $\pi$가 존재한다면, 그 문장 $\phi$는 항상 참(True)이다.
- **전제 2 (검사 가능성)**: 어떤 증명 $\pi$가 특정 문장 $\phi$에 대한 올바른 수학적 증명인지 컴퓨터로 검사하는 알고리즘은 판정 가능(Decidable)하다.
- **연결**: 전제 2에 의해, '증명 가능한 문장들의 집합'은 컴퓨터가 순서대로 증명들을 대입해 보며 참인 것들을 걸러낼 수 있으므로 **튜링 인식 가능(Turing-Recognizable)**합니다.
- **모순 도출**: 만약 참인 문장이 무조건 증명도 가능하다면, 참인 식들의 여집합인 $\overline{A_{\text{TM}}}$(기계 $M$이 문자열 $w$를 수락하지 않는 쌍 $\langle M, w \rangle$들의 집합) 역시 참일 때 무조건 증명이 존재하게 되므로 $\overline{A_{\text{TM}}}$이 인식 가능해집니다. 하지만 우리는 이미 $\overline{A_{\text{TM}}}$이 인식 불가능함을 증명했습니다.
- **결론**: 따라서 **참이지만 그 사실을 증명할 수 없는 문장이 무조건 존재해야만 합니다.**

### 증명할 수 없는 참인 문장 $\phi_U$의 예시
재귀 정리를 사용하면 "이 문장은 증명 불가능하다"라고 외치는 실제 참인 식 $\phi_U$를 직접 구성할 수 있습니다.

$$R = \text{"임의의 인풋에 대해:}$$
1. 자신의 기계 코드 $\langle R \rangle$를 획득하여, 문장 $\phi_U = "\langle R, 0 \rangle \in \overline{A_{\text{TM}}}"$(기계 $R$은 $0$을 수락하지 않는다)을 작성한다.
2. 수학의 모든 증명들 ($\pi_1, \pi_2, \dots$)을 순서대로 스캔하며 **\"$\phi_U$가 참이라는 증명\"**이 있는지 검사한다.
3. 만약 그 증명을 발견하면 기계를 가동하여 즉시 **수락**하고 정지한다."

- **분석 1: 이 문장 $\phi_U$는 증명 가능한가?**
  - 만약 증명 가능하다면, 기계 $R$은 2번 단계에서 증명을 찾아내어 $0$을 수락하게 됩니다 ($\langle R, 0 \rangle \in A_{\text{TM}}$).
  - 이는 문장 $\phi_U$가 거짓임을 뜻합니다. 증명 가능한 문장이 거짓이 되므로 모순이 발생합니다. 따라서 $\phi_U$는 **증명 불가능**합니다.
- **분석 2: 그렇다면 이 문장 $\phi_U$는 참인가?**
  - $\phi_U$는 증명 불가능하므로, 기계 $R$은 평생 2번 단계에서 증명을 찾지 못하고 영원히 대기하여 $0$을 수락하지 못하게 됩니다 ($\langle R, 0 \rangle \in \overline{A_{\text{TM}}}$).
  - 이는 문장 $\phi_U$가 주장한 내용과 정확히 일치하므로, 이 문장은 **참(True)**입니다.

결국 우리는 **"참이지만 수학적으로 증명할 수 없는 문장"**을 컴퓨터 과학의 도구들을 사용해 완벽히 유도해 냈습니다.

## 요약 및 마치며

- **콰인(Quine)**은 두 조각($A$와 $B$)의 분리된 제어 구조를 사용해 순환 참조를 피하고 자기 소스코드를 출력하는 프로그램입니다.
- **클레이니 재귀 정리**는 모든 튜링 머신이 자신의 소스코드를 획득하는 가상 함수를 제약 없이 사용할 수 있음을 보여줍니다.
- **고정점 정리**는 컴파일러나 난독화 등의 프로그램 변환 하에서도 거동이 전혀 변하지 않는 코드가 무조건 존재함을 의미합니다.
- **최소 튜링 머신($MIN_{\text{TM}}$)** 판별은 재귀 정리의 무한 모순 구조를 빌려 튜링 인식조차 불가능함이 입증되었습니다.
- **괴델의 제1불완전성 정리**는 계산 불가능성과 증명 검사 가능성의 틈새를 활용하여, 수학 세계에는 증명 불가능한 참인 문장($\phi_U$)이 항상 존재함을 규명했습니다.

계산 이론은 기계의 연산을 연구하는 것을 넘어, 논리학과 수학 전체의 본질적인 한계를 밝혀내는 거대한 이정표를 완성했습니다. 

다음 12번째 강의 요약에서는 다시 판정 이론으로 돌아와, 컴퓨터의 연산 효율성을 대변하는 시간과 공간의 한계, 그리고 **시간 복잡도(Time Complexity)**의 기초 계층에 대해 알아보겠습니다!
