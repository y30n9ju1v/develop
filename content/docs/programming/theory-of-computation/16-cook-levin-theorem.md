지난 14편에서는 검증 가능한 문제들의 집합인 클래스 NP와, 두 복잡도 클래스의 관계를 규명하는 다항 시간 환원($\le_{\text{P}}$)을 공부했습니다. 

NP 클래스에 속한 모든 문제들을 다항 시간 내에 변환하여 풀 수 있는 **"NP에서 가장 어려운 문제들의 집합"**을 **NP-완전(NP-Complete)** 클래스라고 부릅니다. 만약 NP-완전 문제 중 단 하나라도 다항 시간(P 클래스) 내에 풀린다면, $\text{P} = \text{NP}$가 됨이 보장됩니다.

이번 16번째 강의와 [강의 슬라이드](file:///Users/yeongjun/Develops/develop/static/references/theory-of-computation/lecture-16-cook-levin-theorem.pdf)에서는 전산학 역사상 가장 중요하고 아름다운 증명인 **쿡-레빈 정리(Cook-Levin Theorem)**를 통해 만족 가능성 문제(SAT)가 최초의 NP-완전 문제임을 입증해 보겠습니다.

---

## 1. 쿡-레빈 정리의 아이디어: 계산 이력을 부울 논리식으로 변환하기

> **쿡-레빈 정리 (Cook-Levin Theorem)**
> **"만족 가능성 문제(SAT)는 NP-완전(NP-Complete)이다."**

이를 증명하려면 다음 두 가지 조건을 만족해야 합니다:
1. $\text{SAT} \in \text{NP}$ (지난 편에 완료)
2. **임의의 모든 NP 문제 $A$에 대해, $A \le_{\text{P}} \text{SAT}$ 임을 증명**

임의의 NP 문제 $A$를 결정하는 비결정적 튜링 머신 $M$이 존재하고, 이 기계의 제한 시간은 $n^k$ 다항식입니다. 우리의 목표는 입력 $w$가 들어왔을 때, **$M$이 $w$를 수락하는지에 대한 실행 경로를 하나의 거대한 부울 논리식 $\phi_{M,w}$로 번역**해 내는 것입니다.

만약 이 논리식을 참으로 만드는 변수값 대입(Satisfying assignment)이 존재한다면, 그것이 곧 $M$의 올바른 수락 실행 경로(계산 이력)가 됨을 뜻합니다.

## 2. 태블로(Tableau)의 정의: 격자판에 담긴 계산 경로

비결정적 튜링 머신 $M$의 시간 제한이 $n^k$이므로, 기계가 거쳐 갈 수 있는 계산 경로의 길이는 최대 $n^k$ 단계이며, 테이프 공간도 최대 $n^k$ 칸을 넘지 못합니다.

이 계산의 흐름을 가로 $n^k$칸, 세로 $n^k$줄의 격자판에 채워 넣은 것을 **태블로(Tableau)**라고 부릅니다.

```
       ◀───────────────────  n^k 칸 (테이프)  ───────────────────▶
   ┌───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┐
 ▲ │q_0│w_1│w_2│w_3│...│w_n│ ⊔ │ ⊔ │...│ ⊔ │ ⊔ │ ⊔ │ ⊔ │ ⊔ │ ⊔ │ ⊔ │ ← 시작 설정 (1행)
 │ ├───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┤
   │   │   │   │   │   │   │   │   │   │   │   │   │   │   │   │   │
n^k│   │   │   │   │   │   │   │   │   │   │   │   │   │   │   │   │
줄 │   │   │   │   │   │   │   │   │   │   │   │   │   │   │   │   │
   ├───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┤
 ▼ │...│...│...│...│...│q_a│...│...│...│...│...│...│...│...│...│...│ ← 수락 설정 (마지막행 근처)
   └───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┘
```

태블로의 첫 번째 행은 입력 $w$가 채워진 최초의 시작 설정이어야 하고, 마지막 줄 어딘가에는 수락 상태 $q_{acc}$를 포함해야 합니다. 그리고 가장 중요한 것은 **각 행에서 다음 행으로 넘어갈 때 튜링 머신의 규칙 $\delta$를 완벽히 준수하며 움직였는가**입니다.

우리가 조립할 논리식 $\phi_{M,w}$는 **"이 태블로가 모순 없이 올바르게 채워져 작동하고 있다"**는 것을 완벽하게 선언하는 식입니다.

$$\phi_{M,w} = \phi_{\text{cell}} \wedge \phi_{\text{start}} \wedge \phi_{\text{move}} \wedge \phi_{\text{accept}}$$

## 3. 포뮬러의 조립: 4가지 제약 조건

이 격자판의 논리 연산을 처리하기 위해, 변수 $x_{i,j,s}$를 정의합니다.
- $x_{i,j,s} = \text{TRUE}$: 태블로의 $i$번째 행, $j$번째 열의 셀에 기호 $s$ ($s \in \Gamma \cup Q$)가 적혀 있다.
- 변수의 총개수는 격자판의 크기 $n^k \times n^k = n^{2k}$에 알파벳 크기(상수)를 곱한 것이므로 **$O(n^{2k})$개 (다항식 개수)**입니다.

### A. $\phi_{\text{cell}}$ (단일 문자 제약)
격자판의 모든 셀 $(i,j)$에는 오직 한 개의 문자만 들어가야 합니다. 아무것도 없거나 기호가 두 개 겹쳐 적혀 있는 것을 방지합니다.
$$\phi_{\text{cell}} = \bigwedge_{1 \le i,j \le n^k} \left[ \left( \bigvee_{s \in \Gamma \cup Q} x_{i,j,s} \right) \wedge \left( \bigwedge_{s \neq t} (\neg x_{i,j,s} \vee \neg x_{i,j,t}) \right) \right]$$

### B. $\phi_{\text{start}}$ (시작 제약)
첫 번째 행은 반드시 시작 기호 $q_0$와 입력 $w$로 채워져야 하고, 나머지는 빈칸 $\sqcup$이어야 합니다.
$$\phi_{\text{start}} = x_{1,1,q_0} \wedge x_{1,2,w_1} \wedge \dots \wedge x_{1,n+1,w_n} \wedge x_{1,n+2,\sqcup} \wedge \dots \wedge x_{1,n^k,\sqcup}$$

### C. $\phi_{\text{accept}}$ (수락 완료 제약)
최종적으로 튜링 머신이 수락해야 하므로, 격자판 내에 최소한 하나 이상의 셀이 수락 상태 $q_{acc}$를 포함하고 있어야 합니다.
$$\phi_{\text{accept}} = \bigvee_{1 \le i,j \le n^k} x_{i,j,q_{acc}}$$

### D. $\phi_{\text{move}}$ (올바른 움직임 제약)
이 증명의 가장 우아한 부분입니다. 한 줄에서 다음 줄로 바뀔 때 올바른 계산이었는지를 격자판 전체를 스캔하며 검사하는 것은 불가능해 보입니다.

하지만 튜링 머신의 헤드는 한 번에 단 한 칸만 움직이고 좌우 이웃에만 영향을 주므로, **모든 $2 \times 3$ 크기의 윈도우(이웃 영역)가 전부 물리적으로 적법(Legal)하게 변했는지 검사**하는 것만으로 격자판 전체의 일관성을 완벽히 보장할 수 있습니다!

```
      [ i, j-1 ]   [ i,   j ]   [ i, j+1 ]   <-- 이전 행의 세 셀
      [i+1, j-1]   [i+1,  j ]   [i+1, j+1]   <-- 다음 행의 세 셀
```

튜링 머신의 규칙 테이블에 부합하는 이 $2 \times 3$ 블록의 합법적인 조합(Legal Setting)들의 가짓수는 유한(상수)합니다. 따라서 모든 $2 \times 3$ 영역이 합법적인 세팅 중 하나를 만족해야 함을 선언합니다.

$$\phi_{\text{move}} = \bigwedge_{1 < i < n^k, 1 < j < n^k} \left( \bigvee_{\text{legal } 2\times 3 \text{ settings}} (x_{i,j-1,r} \wedge x_{i,j,s} \wedge x_{i,j+1,t} \wedge x_{i+1,j-1,v} \wedge x_{i+1,j,y} \wedge x_{i+1,j+1,z}) \right)$$

## 4. 복잡도 및 변환 타당성 분석

- **크기 분석**: 격자판의 칸 크기 $n^{2k}$를 기준으로 모든 논리식의 조각들($\phi_{\text{cell}}, \phi_{\text{start}}, \phi_{\text{move}}, \phi_{\text{accept}}$)의 총 길이를 합산하면 다항식 크기인 **$O(n^{2k})$**가 됩니다.
- **다항 시간 변환**: 튜링 머신 $M$의 규칙 표를 바탕으로 이 식을 조립하는 데 걸리는 시간 역시 다항식 시간 내에 완료되므로 다항 시간 환원성($\le_{\text{P}}$)을 충족합니다.

결과적으로 임의의 모든 NP 문제는 다항식 시간 내에 SAT 문제로 번역될 수 있음이 증명되었으며, **SAT는 복잡도 이론의 최초의 NP-완전(NP-Complete) 문제**가 되었습니다.

---

## 5. 3SAT의 NP-완전성 증명 (SAT $\le_{\text{P}}$ 3SAT)

SAT 문제의 논리식 형태를 조금 더 엄격하게 제한하여, 모든 절(Clause)이 정확히 3개의 리터럴(Literal)들의 합으로만 구성된 **3SAT** 역시 NP-완전입니다.

- **증명**: 일반 SAT 문제의 임의의 논리식을 다항 시간 내에 동등한 3CNF 식으로 변형합니다.
- 식을 트리 구조로 구성한 후, 각 노드마다 임시 변수 $z_i$를 부여하여 게이트 연산(AND, OR)을 조건절들의 결합으로 풉니다.
  - 예를 들어, $z_i \leftrightarrow (a \wedge b)$ 연산은 여러 절들의 결합인 $(a \vee \neg z_i) \wedge (b \vee \neg z_i) \wedge (\neg a \vee \neg b \vee z_i)$로 치환됩니다.
- 만약 절 안의 리터럴 개수가 3개 미만이면 더미 변수를 붙여 3개로 맞추고, 3개를 초과하면 쪼개어 연결합니다.
- 이 변환 과정을 거쳐 3SAT 역시 **NP-완전**임이 증명됩니다.

## 요약 및 마치며

- **NP-완전(NP-Complete)**은 모든 NP 문제들 중 가장 난이도가 높은 한계선입니다.
- **쿡-레빈 정리**는 NTM의 계산 경로를 $n^k \times n^k$ 크기의 격자판인 **태블로(Tableau)**로 모델링하고, 이를 검증하는 논리식 $\phi_{M,w}$를 다항 시간 내에 조립함으로써 **SAT가 NP-완전임**을 규명했습니다.
- 격자판의 유효성 검사는 헤드의 부분 전이 특성을 활용해 **모든 $2 \times 3$ 윈도우의 합법성**을 검사하는 방식으로 해결했습니다.
- SAT에서 3CNF 포맷으로의 다항 시간 변환을 통해 **3SAT 역시 NP-완전**임을 보였습니다.

쿡-레빈 정리의 완성을 통해 우리는 이제 임의의 다른 어려운 문제를 증명할 때, 모든 NP 문제를 다 가져올 필요 없이 **오직 3SAT 하나만 가져와 환원($3\text{SAT} \le_{\text{P}} C$)시키는 것만으로도 새로운 NP-완전 문제를 무한히 입증**할 수 있는 강력한 무기를 얻었습니다.
