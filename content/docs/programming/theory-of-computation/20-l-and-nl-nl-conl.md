지난 18편(강의 일정 조율상 19편은 생략됨)에서는 공간 복잡도의 기본 개념과 비결정론적 공간이 결정적 공간과 동등함을 보이는 새비치 정리, 그리고 TQBF 문제의 PSPACE-완전성 증명 과정을 살펴봤습니다.

지금까지는 다항식 크기($n^k$)의 공간 제약을 다루었다면, 이번에는 입력 데이터의 크기 $n$보다도 극도로 작게 요구되는 **로그 수준($\log n$)의 공간 복잡도**와 공간 계층의 놀라운 반전을 선언한 **임머만-셀레프체니 정리**를 다룹니다.

이번 20번째 강의와 강의 슬라이드를 통해 로그 공간과 복잡도 계층의 기적을 공부해 보겠습니다.

---

## 1. 로그 공간(Log Space)의 정의와 포인터 개념

입력 데이터의 길이 $n$보다 적은 공간 복잡도(Sublinear Space)를 엄밀히 다루기 위해, 튜링 머신 모델을 **2-테이프 튜링 머신**으로 확장합니다.

1. **입력 테이프 (Read-only)**: 입력 데이터 $w$가 들어있는 테이프로, 헤드가 이동하며 읽을 수만 있고 **사용 공간 측정에서 아예 제외**됩니다.
2. **작업 테이프 (Read/write)**: 계산 중 데이터를 쓰고 읽을 수 있는 메모리로, **이 작업 테이프의 칸 개수만 공간 복잡도로 계산**합니다.

- **$\text{L} = \text{SPACE}(\log n)$**: 결정적 튜링 머신이 $O(\log n)$ 작업 공간을 사용해 판정하는 클래스.
- **$\text{NL} = \text{NSPACE}(\log n)$**: 비결정적 튜링 머신이 $O(\log n)$ 작업 공간을 사용해 판정하는 클래스.

### 로그 공간 복잡도의 직관적 의미
길이 $n$인 입력에서 어떤 특정 위치를 가리키는 **포인터(Pointer)**가 가질 수 있는 인덱스 값은 $0$부터 $n-1$까지입니다. 이 숫자를 이진수로 저장하는 데 필요한 비트 수는 정확히 $\log n$개입니다. 

즉, **로그 공간 복잡도는 입력 데이터를 가리키는 유한한(상수) 개수의 포인터만을 메모리에 올려두고 계산하는 극도로 정제된 알고리즘**을 뜻합니다.
- **회문 판별 ($\{ww^R\}$)**: 문자열의 앞뒤 끝을 가리키는 포인터 2개만 있으면 공간을 $\log n$만 쓰고 판별이 가능하므로 **$\text{L}$ 클래스**에 속합니다.
- **그래프 경로 탐색 ($\text{PATH}$)**: 엣지를 따라가기 위해 현재 노드의 번호와 다음 노드의 번호를 포인터로 기억하면 되므로 **$\text{NL}$ 클래스**에 속합니다.

## 2. 로그 공간과 다항 시간의 관계 (L, NL $\subseteq$ P)

시간 복잡도의 P 클래스와 로그 공간 사이에는 다음과 같은 포함 관계가 성립합니다.

$$\text{L} \subseteq \text{NL} \subseteq \text{P}$$

- **증명 스케치**: $O(\log n)$ 공간을 사용하는 NTM의 임의의 **설정(Configuration)**의 가짓수를 세어 봅니다.
  - $\text{설정 수} = |\text{상태 집합 } Q| \times n \text{ (입력 헤드 위치)} \times O(\log n) \text{ (작업 헤드 위치)} \times d^{O(\log n)} \text{ (작업 테이프 내용)}$
  - 이 식의 결과는 다항식인 **$O(n^c)$ (단, $c$는 상수)**가 됩니다.
- 설정을 노드로 삼고, 단일 전이를 엣지로 삼는 **설정 그래프(Configuration Graph)**를 만들면 이 그래프의 전체 크기는 다항식 크기입니다.
- 이 그래프 상에서 시작 설정에서 수락 설정으로 가는 경로가 존재하는지 판정하는 일은 다항 시간 내에 해결이 보장되므로, **$\text{NL} \subseteq \text{P}$**가 성립합니다.
- 또한 새비치 정리를 적용하면 $\text{NL} \subseteq \text{SPACE}(\log^2 n)$이 됨도 자명합니다.

## 3. NL-완전성(NL-Completeness)과 로그 공간 환원

NL 계층의 가장 어려운 문제인 **NL-완전**을 정의할 때 역시, 환원 함수가 NL 클래스 자체보다 수학적으로 더 단순해야 분류의 의미가 생깁니다. 따라서 다항 시간 환원보다 훨씬 약한 제약인 **로그 공간 환원**을 사용합니다.

### 로그 공간 변환기 (Log-space Transducer)
읽기 전용 입력 테이프, $O(\log n)$ 제한 작업 테이프, 그리고 결과를 적고 지나가는 **쓰기 전용 출력 테이프**를 가진 튜링 머신입니다. 이 기계가 출력하는 함수 $f$를 로그 공간 계산 가능한 함수라고 부릅니다.

$$\text{언어 } B\text{가 NL-Complete이다} \iff B \in \text{NL} \quad \text{and} \quad \forall A \in \text{NL}, A \le_{\text{L}} B$$

- **$\text{PATH}$의 NL-완전성**: 임의의 NL 문제의 설정 그래프(크기는 다항식)의 엣지 정보를 로그 공간 변환기를 통해 테이프를 거의 소모하지 않고 출력해 낼 수 있으므로, **$\text{PATH}$는 NL-완전**합니다.
- **$\overline{2\text{SAT}}$**: 식 안의 합절 크기가 2 이하인 2SAT의 불만족성 역시 $\text{PATH}$ 문제로 직관적인 환원이 가능하여 **NL-완전**입니다.

## 4. 계산 복잡도의 기적: NL = coNL (임머만-셀레프체니 정리)

시간 복잡도의 비결정적 계층인 $\text{NP}$와 $\text{coNP}$는 서로 다를 것이라 추측(NP $\neq$ coNP)되는 것과 달리, 놀랍게도 **비결정적 공간 계층은 여집합 관계에 대해 닫혀 있습니다.**

> **임머만-셀레프체니 정리 (Immerman-Szelepcsényi Theorem, 1987)**
> **$$\text{NL} = \text{coNL}$$**

이 정리는 NL-완전 문제인 $\text{PATH}$의 여집합 문제인 **"두 노드 $s$와 $t$ 사이에 경로가 존재하지 않는가? ($\overline{\text{PATH}}$)"** 문제가 여전히 NL(로그 공간 NTM) 내에서 해결 가능함을 증명하여 세상에 밝혀졌습니다.

### 증명 알고리즘 핵심 (도달 가능한 노드 수 세기)
그래프의 노드 수를 $m$이라 합시다. $s$에서 출발하여 $d$ 단계 내에 도달할 수 있는 노드들의 집합을 $R_d$라 하고, 그 개수를 $c_d = |R_d|$라고 정의합니다. 

만약 우리가 최종 단계의 도달 가능한 노드 수인 $c_m$을 정확히 알고 있다면, **"경로 상에 $t$가 전혀 도달하지 못함"**을 다음과 같이 증명할 수 있습니다.

1. 그래프의 모든 노드 $u$에 대해 루프를 돌면서 비결정론적으로 둘 중 하나를 선택합니다.
   - **(경로 검증)**: $s$에서 $u$로 가는 길이가 $m$ 이하인 경로를 추측해 따라갑니다. 만약 성공하면 도달 확인 카운터 $k$를 1 늘리고, **이때 $u = t$ 이면 경로가 존재하는 것이므로 즉시 거부(Reject)**합니다.
   - **(스킵)**: 그냥 다음 노드로 넘어갑니다.
2. 루프가 다 끝났을 때, 카운터 $k$가 우리가 알고 있는 도달 노드 수 $c_m$과 일치하지 않으면 (경로 추측 스레드 중 일부를 누락한 것이므로) 이 분기는 거부합니다.
3. **만약 카운터 $k = c_m$이 정확히 일치하고 최종 거부되지 않았다면, 경로상에 $t$가 결코 도달할 수 없었음을 의미하므로 최종 수락(Accept)합니다.**

### $c_{d+1}$의 유도 알고리즘 (수학적 귀납적 카운팅)
위 알고리즘을 성립시키기 위해 $c_0 = 1$부터 시작해서 $c_{d+1}$을 로그 공간 내에서 유도해 나가는 신비한 서브루틴을 돌립니다.

1. 카운터 $k=0$으로 시작합니다.
2. 그래프의 모든 노드 $v$에 대해, $v \in R_{d+1}$ 인지(즉, $R_d$에 속한 어떤 노드와 엣지로 연결되어 있는지) 검사합니다.
   - 이를 위해 모든 노드 $u$에 대해 $s \to u$ 경로(길이 $d$)를 비결정론적으로 추측해 찾아냅니다. 찾을 때마다 확인 카운터 $j$를 1 늘립니다.
   - 만약 $u$를 성공적으로 찾았고 그 $u$에서 $v$로 가는 엣지가 존재한다면, $v$는 확실히 $R_{d+1}$의 일원이 되므로 $k$를 1 늘리고 다음 $v$ 검사로 넘어갑니다.
   - 모든 $u$를 확인했는데도 ($j = c_d$가 확인됨) 엣지가 연결된 노드가 없다면, $v$는 $R_{d+1}$에 속하지 않는 것으로 처리합니다.
3. 최종적으로 도출된 $k$ 값이 바로 **$c_{d+1}$**이 됩니다.

이 알고리즘은 단지 몇 개의 노드 인덱스 포인터($u, v$)와 카운터 값($j, k, d, c_d$)들만 작업 테이프에 유지하면 되므로, **정확히 $O(\log n)$ 공간 내에서 완벽하게 작동**합니다! 

따라서 $\overline{\text{PATH}} \in \text{NL}$ 이며, **$\text{NL} = \text{coNL}$** 이 증명됩니다.

## 요약 및 마치며

- **로그 공간 복잡도(L, NL)**는 입력 데이터 크기 $n$에 비해 극도로 적은 메모리인 **상수 개수의 포인터 비트($O(\log n)$)**만을 사용하는 계층입니다.
- NTM 설정의 총 개수가 다항식 범위 내에 수렴하므로, 설정 그래프 도달성 분석을 통해 **$\text{NL} \subseteq \text{P}$**가 성립합니다.
- NL-완전성을 정의할 때는 다중 전이의 유효성을 훼손하지 않기 위해 더 제약적인 **로그 공간 환원($\le_{\text{L}}$)**을 사용합니다.
- **$\text{PATH}$** 문제와 **$\overline{2\text{SAT}}$**는 대표적인 NL-완전 문제입니다.
- **임머만-셀레프체니 정리**는 $c_d$ 카운팅과 2-테이프 가상 머신 시뮬레이션을 통해 $\overline{\text{PATH}} \in \text{NL}$을 입증하며, 공간 복잡도의 위대한 대칭 정리인 **$\text{NL} = \text{coNL}$**을 완성했습니다.

메모리 공간을 극한으로 아끼는 로그 공간의 절약 정신과 대칭성을 수학적으로 규명했습니다. 

다음 21번째 강의 요약에서는 다시 시간 복잡도의 끝판왕 계층으로 돌아와, 시간과 공간 계층의 엄격한 상하 관계를 증명하는 **위계 정리(Hierarchy Theorems)**에 대해 알아보겠습니다!
