지난 23편에서는 확률적 튜링 머신(PTM)의 정의와 다수결 증폭 정리(Amplification Lemma)를 통한 BPP 클래스의 설계, 그리고 논리 회로를 수식으로 바꾸는 **산술화(Arithmetization)** 기법의 개념을 공부했습니다.

이번 24번째 강의와 강의 슬라이드에서는 산술화 기법을 완벽히 활용하여, 고전적인 결정적 알고리즘으로는 해결하기 극도로 까다로운 **1회 읽기 분기 프로그램(ROBP)의 동치성 문제**가 BPP 클래스에 속함을 증명해 보겠습니다.

---

## 1. 분기 프로그램(Branching Program)과 1회 읽기(Read-Once) 제약

**분기 프로그램(Branching Program, BP)**은 변수 검사 노드들과 0, 1 출력 단말 노드로 이루어진 유향 비순환 그래프(DAG)로, 부울 함수(Boolean Function)를 나타내는 한 모델입니다.
- 임의의 두 분기 프로그램이 동일한 동작을 하는지 판별하는 **$EQ_{\text{BP}}$** 문제는 **coNP-complete** 클래스에 속하는 매우 어려운 문제입니다.

여기서 변수 조회의 제한을 건 모델이 **1회 읽기 분기 프로그램 (Read-Once Branching Program, ROBP)** 입니다.
- **정의**: 임의의 입력 경로 상에서 변수 $x_i$를 **최대 한 번만 조회**할 수 있는 분기 프로그램입니다.
- **동치성 문제**: $EQ_{\text{ROBP}} = \{ \langle B_1, B_2 \rangle \mid B_1, B_2 \text{는 동치인 } \text{ROBP} \text{이다} \}$

이 제약이 걸린 $EQ_{\text{ROBP}}$ 문제는 놀랍게도 **BPP 클래스(확률적 다항 시간)** 내에 속하게 됩니다.

---

## 2. 산술화(Arithmetization) 기법: 논리를 다항식으로 변환

부울 값을 판단하는 분기 프로그램을 **실수나 유한체(Finite Field) 범위의 다항식**으로 번역하기 위해 다음과 같이 수식을 대응시킵니다.
- $x \wedge y \longrightarrow x \times y$ (곱셈)
- $\neg x \longrightarrow 1 - x$ (반전)
- $x \vee y \longrightarrow x + y - x \times y$ (합)

이 변환 룰을 ROBP 격자판 그래프에 적용하여 **산술적 라벨링(Arithmetical Labeling)**을 수행합니다.

```
       [ Start Node ]  (라벨 1로 시작)
             │
             ▼
        [ Query x_i ]
         ┌───┴───┐
      0  │       │ 1
         ▼       ▼
      [ 1 - x_i ] [  x_i  ] (자식 엣지에 부모 라벨과 변수를 곱함)
```

- **여러 경로가 모이는 노드**: 들어오는 엣지들의 라벨 값을 전부 **더합니다($+$)**.
  - *왜 OR 연산 대신 더하기를 쓸까요?* ROBP는 입력 경로 상에서 각 노드를 최대 한 번만 통과하므로, 부울 입력 환경에서는 동시에 참인 경로가 여러 개 겹쳐서 들어오지 않습니다. 따라서 더하기만 해도 완벽히 부울 합(OR)과 동등하게 작동합니다.

이 규칙을 끝까지 적용하면, ROBP의 1번 출력 노드에 도달했을 때 이 분기 프로그램의 출력을 대변하는 변수 $x_1, \dots, x_m$에 대한 거대한 **다항식 $p(x_1, \dots, x_m)$**이 정의됩니다.

## 3. 슈왈츠-지펠 정리(Schwartz-Zippel Theorem)와 동치성 테스트

동치성을 판별하기 위해, 두 다항식 $p_1$과 $p_2$의 무작위 값 대입 비교를 활용합니다. 이를 보장하는 수학적 정리가 **슈왈츠-지펠 정리**입니다.

> **슈왈츠-지펠 정리 (Schwartz-Zippel Theorem)**
> 영다항식이 아닌 각 변수의 최대 차수가 $d$ 이하인 다항식 $p(x_1, \dots, x_m) \neq 0$이 있고, 우리가 임의의 크기 $q$의 유한체 $\mathbb{F}_q$에서 임의의 난수 $r_1, \dots, r_m$을 무작위로 선택할 때, 다항식 계산 결과가 우연히 $0$이 될 확률은 다음과 같이 제한된다.
> $$\Pr[p(r_1, \dots, r_m) = 0] \le \frac{d \cdot m}{q}$$

### $EQ_{\text{ROBP}} \in \text{BPP}$ 알고리즘
1. 변수의 수 $m$에 대해, $q \ge 3m$을 만족하는 임의의 소수 $q$를 찾습니다.
2. 유한체 $\mathbb{F}_q$ 내에서 무작위 값 $r = r_1, \dots, r_m$을 고릅니다.
3. 산술화 기법을 사용하여 두 분기 프로그램 $B_1$과 $B_2$를 대입 값 $r$에 대해 연산하여 결과 다항식 값 $p_1(r)$과 $p_2(r)$을 구합니다.
4. $p_1(r) = p_2(r)$ 이면 **수락(동치)**하고, 다르면 **거부**합니다.

### 확률 및 복잡도 분석
- **동치인 경우 ($B_1 \equiv B_2$)**: 두 다항식이 완전히 수학적으로 동일하므로 무조건 $p_1(r) = p_2(r)$이 되어 **오차 확률은 0**입니다.
- **동치가 아닌 경우 ($B_1 \not\equiv B_2$)**: $p = p_1 - p_2 \neq 0$ 입니다. ROBP 특성상 각 변수를 한 번만 읽으므로 각 변수의 최대 차수는 $d=1$ 입니다. 슈왈츠-지펠 정리에 의해 우연히 결과가 같아질 확률은 다음과 같습니다.
  $$\Pr[p_1(r) = p_2(r)] = \Pr[(p_1 - p_2)(r) = 0] \le \frac{1 \cdot m}{q} \le \frac{m}{3m} = 1/3$$
  오차 확률이 정확히 **$1/3$ 이하**이므로 BPP 클래스의 오차 한계 조건을 완벽히 만족합니다.

## 4. 증명 완성의 두 가지 세부 디테일

### A. 1회 읽기(Read-Once) 제약이 해제되면 어떻게 되나요?
만약 변수를 여러 번 읽는 일반 분기 프로그램(BP)이라면, 다항식의 변수 차수가 $d \ge 2$로 상승할 수 있습니다. 

더 심각한 것은 $x_1^2$과 $x_1$처럼 부울 입력 $\{0,1\}$ 환경에서는 완전히 같은 결과를 내는 서로 다른 다항식이 존재하게 되어, 두 프로그램이 동치임에도 불구하고 다항식 자체가 불일치하는 모순이 생깁니다. 따라서 1회 읽기 제약은 이 다항식 증명의 필수적인 전제입니다.

### B. 공식이 지수적으로 커지면 시간 내에 계산할 수 있나요?
최종 출력 다항식을 완전히 전개(Expand)하여 전 항을 화면에 출력하려 하면 항의 개수가 지수적으로 폭발할 수 있습니다. 

하지만 우리는 **논리식 자체를 전개할 필요가 전혀 없습니다.** 난수 $r$이 주어졌을 때 격자판 그래프의 맨 위 노드부터 라벨에 숫자를 곱하고 더해가며 전파(Propagation)시키는 방식으로 값을 대입 연산하면, 단지 **그래프 크기에 비례하는 다항 시간 $O(|B_1| + |B_2|)$** 내에 결과 숫자값을 얻을 수 있습니다.

## 요약 및 마치며

- **1회 읽기 분기 프로그램(ROBP)**의 동치성 검사($EQ_{\text{ROBP}}$)는 확률적 난수 대입을 통해 BPP 클래스 내에서 풀 수 있습니다.
- **산술화**를 통해 논리합 노드를 단순 덧셈($+$)으로 치환할 수 있는 이유는 1회 읽기 경로의 배타적 전파 특성 덕분입니다.
- 두 다항식의 불일치 여부는 유한체 대입 테스트를 거쳐 **슈왈츠-지펠 정리**에 의해 오차 확률 $1/3$ 이하로 안전하게 수렴합니다.
- 다항식의 직접적인 공식 전개 없이 그래프를 타는 수치 계산 전파법을 통해 시간 복잡도를 다항 시간 내로 억제했습니다.

무작위 대입의 단순한 기법과 대수적 성질이 만나 가장 어려운 문제를 우아하게 돌파하는 확률적 계산의 진수를 공부했습니다.
