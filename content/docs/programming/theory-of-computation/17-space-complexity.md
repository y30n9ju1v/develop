## 1. 공간 복잡도(Space Complexity)의 정의와 클래스

시간 복잡도가 입력 크기 $n$에 대한 알고리즘의 동작 단계(Steps) 수라면, 공간 복잡도는 튜링 머신이 동작하는 동안 사용하는 **테이프 셀(Tape Cell)의 개수**를 기준으로 측정합니다.

> **공간 복잡도의 정의**
> 함수 $f: \mathbb{N} \to \mathbb{N}$에 대하여, 결정적 튜링 머신 $M$이 모든 길이 $n$의 입력에 대해 항상 정지하고 최대 $f(n)$개의 테이프 셀만 사용하여 계산을 마친다면, $M$은 **공간 복잡도 $f(n)$을 가진다**고 정의합니다.
> 
> 비결정적 튜링 머신(NTM) $N$의 경우, 계산 트리 상의 모든 분기 경로가 정지하고, **각 분기 경로가 사용하는 최대 공간이 $f(n)$ 이하**일 때 공간 복잡도 $f(n)$을 가진다고 정의합니다.

이를 바탕으로 다음과 같은 공간 복잡도 클래스를 정의할 수 있습니다.

- **$\text{SPACE}(f(n))$**: $O(f(n))$ 공간의 결정적 튜링 머신으로 판정 가능한 언어들의 집합.
- **$\text{NSPACE}(f(n))$**: $O(f(n))$ 공간의 비결정적 튜링 머신으로 판정 가능한 언어들의 집합.

### 다항 공간 클래스: PSPACE와 NPSPACE
시간 복잡도에서 다항 시간 클래스 P와 NP를 정의했듯이, 공간 복잡도에서도 다항 공간 한계 하의 클래스를 정의합니다.

$$\text{PSPACE} = \bigcup_{k \ge 1} \text{SPACE}(n^k)$$

$$\text{NPSPACE} = \bigcup_{k \ge 1} \text{NSPACE}(n^k)$$

### PSPACE의 강력한 특징: 하드웨어 모델 독립성
우리는 시간 복잡도를 측정할 때 다중 테이프 TM을 단일 테이프 TM으로 변환하면 시간이 최대 제곱($O(t^2(n))$)만큼 늘어나 모델에 따른 시간 변화가 컸던 것을 기억할 것입니다.

하지만 공간 복잡도에서는 매우 놀라운 현상이 일어납니다.

> **Check-in 17.1: 다중 테이프 TM의 공간을 단일 테이프 TM으로 변환하면 어떻게 될까?**
> 다중 테이프 TM에서 사용한 총 공간(각 테이프 공간의 합)이 $f(n)$일 때, 이를 단일 테이프 TM으로 시뮬레이션하더라도 필요한 공간은 **단지 상수 배(Constant Factor) 만큼만 증가**합니다.

여러 개의 테이프 내용을 단일 테이프 위에 나란히 배치하거나 특수 구분자로 묶어 관리하더라도, 실제로 활성화되어 채워진 셀의 물리적 개수는 거의 동일하기 때문입니다. 시간 복잡도가 제곱으로 늘어나는 것과 달리, **공간 복잡도는 하드웨어 모델 변화에 극도로 강력한 면모**를 보입니다.

## 2. 시간 복잡도와 공간 복잡도의 관계

시간과 공간은 서로 긴밀하게 연결되어 있으며, 다음과 같은 두 가지 핵심 정리가 성립합니다.

### 정리 1: $\text{TIME}(t(n)) \subseteq \text{SPACE}(t(n))$
- **직관적 이유**: 튜링 머신이 $t(n)$ 단계 동안 동작하면서 새로운 테이프 셀을 탐색하려면, 매 단계마다 헤드를 최대 한 칸씩만 움직일 수 있습니다. 따라서 $t(n)$ 스텝 내에 도달할 수 있는 테이프 셀의 최대 개수는 $t(n)$개를 절대 넘을 수 없습니다.
- **예**: $O(n^2)$ 시간에 도는 알고리즘은 물리적으로 $O(n^2)$보다 많은 메모리를 사용할 방법이 없습니다.

### 정리 2: $\text{SPACE}(t(n)) \subseteq \text{TIME}(2^{O(t(n))})$
- **직관적 이유**: 알고리즘이 단지 $t(n)$개의 테이프 공간만 사용한다고 해봅시다. 이때 발생할 수 있는 튜링 머신의 유한한 총 상태(Configuration)의 개수는 다음과 같이 계산됩니다.
  $$\text{가능한 상태 수} = (\text{제어 상태 수 } |Q|) \times (\text{헤드 위치 } t(n)) \times (\text{알파벳 조합 수 } |\Gamma|^{t(n)}) = 2^{O(t(n))}$$
  만약 이 기계가 $2^{O(t(n))}$ 단계를 초과하여 동작한다면, 비둘기집 원리에 의해 반드시 동일한 컴퓨터 상태를 최소한 한 번 이상 다시 밟게 됩니다. 이는 무한 루프에 빠져 영원히 정지하지 않음을 의미합니다.
  하지만 우리가 정의한 공간 복잡도의 튜링 머신은 항상 정지하는 판정기(Decider)이므로, 루프 없이 동작을 끝내기 위해선 반드시 $2^{O(t(n))}$ 단계 이내에 정지해야만 합니다.

### 따름정리: P와 NP는 모두 PSPACE에 포함된다 ($\text{P} \subseteq \text{PSPACE}$, $\text{NP} \subseteq \text{PSPACE}$)
정리 1에 의해 $\text{P} \subseteq \text{PSPACE}$임은 자명합니다. 그렇다면 답을 구하기가 매우 까다로운 **NP 클래스도 PSPACE에 들어갈까요?**

> **NP ⊆ PSPACE의 직접 증명: SAT ∈ PSPACE**
> 대표적인 NP-완전 문제인 SAT를 예로 들어봅시다. 변수가 $m$개이고 식의 길이가 $n$인 논리식 $\phi$가 주어졌을 때:
> 1. 변수의 참/거짓 값 조합 $2^m$가지를 하나씩 차례대로 대입하며 논리식을 평가합니다.
> 2. 이때 중요한 점은, **이전 조합을 평가할 때 사용했던 메모리 공간을 다음 조합을 검사할 때 고스란히 재사용(Reuse)할 수 있다**는 점입니다.
> 3. 따라서 필요한 메모리는 현재 대입된 $m$개의 변수 값 저장 공간과 논리식 평가용 임시 공간($O(n)$)이 전부입니다.
> 4. 결과적으로 총 $O(n)$의 선형 공간(Linear Space)만으로도 모든 경우의 수를 돌려보며 SAT를 완벽히 판정해낼 수 있습니다.
> 
> 모든 NP 문제는 SAT로 다항 시간 환원될 수 있으며, PSPACE는 다항 시간 환원에 닫혀 있으므로 **$\text{NP} \subseteq \text{PSPACE}$**가 성립합니다.

시간 복잡도의 세계에서는 한 번에 모든 경로를 탐색해야 해서 분기(Nondeterminism)를 다루기 위해 막대한 시간이 필요했던 반면, **공간 복잡도에서는 계산 결과를 메모리에서 지우고 재사용할 수 있기 때문에** NP 문제조차 PSPACE 내에서 손쉽게 해결할 수 있습니다.

이 관계를 복잡도 계층으로 도식화하면 다음과 같습니다.

$$\text{P} \subseteq \text{NP} \subseteq \text{PSPACE} = \text{NPSPACE}$$

## 3. PSPACE의 대표 문제: TQBF (True Quantified Boolean Formula)

NP의 끝판왕이 SAT였다면, PSPACE의 대변자이자 가장 어려운 핵심 문제는 바로 **TQBF**입니다.

### A. Quantified Boolean Formula (QBF)
기존의 부울 논리식에 논리기호 **$\exists$ (존재한다, exists)**와 **$\forall$ (모든 것에 대하여, for all)** 한정기(Quantifier)가 추가된 식을 말합니다.
- 예시 1: $\phi_1 = \forall x \exists y [(x \vee y) \wedge (\bar{x} \vee \bar{y})]$
  - 의미: "어떤 $x$를 고르더라도, 식을 만족하는 $y$가 항상 존재하는가?"
  - 판단: 만약 $x=\text{True}$이면 $y=\text{False}$를 고르면 되고, $x=\text{False}$이면 $y=\text{True}$를 고르면 만족하므로 이 식은 참(True)입니다. ($\phi_1 \in \text{TQBF}$)
- 예시 2: $\phi_2 = \exists y \forall x [(x \vee y) \wedge (\bar{x} \vee \bar{y})]$
  - 의미: "모든 $x$에 대해 식을 만족하게 만드는 마법의 $y$가 존재하는가?"
  - 판단: $y$를 참/거짓 중 무엇으로 정하든, 상대방이 $x$를 교묘하게 바꾸면 식을 거짓으로 만들 수 있으므로 이 식은 거짓(False)입니다. ($\phi_2 \notin \text{TQBF}$)

### B. TQBF ∈ PSPACE 증명: 재귀적 공간 분석
QBF 논리식이 참인지 판정하는 문제는 변수를 하나씩 참/거짓으로 쪼개서 검사하는 재귀 알고리즘으로 풀 수 있습니다.

```
On input ⟨𝜙⟩:
1. 만약 𝜙에 한정기가 없다면 (즉, 변수 없이 상수만 남은 식):
   - 식을 직접 계산하여 True 또는 False를 출력한다.
2. 만약 𝜙 = ∃x 𝜓 이라면:
   - x = True를 대입한 𝜓와 x = False를 대입한 𝜓를 각각 재귀적으로 호출한다.
   - 둘 중 하나라도 Accept하면 Accept하고, 모두 Reject하면 Reject한다.
3. 만약 𝜙 = ∀x 𝜓 이라면:
   - x = True를 대입한 𝜓와 x = False를 대입한 𝜓를 각각 재귀적으로 호출한다.
   - 둘 다 Accept하면 Accept하고, 하나라도 Reject하면 Reject한다.
```

#### 공간 복잡도 분석
이 재귀 트리의 최대 깊이는 한정기(변수)의 개수인 $m \le n$입니다. 각 재귀 단계에서는 오직 현재 할당된 변수 $x$의 상태($O(1)$)만을 기록하며, 하위 재귀 호출이 끝나면 사용된 스택 메모리는 바로 반환되어 다음 대입을 위해 **재사용**됩니다.

따라서 전체 메모리 공간은 재귀 호출 깊이에 비례하는 **$O(n)$ 선형 공간**이 됩니다.

$$\text{TQBF} \in \text{SPACE}(n) \subseteq \text{PSPACE}$$

## 4. 단어 사다리 문제 (Word Ladder)와 Savitch 정리의 핵심

공간 복잡도의 마지막 논점으로, 한 단어에서 다른 단어로 한 글자씩 바꿔나가며 타깃 단어에 도달하는 게임인 **단어 사다리(Word Ladder)** 문제를 다뤄보겠습니다. 

```
WORK ➔ PORK ➔ PORT ➔ SORT ➔ SOOT ➔ SLOT ➔ PLOT ➔ PLOY ➔ PLAY
(글자를 매번 한 글자씩만 바꾸어 WORK에서 PLAY로 도달)
```

이 문제를 일반화하여, 주어진 DFA $B$가 수락하는 언어들의 문자열 안에서 출발 단어 $u$에서 도착 단어 $v$로 가는 단어 사다리 경로가 있는지 판정하는 문제를 $\text{LADDER}_{\text{DFA}}$라고 정의합니다.

$$\text{LADDER}_{\text{DFA}} = \{ \langle B, u, v \rangle \mid B\text{는 DFA이고, } L(B)\text{ 내에서 } u\text{에서 } v\text{로 가는 단어 사다리가 존재한다} \}$$

### A. 비결정적 접근: $\text{LADDER}_{\text{DFA}} \in \text{NSPACE}(n)$
이 문제를 NTM으로 풀려면 다음처럼 비결정적으로 단어를 하나씩 추측하며 나아가면 됩니다.
1. 현재 단어 $y = u$로 세팅한다.
2. 최대 $t = |\Sigma|^m$번 반복한다 (단어의 최대 길이 $m = |u|$, 중복 방문 방지용 카운터).
3. 비결정적으로 한 글자만 바꾼 새로운 단어 $y'$를 고른다.
4. 만약 $y' \notin L(B)$ 이면 거부한다.
5. 만약 $y' = v$ 이면 수락한다.
6. 반복 횟수가 $t$를 초과하면 거부한다.

이 알고리즘이 사용하는 메모리는 오직 **현재 단어 $y$**와 **카운터 $t$**뿐입니다. $t$는 이진수로 표기하면 $\log (|\Sigma|^m) = O(m)$비트의 메모리만 필요하므로, 전체 사용 공간은 **$O(n)$의 선형 공간**이면 충분합니다. 

따라서 **$\text{LADDER}_{\text{DFA}} \in \text{NSPACE}(n)$**입니다.

### B. 결정적 접근: 분할 정복과 Savitch 정리의 탄생 ($\text{LADDER}_{\text{DFA}} \in \text{SPACE}(n^2)$)
비결정론 공간 알고리즘을 결정론적으로 흉내 내기 위해 모든 경로를 하나씩 따라가며 탐색하면 공간이 엄청나게 많이 들 것 같지만, **분할 정복(Divide-and-Conquer)**을 활용하면 이를 매우 효율적으로 해낼 수 있습니다.

$u$에서 $v$로 $b$ 단계 이내에 갈 수 있는지를 확인하는 재귀 함수 $B\text{-}L(B, u, v, b)$를 만들어 봅시다.

```
B-L(B, u, v, b):
1. 만약 b = 1 이면:
   - u, v가 DFA B에 수락되고, 두 단어 차이가 1글자 이하인지 검사 후 수락/거부 결정.
2. 만약 b > 1 이면:
   - u와 v의 중간 가교 역할을 할 모든 중간 단어 w(길이 |u|)에 대해 다음을 시도한다:
   - B-L(B, u, w, b/2)와 B-L(B, w, v, b/2)를 각각 재귀 호출한다.
   - 두 호출이 모두 성공적으로 수락하면 수락한다.
3. 모든 중간 단어 w에 대해 실패하면 거부한다.
```

이 알고리즘을 통해 최대 단계 수인 $t = |\Sigma|^m$에 대해 $B\text{-}L(B, u, v, t)$를 평가합니다.

#### 공간 복잡도 분석
- **재귀 깊이**: 단계를 매번 절반씩 쪼개므로 재귀 스택의 깊이는 $\log t = \log (|\Sigma|^m) = O(m) = O(n)$이 됩니다.
- **단계별 공간**: 각 재귀 레벨에서는 대입해 볼 중간 단어 $w$의 정보($O(n)$ 공간)만 기억하면 됩니다. 호출이 끝나면 이 공간은 복귀 시점에 즉시 반납되고 재사용됩니다.
- **총 공간 복잡도**: $\text{재귀 깊이} \times \text{레벨당 공간} = O(n) \times O(n) = \mathbf{O(n^2)}$

NPSPACE에 속했던 문제를 결정론적 알고리즘을 통해 다항 공간 제곱 차수($O(n^2)$) 내에 해결해 냈습니다. 이 분할 정복 탐색 기법은 임의의 비결정적 계산 트리 전반에 적용할 수 있으며, 이것이 바로 계산 이론의 이정표인 **Savitch의 정리**의 핵심 메커니즘입니다!

> **새비치 정리 (Savitch's Theorem)**
> $f(n) \ge \log n$인 모든 함수에 대하여 다음이 성립한다.
> $$\text{NSPACE}(f(n)) \subseteq \text{SPACE}(f^2(n))$$
> 
> 결과적으로 다항식의 제곱은 여전히 다항식이므로, 다항 공간 내에서 비결정론과 결정론은 서로 완전히 동일한 능력을 갖춥니다: **$\text{PSPACE} = \text{NPSPACE}$**

---

## 요약 및 마치며

- **공간 복잡도**는 연산 단계수가 아닌 사용한 테이프 셀의 수로 계산 자원을 측정하며, 하드웨어 모델(다중 테이프 등)에 큰 영향을 받지 않는 탄탄한 성질을 갖습니다.
- 시간 복잡도와 공간 복잡도의 관계에 의해 $\text{P} \subseteq \text{NP} \subseteq \text{PSPACE}$ 가 성립합니다. 공간을 재사용할 수 있는 강점 덕분에 $\text{SAT} \in \text{PSPACE}$ 가 쉽게 유도됩니다.
- 한정기를 도입한 부울 논리식 판정 문제인 **$\text{TQBF}$**는 스택 재사용을 통해 $O(n)$ 선형 공간 내에 해결 가능하며, $\text{PSPACE}$의 대표적인 문제 역할을 합니다.
- 단어 사다리 문제($\text{LADDER}_{\text{DFA}}$)는 분할 정복을 이용해 중간 단어를 찾는 방식으로 재귀 탐색을 수행하면 $O(n^2)$ 공간에 판정 가능하며, 이는 **비결정적 공간을 결정적 공간의 제곱 관계로 시뮬레이션할 수 있다**는 **새비치 정리(Savitch's Theorem)**의 실제적인 작동 모델이 됩니다.

이제 우리는 시간과 공간 복잡도를 지나며 복잡도 이론의 거대한 두 축을 모두 세웠습니다. 다음 18번째 강의 요약에서는 이 강력한 PSPACE 계층의 완전성 문제들과 그래프 게임 이론들의 흥미진진한 응용 분야를 공부하겠습니다!
