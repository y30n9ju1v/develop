지난 21편(그리고 상대적 복잡도를 다룬 22편)에서는 계산 자원 증가에 따른 정밀한 한계를 그리는 계층 정리와 오라클(Oracle) 머신의 개념을 공부했습니다. 

지금까지의 튜링 머신들은 철저하게 정해진 경로만을 따라가는 **결정적(Deterministic) 계산**만을 수행해 왔습니다. 하지만 현대의 수많은 효율적인 알고리즘들은 한 단계 한 단계 진행할 때마다 동전을 던져 무작위 선택을 하는 **확률적(Probabilistic) 계산**을 적극적으로 도입하고 있습니다.

이번 23번째 강의와 강의 슬라이드에서는 컴퓨터 과학에서 무작위성(Randomness)이 어떻게 계산 자원으로서 효율성을 가져다주는지, 그리고 이 무작위성을 반영한 다항 시간 클래스인 **BPP**와 그 강력한 기법인 **아리스메티제이션(Arithmetization)**에 대해 알아보겠습니다.

## 1. 확률적 튜링 머신 (Probabilistic Turing Machine, PTM)

**확률적 튜링 머신(PTM)**은 각 계산 단계마다 튜링 머신이 '동전 던지기'를 통해 두 가지 선택지 중 하나를 확률적으로 선택하며 나아가는 비결정론적 튜링 머신(NTM)의 변형 모델입니다.

```
                  [ 현재 상태 ]
                  /          \
  (동전 앞면: 50%)              (동전 뒷면: 50%)
        /                          \
   [ 다음 상태 A ]              [ 다음 상태 B ]
```

- **경로의 확률**: 만약 어떤 특정 계산 경로(Branch) $b$에서 총 $k$번의 동전 던지기가 일어났다면, 이 경로를 타게 될 확률은 **$\text{Pr}[\text{branch } b] = 2^{-k}$**가 됩니다.
- **수락 확률 (Accepting Probability)**: 기계 $M$이 입력 $w$를 수락할 확률은 수락 노드로 끝나는 모든 연산 경로들의 확률의 합입니다.
  $$\text{Pr}[M\text{ 이 } w\text{ 를 수락한다}] = \sum_{b\text{는 수락 경로}} \text{Pr}[\text{branch } b]$$
- **거절 확률**: 자연스럽게 $1 - \text{Pr}[M \text{ 이 } w \text{ 를 수락한다}]$ 가 됩니다.

### 오차 확률(Error Probability)을 가진 판정 조건
확률적 머신은 동전 던지기 결과에 따라 가끔은 잘못된 답을 낼 수도 있습니다. 이를 수학적으로 제어하기 위해 **오차 한계 $\epsilon$**을 정의합니다.

> **PTM의 언어 판정 정의**
> 어떤 오차 확률 $\epsilon \ge 0$에 대하여, PTM $M$이 다음 조건을 만족하면 언어 $A$를 **오차 확률 $\epsilon$으로 판정(Decide)한다**고 정의합니다.
> 1. $w \in A \implies \text{Pr}[M\text{ 이 } w\text{ 를 거절한다}] \le \epsilon$ (참인데 거짓으로 오판할 확률 $\le \epsilon$)
> 2. $w \notin A \implies \text{Pr}[M\text{ 이 } w\text{ 를 수락한다}] \le \epsilon$ (거짓인데 참으로 오판할 확률 $\le \epsilon$)

## 2. 다항 시간 확률 클래스 BPP (Bounded-error Probabilistic Polynomial-time)

현대 컴퓨터 과학에서 실질적인 '무작위성 다항 시간 효율적 알고리즘'들의 경계를 긋는 복잡도 클래스가 바로 **BPP**입니다.

> **클래스 BPP의 정의**
> 다항 시간(Polynomial-time) 내에 동작하는 확률적 튜링 머신 $M$이 존재하여, **오차 확률 $\epsilon = 1/3$ 이하**로 언어 $A$를 판정할 때, 이 언어 $A$들의 집합을 **BPP**라고 정의합니다.
> 
> $$\text{BPP} = \{ A \mid \text{어떤 다항 시간 PTM이 오차 } \epsilon = 1/3 \text{ 이하로 } A\text{를 판정한다} \}$$

### 질문: 왜 하필 오차 확률 경계가 $1/3$ 일까요?
오차 확률이 $1/3$이나 된다는 것은 대략 3번 중 1번은 틀린 답을 낼 수 있다는 의미이므로 너무 부정확해 보입니다. $1/10$이나 $1/1000$처럼 더 엄격한 숫자를 기준으로 삼아야 하지 않을까요?

놀랍게도, **증폭 정리(Amplification Lemma)**에 의해 $1/2$보다 엄격하게 작은 임의의 상수(예: $0.49$)만 보장된다면, 그 기준은 수학적으로 모두 동치임이 증명되어 있습니다.

> **증폭 정리 (Amplification Lemma)**
> 오차 확률 $\epsilon_1 < 1/2$를 가지는 다항 시간 PTM $M_1$이 존재한다면, 임의의 극단적으로 작은 오차 확률 $\epsilon_2 > 0$에 대해서도 이와 동등한 연산을 수행하는 PTM $M_2$를 설계할 수 있습니다.
> 
> 심지어 오차 확률을 입력의 길이에 비례해 지수적으로 작은 **$\epsilon_2 < 2^{-\text{poly}(n)}$** 수준까지 떨어뜨릴 수 있습니다.

- **증명 아이디어**: 
  1. 기계 $M_1$을 입력 $w$에 대해 독립적으로 **$k$번 반복해서 수행**합니다.
  2. $k$번의 연산 결과 중 **다수결(Majority)**이 지목하는 결과를 최종 출력으로 채택합니다.
  3. 통계학의 대수의 법칙(Chernoff Bound)에 의해, $k$가 다항식 수준으로만 커지더라도 다수결의 판단이 틀릴 확률은 지수 함수 곡선을 그리며 순식간에 $0$으로 수렴하게 됩니다.
- **의의**: 따라서 오차 경계치인 $1/3$은 단지 수학적 정의를 명확히 하기 위한 상징적 숫자에 불과하며, 실질적으로 BPP에 속한 알고리즘들은 몇 번만 반복해서 돌려보면 우주적 확률로 오답 가능성이 없는 완벽한 알고리즘으로 업그레이드될 수 있습니다.

### Check-in 23.1: BPP 클래스의 성질
BPP는 다음과 같은 우수한 성질들을 내포하고 있습니다.
- **여집합에 닫혀 있음 (Closed under complement)**: 수락과 거절 상태를 뒤집기만 하면 되므로 자명합니다 ($\text{BPP} = \text{coBPP}$).
- **합집합에 닫혀 있음 (Closed under union)**: 오차를 지수적으로 극단화한 뒤($\epsilon < 1/6$) 두 BPP 판정기를 결합하면 합집합 역시 $1/3$ 이하의 오차로 완벽히 판정해낼 수 있습니다.
- **$\text{P} \subseteq \text{BPP}$**: 동전을 아예 던지지 않는(오차 확률 $0$) 결정적 다항 시간은 BPP의 완벽한 부분집합입니다.
- **$\text{BPP} \subseteq \text{PSPACE}$**: 확률 트리의 모든 경로를 깊이 우선 탐색(DFS) 방식으로 순차적으로 탐색하여 확률들의 합을 계산하되, 메모리 공간을 재사용하면 다항 공간($\text{PSPACE}$) 내에 완벽하게 시뮬레이션할 수 있습니다.

## 3. 분기 프로그램 (Branching Programs, BP)

확률적 계산의 강력한 예시를 설명하기 위해, 하드웨어 회로 복잡도를 분석할 때 널리 쓰이는 **분기 프로그램(Branching Programs, BP)** 모델을 도입하겠습니다.

### A. 정의
분기 프로그램(BP)은 변수값에 따른 조건문 흐름을 방향성 아사이클릭 그래프(DAG, Directed Acyclic Graph)로 도식화한 모델입니다.

1. **질의 노드(Query Node)**: 각 변수 $x_i$ 레이블이 붙어 있으며, 변수값에 따라 이동할 **0번 간선**과 **1번 간선**이 뻗어 나갑니다.
2. **출력 노드(Output Node)**: 최종 결과값인 **0**과 **1** 레이블이 붙은 두 개의 단말 노드입니다.
3. **시작 노드**: 연산이 시작되는 고유한 노드입니다.

입력 변수 쌍 $(x_1, \dots, x_m)$이 주어지면, 시작 노드에서 출발하여 질의 노드의 변수값 지시에 따라 화살표를 타고 내려가서 최종 도달한 출력 노드의 값(0 또는 1)이 프로그램의 최종 아웃풋이 됩니다.

```
        [ x_1 ]
       0/     \1
    [ x_2 ]  [ x_3 ]
     ...      ...
    ( 0 )    ( 1 )  <-- 최종 출력 노드
```

### B. BP의 동치성 판별 문제 ($\text{EQ}_{\text{BP}}$)
두 개의 분기 프로그램 $B_1$과 $B_2$가 완벽하게 동일한 논리 함수를 나타내는지 판별하는 문제를 $\text{EQ}_{\text{BP}}$라고 합니다.
$$\text{EQ}_{\text{BP}} = \{ \langle B_1, B_2 \rangle \mid B_1 \text{과 } B_2 \text{는 동치인 BP이다} \}$$

이 일반적인 동치성 판별 문제는 아쉽게도 **$\text{coNP}$-완전** 문제로 매우 어렵다고 증명되어 있습니다. 만약 이 문제가 $\text{BPP}$에 속한다면 $\text{coNP} \subseteq \text{BPP}$ 즉 $\text{NP} \subseteq \text{BPP}$라는 전산학계의 대변혁이 일어나게 되는데, 이는 매우 드문 케이스로 간주됩니다.

## 4. 읽기 한 번 분기 프로그램(ROBP)과 아리스메티제이션(Arithmetization)

이에 따라 수학자들은 질의 횟수에 제약을 건 **읽기 한 번 분기 프로그램(Read-once Branching Programs, ROBP)**으로 대상을 한정했습니다.

> **읽기 한 번 분기 프로그램 (ROBP)**
> 시작 노드에서 출력 노드에 이르는 그래프 상의 어떠한 경로를 선택하더라도, **동일한 입력 변수 $x_i$를 두 번 이상 중복해서 물어보지 않는(최대 한 번만 읽는)** BP를 말합니다.

놀랍게도, ROBP의 동치성을 판정하는 문제는 **BPP 클래스에 속합니다.**

$$\text{EQ}_{\text{ROBP}} \in \text{BPP}$$

### A. 소박한 접근법의 한계: 왜 무작위 대입 테스트가 실패할까?
동등한지 검사하기 위해 무작위로 $x_1, \dots, x_m$에 $0$ 또는 $1$ 값을 대입하여 결과가 같은지 여러 번 시도해 보는 알고리즘을 떠올릴 수 있습니다.

하지만 만약 $B_1$과 $B_2$가 전체 $2^m$가지 입력 조합 중 **단 한 개의 특수한 조합에서만 결과가 다르다**면 어떻게 될까요? 무작위 샘플링을 다항식 번만 해서는 이 모래사장 속의 바늘 같은 예외 조합을 찾아낼 확률이 거의 제로에 가깝습니다. 이를 해결하기 위해선 지수 번($2^m$) 대입해야 하므로 다항 시간 내에 불가능합니다.

### B. 혁신적인 해결책: 아리스메티제이션 (Arithmetization)
이 한계를 극복하기 위해 부울 논리(0과 1)를 수치 다항식 연산으로 변환하는 **아리스메티제이션(Arithmetization)** 기법을 사용합니다. 논리 기호 $\wedge, \vee, \neg$를 실수 또는 거대 유한체 상의 더하기와 곱하기 다항식 규칙으로 맵핑하는 것입니다.

- **AND 연산 ($\wedge$)**: $a \wedge b \to a \times b = ab$
- **NOT 연산 ($\neg$)**: $\bar{a} \to 1 - a$
- **OR 연산 ($\vee$)**: $a \vee b \to a + b - ab$

이 매핑을 ROBP 구조에 그대로 씌우면, 각 노드와 간선을 지날 때 흘러가는 수치가 수식 다항식으로 표현됩니다.

> **아리스메티제이션 수치 레이블링 규칙**
> 1. **시작 노드**의 입력 수치 레이블은 **$1$**로 설정합니다.
> 2. 변수 $x_i$ 질의 노드에 도달한 입력 수치 값이 $a$일 때:
>    - **0번 간선**으로 흘러갈 수치 값은 **$a(1-x_i)$**로 보냅니다.
>    - **1번 간선**으로 흘러갈 수치 값은 **$a x_i$**로 보냅니다.
> 3. 여러 개의 간선이 한 노드로 모여 들어올 때:
>    - 모여든 수치들을 **전부 더해줍니다** ($a_1 + a_2 + a_3$).

#### Check-in 23.3의 계산 예시
위의 아리스메티제이션 해석을 적용하여, 슬라이드의 예제 그래프에 $x_1 = 1, x_2 = y$를 대입했을 때 출력 1번 노드에 모이는 최종 수식을 계산해 봅시다.

1. **시작 노드**에 값 $1$이 공급됩니다. (레이블 $1$)
2. 첫 번째 노드 $x_1$은 값 $1$을 전송받아 $x_1 = 1$ 조건으로 분기합니다:
   - 0번 간선 방향: $1 \times (1 - x_1) = 1(1-1) = 0$
   - 1번 간선 방향: $1 \times x_1 = 1(1) = 1$
3. 이에 따라 좌측의 $x_2$ 노드는 값 $0$을 받고, 우측의 $x_2$ 노드는 값 $1$을 받습니다.
4. 우측 $x_2$ 노드(입력값 $1$)는 $x_2 = y$ 변수에 대해 분기합니다:
   - 1-출력 노드(0번 간선 방향): $1 \times (1 - x_2) = 1 - y$
   - 0-출력 노드(1번 간선 방향): $1 \times x_2 = y$
5. 좌측 $x_2$ 노드는 입력값이 $0$이므로 출력에 아무 기여를 하지 못합니다 (모두 0).
6. 최종적으로 **1-출력 노드**에 도착한 값들의 합은 **$1 - y$**가 됩니다. (선택지 a)

### C. 비부울 대입을 활용한 동치성 검정 BPP 알고리즘
아리스메티제이션을 거치면, ROBP $B_1$과 $B_2$는 각각 변수 $x_1, \dots, x_m$에 대한 **다항식 $P_1(x_1, \dots, x_m)$과 $P_2(x_1, \dots, x_m)$**으로 완벽하게 환원됩니다. 

이제 두 프로그램이 같은지 검사하기 위해 부울 값(0, 1)이 아닌, 아주 거대하고 거친 수들의 집합인 **비부울 영역(예: 거대 소수 $p$에 대한 유한체 $\mathbb{F}_p$)에서 무작위로 값을 선택해 대입**합니다!

$$\text{무작위 대입 쌍: } r_1, \dots, r_m \in \mathbb{F}_p$$

만약 두 다항식이 서로 다른 다항식($P_1 \ne P_2$)이라면, 이들이 거대한 유한체 공간 상에서 무작위 점 대입 값으로 일치할 확률은 어떻게 될까요? 
대수학의 저명한 법칙인 **Schwartz-Zippel Lemma**에 의하면, 서로 다른 다항식이 무작위 좌표 대입으로 우연히 일치할 확률은 전체 공간의 크기 분의 다항식 차수 정도로 극단적으로 낮습니다.

$$P_1 \ne P_2 \implies \text{Pr}[P_1(r_1, \dots, r_m) = P_2(r_1, \dots, r_m)] \le \frac{d \cdot m}{|S|}$$

(단, $d$는 다항식의 차수, $m$은 변수의 개수, $|S|$는 유한체의 크기입니다.)

따라서 $r_i$를 충분히 큰 범위에서 무작위로 한 번만 뽑아 $P_1(r)$과 $P_2(r)$을 계산해 보고 같으면 수락(Accept), 다르면 거절(Reject)하는 알고리즘을 수행하면 다항식 시간 내에 극소의 오차율을 보장하며 $\text{EQ}_{\text{ROBP}}$를 완벽히 해결할 수 있습니다. 

무작위 대입 대상을 부울 식 영역 너머의 공간으로 강제로 대수적 확장(Arithmetization)을 이끌어냄으로써, **BPP 클래스가 난제를 해결하는 환상적인 메커니즘**이 완성됩니다.

## 요약 및 마치며

- **확률적 튜링 머신(PTM)**은 매 단계 동전 던지기를 가미하여 결과의 확률적 합산으로 언어를 수락 및 거절합니다.
- **클래스 BPP**는 다항 시간 내에 오차율 $1/3$ 이하로 정답을 판정하며, 다수결 반복을 이용한 **증폭 정리** 덕분에 실질적인 정밀 알고리즘 계층의 척도가 됩니다.
- **분기 프로그램(BP)**은 조건 전이 그래프로 논리식을 기술하며, 일반적인 동치성 문제($\text{EQ}_{\text{BP}}$)는 coNP-완전으로 분류됩니다.
- 한 번씩만 읽는 **ROBP**의 경우, 논리 기호를 다항식 덧셈/곱셈으로 치환하는 **아리스메티제이션(Arithmetization)**과 비부울 입력값 무작위 대입(Schwartz-Zippel 활용)을 결합하여 **$\text{EQ}_{\text{ROBP}} \in \text{BPP}$** 임을 성공적으로 증명해 냅니다.

무작위성을 활용해 난공불락의 문제를 우회하여 해결하는 확률적 복잡도의 매혹적인 정수를 경험했습니다. 다음 24번째 강의 요약에서는 이 확률적 계산을 이어나가며 대수적 연산과 더 깊은 인터랙티브 증명 시스템으로 나아가 보겠습니다!
