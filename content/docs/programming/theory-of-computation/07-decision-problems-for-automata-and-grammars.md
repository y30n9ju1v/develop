지난 6편에서는 다중 테이프 머신이나 비결정적 머신 등 온갖 복잡한 변형 튜링 머신들이 결국 단일 테이프 모델과 동등한 능력을 지님을 배웠고, 알고리즘의 본질을 밝히는 처치-튜링 명제를 공부했습니다.

이번 7번째 강의와 [강의 슬라이드](file:///Users/yeongjun/Develops/develop/static/references/theory-of-computation/lecture-07-decision-problems-for-automata-and-grammars.pdf)에서는 이제 시선을 돌려 **"튜링 머신(컴퓨터)을 이용해 다른 오토마타나 문법의 성질을 분석할 수 있을까?"**라는 질문을 다룹니다.

즉, 오토마타와 문법에 대한 다양한 질문들을 하나의 언어(인코딩된 문자열들의 집합)로 정의하고, 이 문제들이 알고리즘을 통해 풀릴 수 있는지(**판정 가능성, Decidability**)를 하나씩 증명해 보겠습니다.

---

## 1. 정규 언어(DFA/NFA) 관련 판정 가능한 문제들

컴퓨터 과학에서 오토마타에 대해 물어볼 수 있는 가장 대표적인 세 가지 질문은 다음과 같습니다:
1. **수락성(Acceptance)**: "이 오토마타가 이 문자열을 수락하는가?"
2. **공백성(Emptiness)**: "이 오토마타가 수락하는 문자열이 단 하나라도 존재하는가? (언어가 비어 있는가?)"
3. **동치성(Equivalence)**: "이 두 오토마타가 인식하는 언어가 완벽히 같은가?"

이 질문들을 코드로 판정하는 판정기(Decider)를 만들 수 있을까요? 답은 전부 **"예"**입니다.

### A. DFA 수락 문제 ($A_{\text{DFA}}$)
$$A_{\text{DFA}} = \{ \langle B, w \rangle \mid B\text{는 DFA이고, } B\text{는 } w\text{를 수락한다} \}$$
- **판정 알고리즘**: 판정기 $D_{\text{A-DFA}}$는 입력받은 DFA $B$를 테이프 위에서 직접 시뮬레이션하여 문자열 $w$를 읽어나갑니다. $B$가 수락 상태로 끝나면 수락하고, 일반 상태로 끝나면 거부합니다. 
- 이 시뮬레이션은 딱 $|w|$ 단계 내에 정지함이 보장되므로, 이 문제는 **판정 가능(Decidable)**합니다.

### B. NFA 수락 문제 ($A_{\text{NFA}}$)
$$A_{\text{NFA}} = \{ \langle B, w \rangle \mid B\text{는 NFA이고, } B\text{는 } w\text{를 수락한다} \}$$
- **판정 알고리즘**: 먼저 서브루틴을 사용하여 NFA $B$를 동등한 DFA $B'$로 변환합니다. 그리고 앞서 만든 $D_{\text{A-DFA}}$ 판정기에 $\langle B', w \rangle$를 넣어 실행합니다. 변환 과정과 시뮬레이션 모두 유한 단계 내에 끝나므로 **판정 가능**합니다.

### C. DFA 공백성 문제 ($E_{\text{DFA}}$)
$$E_{\text{DFA}} = \{ \langle B \rangle \mid B\text{는 DFA이고, } L(B) = \emptyset \}$$
- **판정 알고리즘**: 오토마타의 그래프 상에서 **시작 상태에서 수락 상태로 가는 경로가 존재하는지** 탐색하는 문제입니다.
  1. 시작 상태에 마크(Mark)를 표시합니다.
  2. 마크가 표시된 상태에서 전이 화살표를 타고 갈 수 있는 모든 다음 상태들에 반복해서 마크를 표시합니다. (더 이상 마크할 상태가 없을 때까지 반복)
  3. 탐색이 끝난 후, 수락 상태 중 마크가 표시된 곳이 단 하나도 없다면 수락(언어가 비어 있음)을 선언하고, 하나라도 마크되어 있다면 거부합니다.
- 상태의 개수가 유한하므로 무조건 정지하며, 따라서 **판정 가능**합니다.

### D. DFA 동치성 문제 ($EQ_{\text{DFA}}$)
$$EQ_{\text{DFA}} = \{ \langle A, B \rangle \mid A, B\text{는 DFA이고, } L(A) = L(B) \}$$
- **판정 알고리즘**: 두 DFA $A$와 $B$가 서로 다른 언어를 인식하는 오작동 영역을 감지하기 위해, **대칭차(Symmetric Difference)** 언어를 인식하는 새로운 DFA $C$를 조립합니다.
  $$L(C) = (L(A) \cap \overline{L(B)}) \cup (\overline{L(A)} \cap L(B))$$
  만약 두 언어가 완전히 같다면 대칭차 언어는 완벽히 비어 있어야 합니다 ($L(C) = \emptyset$).
- 정규 언어는 여집합, 교집합, 합집합 연산에 대해 닫혀 있으므로 DFA $C$를 기계적으로 합성할 수 있습니다. 
- 합성된 $\langle C \rangle$를 위에서 정의한 $E_{\text{DFA}}$ 판정기에 넣어 작동시킵니다. 비어 있다고 통과하면 두 기계가 동치이므로 수락하고, 비어 있지 않으면 거부합니다. 따라서 **판정 가능**합니다.

## 2. 문맥 자유 문법(CFG) 관련 판정 가능한 문제들

문맥 자유 문법(CFG)으로 넘어오면 문제가 조금 더 까다로워집니다.

### A. CFG 수락 문제 ($A_{\text{CFG}}$)
$$A_{\text{CFG}} = \{ \langle G, w \rangle \mid G\text{는 CFG이고, } w \in L(G) \}$$
- **문제점**: 규칙에 따라 치환을 무작정 돌리다 보면 $S \to S$나 $S \to \epsilon$ 같은 규칙 때문에 깊이 우선 탐색 시 영원히 루프를 돌 수 있습니다.
- **해결책 (Chomsky 정규형, CNF)**: 모든 규칙이 $A \to BC$ (두 개의 변수) 또는 $A \to a$ (단일 터미널) 형태로만 이루어지도록 문법 $G$를 **촘스키 정규형(Chomsky Normal Form)**으로 변환합니다.
- **CNF 성질**: 길이가 $n$인 문자열 $w$를 CNF 문법으로 유도(Derivation)할 때 거쳐야 하는 치환 횟수는 **정확히 $2n - 1$번**으로 고정됩니다.
- **판정 알고리즘**: $2|w| - 1$단계 만에 문자열을 만들어내는 모든 가능한 문법 유도 경로를 유한하게 검사해 봅니다. 존재하면 수락하고 없으면 거부하므로 **판정 가능**합니다.
- **따라서 모든 문맥 자유 언어(CFL)는 튜링 판정 가능(Decidable)합니다.**

### B. CFG 공백성 문제 ($E_{\text{CFG}}$)
$$E_{\text{CFG}} = \{ \langle G \rangle \mid G\text{는 CFG이고, } L(G) = ∅ \}$$
- **판정 알고리즘**: 오토마타와 반대로 **터미널 기호에서부터 역방향으로** 올라오며 마킹하는 방식을 취합니다.
  1. 문법에 등장하는 모든 터미널 문자들에 마크를 표시합니다.
  2. 우변에 있는 모든 문자들($B_1 \dots B_k$)이 마크되어 있는 규칙 $A \to B_1 \dots B_k$가 있다면, 좌변의 변수 $A$에도 마크를 표시합니다. (새롭게 마크되는 변수가 없을 때까지 반복)
  3. 최종적으로 시작 변수 $S$에 마크가 찍히면 이 문법은 터미널 문자열을 만들어낼 수 있는 것이므로 거부하고, 마크가 찍히지 않았다면 수락(언어가 비어 있음)합니다.
- 변수의 개수가 유한하므로 반드시 정지하며, **판정 가능**합니다.

### C. CFG 동치성 문제 ($EQ_{\text{CFG}}$)는 판정 가능한가?
$$EQ_{\text{CFG}} = \{ \langle G, H \rangle \mid G, H\text{는 CFG이고, } L(G) = L(H) \}$$
- **답은 "아니오"입니다.** CFG 동치성 문제는 **판정 불가능(Undecidable)**합니다.
- **이유**: 앞서 DFA 동치성 증명에 썼던 대칭차 방식을 쓸 수 없습니다. **CFL은 교집합($\cap$)과 여집합(Complement)에 대해 닫혀 있지 않기 때문**에 대칭차에 해당하는 문법을 합성해 낼 수 없습니다.

## 3. 튜링 머신 수락 문제와 유니버설 튜링 머신 (UTM)

그렇다면 오토마타 계층 최상단의 **튜링 머신 수락 문제($A_{\text{TM}}$)**는 어떻게 될까요?
$$A_{\text{TM}} = \{ \langle M, w \rangle \mid M\text{은 튜링 머신이고, } M\text{은 } w\text{를 수락한다} \}$$

이 문제는 다음 시간에 다루겠지만 **판정 불가능(Undecidable)**합니다. 입력받은 튜링 머신 $M$이 $w$를 계산하다가 영원히 정지하지 않고 루프를 돌 수 있기 때문입니다.

하지만 이 문제는 **튜링 인식 가능(Turing-Recognizable)**합니다. 이를 보이기 위해 우리는 역사상 최초로 **프로그램을 데이터처럼 입력받아 실행하는 컴퓨터**인 **유니버설 튜링 머신 (UTM, Universal Turing Machine) $U$**를 설계합니다.

### 유니버설 튜링 머신 $U$의 알고리즘
$$U = \text{"인풋 } \langle M, w \rangle \text{에 대해:}$$
1. 테이프 상에 기록된 튜링 머신 $M$의 상태 전이 규칙과 상태 정보를 바탕으로, 실제 $M$이 입력 $w$에 대해 어떻게 작동하는지 그대로 시뮬레이션한다.
2. 시뮬레이션 도중 $M$이 수락 상태에 들어가면 **수락**하고 정지한다.
3. $M$이 거부 상태에 들어가면 **거부**하고 정지한다."

만약 $M$이 $w$에 대해 영원히 루프를 돈다면, 시뮬레이터인 $U$ 역시 영원히 작동하며 멈추지 않습니다. 비록 판정(Decide)은 못 하지만, 수락하는 경우에는 반드시 정지하여 대답하므로 $A_{\text{TM}}$은 **인식 가능**합니다.

유니버설 튜링 머신 $U$는 소프트웨어(코드 $M$)와 데이터(입력 $w$)를 동일한 메모리에 올려두고 실행하는 현대 **폰 노이만 구조 내장 프로그램 컴퓨터(Stored-program Computer)**의 탄생에 결정적인 영감을 주었습니다.

## 요약 및 마치며

- **$A_{\text{DFA}}, A_{\text{NFA}}, E_{\text{DFA}}, EQ_{\text{DFA}}$**는 모두 튜링 머신에 의해 판정 가능합니다. 동치성 판정에는 **대칭차(Symmetric Difference)** 개념이 사용됩니다.
- **$A_{\text{CFG}}$**는 무한 루프 방지를 위해 문법을 **Chomsky 정규형(CNF)**으로 바꾼 뒤, $2|w|-1$단계의 유도 과정을 검사하여 판정합니다. 따라서 모든 CFL은 판정 가능합니다.
- **$E_{\text{CFG}}$**는 터미널 기호에서 시작해 변수로 타고 올라가는 마킹 방식을 통해 판정합니다.
- **$EQ_{\text{CFG}}$**는 CFL의 교집합/여집합 닫힘성 부재로 인해 **판정 불가능(Undecidable)**합니다.
- **유니버설 튜링 머신(UTM)**은 다른 튜링 머신의 코드를 입력받아 모사하는 다목적 계산 모델로, 현대 컴퓨터 구조의 시초가 되었습니다.

우리는 다양한 컴퓨터 파일 포맷(정규 규칙, 프로그래밍 소스 코드 문법 등)을 기계가 안전하게 검사할 수 있음을 이론적으로 규명했습니다. 다음 강의 요약에서는 계산 이론의 가장 충격적인 결과이자, 컴퓨터가 수학적으로 절대 해결할 수 없는 영원한 한계인 **Halting Problem(정지 문제)의 대각선 논법 증명**을 다루겠습니다!
