함수형 프로그래밍 개념을 자율주행·로봇 도메인에 적용하는 시리즈입니다.

## 글 목록

1. **[센서 파이프라인](autonomous-sensor-pipeline/)** — 액션/계산/데이터로 자율주행 센서 파이프라인 설계하기
2. **[상태 기계](autonomous-state-machine/)** — 자율주행 모드 전이를 타입으로 만들기
3. **[경로 계획](autonomous-path-planning/)** — A*를 함수형으로, 불변 데이터로 구현하기
4. **[PID 제어기](autonomous-pid-controller/)** — 상태를 값으로 전달하는 함수형 PID
5. **[센서 퓨전](autonomous-sensor-fusion/)** — GPS·IMU·카메라를 컴포지션과 추상화 장벽으로 합치기
6. **[ROS2 콜백](autonomous-ros2-functional/)** — 메시지를 데이터로, 핸들러를 계산으로
7. **[시뮬레이션 회귀 테스트](autonomous-simulation-regression/)** — 시나리오를 데이터로, 파이프라인을 계산으로
8. **[오도메트리와 SLAM](autonomous-odometry-slam/)** — 위치 추정을 순수 계산으로
9. **[칼만 필터](autonomous-kalman-filter/)** — predict와 update를 순수 함수로
10. **[역기구학](functional-inverse-kinematics/)** — 순수 계산으로 로봇 팔 제어하기
11. **[포인트 클라우드 처리](functional-point-cloud/)** — LiDAR 파이프라인을 순수 계산으로
