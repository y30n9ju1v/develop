---

함수형 프로그래밍의 핵심 개념을 Rust 예제로 설명합니다.

## 읽기 순서

1. **[시리즈 로드맵](functional-programming-roadmap/)** — 전체 시리즈 구성과 읽기 순서
2. **[액션, 계산, 데이터](functional-actions-calculations-data/)** — 코드를 세 가지로 나누면 복잡성이 사라진다
3. **[함수 컴포지션](functional-composition/)** — 함수형 프로그래밍의 심장
4. **[계층형 설계](functional-stratified-design/)** — 어떤 함수가 어떤 함수 위에 쌓여야 하는가
5. **[타임라인 다이어그램](functional-timeline-diagram/)** — 액션의 실행 순서를 추론하는 법
6. **[불변 데이터와 구조적 공유](functional-immutable-data/)** — 데이터를 안전하게 바꾸는 법
7. **[일급 함수와 클로저](functional-first-class-functions/)** — 함수를 값처럼 다루기
8. **[추상화 장벽](functional-abstraction-barrier/)** — 언제 함수로 묶고, 언제 그냥 두는가
9. **[상태 기계](functional-state-machine/)** — enum과 패턴 매칭으로 상태 기계 만들기
10. **[파서 컴비네이터](functional-parser-combinator/)** — 컴포지션 철학의 극적인 응용
11. **[온어니언 아키텍처](functional-onion-architecture/)** — 액션을 바깥으로, 계산을 안으로
12. **[함수형 DI](functional-dependency-injection/)** — 모킹 없이 테스트 가능한 코드 만들기
13. **[모나드와 에러 처리](functional-monad-error-handling/)** — 함수형 에러 처리 패턴
14. **[Iterator 트레잇 구현](rust-iterator-trait/)** — 지연 평가와 컴포지션의 원리
15. **[async/await와 타임라인](rust-async-timeline/)** — 비동기 액션의 순서 문제
