소프트웨어 설계와 프로그래밍 이론에 관한 시리즈입니다.

## 시리즈 목록

- **[함수형 프로그래밍](functional/)** — 액션/계산/데이터, 컴포지션, 계층형 설계, 자율주행·GPU 적용
- **[nanoGPT from Scratch](nanogpt-from-scratch/)** — Karpathy 강의를 따라 PyTorch로 GPT 직접 구현
- **[Lean](lean/)** — Lean 4 교재 시리즈 (함수형 프로그래밍 + 메타프로그래밍)
- **[계산 이론](theory-of-computation/)** — MIT 18.404J Theory of Computation 강의 정리 (유한 오토마타, 정규 언어)
- **[ONNX 모델을 MLIR로 하드웨어에 맞게 최적화하기](onnx-mlir-hardware-optimization/)** — Conv-BatchNorm-Relu 예제로 따라가는 ONNX → MLIR 그래프/루프/벡터 최적화와 GPU·NPU별 코드 생성
- **[컴파일러 (MIT 6.035 기준)](compilers/)** — 작은 언어 하나를 어휘 분석부터 최적화까지 끝까지 컴파일해보는 시리즈, 계산 이론 시리즈의 NFA/DFA 증명과 교차 참조
