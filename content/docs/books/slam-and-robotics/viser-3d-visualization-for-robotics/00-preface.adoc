== 이 책이 하려는 것

카메라 포즈를 추정하고, 포인트클라우드를 재구성하고, 3D Gaussian Splatting으로 장면을 렌더링하는 코드를 짜다 보면 결국 같은 질문에 부딪힙니다 — "숫자는 맞게 나온 것 같은데, 이게 실제로 맞는 모양인가?" `assert np.allclose(...)`로 계산이 맞는지는 검증할 수 있지만, 카메라가 정말 원하는 방향을 보고 있는지, 포인트클라우드가 정말 그럴듯한 형태인지는 눈으로 봐야 압니다. https://github.com/nerfstudio-project/viser[Viser]는 바로 이 문제를 위한 라이브러리입니다 — matplotlib처럼 파이썬 코드 몇 줄로 3D 장면(포인트클라우드, 메시, 카메라 프러스텀, 좌표축)을 만들고, 그 장면이 브라우저에서 돌아가는 웹 뷰어로 바로 나타납니다. 별도의 프론트엔드 코드를 쓸 필요도, 데스크톱 GUI 툴킷을 설치할 필요도 없습니다.

이 책은 `pip install viser`부터 시작해 점 하나를 띄우는 가장 단순한 예제(1장)를 거쳐, 좌표계와 카메라 프러스텀 같은 컴퓨터 비전에 특화된 요소들(2~3장), 메시와 조명(4장), 슬라이더·버튼 같은 GUI 패널로 장면과 상호작용하는 법(5~6장), 대량의 데이터와 3D Gaussian Splatting을 다루는 실전 기법(7~8장), 시간에 따라 변하는 로봇 궤적을 재생하는 법(9장)까지 순서대로 쌓아 올립니다. 마지막 장(10장)에서는 지금까지 배운 요소들을 하나로 묶어 작은 재구성 결과 뷰어 앱을 만듭니다.

== 이 책의 방식: 매 장마다 서버를 띄우고, 장면을 만들고, 확인한다

이 시리즈의 다른 책들이 NumPy 계산을 `assert`로 검증하듯, 이 책의 모든 예제는 실제로 `viser.ViserServer()`를 띄우고 장면을 구성하는 완결된 스크립트입니다. 각 스크립트를 그대로 실행하면 `http://localhost:8080`(또는 지정한 포트)에서 진짜로 돌아가는 3D 뷰어가 뜹니다 — 책에 있는 그림을 보는 게 아니라, 여러분의 컴퓨터에서 직접 마우스로 돌려보고 확대해보는 장면입니다. 코드가 짧으니 "일단 띄워보고, 뭐가 보이는지 확인하고, 왜 그렇게 보이는지 이해하는" 순서로 각 장이 진행됩니다.

== 왜 지금 Viser인가

이 시리즈의 앞선 책들(멀티뷰 기하, 센서 동기화, 3DGS 파이프라인)은 모두 "숫자가 맞다"를 검증하는 데 집중했습니다. 하지만 실무에서 카메라 캘리브레이션이 틀렸는지, 포인트클라우드 정합이 어긋났는지, 궤적 최적화가 발산했는지를 가장 빠르게 알아채는 방법은 결국 3D로 띄워서 보는 것입니다. Viser는 이런 디버깅 루프를 몇 줄의 파이썬 코드로 줄여주는 도구이고, 이 책에서 배우는 프러스텀 시각화(3장)와 Gaussian Splats 시각화(8장)는 각각 link:../../3dgs-autonomous-driving-e2e/multiview-geometry-3d-reconstruction/[멀티뷰 기하 책]과 3DGS 파이프라인 작업에 곧바로 연결됩니다.

== 누구를 위한 책인가

Python 기본 문법과 NumPy 배열을 다뤄본 적이 있다면 충분합니다. 3D 그래픽스나 웹 프로그래밍 배경지식은 전혀 필요하지 않습니다 — Viser는 씬 그래프, 웹소켓 통신, 프런트엔드 렌더링을 모두 라이브러리 뒤로 숨겨주기 때문에, 여러분은 "어떤 물체를 어디에 놓을까"만 파이썬으로 표현하면 됩니다. 로보틱스, SLAM, 3D 재구성처럼 3D 데이터를 다루는 실무자라면 이 책의 예제들을 자신의 파이프라인 디버깅에 바로 재사용할 수 있습니다.
