Viser는 설치부터 단순합니다.

[source,bash]
----
pip install viser
----

이 한 줄이면 준비가 끝납니다 — 별도의 브라우저 확장이나 프런트엔드 빌드 과정이 필요 없습니다.

== 서버를 띄운다는 것의 의미

Viser의 실행 모델은 세 부분으로 나뉩니다: **서버**(파이썬 프로세스 안에서 돌아가는 `ViserServer`), **씬**(서버가 들고 있는 3D 물체들의 상태), **클라이언트**(그 씬을 렌더링해서 보여주는 브라우저 탭). 여러분이 파이썬 코드로 씬에 물체를 추가하면, 서버가 웹소켓을 통해 연결된 모든 클라이언트에 그 변경사항을 실시간으로 밀어 넣습니다.

[source,python]
----
import viser

server = viser.ViserServer()
----

이 두 줄만 실행해도 `http://localhost:8080`에서 뷰어가 뜹니다. 터미널에 찍히는 안내 박스가 접속 주소를 알려줍니다. 브라우저로 그 주소를 열면 빈 3D 공간이 보입니다 — 아직 아무 물체도 추가하지 않았기 때문입니다.

== 씬에 포인트클라우드 추가하기

빈 공간에 무작위 점들을 흩뿌려 보겠습니다.

[source,python]
----
import numpy as np

points = np.random.uniform(-1.0, 1.0, size=(500, 3))
colors = np.random.randint(0, 256, size=(500, 3), dtype=np.uint8)

point_cloud = server.scene.add_point_cloud(
    name="/random_cloud",
    points=points,
    colors=colors,
    point_size=0.02,
)
----

`points`는 `(N, 3)` 형태의 NumPy 배열(각 행이 x, y, z 좌표), `colors`는 `(N, 3)` 형태의 `uint8` 배열(각 행이 R, G, B 값)입니다. `server.scene`이 씬 트리의 진입점이고, `add_point_cloud`처럼 `add_`로 시작하는 메서드들이 씬에 물체를 추가합니다. 이 코드를 실행하는 순간 브라우저에 이미 열려 있는 뷰어에 점들이 즉시 나타납니다 — 새로고침도 필요 없습니다.

== 이름이 곧 씬 트리의 경로다

`name="/random_cloud"`처럼 물체마다 이름을 지정하는데, 이 이름은 파일 시스템 경로처럼 동작하는 **씬 트리**의 위치입니다.

[source,python]
----
print("scene node name:", point_cloud.name)
assert point_cloud.name == "/random_cloud"
assert point_cloud.points.shape == (500, 3)
----

`/robot/camera/frustum`처럼 슬래시로 계층을 표현할 수 있고, 이 계층 구조는 2장에서 다루는 좌표 프레임 중첩의 기반이 됩니다. 같은 이름으로 `add_point_cloud`를 다시 호출하면 새 물체를 추가하는 게 아니라 기존 물체를 갱신합니다 — 그래서 애니메이션이나 실시간 업데이트를 만들 때도 "새 이름을 계속 만들 필요 없이 같은 이름을 재사용하면 된다"는 점이 중요합니다.

== 기본 좌표축 켜기

장면에 아무 기준점이 없으면 점들이 허공에 떠 있는 것처럼 보이기 쉽습니다. 원점과 축 방향을 눈에 보이게 하려면 `world_axes`를 켭니다.

[source,python]
----
server.scene.world_axes.visible = True
----

빨강·초록·파랑 축이 각각 x·y·z 방향을 가리키며 나타납니다. 이후 장에서 카메라나 로봇의 자세를 다룰 때, 이 세계 좌표축이 "그것과 비교했을 때 어느 쪽을 보고 있는가"를 판단하는 기준이 됩니다.

== 서버를 계속 띄워두기

지금까지의 코드는 스크립트가 끝나면 서버도 같이 종료됩니다. 뷰어를 계속 열어두고 싶다면 스크립트 끝에 무한 루프를 둡니다.

[source,python]
----
import time

while True:
    time.sleep(1.0)
----

이 책의 코드 조각들은 자동 검증을 위해 루프 없이 `server.stop()`으로 바로 종료하지만, 직접 실행해서 브라우저로 확인해볼 때는 이 루프를 추가해서 서버가 계속 떠 있게 하세요.

== 요약

* Viser는 서버(파이썬)-씬(상태)-클라이언트(브라우저)의 세 부분으로 동작하며, `pip install viser`만으로 설치가 끝납니다.
* `server.scene.add_point_cloud(name=..., points=..., colors=...)`로 포인트클라우드를 즉시 브라우저에 렌더링할 수 있습니다.
* 물체의 `name`은 씬 트리 안의 경로이고, 같은 이름으로 다시 호출하면 새로 추가하는 대신 기존 물체를 갱신합니다.

다음 장에서는 이 씬 트리 경로 구조를 본격적으로 활용해, 좌표 프레임을 중첩시켜 로봇이나 카메라의 자세를 표현하는 법을 다룹니다.
