'''

`SO(3)` 행렬은 짐벌락이 없고 대수적으로 깔끔하지만, 숫자 `9`개로 자유도 `3`개를 표현하다 보니 저장·보간·최적화에서 다소 무겁습니다. 쿼터니언은 숫자 `4`개(`w, x, y, z`)로 같은 회전을 표현하는 대안으로, 실전 로봇·그래픽스 코드에서 널리 쓰입니다. 이 장에서는 쿼터니언을 직접 구현하고, 회전 행렬과 자유롭게 오갈 수 있다는 것과, 쿼터니언이 갖는 특유의 함정 — **이중 덮개(double cover)** — 를 수치로 확인합니다.

== 단위 쿼터니언으로 회전 표현하기

축-각(axis-angle) 표현 — "축 `v`(단위벡터) 둘레로 각도 `θ`만큼 회전" — 을 쿼터니언 `q = (cos(θ/2), sin(θ/2)·v)`로 인코딩합니다.

[source,python]
----
import numpy as np

def axis_angle_to_quat(axis, angle):
    axis = axis / np.linalg.norm(axis)
    return np.array([np.cos(angle / 2), *(np.sin(angle / 2) * axis)])

q = axis_angle_to_quat(np.array([0.0, 0.0, 1.0]), 0.7)
print(q, np.linalg.norm(q))
----

[source]
----
[0.9394... 0.     0.     0.3271...] 1.0
----

각도를 `2`로 나눠서 넣는 것이 처음엔 어색해 보이지만(왜 `θ`가 아니라 `θ/2`인가는 이 장 끝에서 이중 덮개와 함께 설명합니다), 노름이 정확히 `1`인 단위 쿼터니언이 나옵니다 — 회전을 나타내는 쿼터니언은 항상 단위 쿼터니언이어야 합니다.

== 쿼터니언 곱셈과 회전 합성

쿼터니언 곱셈(해밀턴 곱)은 벡터 내적·외적을 섞은 형태로 정의됩니다.

[source,python]
----
def quat_mult(q1, q2):
    w1, x1, y1, z1 = q1
    w2, x2, y2, z2 = q2
    return np.array([
        w1 * w2 - x1 * x2 - y1 * y2 - z1 * z2,
        w1 * x2 + x1 * w2 + y1 * z2 - z1 * y2,
        w1 * y2 - x1 * z2 + y1 * w2 + z1 * x2,
        w1 * z2 + x1 * y2 - y1 * x2 + z1 * w2,
    ])
----

회전 행렬의 합성이 행렬 곱셈이었던 것처럼, 쿼터니언의 합성도 이 곱셈 하나로 이루어집니다. `q1`을 먼저 적용하고 그다음 `q2`를 적용하는 것은 `q2 * q1`(순서 주의!)로 표현합니다.

[source,python]
----
def Rz(a):
    c, s = np.cos(a), np.sin(a)
    return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1]])

def Rx(a):
    c, s = np.cos(a), np.sin(a)
    return np.array([[1, 0, 0], [0, c, -s], [0, s, c]])

q1 = axis_angle_to_quat(np.array([1.0, 0.0, 0.0]), 0.3)
q2 = axis_angle_to_quat(np.array([0.0, 0.0, 1.0]), 0.5)
q_composed = quat_mult(q2, q1)
print(quat_mult(q1, q2) - quat_mult(q2, q1))
----

[source]
----
[0.        0.        0.        0.05...]
----

`quat_mult(q1, q2)`와 `quat_mult(q2, q1)`이 다릅니다 — 쿼터니언 곱셈도 `SO(3)`의 행렬 곱셈과 마찬가지로 교환법칙이 성립하지 않습니다. 회전을 합성하는 순서가 중요하다는 사실이 표현을 바꿔도 그대로 남아 있다는 것은, 이것이 특정 표현의 우연이 아니라 회전이라는 대상 자체의 본질적인 성질(비가환성)이라는 걸 보여줍니다.

== 쿼터니언 ↔ 회전 행렬 변환

쿼터니언을 `3x3` 회전 행렬로 바꾸는 표준 공식을 구현하고, 2장의 `Rz`와 결과가 일치하는지 확인합니다.

[source,python]
----
def quat_to_R(q):
    w, x, y, z = q / np.linalg.norm(q)
    return np.array([
        [1 - 2 * (y * y + z * z), 2 * (x * y - z * w), 2 * (x * z + y * w)],
        [2 * (x * y + z * w), 1 - 2 * (x * x + z * z), 2 * (y * z - x * w)],
        [2 * (x * z - y * w), 2 * (y * z + x * w), 1 - 2 * (x * x + y * y)],
    ])

q = axis_angle_to_quat(np.array([0.0, 0.0, 1.0]), 0.7)
print(np.allclose(quat_to_R(q), Rz(0.7)))

R1, R2 = quat_to_R(q1), quat_to_R(q2)
print(np.allclose(quat_to_R(q_composed), R2 @ R1))
----

[source]
----
True
True
----

`z`축 `0.7`라디안 회전을 쿼터니언으로 인코딩한 뒤 행렬로 되돌리니 `Rz(0.7)`과 정확히 일치하고, 쿼터니언 곱셈으로 합성한 결과를 행렬로 바꾼 것이 각각을 행렬로 바꿔 곱한 것(`R2 @ R1`)과도 정확히 일치합니다 — 쿼터니언과 회전 행렬이 (지금까지는) 그냥 같은 회전을 표현하는 두 가지 다른 "언어"일 뿐이라는 걸 확인했습니다.

== 이중 덮개: q와 -q는 같은 회전이다

쿼터니언 표현에는 회전 행렬에는 없는 함정이 하나 있습니다 — `q`와 `-q`(모든 성분의 부호를 뒤집은 것)가 **똑같은 회전**을 나타냅니다.

[source,python]
----
q = axis_angle_to_quat(np.array([0.0, 0.0, 1.0]), 0.7)
print(np.allclose(quat_to_R(q), quat_to_R(-q)))
print(q)
print(-q)
----

[source]
----
True
[0.9394... 0.     0.     0.3271...]
[-0.9394... -0.     -0.     -0.3271...]
----

정반대 부호를 가진 두 쿼터니언이 회전 행렬로 바꾸면 완전히 같은 행렬이 됩니다. 이것이 앞서 각도를 `θ/2`로 나눠 넣은 이유와 직접 연결됩니다 — `θ`만큼 회전한 쿼터니언과 `θ + 360도`만큼 회전한 쿼터니언은 서로 다른 벡터(`q`와 `-q`)이지만, 실제 3D 공간에서는 `360도`를 한 바퀴 더 돈 것뿐이라 똑같은 자세입니다. 단위 쿼터니언의 집합(4차원 구, `S^3`)이 `SO(3)`을 "두 겹으로" 덮고 있다고 해서 이 성질을 이중 덮개라고 부릅니다.

=== 왜 문제가 되는가: 평균과 보간에서 부호가 꼬인다

이중 덮개 자체는 회전 하나를 표현하고 적용하는 데는 문제가 없습니다. 문제는 **여러 쿼터니언을 평균 내거나 보간할 때** 생깁니다. 두 쿼터니언이 사실 "가까운 회전"인데 부호가 서로 다르게 저장돼 있으면, 단순 평균이 완전히 엉뚱한 회전을 만듭니다.

[source,python]
----
q_a = axis_angle_to_quat(np.array([0.0, 0.0, 1.0]), 0.1)
q_b = -axis_angle_to_quat(np.array([0.0, 0.0, 1.0]), 0.12)  # 거의 같은 회전인데 부호가 반대

naive_avg = (q_a + q_b)
naive_avg /= np.linalg.norm(naive_avg)
print("naive average matrix:\n", np.round(quat_to_R(naive_avg), 3))

q_b_fixed = -q_b if np.dot(q_a, q_b) < 0 else q_b   # 부호를 맞춰준 뒤 평균
fixed_avg = (q_a + q_b_fixed)
fixed_avg /= np.linalg.norm(fixed_avg)
print("fixed average matrix:\n", np.round(quat_to_R(fixed_avg), 3))
print("fixed average close to Rz(0.11):", np.allclose(quat_to_R(fixed_avg), Rz(0.11), atol=1e-2))
----

`q_a`(`0.1`라디안 회전)와 `q_b`(`-0.12`라디안 회전을 나타내지만 부호가 뒤집혀 저장됨)는 실제로는 거의 같은 방향의 작은 회전인데, 부호를 맞추지 않고 그냥 더하면 두 벡터가 거의 반대 방향을 향하고 있어 평균이 거의 `0`에 가까운, 방향이 불안정한 쿼터니언이 나옵니다. 내적(`dot product`)의 부호로 두 쿼터니언이 "같은 반구"에 있는지 확인하고 필요하면 부호를 뒤집어준 뒤에야, 평균이 우리가 기대하는 `0.11`라디안 근처 회전이 됩니다. 이 "부호 맞추기"는 쿼터니언을 다루는 실전 코드(포즈 그래프 최적화, IMU 프리인테그레이션, 파티클 필터의 쿼터니언 평균)에서 반드시 필요한 관례이고, 잊어버리면 드물게 발생하는 미묘한 버그의 흔한 원인이 됩니다.

== SO(3) 대신 SU(2): 다음 장으로 가는 다리

이중 덮개는 사실 쿼터니언만의 특이한 결함이 아니라, 단위 쿼터니언이 이루는 군(`SU(2)`라고 부릅니다)과 `SO(3)`의 관계 그 자체입니다 — `SU(2)`가 `SO(3)`을 2:1로 덮는다는 것은 표현을 아무리 잘 짜도 없앨 수 없는 위상수학적 사실입니다. 회전 행렬(`SO(3)`)은 이 문제가 없지만 자유도 `3`에 비해 원소가 `9`개로 과잉이고, 쿼터니언(`SU(2)`)은 딱 필요한 만큼 압축돼 있지만 이중 덮개라는 대가를 치릅니다.

두 표현 모두 짐벌락은 없다는 공통점이 있습니다 — 그리고 두 표현 모두 "군"이라는 대수 구조를 갖고 있다는 것도 확인했습니다. 다음 장에서는 이 공통점을 정면으로 다뤄, `SO(3)`과 `SU(2)`처럼 군이면서 동시에 매끄러운 공간(다양체)인 대상들을 통틀어 **리 군**이라고 부르고, 그 각 점에서 정의되는 접평면인 **리 대수**를 도입합니다. 리 대수 위에서는 이중 덮개 같은 문제 없이, 회전에 노이즈를 더하고 최적화 변수로 다루는 방법이 자연스럽게 정의됩니다.

== 직접 해보기

* `q`와 `-q`가 같은 회전 행렬을 만든다는 것을 이용해, 축-각으로 `θ = 2π - 0.7`(즉 `0.7`라디안을 반대 방향으로 거의 한 바퀴 돈 것과 같은 각도)을 넣은 쿼터니언이 `axis_angle_to_quat(axis, -0.7)`과 부호만 다른(또는 같은) 쿼터니언이 되는지 확인해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
axis = np.array([0.0, 0.0, 1.0])
q_long_way = axis_angle_to_quat(axis, 2 * np.pi - 0.7)
q_short_way = axis_angle_to_quat(axis, -0.7)
print(np.allclose(q_long_way, q_short_way))
print(np.allclose(quat_to_R(q_long_way), quat_to_R(q_short_way)))
----

[source]
----
True
True
----

`2π - 0.7`만큼(긴 길로) 돈 것과 `-0.7`만큼(짧은 길로) 돈 것이 쿼터니언 벡터 자체가 거의 같게 나옵니다(`cos`, `sin`의 반각 공식이 `2π`를 자연스럽게 처리하기 때문입니다). 회전 행렬도 당연히 같습니다. 이 경우엔 이중 덮개의 부호 문제가 직접 드러나지 않았지만, 두 회전이 기하학적으로 완전히 같은 자세라는 것과, 쿼터니언의 각도가 실제로는 `mod 4π`로 순환한다는 것(한 바퀴가 아니라 두 바퀴를 돌아야 원래 부호로 돌아온다는 것)을 함께 보여줍니다.

== 요약

* 단위 쿼터니언 `q = (cos(θ/2), sin(θ/2)·v)`는 회전을 숫자 `4`개로 표현하며, 쿼터니언 곱셈이 회전 행렬의 곱셈과 정확히 대응하는 합성 연산을 제공합니다(비가환성도 그대로 유지됩니다).
* 쿼터니언과 회전 행렬 사이의 변환 공식을 구현해, 두 표현이 같은 회전에 대해 항상 일치하는 결과를 준다는 것을 확인했습니다.
* 쿼터니언은 `q`와 `-q`가 같은 회전을 나타내는 이중 덮개 문제를 갖고 있으며, 이는 여러 쿼터니언을 평균/보간할 때 부호를 맞춰야 한다는 실전적인 함정으로 이어집니다.
* 회전 행렬(`SO(3)`)과 쿼터니언(`SU(2)`)은 모두 군이자 매끄러운 공간이라는 공통점을 갖고 있으며, 다음 장에서는 이 공통점을 리 군이라는 이름으로 정식화합니다.
