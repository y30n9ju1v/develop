오일러각의 짐벌락 문제에서 시작해 회전 행렬·쿼터니언(1부) → 리 군과 리 대수, 지수/로그 사상(2부) → SE(3)와 강체 운동(3부) → 접평면 위의 최적화와 포즈 그래프(4부) → IMU와 3D SLAM 실전 적용(5부)까지, `SO(3)`·`SE(3)`을 NumPy/SciPy로 직접 구현하고 수치로 검증하며 배우는 심화 입문서입니다.

이 책은 2권 "모르는 곳에서 나를 찾는 법"이 2D 평면에 한정하며 남겨둔 3D 회전 문제를 정면으로 다루는 심화편이자, 독립적으로 읽을 수 있는 책입니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
