일반적인 최적화(경사하강법, 가우스-뉴턴)는 변수를 `x ← x - lr · ∇f`처럼 **더하고 빼는** 연산으로 갱신합니다. 그런데 `SO(3)`의 원소는 더할 수 없습니다(2장에서 확인했듯 두 회전 행렬을 그냥 더하면 결과가 `SO(3)`을 벗어납니다). 이 장에서는 5~9장에서 만든 지수/로그 사상을 이용해, "회전에 접평면 벡터를 더한다"(`⊞`)와 "두 회전의 차이를 접평면 벡터로 잰다"(`⊟`)는 연산을 정의하고, 이것으로 실제 최적화 루프를 돌립니다.

== ⊞(boxplus): 회전에 리 대수 벡터를 "더하기"

`R ⊞ δ`는 회전 `R`에 리 대수 벡터 `δ`(작은 회전 증분)를 지수 사상으로 반영해 새로운 회전을 만드는 연산입니다.

[source,python]
----
import numpy as np

def skew(w):
    return np.array([[0, -w[2], w[1]], [w[2], 0, -w[0]], [-w[1], w[0], 0]])

def exp_so3(w):
    theta = np.linalg.norm(w)
    if theta < 1e-8:
        return np.eye(3) + skew(w)
    axis = w / theta
    K = skew(axis)
    return np.eye(3) + np.sin(theta) * K + (1 - np.cos(theta)) * (K @ K)

def log_so3(R):
    cos_theta = np.clip((np.trace(R) - 1) / 2, -1, 1)
    theta = np.arccos(cos_theta)
    if theta < 1e-8:
        return np.array([R[2, 1] - R[1, 2], R[0, 2] - R[2, 0], R[1, 0] - R[0, 1]]) / 2
    w_hat = (R - R.T) / (2 * np.sin(theta))
    w_axis = np.array([w_hat[2, 1], w_hat[0, 2], w_hat[1, 0]])
    return w_axis * theta

def boxplus(R, delta):
    return R @ exp_so3(delta)
----

`R ⊞ δ`가 항상 정확히 `SO(3)`에 속한다는 것은 5장에서 이미 확인했습니다(`exp_so3`의 출력이 항상 `SO(3)`이고, `SO(3)`은 곱셈에 닫혀 있으니까요). 이게 오일러각 같은 표현에 `+`를 그냥 적용하는 것과 근본적으로 다른 점입니다 — `⊞`는 **항상 다양체 위에 머무르는** 덧셈입니다(이런 연산을 수학에서는 "리트랙션(retraction)"이라고 부릅니다).

== ⊟(boxminus): 두 회전의 "차이"를 리 대수 벡터로

반대로 `R1 ⊟ R2`는 "`R2`에 어떤 `δ`를 `⊞`해야 `R1`이 되는가"를 답으로 돌려주는 연산입니다.

[source,python]
----
def boxminus(R1, R2):
    return log_so3(R2.T @ R1)
----

=== ⊞와 ⊟가 서로 정확한 역관계인지 검증

[source,python]
----
def random_so3(rng):
    A = rng.standard_normal((3, 3))
    Q, R = np.linalg.qr(A)
    Q = Q @ np.diag(np.sign(np.diag(R)))
    if np.linalg.det(Q) < 0:
        Q[:, 0] *= -1
    return Q

rng = np.random.default_rng(5)
R = random_so3(rng)
R2 = random_so3(rng)

delta = boxminus(R2, R)              # "R에 얼마를 더해야 R2가 되는가"
R_reconstructed = boxplus(R, delta)  # R ⊞ (R2 ⊟ R) == R2 여야 한다
print(np.allclose(R_reconstructed, R2))
----

[source]
----
True
----

`R ⊞ (R2 ⊟ R) = R2`가 정확히 성립합니다 — `⊞`와 `⊟`가 일반적인 덧셈·뺄셈이 만족하는 관계(`x + (y - x) = y`)를 `SO(3)` 위에서 그대로 재현한다는 뜻입니다. 이제 이 두 연산으로 "일반적인 벡터 공간에서 하듯" 최적화를 할 수 있습니다.

== 실전: 경사하강법으로 목표 회전에 수렴하기

목표는 무작위 초기 회전 `R`을 목표 회전 `R_target`에 맞추는 것입니다. 오차를 `e = R_target ⊟ R`(현재 `R`에서 목표까지 필요한 리 대수 벡터)로 정의하고, `R`을 그 방향으로 `⊞`시켜 갱신합니다.

[source,python]
----
R_target = random_so3(rng)
R = random_so3(rng)

lr = 0.5
errors = []
for step in range(20):
    e = boxminus(R_target, R)     # 현재 R에서 목표까지 필요한 리 대수 벡터
    errors.append(np.linalg.norm(e))
    R = boxplus(R, lr * e)        # R ← R ⊞ (lr * e)

print([round(x, 4) for x in errors[:6]])
print([round(x, 8) for x in errors[-3:]])
print(np.allclose(R, R_target, atol=1e-6))
----

----

[1.4e-05, 7.1e-06, 3.6e-06]

----

오차의 노름이 매 스텝마다 정확히 절반(`lr=0.5`)씩 줄어들면서 `20`스텝 만에 `R`이 `R_target`과 사실상 같아졌습니다(`10⁻⁶` 이내). 짐벌락도, 정규직교성 붕괴도 없이 — 매 스텝 `boxplus`가 반환하는 `R`은 항상 정의상 정확한 `SO(3)` 원소이기 때문입니다. 이것이 오일러각으로 같은 최적화를 시도했다면 1장에서 봤던 특이점 문제에 걸릴 수 있는 것과 대조됩니다.

== 이 연산이 최적화 알고리즘 전체로 일반화되는 이유

방금 한 것은 사실상 "학습률이 고정된 경사하강법"입니다. `f(R) = 0.5 |R_target ⊟ R|²`이라는 목적함수를 최소화하는 문제로 보면, `e = R_target ⊟ R`이 (부호를 조정하면) 이 목적함수의 그래디언트와 정확히 비례하고, `boxplus`가 "그래디언트 방향으로 한 걸음 내딛는" 리트랙션 역할을 합니다. 11장에서 다룰 야코비안, 12장의 포즈 그래프 최적화(가우스-뉴턴/레벤버그-마쿼트)도 전부 이 `⊞`/`⊟` 패턴 위에 세워집니다 — 유클리드 공간의 최적화 알고리즘을, 변수가 `SO(3)`(또는 `SE(3)`)에 살고 있다는 것만 빼면 거의 그대로 재사용할 수 있게 해주는 게 이 두 연산의 핵심 가치입니다.

== 직접 해보기

* 학습률 `lr`을 `0.5`가 아니라 `1.0`으로 바꾸면 몇 스텝 만에 수렴하는지 확인하고, 왜 `1.0`이 이 특정 목적함수에서는 "한 번에 정확히 도달하는" 이상적인 학습률인지 `boxplus`/`boxminus`의 정의로 설명해보세요.

== 요약

* `R ⊞ δ = R @ exp(δ)`는 회전에 리 대수 벡터를 더하되 결과가 항상 정확히 `SO(3)`에 머무르게 하는 리트랙션이고, `R1 ⊟ R2 = log(R2^T R1)`은 그 역방향으로 두 회전의 차이를 리 대수 벡터로 재는 연산입니다.
* `R ⊞ (R2 ⊟ R) = R2`라는 항등식으로 두 연산이 일반적인 덧셈·뺄셈의 역관계를 정확히 재현한다는 것을 확인했습니다.
* 오차 `e = R_target ⊟ R`을 이용한 경사하강법(`R ← R ⊞ (lr · e)`)으로 무작위 회전을 목표 회전에 짐벌락이나 정규직교성 붕괴 없이 수렴시켰습니다.
* 이 `⊞`/`⊟` 패턴이 이후 야코비안 계산과 포즈 그래프 최적화(가우스-뉴턴) 전체의 기초가 됩니다.
* 다음 장에서는 이 접평면 위에서 야코비안을 계산할 때 왼쪽 섭동과 오른쪽 섭동 중 어느 쪽을 쓰느냐에 따라 야코비안의 형태가 달라진다는 것을 다룹니다.
