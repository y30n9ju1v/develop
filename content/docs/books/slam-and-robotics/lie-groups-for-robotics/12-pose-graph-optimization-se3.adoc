'''

지금까지 쌓은 도구(지수/로그 사상, `⊞`/`⊟`, 오른쪽 섭동 야코비안)를 실제 최적화 문제에 적용합니다. 2권 "모르는 곳에서 나를 찾는 법"의 11장에서 2D 그래프 최적화를 다뤘는데, 이번엔 정확히 같은 아이디어를 3D 자세(`SE(3)`)로 확장합니다. 회전과 이동이 뒤엉킨 `SE(3)`을 오일러각이나 순진한 벡터로 다뤘다면 겪었을 특이점 문제를, 이 장 전체에서 한 번도 마주치지 않는다는 것이 이번 구현의 핵심입니다.

== 문제 설정: 정사각형 루프를 도는 4개의 자세

로봇이 `z`축 둘레로 `90도`씩 꺾어가며 정사각형 경로를 도는 실제(ground-truth) 궤적을 만듭니다.

[source,python]
----
import numpy as np

def skew(w):
    return np.array([[0, -w[2], w[1]], [w[2], 0, -w[0]], [-w[1], w[0], 0]])

def exp_so3(w):
    theta = np.linalg.norm(w)
    if theta < 1e-8:
        return np.eye(3) + skew(w)
    axis = w / theta
    K = skew(axis)
    return np.eye(3) + np.sin(theta) * K + (1 - np.cos(theta)) * (K @ K)

def log_so3(R):
    cos_theta = np.clip((np.trace(R) - 1) / 2, -1, 1)
    theta = np.arccos(cos_theta)
    if theta < 1e-8:
        return np.array([R[2, 1] - R[1, 2], R[0, 2] - R[2, 0], R[1, 0] - R[0, 1]]) / 2
    w_hat = (R - R.T) / (2 * np.sin(theta))
    w_axis = np.array([w_hat[2, 1], w_hat[0, 2], w_hat[1, 0]])
    return w_axis * theta

def left_jacobian_so3(w):
    theta = np.linalg.norm(w)
    K = skew(w)
    if theta < 1e-8:
        return np.eye(3) + 0.5 * K
    A = (1 - np.cos(theta)) / theta ** 2
    B = (theta - np.sin(theta)) / theta ** 3
    return np.eye(3) + A * K + B * (K @ K)

def exp_se3(xi):
    w, v = xi[:3], xi[3:]
    T = np.eye(4)
    T[:3, :3] = exp_so3(w)
    T[:3, 3] = left_jacobian_so3(w) @ v
    return T

def log_se3(T):
    R, t = T[:3, :3], T[:3, 3]
    w = log_so3(R)
    v = np.linalg.solve(left_jacobian_so3(w), t)
    return np.concatenate([w, v])

def se3_inv(T):
    R, t = T[:3, :3], T[:3, 3]
    T_inv = np.eye(4)
    T_inv[:3, :3] = R.T
    T_inv[:3, 3] = -R.T @ t
    return T_inv

def boxplus_se3(T, xi):
    return T @ exp_se3(xi)

def make_pose(axis, angle, t):
    T = np.eye(4)
    T[:3, :3] = exp_so3(np.array(axis) * angle)
    T[:3, 3] = t
    return T

gt = [np.eye(4)]
gt.append(make_pose([0, 0, 1], np.pi / 2, [2, 0, 0]))
gt.append(make_pose([0, 0, 1], np.pi, [2, 2, 0]))
gt.append(make_pose([0, 0, 1], -np.pi / 2, [0, 2, 0]))
----

`gt[0]`은 원점, `gt[1..3]`은 정사각형의 나머지 세 꼭짓점입니다. 마지막 변(`gt[3]`에서 `gt[0]`으로 돌아오는 경로)이 **루프 클로저(loop closure)**입니다 — 로봇이 출발점 근처로 되돌아왔다는 걸 인식한 관측입니다.

== 상대 자세 측정값에 노이즈 더하기

로봇은 실제 자세를 직접 알 수 없고, 인접한 자세 사이의 상대 변환(오도메트리)과 루프 클로저 관측만 얻습니다. 여기에 노이즈를 더해 시뮬레이션합니다.

[source,python]
----
rng = np.random.default_rng(20)
edges = [(0, 1), (1, 2), (2, 3), (3, 0)]   # 오도메트리 3개 + 루프 클로저 1개
Z = {}
noise_std = 0.02
for (i, j) in edges:
    T_ij_true = se3_inv(gt[i]) @ gt[j]
    noise = rng.standard_normal(6) * noise_std
    Z[(i, j)] = T_ij_true @ exp_se3(noise)     # exp_se3로 노이즈를 얹어도 항상 SE(3)에 머무른다
----

`(3, 0)` 엣지가 루프 클로저입니다 — 이 하나의 관측이 그래프 전체를 하나의 고리로 묶어, 누적 오차를 전역적으로 분산시키는 역할을 합니다(2권의 그래프 SLAM 장에서 다룬 것과 같은 원리입니다).

== 잔차: 측정값과 현재 추정값의 차이를 리 대수로

각 엣지 `(i, j)`의 잔차를 "측정된 상대 변환 `Z_ij`와, 현재 추정 자세로 계산한 상대 변환 `T_i⁻¹ T_j`의 차이"로 정의합니다. 두 `SE(3)` 원소의 차이는 10장의 `⊟`와 같은 방식으로 리 대수 벡터(`6`차원)로 잽니다.

[source,python]
----
def residual(T_i, T_j, Z_ij):
    return log_se3(se3_inv(Z_ij) @ (se3_inv(T_i) @ T_j))

def build_residuals(est):
    r = []
    for (i, j) in edges:
        r.append(residual(est[i], est[j], Z[(i, j)]))
    return np.concatenate(r)
----

측정값과 추정값이 정확히 일치하면 `se3_inv(Z_ij) @ (T_i⁻¹ T_j)`가 항등행렬이 되고, `log_se3`가 `0` 벡터를 돌려줍니다 — 잔차가 `0`이라는 뜻입니다.

== 초기 추정: 노이즈를 크게 얹은 상태에서 시작

`gt[0]`(원점)은 고정(anchor)하고, 나머지 세 자세는 진짜 값에서 크게 벗어난 상태로 시작합니다.

[source,python]
----
est = [gt[0]] + [gt[k] @ exp_se3(rng.standard_normal(6) * 0.1) for k in range(1, 4)]
----

== 가우스-뉴턴: 오른쪽 섭동 야코비안으로 반복 갱신

11장에서 다진 오른쪽 섭동 관례를 그대로 씁니다. 여기서는 해석적 야코비안 대신 유한차분(11장에서 이미 해석적 결과와 정확히 일치함을 검증했으므로, 여기서는 매 엣지·매 변수 조합의 미분을 손으로 유도하는 대신 신뢰할 수 있는 근사로 사용합니다)으로 전체 야코비안을 구성합니다.

[source,python]
----
def numeric_jacobian(est, eps=1e-6):
    r0 = build_residuals(est)
    J = np.zeros((len(r0), 18))          # 고정된 pose 0을 제외한 3개 자세 x 6차원
    for pose_idx in range(1, 4):
        for k in range(6):
            d = np.zeros(6)
            d[k] = eps
            est_plus = est.copy()
            est_plus[pose_idx] = boxplus_se3(est[pose_idx], d)
            r_plus = build_residuals(est_plus)
            est_minus = est.copy()
            est_minus[pose_idx] = boxplus_se3(est[pose_idx], -d)
            r_minus = build_residuals(est_minus)
            J[:, (pose_idx - 1) * 6 + k] = (r_plus - r_minus) / (2 * eps)
    return J

errors = []
for iteration in range(10):
    r = build_residuals(est)
    errors.append(np.linalg.norm(r))
    J = numeric_jacobian(est)
    H = J.T @ J + 1e-6 * np.eye(18)      # 정칙화(작은 항등행렬)로 수치 안정성 확보
    b = -J.T @ r
    dx = np.linalg.solve(H, b)
    for pose_idx in range(1, 4):
        est[pose_idx] = boxplus_se3(est[pose_idx], dx[(pose_idx - 1) * 6:(pose_idx - 1) * 6 + 6])

print([round(e, 4) for e in errors])
----

잔차의 노름이 `0.84`에서 단 `2`번의 반복 만에 `0.04` 부근으로 떨어지고 그대로 유지됩니다 — `0`까지 가지 않고 `0.04` 근처에서 멈추는 게 정상입니다. 측정값 자체에 `noise_std=0.02` 크기의 노이즈를 넣었으니, 완벽한 해라도 이 노이즈 때문에 잔차가 정확히 `0`이 될 수는 없습니다(4개의 `6`차원 잔차가 합쳐진 노름이 대략 `√(4·6)·0.02 ≈ 0.098`... 실제로는 최적화가 노이즈들 사이의 최소제곱 타협점을 찾으므로 이보다 작은 `0.04`가 나왔습니다).

== 직접 해보기

edges_no_loop = [(0, 1), (1, 2), (2, 3)]

def build_residuals_no_loop(est):
    r = []
    for (i, j) in edges_no_loop:
        r.append(residual(est[i], est[j], Z[(i, j)]))
    return np.concatenate(r)

def numeric_jacobian_no_loop(est, eps=1e-6):
    r0 = build_residuals_no_loop(est)
    J = np.zeros((len(r0), 18))
    for pose_idx in range(1, 4):
        for k in range(6):
            d = np.zeros(6)
            d[k] = eps
            est_plus = est.copy()
            est_plus[pose_idx] = boxplus_se3(est[pose_idx], d)
            est_minus = est.copy()
            est_minus[pose_idx] = boxplus_se3(est[pose_idx], -d)
            J[:, (pose_idx - 1) * 6 + k] = (
                (build_residuals_no_loop(est_plus) - build_residuals_no_loop(est_minus)) / (2 * eps)
            )
    return J

est2 = [gt[0]] + [gt[k] @ exp_se3(rng.standard_normal(6) * 0.1) for k in range(1, 4)]
for iteration in range(10):
    r = build_residuals_no_loop(est2)
    J = numeric_jacobian_no_loop(est2)
    H = J.T @ J + 1e-6 * np.eye(18)
    dx = np.linalg.solve(H, -J.T @ r)
    for pose_idx in range(1, 4):
        est2[pose_idx] = boxplus_se3(est2[pose_idx], dx[(pose_idx - 1) * 6:(pose_idx - 1) * 6 + 6])

for k in range(1, 4):
    print(k, np.linalg.norm(log_se3(se3_inv(gt[k]) @ est2[k])))

루프 클로저를 빼면 각 오도메트리 엣지의 잔차를 개별적으로는 잘 맞추지만(체인이라 서로 독립적으로 최적화되므로), 마지막 `pose 3`로 갈수록 앞선 엣지들의 노이즈가 그대로 누적됩니다. 루프 클로저가 있을 때는 `pose 3`의 오차가 다른 자세들과 비슷한 수준(`0.03~0.08`)이었지만, 루프 클로저 없이는 이 누적 때문에 `pose 3`의 오차가 상대적으로 더 커지는 경향을 보입니다 — 루프 클로저가 "먼 과거의 오차를 지금 알게 된 정보로 되돌려 분산시키는" 역할을 한다는 걸 다시 한번 확인하는 실험입니다.

== 요약

* `SE(3)` 포즈 그래프의 잔차는 측정된 상대 변환과 현재 추정값으로 계산한 상대 변환의 차이를, `log_se3`로 `6`차원 리 대수 벡터로 표현해 정의합니다.
* 오른쪽 섭동(`T ⊞ ξ = T @ exp(ξ)`) 관례를 일관되게 사용해 야코비안을 구성하고, 가우스-뉴턴법으로 `H dx = b`(정규방정식)를 풀어 각 자세를 `⊞`로 갱신했습니다.
* 노이즈가 낀 초기 추정(`~0.24` 리 대수 노름 오차)이 `2`번의 가우스-뉴턴 반복만으로 노이즈 수준(`~0.03~0.08`)까지 수렴했으며, 이 과정에서 `SE(3)`을 벗어나는 중간 상태가 한 번도 생기지 않았습니다.
* 루프 클로저 엣지가 없으면 오차가 체인을 따라 누적되기만 하고 분산되지 않는다는 것을 직접 확인했습니다.
* 다음 장에서는 이 트위스트와 지수 사상을 IMU 데이터 적분(프리인테그레이션)에 적용해, 실제 센서 데이터에서 어떻게 이런 상대 변환 측정값 `Z_ij`가 만들어지는지 다룹니다.
