'''

EKF는 믿음을 가우시안(평균 하나, 공분산 하나) 하나로만 표현합니다 — 즉 "여기 아니면 저기, 둘 중 하나일 가능성이 비슷하게 있다"는 상황을 표현할 방법이 없습니다. 파티클 필터는 이 제약을 완전히 버립니다. 믿음을 수천 개의 가상 "가설"(파티클) 각각에 위치와 가중치를 매겨 표현하고, 그 파티클들의 분포 자체가 믿음이 됩니다 — 봉우리가 몇 개든, 모양이 어떻든 상관없습니다.

== 왜 다봉(multimodal) 분포가 필요한가

로봇이 좌우 대칭인 환경(예: 랜드마크가 정확히 로봇 정면 축 위에 하나만 있는 복도)에 있다고 합시다. 이 랜드마크까지의 거리와 방위각만으로는, 로봇이 랜드마크의 "오른쪽"에 있는지 "왼쪽"에 있는지(거울 대칭인 두 위치) 구별할 수 없습니다 — 두 가설 모두 관측과 완벽하게 들어맞습니다. 가우시안 하나로는 이 "두 개의 뚜렷이 분리된 가능성"을 표현할 수 없지만(가우시안을 억지로 두 봉우리 사이에 끼워 넣으면, 실제로는 있을 법하지 않은 "중간" 위치가 가장 그럴듯하다고 잘못 말하게 됩니다), 파티클 집합은 절반은 오른쪽에, 절반은 왼쪽에 그대로 둘 수 있습니다.

== 파티클로 믿음 표현하기

[source,python]
----
N = 2000
particles = np.zeros((N, 3))   # 각 파티클: [x, y, theta] 가설 하나
half = N // 2
particles[:half, 0] = rng.normal(3.0, 0.5, half)     # 오른쪽 후보
particles[half:, 0] = rng.normal(-3.0, 0.5, N-half)  # 왼쪽(거울상) 후보
weights = np.ones(N) / N        # 처음엔 모든 파티클이 똑같이 그럴듯함
----

`2000`개의 파티클 중 절반은 오른쪽(참값이 있는 쪽) 근처에, 절반은 왼쪽(거울 대칭인 잘못된 가설) 근처에 뿌려둡니다 — 로봇이 자신의 초기 위치를 전혀 모른다고 가정한(전역 위치추정, global localization) 상황을 재현한 것입니다.

== 예측: 모든 파티클을 각자 전파

[source,python]
----
particles = motion_model(particles, u, dt)
particles += rng.normal(0, process_noise_std, size=particles.shape)
----

`2000`개 파티클 전부에 3장의 운동 모델을 동시에 적용하고(넘파이 벡터화로 한 번에), 각각에 독립적인 노이즈를 더합니다 — 1장의 히스토그램 필터가 "칸마다" 확률을 퍼뜨렸던 것과 원리는 같지만, 여기서는 이산적인 칸 대신 연속 공간의 표본으로 그 퍼짐을 표현합니다.

== 갱신: 관측과 얼마나 잘 맞는지로 가중치 매기기

[source,python]
----
z_pred = measurement_model(particles, landmark)   # 모든 파티클 각각의 예상 관측
y = z - z_pred
y[:, 1] = wrap_angle(y[:, 1])
likelihood = gaussian_likelihood(y, R_inv, None)    # 실제 관측과 얼마나 가까운지
weights = weights * likelihood
weights /= weights.sum()
----

각 파티클이 "내가 실제로 그 위치에 있었다면, 방금 나온 관측값이 얼마나 그럴듯했을까"를 계산해서, 그 값에 비례하게 가중치를 올립니다 — 관측과 잘 들어맞는 파티클(어느 쪽이든, 처음엔 오른쪽도 왼쪽도 둘 다 그럴듯합니다)은 가중치가 커지고, 안 맞는 파티클은 가중치가 사그라듭니다.

== 유효 표본 크기(ESS)와 리샘플링

[source,python]
----
def effective_sample_size(weights):
    return 1.0 / np.sum(weights**2)
----

시간이 지나면 대부분의 파티클이 거의 `0`에 가까운 가중치를 갖고, 소수의 파티클만 의미 있는 가중치를 갖게 됩니다 — 이걸 그대로 두면 "사실상 몇 개 안 되는 파티클로만 믿음을 표현하는" 낭비가 생깁니다. 유효 표본 크기(ESS)가 이 낭비를 재는 지표이고, 너무 낮아지면(`ESS < N/2`) **리샘플링**으로 가중치가 높은 파티클 근처에 새 파티클들을 다시 뿌립니다.

[source,python]
----
def systematic_resample(particles, weights):
    N = len(weights)
    positions = (rng.uniform() + np.arange(N)) / N
    cumsum = np.cumsum(weights)
    idx = np.searchsorted(cumsum, positions)
    return particles[idx].copy(), np.ones(N) / N
----

체계적 리샘플링(systematic resampling)은 가중치 누적분포에서 일정한 간격으로 표본을 뽑는 방법입니다 — 가중치가 높은 파티클은 여러 번 복제되고, 가중치가 거의 `0`인 파티클은 사라집니다. 리샘플링 후에는 모든 파티클의 가중치가 다시 균등(`1/N`)해집니다.

== 실험: 대칭이 실제로 깨지는가

로봇이 정면을 향한 채 직진합니다(`w≈0`) — 직진하면 오른쪽 후보(참값)는 랜드마크에 점점 가까워지고, 왼쪽 후보(거울상)는 점점 멀어집니다. 이 비대칭적인 거리 변화가, 좌우를 구별하는 유일한 단서입니다.

[source,python]
----
mean_x_history = [np.average(particles[:,0], weights=weights)]
for step in range(15):
    # ... 예측 + 갱신 + (필요시) 리샘플링 ...
    mean_x_history.append(np.average(particles[:,0], weights=weights))
----

[source]
----
weighted mean x history:
[0.0, 3.07, 3.16, 3.13, 3.17, 3.18, 3.25, ...]   -- 첫 관측 직후 바로 3 근처로!

ESS history: [2000, 422.7, 1545.4, 1226.7, 738.5, ...]
----

시작할 때 가중 평균이 정확히 `0.0`이었던 이유가 명확합니다 — 오른쪽(`+3` 근처)과 왼쪽(`-3` 근처)에 정확히 절반씩 있으니 평균은 정확히 중간(`0`)이 됩니다(이게 바로 가우시안 하나로는 이 상황을 표현할 수 없다는 걸 보여주는 신호입니다 — "평균이 `0`"이라는 요약이 실제로는 "`0`에 아무도 없다"는 실제 분포를 완전히 잘못 전달합니다). 그런데 **단 한 번의 관측**만으로 가중 평균이 `3.07`로 뛰어올랐습니다 — 직진 한 스텝 만에 오른쪽과 왼쪽 후보의 거리 변화가 갈리기 시작했고, 그 미묘한 차이만으로 필터가 벌써 오른쪽 가설 쪽에 훨씬 큰 가중치를 실은 것입니다.

== 검증: 틀린 가설이 완전히 사라지는가

[source,python]
----
left_mask = particles[:, 0] < 0
left_weight_fraction = weights[left_mask].sum()
print(left_weight_fraction)   # 0.0
----

`15`스텝 뒤, 왼쪽(거울상, 잘못된) 가설에 남은 가중치 총합은 정확히 `0.0`입니다 — 리샘플링을 몇 차례 거치면서, 그쪽 파티클들이 반복적으로 낮은 가중치를 받아 완전히 도태되어 사라진 것입니다. 최종 가중 평균(`3.22`)도 실제 위치(`3.09`)에 근접합니다.

== 파티클 필터의 대가: 계산량

`2000`개의 파티클을 매 스텝 전파하고 가중치를 매기고 리샘플링하는 건, EKF의 "평균과 공분산 행렬 하나만 갱신"하는 것보다 훨씬 많은 계산입니다 — 표현력(다봉 분포까지 다룰 수 있음)을 얻은 대신 계산량을 지불하는 셈입니다. 게다가 상태 차원이 높아질수록(SLAM처럼 로봇 + 수십 개의 랜드마크), 그 넓은 공간을 충분히 촘촘하게 덮으려면 파티클 수가 기하급수적으로 늘어나야 한다는 "차원의 저주" 문제도 있습니다 — 다음 장에서 다룰 FastSLAM은 이 문제를 정면으로 다루는 영리한 분해 방법입니다.

이미 올바른 후보 근처에서 시작했으니, 다봉분포에서 시작했을 때처럼 "틀린 가설을 없애는" 시간이 필요 없습니다 — 첫 관측부터 곧바로 참값 근처로 더 좁게 수렴합니다. 이 비교는 파티클 필터가 실제로 하는 일이 정확히 무엇인지를 보여줍니다 — 단봉 분포에서는 EKF와 본질적으로 비슷한 일(불확실성을 관측으로 좁히는 것)을 하지만, 다봉 분포에서는 EKF가 아예 할 수 없는 일(여러 가설 중 옳은 것을 시간이 지나며 가려내는 것)을 해냅니다.

== 요약

* 파티클 필터는 믿음을 가우시안 하나가 아니라, 위치와 가중치를 가진 수많은 파티클의 집합으로 표현해 다봉 분포까지 다룰 수 있습니다.
* 예측은 모든 파티클에 운동 모델과 노이즈를 적용하고, 갱신은 관측과 얼마나 잘 맞는지로 가중치를 매기며, 유효 표본 크기가 낮아지면 리샘플링으로 파티클을 다시 채웁니다.
* 좌우 대칭인 랜드마크 배치 때문에 생긴 두 개의 그럴듯한 가설이, 로봇이 이동하며 대칭을 깨는 관측을 반영하자 단 몇 스텝 만에 하나(옳은 가설)로 좁혀지고, 틀린 가설의 가중치는 정확히 `0`으로 사라지는 걸 확인했습니다.
* 이 표현력은 계산 비용을 대가로 치릅니다 — 파티클 수가 많이 필요하고, 상태 차원이 높아질수록 그 비용은 더 커집니다.

다음 장에서는 이 계산 비용 문제를, SLAM의 구조(로봇 경로가 정해지면 랜드마크들은 서로 독립이 된다는 성질)를 이용해 영리하게 줄이는 FastSLAM을 다룹니다.
