SLAM의 핵심 질문은 "로봇이 지금 어디에 있는가"입니다. 로봇은 자신의 위치를 직접 볼 수 없고, 대신 (1) 이동 명령(예: "앞으로 1m")과 (2) 센서 측정값(예: "문이 보인다")이라는 간접적인 정보만 가집니다. 두 정보 모두 노이즈가 섞여 있습니다 — 바퀴가 미끄러질 수도 있고, 센서가 오작동할 수도 있습니다. 베이지안 필터링은 이런 불확실한 정보들을 체계적으로 합쳐서, "로봇이 어디 있을 것 같은가"에 대한 확률 분포(믿음, belief)를 유지하고 갱신하는 수학적 틀입니다. 이 책 전체(칼만 필터, EKF, 파티클 필터)가 결국 이 하나의 아이디어를 서로 다른 방식으로 구현한 것입니다.

== 장난감 문제: 1D 복도의 로봇

로봇이 `20`칸짜리 1차원 복도를 걸어다닙니다. 몇 칸에는 문이 있고, 로봇은 "지금 문 앞에 있는가"를 감지하는 (불완전한) 센서를 갖고 있습니다.

[source,python]
----
import numpy as np

N = 20
doors = np.array([3, 8, 13, 17])
is_door = np.zeros(N, dtype=bool)
is_door[doors] = True
----

== 믿음(belief): 위치에 대한 확률 분포

로봇은 자기가 정확히 몇 번 칸에 있는지 모릅니다 — 대신 각 칸에 있을 확률을 갖고 있습니다. 아무 정보가 없을 때는 모든 칸이 똑같이 그럴듯합니다.

[source,python]
----
belief = np.ones(N) / N   # 균등분포 -- "아무것도 모른다"
print(belief.sum())        # 1.0
----

== 센서 갱신: 베이즈 정리로 믿음을 좁히기

로봇의 센서가 완벽하지 않습니다 — 문 앞에서 `80%` 확률로 맞게 "문이다"라고 감지하고, 문이 아닌 곳에서도 `15%` 확률로 잘못 "문이다"라고 오탐합니다.

[source,python]
----
p_door_given_door = 0.8     # 문 앞에서 맞게 감지할 확률
p_door_given_nodoor = 0.15  # 문이 아닌데 잘못 감지할 확률(오탐)

def sensor_update(belief, is_door, measurement_is_door):
    if measurement_is_door:
        likelihood = np.where(is_door, p_door_given_door, p_door_given_nodoor)
    else:
        likelihood = np.where(is_door, 1 - p_door_given_door, 1 - p_door_given_nodoor)
    posterior = belief * likelihood
    posterior /= posterior.sum()
    return posterior
----

이게 베이즈 정리 그 자체입니다 — `사후확률 ∝ 사전확률 × 우도`.

* **사전확률(Prior, `belief`):** 센서 측정값을 보기 전에 "내가 이 칸에 있을 확률"입니다.
* **우도(Likelihood, 가능도):** **"만약 내가 이 칸에 진짜로 서 있다면, 지금과 같은 센서 측정값이 나올 그럴듯함(확률)"**을 뜻합니다. 예를 들어 센서가 "문이다!"라고 외쳤다면, 진짜 문이 있는 칸의 우도는 `0.8`(정상 감지)로 높고, 벽만 있는 칸의 우도는 `0.15`(오탐)로 낮습니다.
* **사후확률(Posterior):** 사전확률에 우도를 곱해 새롭게 갱신된 "내가 이 칸에 있을 최종 확률"입니다.

각 칸에 대한 현재 믿음(`belief`, 사전확률)에 방금 들어온 측정값의 우도(`likelihood`)를 곱하고, 전체 확률의 합이 `1`이 되도록 다시 정규화(normalize)하면 센서 갱신이 끝납니다.

[source,python]
----
belief_after_sensor = sensor_update(belief, is_door, measurement_is_door=True)
print(belief_after_sensor[is_door].mean(), belief_after_sensor[~is_door].mean())
----

"문이다"라는 측정을 반영하니, 문이 있는 칸들의 평균 확률이 문이 없는 칸들의 평균 확률보다 뚜렷하게 높아집니다 — 완벽하지 않은 센서라도, 정보가 아예 없는 것보다는 믿음을 실제 위치 쪽으로 끌어당긴다는 걸 확인할 수 있습니다.

== 운동 갱신: 이동 명령을 반영하되 불확실성을 더하기

로봇이 "오른쪽으로 1칸"이라는 명령을 받으면, 믿음도 오른쪽으로 옮겨가야 합니다. 하지만 완벽하게 1칸만 이동한다고 가정하면 안 됩니다 — 바퀴가 미끄러지거나 더 가거나 덜 갈 수 있으므로, 그 불확실성까지 반영합니다.

[source,python]
----
def motion_update(belief, move, p_correct=0.7, p_over=0.15, p_under=0.15):
    new_belief = np.zeros_like(belief)
    for i in range(len(belief)):
        target = i + move
        if 0 <= target < len(belief):
            new_belief[target] += belief[i] * p_correct
        target_over = i + move + 1
        if 0 <= target_over < len(belief):
            new_belief[target_over] += belief[i] * p_over
        target_under = i + move - 1
        if 0 <= target_under < len(belief):
            new_belief[target_under] += belief[i] * p_under
    return new_belief / new_belief.sum()
----

각 칸의 확률 덩어리가 `70%`는 정확히 목표 칸으로, `15%`씩은 한 칸 더 가거나 덜 간 칸으로 퍼져나갑니다 — 이 "퍼짐"이 운동 자체가 가진 불확실성을 표현합니다. 센서 갱신이 믿음을 뾰족하게(확신 있게) 만드는 방향이라면, 운동 갱신은 반대로 믿음을 퍼뜨리는(불확실하게 만드는) 방향입니다.

== 예측-갱신 순환: 다섯 걸음 시뮬레이션

로봇이 실제로 칸 `5→6→7→8→9`로 이동한다고 하고(칸 `8`은 문입니다!), 매 칸마다 센서 갱신을, 이동할 때마다 운동 갱신을 번갈아 적용합니다.

[source,python]
----
belief = np.ones(N) / N
true_positions = [5, 6, 7, 8, 9]
for step, tp in enumerate(true_positions):
    meas = is_door[tp]                                  # 이 위치에서 실제로 나올 이상적 측정
    belief = sensor_update(belief, is_door, measurement_is_door=meas)
    entropy = -np.sum(belief * np.log(belief + 1e-12))
    if step < len(true_positions) - 1:
        belief = motion_update(belief, move=1)
----

[source]
----
entropy over steps: [2.910, 2.854, 2.818, 2.321, 2.442]
final belief argmax: 9   true final position: 9
----

엔트로피(불확실성의 척도, 낮을수록 믿음이 한 곳에 뾰족하게 모여 있다는 뜻)가 전반적으로 줄어들고 있습니다 — 특히 로봇이 칸 `8`(문)을 지나는 시점에 크게 떨어집니다(`2.818→2.321`), 문이라는 뚜렷한 정보가 들어왔기 때문입니다. `5`걸음 뒤, 믿음이 가장 높은 칸(`argmax`)이 실제 위치(`9`)와 정확히 일치했습니다 — 완벽하지 않은 센서와 완벽하지 않은 운동 모델만으로도, 반복적으로 정보를 결합하면 위치를 정확하게 좁혀낼 수 있다는 걸 확인했습니다.

== 이 순환이 SLAM의 뼈대인 이유

방금 본 "센서 갱신 → 운동 갱신 → 센서 갱신 → ..." 순환이 사실상 모든 SLAM 알고리즘의 기본 골격입니다. 이 장의 히스토그램 필터는 위치를 이산적인 칸들의 확률로 표현했지만, 다음 장의 칼만 필터는 같은 순환을 연속적인 가우시안 분포로, 7장의 파티클 필터는 수많은 가상의 "가설 위치" 표본으로, 10장의 그래프 기반 SLAM은 전체 궤적에 대한 최적화 문제로 표현합니다 — 표현 방식은 다르지만, "불확실한 정보를 순차적으로 결합해 믿음을 갱신한다"는 핵심 아이디어는 똑같습니다.

== 직접 해보기

p_door_given_nodoor_bad = 0.4  # 오탐률이 훨씬 높은 나쁜 센서

def sensor_update_bad(belief, is_door, measurement_is_door):

== 전체 코드

이 장에서 단계별로 작성한 1차원 히스토그램 베이지안 필터의 전체 실행 코드입니다.

[source,python]
----
import numpy as np

# 1. 1차원 복도 환경 정의 (20칸 중 3, 8, 13, 17번 칸에 문 위치)
N = 20
doors = np.array([3, 8, 13, 17])
is_door = np.zeros(N, dtype=bool)
is_door[doors] = True

# 2. 초기 믿음: 균등분포 (아무것도 모르는 상태)
belief = np.ones(N) / N

# 3. 센서 갱신 함수 (베이즈 정리: 사후확률 ∝ 사전확률 × 우도)
p_door_given_door = 0.8     # 문 앞에서 맞게 감지할 확률
p_door_given_nodoor = 0.15  # 문이 아닌데 잘못 감지할 확률(오탐)

def sensor_update(belief, is_door, measurement_is_door):
    if measurement_is_door:
        likelihood = np.where(is_door, p_door_given_door, p_door_given_nodoor)
    else:
        likelihood = np.where(is_door, 1 - p_door_given_door, 1 - p_door_given_nodoor)
    posterior = belief * likelihood
    posterior /= posterior.sum()
    return posterior

# 4. 운동 갱신 함수 (이동 불확실성을 반영한 컨볼루션)
def motion_update(belief, move, p_correct=0.7, p_over=0.15, p_under=0.15):
    new_belief = np.zeros_like(belief)
    for i in range(len(belief)):
        target = i + move
        if 0 <= target < len(belief):
            new_belief[target] += belief[i] * p_correct
        target_over = i + move + 1
        if 0 <= target_over < len(belief):
            new_belief[target_over] += belief[i] * p_over
        target_under = i + move - 1
        if 0 <= target_under < len(belief):
            new_belief[target_under] += belief[i] * p_under
    return new_belief / new_belief.sum()

# 5. 5걸음 시뮬레이션: 센서 갱신과 운동 갱신의 순환
true_positions = [5, 6, 7, 8, 9]

for step, tp in enumerate(true_positions):
    meas = is_door[tp]  # 해당 위치에서의 센서 측정값
    belief = sensor_update(belief, is_door, measurement_is_door=meas)
    entropy = -np.sum(belief * np.log(belief + 1e-12))
    print(f"step {step} (pos={tp}, meas={meas}): entropy={entropy:.3f}")
    
    if step < len(true_positions) - 1:
        belief = motion_update(belief, move=1)

print(f"\n최종 추정 위치(argmax): {np.argmax(belief)} | 실제 위치: {true_positions[-1]}")
----

== 요약

* 베이지안 필터링은 "센서 갱신(베이즈 정리로 믿음을 좁힘) → 운동 갱신(이동을 반영하되 불확실성을 더함)"을 반복해서, 불확실한 정보로부터 위치에 대한 확률 분포를 유지하는 방법입니다.
* 센서 갱신은 `사후확률 ∝ 사전확률 × 우도`라는 베이즈 정리 그대로이고, 운동 갱신은 이동 명령의 불확실성만큼 믿음을 퍼뜨립니다.
* 완벽하지 않은 센서와 운동 모델만으로도, 반복적인 갱신을 통해 믿음이 실제 위치로 수렴하는 것을 엔트로피 감소와 최종 추정치로 직접 확인했습니다.
* 이 예측-갱신 순환이 이 책에서 다룰 모든 SLAM 알고리즘(칼만 필터, EKF, 파티클 필터, 그래프 기반 SLAM)의 공통된 뼈대입니다.

다음 장에서는 이 순환을 이산적인 칸이 아니라 연속적인 실수 공간에서, 그것도 정확한 닫힌 형태의 수식으로 풀어내는 칼만 필터를 다룹니다.
