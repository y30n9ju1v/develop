5장에서 `:toc:`, `:sectnums:` 같은 미리 정해진 속성으로 목차와 섹션 번호를 켰습니다. 이 장에서는 **직접 이름을 정한 속성**을 변수처럼 쓰는 법과, 그 속성의 유무로 문서 내용을 조건부로 바꾸는 법을 봅니다.

== 속성 정의하고 재사용하기

[source,asciidoc]
----
= t
:product-name: MyApp
:version: 2.0

{product-name} 버전 {version}에 오신 것을 환영합니다.
----

문서 제목 아래에 `:이름: 값`으로 속성을 정의하면, 본문 어디서든 `{이름}`으로 그 값을 끼워 넣을 수 있습니다. 변환하면 `{product-name}`과 `{version}` 자리에 실제 값이 그대로 치환됩니다.

[source,html]
----
<p>MyApp 버전 2.0에 오신 것을 환영합니다.</p>
----

제품 이름이나 버전 번호처럼 문서 여러 곳에서 반복되는 값을 한 곳에서만 정의해두면, 나중에 값이 바뀔 때 그 한 줄만 고치면 됩니다 — 문서 전체를 찾아 바꿀 필요가 없습니다.

== ifdef/ifndef: 속성의 유무로 조건부 내용 보이기

[source,asciidoc]
----
:draft:

ifdef::draft[]
이건 초안일 때만 보입니다.
endif::draft[]

ifndef::draft[]
이건 초안이 아닐 때만 보입니다.
endif::draft[]
----

`:draft:`처럼 값 없이 속성 이름만 선언하면(빈 문자열로 정의된 것과 같습니다), 그 속성이 "켜져 있다"는 표시로 씁니다. `ifdef::속성이름[]` ~ `endif::속성이름[]` 사이의 내용은 그 속성이 정의돼 있을 때만 출력에 포함되고, `ifndef`는 반대로 그 속성이 정의돼 있지 **않을** 때만 포함됩니다. 이 예제에서는 `:draft:`가 선언돼 있으니 "초안일 때만 보입니다" 쪽만 실제로 출력에 나타납니다. 초안용 내용과 정식 배포용 내용을 하나의 소스 파일에서 관리하면서, 명령줄에서 속성을 켜고 끄는 것만으로 두 가지 버전을 만들어낼 수 있습니다.

== ifeval: 값을 직접 비교하기

[source,asciidoc]
----
ifeval::["{version}" == "2.0"]
버전이 정확히 2.0입니다.
endif::[]
----

`ifdef`/`ifndef`가 "속성이 정의됐는가"만 볼 수 있는 데 비해, `ifeval::[조건식]`은 속성의 **실제 값**을 비교할 수 있습니다 — 이 예제는 `version` 속성의 값이 정확히 `"2.0"`일 때만 안의 내용을 포함시킵니다. `ifeval`을 닫을 때는 속성 이름 없이 그냥 `endif::[]`만 씁니다.

== 명령줄에서 속성 넘기기

문서 안에서 `:이름: 값`으로 정의하는 대신, 변환할 때 명령줄에서 속성을 넘길 수도 있습니다.

[source,bash]
----
asciidoctor -a version=3.0 my-document.adoc
----

이렇게 하면 문서 안에서 `:version:`을 따로 정의하지 않아도(혹은 정의돼 있어도 덮어써서) `{version}`이 `3.0`으로 치환됩니다 — 같은 문서 소스를 다른 값으로 여러 번 변환해야 할 때 유용합니다.

== 직접 해보기

* `:site-name:` 속성을 "우리 사이트"로 정의하고, "{site-name}에 오신 것을 환영합니다"라는 문장을 만들어보세요. 그리고 `:beta:` 속성이 정의돼 있을 때만 "베타 버전입니다"라는 문장이 보이도록 `ifdef`로 감싸보세요.

.해답 보기
[%collapsible]
====
[source,asciidoc]
----
:site-name: 우리 사이트
:beta:

{site-name}에 오신 것을 환영합니다.

ifdef::beta[]
베타 버전입니다.
endif::beta[]
----
====

== 요약

* `:이름: 값`으로 속성을 정의하고 `{이름}`으로 문서 곳곳에서 재사용합니다.
* `ifdef`/`ifndef`는 속성이 정의됐는지 여부로, `ifeval`은 속성의 실제 값을 비교해 조건부로 내용을 켜고 끕니다.
* 명령줄에서 `-a 이름=값`으로 속성을 넘기면, 같은 소스를 다른 값으로 여러 번 변환할 수 있습니다.
