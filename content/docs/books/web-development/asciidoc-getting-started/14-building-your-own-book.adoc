'''

지금까지 배운 걸 하나로 엮어보겠습니다. 이 장에서는 "레시피 모음"이라는 아주 작은 3장짜리 문서를 처음부터 끝까지 설계하고 조립합니다.

== 1단계: 파일 구조 설계하기

이 사이트의 모든 책이 쓰는 구조(10장, 12장에서 뜯어본)를 그대로 따라 합니다 — 장마다 파일 하나, 그리고 전체를 이어 붙이는 파일 하나.

[source]
----
recipes/
  00-preface.adoc
  01-soup.adoc
  02-salad.adoc
  03-dessert.adoc
  _index.adoc
----

== 2단계: 각 장 파일 작성하기

각 장 파일은 2부에서 배운 구조(제목, nav 줄, 본문, 태그)를 갖춥니다.

[source,asciidoc]
----
// 01-soup.adoc
= 1장: 수프

// tag::body[]
_link:../[전체 목차] · 다음: link:../02-salad/[2장: 샐러드]_

'''

== 기본 야채 수프

[source]
----
당근, 양파, 감자를 깍둑썰기 합니다.
----

TIP: 야채는 크기를 맞춰 썰어야 익는 시간이 고르게 됩니다.
// end::body[]
----

3장(텍스트 강조), 6장(표), 8장(admonition), 9장(코드 블록)에서 배운 문법이 한 장 안에 자연스럽게 섞여 들어갑니다 — 실제로 책을 쓸 때는 이렇게 필요한 문법을 그때그때 조합해서 씁니다.

== 3단계: 전체를 이어 붙이는 _index.adoc 만들기

10장에서 배운 `include`와 `tag=body`, `leveloffset`을 조합합니다.

[source,asciidoc]
----
// _index.adoc
= 레시피 모음

== 목차

. link:00-preface/[서문]
. link:01-soup/[1장: 수프]
. link:02-salad/[2장: 샐러드]
. link:03-dessert/[3장: 디저트]

\include::00-preface.adoc[tag=body,leveloffset=+1]

\include::01-soup.adoc[tag=body,leveloffset=+1]

\include::02-salad.adoc[tag=body,leveloffset=+1]

\include::03-dessert.adoc[tag=body,leveloffset=+1]
----

이제 `asciidoctor _index.adoc`으로 변환하면 전체 레시피 모음이 한 페이지로 이어진 HTML이 만들어지고, `asciidoctor 01-soup.adoc`으로 변환하면 수프 장만 따로 볼 수 있는 HTML이 만들어집니다 — 같은 소스 파일들로 두 가지 형태를 모두 얻는 것이, 이 책 전체를 관통하는 핵심 아이디어였습니다.

== 자신만의 문서를 설계할 때 고려할 것들

* **장 나누기 기준**: 한 장 안에 너무 많은 주제를 욱여넣지 마세요. 이 책도 "기초 문법(1부) → 구조화(2부) → 코드/재사용(3부) → 실전(4부)"처럼, 개념적으로 묶이는 것끼리 부로 나누고 각 부 안에서 다시 장을 쪼갰습니다.
* **nav 줄을 마지막에 점검하기**: 12장에서 짚었듯, 장을 추가하거나 순서를 바꾸면 앞뒤 장의 nav 줄이 깨지기 쉽습니다. 문서를 완성하기 전 마지막으로 모든 장의 nav 줄이 실제로 앞뒤 장을 정확히 가리키는지 확인하세요.
* **재사용 여부 먼저 판단하기**: 반복되는 코드나 문구가 있다면, 처음부터 복사-붙여넣기 하지 말고 10장·12장에서 배운 태그/include로 한 곳에서만 관리하도록 설계하세요 — 나중에 뜯어고치는 것보다 처음부터 그렇게 설계하는 게 훨씬 쉽습니다.

== 직접 해보기

* 이 장에서 설계한 "레시피 모음" 문서에 2장(샐러드)과 3장(디저트) 파일을 직접 채워 넣고, `_index.adoc`을 실제로 `asciidoctor`로 변환해서 전체 문서가 예상대로 조립되는지 확인해보세요.

.해답 보기
[%collapsible]
====
`02-salad.adoc`과 `03-dessert.adoc`을 `01-soup.adoc`과 같은 틀(제목, nav 줄, `tag::body[]`/`end::body[]`)로 채우고, `_index.adoc`이 있는 폴더에서 `asciidoctor _index.adoc`을 실행하면 `_index.html`이 만들어집니다. 이 파일을 브라우저로 열어보면, 서문부터 3장까지 순서대로 이어진 하나의 문서가 됩니다 — 개별 장 파일(`asciidoctor 02-salad.adoc`)을 따로 변환하면 그 장만 독립된 페이지로도 볼 수 있다는 것도 함께 확인해보세요.
====

== 요약

* 여러 장으로 나뉜 문서는 장마다 파일 하나 + 전체를 이어 붙이는 `_index.adoc`이라는 구조로 설계합니다.
* 각 장 파일은 이 책의 1~3부에서 배운 문법(제목, 목록, 표, admonition, 코드 블록)을 필요에 맞게 조합해서 채웁니다.
* `tag::body[]`/`end::body[]`와 `include`/`leveloffset`을 조합하면, 같은 소스로 개별 페이지와 전체 페이지를 동시에 만들 수 있습니다.
