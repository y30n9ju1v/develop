1부에서 제목의 레벨(`=`, `==`, `===`)을 다뤘습니다. 이 장에서는 그 섹션들을 자동으로 목차로 뽑고, 번호를 매기고, 여러 문단을 하나의 단위로 묶는 법을 봅니다.

== 문서 속성: 목차와 섹션 번호 자동 생성

[source,asciidoc]
----
= 문서 제목
:toc:
:toclevels: 2
:sectnums:

== 첫 번째 장

내용입니다.

=== 첫 번째 절

더 내용입니다.

== 두 번째 장

내용입니다.
----

문서 제목 바로 아래, 저자 정보 다음 줄부터 `:이름: 값` 형식으로 **문서 속성(attribute)**을 선언할 수 있습니다. `:toc:`를 켜면 문서 앞부분에 목차가 자동으로 생기고, `:sectnums:`를 켜면 섹션 제목 앞에 `1.`, `1.1.` 같은 번호가 자동으로 붙습니다 — 둘 다 직접 손으로 쓰지 않아도 됩니다. `:toclevels: 2`는 목차에 몇 단계 깊이까지 보여줄지를 정합니다. 변환하면 이렇게 됩니다.

[source,html]
----
<div id="toc" class="toc">
<div id="toctitle">Table of Contents</div>
<ul class="sectlevel1">
<li><a href="#_첫_번째_장">1. 첫 번째 장</a>
<ul class="sectlevel2">
<li><a href="#_첫_번째_절">1.1. 첫 번째 절</a></li>
</ul>
</li>
<li><a href="#_두_번째_장">2. 두 번째 장</a></li>
</ul>
</div>
----

각 섹션 제목의 텍스트로부터 자동으로 앵커 ID(`#_첫_번째_장`)가 만들어지고, 목차의 링크가 그 앵커를 가리킵니다 — 3장에서 본 `<<앵커,글자>>` 문법으로 문서 어디서든 이 섹션을 직접 가리킬 수도 있습니다.

이 문서 속성들은 이 사이트에서는 Hugo가 프런트매터와 함께 처리하기 때문에 각 장 파일에 직접 쓰지 않지만, AsciiDoc 문서를 단독으로 컴파일할 때는 이렇게 문서 맨 위에서 켭니다.

== 예제 블록: 예시를 감싸기

[source,asciidoc]
----
.예제 제목
====
예제 블록입니다.
====
----

`====`(등호 네 개)로 감싸면 **예제 블록**이 됩니다 — 여러 문단이나 코드, 목록을 하나로 묶어서 "이건 예시다"라는 걸 시각적으로 표시할 때 씁니다. 바로 위 줄의 `.예제 제목`처럼 점으로 시작하는 줄은 그 블록의 **제목**이 되고, 변환하면 "Example 1. 예제 제목"처럼 번호가 자동으로 붙습니다. 이 책의 "해답 보기" 접이식 블록도 사실 이 예제 블록 문법(`[%collapsible]`을 곁들인)을 씁니다.

== 사이드바 블록: 본문 흐름과 분리된 덧붙임

[source,asciidoc]
----
[sidebar]
****
사이드바 블록입니다. 본문 흐름과 별개로 강조되는 덧붙이는 내용을 담습니다.
****
----

`[sidebar]`를 앞에 붙이고 `****`(별표 네 개)로 감싸면 사이드바 블록이 됩니다. 예제 블록과 헷갈리기 쉬운데, **구분 기호가 다르다는 걸** 꼭 기억해야 합니다 — `====`는 예제 블록, `****`는 사이드바 블록입니다. 잘못된 기호를 쓰면 의도한 것과 다른 종류의 블록으로 변환되어 스타일이 어긋납니다.

== 열린 블록: 아무 의미 없이 그냥 묶기

[source,asciidoc]
----
--
열린 블록(open block)입니다. 여러 요소를 하나로 묶을 때 씁니다.
--
----

`--`(하이픈 두 개)로 감싸는 **열린 블록**은 그 자체로는 특별한 스타일이 없습니다 — 여러 문단이나 블록을 하나의 단위로 묶어서, 거기에 공통된 속성(`[.클래스명]` 같은)을 한 번에 적용하고 싶을 때 씁니다. 이 책의 각 장 맨 위 nav 줄 아래 놓인 `'''`(가로줄, thematic break)도 비슷하게 "여기서 한 구획이 끝난다"는 걸 시각적으로 표시하는 가벼운 문법입니다.

== 직접 해보기

* "팁"이라는 제목을 가진 예제 블록 안에 두 개의 문단을 넣어보세요.

.해답 보기
[%collapsible]
=====
[source,asciidoc]
----
.팁
====
첫 번째 문단입니다.

두 번째 문단입니다.
====
----

예제 블록 안에서도 빈 줄로 문단을 구분하는 규칙(2장)이 그대로 적용됩니다.
=====

== 요약

* `:toc:`, `:sectnums:` 같은 문서 속성으로 목차와 섹션 번호를 자동 생성할 수 있습니다.
* 예제 블록(`====`)은 예시를 감싸는 데, 사이드바 블록(`****`)은 본문과 분리된 덧붙임에 쓰이고, 구분 기호를 혼동하지 않아야 합니다.
* 열린 블록(`--`)은 특별한 스타일 없이 여러 요소를 하나로 묶습니다.
