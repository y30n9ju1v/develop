== 이 책이 하려는 것

Markdown은 간단한 글을 쓰기에는 좋지만, 책이나 기술 문서처럼 여러 장으로 나뉘고, 표와 이미지와 소스 코드가 섞이고, 문서 일부를 재사용해야 하는 글을 쓰다 보면 금방 한계에 부딪힙니다. **AsciiDoc**은 이런 상황을 염두에 두고 설계된 문서 작성 언어입니다 — Markdown만큼 손에 익히기 쉬우면서도, 표·admonition(주의/참고 박스)·소스 코드 하이라이팅·문서 조립(include) 같은 기능을 문법 자체에 갖추고 있습니다.

이 책은 AsciiDoc의 기본 문법부터 시작해서, 문서를 구조화하는 법, 소스 코드와 다른 문서를 재사용하는 법, 그리고 실제로 문서를 HTML이나 PDF로 변환해 눈으로 확인하는 법까지 다룹니다. 이 사이트에 실린 모든 책이 사실 AsciiDoc으로 쓰여 있습니다 — 이 책을 다 읽으면, 이 사이트의 다른 책들이 어떻게 만들어졌는지도 함께 이해하게 됩니다.

== 누구를 위한 책인가

Markdown을 한 번이라도 써본 적이 있다면 충분합니다. AsciiDoc 문법 대부분이 Markdown과 닮았거나 더 직관적이기 때문에, 처음 마크업 언어를 배우는 사람도 무리 없이 따라올 수 있습니다. 이 책의 모든 예제는 실제로 `asciidoctor`로 변환해 확인한 것들입니다.

== 읽는 순서

이 책은 4부 14개 장으로 나뉩니다.

*1부(1~4장)* 는 기초 문법을 다집니다 — AsciiDoc이 무엇인지, 제목과 문단, 텍스트 강조와 인라인 서식, 목록을 다룹니다.

*2부(5~8장)* 는 문서를 구조화하는 법을 다룹니다 — 섹션과 문서 구조, 표, 이미지와 링크, admonition과 인용을 다룹니다.

*3부(9~12장)* 는 코드와 재사용을 다룹니다 — 소스 코드 블록과 문법 강조, 태그와 include로 문서를 조립하는 법, 속성(attribute)과 변수, 그리고 조건부 포함과 재사용 패턴을 다룹니다.

*4부(13~14장)* 는 실전 활용입니다 — 문서를 HTML/PDF로 변환하는 법과, 직접 자신만의 책이나 문서를 설계해보는 법을 다룹니다.

각 장의 예제는 바로 앞 장에서 배운 문법을 재사용합니다 — 순서대로 읽는 걸 권합니다.
