Markdown의 표는 파이프(`|`)로 열을 맞춰 써야 해서 셀 안에 줄바꿈이나 목록을 넣기 어렵습니다. AsciiDoc의 표는 다릅니다 — 셀마다 새 줄에서 시작하기 때문에, 셀 안에 얼마든지 복잡한 내용을 넣을 수 있습니다.

== 기본 표: cols와 헤더

[source,asciidoc]
----
.표 제목
[cols="1,2,1", options="header"]
|===
|이름 |설명 |타입

|foo
|첫 번째 값
|Int

|bar
|두 번째 값, +
줄바꿈도 됩니다
|String
|===
----

표는 `|===`로 시작하고 `|===`로 끝납니다. `[cols="1,2,1"]`은 세 열의 상대적 너비 비율을 정합니다(가운데 열이 양옆보다 두 배 넓어집니다). `options="header"`를 켜면 표 시작 직후의 첫 줄이 헤더 행(`<th>`)이 됩니다. 각 셀은 `|`로 시작하고, 한 셀 안에서는 3장에서 배운 강제 개행(`+`)이나 다른 인라인 서식이 그대로 통합니다.

**한 행을 한 줄에 몰아 써도 되고**(헤더 행에서처럼), **각 셀을 줄마다 나눠 써도** 됩니다(그 아래 데이터 행들처럼) — 어느 쪽이든 셀 사이의 경계는 `|`가 정합니다.

== 셀 안에 서식 넣기

[source,asciidoc]
----
[cols="1,1"]
|===
|왼쪽 셀 |오른쪽 셀에 *굵게* 서식도 됩니다
|===
----

기본적으로 셀 내용은 일반 문단으로 취급되기 때문에, 3장에서 배운 `*굵게*`, `_기울임_` 같은 인라인 서식이 셀 안에서도 그대로 작동합니다.

== AsciiDoc 셀: 셀 안에 블록 통째로 넣기

[source,asciidoc]
----
[cols="1,1a"]
|===
|일반 셀
a|AsciiDoc 셀입니다.

* 목록도 들어갑니다
* 두 번째 항목
|===
----

`cols` 속성에서 열 번호 뒤에 `a`를 붙이면(`1,1a`, 두 번째 열이 "AsciiDoc 셀"이 됩니다), 그 열의 셀은 `a|`로 시작해서 **목록, 코드 블록, 심지어 다른 표까지** 통째로 담을 수 있는 셀이 됩니다 — 일반 셀은 문단 하나만 들어가는 게 기본이지만, AsciiDoc 셀은 그 안에서 빈 줄로 나뉜 여러 블록을 온전히 해석합니다. 표 안에 목록이나 여러 문단을 넣고 싶을 때 이 문법이 필요합니다.

== 직접 해보기

* 2열짜리 표를 만들어보세요 — 첫 번째 열은 "재료", 두 번째 열은 "수량"이라는 헤더를 가지고, 데이터 행 두 개를 채워보세요.

.해답 보기
[%collapsible]
====
[source,asciidoc]
----
[cols="1,1", options="header"]
|===
|재료 |수량

|밀가루
|200g

|설탕
|50g
|===
----
====

== 요약

* 표는 `|===`로 감싸고, `[cols="비율,..."]`로 열 너비를, `options="header"`로 헤더 행을 지정합니다.
* 셀은 `|`로 시작하고, 한 행을 한 줄에 몰아 쓸 수도, 셀마다 줄을 나눠 쓸 수도 있습니다.
* 기본 셀 안에서도 인라인 서식이 작동하지만, 목록이나 여러 문단처럼 복잡한 내용을 넣으려면 `cols`에 `a`를 붙인 AsciiDoc 셀(`a|`)이 필요합니다.
