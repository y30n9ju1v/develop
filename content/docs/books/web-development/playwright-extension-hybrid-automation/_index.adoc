draft: false
---

규칙이 명확한 웹 자동화는 Playwright로, 캔버스로만 그려진 좌석맵처럼 판단이 필요한 부분은 크로미움 익스텐션 안에서 LLM을 호출해 처리하는 하이브리드 자동화 기술을, 직접 만든 연습용 예매 사이트로 실습하는 책입니다. 실제 예매 사이트는 다루지 않습니다 — 대부분의 티켓 플랫폼 약관이 자동화 예매를 금지하고, 한국은 2024년 공연법 개정으로 관련 규제가 강화됐습니다. 대신 대기열·캔버스 좌석맵·경쟁 조건까지 갖춘 가짜 사이트를 1부에서 직접 짓고, 그 위에서만 자동화를 연습합니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
