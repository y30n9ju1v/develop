2부(Playwright)와 3부(익스텐션+LLM)를 각각 따로 만들었습니다. 이 장에서 하나로 잇습니다 — 로그인과 대기열은 Playwright가 직접 하고, 좌석 선택은 실제 팝업을 열어 익스텐션이 LLM으로 판단하게 합니다.

== 전체 스크립트

[source,javascript]
----
const { chromium } = require('playwright');
const path = require('path');

const extPath = path.join(__dirname, 'ext');
const context = await chromium.launchPersistentContext('./udata', {
  headless: false,
  args: [
    '--headless=new', // 18장에서 다시 다룹니다
    `--disable-extensions-except=${extPath}`,
    `--load-extension=${extPath}`,
  ],
});

let [sw] = context.serviceWorkers();
if (!sw) sw = await context.waitForEvent('serviceworker', { timeout: 10000 });
const extensionId = sw.url().split('/')[2];

const page = await context.newPage();
await page.goto('http://localhost:4100');

// 3장: 로그인
await page.fill('#name', '홍길동');
await page.fill('#phone', '010-1234-5678');
await page.click('#login');
await page.waitForSelector('#enter', { state: 'visible' });

// 4장: 대기열
let position = Infinity;
while (position > 0) {
  await page.click('#enter');
  position = Number(await page.locator('#qpos').innerText());
}
await page.waitForSelector('#seatmap-area', { state: 'visible' });
console.log('queue cleared, seatmap visible');

// 8장: 실제 팝업을 별도 페이지로 열어 그대로 조작한다 (7장의 격리된 world 함정을 피하는 방법)
const popup = await context.newPage();
await popup.goto(`chrome-extension://${extensionId}/popup.html`);
await popup.fill('#pref', '3루측 그늘, 앞뒤 여유 있는 자리');
await popup.click('#go');
await popup.waitForTimeout(500);
console.log('popup result:', await popup.locator('#out').innerText());

console.log('final reservation status on the ticket page:', await page.locator('#status').innerText());

await context.close();
----

한 프로세스 안에서 Playwright가 로그인 폼을 채우고, 대기열을 뚫고(6번의 폴링), 실제 익스텐션 팝업을 열어 선호도를 입력하고, 그 팝업이 content script → service worker → LLM(모크) → content script로 이어지는 전체 왕복을 실행해 좌석을 클릭했고, 원래 예매 페이지에 `예매 완료: 2행 3열`이 떴습니다. 이게 이 책이 처음부터 짓고 있던 하이브리드 파이프라인입니다 — 규칙이 명확한 부분은 Playwright가, 판단이 필요한 부분은 익스텐션과 LLM이 처리했습니다.

== 요약

* Playwright 한 스크립트 안에서 일반 페이지 자동화(로그인·대기열)와 익스텐션 팝업 조작을 순서대로 이었습니다.
* `page.evaluate()`로 content script 함수를 직접 부르는 대신(7장의 함정), 실제 팝업 페이지를 열어 버튼을 누르는 방식으로 정확한 통신 경로를 재현했습니다.
* 전체 파이프라인을 실제로 끝까지 실행해, 로그인부터 최종 예매 완료 메시지까지 하나의 로그로 확인했습니다.
