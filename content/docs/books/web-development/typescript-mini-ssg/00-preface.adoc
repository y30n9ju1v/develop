== 이 책이 하려는 것

TypeScript 튜토리얼 대부분은 "이런 문법이 있습니다"를 하나씩 나열합니다. 이 책은 반대로 갑니다 — **Markdown 파일을 읽어 HTML 사이트로 만드는 미니 정적 사이트 생성기(SSG)를 처음부터 끝까지 짓고**, 그 과정에서 부딪히는 문제마다 TypeScript의 기능이 왜 필요한지 확인합니다. 판별 유니온은 "글"과 "페이지"를 구분해야 해서 필요해지고, 제네릭은 재사용 가능한 목록 렌더링 함수를 짜다가 필요해지고, `unknown`은 Markdown 파일의 프런트매터(YAML 헤더)가 원래 타입이 없는 텍스트라서 필요해집니다.

== 왜 SSG인가

이 사이트(`develop`) 자체가 정적 사이트 생성기(Hugo)로 만들어졌다는 걸 눈치채셨을 수도 있습니다 — 그 원리를 훨씬 작은 규모로, TypeScript로 직접 다시 지어봅니다. 프로젝트가 작아서 한 장 한 장이 실제로 손에 잡히고, 끝나면 여러분의 컴퓨터에서 실제로 동작하는 도구가 남습니다.

== 이 책의 구조

*1부(1~2장)* 는 프로젝트를 셋업하고, 타입 없이 가장 단순한 버전부터 만들어봅니다.

*2부(3~5장)* 는 이 책의 핵심입니다 — 파일에서 막 읽어온 데이터를 `unknown`과 커스텀 타입 가드로 검증하고, 판별 유니온으로 "글"과 "페이지"를 구분하고, 제네릭과 제약(`extends`)으로 재사용 가능한 함수를 짜면서, TypeScript가 다른 언어와 근본적으로 다른 지점인 **구조적 타이핑**까지 정면으로 다룹니다.

*3부(6~10장)* 는 실전 기능을 확장합니다 — 유틸리티 타입, 비동기 파일 처리, 예외 대신 값으로 실패를 다루는 Result 타입, 클래스 기반 플러그인 시스템, 그리고 URL 슬러그의 모양을 타입으로 표현하는 템플릿 리터럴 타입까지.

*4부(11~12장)* 는 지금까지 지은 조각을 모두 이어 실제로 사이트를 빌드하고, 이 책이 확인한 것과 다루지 않은 것을 정리합니다.

== 실측 원칙

이 책의 모든 코드는 실제로 `tsc`로 컴파일하고 `node`로 실행해 검증합니다 — 컴파일 에러도, 실행 결과도 전부 이 세션에서 실제로 재현한 것을 그대로 싣습니다. TypeScript가 "이 코드는 안전하지 않다"고 거부하는 순간들도 감추지 않고, 그 에러 메시지를 그대로 보여줍니다 — 에러 메시지를 읽는 법 자체가 이 책이 가르치려는 것 중 하나입니다.

== 사전 지식

JavaScript 기본 문법(함수, 배열, 객체, `async/await`)이면 충분합니다. TypeScript를 한 번도 안 써봤어도, 이 책 안에서 필요한 만큼 개념을 함께 설명합니다.
