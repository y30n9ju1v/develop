Go의 표준 라이브러리 `net/http`, 컴파일 타임 타입 검사를 받는 템플릿 라이브러리 `templ`, HTML 속성만으로 부분 갱신을 만드는 `htmx`를 조합해, SPA 프레임워크 없이 상호작용하는 웹 서비스를 서버 중심으로 만드는 법을 실습하는 입문서입니다. 기초 다지기(1부) → htmx로 상호작용 만들기(2부) → 실전 패턴: 컴포넌트 설계·데이터베이스·검색·인증(3부) → 완성과 배포: 실시간 갱신·테스트·종합 실전(4부) 순서로 쌓아 올립니다.

이 책의 모든 코드는 실제로 `go build`/`go run`으로 실행하고, `curl`로 실제 HTTP 요청·응답을 눈으로 확인하며 검증합니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
