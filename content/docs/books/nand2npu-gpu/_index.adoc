title: "nand2npu 2권: NPU에서 미니 GPU로"

link:../nand2npu/[1권]에서 완성한 16비트 CPU 위에, 프로그램 가능한 병렬 코어(SIMT, Single Instruction Multiple Threads) — 이른바 미니 GPU — 를 얹는 시리즈의 2권입니다. 1권과 같은 방법론 — Lean4로 명세와 안전 조건을 증명하고, 그 증명이 통과한 설계만 CIRCT를 거쳐 SystemVerilog로 방출하고, Verilator로 실행 검증하는 것 — 을 그대로 이어갑니다. 레인 하나(1장)에서 시작해 분기 발산(2장), 워프 스케줄링(3장), 공유 메모리(4장), 타일링(5장), 멀티코어 동기화(6장), 컴파일러 확장(7장)까지 쌓은 뒤, 8장에서 그 부품만으로 진짜 발산이 필요한 이미지 에지 검출을 조립하고, 9장에서 이 유연한 코어의 비용을 link:../nand2npu-vision/[3권]의 고정 기능 NPU와 정면으로 비교합니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
