CPU 한 개로는 안 되는 계산(3D Gaussian Splatting, 실시간 시뮬레이션)을 GPU로 가속하는 법을, 호스트-디바이스 분리(1부) → 워크그룹과 SIMT 실행 모델(2부) → 메모리 계층구조(3부) → 3DGS 점군 래스터라이제이션(4부) → 실시간 시뮬레이션 루프(5부) 순서로 쌓아 올리는 독립적인 입문서입니다. CUDA(NVIDIA 전용)나 Metal(Apple 전용) 대신 어떤 GPU에서나 동작하는 개방 표준 **OpenCL**을 씁니다.

이 책의 모든 커널은 이 세션 환경에 실제로 있는 GPU(Apple M4, OpenCL "Apple" 플랫폼)에서 실제로 컴파일되고 실행됩니다. 속도 비교는 전부 ``time.perf_counter()``로 실측한 숫자이고, 배리어를 빠뜨리면 실제로 어떻게 틀린 값이 나오는지, 분기가 갈리면 실제로 얼마나 느려지는지, 타일링으로 메모리 접근을 줄이면 실측 속도가 얼마나 개선되는지 — 전부 실제 실행 결과를 그대로 싣습니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
