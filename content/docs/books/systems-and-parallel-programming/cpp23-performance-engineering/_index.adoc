link:../safe-parallel-cpp23/[『이론을 C++23으로 옮기다: 안전한 병렬 프로그래밍』]의 후속편입니다. 전작이 TaskGrid를 **정확하게** 만드는 데 집중했다면, 이 책은 같은 TaskGrid를 **빠르게** 만드는 데 집중합니다. `std::mdspan`으로 캐시 친화적인 메모리 뷰를 만들고(1부), `deducing this`와 `consteval`로 코드를 단순화하며 계산을 컴파일 타임으로 옮기고(2부), `allocate_at_least`와 PMR 아레나로 병렬 처리의 할당 병목을 없애고(3부), `views::zip`으로 중간 컨테이너 없는 파이프라인을 짜는 것(4부)까지, C++23이 새로 들여온 성능 관련 기능들을 실제로 벤치마크하며 다룹니다.

이 책의 모든 벤치마크는 이 세션 환경에 실제로 설치된 Apple Clang 21(`-std=c++23`, `-O2`)로 컴파일하고 실행해서 나온 실측치입니다. 지어낸 숫자나 "이론적으로는 빨라야 한다"는 주장은 이 책에 없습니다 — 이 툴체인이 아직 구현하지 않은 기능(`std::submdspan`, `views::chunk`/`slide`/`stride`)도 실제 컴파일 에러로 확인하고 정직하게 짚었습니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
