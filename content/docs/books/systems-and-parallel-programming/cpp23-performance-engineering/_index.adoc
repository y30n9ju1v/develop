link:../safe-parallel-cpp23/[『이론을 C{pp}23으로 옮기다: 안전한 병렬 프로그래밍』]의 후속편입니다. 전작이 TaskGrid를 **정확하게** 만드는 데 집중했다면, 이 책은 같은 문제를 성능 관점에서 다시 짠 **PerfGrid**를 1장부터 10장까지 한 조각씩 조립하며 **빠르게** 만드는 데 집중합니다. ``std::mdspan``으로 캐시 친화적인 ``BatchBuffer``를 만들고(1부), ``deducing this``와 ``consteval``로 ``TransformWorker``를 완성하고(2부), ``atomic_ref``로 ``Coordinator``의 진행률을 추적하고(3부), ``allocate_at_least``와 PMR 아레나로 할당 병목을 없애고(4부), ``flat_map``과 ``views::zip``으로 코디네이터의 보고 경로를 마무리하는(5부) 것까지, 매 장이 이전 장의 코드를 그대로 확장합니다. 마지막 장(6부)에서는 이렇게 조립된 시스템 전체를 재구성 없이 그대로 실행해, 최적화를 하나도 적용하지 않은 순진한 버전과 나란히 벤치마크합니다.

이 책의 모든 벤치마크는 이 세션 환경에 실제로 설치된 Apple Clang 21(`-std=c{pp}23`, `-O2`)로 컴파일하고 실행해서 나온 실측치입니다. 지어낸 숫자나 "이론적으로는 빨라야 한다"는 주장은 이 책에 없습니다 — 이 툴체인이 아직 구현하지 않은 기능(`std::submdspan`, `views::chunk`/`slide`/`stride`, `std::start_lifetime_as`)도 실제 컴파일 에러로 확인하고 정직하게 짚었습니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
