== 이 책이 하려는 것

전작 link:../../safe-parallel-cpp23/[『이론을 C++23으로 옮기다』]는 "이 프로그램이 정확한가"만 다뤘습니다 — 데이터 경쟁이 없는가, 프로토콜을 어긴 호출이 컴파일되지 않는가, merge가 항상 같은 값에 수렴하는가. 정확성은 확인했지만, 그 코드가 **얼마나 빠른가**는 의도적으로 다루지 않았습니다(전작 맺음말이 정직하게 그렇게 밝혔습니다).

이 책은 그 빈자리를 채웁니다. C++23이 새로 들여온 기능 몇 가지 — `std::mdspan`, `layout_stride`, `deducing this`, 확장된 `constexpr`/`consteval`, `allocate_at_least`, PMR(Polymorphic Memory Resource), `std::views::zip` — 를 하나씩 실제로 써서, "정확했지만 딱히 빠르지는 않았던" 코드를 눈에 보이게 더 빠른 코드로 고칩니다. 전작과 똑같은 원칙을 지킵니다 — **이 책의 모든 벤치마크는 이 세션 환경에 실제로 설치된 Apple Clang 21(`-std=c++23`, `-O2`)로 컴파일하고 실행해서 나온 실측치**입니다. 지어낸 숫자나 "이론적으로는 빨라야 한다"는 주장은 이 책에 없습니다.

== 정확성 책과 다른 것: 벤치마크는 매번 흔들린다

전작의 검증(컴파일 성공/실패, TSan 리포트, merge 결과값)은 한 번 확인하면 항상 같은 결과가 나옵니다. 이 책이 다루는 성능 수치는 다릅니다 — 같은 코드를 다시 돌려도 이 세션의 머신 상태(다른 프로세스, 캐시 워밍업, 스케줄러 변덕)에 따라 몇 퍼센트씩 흔들립니다. 그래서 이 책은 다음 원칙을 지킵니다.

* 각 벤치마크는 **여러 번 반복 실행**해서 대세(order of magnitude)가 일관되게 재현되는지 확인한 뒤, 그중 대표적인 한 번의 출력을 그대로 싣습니다.
* "2배 빨라졌다"는 식의 주장은 **같은 알고리즘의 두 변형을 같은 입력, 같은 머신, 같은 실행에서 나란히 잰 상대적 차이**일 뿐, 절대적인 처리량 보장이 아닙니다.
* 이 세션의 툴체인(Apple Clang 21, Darwin, `libc++`)이 `std::mdspan::submdspan`이나 `std::views::chunk`/`stride`/`slide`처럼 아직 구현하지 않은 조각도 있습니다 — 전작이 Darwin TSan의 lock-order-inversion 진단 부재를 정직하게 밝혔듯, 이 책도 안 되는 건 안 된다고 그대로 적습니다.

== TaskGrid, 이번엔 빠르게

이 책도 전작처럼 하나의 예제 시스템을 처음부터 끝까지 같이 만들어 나갑니다 — 전작의 그 **TaskGrid**(코디네이터가 워커에게 배치를 나눠주고, 워커가 처리해 결과를 돌려주는 시스템)를 그대로 이어받되, 이번엔 정확성이 아니라 처리량이 기준입니다.

* *1부* 는 `std::mdspan`으로 TaskGrid가 다루는 평평한 버퍼를 다차원 뷰로 감싸, 순회 순서와 메모리 레이아웃이 어긋날 때 캐시가 얼마나 느려지는지 실측합니다.
* *2부* 는 `deducing this`로 오래된 CRTP 코드를 단순화하고, `consteval`로 런타임 계산의 일부를 컴파일 타임 조회 테이블로 옮깁니다.
* *3부* 는 `allocate_at_least`와 PMR 스레드 로컬 아레나로, 워커가 배치를 처리할 때마다 반복하는 힙 할당의 병목을 줄입니다.
* *4부* 는 `std::views::zip`으로 여러 배열을 중간 컨테이너 없이 짝지어 순회하고, 마지막 장에서 지금까지의 기법을 전부 모아 TaskGrid의 배치 처리 파이프라인을 처음부터 끝까지 다시 벤치마크합니다.

== 누구를 위한 책인가

전작처럼 이 책도 **독립적으로 완결**되어 있습니다 — C++을 어느 정도 다뤄봤다면 전작을 안 읽었어도 따라올 수 있습니다. 다만 코디네이터/워커/`WorkerSession`이라는 TaskGrid의 기본 모양은 전작에서 가져온 것이므로, 그 배경이 궁금하다면 link:../../safe-parallel-cpp23/[전작]을 먼저 훑어보길 권합니다. 병렬 코드를 "정확하게" 짜는 법을 이미 알고, 이제 그걸 "빠르게" 만들고 싶은 독자를 위한 책입니다.
