link:../heterogeneous-computing-opencl/[『OpenCL로 배우는 헤테로지니어스 컴퓨팅』]과 같은 구조의 독립적인 입문서입니다. Apple의 배열 프레임워크 **MLX**로 통합 메모리(1부), 지연 평가(1부), 자동 미분과 컴파일(2부), ``mlx.nn``으로 짓는 신경망(3부), 배치 크기·양자화 최적화(4부)까지 확인하며, 3개의 나선형 팔로 뒤섞인 2차원 점을 분류하는 다층 퍼셉트론 하나를 1장부터 10장까지 함께 만들고 NumPy·MLX-CPU·MLX-GPU로 나란히 벤치마크합니다(5부).

이 책의 모든 코드는 이 세션 환경에 실제로 있는 Apple GPU(Metal, ``mx.default_device()``가 돌려주는 ``Device(gpu, 0)``)에서 실제로 실행됩니다. 손으로 미분한 그래디언트와 ``mx.grad``의 결과를 나란히 찍어 오차가 부동소수점 정밀도 수준(``1e-7`` 안팎)인지 확인하고, "GPU가 항상 빠르다"는 흔한 직관이 이 책의 작은 나선형 문제에서는 깨진다는 것(NumPy가 MLX-GPU보다 4.9배 빠릅니다)도 감추지 않고 그대로 싣습니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
