'''

신경망을 학습시키려면 손실 함수를 파라미터로 미분한 그래디언트가 필요합니다. 이 책 뒤에서 다룰 다층 퍼셉트론은 손으로 미분하기엔 너무 복잡하지만, 그 전에 ``mx.grad``가 정말로 옳은 답을 내는지 손으로 미분할 수 있는 가장 단순한 경우 — 선형 회귀 — 로 먼저 확인합니다.

== 손으로 미분하기: 선형 회귀

``pred = x @ W``, ``loss = mean((pred - y)^2)``일 때, 체인 룰로 손 미분하면 ``∂loss/∂W = (2/N) * x^T @ (pred - y)``(``N``은 원소 개수)입니다.

[source,python]
----
import numpy as np

def forward_np(W, x): return x @ W
def loss_np(W, x, y):
    pred = forward_np(W, x)
    return ((pred - y)**2).mean()

pred = forward_np(W, x_np)
grad_hand = (2.0 / (x_np.shape[0] * y_np.shape[1])) * x_np.T @ (pred - y_np)
----

== ``mx.grad``로 같은 걸 자동으로

[source,python]
----
import mlx.core as mx

def loss_mx(W, x, y):
    pred = x @ W
    return ((pred - y)**2).mean()

grad_mx = mx.grad(loss_mx)(Wm, xm, ym)
mx.eval(grad_mx)
----

``mx.grad(loss_mx)``는 함수를 받아서 **또 다른 함수**를 돌려줍니다 — "``loss_mx``를 첫 번째 인자(``W``)로 미분한 함수"입니다. 그 함수에 실제 값을 넣으면 그래디언트가 나옵니다. 손실 함수를 순전파 방향으로만 짰을 뿐, 역전파 수식은 한 줄도 쓰지 않았습니다.

== 대조: 두 결과가 정말 같은가

[source]
----
$ python3 mlx_grad_check.py
hand-derived grad:
 [[ 0.14774522 -0.44340342]
 [ 0.5314623  -0.37669545]
 [ 1.4738606  -0.58173966]]
mx.grad result:
 [[ 0.14774522 -0.44340348]
 [ 0.5314623  -0.37669545]
 [ 1.4738606  -0.5817397 ]]
max abs diff: 5.9604645e-08
----

``5.96e-08``는 ``float32``의 머신 엡실론(``2^-24 ≈ 1.19e-07``)과 같은 자릿수입니다 — 두 계산이 부동소수점 반올림 오차 말고는 완전히 같은 값을 낸다는 뜻입니다. ``mx.grad``가 실제로 하는 일이 "체인 룰을 자동으로, 정확하게 적용하는 것"이라는 걸 이 오차 크기 자체가 증거로 보여줍니다.

== 자동 미분이 정말로 버는 것

이 장의 예제는 손으로도 30초면 미분할 수 있는 식입니다 — 자동 미분의 가치는 여기서 안 보입니다. 5장에서 만들 다층 퍼셉트론은 층이 세 개, 비선형 함수(ReLU)가 두 번 끼어 있고, 6장의 학습 루프는 매 반복마다 이 미분을 다시 계산해야 합니다. 그 정도 복잡도에서 체인 룰을 손으로 다시 짜다가 부호나 전치(transpose) 하나를 놓치는 실수는 흔하고, 흔한 만큼 찾기도 어렵습니다 — ``mx.grad``는 forward 함수 하나만 정확히 짜면, 그 미분은 항상 정확하다는 걸 이 장의 대조가 보장해줍니다.

== 요약

* ``mx.grad(f)``는 함수 ``f``를 받아 그 그래디언트를 계산하는 새 함수를 돌려준다는 걸 확인했습니다.
* 선형 회귀 손실의 그래디언트를 손으로 미분한 결과와 ``mx.grad``의 결과를 나란히 찍어, ``float32`` 머신 엡실론 수준까지 일치한다는 걸 검증했습니다.
* 자동 미분의 실제 가치는 이 장처럼 단순한 식이 아니라, 손 미분이 실수하기 쉬운 복잡한 신경망(5~6장)에서 나온다는 것도 짚었습니다.
