== 이 책에서 조립한 것: MarioRL

``Unconfigured → EnvReady → PolicyLoaded → Training → Checkpointed``라는 타입 상태(2장) 위에, CPython을 임베딩해 ``nes-py``를 프레임 단위로 부르는 얇은 다리(3장)가 원시 프레임을 넘기면, ``mdspan``(4장)이 그레이스케일·리사이즈·4프레임 스택을 짜고, MLX의 C++ API로 손으로 지은 CNN 정책망(5장)이 그걸 받아 행동을 고르고, ``mx::grad``로 미분한 PPO 손실(6장)이 학습 신호를 만듭니다. ``fork()``로 복제한 여러 프로세스(7장)가 이 사이클을 동시에 여러 벌 돌리고, PMR 아레나와 ``atomic_ref``로 지은 ``RolloutBuffer``(8장)가 그 결과를 안전하게 모읍니다. 9~10장은 이 모든 배치 결정(워커 개수, 정책망 배치 크기, 전처리를 어디서 할지)을 추측이 아니라 실측으로 정했고, 11장은 이 조각들을 재구성 없이 이어 실제 마리오 환경에서 사이클 하나가 ``1.145ms``에 돈다는 걸 확인했습니다. 12장은 이 정책망을 TinyRT/CoreML 배포 경로로 옮기며 NHWC↔NCHW flatten 순서라는 새 함정을 만나 고쳤습니다.

* **link:../../cpp23-performance-engineering/[『안전을 넘어 성능으로』]** — 4장의 ``mdspan``, 8장의 PMR 아레나와 ``atomic_ref``가 CPU 쪽 성능을 책임졌습니다.
* **link:../../heterogeneous-computing-opencl/[『OpenCL로 배우는 헤테로지니어스 컴퓨팅』]** — 산술 강도라는 원칙이 9~10장의 배치 결정을 갈랐습니다.
* **link:../../tinyrt-cpu-gpu-inference/[『TinyRT』]** — 11장의 GIL 회피(프로세스 분리)와 12장의 ``LayerRegistry``를 그대로 재사용했습니다.
* **link:../../mlx-apple-silicon-optimization/[『복사 없는 GPU 프로그래밍』]** — 5~6장의 정책망과 PPO가 MLX의 C++ API 위에 섰습니다.

== 이 책이 확인한 것과 확인하지 못한 것

이 책은 두 가지 서로 다른 질문을 섞지 않으려 했습니다 — "이 프레임워크가 빠르고 안전한가"(그렇습니다, 매 장에서 실측했습니다)와 "이 프레임워크로 좋은 정책이 학습되는가"(11장이 정직하게 밝혔듯, 확인하지 못했습니다). 전작이 "학습이 안정적으로 개선되지 않았다"고 인정했던 것과 같은 자리에서, 이 책은 "적어도 이제 병목은 순전파가 아니다, 그리고 그 사실을 실측으로 압니다"라는 한 걸음을 더 갔습니다.

== 이 책이 다루지 않은 것

* **실제로 마리오를 깨는 정책 학습** — 11장이 명시했듯, 완전한 다중 워커 학습을 며칠씩 돌려 실제로 스테이지를 진행하는 정책이 나오는지는 이 세션의 범위 밖입니다.
* **CoreML 이식의 잔차 오차** — 12장이 flatten 순서 문제를 고쳤지만, 남은 오차(``0.000251``)의 정확한 원인(Espresso 백엔드의 패딩/경계 처리 추정)까지는 추적하지 못했습니다.
* **NPU 경로의 동시성** — link:../../tinyrt-cpu-gpu-inference/[『TinyRT』]가 이미 남겨둔 한계와 같습니다 — ``MLModel``을 여러 워커가 동시에 호출하는 상황을 스트레스 테스트하지 않았습니다.
* **다중 GPU/분산 학습** — 이 책의 모든 실측은 이 세션의 Apple Silicon 하나에서만 나왔습니다.

== 다음 단계

이 책이 다진 기반(타입 상태 파이프라인, 프레임 단위 언어 경계, 실측 기반 CPU/GPU/NPU 디스패치) 위에서, 정말로 마리오를 깨는 정책을 학습시키는 건 순전히 시간과 컴퓨팅 예산의 문제입니다 — 프레임워크 자체가 병목이 아니라는 걸 이 책이 확인했으니까요. 그 외에 볼 만한 방향은 12장의 잔차 오차를 끝까지 추적하는 것, 그리고 NPU 경로를 7~8장의 워커 풀에 실제로 통합해 학습과 배포를 같은 프로세스 안에서 오가게 만드는 것입니다. 이 시리즈 전체를 관통한 태도는 여기서도 유효합니다 — **추측하지 말고, 재고, 그다음에 판단하십시오.**
