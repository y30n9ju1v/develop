link:../../../machine-learning-and-rl/reward-only-rl-from-scratch/[『보상만으로 배운다』]가 순수 NumPy로 마리오를 학습시키다 남긴 한계에서 이어받아, link:../safe-parallel-cpp23/[안전]·link:../cpp23-performance-engineering/[성능]·link:../heterogeneous-computing-opencl/[산술 강도]·link:../tinyrt-cpu-gpu-inference/[CPU/GPU/NPU 디스패치]·link:../mlx-apple-silicon-optimization/[MLX]·link:../onnx-hardware-optimization/[가중치 이식] 여섯 책의 기법을 한데 모아 실제 병렬 강화학습 프레임워크 **MarioRL**을 처음부터 끝까지 짓는 캡스톤입니다. C{pp}23이 핵심이고 Python은 CPython 임베딩으로 ``nes-py``를 프레임 단위로만 부르는 얇은 다리입니다.

이 책의 핵심 발견 하나를 미리 밝혀둡니다 — 1장이 진단한 병목(순수 파이썬 루프 컨볼루션이 전체 시간의 75%)을 MLX C++로 옮기니 **6.9배** 빨라졌지만, 그렇다고 모든 걸 GPU로 보내면 안 됩니다 — 배치가 작을 때(정책망 배치 1)는 GPU가 오히려 **7배 느렸고**, 정반대로 정책망이 GPU로 이기는 바로 그 배치 크기에서도 그레이스케일 전처리는 여전히 GPU가 **5.7배 느렸습니다.** "빠르게 만드는 법"은 하나의 규칙이 아니라 매번 실측해야 하는 질문이라는 걸, 이 시리즈의 다른 책들처럼 감추지 않고 그대로 싣습니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
