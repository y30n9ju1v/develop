title: "RIIR: C의 JSON 파서를 Rust로 다시 쓰고 Python에 배포하기"
draft: false
---

C의 대표 JSON 라이브러리 `cJSON`을 기준 삼아 JSON 파서를 Rust로 처음부터 짓고, PyO3와 `maturin`으로 Python 패키지까지 배포하는 책입니다. 소유권·라이프타임·트레잇·안전한 병렬처리(1~5부)를 실제 컴파일 에러와 C 비교로 익힌 뒤, 같은 파서를 Python 확장 모듈로 감싸 Result를 예외로 바꾸고(6~7부), PyObject 변환 비용과 GIL을 실측으로 분석하며(8부), 새 가상환경에 설치 가능한 wheel로 패키징합니다(9부). 벤치마크의 좋은 결과와 나쁜 결과를 모두 원인까지 추적하는 실무 지향적 입문서입니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
