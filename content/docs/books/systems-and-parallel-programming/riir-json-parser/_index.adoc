title: "RIIR: C의 JSON 파서를 Rust로 다시 쓰며 배우는 안전한 병렬 프로그래밍"
draft: false
---

C의 대표 JSON 라이브러리 `cJSON`을 기준 삼아, 같은 기능의 JSON 파서를 Rust로 처음부터 지으며 소유권·라이프타임·트레잇·이터레이터와 클로저·안전한 병렬처리까지 Rust 언어의 핵심을 익히는 책입니다. "Rust는 병렬처리를 컴파일 타임에 안전하게 체크해서 빠르다"는 흔한 오해를 서문에서 바로잡고, C와 실제로 벤치마크한 결과 — 9장에서 C가 근소하게 더 빨랐던 것, 10장에서 `cpp23-performance-engineering` 책의 기법을 그대로 적용하니 C·C++23보다도 2배 넘게 빨라졌던 반전, 그리고 그 반전의 진짜 원인이 파서가 아니라 C++ 쪽의 느린 파일 읽기 방식이었다는 걸 끝까지 추적해 밝혀낸 것까지 — 를 감추지 않고 싣는 실무 지향적 입문서입니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
