draft: false

`riir-json-parser` 책에서 지은 Rust JSON 파서를 PyO3와 `maturin`으로 파이썬 확장 모듈로 감싸고, 파이썬 표준 `json`과 실제로 벤치마크한 뒤 wheel로 패키징하는 책입니다. 첫 벤치마크에서 파이썬 표준 `json`에게 오히려 졌던 결과를 그대로 싣고, 파싱과 파이썬 객체 변환을 실측으로 쪼개 진짜 병목이 파서가 아니라 PyObject를 만드는 비용이라는 걸 찾아낸 뒤, GIL을 실제로 놓아 병렬성을 얻고 완전히 새로운 환경에 wheel을 설치해 검증하기까지 감추지 않고 싣는 실무 지향적 입문서입니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
