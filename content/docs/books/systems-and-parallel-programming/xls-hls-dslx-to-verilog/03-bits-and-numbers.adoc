하드웨어에서 "정수"는 정해진 개수의 비트입니다. DSLX는 그 사실을 숨기지 않습니다. 이 장은 폭이 바뀔 때 정확히 무슨 일이 일어나는지를 다룹니다.

== 산술은 폭 안에서 닫힌다

`uN`/`sN` 산술은 결과를 같은 폭으로 자릅니다(모듈러 2^N^).

[source,dslx]
----
#[test]
fn wrap_test() {
    assert_eq(u8:200 + u8:100, u8:44);      // 300 mod 256 = 44
    assert_eq(u8:0 - u8:1, u8:255);         // 무부호 언더플로
    assert_eq(s8:127 + s8:1, s8:-128);      // 부호 오버플로 (2의 보수)
    assert_eq(u4:0b1111 * u4:0b0011, u4:0b1101);  // 15*3=45, 45 mod 16 = 13
}
----

곱셈이 폭을 넓히길 원하면 명시적으로 캐스팅하거나 표준 라이브러리의 넓은 곱(`umul`, `smul` 계열)을 씁니다. 기본 `*`는 "입력과 같은 폭"입니다.

== 폭을 바꾸는 세 가지 캐스팅

`x as T` 문법으로 폭을 바꿉니다. 방향에 따라 규칙이 다릅니다.

[cols="1,3", options="header"]
|===
| 상황 | 규칙

| 넓히기, 무부호 (`u8 -> u16`)
| **zero-extend.** 상위 비트를 0으로 채웁니다.

| 넓히기, 부호 (`s8 -> s16`)
| **sign-extend.** 상위 비트를 부호 비트로 채워 값을 보존합니다.

| 좁히기 (`u16 -> u8`)
| **truncate.** 하위 N비트만 남기고 상위를 버립니다. 값이 바뀔 수 있습니다.

| 같은 폭, 부호만 바꾸기 (`u8 -> s8`)
| 비트 패턴 그대로, 해석만 바꿉니다. `u8:255 as s8 == s8:-1`.
|===

[source,dslx]
----
#[test]
fn cast_test() {
    assert_eq(u8:0xff as u16, u16:0x00ff);   // zero-extend
    assert_eq(s8:-1 as s16, s16:-1);         // sign-extend
    assert_eq(u16:0x1234 as u8, u8:0x34);    // truncate
    assert_eq(u8:0xff as s8, s8:-1);         // 재해석
}
----

캐스팅이 값을 바꿀 수 있는 곳(좁히기)은 코드에서 눈에 띄게 두는 편이 좋습니다. 나중에 형식 검증(14장)에서 "여기서 상위 비트를 버려도 괜찮은가"가 논점이 되곤 합니다.

== 비트 슬라이스와 연결

값을 비트 범위로 잘라내고(`x[hi:lo]`), 이어 붙일(`++`) 수 있습니다.

[source,dslx]
----
#[test]
fn slice_test() {
    let x = u32:0xDEAD_BEEF;
    assert_eq(x[0:8],   u8:0xEF);     // 하위 8비트
    assert_eq(x[24:32], u8:0xDE);     // 상위 8비트
    assert_eq(x[16:32], u16:0xDEAD);  // 상위 16비트

    // 연결: 왼쪽이 상위(MSB), 오른쪽이 하위(LSB)
    let hi = u8:0xAB;
    let lo = u8:0xCD;
    assert_eq(hi ++ lo, u16:0xABCD);
}
----

슬라이스 인덱스는 `[lo:hi]`로 lo는 포함, hi는 제외이며 0이 최하위 비트입니다. 폭이 결과 타입과 맞아야 합니다.

== 유용한 내장/표준 연산

* `clog2`, `bit_count` 같은 컴파일타임 도우미
* `rev(x)` — 비트 뒤집기
* `one_hot`, `one_hot_sel`, `priority_sel` — 선택 회로에 직접 대응하는 연산
* `x ++ y`, `x[a:b]` — 위에서 본 연결/슬라이스
* `std::` 표준 라이브러리: `std::umax`, `std::clog2`, `std::mul` 계열 넓은 곱 등

`import std;` 후 `std::umax(a, b)`처럼 씁니다. 표준 라이브러리는 순수 DSLX로 작성돼 있어, 궁금하면 소스를 그대로 읽을 수 있습니다.

== 부동소수점: apfloat와 float32

DSLX에는 하드웨어 `float` 타입이 없습니다. 대신 표준 라이브러리가 IEEE-754를 **구조체로** 제공합니다.

[source,dslx]
----
import float32;

type F32 = float32::F32;   // { sign: u1, bexp: u8, fraction: u23 }

#[test]
fn f32_test() {
    let one = float32::one(u1:0);           // +1.0
    let two = float32::add(one, one);       // 1.0 + 1.0
    assert_eq(float32::to_int(two, s32:0) as s32, s32:2);
}
----

`float32::add`, `float32::mul`, `float32::from_int32`, `float32::to_int` 등이 순수 DSLX로 구현돼 있습니다. 즉 여러분이 `float32::add`를 쓰면, 합성 결과에는 진짜 부동소수점 가산기 회로(정규화·라운딩 포함)가 들어갑니다. 이것이 XLS로 부동소수점 유닛을 만드는 방식입니다. 튜토리얼 "Float-to-int Conversion"이 이 과정을 처음부터 짚습니다.

일반 폭(`bfloat16`, 커스텀 지수/가수)이 필요하면 `apfloat` 모듈을 파라메트릭하게 씁니다(파라메트릭은 5장).
