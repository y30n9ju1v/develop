---

https://github.com/google/xls[Google XLS]는 고수준 합성(HLS) 툴체인입니다. Rust를 닮은 함수형 하드웨어 기술 언어 **DSLX**로 기능을 적으면, XLS가 그것을 자체 중간표현(**XLS IR**)으로 바꾸고, 최적화하고, 파이프라인으로 스케줄링하고, 합성 가능한 (System)Verilog로 방출합니다. 여기에 LLVM JIT 기반의 네이티브 속도 시뮬레이션, 채널로 통신하는 동시 프로세스(**proc**), Z3를 이용한 형식 등가 검증이 함께 옵니다.

이 책은 `fn` 하나를 적는 것에서 시작해 DSLX 언어 전체(1부), DSLX를 IR로 낮추고 최적화하는 과정(2부), 지연 모델과 파이프라인 스케줄링과 Verilog 생성(3부), 상태와 동시성을 다루는 proc(4부), 형식 검증과 작은 가속기 종합 실전(5부)까지 순서대로 쌓아 올립니다.

이 사이트의 nand2npu 시리즈(MLIR/CIRCT로 하드웨어를 방출)와 "언어를 처음부터 끝까지"(MLIR로 소프트웨어 언어를 방출)와 나란히 서는 책입니다. 세 책 모두 "고수준 기술 → 중간표현 → 낮추기 → 실행/합성"이라는 같은 골격을 공유하되, 이 책의 목적지는 **레지스터 전송 수준의 하드웨어**입니다.

[NOTE]
====
*이 책의 예제 검증 방식.* nand2npu·"언어를 처음부터 끝까지"는 이 세션 환경에 설치된 툴체인으로 예제를 실검증하지만, XLS는 Bazel 빌드가 필요해 이 책은 그렇게 하지 못했습니다. 예제는 XLS 공식 문서(DSLX 레퍼런스, 튜토리얼, codegen 옵션 문서)를 기준으로 작성했고, 각 장 끝에 GitHub 릴리스 바이너리(`dslx_interpreter_main`, `ir_converter_main`, `opt_main`, `codegen_main`)로 직접 재현하는 명령을 붙였습니다. 플래그 철자와 경로는 XLS 버전에 따라 다를 수 있으니 `--help`로 확인하세요.
====
