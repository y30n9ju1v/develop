title: "모르는 곳에서 나를 찾는 법: 필터와 그래프로 배우는 SLAM"
draft: false
---

칼만 필터에서 EKF-SLAM, 파티클 필터/FastSLAM, 그래프 기반 SLAM(ICP·팩터 그래프·그래프 최적화·루프 클로저)까지, SLAM을 지탱하는 세 가지 주요 패러다임을 NumPy/SciPy로 직접 구현하고 시뮬레이션으로 검증하며 배우는 SLAM 심화 입문서입니다. 확률적 상태 추정 기초(1부) → EKF-SLAM(2부) → 파티클 필터와 FastSLAM(3부) → 그래프 기반 SLAM(4부) → 매핑과 통합(5부) 순서로 쌓아 올립니다.

이 책은 1권 "사진에서 세계로"의 SLAM 개요(4부)를 훨씬 깊게 파고든 심화편이자, 3DGS 자율주행 검증 시리즈와는 독립적으로 읽을 수 있는 책입니다. 로봇도, 센서도 없는 대신, 시뮬레이션으로 만든 궤적·랜드마크·라이다 스캔을 "정답"으로 삼아 각 알고리즘이 그 정답을 얼마나 정확하게 복원하는지 직접 잽니다 — 유한차분으로 야코비안을 검증하고, 실제로 발견한 버그(공분산 인덱싱 오류, 각도 wrap 누락)를 감추지 않고 그대로 다룹니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
