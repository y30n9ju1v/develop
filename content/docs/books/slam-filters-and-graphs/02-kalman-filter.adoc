1장의 히스토그램 필터는 위치를 이산적인 칸들의 확률로 표현했습니다 — 표현은 직관적이지만, 칸 수가 늘어나거나 차원이 높아지면 계산량이 감당할 수 없이 커집니다. 칼만 필터는 믿음을 **가우시안 분포**(평균과 공분산 행렬)로만 표현합니다. 상태가 선형적으로 변하고 노이즈가 가우시안이라는 두 가정만 성립하면, 예측-갱신 순환 전체가 몇 개의 행렬 연산만으로 정확하게(근사가 아니라 수학적으로 정확하게) 계산됩니다.

== 상태: 위치와 속도

이 장의 로봇은 위치만 재는 센서를 갖고 있지만, 상태에는 위치와 속도를 **함께** 담습니다.

[source,python]
----
dt = 1.0
F = np.array([[1, dt], [0, 1]])   # 상태전이: [pos, vel] -> [pos + vel*dt, vel]
H = np.array([[1, 0]])             # 관측행렬: 위치만 관측 가능

Q = np.array([[0.01, 0], [0, 0.01]])  # 프로세스 노이즈 (모델의 불확실성)
R = np.array([[4.0]])                  # 관측 노이즈 (센서의 불확실성)
----

`F`는 "다음 상태 = 현재 상태로부터 어떻게 예측되는가"를 나타내는 행렬입니다 — `위치_다음 = 위치 + 속도×dt`, `속도_다음 = 속도`(등속도 가정)라는 물리 법칙 그 자체를 행렬로 표현한 것입니다. `H`는 "상태 중 무엇을 실제로 관측할 수 있는가"를 나타내는데, 이 행렬이 `[1, 0]`이라는 건 위치만 보이고 속도는 안 보인다는 뜻입니다.

== 예측: 물리 법칙으로 다음 상태를 미리 짐작하기

[source,python]
----
def kf_predict(x, P, F, Q):
    x_pred = F @ x                    # 평균: 물리 법칙 그대로 전파
    P_pred = F @ P @ F.T + Q          # 공분산: 전파되면서 불확실성도 더해짐
    return x_pred, P_pred
----

평균(`x`)은 그냥 `F`를 곱해서 전파하면 됩니다. 공분산(`P`, 불확실성)은 `F @ P @ F.T`(선형 변환을 거친 불확실성)에 `Q`(모델 자체가 못 담아내는 불확실성, 예: 로봇이 갑자기 가속할 수도 있다는 것)를 더합니다 — 예측할수록 불확실성이 늘어난다는 걸 수식이 그대로 담고 있습니다.

== 갱신: 측정값으로 예측을 보정하기

[source,python]
----
def kf_update(x_pred, P_pred, z, H, R):
    y = z - H @ x_pred                        # 잔차: 측정값과 예측의 차이
    S = H @ P_pred @ H.T + R                    # 잔차의 불확실성
    K = P_pred @ H.T @ np.linalg.inv(S)          # 칼만 이득: 잔차를 얼마나 믿을지
    x_new = x_pred + K @ y
    P_new = (np.eye(len(x_pred)) - K @ H) @ P_pred
    return x_new, P_new
----

`칼만 이득(K)`이 이 알고리즘의 핵심입니다 — 예측이 이미 확신에 차 있다면(`P_pred`가 작다면) `K`도 작아져서 측정값을 약하게만 반영하고, 반대로 예측이 불확실하다면(`P_pred`가 크다면) `K`가 커져서 측정값을 강하게 신뢰합니다. 1장에서 "사전확률과 우도를 곱한다"고 했던 베이즈 정리가, 가우시안이라는 특수한 경우에는 이렇게 닫힌 형태의 행렬 연산으로 정확히 계산됩니다.

== 시뮬레이션: 참값, 측정값, 추정값 비교

[source,python]
----
true_states = np.zeros((50, 2))
true_states[0] = [0.0, 1.0]
for k in range(1, 50):
    accel_noise = rng.normal(0, 0.1)
    true_states[k, 1] = true_states[k-1, 1] + accel_noise
    true_states[k, 0] = true_states[k-1, 0] + true_states[k-1, 1] * dt

measurements = true_states[:, 0] + rng.normal(0, 2.0, size=50)  # 표준편차 2인 노이즈
----

로봇은 대략 등속도로 움직이지만 약간의 무작위 가속(`accel_noise`)이 섞입니다 — 이게 바로 `Q`가 담아내야 하는 "모델이 완벽하지 않은 부분"입니다. 측정값에는 표준편차 `2`(`R=4`)짜리 상당한 노이즈가 섞여 있습니다.

== 검증 1: 필터 추정이 순수 측정값보다 정확한가

[source,python]
----
x, P = np.array([0.0, 0.0]), np.eye(2) * 10.0   # 초기값: 속도를 모른다고 가정, 불확실성 크게

estimates = np.zeros((50, 2))
for k in range(1, 50):
    x_pred, P_pred = kf_predict(x, P, F, Q)
    x, P = kf_update(x_pred, P_pred, measurements[k], H, R)
    estimates[k] = x

rmse_raw = np.sqrt(np.mean((measurements - true_states[:, 0]) ** 2))
rmse_kf = np.sqrt(np.mean((estimates[:, 0] - true_states[:, 0]) ** 2))
print(rmse_raw, rmse_kf)
----

[source]
----
raw measurement RMSE: 1.67
kalman filter RMSE:   0.65   (2.6배 개선)
----

측정값을 그냥 쓰는 것보다 칼만 필터를 거친 추정이 `2.6`배 더 정확합니다 — 필터가 "위치는 갑자기 안 변하고 속도를 따라 부드럽게 변한다"는 운동 모델의 사전 지식을, 노이즈 낀 순간 측정값과 결합해서 더 나은 추정을 만들어낸 것입니다.

== 검증 2: 불확실성이 정상상태로 수렴하는가

[source,python]
----
pos_variance = covariances[:, 0, 0]
print(pos_variance[::10])
----

[source]
----
[10.0, 1.39, 1.10, 1.098, 1.098]
----

처음에는 `10.0`(일부러 크게 잡은 초기 불확실성)이었다가, 몇 스텝 만에 `1.1` 근처로 떨어지고 이후로는 거의 변하지 않습니다 — 매 스텝 "예측이 불확실성을 늘리고, 측정이 다시 줄이는" 두 힘이 균형을 이루는 **정상상태(steady state)**에 도달한 것입니다. 이 정상상태 공분산은 `Q`와 `R`의 비율(모델을 얼마나 믿을지 대 센서를 얼마나 믿을지)에 의해 결정됩니다.

== 검증 3: 직접 관측하지 못하는 속도까지 복원되는가

[source,python]
----
rmse_vel = np.sqrt(np.mean((estimates[10:, 1] - true_states[10:, 1]) ** 2))
print(rmse_vel)   # 0.204
----

`H = [1, 0]`이라 속도는 센서로 **한 번도 직접 관측되지 않았는데도**, 워밍업(`10`스텝) 이후 속도 추정 오차가 `0.2`밖에 안 됩니다. 이게 가능한 이유는, 연속된 위치 측정값들의 변화 패턴 자체가 속도에 대한 간접적인 정보를 담고 있고, 상태전이행렬 `F`가 위치와 속도를 연결해주기 때문입니다 — 칼만 필터가 "안 보이는 상태"까지 추정해낼 수 있다는 건, 뒤에서 다룰 EKF-SLAM에서 로봇 위치뿐 아니라 한 번도 정확히 측정되지 않은 랜드마크의 절대 위치까지 함께 추정하는 것의 기초가 됩니다.

== 왜 "선형" 가우시안인가

칼만 필터가 정확한 답을 주는 건, `F`와 `H`가 모두 **선형** 행렬이고 노이즈가 **가우시안**일 때뿐입니다 — 가우시안 분포에 선형 변환을 가하면 결과도 정확히 가우시안이기 때문에, 예측과 갱신을 몇 번을 반복해도 분포가 계속 가우시안으로 남아 평균과 공분산만으로 완전히 표현됩니다. 하지만 실제 로봇은 회전을 포함하기 마련이고, 회전은 비선형입니다 — 다음 장에서 이 문제를 다룹니다.

== 직접 해보기

* `Q`(프로세스 노이즈)를 `0.01`에서 `1.0`으로 훨씬 크게 하면(모델을 덜 믿는다는 뜻), 정상상태 위치 분산이 어떻게 달라지는지 확인해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
Q_big = np.array([[1.0, 0], [0, 1.0]])
x, P = np.array([0.0, 0.0]), np.eye(2) * 10.0
covariances_big = np.zeros((50, 2, 2))
for k in range(1, 50):
    x_pred, P_pred = kf_predict(x, P, F, Q_big)
    x, P = kf_update(x_pred, P_pred, measurements[k], H, R)
    covariances_big[k] = P
print(covariances_big[-1, 0, 0])
----

`Q`를 키우면 정상상태 위치 분산도 커집니다 — 모델을 덜 믿을수록(`Q` 큼), 필터는 매 스텝 측정값에 더 크게 의존하게 되고(칼만 이득 `K`가 커짐), 노이즈 낀 측정값을 더 강하게 반영하니 최종 추정의 불확실성도 커집니다. `Q`와 `R`의 상대적인 크기가 "모델을 믿을지 센서를 믿을지"를 정하는 손잡이라는 걸 다시 확인할 수 있습니다 — 이 손잡이를 잘못 설정하는 게, 다음 장에서 다룰 필터의 실전 튜닝에서 가장 흔한 실수입니다.
====

== 요약

* 칼만 필터는 믿음을 가우시안(평균 `x`, 공분산 `P`)으로 표현하고, 예측(`F`로 전파 + `Q` 추가)과 갱신(측정값과 칼만 이득 `K`로 보정)을 반복합니다.
* 필터를 거친 추정이 순수 측정값보다 `2.6`배 낮은 RMSE를 보였고, 직접 관측되지 않는 속도 상태까지 정확히 복원했습니다.
* 공분산은 시간이 지나며 정상상태로 수렴하고, 이 정상상태는 `Q`(모델 불확실성)와 `R`(센서 불확실성)의 비율로 결정됩니다.
* 칼만 필터가 정확한 건 상태전이·관측이 모두 선형이고 노이즈가 가우시안일 때뿐입니다.

다음 장에서는 로봇이 회전하는(비선형인) 실제 상황으로 넘어가, 칼만 필터를 국소적으로 선형화해서 확장하는 확장 칼만 필터(EKF)를 다룹니다.
