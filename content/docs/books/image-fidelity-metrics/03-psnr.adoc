2장에서 확인한 MSE는 한 가지 불편한 점이 있습니다 — 이미지마다 값의 범위가 다르면(예: `0~1`이 아니라 `0~255`로 계산하면) MSE 숫자 자체의 크기도 완전히 달라져서, "이 MSE 값이 좋은 건지 나�쁜 건지" 감을 잡기 어렵습니다. **PSNR(Peak Signal-to-Noise Ratio, 최대 신호 대 잡음비)**은 MSE를 사람이 더 직관적으로 비교할 수 있는 로그 스케일 숫자(데시벨, dB)로 바꾼 지표입니다.

== PSNR 공식과 구현

[stem]
++++
\text{PSNR} = 10 \cdot \log_{10}\left(\frac{\text{MAX}^2}{\text{MSE}}\right)
++++

`MAX`는 픽셀이 가질 수 있는 최댓값입니다(우리는 1장에서 `[0, 1]` 범위로 정규화했으니 `MAX=1`).

[source,python]
----
import numpy as np

def mse(a, b):
    return np.mean((a - b) ** 2)

def psnr(a, b, max_val=1.0):
    m = mse(a, b)
    if m == 0:
        return float('inf')   # 완전히 같은 이미지는 "무한대로 좋다"
    return 10 * np.log10((max_val ** 2) / m)
----

MSE가 `0`(완전히 같은 이미지)이면 나눗셈이 `0`으로 나누는 게 되므로, 이 경우를 따로 처리해 무한대를 돌려줍니다 — 직관적으로도 "차이가 전혀 없다"는 건 "잡음 대비 신호가 무한히 크다"는 뜻이니 자연스럽습니다.

== 2장의 예제로 PSNR 감 잡기

[source,python]
----
N = 20
x = np.arange(N)
stripe = (np.sin(x * np.pi / 2) > 0).astype(np.float64)
img = np.tile(stripe, (N, 1))

print("완전히 같음:", psnr(img, img))

shifted = np.roll(img, 1, axis=1)
print("1픽셀 이동:", psnr(img, shifted))
----

[source]
----
완전히 같음: inf
1픽셀 이동: 3.01
----

`1`픽셀 이동은 PSNR이 `3.01dB`로 매우 낮게 나왔습니다 — MSE가 컸으니(`0.5`) 당연한 결과입니다. 이 값 자체만으로는 아직 "낮다"가 무슨 뜻인지 감이 안 오니, 노이즈 강도를 서서히 바꿔가며 PSNR이 어떻게 변하는지 봅니다.

== 노이즈 강도와 PSNR의 관계

이미지에 다양한 세기의 가우시안(정규분포) 노이즈를 더하고, 노이즈가 강해질수록 PSNR이 어떻게 줄어드는지 확인합니다.

[source,python]
----
rng = np.random.default_rng(0)
for std in [0.01, 0.05, 0.1, 0.2]:
    noisy = img + rng.normal(0, std, img.shape)
    m = mse(img, noisy)
    p = psnr(img, noisy)
    print(f"노이즈 표준편차={std}: MSE={m:.5f}, PSNR={p:.2f} dB")
----

[source]
----
노이즈 표준편차=0.01: MSE=0.00010, PSNR=40.04 dB
노이즈 표준편차=0.05: MSE=0.00253, PSNR=25.97 dB
노이즈 표준편차=0.1: MSE=0.00869, PSNR=20.61 dB
노이즈 표준편차=0.2: MSE=0.04091, PSNR=13.88 dB
----

노이즈가 강해질수록(표준편차가 커질수록) MSE는 커지고, PSNR은 작아집니다 — PSNR이 "높을수록 좋은" 지표라는 걸 확인할 수 있습니다. 눈여겨볼 부분은 노이즈 표준편차가 `10`배(`0.01 → 0.1`) 커졌는데 MSE는 대략 `100`배(`0.0001 → 0.0087`쯤, 표준편차의 제곱에 비례하므로) 커진 반면, PSNR은 `40.04 → 20.61`로 딱 `20dB` 정도 줄었다는 것입니다 — 로그 스케일 덕분에, MSE가 몇 자릿수씩 뛰는 극단적인 변화가 PSNR에서는 훨씬 다루기 쉬운 크기의 변화로 나타납니다.

== 30dB, 40dB라는 관례적 기준은 어디서 오는가

영상 압축이나 렌더링 분야에서 관례적으로 "PSNR이 `30dB` 이상이면 볼만하다", "`40dB` 이상이면 원본과 거의 구별 안 된다"는 식의 경험적 기준이 쓰입니다. 방금 실험에서 노이즈 표준편차 `0.01`(픽셀 값이 `[0,1]` 범위인 것에 비해 매우 미세한 흔들림)일 때 PSNR이 `40dB`였다는 걸 떠올려보면, 이 기준이 왜 그 근처에서 그어지는지 감이 옵니다 — `40dB`대는 "눈에 거의 안 띌 정도로 미세한 잡음"에 해당하고, `20dB`대는 이미 꽤 눈에 띄는 손상(표준편차 `0.1`은 픽셀 값 범위의 `10%`에 해당하는 흔들림)에 해당합니다. 다만 이건 어디까지나 관례이지 절대적인 기준이 아니라는 점이 다음 장의 주제입니다.

== 직접 해보기

* 노이즈 표준편차를 `0.001`(매우 미세)로 낮춰서 PSNR이 몇 dB나 나오는지 확인하고, 이 값이 앞선 `0.01`일 때(`40.04dB`)와 비교해 얼마나 차이 나는지, 그리고 그 차이가 "표준편차가 `10`배 줄면 PSNR이 `20dB` 늘어난다"는 규칙과 맞는지 확인해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
noisy_tiny = img + rng.normal(0, 0.001, img.shape)
print(psnr(img, noisy_tiny))
----

[source]
----
59.54...
----

`40.04dB`(표준편차 `0.01`)에서 표준편차를 `10`분의 `1`(`0.001`)로 줄이니 PSNR이 `59.54dB`로, 거의 정확히 `20dB` 가까이 늘었습니다 — `MSE`가 표준편차의 제곱에 비례하니 표준편차가 `10`분의 `1`이면 `MSE`는 `100`분의 `1`이 되고, `PSNR`은 `10·log₁₀(100) = 20dB`만큼 늘어난다는 공식대로 정확히 들어맞습니다. 이 "표준편차 `10`배마다 `PSNR` `20dB`"라는 규칙을 알아두면, PSNR 숫자만 보고도 대략 어느 정도 노이즈 수준인지 거꾸로 짐작할 수 있습니다.
====

== 요약

* PSNR은 `10·log₁₀(MAX²/MSE)`로 정의되며, MSE를 로그 스케일로 압축해 극단적인 값 변화도 사람이 다루기 쉬운 크기로 보여줍니다.
* PSNR은 높을수록 좋은 지표이며, 노이즈 표준편차가 `10`배 커질 때마다 PSNR은 대략 `20dB`씩 줄어듭니다.
* `30dB`, `40dB` 같은 관례적 기준은 "이 정도 크기의 노이즈면 대략 이 정도로 보인다"는 경험칙에서 나온 것이며, 절대적인 법칙이 아닙니다.
* PSNR은 결국 MSE를 스케일만 바꾼 것이므로, 2장에서 확인한 MSE의 한계(구조를 무시하고 픽셀별 차이만 본다)를 그대로 물려받습니다 — 다음 장에서 이걸 직접 확인합니다.
