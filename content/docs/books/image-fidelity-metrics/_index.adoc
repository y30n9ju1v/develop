3D Gaussian Splatting 같은 렌더링이나 생성 모델이 만든 이미지가 실제 사진과 얼마나 닮았는지, 픽셀 하나를 비교하는 가장 단순한 아이디어부터 시작해 차근차근 쌓아 올리는 입문서입니다. 픽셀 기반 지표(1부: MSE·PSNR) → 구조를 보는 지표(2부: SSIM) → 사람처럼 보는 지표(3부: 지각적 유사도/LPIPS 아이디어) → 이미지 집합을 비교하는 지표(4부: FID) → 3DGS 렌더링에 적용하기(5부)까지, 모든 지표를 NumPy/SciPy로 직접 구현하고 각 지표가 어떤 손상은 잘 잡고 어떤 손상은 완전히 놓치는지 직접 계산으로 확인합니다.

정말 아무것도 몰라도 되는 지점(이미지가 숫자 배열이라는 것)에서 출발하는 독립적인 입문서입니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
