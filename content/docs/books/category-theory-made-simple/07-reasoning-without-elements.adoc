6장에서 "내부를 몰라도 관계만으로 정체성을 결정한다"는 걸 봤습니다. 이 장에서는 이 태도를 정면으로 다뤄, "두 대상이 같다"는 것조차 원소를 하나도 보지 않고 화살표만으로 정의합니다.

== 두 대상이 "같다"는 것은 무엇인가

두 집합 `{1, 2, 3}`과 `{사과, 바나나, 포도}`는 원소가 다르지만, 어떤 의미에서는 "같은 모양"입니다 — 원소 개수가 같고, 하나씩 짝지을 수 있기 때문입니다. 범주론은 이 "같은 모양"이라는 직관을 **동형(isomorphism)**이라는 개념으로 정확하게 표현합니다.

`A`에서 `B`로 가는 화살표 `f`가 있고, `B`에서 `A`로 가는 화살표 `g`가 있다고 합시다. 이 둘이 "서로를 완전히 되돌린다"는 조건 — `g ∘ f`가 `A`의 항등 화살표와 같고, `f ∘ g`가 `B`의 항등 화살표와 같다 — 을 만족하면, `f`(와 `g`)를 **동형사상(isomorphism)**이라고 부르고, `A`와 `B`는 **동형(isomorphic)**이라고 말합니다.

[source]
----
          A ----f----> B
          A <---g----- B

          g ∘ f = idA          f ∘ g = idB
----

이 정의 어디에도 "원소"라는 말이 없습니다 — 오직 화살표와 합성, 그리고 항등이라는, 범주가 갖춘 최소한의 재료만으로 "같다"는 걸 정의했습니다.

== 동형을 직접 손으로 확인해보기

`{1, 2, 3}`과 `{사과, 바나나, 포도}` 사이에서 실제로 동형사상을 만들어봅시다. `f`를 `1 ↦ 사과`, `2 ↦ 바나나`, `3 ↦ 포도`로 정하고, `g`를 그 반대 방향(`사과 ↦ 1`, `바나나 ↦ 2`, `포도 ↦ 3`)으로 정합니다.

* `g ∘ f`를 확인해봅니다: `1`을 `f`에 넣으면 `사과`, `사과`를 `g`에 넣으면 다시 `1`입니다. `2`, `3`도 마찬가지로 제자리로 돌아옵니다 — `g ∘ f`는 정확히 `{1,2,3}`의 항등 화살표입니다.
* `f ∘ g`도 같은 방식으로 확인됩니다: `사과 → 1 → 사과`, 나머지도 마찬가지입니다.

두 조건이 전부 성립하니, `f`(와 `g`)는 진짜 동형사상이고 두 집합은 동형입니다. 이번엔 **실패하는 경우**를 봅시다 — `{1, 2, 3}`과 `{빨강, 파랑}`(원소가 2개뿐입니다) 사이에 `f : 1↦빨강, 2↦파랑, 3↦빨강`을 만들고, `g : 빨강↦1, 파랑↦2`를 만들었다고 합시다. `f ∘ g`를 확인하면 `빨강 → 1 → 빨강`, `파랑 → 2 → 파랑`으로 `{빨강,파랑}`의 항등 화살표가 맞아떨어지는 것처럼 보이지만, `g ∘ f`를 확인하면 `3 → 빨강 → 1`이 나옵니다 — `3`이 제자리(`3`)로 돌아오지 못하고 `1`로 가버렸으므로, `g ∘ f`는 `{1,2,3}`의 항등 화살표가 **아닙니다**. 두 조건 중 하나라도 깨지면 동형이 아니고, 실제로 원소 개수가 다른 두 집합은 어떤 화살표 쌍을 골라도 결코 동형이 될 수 없습니다 — "동형이면 정확히 같은 크기다"라는, 원소를 셀 수 있는 상황에서는 당연해 보이는 사실이, 원소를 세지 않고 화살표만으로 정의한 개념에서도 정확히 재현된다는 걸 이 예시가 보여줍니다.

== 왜 원소를 보지 않는 것이 더 강력한가

"두 집합의 원소 개수가 같다"는 정의는 집합에서는 잘 통하지만, 원소라는 개념이 없거나 이상하게 작동하는 다른 범주(예를 들어 2장에서 본 "순서의 범주")에서는 아예 쓸 수 없습니다. 반면 화살표로 쓴 동형의 정의는 **어떤 범주에서든 그대로 통합니다** — 순서의 범주에서 동형은 "`a ≤ b`이고 `b ≤ a`"(즉 `a = b`)가 되고, 마을과 길의 범주에서 동형은 "서로를 완전히 오갈 수 있는 왕복 길이 있다"는 뜻이 됩니다. 하나의 정의가 완전히 다른 상황에마다 그 상황에 맞는 올바른 의미로 저절로 번역되는 것 — 이게 1장에서 예고했던 "안을 들여다보지 않는 태도가 오히려 힘을 낸다"는 말이 실제로 작동하는 모습입니다.

== 원소도 사실은 화살표다

한 걸음 더 나아가면, 범주론은 "원소"라는 개념 자체도 화살표로 재현할 수 있습니다. 6장에서 본 끝대상 `T`(집합의 범주에서는 원소가 하나뿐인 집합)를 떠올려보세요 — `T`에서 어떤 집합 `A`로 가는 화살표 하나는, 정확히 `A`의 원소 하나를 "가리키는" 것과 같습니다(끝대상의 유일한 원소가 `A`의 어느 원소로 보내지는지를 정하는 것이니까요). 그래서 `A`의 "원소 하나"라는 개념은 사실 `T → A`라는 화살표로 다시 쓸 수 있습니다 — 원소조차 화살표로 환원되는 것입니다.

이 관찰이 왜 중요할까요? "원소"라는 특권적인 개념 없이 오직 화살표만으로 모든 걸 설명할 수 있다면, 범주론의 모든 정의와 정리는 원소라는 개념이 있든 없든, 심지어 그 개념이 완전히 다르게 작동하는 낯선 범주에서도 그대로 적용됩니다. 이게 범주론이 그토록 넓은 범위의 수학을 동시에 다룰 수 있는 근본적인 이유입니다.

== 화살표의 성질로 재는 "일부만 같음"

동형이 "완전히 같음"을 화살표로 표현한 것이었다면, "부분적으로 같음"을 표현하는 화살표의 성질들도 있습니다. `f : A → B`가 **단사(injective)**라는 건, 서로 다른 `A`의 원소가 `f`를 거치면 항상 서로 다른 `B`의 원소로 간다는 뜻이고(정보를 잃지 않고 "밀어 넣는다"), **전사(surjective)**라는 건 `B`의 모든 원소가 `f`의 결과로 도달 가능하다는 뜻입니다(`B`를 남김없이 "덮는다"). 원소를 직접 세지 않고 화살표만으로 이 둘을 표현할 수도 있습니다 — 예를 들어 단사는 "`f ∘ g1 = f ∘ g2`이면 항상 `g1 = g2`"라는, 오직 화살표의 합성만으로 쓴 조건과 정확히 같습니다(직접 확인해보면, `f`가 서로 다른 값을 같은 곳으로 뭉개버리는 순간 이 조건이 깨진다는 걸 알 수 있습니다). 그리고 `f`가 단사이면서 동시에 전사일 때, 그리고 오직 그때만, `f`는 동형사상이 됩니다(적어도 집합의 범주에서는 그렇습니다 — 다른 범주에서는 이 동치가 깨질 수도 있다는 점이 흥미로운 여담입니다). 동형이라는 "완전한 같음"이, 단사와 전사라는 두 개의 더 잘게 쪼갠 화살표의 성질이 합쳐진 결과라는 걸 알 수 있습니다.

== 요약

* 동형은 서로를 완전히 되돌리는 화살표 한 쌍(`g∘f = id`, `f∘g = id`)으로 정의되고, "두 대상이 사실상 같다"는 직관을 원소 없이 정확하게 표현합니다.
* 화살표로 쓴 정의는 원소라는 개념이 없거나 다르게 작동하는 범주에서도 그대로 통합니다 — 이게 원소 기반 정의보다 강력한 이유입니다.
* 끝대상으로 가는 화살표를 이용하면 "원소"라는 개념조차 화살표로 다시 쓸 수 있습니다.
* 범주론이 오직 화살표만으로 모든 것을 설명할 수 있다는 사실이, 서로 다른 수학 분야를 동시에 다룰 수 있는 근본적인 힘입니다.

2부가 여기서 끝났습니다. 3부에서는 이 화살표의 언어가 실전에서 무엇을 해내는지 — 모나드, 그리고 프로그래밍이 사실 범주론이라는 것 — 을 봅니다.
