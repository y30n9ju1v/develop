13~16장의 고유값·고유벡터는 정사각행렬(`n×n`)에서만 정의됩니다 — `Av = λv`가 성립하려면 `Av`와 `v`가 같은 차원이어야 하기 때문입니다. 하지만 실제 데이터(예: `k`개의 데이터 점을 `n`개의 특성으로 기록한 `k×n` 행렬)는 대부분 정사각이 아닙니다. **특이값분해(SVD, Singular Value Decomposition)**는 고유분해의 아이디어를 임의의 `m×n` 행렬로 확장합니다. 이 장이 왜 중요한지는 명확합니다 — 이미지 압축(각 이미지를 픽셀 행렬로 보고 중요한 성분만 남기는 것), 추천 시스템(사용자×상품 평점 행렬을 저랭크로 근사하는 것), 자연어 처리의 초기 임베딩 기법(잠재의미분석)이 전부 SVD 위에 서 있습니다. 이 장에서 완전히 증명하는 것은, SVD의 재료(특이벡터·특이값)가 사실 16장에서 이미 다진 도구 — `AᵀA`가 항상 대칭이라는 것, 그리고 대칭행렬의 고유분해 — 로 환원된다는 것입니다. 즉 18장은 새로운 이론이 아니라, 10·16장의 결과를 정사각이 아닌 경우로 재조립하는 장입니다.

== 특이값분해가 말하는 것

`m×n` 행렬 `A`는 다음과 같이 분해됩니다.

[source,text]
----
A = U Σ Vᵀ
----

여기서 `U`는 `m×m` 직교행렬(열들이 정규직교, 12·15장에서 다룬 `QᵀQ=I`와 같은 뜻), `V`는 `n×n` 직교행렬, `Σ`는 `m×n` "대각" 행렬(정사각이 아니어도 `(i,i)` 자리만 0이 아닐 수 있다는 뜻으로 대각을 확장한 것)로 대각성분이 음이 아닌 실수 `σ₁ ≥ σ₂ ≥ ... ≥ 0`(**특이값, singular value**)입니다.

기하학적으로, `A`가 하는 일(벡터를 옮기는 것)은 세 단계로 쪼개집니다 — `Vᵀ`로 회전하고, `Σ`로 각 축을 독립적으로 스케일하고(차원이 바뀔 수 있습니다, `m≠n`이면), `U`로 다시 회전합니다. 14장의 대각화가 "정사각행렬은 회전-스케일-역회전으로 쪼개진다"였다면, SVD는 "**임의의** 행렬은 회전-스케일-회전으로 쪼개진다"는 일반화입니다 — 대각화와 달리 시작 좌표계(`Vᵀ`)와 끝 좌표계(`U`)가 같을 필요가 없다는 게 핵심적인 차이입니다.

== 완전히 증명하는 것: 특이값의 제곱은 AᵀA의 고유값이다

`A`의 **특이벡터 쌍** `(u, v, σ)`는 `Av = σu`와 `Aᵀu = σv`를 동시에 만족하는 것으로 정의합니다(`u`는 `Vec m`, `v`는 `Vec n`, `σ ≥ 0`). 이 정의로부터, `v`가 `AᵀA`의 고유벡터이고 그 고유값이 `σ²`라는 것이 바로 따라옵니다 — 이게 SVD를 실제로 계산할 때 쓰이는 사실입니다(`AᵀA`는 정사각·대칭이라 16장의 도구를 그대로 쓸 수 있으므로).

[source,lean]
----
-- Transforms/SVD.lean
import Eigen.PCA

namespace LinAlg

def Mat.IsSingularPair {m n : ℕ} (A : Mat m n) (u : Vec m) (v : Vec n) (sig : ℝ) : Prop :=
  A *ᵥ v = sig • u ∧ Aᵀ *ᵥ u = sig • v

theorem Mat.singular_sq_eq_covariance_eigenvalue {m n : ℕ} (A : Mat m n)
    (u : Vec m) (v : Vec n) (sig : ℝ) (h : A.IsSingularPair u v sig) :
    (Aᵀ * A) *ᵥ v = (sig ^ 2) • v := by
  obtain ⟨h1, h2⟩ := h
  have step : Aᵀ *ᵥ (A *ᵥ v) = (Aᵀ * A) *ᵥ v := by
    sorry
    -- 힌트: (M * N) *ᵥ w = M *ᵥ (N *ᵥ w)라는, 15장에서 이미 다룬 행렬 곱과
    -- 행렬-벡터 곱의 결합성을 그대로 적용합니다(9장 mul_assoc과 사실상 같은 계산으로
    -- 별도 보조정리로 완전히 증명해둘 수 있습니다).
  rw [← step, h1]
  have : Aᵀ *ᵥ (sig • u) = sig • (Aᵀ *ᵥ u) := by
    sorry -- 힌트: Mat.mulVec_smul(8장)을 그대로 적용
  rw [this, h2]
  funext i
  show sig * (sig * v i) = sig ^ 2 * v i
  ring

end LinAlg
----

증명의 흐름은 `v`에 `Aᵀ * A`를 곱한 결과를 두 단계로 나눠 계산하는 것입니다 — 먼저 `A *ᵥ v`를 `h1`(`= σu`)으로 바꾸고, 그 결과에 `Aᵀ`를 곱한 것을 `h2`(`Aᵀu = σv`)로 다시 바꾸면, `σ`가 두 번 곱해져 `σ²v`가 남습니다. 필요한 재료(행렬 곱과 행렬-벡터 곱의 결합성, 8장의 스칼라 보존)는 전부 앞 장에서 이미 증명한 것들입니다.

이 정리가 왜 실용적인지는 명확합니다 — **SVD를 직접 계산하는 표준적인 방법은, 먼저 대칭행렬 `AᵀA`의 고유분해를 16장의 방법(스펙트럼 정리)으로 구하고, 그 고유값의 제곱근을 특이값으로, 고유벡터를 `V`의 열로 삼는 것**입니다. 즉 18장이 실제로 하는 일은 정사각이 아닌 문제(`A`의 분해)를 정사각인 문제(`AᵀA`의 고유분해)로 환원하는 것이고, 방금 증명한 정리가 정확히 그 환원이 타당하다는 근거입니다.

== 저랭크 근사: 왜 SVD가 압축의 표준 도구인가

특이값을 큰 것부터 `σ₁ ≥ σ₂ ≥ ... ≥ σᵣ` 순서로 나열하면, `A`는 다음과 같이 다시 쓸 수 있습니다(랭크-1 행렬들의 합, 이 책은 이 전개 자체를 증명하지 않지만 SVD의 정의로부터 자연스럽게 나옵니다).

[source,text]
----
A = σ₁ u₁ v₁ᵀ + σ₂ u₂ v₂ᵀ + ... + σᵣ uᵣ vᵣᵀ
----

큰 특이값에 대응하는 항일수록 `A`를 재구성하는 데 더 많이 기여하고, 작은 특이값의 항은 거의 기여하지 않습니다 — 이건 16장에서 "고유값이 클수록 그 방향의 분산이 크다"고 봤던 것과 정확히 같은 구조입니다(사실 `σᵢ²`가 `AᵀA`의 고유값이므로, 이건 우연이 아니라 방금 증명한 정리의 직접적인 결과입니다). 큰 특이값 `k`개만 남기고 나머지를 버리면(**저랭크 근사, low-rank approximation**), 원래 행렬과 매우 비슷하지만 훨씬 적은 숫자(`k(m+n+1)`개, 원래 `mn`개 대신)로 저장할 수 있는 근사 행렬을 얻습니다. 이미지 압축(픽셀 행렬을 저랭크로 근사), 추천 시스템(평점 행렬을 저랭크로 근사해 빈 칸을 채우는 것), 워드 임베딩(단어-문맥 행렬을 저랭크로 근사하는 잠재의미분석)이 전부 이 원리를 그대로 씁니다.

== 이 장에서 확정한 것

* 특이값분해(`A = UΣVᵀ`)가 고유분해를 정사각이 아닌 임의의 행렬로 일반화한 것이라는 걸 확인하고, "회전-스케일-역회전"(대각화)과 "회전-스케일-회전"(SVD)의 차이를 짚었습니다.
* 특이벡터 쌍의 정의(`Av=σu`, `Aᵀu=σv`)로부터 `v`가 `AᵀA`의 고유벡터이고 그 고유값이 `σ²`라는 것을 완전히 증명해서, SVD 계산이 실제로는 16장의 대칭행렬 고유분해로 환원된다는 것을 확인했습니다.
* 특이값 순으로 정렬한 랭크-1 행렬들의 합으로 `A`를 재구성하는 것과, 큰 특이값 몇 개만 남기는 저랭크 근사가 이미지 압축·추천 시스템·워드 임베딩의 공통 원리라는 것을 짚었습니다.
