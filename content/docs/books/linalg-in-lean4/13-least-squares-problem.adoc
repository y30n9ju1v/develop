== 방정식이 미지수보다 많을 때

`Ax = b`라는 선형방정식을 풀 때, 미지수(`x`의 성분 개수)보다 방정식(`b`의 성분 개수, 즉 `A`의 행 개수)이 더 많은 경우가 있습니다 — 이런 시스템을 **과결정계(overdetermined system)**라 부릅니다. 과결정계는 일반적으로 정확한 해를 갖지 않습니다.

로봇 예제로 보면, 로봇이 여러 landmark까지의 거리를 측정해서 자기 위치를 추정하는 상황을 생각해봅시다. landmark가 3개뿐이면 위치(2차원이라면 미지수 2개)를 정확히 결정할 수도 있지만, landmark가 10개면 측정 오차 때문에 "이 10개 측정값을 전부 정확히 만족하는 위치"는 존재하지 않을 가능성이 큽니다. 그렇다고 포기할 수는 없습니다 — 우리가 원하는 건 "완벽하게 맞는 해"가 아니라 **"가장 그럴듯한 근사해"**입니다.

== 잔차: 얼마나 못 맞았는가

어떤 후보 `x`에 대해, `Ax`가 목표값 `b`와 얼마나 다른지를 나타내는 벡터를 **잔차(residual)**라 부릅니다 — `r = Ax - b`. 잔차가 영벡터면 정확한 해를 찾은 것이고, 그렇지 않다면 잔차의 "크기"가 작을수록 더 좋은 근사입니다. 이 크기를 재는 자연스러운 방법이 1부에서 만든 노름입니다 — `‖Ax - b‖`.

**최소자승 문제(least squares problem)**는 이 잔차의 노름을 최소화하는 `x`를 찾는 문제입니다. "제곱"이라는 이름이 붙은 이유는, 노름 자체보다 노름의 제곱(`‖Ax-b‖²`)을 최소화하는 것이 수학적으로 다루기 쉽고 — 노름은 제곱근이 있어 미분이나 대수적 조작이 번거롭지만, 노름의 제곱은 각 성분의 제곱의 합(다항식)이라 훨씬 다루기 쉽습니다 — 노름 자체를 최소화하는 것과 노름의 제곱을 최소화하는 것이 정확히 같은 `x`를 준다는 사실(노름이 음이 아니므로 제곱은 순서를 보존하는 변환입니다) 때문입니다.

[source,lean]
----
-- LeastSquares/Problem.lean
import Matrices.Inverse

namespace LinAlg

def residual {m n : ℕ} (A : Mat m n) (x : Vec n) (b : Vec m) : Vec m :=
  A *ᵥ x - b

def objective {m n : ℕ} (A : Mat m n) (b : Vec m) (x : Vec n) : ℝ :=
  ‖residual A x b‖ ^ 2

def IsLeastSquaresSolution {m n : ℕ} (A : Mat m n) (b : Vec m) (x : Vec n) : Prop :=
  ∀ y : Vec n, objective A b x ≤ objective A b y

end LinAlg
----

`IsLeastSquaresSolution`이 이 문제의 정확한 정의입니다 — "`x`가 최소자승해다"라는 것은, 다른 어떤 `y`를 대입해도 `x`가 만드는 목적함수 값보다 작아질 수 없다는 뜻입니다. 이건 최솟값의 정의를 그대로 옮긴 것이고, 1부 6장에서 `argmin`을 "다른 모든 인덱스보다 작거나 같은 값"으로 정의했던 것과 형태가 같습니다 — 다만 여기서는 후보가 유한한 리스트가 아니라 **연속적인 `n`차원 공간 전체**라는 점이 다릅니다. 6장의 `argmin`은 유한 개의 후보를 순회하며 계산할 수 있었지만, 여기서는 무한히 많은 `x`를 순회할 수 없으므로 "최솟값을 찾는 알고리즘"이 아니라 "언제 `x`가 최솟값을 만족하는가"에 대한 대수적 조건을 찾아야 합니다. 이게 다음 장(정규방정식)의 역할입니다.

== 목적함수를 노름의 제곱으로 펼치기

`objective`를 실제로 계산 가능한 형태로 펼쳐보면, 뒤에서 쓸 정규방정식 유도의 재료가 나옵니다.

=== 연습 문제로 남기는 것: 목적함수를 내적으로 펼치기

[source,lean]
----
namespace LinAlg

theorem objective_eq_inner {m n : ℕ} (A : Mat m n) (b : Vec m) (x : Vec n) :
    objective A b x = (A *ᵥ x - b) ⬝ (A *ᵥ x - b) := by
  sorry
  -- 힌트: objective의 정의(노름의 제곱)를 펼치면 Real.sqrt (r ⬝ r) 형태가 나오고,
  -- (Real.sqrt y)^2 = y (y ≥ 0일 때, Real.sq_sqrt)를 적용하면 끝입니다.
  -- 3장의 inner_self_nonneg가 y ≥ 0의 근거입니다.

end LinAlg
----

이 정리는 3장에서 이미 증명해둔 `inner_self_nonneg`(자기 자신과의 내적은 음이 아니다)와, Mathlib의 `Real.sq_sqrt`(음이 아닌 값은 제곱근을 취했다가 다시 제곱하면 원래대로 돌아온다)를 조합하는 것으로 끝납니다 — 새로운 개념 없이, "왜 노름의 제곱을 다루는 게 노름 자체보다 편한가"를 실제로 확인하는 절차입니다. 이 등식이 있어야 다음 장에서 목적함수를 내적의 성질(분배법칙, 전치)만으로 다룰 수 있습니다 — 제곱근이 섞여 있으면 대수적 조작이 훨씬 번거로워집니다.

== 이 장에서 확정한 것

* 과결정계에서 정확한 해 대신 잔차의 노름을 최소화하는 근사해를 찾는다는 최소자승 문제를 정의했습니다.
* 노름 대신 노름의 제곱을 목적함수로 쓰는 이유(대수적 조작의 편의성, 그리고 최솟값을 주는 `x`가 동일하다는 것)를 짚었습니다.
* `IsLeastSquaresSolution`을 "모든 후보보다 작거나 같다"는, 1부 6장의 `argmin` 정의와 같은 형태로 세우되, 후보가 유한 리스트가 아니라 연속 공간 전체라는 차이를 확인했습니다.
* 목적함수를 노름의 제곱에서 내적 형태로 펼치는 정리를 연습 문제로 남겼습니다 — 다음 장에서 이 형태 위에서 미분 없이 대수적으로 최솟값 조건을 유도합니다.

다음 장에서는 이 목적함수를 최소화하는 `x`가 만족해야 하는 대수적 조건 — 정규방정식(`AᵀAx = Aᵀb`) — 을 유도하고, `AᵀA`가 가역이라면 이 조건이 유일한 해를 결정한다는 것을 증명합니다.
