2장에서 표준 기저로 벡터를 유일하게 표현할 수 있다는 걸 봤는데, 사실 그 성질을 만드는 진짜 이유가 선형독립입니다 — 어떤 벡터 집합이 선형독립이면, 그 집합의 선형결합으로 표현되는 벡터는 표현 방법이 유일합니다. 이 개념이 중요한 이유는 "이 벡터 집합에 중복된(다른 벡터들로 재구성 가능한) 정보가 있는가"를 정확히 판별해주기 때문입니다 — 뒤에서 다룰 행렬의 랭크, 14장의 대각화에서 "고유벡터들이 좌표축으로 쓸 수 있을 만큼 서로 독립적인가"를 따지는 질문이 전부 이 개념 위에 서 있습니다. 이 장은 선형독립을 정의하고, 직교하는 벡터는 항상 선형독립이라는 것을 4장의 도구만으로 증명해서, 1부에서 쌓은 개념들이 서로 어떻게 맞물리는지 보여줍니다. 이 정리가 실전에서 중요한 이유는, 12장의 그람-슈미트 직교화가 "선형독립인 벡터들을 입력받아 직교하는 벡터들을 만들어낸다"는 절차이기 때문입니다 — 선형독립은 그람-슈미트가 성립하기 위한 전제 조건이고, 이 장에서 "직교 ⇒ 선형독립"을 증명해두면 그람-슈미트의 결과물이 다시 선형독립이라는 것(그래서 QR 분해에서 `Q`의 열들이 여전히 유효한 좌표축 역할을 한다는 것)을 별도 증명 없이 바로 확인할 수 있습니다.

== 선형독립: 중복된 정보가 없다는 것

벡터 `v₁, ..., vₖ`가 **선형독립(linearly independent)**이라는 것은, 이들의 선형결합으로 영벡터를 만드는 방법이 "계수를 전부 0으로 두는" 자명한 방법 하나뿐이라는 뜻입니다. 반대로, 계수를 전부 0으로 두지 않고도 선형결합이 영벡터가 되는 경우가 있다면(예를 들어 `v₃ = 2v₁ + v₂`처럼 어떤 벡터가 나머지의 선형결합으로 표현된다면), 그 벡터 집합은 **선형종속(linearly dependent)**입니다.

로봇 예제로 보면, 세 개의 센서가 각각 독립적인 정보를 주는지 확인하고 싶을 때 이 개념이 쓰입니다 — 만약 세 번째 센서의 측정값이 항상 앞의 두 센서 측정값의 어떤 고정된 조합으로 정확히 계산된다면, 세 번째 센서는 "새로운 정보"를 주지 않는 셈입니다. 선형독립은 정확히 이 "새로운 정보가 있는가"를 수학적으로 표현한 것입니다.

[source,lean]
----
-- Vectors/Independence.lean
import Vectors.CauchySchwarz

namespace LinAlg.Vec

def LinIndep {n k : ℕ} (v : Fin k → Vec n) : Prop :=
  ∀ c : Fin k → ℝ, linComb c v = 0 → ∀ i, c i = 0

end LinAlg.Vec
----

정의를 문장 그대로 옮기면 이렇습니다 — "어떤 계수 `c`로 `v`들을 선형결합했을 때 그 결과가 영벡터라면, 그 계수는 (모든 인덱스에서) 반드시 0이어야 한다."

== 직교하는 벡터는 항상 선형독립이다

이 장의 핵심 정리는, "0이 아닌 벡터들이 서로 직교한다면, 그 벡터들은 항상 선형독립이다"입니다. 이 정리가 흥미로운 이유는, 4장에서 만든 도구(내적, 직교성)만으로 증명이 끝난다는 데 있습니다 — 새로운 개념이 필요 없습니다.

증명의 아이디어는 이렇습니다. `v₁, ..., vₖ`가 서로 직교하고 전부 0이 아니라고 합시다. 어떤 계수 `c`로 이들을 선형결합한 결과가 영벡터라고 가정합니다: `c₁v₁ + ... + cₖvₖ = 0`. 이 등식의 양변을 특정 `vⱼ`와 내적하면, 직교성 덕분에 `vⱼ`와 다른 모든 `vᵢ`(i≠j)의 내적이 0이라 왼쪽 항이 전부 사라지고 `cⱼ (vⱼ⬝vⱼ)`만 남습니다. 오른쪽은 영벡터와의 내적이므로 0입니다. 즉 `cⱼ (vⱼ⬝vⱼ) = 0`인데, `vⱼ`가 0이 아니므로 `vⱼ⬝vⱼ > 0`이고(3장의 `norm_eq_zero_iff`), 따라서 `cⱼ = 0`이어야 합니다. 이 논증을 모든 `j`에 대해 반복하면 모든 계수가 0이라는 것이 나옵니다 — 정확히 선형독립의 정의입니다.

[source,lean]
----
namespace LinAlg.Vec

theorem orthogonal_indep {n k : ℕ} (v : Fin k → Vec n)
    (hne : ∀ i, v i ≠ 0)
    (horth : ∀ i j, i ≠ j → v i ⬝ v j = 0) :
    LinIndep v := by
  intro c hzero j
  -- 양변을 v j와 내적
  have step : (linComb c v) ⬝ (v j) = (0 : Vec n) ⬝ (v j) := by rw [hzero]
  have lhs_eq : (linComb c v) ⬝ (v j) = c j * (v j ⬝ v j) := by
    show (∑ l, (∑ i, c i * v i l) * v j l) = c j * (v j ⬝ v j)
    sorry
    -- 힌트: 바깥 곱을 안으로 넣고(Finset.sum_mul) 합의 순서를 바꾸면(Finset.sum_comm)
    -- ∑ i, c i * (v i ⬝ v j) 형태가 됩니다(c i를 밖으로 빼내는 데 Finset.mul_sum을 씁니다).
    -- horth로 i ≠ j인 항이 전부 0임을 보이면 i = j인 항 c j * (v j ⬝ v j)만 남습니다.
    -- (Finset.sum_eq_single j로 마무리)
  have rhs_eq : (0 : Vec n) ⬝ (v j) = 0 := by
    show (∑ l, (0:Vec n) l * v j l) = 0
    have hz : ∀ l, (0:Vec n) l = (0:ℝ) := fun l => rfl
    simp [hz]
  rw [lhs_eq, rhs_eq] at step
  have hvj_pos : 0 < v j ⬝ v j := by
    have hnn := inner_self_nonneg (v j)
    rcases hnn.lt_or_eq with h | h
    · exact h
    · exfalso
      apply hne j
      exact (norm_eq_zero_iff (v j)).mp (by show Real.sqrt (v j ⬝ v j) = 0; rw [← h]; simp)
  exact (mul_eq_zero.mp step).resolve_right (ne_of_gt hvj_pos)

end LinAlg.Vec
----

`lhs_eq` 부분을 연습 문제(구체적인 힌트와 함께)로 남긴 이유는, 이게 정확히 "이중 합을 정리해서 한 항만 남긴다"는, 앞 장들에서 여러 번 연습한 패턴의 반복이기 때문입니다 — 2장의 `stdBasis_expansion`에서 `Finset.sum_ite_eq`로 합을 한 항으로 줄였던 것과 본질적으로 같은 기술을, 여기서는 `horth` 가정으로 대체한 것입니다. 나머지(`hvj_pos`를 이용해 `cⱼ (vⱼ⬝vⱼ) = 0`에서 `cⱼ = 0`을 끌어내는 부분)는 완전히 증명되어 있습니다 — 이게 이 정리의 "새로운" 부분이고, 3장의 `norm_eq_zero_iff`가 정확히 필요한 자리에서 재사용된다는 것을 보여줍니다.

== 기저: 선형독립이면서 전체를 생성하는 것

n개의 벡터가 선형독립이면서 동시에 (n차원 공간의) 모든 벡터를 이들의 선형결합으로 표현할 수 있다면, 이 n개의 벡터를 **기저(basis)**라 부릅니다. 2장에서 다룬 표준 기저(`stdBasis`)가 정확히 이 조건을 만족하는 가장 단순한 예입니다 — `stdBasis_expansion` 정리가 "모든 벡터를 표준 기저로 전개할 수 있다"는 것을 이미 증명했고, 표준 기저 벡터들은 서로 직교(다른 인덱스에서는 곱이 항상 0)하고 모두 0이 아니므로, 이 장의 `orthogonal_indep` 정리에 의해 자동으로 선형독립이기도 합니다.

=== 연습 문제로 남기는 것: 표준 기저가 실제로 기저임을 확인하기

[source,lean]
----
namespace LinAlg.Vec

theorem stdBasis_orthogonal {n : ℕ} (i j : Fin n) (h : i ≠ j) :
    stdBasis n i ⬝ stdBasis n j = 0 := by
  sorry -- 힌트: stdBasis 정의를 펼치면 각 항이 (i=l이고 j=l)일 때만 1*1이 되는데,
        -- i ≠ j이므로 그런 l은 존재하지 않아 모든 항이 0입니다.

theorem stdBasis_ne_zero {n : ℕ} (i : Fin n) : stdBasis n i ≠ 0 := by
  sorry -- 힌트: stdBasis n i의 i번째 성분이 1이라는 것을 보이면,
        -- 영벡터는 모든 성분이 0이므로 같을 수 없습니다.

theorem stdBasis_indep {n : ℕ} : LinIndep (stdBasis n) :=
  orthogonal_indep (stdBasis n) stdBasis_ne_zero stdBasis_orthogonal

end LinAlg.Vec
----

앞의 두 보조정리(`stdBasis_orthogonal`, `stdBasis_ne_zero`)를 채우면, `stdBasis_indep`은 이 장의 핵심 정리(`orthogonal_indep`)를 그냥 적용하는 것으로 공짜로 따라옵니다 — 여기에 `stdBasis_expansion`(2장)까지 합치면, "표준 기저는 선형독립이고 모든 벡터를 생성한다"는 기저의 두 조건이 전부 갖춰집니다.

== 이 장에서 확정한 것

* 선형독립을 "선형결합이 영벡터가 되는 유일한 방법은 모든 계수가 0인 경우뿐"이라는 정의로 세웠습니다.
* "0이 아닌 직교 벡터들은 항상 선형독립이다"라는 핵심 정리를 증명했고, 이 과정에서 4장(직교성)과 3장(`norm_eq_zero_iff`)의 도구가 그대로 재사용된다는 것을 확인했습니다.
* 표준 기저가 서로 직교하고 0이 아니므로 이 정리에 의해 자동으로 선형독립이라는 것을, 그리고 2장의 `stdBasis_expansion`과 합쳐 표준 기저가 실제로 "기저"의 두 조건을 모두 만족한다는 것을 정리했습니다.

1부 마지막 장에서는 지금까지 쌓은 도구(노름, 코시-슈바르츠)를 실제 문제 — 여러 후보 중 가장 가까운 것을 찾는 최근접 이웃 탐색 — 에 적용하고, 그 알고리즘이 실제로 올바른 답을 낸다는 것을 증명합니다.
