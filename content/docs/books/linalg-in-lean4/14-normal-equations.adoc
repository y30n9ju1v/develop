이 장은 이 책 3부에서 가장 중요한 장입니다. "잔차의 노름을 최소화하는 `x`를 어떻게 찾는가"라는 13장의 질문에, 미분을 전혀 쓰지 않고 순수하게 대수적 조작만으로 답합니다.

== 정규방정식이 말하는 것

**정규방정식(normal equations)**은 `AᵀAx = Aᵀb`라는 방정식입니다. 이 장의 핵심 정리는, `x`가 이 방정식을 만족한다면 `x`가 최소자승 문제의 해(잔차의 노름을 최소화하는 `x`)라는 것입니다.

이름이 왜 "정규방정식"인지는 기하학적으로 이해할 수 있습니다 — `Ax - b`(잔차)가 `A`의 열들이 만드는 공간과 **직교(수직, normal)**해야 한다는 조건이 정확히 `Aᵀ(Ax-b) = 0`, 즉 `AᵀAx = Aᵀb`입니다. 4장에서 다룬 직교성이 여기서 "최적의 근사"라는 개념과 직접 연결됩니다.

== 증명 전략: 완전제곱식 트릭

4장에서 코시-슈바르츠 부등식을 판별식 트릭(임의의 `t`에 대해 `‖u-tv‖² ≥ 0`)으로 증명했던 것을 기억할 겁니다. 이 장에서는 비슷한 정신의 트릭을 씁니다 — 미분으로 극값을 찾는 대신, **목적함수를 "이미 최솟값을 알고 있는 형태 + 항상 음이 아닌 항"으로 억지로 분해**합니다.

핵심 항등식은 이것입니다. `x`가 정규방정식을 만족한다고 하고, 임의의 `y`에 대해 `y = x + v`(즉 `v = y - x`)로 놓으면:

[source,text]
----
‖Ay - b‖² = ‖A(x+v) - b‖²
          = ‖(Ax - b) + Av‖²
          = ‖Ax-b‖² + 2(Ax-b)⬝(Av) + ‖Av‖²
----

여기서 가운데 항 `(Ax-b)⬝(Av)`는 `Aᵀ(Ax-b)⬝v`와 같은데(내적과 전치의 관계, 뒤에서 확인합니다), 정규방정식 가정(`Aᵀ(Ax-b) = 0`)에 의해 이 항 전체가 **모든 `v`에 대해** 0입니다. 그러면:

[source,text]
----
‖Ay - b‖² = ‖Ax-b‖² + ‖Av‖² ≥ ‖Ax-b‖²
----

마지막 부등식은 `‖Av‖² ≥ 0`(노름의 제곱은 항상 음이 아니므로)에서 바로 나옵니다. 즉 **어떤 `y`를 대입해도 `‖Ay-b‖²`는 `‖Ax-b‖²`보다 작아질 수 없습니다** — 이게 정확히 `x`가 최소자승해라는 뜻입니다.

== Lean4로 완전히 증명하기

이 전략을 그대로 옮깁니다. 먼저 내적과 전치의 관계 — `(Au)⬝w = u⬝(Aᵀw)` — 를 보조정리로 세웁니다.

[source,lean]
----
-- LeastSquares/NormalEquations.lean
import LeastSquares.Problem
import Matrices.Transpose

namespace LinAlg

theorem mulVec_inner_eq_inner_transpose_mulVec {m n : ℕ}
    (A : Mat m n) (u : Vec n) (w : Vec m) :
    (A *ᵥ u) ⬝ w = u ⬝ (Aᵀ *ᵥ w) := by
  show (∑ i, (∑ j, A i j * u j) * w i) = ∑ j, u j * (∑ i, Aᵀ j i * w i)
  simp only [Mat.transpose]
  rw [Finset.sum_comm]
  congr 1
  funext i
  rw [Finset.sum_mul, Finset.mul_sum]
  congr 1
  funext j
  ring

theorem is_least_squares_of_normal_eq {m n : ℕ} (A : Mat m n) (b : Vec m) (x : Vec n)
    (hx : (Aᵀ * A) *ᵥ x = Aᵀ *ᵥ b) : IsLeastSquaresSolution A b x := by
  intro y
  set v := y - x with hv_def
  have hy : y = x + v := by rw [hv_def]; ring_nf; module  -- y = x + (y - x)
  have key : objective A b y = objective A b x + ‖A *ᵥ v‖ ^ 2 := by
    rw [objective_eq_inner, objective_eq_inner, hy]
    have expand : A *ᵥ (x + v) - b = (A *ᵥ x - b) + A *ᵥ v := by
      sorry -- 힌트: A *ᵥ (x+v) = A*ᵥx + A*ᵥv (8장 mulVec_add)를 쓴 뒤 벡터 뺄셈/덧셈을 재배열
    rw [expand]
    have cross_zero : (A *ᵥ x - b) ⬝ (A *ᵥ v) = 0 := by
      rw [mulVec_inner_eq_inner_transpose_mulVec]
      have : Aᵀ *ᵥ (A *ᵥ x - b) = (Aᵀ * A) *ᵥ x - Aᵀ *ᵥ b := by
        sorry -- 힌트: Aᵀ *ᵥ (Ax - b) = Aᵀ*ᵥ(Ax) - Aᵀ*ᵥb (mulVec_add의 뺄셈 버전),
               -- 그리고 Aᵀ *ᵥ (A *ᵥ x) = (Aᵀ * A) *ᵥ x (행렬 곱의 결합성과
               -- 행렬-벡터 곱의 관계 — 이 자체도 짧은 보조정리로 분리할 만합니다)
      rw [this, hx]
      simp [Vec.sub_self]  -- (AᵀA)x - Aᵀb = 0 (hx로부터), 따라서 내적도 0
    -- (Ax-b + Av) ⬝ (Ax-b + Av) = (Ax-b)⬝(Ax-b) + 2*cross + (Av)⬝(Av), cross_zero로 가운데 항 소거
    sorry -- 힌트: 내적의 분배법칙을 두 번 적용해 네 항으로 펼치고,
           -- (Ax-b)⬝(Av) = (Av)⬝(Ax-b) (내적의 대칭성)까지 이용해 cross_zero를 두 번 대입
  rw [key]
  have : (0:ℝ) ≤ ‖A *ᵥ v‖ ^ 2 := sq_nonneg _
  linarith

end LinAlg
----

`mulVec_inner_eq_inner_transpose_mulVec`(전치가 내적의 양쪽 자리를 오갈 수 있게 해주는 관계)는 완전히 증명했습니다 — 9장에서 결합법칙을 증명할 때 썼던 "이중 합의 순서를 바꾼다"는 기법이 여기서 다시 등장합니다. 메인 정리(`is_least_squares_of_normal_eq`)는 전체 뼈대(`key`로 목적함수를 "최적값 + 음이 아닌 항"으로 분해하고, 그 분해에서 바로 부등식을 끌어내는 마지막 두 줄)는 완전히 짜여 있지만, `key` 안의 세부 전개(벡터 뺄셈의 재배열, 행렬 곱의 결합성과 행렬-벡터 곱의 관계, 내적의 분배법칙 적용) 세 곳을 연습 문제로 남겼습니다 — 전부 7~10장에서 이미 증명한 정리들을 조합하는 작업이라, 막힌다면 어느 장의 어느 정리가 필요한지가 힌트에 명시되어 있습니다.

== 이 정리가 증명하지 않는 것

`is_least_squares_of_normal_eq`가 증명하는 건 "정규방정식을 만족하는 `x`가 있다면, 그 `x`는 최소자승해다"라는 **충분조건**입니다. 이 정리가 증명하지 않는 것은 두 가지입니다 — 첫째, 정규방정식을 만족하는 `x`가 항상 존재하는가(`AᵀA`가 가역이 아니면 정규방정식 자체가 유일한 해를 갖지 않을 수 있습니다). 둘째, 최소자승해가 정규방정식을 만족하는 `x` 외에는 없는가(필요조건 방향). 이 두 질문에 대한 답은 `AᵀA`의 가역성에 달려 있고, 이는 5장의 선형독립과 직접 연결됩니다 — `A`의 열들이 선형독립이면 `AᵀA`가 가역이라는 것이 이 두 질문을 모두 해결하는 열쇠인데, 이 증명은 이 책의 범위를 넘어서는 더 깊은 도구(행렬식이나 계수(rank) 이론)를 요구합니다.

== 이 장에서 확정한 것

* 정규방정식(`AᵀAx = Aᵀb`)을 만족하는 `x`가 최소자승해라는 것을, 미분 없이 "목적함수를 최적값과 음이 아닌 항의 합으로 분해한다"는 순수 대수적 트릭으로 증명했습니다 — 이 트릭이 4장의 코시-슈바르츠 판별식 트릭과 같은 정신이라는 것을 확인했습니다.
* 전치가 내적의 양쪽 인자를 오갈 수 있게 하는 관계(`(Au)⬝w = u⬝(Aᵀw)`)를 9장의 "이중 합 순서 교환" 기법으로 완전히 증명했습니다.
* 이 정리가 충분조건만 다룬다는 것과, 존재성·유일성은 `AᵀA`의 가역성(궁극적으로는 5장의 선형독립)에 달려 있다는 것을 명시했습니다.

다음 장에서는 2부 마지막에서 미뤄뒀던 QR 분해를 완성하고, `AᵀA`를 직접 다루는 대신 `Q`, `R`을 이용해 정규방정식을 더 간단한 형태(`Rx = Qᵀb`)로 바꿔 푸는 방법을 다룹니다.
