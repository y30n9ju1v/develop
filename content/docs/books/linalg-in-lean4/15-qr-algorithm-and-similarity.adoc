13장에서 `2×2` 행렬은 특성방정식(`det(A-λI)=0`)을 손으로 풀어 고유값을 직접 찾았습니다. 하지만 이 방법은 `n`이 커질수록 `n×n` 행렬식과 `n`차 다항식의 근을 구하는 일이 되어 이 책이 다루지 않는 이론이 필요해지고, 실무에서도 `n`이 크면 다항식의 근을 정확히 구하는 것 자체가 수치적으로 까다롭습니다. 특성방정식을 세우지 않고도 고유값에 접근하는 실용적인 방법이 있습니다 — **QR 알고리즘**입니다. 이 알고리즘은 12장에서 다룬 그람-슈미트/QR 분해(두 벡터의 직교화와 그 결과가 `QᵀQ=I`를 만족한다는 것은 완전히 증명하고, 일반적인 k개로의 확장과 QR 분해 자체의 구현은 연습 문제·범위 밖으로 남겼습니다)를 반복 적용해서, 고유값을 정확히 계산하는 대신 점점 더 정확하게 근사합니다. 이 장이 왜 여기 있는지는 12장 끝에서 이미 예고되어 있습니다 — 12장은 QR 분해가 "왜 유용한지"를 뒤로 미뤘는데, 최소자승법이 아니라 바로 이 고유값 근사가 그 답입니다. 이 장에서 완전히 증명하는 정리("닮은 행렬은 같은 고유값을 갖는다")가 QR 알고리즘이 왜 작동하는지를 정당화하는 근거이고, 그래픽스 라이브러리와 딥러닝 프레임워크의 고유값 계산 함수(예: PCA에 쓰이는 `eig`, `svd` 계열 함수)는 대부분 이 알고리즘의 변형을 내부적으로 씁니다.

== 닮음변환: 좌표계만 바꾸는 것

두 정사각행렬 `A`, `B`가 어떤 가역행렬 `P`에 대해 `B = P⁻¹AP`를 만족하면, `A`와 `B`가 **닮음(similar)**이라 부릅니다. 14장의 대각화(`A = PDP⁻¹`, 즉 `D = P⁻¹AP`)를 이 언어로 다시 쓰면, "대각화 가능하다"는 것은 정확히 "그 행렬이 어떤 대각행렬과 닮음이다"라는 뜻입니다.

기하학적으로, 닮음변환은 `A`가 하는 일을 바꾸지 않고 **그 일을 기술하는 좌표계만 바꾸는** 연산입니다 — `P`가 좌표계를 바꾸는 행렬이라면, `B = P⁻¹AP`는 "새 좌표계로 바꾸고(`P⁻¹`), 원래 좌표계에서 `A`가 하던 일을 하고(`A`를 그 사이에 끼워 넣고), 다시 새 좌표계로 표현한다(`P`)"는 뜻입니다. 같은 변환을 다른 언어로 적은 것일 뿐이므로, 닮은 행렬끼리는 "변환 자체의 성질"(고유값이 무엇인가)이 똑같이 유지되어야 합니다 — 이걸 정확히 증명하는 것이 이 장의 핵심입니다.

[source,lean]
----
-- Eigen/Similarity.lean
import Eigen.Diagonalization

namespace LinAlg

def Mat.IsSimilarTo {n : ℕ} (A B P Pinv : Mat n n) : Prop :=
  Mat.IsLeftInverse Pinv P ∧ Mat.IsRightInverse Pinv P ∧ B = Pinv * A * P

end LinAlg
----

== 완전히 증명하는 것: 닮은 행렬은 고유값을 공유한다

`A`와 `B = P⁻¹AP`가 닮음이라고 합시다. `v`가 `A`의 고유값 `λ`에 대응하는 고유벡터라면, `P⁻¹v`는 `B`의 고유값 `λ`에 대응하는 고유벡터입니다 — **같은 고유값**이 그대로 넘어간다는 것이 핵심입니다.

[source,lean]
----
namespace LinAlg

theorem Mat.similar_shares_eigenvalue {n : ℕ} (A B P Pinv : Mat n n) (lam : ℝ) (v : Vec n)
    (hsim : Mat.IsSimilarTo A B P Pinv) (hv : A.EigenspaceMember lam v) :
    B.EigenspaceMember lam (Pinv *ᵥ v) := by
  obtain ⟨hleft, hright, hB⟩ := hsim
  show B *ᵥ (Pinv *ᵥ v) = lam • (Pinv *ᵥ v)
  rw [hB]
  have step : (Pinv * A * P) *ᵥ (Pinv *ᵥ v) = Pinv *ᵥ (A *ᵥ (P *ᵥ (Pinv *ᵥ v))) := by
    rw [Mat.mulVec_assoc, Mat.mulVec_assoc]
  rw [step]
  have collapse : P *ᵥ (Pinv *ᵥ v) = v := by
    rw [← Mat.mulVec_assoc, hright, Mat.identity_mulVec]
  rw [collapse, hv]
  exact Mat.mulVec_smul Pinv lam v

end LinAlg
----

증명의 전체 흐름은 "`B`에 `Pinv *ᵥ v`를 곱한다"는 목표를, `B`의 정의(`Pinv * A * P`)를 펼쳐 `Pinv *ᵥ (A *ᵥ (P *ᵥ (Pinv *ᵥ v)))`로 바꾸고, 가운데 `P *ᵥ (Pinv *ᵥ v)`가 `v`로 "약분"되는(`collapse`) 것을 이용해 `Pinv *ᵥ (A *ᵥ v)`로 줄인 뒤, `A`의 고유벡터 조건(`hv`)을 대입해 `Pinv *ᵥ (λ • v)`로 만들고, 마지막으로 스칼라를 밖으로 빼내는 것으로 끝납니다. 이 증명이 짧은 이유는 새로운 계산이 전혀 없기 때문입니다 — `step`은 13장에서 이미 완전히 증명한 `Mat.mulVec_assoc`(행렬 곱과 행렬-벡터 곱의 결합성)을 두 번 적용하는 것이고, `collapse`는 그 결합성을 거꾸로 적용해 `P *ᵥ (Pinv *ᵥ v)`를 `(P * Pinv) *ᵥ v`로 바꾼 뒤 `hright`(`P * Pinv = I`)와 8장의 `identity_mulVec`으로 마무리하는 것이며, 마지막 줄은 8장의 `mulVec_smul`을 그대로 호출하는 것뿐입니다.

이 정리가 뜻하는 바는 명확합니다 — **`A`의 고유값을 구하고 싶다면, `A`와 닮은 아무 행렬 `B`의 고유값을 구해도 된다**는 것입니다. 이게 QR 알고리즘의 존재 이유입니다.

== QR 알고리즘: 닮음변환을 반복해서 대각행렬에 가까워지기

QR 알고리즘의 절차는 다음과 같습니다 — 행렬 `A₀ = A`에서 시작해서, 매 단계 `Aₖ`를 12장의 QR 분해로 `Aₖ = QₖRₖ`로 쪼갠 뒤, 곱셈 순서를 뒤집은 `Aₖ₊₁ = RₖQₖ`를 다음 단계로 삼습니다.

[source,text]
----
A₀ = A
A₀ = Q₀R₀  →  A₁ = R₀Q₀
A₁ = Q₁R₁  →  A₂ = R₁Q₁
A₂ = Q₂R₂  →  A₃ = R₂Q₂
   ⋮
----

이 반복이 왜 고유값을 향해 수렴하는지 짚어볼 만합니다. `Aₖ`와 `Aₖ₊₁`이 서로 닮음이라는 게 핵심입니다 — `Aₖ = QₖRₖ`이므로 `Rₖ = Qₖᵀ Aₖ`(12장 연습 문제에서 확인했듯, `Q`가 정규직교면 `QᵀQ=I`이므로)이고, 따라서 `Aₖ₊₁ = RₖQₖ = Qₖᵀ Aₖ Qₖ`입니다 — 이건 정확히 `P = Qₖ`인 닮음변환입니다. 방금 증명한 정리에 의해 `Aₖ₊₁`은 `Aₖ`와 정확히 같은 고유값을 갖고, 이 성질이 모든 단계에서 유지되므로 `A₀, A₁, A₂, ...`는 전부 `A`와 같은 고유값을 공유합니다. 이 반복이 (적당한 조건 아래) 상삼각행렬로 수렴한다는 것이 알려져 있고, 상삼각행렬의 대각성분이 바로 그 행렬의 고유값입니다 — 즉 반복할수록 대각성분이 실제 고유값에 점점 가까워집니다. 이 수렴성 자체(극한, 상삼각행렬의 대각성분이 고유값이라는 사실)는 해석학적 도구가 필요한 별도의 정리라 이 장에서는 증명하지 않습니다 — 아래에서 확인하는 건 "왜 반복해도 안전한가"(고유값이 안 바뀐다는 대수적 근거)뿐입니다.

[source,lean]
----
namespace LinAlg

/-- QR 알고리즘 한 단계. gramSchmidt/QR 분해 자체는 12장에서 완전히 구현하지
    않았으므로, 여기서는 그 분해가 주어졌다고 가정한 상태에서 한 단계의 정의만 적습니다. -/
def qrStep {n : ℕ} (A Q R : Mat n n) (_hQR : A = Q * R) : Mat n n := R * Q

theorem qrStep_similar_to_A {n : ℕ} (A Q R Qinv : Mat n n)
    (hQR : A = Q * R) (hleft : Mat.IsLeftInverse Qinv Q) (hright : Mat.IsRightInverse Qinv Q) :
    Mat.IsSimilarTo A (qrStep A Q R hQR) Q Qinv := by
  refine ⟨hleft, hright, ?_⟩
  show qrStep A Q R hQR = Qinv * A * Q
  show R * Q = Qinv * A * Q
  sorry
  -- 힌트: hQR(A = Q*R)을 우변에 대입하면 Qinv * (Q * R) * Q가 되고,
  -- 9장의 결합법칙으로 (Qinv * Q) * R * Q로 묶은 뒤 hleft(Qinv*Q=I)와
  -- 8장/11장의 "항등행렬은 곱셈에서 사라진다"로 R * Q로 정리하면 좌변과 같아집니다.

end LinAlg
----

`qrStep_similar_to_A`가 이 절의 결론을 그대로 코드로 옮긴 것입니다 — QR 알고리즘의 한 단계가 실제로 방금 정의한 `IsSimilarTo`의 조건을 만족한다는 것을 확인하면, `similar_shares_eigenvalue`에 의해 그 단계가 고유값을 보존한다는 게 자동으로 따라옵니다.

== 이 장에서 확정한 것

* 닮음(`B = P⁻¹AP`)을 정의하고, 대각화가 "대각행렬과 닮음이다"라는 특수한 경우로 다시 읽힌다는 것을 확인했습니다.
* 닮은 행렬은 정확히 같은 고유값을 공유한다는 것을(대응하는 고유벡터는 `P⁻¹`로 옮겨진다는 것까지) 8장의 선형성과 11장의 역행렬 정의만으로 완전히 증명했습니다.
* QR 알고리즘의 한 단계(`A = QR` → `RQ`)가 실제로 닮음변환이라는 것을 확인해서, "반복해도 고유값이 보존된다"는 알고리즘의 대수적 근거를 세웠습니다 — 실제 수렴성(해석학적 사실)은 이 책의 범위 밖으로 남겼습니다.

마지막 장에서는 대칭행렬(10장에서 `AᵀA`가 항상 대칭이라는 것을 이미 증명했습니다)의 고유벡터가 서로 직교한다는 사실을 이용해, 데이터의 공분산 행렬을 고유분해해서 데이터가 가장 넓게 퍼진 방향(주성분)을 찾는 PCA를 다룹니다.
