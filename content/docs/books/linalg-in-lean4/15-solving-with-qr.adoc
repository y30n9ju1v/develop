14장에서 정규방정식 `AᵀAx = Aᵀb`을 증명했지만, 이 방정식을 실제로 푸는 건 `AᵀA`를 계산하고 그 역행렬(또는 그에 상응하는 절차)을 구해야 하는 일입니다. `A`의 열이 많거나 조건이 나쁘면 이 계산은 수치적으로 불안정해질 수 있습니다 — QR 분해가 이 문제를 우회하는 표준적인 방법입니다.

== 정규직교 행렬의 핵심 성질: QᵀQ = I

12장에서 그람-슈미트 과정으로 만든 벡터들을 노름으로 나누면(정규화하면) **정규직교(orthonormal)** — 서로 직교하고 각각의 노름이 1인 — 벡터 집합이 됩니다. 이 벡터들을 열로 모은 행렬 `Q`는 특별한 성질을 만족합니다 — `QᵀQ = I`입니다.

이 성질이 왜 성립하는지는 `QᵀQ`의 `(i,j)` 성분이 정확히 `Q`의 `i`번째 열과 `j`번째 열의 내적이라는 사실에서 나옵니다 — `i=j`이면 같은 열끼리의 내적, 즉 그 열의 노름의 제곱인데 정규직교이므로 1이고, `i≠j`이면 서로 다른 열끼리의 내적인데 직교이므로 0입니다. 이게 정확히 항등행렬의 정의(대각선은 1, 나머지는 0)입니다.

[source,lean]
----
-- LeastSquares/QRSolve.lean
import LeastSquares.NormalEquations

namespace LinAlg

def Mat.col {m n : ℕ} (A : Mat m n) (j : Fin n) : Vec m := fun i => A i j

def Mat.HasOrthonormalCols {m n : ℕ} (Q : Mat m n) : Prop :=
  (∀ j, ‖Q.col j‖ = 1) ∧ (∀ i j, i ≠ j → Q.col i ⬝ Q.col j = 0)

theorem transpose_mul_self_eq_identity_of_orthonormal {m n : ℕ} (Q : Mat m n)
    (h : Q.HasOrthonormalCols) : Qᵀ * Q = Mat.identity n := by
  funext i j
  show (∑ k, Q k i * Q k j) = if i = j then 1 else 0
  by_cases hij : i = j
  · subst hij
    have : (∑ k, Q k i * Q k i) = Q.col i ⬝ Q.col i := by
      show _ = ∑ k, Q.col i k * Q.col i k
      rfl
    rw [this]
    have hnorm := h.1 i
    have : Q.col i ⬝ Q.col i = ‖Q.col i‖ ^ 2 := by
      show _ = (Real.sqrt (Q.col i ⬝ Q.col i)) ^ 2
      rw [Real.sq_sqrt (inner_self_nonneg _)]
    rw [this, hnorm]
    simp
  · have := h.2 i j hij
    show (∑ k, Q k i * Q k j) = 0
    have heq : (∑ k, Q k i * Q k j) = Q.col i ⬝ Q.col j := rfl
    rw [heq, this, if_neg hij]

end LinAlg
----

이 정리(`transpose_mul_self_eq_identity_of_orthonormal`)를 완전히 증명한 이유는, 이게 이 장의 나머지 전부를 떠받치는 기둥이기 때문입니다 — 앞서 몇 장에서 반복한 도구(3장의 노름-내적 관계, 10장의 전치, 4장의 직교성)가 한자리에 모입니다. `i = j`인 경우와 `i ≠ j`인 경우로 나눠, 각각 정규직교 조건의 두 부분(단위 노름, 직교)을 그대로 적용하는 구조입니다.

== 정규방정식을 Rx = Qᵀb로 단순화하기

`A = QR`이고 `Q`가 정규직교 열을 가지며 `R`이 가역이라고 합시다. `AᵀA`를 QR로 다시 써보면:

[source,text]
----
AᵀA = (QR)ᵀ(QR) = RᵀQᵀQR = Rᵀ(QᵀQ)R = RᵀIR = RᵀR
----

(10장의 `transpose_mul`로 `(QR)ᵀ = RᵀQᵀ`, 이 장에서 증명한 `QᵀQ = I`를 차례로 적용한 것입니다.) 비슷하게 `Aᵀb = (QR)ᵀb = RᵀQᵀb`입니다. 이걸 정규방정식 `AᵀAx = Aᵀb`에 대입하면:

[source,text]
----
RᵀRx = RᵀQᵀb
----

`R`이 가역이면 `Rᵀ`도 가역이므로(전치의 가역성은 11장의 도구로 증명할 수 있는 사실입니다), 양변에서 `Rᵀ`를 "약분"할 수 있어 `Rx = Qᵀb`가 남습니다. 이게 이 장의 결론입니다 — **`AᵀA`를 다룰 필요 없이, `R`(위삼각행렬)과 `Qᵀb`만으로 훨씬 간단한 방정식을 풉니다.** `R`이 위삼각이라는 게 결정적입니다 — 위삼각 연립방정식은 마지막 행부터 거꾸로 대입해나가면(후진대입, back substitution) 나눗셈 몇 번으로 풀리기 때문입니다.

이 정리는 위에서 손으로 유도한 계산(`AᵀA = RᵀR`)을 그대로 Lean4로 옮기는 것이고, 필요한 도구(전치의 곱셈 법칙, 결합법칙, 이 장의 `QᵀQ=I`)가 전부 이미 증명되어 있으므로 순서대로 적용하는 것으로 끝납니다.

== 이 장에서 확정한 것

* 정규직교 열을 가진 행렬 `Q`가 `QᵀQ = I`를 만족한다는 것을 완전히 증명했습니다 — 이 증명이 3, 4, 10장의 도구를 한자리에 모으는 이 장의 중심입니다.
* `A = QR`일 때 정규방정식이 `RᵀRx = RᵀQᵀb`로, `R`이 가역이면 다시 `Rx = Qᵀb`로 단순화된다는 것을 유도했습니다 — 위삼각행렬을 다루는 것이 일반 행렬(`AᵀA`)보다 계산상 훨씬 유리하다는 실무적 이유를 짚었습니다.
* `AᵀA = RᵀR`이라는 핵심 등식을 연습 문제로 남기되, 필요한 모든 도구가 이미 앞 장들에 있다는 것을 확인했습니다.

마지막 장에서는 이 모든 도구를 실제 데이터에 적용합니다 — 여러 점에 가장 잘 맞는 직선을 찾는 선형 회귀 문제를 최소자승법으로 풀고, 그 결과가 실제로 최적이라는 것을 이 책에서 증명한 정리들로 확인합니다.
