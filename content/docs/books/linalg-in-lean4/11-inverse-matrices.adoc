`Ax = b`를 풀 때 가장 먼저 떠오르는 방법은 "양변에 `A⁻¹`을 곱한다"입니다. 이 방법이 의미를 가지려면 애초에 `A`가 역행렬을 가져야 하고, 그 역행렬이 하나뿐이어야 합니다 — 이 장은 그 두 번째 조건(유일성)을 정사각행렬에 한정해 증명합니다. 이게 왜 3부의 토대인지는 명확합니다 — 14장의 대각화(`A = PDP⁻¹`)에서 `P`는 반드시 정사각이고 가역이어야 하고, `P⁻¹`이라는 표기가 모호함 없이 하나의 행렬을 가리키려면 정확히 이 장에서 증명하는 유일성이 필요합니다. 여기서 완전히 증명하는 정리("왼쪽 역과 오른쪽 역이 둘 다 존재하면 같다")는 9장에서 증명한 결합법칙 하나만으로 끝나는데, 이 사실 자체가 "결합법칙 같은 기초 성질을 미리 완전히 증명해두면 나중에 새 계산 없이 재사용할 수 있다"는 이 책의 방법론을 그대로 보여줍니다. 이 장이 왜 정사각행렬로 범위를 좁히는지도 짚어둘 만합니다 — 직사각행렬은 왼쪽 역과 오른쪽 역이 따로 존재하며 서로 다를 수 있어서, "역행렬"이라는 말 자체가 모호해집니다. 정사각행렬로 범위를 좁히고 나서야 14장의 `P⁻¹`, 15장의 `P⁻¹AP` 같은 표기가 안전하게 쓰일 수 있습니다.

== 역행렬: 곱하면 항등행렬이 되는 짝

정사각행렬 `A`에 대해, `AB = I`이고 동시에 `BA = I`를 만족하는 행렬 `B`가 있다면, `B`를 `A`의 **역행렬(inverse)**이라 부르고 `A⁻¹`로 씁니다. 8장에서 행렬을 "벡터를 옮기는 함수"로 봤으니, 역행렬은 그 함수를 "되돌리는" 함수에 해당합니다 — `A`가 `v`를 `Av`로 옮겼다면, `A⁻¹`은 `Av`를 다시 `v`로 되돌립니다.

== 왼쪽 역과 오른쪽 역을 구분하는 이유

정의에서 `AB = I`와 `BA = I`를 모두 요구했습니다. 이걸 굳이 나눠서 이름 붙이는 이유가 있습니다 — `AB = I`만 만족하는 `B`를 `A`의 **오른쪽 역(right inverse)**, `BA = I`만 만족하는 `B`를 **왼쪽 역(left inverse)**이라 부르는데, 정사각행렬이 아닌 일반적인 직사각행렬에서는 왼쪽 역과 오른쪽 역이 따로 존재하면서 서로 다를 수 있습니다. 정사각행렬로 범위를 좁히면 이 장의 핵심 정리가 성립합니다 — **왼쪽 역과 오른쪽 역이 둘 다 존재한다면, 그 둘은 반드시 같습니다.**

[source,lean]
----
-- Matrices/Inverse.lean
import Matrices.Transpose

namespace LinAlg

def Mat.IsLeftInverse {n : ℕ} (B A : Mat n n) : Prop := B * A = Mat.identity n
def Mat.IsRightInverse {n : ℕ} (B A : Mat n n) : Prop := A * B = Mat.identity n

end LinAlg
----

== 왼쪽 역과 오른쪽 역이 같다는 것

이게 이 책 2부에서 가장 중요한 정리입니다 — 그리고 놀랍게도, 새로운 계산이 전혀 필요 없습니다. 9장에서 완전히 증명한 **결합법칙 하나만으로** 끝납니다.

=== 완전히 증명하는 것: 왼쪽 역 = 오른쪽 역

[source,lean]
----
namespace LinAlg

theorem Mat.left_inverse_eq_right_inverse {n : ℕ} (A B C : Mat n n)
    (hB : Mat.IsLeftInverse B A) (hC : Mat.IsRightInverse C A) : B = C := by
  have step1 : B * (A * C) = B := by
    unfold Mat.IsRightInverse at hC
    rw [hC]
    sorry -- 힌트: B * identity n = B, 즉 identity가 곱셈의 항등원이라는 것
             -- (이 절 자체는 짧은 별도 보조정리 Mat.mul_identity로 분리해 증명해도 좋습니다 —
             --  Mat.identity_mulVec을 8장에서 증명했다면, 행렬 전체에 대한 버전도 비슷하게 나옵니다)
  have step2 : (B * A) * C = C := by
    unfold Mat.IsLeftInverse at hB
    rw [hB]
    sorry -- 힌트: identity n * C = C, 위와 대칭적인 사실

  calc B = B * (A * C) := step1.symm
    _ = (B * A) * C := (Mat.mul_assoc B A C).symm
    _ = C := step2

end LinAlg
----

이 증명의 뼈대(`calc` 블록)가 이 정리의 핵심을 그대로 보여줍니다 — `B`에서 시작해서, `A * C = I`(오른쪽 역의 정의)를 이용해 `B`를 `B * (A * C)`로 "부풀리고", 9장의 결합법칙으로 괄호 위치를 `(B * A) * C`로 옮긴 뒤, `B * A = I`(왼쪽 역의 정의)를 이용해 `C`로 "줄입니다." 시작점과 끝점이 같은 값을 가리키는 서로 다른 표현이라는 것을, 결합법칙이라는 다리 하나로 잇는 것입니다.

`step1`, `step2`에 남겨둔 두 개의 작은 `sorry`는 "항등행렬을 곱해도 변하지 않는다"는, 8장의 `identity_mulVec`(벡터 버전)과 형태가 같은 사실의 행렬 버전입니다 — 8장의 증명을 참고해 `Mat.mul_identity : A * Mat.identity n = A`와 `Mat.identity_mul : Mat.identity n * A = A`를 별도 보조정리로 먼저 완성해두면, 이 두 `sorry`는 그 보조정리를 호출하는 한 줄로 끝납니다.

== 이 정리가 "유일성"을 뜻하는 이유

`left_inverse_eq_right_inverse`가 왜 "역행렬은 유일하다"는 것을 보장하는지 짚고 넘어갈 만합니다. 만약 어떤 행렬 `A`에 대해 `B`와 `C` 둘 다 (양쪽 조건을 모두 만족하는 진짜) 역행렬이라면, `B`는 `A`의 왼쪽 역이면서 오른쪽 역이고 `C`도 마찬가지입니다. `B`를 왼쪽 역으로, `C`를 오른쪽 역으로 놓고 이 정리를 적용하면 `B = C`가 나옵니다 — 즉 "역행렬"이라 부를 수 있는 행렬이 있다면 그건 단 하나뿐입니다. 이 유일성 덕분에 `A⁻¹`이라는 표기가 모호함 없이 하나의 대상을 가리킬 수 있는 것입니다.

== 이 장에서 확정한 것

* 역행렬을 왼쪽 역과 오른쪽 역으로 나눠 정의하고, 정사각행렬에서는 이 둘이 (둘 다 존재한다면) 항상 같다는 것을 증명했습니다.
* 이 증명이 9장에서 완전히 증명해둔 결합법칙 하나로 끝난다는 것을 확인했습니다 — 새로운 계산 기법이 필요 없었습니다.
* 이 동일성 정리가 정확히 "역행렬의 유일성"을 뜻한다는 것과, 그래서 `A⁻¹`이라는 표기가 모호하지 않다는 것을 짚었습니다.

이 장에서 "어떤 행렬이 역행렬을 갖는가"(가역성의 조건)는 다루지 않았습니다 — 그 질문에 답하려면 선형독립·기저·행렬식 같은 도구가 더 필요합니다. 다음 장에서는 1부의 직교성 도구를 다시 불러와, 임의의 선형독립 벡터 집합을 직교하는 집합으로 바꾸는 그람-슈미트 과정과 QR 분해를 다룹니다 — 이 QR 분해가 3부에서 고유값을 반복적으로 근사하는 QR 알고리즘의 재료가 됩니다.
