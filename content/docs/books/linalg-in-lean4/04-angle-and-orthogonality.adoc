이 장은 이 책 1부에서 가장 중요한 장입니다. 코시-슈바르츠 부등식 하나가 "두 벡터 사이의 각도"라는 개념을 정당화하고, 삼각부등식(노름이 실제로 "거리"라 부를 자격이 있다는 것)을 낳고, 뒤에서 직교성과 선형독립을 다룰 때도 계속 재사용됩니다.

== 코시-슈바르츠 부등식이 말하는 것

두 벡터 `u`, `v`의 내적의 절댓값은, 각 벡터의 노름을 곱한 것을 절대 넘지 않습니다 — `|u ⬝ v| ≤ ‖u‖ ‖v‖`. 직관적으로는 "두 벡터가 완전히 같은 방향을 향할 때 내적이 최대가 되고, 그 최댓값이 두 노름의 곱을 넘어설 수 없다"는 뜻입니다.

이 부등식이 다루는 상황을 그림으로 먼저 그려보면 뒤의 대수적 증명이 왜 그런 형태를 띠는지 짐작하기 쉬워집니다. `u`를 `v` 방향과 `v`에 수직인 방향으로 분해한다고 생각해보세요 — `v` 방향 성분의 길이가 길수록 두 벡터는 "같은 방향에 가깝다"는 뜻이고, 내적은 정확히 이 성분의 크기(부호 포함)를 재는 양입니다.

[source,text]
----
        u
        ^
       /|
      / |  (v에 수직인 성분 — u가 v와 얼마나 "다른 방향"인지)
     /  |
    /θ  |
   +----+------> v
   (v 방향 성분 — u⬝v/‖v‖, 이 길이가 클수록 u와 v가 같은 방향에 가까움)
----

`θ`가 `u`와 `v` 사이의 각도입니다. `u`가 `v`와 완전히 같은 방향(θ=0)이면 수직 성분이 사라지고 내적이 `‖u‖‖v‖`로 최대가 되며, `u`가 `v`와 직교(θ=90°)하면 `v` 방향 성분이 0이 되어 내적도 0이 됩니다. 코시-슈바르츠 부등식은 이 둘 사이의 모든 각도에서 내적이 항상 이 최댓값 `‖u‖‖v‖`를 넘지 않는다는 것을 정확히 포착합니다 — 뒤에서 볼 판별식 트릭은 이 그림을 "`u`에서 `v` 방향 성분을 변수 `t`로 스칠하며 뺀 나머지의 길이는 항상 0 이상이다"라는 대수 식으로 옮긴 것입니다.

이 부등식이 중요한 이유는, 이게 있어야 "각도"라는 개념을 실수 벡터에 정의할 수 있기 때문입니다 — 두 벡터 사이의 각도를 `cos θ = (u ⬝ v) / (‖u‖ ‖v‖)`로 정의하고 싶은데, 코사인 값은 항상 -1과 1 사이여야 합니다. 코시-슈바르츠 부등식이 정확히 이 우변이 -1과 1 사이에 있다는 것을 보장합니다 — 이 부등식 없이는 "각도"라는 정의 자체가 성립하지 않습니다.

== 증명 전략: 판별식 트릭

코시-슈바르츠 부등식을 증명하는 여러 방법이 있는데, 이 책에서는 "판별식 트릭"이라 불리는 고전적인 방법을 씁니다. 임의의 실수 `t`에 대해 `‖u - t•v‖² ≥ 0`이 항상 성립합니다(노름의 제곱은 절대 음수가 될 수 없으므로). 이 식을 `t`에 대한 이차식으로 펼치면:

[source,text]
----
‖u - t•v‖² = (u - t•v) ⬝ (u - t•v)
           = u⬝u - 2t(u⬝v) + t²(v⬝v)
           = ‖v‖² · t² - 2(u⬝v) · t + ‖u‖²
----

이건 `t`에 대한 이차식 `A t² + B t + C` (A = `‖v‖²`, B = `-2(u⬝v)`, C = `‖u‖²`)이고, 이 값이 모든 `t`에 대해 0 이상이려면 판별식 `B² - 4AC`가 0 이하여야 합니다(만약 판별식이 양수라면 이차식이 두 실근을 가져서 그 사이에서 음수가 되는 `t`가 존재하기 때문입니다). 판별식 조건을 풀면:

[source,text]
----
B² - 4AC ≤ 0
4(u⬝v)² - 4‖v‖²‖u‖² ≤ 0
(u⬝v)² ≤ ‖u‖²‖v‖²
----

양변에 제곱근을 취하면 `|u⬝v| ≤ ‖u‖‖v‖`가 나옵니다 — 이게 코시-슈바르츠 부등식입니다.

== Lean4로 완전히 증명하기

이 전략을 그대로 Lean4로 옮깁니다. 다만 "판별식이 0 이하다"를 직접 다루는 대신, 특정 `t`값 하나(`v⬝v ≠ 0`일 때 `t = (u⬝v)/(v⬝v)`)를 그 이차식에 대입해서 바로 원하는 부등식을 끌어내는 것이 Lean4 증명에서는 더 짧습니다 — 판별식 공식을 일반적으로 세우는 것보다, "이 이차식이 최소가 되는 지점에서 이미 부등식이 나온다"는 것을 직접 계산으로 보여주는 편이 자연스럽습니다.

[source,lean]
----
-- Vectors/CauchySchwarz.lean
import Vectors.InnerProduct

namespace LinAlg.Vec

theorem inner_mul_inner_self_le {n : ℕ} (u v : Vec n) :
    (u ⬝ v) ^ 2 ≤ (u ⬝ u) * (v ⬝ v) := by
  rcases eq_or_ne (v ⬝ v) 0 with hv | hv
  · -- v ⬝ v = 0이면 v = 0 (3장의 norm_eq_zero_iff에서 이미 증명), 그러면 u ⬝ v = 0
    have hv0 : v = 0 := by
      have := (norm_eq_zero_iff v).mp (by
        show Real.sqrt (v ⬝ v) = 0
        rw [hv]; exact Real.sqrt_zero)
      exact this
    subst hv0
    simp [inner]
  · -- v ⬝ v ≠ 0인 일반적인 경우: t = (u⬝v)/(v⬝v)를 대입한 non-negativity에서 유도
    have key : 0 ≤ (u ⬝ u) - (u ⬝ v)^2 / (v ⬝ v) := by
      have expand : (u ⬝ u) - (u ⬝ v)^2 / (v ⬝ v) =
          (‖u - ((u ⬝ v) / (v ⬝ v)) • v‖)^2 := by
        show _ = (u - ((u ⬝ v) / (v ⬝ v)) • v) ⬝ (u - ((u ⬝ v) / (v ⬝ v)) • v)
        unfold inner
        simp only [smul_eq_mul]
        field_simp
        ring
      rw [expand]
      exact sq_nonneg _
    have hvv : 0 < v ⬝ v := lt_of_le_of_ne (inner_self_nonneg v) (Ne.symm hv)
    have step : (u ⬝ v)^2 / (v ⬝ v) ≤ u ⬝ u := by linarith
    calc (u ⬝ v)^2 = (u ⬝ v)^2 / (v ⬝ v) * (v ⬝ v) := by field_simp
      _ ≤ (u ⬝ u) * (v ⬝ v) := by
          apply mul_le_mul_of_nonneg_right step (le_of_lt hvv)

theorem abs_inner_le_norm_mul_norm {n : ℕ} (u v : Vec n) :
    |u ⬝ v| ≤ ‖u‖ * ‖v‖ := by
  have h := inner_mul_inner_self_le u v
  have hu : ‖u‖ = Real.sqrt (u ⬝ u) := rfl
  have hv : ‖v‖ = Real.sqrt (v ⬝ v) := rfl
  rw [hu, hv, ← Real.sqrt_mul (inner_self_nonneg u)]
  rw [← Real.sqrt_sq_eq_abs]
  apply Real.sqrt_le_sqrt
  exact h

end LinAlg.Vec
----

`inner_mul_inner_self_le`가 이 장의 핵심 증명입니다. `v ⬝ v = 0`인 경우(즉 `v`가 영벡터인 경우)와 그렇지 않은 경우로 나누는데, 전자는 3장에서 증명한 `norm_eq_zero_iff`를 바로 재사용해서 몇 줄로 끝납니다 — 앞 장의 정리가 이 장에서 그대로 부품으로 쓰이는 첫 사례입니다. 후자(일반적인 경우)에서 `expand` 부분이 판별식 트릭의 핵심입니다 — "`‖u - t•v‖²`을 전개하면 `u⬝u - (u⬝v)²/(v⬝v)`가 된다"는 대수적 항등식을 `field_simp`와 `ring`으로 확인하고, 좌변이 노름의 제곱(`sq_nonneg`에 의해 항상 0 이상)이라는 사실에서 원하는 부등식을 끌어냅니다. 그다음 `abs_inner_le_norm_mul_norm`은 이 결과에 제곱근을 씌워 최종 형태로 바꾸는, 비교적 기계적인 마무리입니다.

== 삼각부등식: 코시-슈바르츠의 첫 번째 보상

코시-슈바르츠 부등식을 증명해두면, "두 벡터의 합의 노름은 각 노름의 합을 넘지 않는다"는 삼각부등식(`‖u + v‖ ≤ ‖u‖ + ‖v‖`)이 몇 줄 만에 따라옵니다. 이 부등식이 있어야 노름이 진짜 "거리"라 부를 자격을 얻습니다 — 두 지점을 곧장 잇는 경로가, 다른 지점을 거쳐 돌아가는 경로보다 항상 짧거나 같다는 성질이기 때문입니다.

=== 연습 문제로 남기는 것: 삼각부등식

[source,lean]
----
namespace LinAlg.Vec

theorem norm_add_le {n : ℕ} (u v : Vec n) : ‖u + v‖ ≤ ‖u‖ + ‖v‖ := by
  sorry
  -- 힌트: ‖u+v‖² = ‖u‖² + 2(u⬝v) + ‖v‖² (내적 전개)
  --      ≤ ‖u‖² + 2‖u‖‖v‖ + ‖v‖²   (코시-슈바르츠: u⬝v ≤ |u⬝v| ≤ ‖u‖‖v‖)
  --      = (‖u‖ + ‖v‖)²
  --  양변이 음이 아니므로 제곱근을 취해도 부등식 방향이 유지됩니다 (Real.sqrt_le_sqrt, 또는
  --  pow_le_pow_left의 역방향 — sq_le_sq'나 abs_le_abs 계열 정리를 찾아보세요).

end LinAlg.Vec
----

이 증명의 뼈대는 본문에 전부 있습니다 — `‖u+v‖²`를 전개해서 코시-슈바르츠가 정확히 필요한 자리에 어떻게 들어가는지 확인하는 것이 핵심입니다. 막힌다면 먼저 `‖u+v‖² ≤ (‖u‖+‖v‖)²`까지만(제곱근을 씌우기 전 단계) 별도로 증명해보고, 그다음 양변에 제곱근을 씌우는 마무리 단계를 분리해서 접근하는 것을 권합니다.

== 직교성: 각도가 정확히 90도인 경우

두 벡터의 내적이 0이면, 그 둘을 **직교(orthogonal)**한다고 부릅니다. `cos θ = (u⬝v)/(‖u‖‖v‖)`였으니, 내적이 0이면 각도가 90도(코사인이 0)라는 것과 일치합니다.

[source,lean]
----
namespace LinAlg.Vec

def IsOrthogonal {n : ℕ} (u v : Vec n) : Prop := u ⬝ v = 0

/-- 직교하는 두 벡터의 합의 노름 제곱은, 각 노름 제곱의 합과 같습니다 (피타고라스 정리). -/
theorem norm_sq_add_of_orthogonal {n : ℕ} (u v : Vec n) (h : IsOrthogonal u v) :
    ‖u + v‖ ^ 2 = ‖u‖ ^ 2 + ‖v‖ ^ 2 := by
  show (u + v) ⬝ (u + v) = u ⬝ u + v ⬝ v
  unfold inner IsOrthogonal at *
  simp only [Vec.add]
  sorry  -- 힌트: (u+v)⬝(u+v)를 전개하면 u⬝u + 2(u⬝v) + v⬝v가 나오고, h로 u⬝v = 0을 대입하면 끝

end LinAlg.Vec
----

이 정리의 이름이 이미 답을 말해줍니다 — **피타고라스 정리**입니다. 직교하는 두 변으로 이루어진 직각삼각형에서 빗변의 제곱이 두 변의 제곱의 합과 같다는, 학교에서 배운 그 정리가 여기서는 임의의 `n`차원 벡터에 대한 명제로 다시 등장합니다. 증명의 실질적인 내용은 `(u+v)⬝(u+v)`를 전개해서 `u⬝u + 2(u⬝v) + v⬝v`를 얻고, 여기에 직교 가정(`u⬝v = 0`)을 대입하는 것뿐입니다 — 3장에서 다뤘던 내적 전개 패턴의 재사용입니다.

== 이 장에서 확정한 것

* 코시-슈바르츠 부등식(`|u⬝v| ≤ ‖u‖‖v‖`)을 판별식 트릭으로 완전히 증명했습니다 — 이 증명이 "임의의 t에 대해 노름의 제곱이 음이 아니다"라는 사실에서 출발해, 특정 t값을 대입하는 것만으로 끝난다는 것을 확인했습니다.
* 이 부등식이 있어야 두 벡터 사이의 각도(코사인)가 -1과 1 사이의 값으로 정의될 수 있다는 것을 짚었습니다.
* 삼각부등식과 피타고라스 정리(직교하는 벡터의 노름 제곱 덧셈 법칙)를 연습 문제로 남기되, 둘 다 코시-슈바르츠와 내적 전개라는 이미 확보한 도구로 몇 단계 만에 도달한다는 것을 확인했습니다.
