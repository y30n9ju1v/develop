이 책의 마지막 장입니다. 1부의 벡터, 2부의 행렬, 3부의 최소자승 정리를 실제 문제 — 데이터에 직선을 맞추는 선형 회귀 — 에 적용합니다.

== 문제 설정: k개의 점에 직선 맞추기

`k`개의 데이터 점 `(x₁,y₁), ..., (xₖ,yₖ)`이 있을 때, `y = a + bx` 형태의 직선 중 이 점들에 "가장 잘 맞는" 것을 찾고 싶습니다. 로봇 예제로 보면, 배터리 잔량(`x`)과 남은 주행 가능 거리(`y`)를 여러 번 측정한 데이터에서, 배터리 잔량으로 주행 거리를 예측하는 선형 모델을 만드는 상황입니다.

미지수는 절편 `a`와 기울기 `b`, 두 개뿐입니다. 이걸 `x = (a, b)`라는 2차원 벡터로 묶고, "이 점이 직선 위에 있다"는 조건 `a + bxᵢ = yᵢ`를 행렬 형태로 쓰면:

[source,text]
----
⎡1  x₁⎤        ⎡y₁⎤
⎢1  x₂⎥ ⎡a⎤    ⎢y₂⎥
⎢⋮  ⋮ ⎥ ⎣b⎦ =  ⎢⋮ ⎥
⎣1  xₖ⎦        ⎣yₖ⎦
----

즉 `Ax = y`인데, `A`는 `k×2` 행렬(첫 열은 전부 1, 둘째 열은 `xᵢ`들), `x = (a,b)`, `y`는 측정값 벡터입니다. `k`개의 점이 정확히 한 직선 위에 있지 않는 한(실제 측정 데이터라면 거의 항상 그렇습니다), 이건 13장에서 다룬 과결정계입니다 — 정확한 해는 없고, 최소자승해를 찾아야 합니다.

[source,lean]
----
-- LeastSquares/LinearRegression.lean
import LeastSquares.QRSolve

namespace LinAlg

def regressionMatrix {k : ℕ} (xs : Fin k → ℝ) : Mat k 2 :=
  fun i j => if j = 0 then 1 else xs i

def fitLine {k : ℕ} (xs : Fin k → ℝ) (ys : Fin k → ℝ) (a b : ℝ) : Prop :=
  IsLeastSquaresSolution (regressionMatrix xs) ys (fun j => if j = 0 then a else b)

end LinAlg
----

== 구체적인 세 점으로 확인하기

일반적인 `k`에 대해 최소자승해의 공식(`a`, `b`를 `x`, `y` 값들의 평균·분산·공분산으로 표현하는 닫힌 형태)을 유도하는 건 이 책의 범위를 넘어서는 대수적 전개가 필요합니다. 대신 이 책 전체가 그래왔듯, 구체적인 작은 예로 지금까지 증명한 정리가 실제로 어떻게 맞물리는지 확인합니다.

세 점 `(0, 1), (1, 2), (2, 4)`가 있다고 합시다. 정확히 한 직선 위에 있지 않다는 걸 바로 알 수 있습니다 — 처음 두 점을 잇는 직선(`y = 1 + x`)은 세 번째 점에서 `y = 3`을 예측하지만 실제 값은 4입니다.

[source,lean]
----
namespace LinAlg

def sampleXs : Fin 3 → ℝ | 0 => 0 | 1 => 1 | 2 => 2
def sampleYs : Fin 3 → ℝ | 0 => 1 | 1 => 2 | 2 => 4

-- 정규방정식 AᵀA x = Aᵀy 를 이 구체적인 A, y에 대해 직접 계산하면
-- (실수 성분을 손으로 계산하거나 #eval로 근사할 수 있습니다):
--   AᵀA = ⎡3  3⎤   Aᵀy = ⎡7⎤
--         ⎣3  5⎦          ⎣10⎦
-- 이 2×2 선형계를 풀면 a = 5/6, b = 3/2 (직접 대입해 검산 가능:
-- 3*(5/6) + 3*(3/2) = 2.5 + 4.5 = 7 ✓, 3*(5/6) + 5*(3/2) = 2.5 + 7.5 = 10 ✓).

theorem sample_normal_equations_solution_is_optimal (a b : ℝ)
    (h : (regressionMatrix sampleXs)ᵀ * (regressionMatrix sampleXs) *ᵥ (fun j => if j = 0 then a else b)
       = (regressionMatrix sampleXs)ᵀ *ᵥ sampleYs) :
    fitLine sampleXs sampleYs a b :=
  is_least_squares_of_normal_eq (regressionMatrix sampleXs) sampleYs _ h

end LinAlg
----

[NOTE]
====
`AᵀA`와 `Aᵀy`의 실제 숫자 성분을 손으로 정확히 계산해 `a`, `b`의 닫힌 형태 값을 구하고 그 값이 실제로 `h`의 가설을 만족한다는 것(2×2 선형계를 실제로 풀어 확인하는 것)은 이 장의 연습 문제로 남깁니다 — 계산 자체는 2×2 역행렬 공식이나 직접 대입 소거로 끝나는 초등적인 작업이지만, 정확한 값을 여기 지면에 확정적으로 적으려면 실제로 손이나 `#eval`로 재검산해야 하므로, 위 주석에 계산 과정의 자리만 남겨뒀습니다.
====

`sample_normal_equations_solution_is_optimal`이 이 장에서, 그리고 이 책 전체에서 가장 중요하게 보여주고 싶었던 지점입니다 — **이 정리는 새로운 증명이 아닙니다.** 14장에서 완전히 증명한 `is_least_squares_of_normal_eq`를 `regressionMatrix sampleXs`라는 구체적인 행렬에 그대로 적용한 것뿐입니다. "선형 회귀가 최적의 직선을 찾는다"는, 데이터 과학에서 당연하게 받아들여지는 사실이, 사실은 이 책 1부(노름, 코시-슈바르츠)와 2부(행렬 곱셈, 전치)와 3부(정규방정식)의 정리들이 정확히 이 지점에서 만나 이뤄낸 결과라는 것을 확인하는 것이 이 마지막 장의 목적입니다.

== 이 책 전체를 돌아보며

1장에서 벡터의 덧셈이 교환법칙을 만족한다는, 거의 자명해 보이는 사실을 증명하는 것부터 시작했습니다. 그 짧은 증명에서 세운 패턴(`funext`로 성분에 대한 명제로 좁히고, 실수의 성질로 환원한다)이 2부의 행렬로, 3부의 최소자승법으로 계속 재사용됐습니다. 코시-슈바르츠 부등식(4장)은 각도라는 개념을 정당화했을 뿐 아니라, 정규방정식(14장)의 증명 전략(완전제곱식 트릭) 자체에 영감을 줬습니다. 표준 기저 전개(2장)는 항등행렬의 성질(8장)로, 다시 정규직교 행렬의 성질(15장)로 형태를 바꿔가며 반복해서 등장했습니다.

이 책이 보여주고 싶었던 건 결국 하나입니다 — 선형대수의 정리들은 서로 동떨어진 사실의 나열이 아니라, 소수의 근본적인 아이디어(성분별 연산은 실수의 성질로 환원된다, 노름의 제곱은 항상 음이 아니다, 직교성은 최적성과 연결된다)가 문맥을 바꿔가며 계속 재등장하는 하나의 그물입니다. 그 그물의 매듭 하나하나를 Lean4로 직접 묶어보는 것이, "선형대수를 안다"는 것의 의미를 다시 세우는 이 책의 방법이었습니다.
