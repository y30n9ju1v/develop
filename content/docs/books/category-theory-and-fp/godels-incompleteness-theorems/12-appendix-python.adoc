'''

이 부록은 본문 이해에 필수가 아닙니다 — 건너뛰어도 책의 내용을 이해하는 데 전혀 지장이 없습니다.

하지만 6장에서 배운 **"문장틀에 자기 자신의 번호를 채워 넣어 스스로를 가리킨다"**는 기막힌 아이디어가, 현대 컴퓨터에서 **실제로 작동하는 프로그램으로 완벽히 구현된다는 사실을 눈으로 확인**하는 것은 대단히 흥미진진한 경험입니다.

실행하면 **자신의 소스 코드 전체를 한 글자도 틀리지 않고 그대로 화면에 출력하는 프로그램**, 즉 **쿼인(Quine)**을 파이썬으로 직접 작성해 봅시다.

== 쿼인의 핵심 발상: 6장의 사진 비유 재현하기

6장에서 우리는 사진사가 "방 안의 빈 액자 구도(틀)"를 잡고, 그 사진을 인화해 "액자에 채워 넣는" 방식으로 사진 속의 사진을 연출했던 것을 보았습니다.

파이썬 쿼인도 정확히 이 2단계 구조로 만듭니다.

....
                   [ 파이썬 쿼인의 2단계 구조 ]

   【1단계: 템플릿 문자열 준비 (문장틀)】
    • 변수 s에 "출력할 코드의 뼈대"를 문자열 데이터로 담아둔다.
    (문자열 안에는 데이터를 끼워 넣을 '%r'이라는 빈칸이 뚫려 있음)
                         │
                         ▼
   【2단계: 틀 자신을 빈칸에 대입하기 (대각선화)】
    • print(s % s)를 실행하여, 템플릿 s의 빈칸 자리에
      다름 아닌 's 문자열 자기 자신'을 채워 넣어 화면에 출력한다
....

== 단 2줄의 마법: 파이썬 쿼인 코드

[source,python]
----
s = 's = %r\nprint(s %% s)'
print(s % s)
----

이 짧은 코드를 찬찬히 뜯어봅시다.

1. `s = '...'`: 변수 `s`에는 전체 소스 코드의 골격이 들어있습니다. 여기서 `%r`은 "이 자리에 문자열을 따옴표까지 포함해서 그대로 넣어라"는 파이썬의 서식 지정자입니다 (빈 액자 틀).
2. `print(s % s)`: 템플릿 `s`의 `%r` 자리에 **자기 자신(`s`)**을 쏙 집어넣어 출력합니다

== 실제로 실행해서 원본과 비교해보기

이 코드를 `quine.py`라는 파일로 저장하고, 터미널에서 실행한 출력을 `quine_output.py`로 저장한 뒤 두 파일의 차이점을 검사(`diff`)해 봅시다.

[source,bash]
----
$ python3 quine.py > quine_output.py
$ diff quine.py quine_output.py
(아무런 차이점도 출력되지 않음)
----

`diff` 명령어가 아무것도 출력하지 않았습니다 즉, **프로그램이 실행되어 스스로 찍어낸 결과물이, 원본 소스 코드와 단 한 글자의 공백도 없이 100% 완벽히 일치**한다는 뜻입니다.

여기서 한 걸음 더 나아가, 출력된 `quine_output.py`를 다시 실행해 봅시다.

[source,bash]
----
$ python3 quine_output.py > quine_output2.py
$ diff quine_output.py quine_output2.py
(역시 아무런 차이 없음)
----

100번을 다시 실행해도 영원히 자기 자신만을 복제해 내는 완벽한 **고정점(Fixed-Point)**입니다

[NOTE]
====
**흔히 헷갈리는 지점: 자기 소스 파일을 열어서 읽은 것 아닌가요?**  
절대 아닙니다 `open('quine.py')`처럼 외부 파일을 읽어오는 반칙을 쓰지 않았습니다. 오직 **"틀(함수)"과 "틀 자신을 나타내는 데이터(인자)"를 조립하는 순수한 논리적 구조만으로** 자기 자신을 완벽하게 재구성해 낸 것입니다. 괴델의 문장 $G$도 외부의 관찰자가 아니라 순수한 내부 산술식만으로 자기를 가리켰던 것과 완벽히 똑같은 원리입니다.
====

== 요약

* **쿼인 (Quine)**: 외부 파일을 읽지 않고 오직 내부의 데이터 대입만으로 자기 자신의 소스 코드를 그대로 출력하는 프로그램입니다.
* **괴델과의 연결**: 6장의 대각선 보조정리(문장틀에 자기 자신의 괴델 수를 넣는 것)가 추상적인 사변이 아니라, 컴퓨터 위에서 실제로 실행되는 명백한 수학적 실체임을 확인했습니다.
