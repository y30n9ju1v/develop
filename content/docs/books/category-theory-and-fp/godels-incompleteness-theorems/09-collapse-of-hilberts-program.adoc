'''

7장과 8장에서 우리는 괴델이 완성한 두 개의 거대한 정리를 확인했습니다.

이 두 정리는 수학 전체를 완벽한 형식 체계의 성에 가두려 했던 **'힐베르트 프로그램(Hilbert's Program)'의 심장에 치명타**를 날렸습니다.

== 힐베르트 프로그램의 두 기둥이 무너지다

힐베르트가 꿈꾸었던 프로그램의 목표는 크게 두 가지였습니다.

....
                   [ 힐베르트 프로그램의 붕괴 ]

   【 힐베르트의 목표 1 】                  【 힐베르트의 목표 2 】
    "참인 모든 것을 증명한다"              "우리 체계의 무모순성을
    (완전한 체계의 완성)                    스스로의 힘으로 증명한다"
             │                                       │
             ▼                                       ▼
   [ 제1불완전성 정리의 일격 ]            [ 제2불완전성 정리의 일격 ]
    참이지만 증명할 수 없는                  체계는 스스로의 무모순성을
    괴델 문장 G가 반드시 존재               결코 증명할 수 없음
             │                                       │
             └───────────────────┬───────────────────┘
                                 ▼
                     [ 힐베르트 프로그램의 완전한 종말 ]
....

1. **제1불완전성 정리**: 참이지만 증명할 수 없는 문장 $G$의 존재를 밝혀 **완전성**이라는 목표를 무너뜨렸습니다.
2. **제2불완전성 정리**: 체계가 스스로의 안전성을 보증할 수 없음을 증명하여 **자기 완결적 무모순성 증명**이라는 목표를 산산조각 냈습니다.

== 사다리 위에서 사다리를 들어 올리려는 시도

힐베르트가 원했던 것은 마치 **"사다리 위에 올라선 사람이, 공중에 뜬 채로 자기 발밑의 사다리를 번쩍 들어 올려 보이겠다는 것"**과 같았습니다.

....
                     [ 사다리 비유와 겐첸의 증명 ]

     【 힐베르트의 불가능한 시도 】           【 겐첸의 현실적 해법 (1936) 】
      "사다리 위에서 스스로 들기"            "바깥의 단단한 땅을 딛고 사다리 받치기"

           ┌─┐                                    ┌─┐
           │ │ ◄── 체계 안에서                     │ │
           │ │     스스로 증명 불가               │ │
           └─┘                                    └─┘
                                             ═════════════════  ◄── 더 강력한 외부 원리
                                             [ 단단한 외부 지지대 ]  (초한 귀납법)
....

사다리가 튼튼한지 확인하려면 반드시 **사다리 바깥의 단단한 땅**을 딛고 서서 사다리를 점검해야 합니다.

실제로 1936년, 수학자 게르하르트 겐첸(Gerhard Gentzen)은 산술 체계보다 조금 더 강력한 외부 도구인 **'초한 귀납법(Transfinite Induction)'**이라는 단단한 땅을 딛고 서서 산술 체계의 무모순성을 증명해 냈습니다. 

이는 제2정리를 뒤집은 것이 아니라, **"수학의 안전성을 확인하려면 반드시 더 강력한 외부의 시선이 필요하다"**는 괴델의 통찰을 완벽히 재확인해 준 사건이었습니다.

[NOTE]
====
**흔히 헷갈리는 지점: 수학 전체가 실패하고 무너진 것인가요?**  
절대 아닙니다 괴델의 정리는 수학이 틀렸다거나 쓸모없어졌다는 뜻이 아닙니다. **"수학을 닫힌 기계적 규칙의 상자 안에 완벽히 가둘 수는 없다"**는 형식주의의 본질적 한계를 명확히 규명한 것입니다. 수학자들은 이후로도 여전히 정리를 증명하고 공학을 발전시켰으며, 오히려 수학 기초론을 훨씬 더 깊고 풍요롭게 이해하게 되었습니다.
====

== 한계를 안다는 것의 위대함

괴델의 발견은 절망이 아니라 해방이었습니다.

수학은 차가운 기계적 규칙의 틀에 영원히 갇힌 감옥이 아니라, **새로운 공리와 통찰을 통해 끝없이 지평을 넓혀갈 수 있는 살아 숨 쉬는 유기체**임이 드러난 것입니다.

이제 우리는 마지막 단계로 나아갑니다. 괴델이 수학의 세계에서 밝혀낸 이 한계선이, 앨런 튜링이 컴퓨터 과학의 세계에서 밝혀낸 **'정지 문제'**와 어떻게 완벽하게 일치하는지 그 찬란한 접점을 살펴봅시다.

== 요약

* **프로그램의 붕괴**: 제1정리는 완전성을, 제2정리는 자기 무모순성 증명을 무너뜨림으로써 힐베르트 프로그램을 종결시켰습니다.
* **외부의 시선 (겐첸)**: 사다리 비유처럼, 체계의 안전성을 증명하려면 반드시 더 강력한 외부의 도구가 필요합니다.
* **진짜 교훈**: 수학이 무너진 것이 아니라, 수학적 진리가 닫힌 기계적 형식 체계보다 훨씬 광대하다는 진실이 밝혀진 것입니다.

[TIP]
====
**확인 질문**: 사다리 비유에서 왜 "사다리 위에서 사다리를 드는 것"은 불가능하고, "바깥의 단단한 땅을 딛는 것"이 겐첸의 증명과 대응하는지 머릿속으로 정리해 보세요.
====
