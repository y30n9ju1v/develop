'''

4부가 시작됩니다. 

7장에서 우리는 산술 체계가 완전할 수 없다는 제1불완전성 정리를 목격했습니다. 하지만 힐베르트에게는 아직 마지막 희망이 남아있었습니다.

> "완전하지 않더라도 좋다. 적어도 우리 체계에 **'모순이 없다(무모순성)'는 사실만큼은 수학 스스로 확실하게 증명**할 수 있지 않겠는가?"

하지만 괴델은 이 마지막 남은 보루마저 무자비하게 무너뜨렸습니다.

== "우리 체계는 모순이 없다"는 문장: Con

4장에서 우리는 "증명 가능하다"는 성질을 산술식으로 번역했습니다. 그렇다면 **"이 체계는 무모순이다(모순이 없다)"**라는 주장 역시 산술식으로 적을 수 있습니다.

"모순이 없다"는 것은 곧 "거짓인 문장(예: `0 = 1`)의 증명이 존재하지 않는다"는 뜻이므로, 이를 하나의 산술 문장으로 조립할 수 있습니다. 이 문장을 **`Con` (Consistency)**이라고 부릅시다.

== 괴델의 치명적인 연쇄 논증

괴델은 체계 안에서 다음과 같은 놀라운 연결고리가 이미 증명되어 있음을 발견했습니다.

> **"만약 우리 체계가 무모순이라면(`Con`), 괴델 문장 $G$는 증명될 수 없다." (`Con → G`)**

이것은 7장에서 우리가 밖에서 확인한 '경우 1'의 논리를 체계 안의 형식적 수식으로 옮겨 적은 것입니다.

이제 체계가 자기 자신의 무모순성(`Con`)을 스스로 증명할 수 있다고 가정해 봅시다.

....
                  [ 제2불완전성 정리 연쇄 추론 단계 ]

  【1단계: 이미 확보된 정리】
   • 체계는 "Con이면 G이다 (Con → G)"를 이미 증명해 두었다.
                              │
  【2단계: 가정】             │
   • 만약 체계가 스스로 "우리 체계는 무모순이다 (Con)"까지 증명해낸다면?
                              │
                              ▼
  【3단계: 전건 긍정 적용】
   • (Con → G)와 (Con)을 합치면 ──► 체계는 【 문장 G 】를 증명해버린다
                              │
                              ▼
  【4단계: 모순 발생】
   • 하지만 7장에서 "무모순인 체계는 G를 결코 증명할 수 없다"는 것을 확인했다.
   • [결론] 2단계의 가정 자체가 틀렸다.
   ──► 【 체계는 자기 자신의 무모순성(Con)을 결코 스스로 증명할 수 없다 】
....

만약 수학 체계가 자기 자신의 무모순성(`Con`)을 증명한다면, 그 즉시 `G`까지 증명되어 체계가 모순에 빠지고 맙니다.

따라서 체계가 모순 없이 건강하려면, **자기 자신의 무모순성을 스스로 증명하는 일만큼은 절대로 해낼 수 없습니다.**

이것이 바로 **괴델의 제2불완전성 정리(Second Incompleteness Theorem)**입니다.

== 은행의 자기 신용 보증서에 비유하기

이 기막힌 결론을 **은행의 신용 보증서**에 비유해 봅시다.

....
                     [ 은행의 자기 신용 보증서 비유 ]

        어떤 은행이 자체 발행한 문서: "우리 은행은 절대 파산하지 않습니다"
                                    │
                                    ▼
        "이 보증서를 과연 믿을 수 있는가?"
        • 파산할 사기 은행이라도 이 문서는 얼마든지 찍어낼 수 있다
        • 따라서 은행 '내부'의 서류만으로는 자신의 건전성을 보증할 수 없다
        • 건전성을 입증하려면 반드시 【외부의 공인 감사기관】이 필요하다
....

정말로 정직하고 건전한 은행일수록, 역설적으로 "내가 안전하다"는 것을 자기 은행의 도장만으로는 증명할 수 없습니다.

마찬가지로 산술 체계가 모순이 없음을 보증하려면, 반드시 **그 체계보다 더 강력한 '체계 바깥의 외부 원리'**를 빌려와야만 합니다.

[NOTE]
====
**흔히 헷갈리는 지점: 체계가 무모순성을 증명 못 하니, 실제로는 모순이라는 뜻인가요?**  
전혀 아닙니다. 이 정리는 "체계가 실제로 모순이다"라는 뜻이 아니라, **"실제로 완벽하게 무모순이더라도, 그 사실을 자기 자신의 좁은 규칙만으로는 스스로 증명할 수 없다"**는 뜻입니다. 진리와 증명 가능성의 한계가 다시 한번 명확히 드러난 것입니다.
====

== 요약

* **문장 `Con`**: "이 체계 안에서 모순(예: 0=1)의 증명은 존재하지 않는다"는 무모순성 문장입니다.
* **연쇄 추론의 모순**: `Con`을 증명하면 `Con → G`에 의해 `G`까지 증명되어 제1정리와 충돌합니다.
* **제2불완전성 정리**: 산술을 다룰 수 있는 무모순인 형식 체계는, 자기 자신이 무모순이라는 사실조차 스스로의 규칙만으로는 증명할 수 없습니다.

[TIP]
====
**확인 질문**: 1장에서 배운 추론 규칙인 '전건 긍정'(A와 A→B가 있으면 B를 얻는다)을 떠올리며, 왜 체계가 `Con`을 증명하는 순간 `G`까지 연쇄적으로 증명되어 버리는지 과정을 복습해 보세요.
====
