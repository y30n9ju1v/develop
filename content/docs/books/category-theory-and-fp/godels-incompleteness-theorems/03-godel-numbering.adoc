2부가 시작됩니다. 괴델의 증명에서 가장 독창적인 첫걸음 — 수학 문장을 숫자로 바꾸는 방법을 직접 따라가 봅니다.

== 왜 문장을 숫자로 바꾸려 하는가

산술(자연수와 `+`, `×` 같은 연산에 대한 이론)은 "숫자에 대한 성질"을 다루는 이론입니다. 그런데 괴델이 증명하고 싶었던 건 "문장에 대한 성질"("이 문장이 증명 가능한가")입니다. 이 둘은 원래 다른 세계에 있는 이야기입니다 — 산술은 숫자를 다루지, 문장을 다루지 않으니까요. 괴델의 통찰은, **문장 자체를 숫자로 바꿔버리면, "문장에 대한 이야기"가 그대로 "숫자에 대한 이야기"(즉 산술)로 바뀐다**는 것이었습니다. 이렇게 하면 산술이 자기 자신(자신의 언어로 표현된 문장들)에 대해 이야기할 수 있게 됩니다.

== 우편번호처럼 부호를 매긴다

이 사이트의 다른 책 `람다 계산법과 계산 가능성` 10장에서 짧게 언급했던 비유를 여기서 실제로 끝까지 따라갑니다. 우편번호가 "어느 지역 어느 동네"라는 정보를 숫자 하나로 압축하듯, 괴델은 수학 기호 하나하나에 고유한 번호를 매겼습니다. 아주 단순화한 버전으로 감을 잡아봅시다 — 기호마다 번호를 이렇게 정합니다.

* `0` → `6`
* `=` → `7`
* `+` → `11`
* `(` → `8`, `)` → `9`
* 변수 `x`, `y`, ... → `13`, `17`, ... (13 이후의 소수들)

== 손으로 직접 부호화하기

`0=0`이라는 아주 단순한 문장을 부호화해봅시다. 이 문장은 기호 세 개(`0`, `=`, `0`)로 이루어져 있고, 각 기호의 번호는 순서대로 `6`, `7`, `6`입니다. 이제 처음 세 개의 소수(`2`, `3`, `5`)를 순서대로 골라, 각 소수를 그 자리의 기호 번호만큼 거듭제곱한 다음 전부 곱합니다.

`2^6 × 3^7 × 5^6 = 64 × 2187 × 15625`

이 계산 결과(아주 큰 자연수 하나)가 `0=0`이라는 문장 전체의 **괴델 수**입니다. 중요한 건 정확한 계산값이 아니라, **이 큰 숫자 하나만 있으면 `0=0`이라는 원래 문장을 정확히 되돌릴 수 있다**는 점입니다 — 소인수분해를 하면 `2`의 지수가 `6`(첫 번째 기호), `3`의 지수가 `7`(두 번째 기호), `5`의 지수가 `6`(세 번째 기호)이라는 게 그대로 드러나고, 이 지수들을 다시 기호로 되돌리면 정확히 `0=0`이 나옵니다. 소인수분해의 결과가 유일하다는(어떤 자연수든 소인수분해 방법이 딱 하나뿐이라는) 산술의 기본 성질 덕분에, 이 부호화는 절대 애매하지 않습니다 — 숫자 하나가 정확히 하나의 문장에만 대응합니다.

[NOTE]
====
**흔히 헷갈리는 지점**: "왜 하필 소수의 거듭제곱을 곱하는 복잡한 방법을 쓰는가, 그냥 기호 번호를 순서대로 나열하면(`676`처럼) 안 되는가"라고 생각하기 쉽습니다. 문제는 **경계를 구분할 수 없다는 것**입니다 — `676`이 "6, 7, 6"(세 기호)인지 "67, 6"(두 기호)인지 "6, 76"인지 구분할 방법이 없습니다. 소수의 거듭제곱과 곱셈을 쓰면, 소인수분해가 유일하다는 성질 덕분에 이런 모호함이 절대 생기지 않습니다 — 이게 이 복잡해 보이는 방법을 쓰는 진짜 이유입니다.
====

== 증명 전체도 하나의 숫자로

여기서 한 걸음 더 나아갑니다 — **증명**이란 문장 하나가 아니라, 공리에서 시작해 추론 규칙을 여러 번 적용해 만든 **문장들의 나열**입니다(1단계: 공리, 2단계: 공리에서 추론한 문장, ... 마지막 단계: 증명하려던 문장). 각 단계의 문장은 이미 위에서 본 방법으로 괴델 수 하나로 바꿀 수 있으니, 이제 "증명 전체"도 **각 단계 문장의 괴델 수들을, 다시 소수의 거듭제곱으로 겹쳐서** 하나의 거대한 자연수로 부호화할 수 있습니다 — 문장 하나를 숫자로 바꾸는 바로 그 방법을, 문장들의 나열(증명)에도 그대로 한 번 더 적용하는 것입니다. 결국 **"어떤 문장이 증명 가능한가"**라는 질문은, **"이 문장의 괴델 수를 마지막 단계로 갖는 어떤 증명 전체의 괴델 수가 존재하는가"**라는, 순수하게 숫자들 사이의 관계를 묻는 질문으로 완전히 바뀝니다.

[TIP]
====
**확인 질문**: 본문의 기호 번호표(`0→6`, `=→7`)를 이용해, `0+0=0`이라는 문장(기호 다섯 개: `0`, `+`, `0`, `=`, `0`)의 괴델 수를 계산하는 식을 직접 세워보세요(정확한 곱셈 결과까지 계산할 필요는 없습니다 — `2^6 × 3^11 × 5^6 × 7^7 × 11^6` 형태의 식만 세우면 됩니다).
====

== 요약

* 괴델 수 매기기는 우편번호처럼, 수학 기호 하나하나에 고유 번호를 매기고 소수의 거듭제곱으로 곱해서 문장 전체를 하나의 자연수로 부호화하는 방법입니다.
* 소인수분해가 유일하다는 산술의 성질 덕분에, 이 부호화는 애매함 없이 숫자와 문장 사이를 정확히 오갈 수 있습니다.
* 같은 방법을 한 번 더 적용하면 "증명 전체"도 하나의 숫자로 부호화할 수 있고, 이로써 "증명 가능한가"라는 질문이 순수한 숫자 관계의 질문으로 바뀝니다.

다음 장에서는 이렇게 숫자로 바뀐 세계 안에서, "증명 가능하다"는 것 자체가 어떻게 산술적 성질로 표현되는지 봅니다.
