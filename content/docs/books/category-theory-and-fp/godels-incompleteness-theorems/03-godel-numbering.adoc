괴델의 증명에서 가장 독창적이고 천재적인 첫 번째 무기, 바로 **수학 문장과 증명 전체를 하나의 자연수로 바꾸는 '괴델 수 매기기(Gödel Numbering)'**를 만나봅시다.

== 왜 문장을 숫자로 바꾸려 했을까?

산술(자연수와 `+`, `×` 같은 덧셈·곱셈 체계)은 오직 **'숫자들 사이의 성질'**만을 다루는 학문입니다. 숫자가 아닌 '문장'이나 '증명'이라는 철학적 개념은 원래 산술의 언어로 다룰 수 없습니다.

그런데 괴델은 기막힌 통찰을 얻었습니다.

> **"만약 수학 문장과 증명 전체를 어떤 규칙에 따라 '하나의 숫자'로 완벽히 암호화해 버린다면?  
> '문장에 대한 메타적 이야기'가 순식간에 '숫자에 대한 산술 이야기'로 탈바꿈하지 않을까?"**

수학 체계가 자기 자신을 직접 들여다보게 만드는 마법의 열쇠가 바로 여기에 있었습니다.

== 우편번호처럼 기호에 고유 번호를 매긴다

우편번호 '04524'가 "서울특별시 중구 세종대로"라는 긴 주소 정보를 깔끔하게 숫자로 압축하듯, 괴델은 수학에 쓰이는 모든 기호에 고유한 일련번호를 붙였습니다.

이해를 돕기 위해 단순화한 번호표를 하나 만들어 봅시다.

....
                 [ 기호 고유 번호표 (예시) ]

     기호  │  0   │  =   │  +   │  (   │  )   │  변수 x  │  변수 y
   ───────┼──────┼──────┼──────┼──────┼──────┼─────────┼─────────
    번호  │  6   │  7   │  11  │  8   │  9   │   13    │   17
....

== 문장을 단 하나의 거대한 자연수로 압축하기

이제 `0 = 0`이라는 아주 단순한 문장을 하나의 숫자로 바꾸어 봅시다.

이 문장은 `0`, `=`, `0`이라는 3개의 기호로 이루어져 있으므로, 기호 번호는 순서대로 **`6`, `7`, `6`**입니다.

괴델은 소수(Prime Number)인 **`2, 3, 5, 7, 11...`**을 작은 순서대로 꺼내어, 각 기호의 번호만큼 거듭제곱한 뒤 전부 곱했습니다

....
                 [ 괴델 수 인코딩 파이프라인 ]

      원래 문장 :       0       =       0
                       │       │       │
      기호 번호 :       6       7       6
                       │       │       │
      소수 거듭제곱 :  2⁶   ×  3⁷   ×  5⁶
                       │       │       │
      최종 괴델 수 :   64   × 2187  × 15625  ──►  2,187,000,000
....

이 곱셈의 최종 결과인 거대한 자연수 하나가 바로 `0 = 0`이라는 문장의 **괴델 수(Gödel Number)**입니다.

== 왜 100% 완벽하게 원본을 되돌릴 수 있는가?

중요한 것은 거대한 숫자의 크기가 아닙니다. **"이 숫자 하나만 손에 쥐면, 원래 문장이 무엇이었는지를 100% 오차 없이 완벽하게 복원할 수 있다"**는 사실입니다.

중학교 때 배운 산술의 대원칙, **'소인수분해의 유일성(Fundamental Theorem of Arithmetic)'**을 기억하시나요? 어떤 자연수든 소인수분해를 하는 방법은 우주에서 오직 단 한 가지뿐입니다.

....
                 [ 괴델 수 디코딩 (소인수분해) ]

     거대한 괴델 수  ──►  소인수분해 수행  ──►  2⁶ × 3⁷ × 5⁶
                                                     │
        ┌────────────────────────────────────────────┘
        ▼
     • 2의 지수가 6  ──► 첫 번째 기호는 6번 기호: '0'
     • 3의 지수가 7  ──► 두 번째 기호는 7번 기호: '='
     • 5의 지수가 6  ──► 세 번째 기호는 6번 기호: '0'
        │
        ▼
     [ 원래 문장 '0 = 0' 완벽 복원 완료 ]
....

[NOTE]
====
**왜 단순하게 `676`처럼 자릿수를 이어 붙이지 않고 소수를 쓸까요?**  
`676`이라고 쓰면 이것이 `6, 7, 6`(3글자)인지, `67, 6`(2글자)인지 경계가 모호해집니다. 하지만 소인수분해는 지수의 크기와 소수의 순서가 완벽히 고정되므로, 어떤 모호함도 없이 원래의 문장 구조를 1:1로 정확하게 복원해 냅니다.
====

== 증명 전체도 하나의 숫자로 바꾼다

여기서 한 걸음 더 나아갑니다. **'증명(Proof)'**이란 결국 공리에서 시작해 결론에 도달하는 **'문장들의 나열'**입니다.

* 1단계 문장 ($S_1$)의 괴델 수: $g_1$
* 2단계 문장 ($S_2$)의 괴델 수: $g_2$
* 3단계 문장 ($S_3$)의 괴델 수: $g_3$

이 문장들의 괴델 수들을 다시 소수의 거듭제곱으로 묶으면:  
**`2^(g₁) × 3^(g₂) × 5^(g₃)`**  
이로써 **증명 전체조차 단 하나의 자연수로 완벽하게 압축**됩니다

== 이것이 뜻하는 놀라운 혁명

이제 **"어떤 명제가 증명 가능한가?"**라는 질문은 철학의 영역을 떠나 다음과 같은 순수한 수학 문제로 바뀝니다.

> **"어떤 문장의 괴델 수 $S$가 주어졌을 때, $S$를 결론으로 갖는 증명의 괴델 수 $P$가 존재하는가?"**

문장과 증명이 모두 숫자가 됨으로써, 산술 체계 안에서 "증명 가능성"을 사칙연산으로 계산할 수 있는 길이 열린 것입니다.

== 요약

* **괴델 수 매기기**: 기호 번호를 소수의 지수에 얹어 곱함으로써, 문장과 증명 전체를 고유한 자연수로 1:1 인코딩합니다.
* **소인수분해의 유일성**: 어떤 괴델 수가 주어지든 소인수분해를 통해 원래의 문장이나 증명을 애매함 없이 완벽히 복원할 수 있습니다.
* **산술화의 완성**: 논리적 증명 과정 전체가 거대한 숫자들 사이의 곱셈과 나눗셈 관계로 환원되었습니다.

[TIP]
====

(정답: $2^6 \times 3^{11} \times 5^6 \times 7^7 \times 11^6$)
