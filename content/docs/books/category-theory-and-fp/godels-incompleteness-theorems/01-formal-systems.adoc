서문에서 살펴본 힐베르트의 원대한 꿈을 이해하려면, 먼저 **"형식 체계(Formal System)"**가 무엇인지 그 뼈대를 정확히 알아야 합니다.

== 체스 게임에 비유하기

체스 게임을 떠올려 봅시다. 체스는 다음의 단순한 규칙만으로 끝없이 광대한 대국이 펼쳐집니다.

....
                   [ 체스 게임과 수학 형식 체계의 비교 ]

      【 체스 게임 】                          【 수학 형식 체계 】
   ┌───────────────────────┐               ┌───────────────────────┐
   │ • 체스 말 (폰, 킹, 퀸)  │ ◄───[기 호]───► │ • 수학 기호 (0, 1, +, =)│
   │ • 말들의 초기 배치     │ ◄───[공 리]───► │ • 출발점 명제 (공리)   │
   │ • 말의 이동 규칙      │ ◄─[추론 규칙]─► │ • 기계적 연역 규칙     │
   └───────────────────────┘               └───────────────────────┘
               │                                       │
               ▼                                       ▼
    "이 수가 합법적인가?"                   "이 문장이 증명 가능한가?"
    (심판의 기계적 판정)                    (사람의 직관 없이 규칙 대조)
....

체스에서 "이 수가 규칙에 맞는 합법적인 수인가?"를 판단할 때, 심판의 개인적인 취향이나 직관은 전혀 필요 없습니다. 그저 룰북을 펼쳐놓고 기계적으로 대조해 보면 그만입니다.

힐베르트의 꿈은 **수학 전체를 바로 이 체스 게임처럼 완벽하게 엄밀한 시스템으로 만드는 것**이었습니다.

== 형식 체계의 3가지 재료

수학의 모든 형식 체계는 정확히 다음 세 가지 부품으로 조립됩니다.

1. **기호 (Symbols)**: 체스의 말에 해당합니다. `0`, `1`, `+`, `=`, `(`와 같은 문자 및 논리 기호들입니다.
2. **공리 (Axioms)**: 체스의 초기 말 배치에 해당합니다. 증명하지 않고도 "참"으로 약속하고 출발하는 가장 기초적인 문장들입니다 (예: "모든 수 $n$에 대해, $n$에 1을 더한 것은 0이 아니다").
3. **추론 규칙 (Inference Rules)**: 체스 말의 이동 규칙에 해당합니다. "이미 참인 문장 $A$와 '$A$이면 $B$이다'가 주어지면, 새로운 문장 $B$도 참으로 인정한다"(**전건 긍정**, Modus Ponens)처럼, 기존 문장에서 새로운 문장을 기계적으로 찍어내는 합법적인 변환 절차입니다.

이 3가지만 갖추어지면, 어떤 수학 문장이 **"증명 가능하다"**는 것은 더 이상 인간의 통찰력이나 영감의 문제가 아닙니다.

> **"공리라는 출발점에서 시작하여, 추론 규칙이라는 합법적인 수만을 유한 번 두어서 그 문장에 도달할 수 있는가?"**라는 순수한 기계적 검증의 문제가 됩니다.

== 손으로 직접 확인하는 기계적 증명

아주 간단한 형식 체계로 실제 증명의 2단계를 밟아봅시다.

* **공리**: "모든 $n$에 대해, $n = n$이다."
* **추론 규칙 (전칭 예화)**: "'모든 $n$에 대해 $P(n)$'이 참이면, 특정한 숫자 $5$에 대해서도 $P(5)$를 참으로 인정한다."

....
  [1단계: 공리 꺼내기]  ──►  "모든 n에 대해 n = n 이다" (공리이므로 무조건 참)
                                     │
                                     ▼ [추론 규칙 적용: n 자리에 5를 대입]
  [2단계: 결론 도달]    ──►  "5 = 5" (증명 완료)
....

이 증명 과정 어디에도 "5는 5와 같다는 게 당연해 보인다"는 인간의 주관적 느낌이 끼어들지 않았습니다. 정해진 규칙을 로봇처럼 기계적으로 따라갔을 뿐인데 완벽한 증명이 완성되었습니다.

[NOTE]
====
**흔히 헷갈리는 지점: "참이다"와 "증명 가능하다"는 같은 말인가요?**  
형식 체계에서 이 둘은 완전히 다른 개념입니다.
* **참이다 (True)**: 그 문장이 현실적·수학적 의미상 실제로 옳다는 '진리'의 영역입니다.
* **증명 가능하다 (Provable)**: 공리에서 출발해 추론 규칙만으로 그 문장에 기계적으로 도달할 수 있다는 '절차'의 영역입니다.

힐베르트의 꿈은 **"참인 것과 증명 가능한 것이 단 1밀리미터의 오차도 없이 100% 완벽히 일치하는 체계"**를 만드는 것이었습니다.
====

== 힐베르트가 만들고 싶었던 세계

만약 힐베르트의 바람대로 수학 전체가 완벽한 형식 체계로 완성된다면, 인류 역사상의 모든 수학 난제(골드바흐의 추측, 페르마의 마지막 정리 등)는 컴퓨터나 기계에게 "공리에서 규칙을 계속 적용해 봐라" 하고 맡겨두기만 하면 언젠가 무조건 풀릴 수 있게 됩니다.

하지만 이 낙원이 완성되기 위해서는 그 체계가 반드시 갖추어야 할 **두 가지 절대적인 조건**이 있었습니다.

다음 장에서 그 두 조건, **'무모순성'**과 **'완전성'**이 무엇인지 정의합니다.

== 요약

* **형식 체계의 3요소**: 기호(말), 공리(초기 배치), 추론 규칙(이동 규칙)으로 구성된 기계적 수학 시스템입니다.
* **기계적 증명**: 인간의 직관 없이, 공리에서 추론 규칙을 정해진 절차대로 적용해 결론에 도달하는 과정입니다.
* **참과 증명 가능의 분리**: 참(진리)과 증명 가능(규칙 도달)은 원칙적으로 구별되며, 힐베르트는 이 둘이 완벽히 일치하길 바랐습니다.

[TIP]
====
