수학 전체를 몇 개의 공리와 규칙만으로 완벽하게 정리하려던 힐베르트의 꿈이, 왜 그리고 어떻게 무너졌는지를 수식 없이 비유와 논증으로 풀어가는 책입니다. 형식 체계와 완전성·무모순성이라는 개념(1부)에서 시작해, 우편번호처럼 수학 문장 자체를 숫자로 부호화하는 괴델 수 매기기(2부), 대각선 보조정리로 "나는 증명될 수 없다"는 문장을 실제로 지어내 제1불완전성 정리를 증명하는 과정(3부), 그리고 체계가 자기 자신의 무모순성조차 증명할 수 없다는 제2불완전성 정리와 튜링의 정지 문제와의 접점(4부)까지 다룹니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
