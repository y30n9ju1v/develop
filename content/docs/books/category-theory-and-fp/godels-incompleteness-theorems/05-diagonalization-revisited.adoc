'''

3부가 시작됩니다. 

자기 자신을 가리키는 수학 문장을 조립하기 전에, 먼저 고대부터 인류를 괴롭혀 온 가장 유명한 역설을 다시 만나봅시다.

== 거짓말쟁이 역설: 자기 지시의 덫

고대 그리스의 철학자 에피메니데스로부터 전해 내려오는 유명한 문장이 있습니다.

> **"이 문장은 거짓이다."**

이 문장은 참일까요, 거짓일까요?

....
                    [ 거짓말쟁이 역설의 딜레마 ]

     만약 이 문장이 '참'이라면?  ──► "나는 거짓이다"라고 했으므로 【거짓】이 됨 (모순)
     만약 이 문장이 '거짓'이라면? ──► "나는 거짓이다"라는 말이 맞으므로 【참】이 됨 (모순)
....

참이라고 해도 모순, 거짓이라고 해도 모순에 빠집니다. 이것이 바로 **자기 지시(Self-Reference)**가 만들어내는 가장 오래된 골칫거리, **거짓말쟁이 역설(Liar Paradox)**입니다.

== 왜 수학자들은 이를 '궤변'으로 치부했을까?

수학자들은 오랫동안 이 역설을 엄밀한 수학적 대상으로 인정하지 않고 "일상 언어의 장난(궤변)"으로 여겼습니다.

그 이유는 일상어의 **"이 문장"**이라는 지시어가 수학적으로 너무나 모호하기 때문입니다.

회의실 문 앞의 안내판에 비유해 봅시다.
> 안내판: *"이 안내판이 가리키는 방은 비어있지 않다."*

이 안내판을 정식 행정 문서로 옮기려면 "이 안내판"이 정확히 몇 번 건물, 몇 호실 문에 걸려 있는지 일련번호나 좌표로 명시해야 합니다. 하지만 안내판을 제작하는 시점에는 아직 어디에 걸릴지 알 수 없어서 순환 논리에 빠지게 됩니다.

== 칸토어의 대각선 논법: 자기 자신을 찔러 모순 만들기

하지만 수학자 게오르크 칸토어(Georg Cantor)는 이 자기 지시의 메커니즘을 엄밀한 수학적 증명 도구로 끌어올렸습니다. 바로 **대각선 논법(Diagonal Argument)**입니다.

....
                   [ 칸토어의 대각선 논법 격자 ]

                 1번째 자리  2번째 자리  3번째 자리 ...
       수 1 :       [ 0 ]       1          0       ...
       수 2 :         1       [ 1 ]        0       ...
       수 3 :         0         0        [ 1 ]     ...
                               ...
       ─────────────────────────────────────────────────
       대각선 성분 :   0         1          1       ...
       반전된 새 수:   1         0          0       ... ──► 목록에 없는 새로운 수
....

대각선에 놓인 숫자들을 하나씩 뽑아 정반대로 뒤집어 만든 새로운 숫자는, 목록 안의 그 어떤 기존 숫자와도 최소한 한 자리 이상 달라 목록에 결코 포함될 수 없습니다.

* 칸토어는 이를 통해 **실수의 개수가 자연수의 개수보다 더 거대한 무한**임을 증명했습니다.
* 튜링은 이를 통해 **정지 문제를 해결하는 만능 프로그램이 존재할 수 없음**을 증명했습니다.
* 그리고 괴델은 이를 통해 **수학 체계의 불완전성**을 증명하려 합니다.

== 괴델의 돌파구: 지시어 없이 자기를 콕 집기

괴델은 3~4장에서 만든 도구로 거짓말쟁이 역설의 모호함을 완전히 극복했습니다.

"이 문장"이라는 애매한 말 대신, **"괴델 수가 2,187,000,000인 문장"**처럼 **고유한 자연수로 대상을 콕 집어 지칭**할 수 있게 된 것입니다

그렇다면 괴델은 거짓말쟁이 역설처럼 체계를 모순으로 폭발시켰을까요? 아닙니다. 여기에 괴델의 천재성이 빛납니다.

|===
| 비교 항목 | 거짓말쟁이 역설 | 괴델의 자기 지시 문장 $G$

| **주장의 내용** | "나는 **거짓(False)**이다." | "나는 **증명 불가능(Unprovable)**하다."
| **다루는 대상** | 진리(Truth) 자체를 부정 | 증명 가능성(Provability)을 부정
| **결과** | 체계가 **논리적 모순**으로 파멸함 | 체계가 **불완전(Incomplete)**함을 증명함
|===

[NOTE]
====
**거짓말쟁이 역설과 괴델 문장의 결정적 차이**  
"참"과 "증명 가능"은 2장에서 배웠듯이 다른 개념입니다 괴델은 진리 자체를 부정한 것이 아니라 "기계적 증명 가능성"을 부정했기 때문에, 모순으로 무너지지 않고 **"참이지만 증명할 수는 없다"**는 불완전성의 위대한 결론을 이끌어낼 수 있었습니다.
====

== 요약

* **거짓말쟁이 역설**: "나는 거짓이다"는 자기 지시로 인해 참/거짓 양쪽 모두에서 모순을 일으킵니다.
* **대각선 논법**: 자기 자신을 참조하여 만능의 목록이나 가정을 무너뜨리는 강력한 수학적 기교입니다.
* **괴델의 전략**: "나는 거짓이다" 대신 "나는 증명될 수 없다"는 문장을 고유한 괴델 수로 엄밀하게 구성하여, 모순 없이 체계의 불완전성을 증명합니다.

[TIP]
====
**확인 질문**: 왜 "나는 거짓이다"라는 문장은 체계를 모순으로 파괴하지만, "나는 증명될 수 없다"라는 문장은 체계를 파괴하지 않고 "불완전성"이라는 새로운 통찰로 이어질 수 있는지 두 문장의 차이를 곱씹어 보세요.
====

다음 장에서는 "나는 증명될 수 없다"고 외치는 전설의 문장, **괴델 문장 $G$**를 실제로 조립해 봅니다.
