'''

2부가 시작됩니다.

서문에서 던졌던 스도쿠 퍼즐 이야기로 다시 돌아가 봅시다.

== 풀기는 막막하지만 확인은 순식간이다

빈칸이 빽빽한 스도쿠 판을 받으면, 처음부터 정답을 찾아내는 것은 온갖 경우의 수를 따져보느라 오랜 시간이 걸립니다.

그런데 친구가 "내가 다 풀었어" 하고 이미 숫자가 다 채워진 완성본을 건네준다면 어떨까요?

....
                    [ 스도쿠 정답 확인의 3단계 ]

      【 가로줄 9개 검사 】       【 세로줄 9개 검사 】       【 3x3 박스 9개 검사 】
     1~9가 겹치지 않는가?        1~9가 겹치지 않는가?        1~9가 겹치지 않는가?
             │                           │                           │
             └───────────────────────────┼───────────────────────────┘
                                         ▼
                     [ 10초 만에 검산 완료 (다항 시간) ]
....

가로줄, 세로줄, 3x3 박스를 훑으며 1부터 9까지 겹치지 않는지만 세어보면 끝납니다. 이 검산 작업은 아무리 초보자라도 10초 안에 끝낼 수 있는 **명백한 다항 시간 작업**입니다.

이처럼 **"답을 처음부터 찾아내는 것(Solving)"**과 **"주어진 답이 진짜 정답인지 확인하는 것(Verifying)"** 사이에는 거대한 간극이 존재합니다.

== NP의 정의: "답을 확인하는 게 다항 시간인 문제들"

**NP**는 바로 이 '확인(검증)'의 관점에서 정의된 문제들의 모임입니다.

> **NP란, 누군가 "이것이 정답이다"라며 정답 후보(증거, Certificate)를 건네주었을 때, 그 답이 진짜 맞는지 틀렸는지를 【다항 시간 안에 검증할 수 있는】 모든 문제들의 집합이다.**

스도쿠 외에도 우리가 일상에서 만나는 수많은 퍼즐과 난제들이 전부 NP에 속합니다.

....
                   [ 복잡도 클래스 NP의 대표적인 문제들 ]

   • 스도쿠 (Sudoku): 숫자가 다 채워진 판을 주면 검산은 순식간
   • 지도 색칠하기 (Map Coloring): 인접한 나라가 다른 색인지 검사하는 건 순식간
   • 부분집합 합 (Subset Sum): 고른 숫자들을 다 더해서 목표값이 되는지 확인은 순식간
   • 여행하는 외판원 (TSP 판정): 주어진 경로의 거리 총합이 100km 이하인지 확인은 순식간
....

이 문제들의 공통점은 명확합니다. **"정답을 증명하는 힌트(답안지)가 손에 쥐어지는 순간, 확인하는 것은 누워서 떡 먹기"**라는 사실입니다.

[NOTE]
====
**NP는 'Not Polynomial(다항 시간이 아님)'의 약자인가요?**  
가장 흔하게 하는 오해입니다 NP는 **Non-deterministic Polynomial(비결정적 다항 시간)**의 약자입니다.  
과거 이론학자들은 "갈림길을 만날 때마다 분신술을 쓰듯 모든 경로를 동시에 탐색하는 마법의 가상 컴퓨터(**비결정적 튜링 기계**)"를 상상했습니다. 이 마법의 컴퓨터가 정답을 단번에 찍어서 다항 시간 안에 확인할 수 있다는 뜻에서 붙은 이름입니다. 오늘날에는 **"답을 확인(검증)하는 것이 다항 시간에 끝나는 문제"**로 이해하는 것이 가장 직관적이고 정확합니다.
====

== P는 무조건 NP 안에 쏙 들어간다 ($P \subseteq NP$)

여기서 아주 자연스럽고 중요한 수학적 사실이 하나 도출됩니다.

어떤 문제를 다항 시간 안에 **직접 풀어낼 수 있다면(P)**, 누군가 답을 주었을 때 그 답이 맞는지 **확인하는 것(NP)**은 당연히 다항 시간 안에 할 수 있지 않을까요? 내가 직접 풀 수 있는 실력이 있는데, 남이 푼 답을 채점하지 못할 리가 없습니다.

따라서 **P에 속하는 모든 문제는 100% 전부 NP에도 속합니다.**

....
                    [ P와 NP의 명백한 포함 관계 ]

               ┌─────────────────────────────────┐
               │  NP (답을 확인하기 쉬운 문제들)     │
               │                                 │
               │     ┌─────────────────────┐     │
               │     │  P (풀기도 쉬운 문제) │     │
               │     │  • 정렬, 최단 경로   │     │
               │     └─────────────────────┘     │
               │   • 스도쿠, 부분집합 합, 외판원  │
               └─────────────────────────────────┘
....

수학 기호로 쓰면 **`P ⊆ NP` (P는 NP의 부분집합이다)**가 됩니다.

== 이제 진짜 질문을 던질 시간

$P$가 $NP$ 안에 들어간다는 것은 너무나 당연하고 상식적인 결론이었습니다.

그렇다면 질문은 이제 정반대 방향을 향합니다.

> **"NP 안에 있지만 아직 빠른 풀이법을 못 찾은 문제들(스도쿠, 부분집합 합 등)도,  
> 사실은 우리가 방법을 몰랐을 뿐 P처럼 다항 시간 안에 푸는 마법의 지름길이 존재하는 것은 아닐까?"**

다음 장에서 이 책의 심장부, **P vs NP 질문**을 정면으로 마주합니다.

== 요약

* **복잡도 클래스 NP**: 정답 후보가 주어졌을 때, 그것이 참인지 거짓인지를 다항 시간 안에 검증할 수 있는 문제들의 모임입니다.
* **풀기와 확인하기**: 스도쿠처럼 처음부터 답을 찾는 것은 어려워 보여도, 남이 푼 답을 검산하는 것은 다항 시간 안에 끝납니다.
* **포함 관계 ($P \subseteq NP$)**: 풀 수 있는 문제는 당연히 확인도 쉬우므로, P는 언제나 NP의 완벽한 부분집합입니다.
