9장에서 우리는 $P = NP$가 그리는 미래를 상상해 보았습니다.

이제 상상에서 현실로 돌아와, 현대 컴퓨터 과학이 **지금 정확히 어디까지 알고 있고 어디서부터 모르는지** 전체 지도를 펼쳐봅시다.

== 밀레니엄 문제로서의 위상

2000년 클레이 수학연구소가 선정한 7대 밀레니엄 문제 중, 2002년 러시아의 그리고리 페렐만이 푼 '푸앵카레 추측'을 제외한 나머지 6개 난제는 여전히 미해결 상태입니다.

P vs NP 문제는 리만 가설, 양-밀스 질량 간극 등 순수 수학의 거대한 봉우리들과 어깨를 나란히 하며, 현대 지성사에서 가장 중요한 미개척지로 우뚝 서 있습니다.

== NP-완전과 NP-난해: 확실한 정리

6장에서 다루었던 구분을 다시 한번 완벽하게 정리해 둡시다.

....
                 [ 판정 버전 vs 최적화 버전의 차이 ]

   【 판정 문제 (Decision) 】 ──► "총 거리가 100km 이하인 경로가 있는가?"
   • 답이 "예 / 아니오"로 나옴
   • 정답 경로를 주면 1초 만에 검산 가능 ──► 【 NP-완전 (NP-Complete) 】
                                 │
                                 ▼ (더 확장하면?)
   【 최적화 문제 (Optimization) 】 ──► "가장 짧은 최적 경로의 길이가 정확히 몇 km인가?"
   • 구체적인 최적 숫자를 요구함
   • 최적임을 증명하려면 다른 경로와 다 비교해야 해서
     검산 자체가 다항 시간에 안 끝날 수 있음 ──► 【 NP-난해 (NP-Hard) 】
....

* **NP-완전 (NP-Complete)**: NP에 속하면서(답 확인이 쉬움), 동시에 가장 어려운 문제입니다.
* **NP-난해 (NP-Hard)**: NP의 모든 문제가 환원되는 문제들의 모임입니다. 답 확인조차 다항 시간에 불가능한 더 넓고 거대한 영역입니다.

== 래드너의 정리: P와 NP-완전 사이의 '중간 지대'

우리가 아직 $P=NP$인지 $P \neq NP$인지는 모르지만, 그 사이에 대해 확실하게 알고 있는 놀라운 수학적 사실이 있습니다.

1975년 수학자 리처드 래드너(Richard Ladner)는 다음의 정리를 완벽하게 증명했습니다.

> **래드너의 정리 (Ladner's Theorem, 1975):  
> 만약 $P \neq NP$가 참이라면,  
> P에도 속하지 않고 NP-완전도 아닌 【중간 지대의 문제(NP-Intermediate, NPI)】가 반드시 존재한다.**

....
                   [ 래드너 정리가 밝혀낸 복잡도 지도 (P ≠ NP 시) ]

             ┌───────────────────────────────────────────────┐
             │  NP (답 확인이 다항 시간인 문제들)               │
             │                                               │
             │   ┌──────────────┐       ┌────────────────┐   │
             │   │      P       │       │    NP-완전     │   │
             │   │ (풀기도 쉬움) │       │   (NPC, 왕)    │   │
             │   └──────────────┘       └────────────────┘   │
             │          ▲                       ▲            │
             │          │       ┌───────┐       │            │
             │          └───────┤  NPI  ├───────┘            │
             │                  │(중간) │                    │
             │                  └───────┘                    │
             │         【 유력 후보: 정수 소인수분해 】         │
             │         【          그래프 동형 문제 】        │
             └───────────────────────────────────────────────┘
....

오랫동안 이 '중간 지대(NPI)'의 가장 유력한 현실 후보로 거론되어 온 것이, 다름 아닌 8장에서 본 **'정수 소인수분해(Integer Factorization)'**와 **'그래프 동형(Graph Isomorphism)'** 문제입니다.

* 다항 시간 알고리즘이 발견되지 않아 **P에는 아직 못 들어왔지만**,
* 그렇다고 SAT처럼 다른 모든 문제가 환원되는 **NP-완전이라는 증거도 없습니다.**

[NOTE]
====
**소인수분해가 확실히 중간 지대(NPI)에 있다는 뜻인가요?**  
아직 아닙니다 소인수분해가 P에 속하는지, NP-완전인지, 아니면 진짜 NPI에 속하는지는 여전히 미해결입니다. 하지만 래드너의 정리는 "세상이 흑백(P 아니면 NP-완전) 두 칸으로만 나뉘어 있는 것이 아니라, 그 사이에 섬세한 그라데이션의 중간 지대가 존재한다"는 깊은 지형도를 보여줍니다.
====

== 우리가 지나온 길을 한 문장으로

1장부터 10장까지의 대장정을 한 문장으로 압축하면 이렇습니다.

> **"스도쿠의 풀기와 확인하기가 왜 다른가라는 소박한 질문에서 출발하여,  
> 수천 개의 난제를 하나로 묶는 NP-완전의 도미노를 세우고,  
> 현대 암호학과 인간 창조성의 본질을 성찰하며,  
> 래드너의 중간 지대라는 지도를 완성했지만,  
> 그 최종 답은 여전히 21세기 인류의 도전을 기다리고 있다."**

== 요약

* **밀레니엄 문제**: 푸앵카레 추측 외에 P vs NP를 포함한 6개 난제는 여전히 인류 최고의 미해결 과제입니다.
* **판정과 최적화**: 판정 버전은 NP-완전, 더 넓은 최적화 버전은 NP-난해로 분류됩니다.
* **래드너의 정리 (1975)**: $P \neq NP$라면 P도 아니고 NP-완전도 아닌 '중간 지대(NPI)' 문제가 반드시 존재하며, 소인수분해가 그 유력한 후보입니다.

====
