== 사소해 보이는 일상의 관찰

스도쿠(Sudoku) 퍼즐을 풀어본 적이 있다면 누구나 공감하는 경험이 있습니다.

9x9 격자의 빈칸을 논리적으로 하나씩 채워나가는 것은 몇십 분, 때로는 며칠이 걸릴 만큼 머리가 지끈거립니다. 그런데 누군가 완성된 정답지를 눈앞에 내밀면 어떨까요? 가로, 세로, 3x3 상자에 1부터 9까지 겹치지 않고 잘 들어갔는지 **'확인(검산)'하는 것은 10초도 안 걸려 순식간에 끝납니다.**

....
                    [ 스도쿠가 보여주는 두 세계 ]

      【 답을 직접 찾아내기 (풀기) 】          【 주어진 답을 검산하기 (확인) 】
      ┌──────────────────────────┐          ┌──────────────────────────┐
      │  수많은 경우의 수를 탐색  │          │  정해진 규칙만 훑어보기  │
      │  (시간이 아주 오래 걸림) │          │  (눈 깜짝할 사이에 끝남) │
      └──────────────────────────┘          └──────────────────────────┘
                  ▲                                      ▲
                  └──────────────────┬───────────────────┘
                                     │
                 "왜 '풀기'는 이렇게 어렵고, '확인'은 쉬울까?
                  정말 풀기가 본질적으로 더 어려운 것일까,
                  아니면 우리가 아직 빠른 지름길을 못 찾았을 뿐일까?"
....

이 사소해 보이는 질문을 수학과 컴퓨터 과학의 언어로 엄밀하게 정제한 것이, 바로 현대 과학 최고의 미해결 난제인 **P vs NP 문제**입니다.

== 100만 달러의 상금이 걸린 21세기 최대의 난제

2000년, 미국의 클레이 수학연구소(Clay Mathematics Institute)는 21세기에 인류가 풀어야 할 가장 중요한 7대 수학 난제를 선정하여 각각 100만 달러(약 13억 원)의 상금을 걸었습니다(**밀레니엄 문제**).

그중 지금까지 풀린 것은 단 하나(푸앵카레 추측)뿐이며, 컴퓨터 과학 분야에서 유일하게 이름을 올린 **P vs NP 문제는 반세기 넘게 여전히 난공불락의 요새**로 남아 있습니다.

이 책은 자매 서적 『람다 계산법과 계산 가능성』의 사유와 자연스럽게 이어집니다.

* **람다 계산법과 튜링 기계**: "어떤 문제를 컴퓨터로 **원리상 계산할 수 있는가(Computable)**?" (계산 가능성의 경계)
* **P vs NP**: "계산할 수 있다면, **현실적인 시간 안에 효율적으로 계산할 수 있는가(Tractable)**?" (계산 복잡도의 경계)

== 왜 수식 없이 가능한가

P vs NP 문제는 복잡한 적분이나 기하학 공식을 요구하지 않습니다.

이 책은 **체스판 위의 쌀알, 스도쿠, 지도 색칠하기, 도미노처럼 연결된 환원, 다이얼 자물쇠** 같은 친숙한 일상의 장면들을 통해, "다항 시간"과 "지수 시간"이 왜 완전히 다른 차원의 세계인지, 그리고 왜 전 세계 수학자들이 이 문제에 매료되었는지를 흥미진진한 이야기로 풀어냅니다.

본문(1~10장)에는 어려운 수학 공식이나 코드가 단 한 줄도 나오지 않습니다.

== 이 책의 구성

이 책은 총 4부와 부록으로 이루어져 있습니다.

....
 [ 1부: 문제와 시간 ]  체스판 쌀알과 속도 ──► P (효율적으로 풀리는 문제들)
                            │
                            ▼
 [ 2부: P와 NP ]      NP (확인은 쉬운 문제들) ──► P = NP인가, P ≠ NP인가?
                            │
                            ▼
 [ 3부: NP-완전 ]     환원 (문제의 갈아끼우기) ──► 도미노 연결망과 2대 증명 장벽
                            │
                            ▼
 [ 4부: 파장과 지도 ]  암호학과 최적화 ──► P=NP 사고 실험 ──► 래드너의 중간 지대
....

* **1부: 문제와 시간 (1~2장)** — "빠르다"는 것의 수학적 기준(다항 시간)을 세우고, 효율적으로 풀 수 있는 문제들의 모임인 **P**를 정의합니다.
* **2부: 확인은 쉬운데 풀기는 어려운 (3~4장)** — 답을 검산하기 쉬운 문제들의 모임인 **NP**를 정의하고, "P가 정말 NP의 전부일까?"라는 핵심 질문을 세웁니다.
* **3부: NP-완전이라는 핵심 (5~7장)** — 문제를 다른 문제로 변환하는 '환원'의 마법을 통해, NP에서 가장 어려운 문제들이 하나로 묶인 **NP-완전(NP-Complete)**과 50년 동안 증명을 가로막은 **2대 증명 장벽**을 살펴봅니다.
* **4부: 실전에서의 의미 (8~10장)** — 이 문제가 현대 인터넷 보안(암호학)과 물류 최적화에 미치는 영향, 만약 $P=NP$로 풀린다면 벌어질 미래, 그리고 우리가 알고 있는 복잡도 지도를 정리합니다.
* **부록 (12장)** — 파이썬으로 '부분집합 합 문제'를 직접 실행하여, 입력 크기가 조금만 커져도 계산 시간이 어떻게 지수적으로 폭발하는지 **백만 배의 실측 데이터**로 검증합니다.

[NOTE]
====
수학이나 프로그래밍 전공자가 아니어도 괜찮습니다. "스도쿠는 풀기보다 확인하기가 훨씬 쉽다"는 일상적인 직관만 가지고 계신다면, 현대 컴퓨터 과학에서 가장 깊고 찬란한 질문 속으로 막힘없이 빠져들 수 있습니다.
====
