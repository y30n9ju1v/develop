5장에서 우리는 환원($A \le_p B$)이 문제들 사이의 난이도 순서를 매기는 강력한 자라는 것을 확인했습니다.

이제 이 도구로 컴퓨터 과학 역사상 가장 위대한 발견 중 하나인 **NP-완전(NP-Complete)**의 세계로 들어갑니다.

== NP의 가장 높은 꼭대기: NP-완전

NP 안에는 수천 개가 넘는 문제들이 존재합니다. 이 문제들 사이에 환원의 화살표를 계속 그리다 보면, 놀랍게도 **모든 화살표가 가리키는 궁극의 종착역**이 드러납니다.

> **NP-완전(NP-Complete) 문제란,  
> 1. 그 문제 자신이 NP에 속하면서(답 확인이 다항 시간),  
> 2. NP에 속하는 【모든 문제】가 다항 시간 안에 이 문제로 환원될 수 있는 가장 어려운 핵심 문제이다.**

....
                    [ 복잡도 클래스의 벤 다이어그램 (P ≠ NP 가정 시) ]

         ┌────────────────────────────────────────────────────────┐
         │  NP-난해 (NP-Hard: NP의 모든 문제가 환원됨)                 │
         │                                                        │
         │       ┌────────────────────────────────────────┐       │
         │       │  NP (답 확인이 다항 시간)                  │       │
         │       │                                        │       │
         │       │     ┌──────────────┐   ┌────────────┐  │       │
         │       │     │      P       │   │  NP-완전   │  │       │
         │       │     │ (풀기도 쉬움) │   │ (NPC, 왕)  │  │       │
         │       │     └──────────────┘   └────────────┘  │       │
         │       │                                        │       │
         │       └────────────────────────────────────────┘       │
         └────────────────────────────────────────────────────────┘
....

NP-완전 문제는 NP라는 거대한 산맥의 가장 높은 정상에 우뚝 솟아 있는 '만능 관문'과 같습니다.

== 최초의 NP-완전 문제: 쿡-레빈 정리와 SAT

1971년 스티븐 쿡(Stephen Cook)과 레오니드 레빈(Leonid Levin)은 독립적으로 세상을 뒤흔든 정리를 증명했습니다.

바로 **SAT(충족 가능성 문제, Boolean Satisfiability)**라는 논리 퍼즐이 최초의 NP-완전 문제임을 수학적으로 증명해 낸 것입니다(**쿡-레빈 정리**).

SAT는 `(x₁ 또는 x₂) 그리고 (아니다 x₁ 또는 x₃)...`처럼 참/거짓 변수들로 얽힌 논리식이 주어졌을 때, 식 전체를 참(`True`)으로 만드는 변수들의 조합이 존재하는지를 묻는 문제입니다.

쿡과 레빈은 **컴퓨터가 실행하는 모든 다항 시간 검증 프로그램의 동작 과정을, 하나의 거대한 SAT 논리식으로 100% 번역할 수 있음**을 증명했습니다 스도쿠든, 외판원 문제든, 단백질 접힘이든, 모든 NP 문제는 본질적으로 SAT 문제로 완벽하게 변환될 수 있다는 뜻입니다.

== 거대한 도미노의 연쇄 폭발

쿡-레빈 정리 이후, 1972년 리처드 카프(Richard Karp)를 비롯한 수학자들은 SAT로부터 환원의 화살표를 뻗어나가며 수천 개의 문제들이 줄줄이 NP-완전임을 밝혀냈습니다.

....
                   [ NP-완전 문제들의 도미노 연결망 ]

                          【 SAT (논리식 충족) 】
                                    │
            ┌───────────────────────┼───────────────────────┐
            ▼                       ▼                       ▼
      [ 3-SAT ]              [ 지도 3색 칠하기 ]       [ 부분집합 합 문제 ]
            │                       │                       │
            ▼                       ▼                       ▼
    [ 클릭(Clique) 찾기 ]    [ 외판원 순회 (TSP) ]     [ 배낭 문제 (Knapsack) ]
                                    │
                                    ▼
       【 도미노 법칙: 단 하나만 P로 풀려도, 전체가 와르르 P로 무너진다 】
....

이 도미노 구조가 의미하는 바는 실로 경이롭습니다.

> **만약 이 수천 개의 NP-완전 문제 중 단 하나라도 다항 시간 알고리즘(P)이 발견된다면,  
> 5장의 환원 법칙에 의해 나머지 모든 NP-완전 문제와 NP 안의 모든 문제가 모조리 다항 시간으로 풀리게 되며,  
> 그 즉시 세상은 `P = NP`로 통일된다.**

[NOTE]
====
**NP-완전(NP-Complete)과 NP-난해(NP-Hard)의 차이**  
* **NP-완전**: NP에 속하면서(답 확인이 쉬움), 동시에 가장 어려운 문제입니다 (위 다이어그램의 NPC 영역).
* **NP-난해**: "NP의 모든 문제가 환원된다"는 조건만 만족하면 되며, 그 문제 자체가 꼭 NP에 속할 필요는 없습니다. 심지어 답 확인조차 다항 시간에 불가능한 극악의 문제(예: 정지 문제, 외판원 문제의 실수 최적값 구하기)도 NP-난해에 속합니다.
====

== P vs NP 질문의 단일화

수천 개에 달하던 막막한 퍼즐들의 모임이, 이 도미노 연결망 덕분에 단 하나의 명확한 질문으로 압축되었습니다.

> **"이 수많은 NP-완전 문제들 중, 단 하나라도 다항 시간에 뚫을 수 있는가?"**

단 하나의 균열만 내면 성채 전체가 무너집니다.

그런데 왜 지난 50년 동안 전 세계의 천재들이 이 좁혀진 성채의 벽돌 하나조차 빼내지 못했을까요? 다음 장에서 그 비밀을 파헤칩니다.

== 요약

* **NP-완전 (NPC)**: NP 안의 모든 문제가 다항 시간 안에 환원될 수 있는, NP에서 가장 어렵고 핵심적인 문제들의 집합입니다.
* **쿡-레빈 정리 (1971)**: 논리식을 다루는 SAT 문제가 최초의 NP-완전 문제임을 증명했습니다.
* **도미노 효과**: 수천 개의 NP-완전 문제 중 단 하나만 다항 시간(P)으로 풀려도 $P=NP$가 성립합니다.
