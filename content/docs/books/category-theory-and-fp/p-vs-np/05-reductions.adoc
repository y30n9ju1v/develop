3부가 시작됩니다. 

NP 안에 존재하는 수천 개의 복잡한 문제들을 하나로 꿰뚫기 위해, 우리는 컴퓨터 과학에서 가장 강력한 렌즈인 **환원(Reduction)**이라는 도구를 장착해야 합니다.

== 문제를 다른 문제로 갈아 끼우기

이런 상황을 상상해 봅시다.

여러분에게 어떤 숫자 목록이든 순식간에 크기 순으로 줄을 세워주는 강력한 **'정렬 블랙박스 기계'**가 하나 주어졌습니다.

그런데 갑자기 상사가 찾아와 **"이 100만 개의 숫자 중에서 가장 큰 값(최댓값)을 찾아오게!"**라는 새로운 문제를 던졌습니다.

....
                   [ 환원(Reduction)의 작동 파이프라인 ]

   【 풀고 싶은 문제 A: 최댓값 찾기 】
   숫자 목록: [ 12, 99, 45, 7, 83 ]
                 │
                 ▼ [다항 시간 입력 변환: 그대로 기계에 전달]
   ┌─────────────────────────────────────────┐
   │    【 이미 있는 기계 B: 정렬 기계 】      │
   │    목록을 크기순으로 정렬한다           │
   └─────────────────────────────────────────┘
                 │
                 ▼ [정렬된 결과: 7, 12, 45, 83, 99]
   맨 마지막 숫자를 확인 ──► 【 99 】 (최댓값 찾기 문제 해결 완료)
....

새로운 최댓값 검색 알고리즘을 밑바닥부터 짤 필요가 전혀 없습니다 목록을 정렬 기계에 넣고 돌린 뒤, 맨 끝에 나온 숫자(`99`)만 쏙 뽑아내면 최댓값이 공짜로 얻어집니다.

이처럼 **"문제 A를 풀기 위해, 입력을 다항 시간 안에 변환하여 문제 B를 푸는 기계에 넣음으로써 A의 답을 얻어내는 기교"**를 **환원(Reduction)**이라고 부르며, 기호로 **`A ≤ₚ B`** ("$A$가 $B$로 다항 시간 환원된다")라고 씁니다.

== 환원이 알려주는 진실: "어느 문제가 더 어려운가?"

환원은 단순한 요령이 아닙니다. **"두 문제 사이의 상대적인 난이도를 측정하는 완벽한 자(Ruler)"** 역할을 합니다.

....
                    [ 환원 A ≤ₚ B 가 알려주는 2가지 법칙 ]

      A를 B로 환원할 수 있다 (A ≤ₚ B) ──► 【 B가 최소한 A만큼은 어렵다 】
                                              │
         ┌────────────────────────────────────┴────────────────────────────────────┐
         ▼                                                                         ▼
   【 법칙 1: 지름길의 전파 】                                            【 법칙 2: 난이도의 전파 】
   "만약 B를 빠르게 풀 수 있다면,                                         "만약 A가 도저히 빠르게 안 풀린다면,
    A도 공짜로 빠르게 풀린다"                                             B도 결코 빠르게 풀릴 수 없다"
....

1. **지름길의 전파**: 만약 누군가 $B$(정렬)를 다항 시간에 푸는 기막힌 알고리즘을 찾아낸다면, $A$(최댓값 찾기)도 그 기계를 빌려 써서 다항 시간 안에 자동으로 풀립니다.
2. **난이도의 전파**: 만약 $A$가 너무 어려워서 다항 시간 안에 절대 안 풀린다는 것이 증명된다면, $B$ 역시 절대 다항 시간 안에 풀릴 수 없습니다 ($B$가 풀리면 $A$도 풀려야 하니까요).

[NOTE]
====
**흔히 헷갈리는 지점: $A \le_p B$일 때 어느 쪽이 더 어려운 문제인가요?**  
부등호 방향(`A ≤ B`)을 보세요 $A$를 풀기 위해 $B$라는 강력한 만능 도구를 빌려 썼으므로, **$B$가 $A$보다 더 어렵거나 최소한 같은 난이도(B ≥ A)**라는 뜻입니다. 최댓값 찾기($A$)보다 정렬($B$)이 훨씬 더 많은 정보와 수고를 요구하는 무거운 문제라는 현실과 완벽히 일치합니다.
====

== 환원이 만들어내는 기적

NP 안에는 스도쿠, 지도 색칠하기, 부분집합 합, 여행하는 외판원 등 겉보기에 완전히 다른 수천 개의 퍼즐이 흩어져 있습니다.

이 문제들을 하나하나 개별적으로 연구하는 것은 불가능에 가깝습니다.

하지만 환원이라는 렌즈를 들이대면, 이 수천 개의 문제들이 사실 **그물망처럼 서로에게 환원되며 촘촘하게 엮여 있다**는 놀라운 지도가 드러납니다.

그리고 다음 장에서, 이 거대한 연결망의 가장 높은 꼭대기에 앉아 있는 보스 몬스터, **'NP-완전(NP-Complete)'**을 만나게 됩니다.

== 요약

* **환원 (`A ≤ₚ B`)**: 문제 $A$의 입력을 다항 시간 안에 변환하여 문제 $B$의 알고리즘으로 $A$를 풀어내는 기법입니다.
* **난이도 비교**: $A \le_p B$는 "$B$가 최소한 $A$만큼은 어렵다"는 뜻이며, $B$가 풀리면 $A$도 풀립니다.
* **지도의 구축**: 환원을 통해 수천 개의 복잡한 NP 문제들 사이의 난이도 계층 지도를 그릴 수 있습니다.
