3장에서 우리는 `P ⊆ NP`(풀 수 있으면 확인도 쉽다)라는 명백한 한쪽 방향의 포함 관계를 확인했습니다.

이제 이 책 전체를 관통하는 진짜 질문을 던질 차례입니다.

> **"혹시 반대 방향도 성립할까? 즉, 답을 확인하기 쉬운 문제(NP)는 전부 사실 풀기도 쉬운(P) 문제인 것은 아닐까?"**

이 질문이 바로 **P vs NP 문제**입니다.

== 두 개의 서로 다른 세계관

우리가 살고 있는 우주는 과연 다음 두 세계 중 어느 쪽에 속해 있을까요?

....
                    [ P vs NP가 그리는 두 세계관 ]

      【 세계 1: P = NP 일 때 】              【 세계 2: P ≠ NP 일 때 】
      ┌─────────────────────────┐            ┌─────────────────────────┐
      │                         │            │  NP (확인이 쉬운 문제)     │
      │         P = NP          │            │    ┌──────────────┐     │
      │   (풀기와 확인하기가       │            │    │  P (풀기도    │     │
      │    완벽하게 일치함)     │            │    │    쉬운 문제) │     │
      │                         │            │    └──────────────┘     │
      └─────────────────────────┘            └─────────────────────────┘
      "확인할 수 있는 모든 퍼즐은,             "확인은 쉬워도 풀기는 본질적으로
       빠르게 푸는 지름길이 존재한다"          어려운 문제가 실제로 존재한다"
....

1. **만약 $P = NP$라면**: 스도쿠, 최적 배송 경로, 단백질 구조 예측처럼 "답을 검산하기 쉬운 모든 문제"는, 사실 전부 다항 시간 안에 정답을 뚝딱 찾아내는 기막힌 알고리즘이 존재한다는 뜻입니다.
2. **만약 $P \neq NP$라면**: 우리가 스도쿠나 외판원 문제 앞에서 느끼는 "확인은 10초인데 풀기는 왜 이렇게 오래 걸리지?"라는 답답함이, 인간의 무능 탓이 아니라 **우주와 논리의 본질적인 한계선**이라는 뜻입니다.

== 우리의 직관 vs 수학적 증명

우리의 일상적 직관은 강력하게 **"$P \neq NP$일 것이다"**라고 외칩니다.

스도쿠를 10초 만에 채점하는 것과 텅 빈 스도쿠를 처음부터 푸는 것은 상식적으로 완전히 다른 차원의 일처럼 느껴지기 때문입니다. 실제로 전 세계 컴퓨터 과학자의 90% 이상은 $P \neq NP$일 것이라고 믿고 있습니다.

하지만 **직관은 증명이 아닙니다.**

지난 50년 동안 "확인하기 쉬운 문제 중에 절대 다항 시간으로 풀 수 없는 문제가 존재한다"는 사실을 수학적으로 증명해 낸 사람은 단 한 명도 없습니다. 반대로 "모든 NP 문제는 사실 다항 시간으로 풀린다($P=NP$)"는 것을 증명한 사람도 없습니다.

[NOTE]
====
**"지금까지 아무도 빠른 방법을 못 찾았으니 $P \neq NP$ 아닌가요?"**  
2장에서 본 소수 판정 문제를 떠올려 보세요 수천 년 동안 아무도 다항 시간 알고리즘을 못 찾아서 다들 "소수 판정은 P가 아닐 것"이라고 생각했지만, 2002년에 기발한 알고리즘(AKS)이 홀연히 등장하며 P로 들어왔습니다. "지금까지 못 찾았다"는 것은 강력한 정황 증거일 뿐, 수학적 증명이 결코 될 수 없습니다.
====

== 상금 100만 달러의 무게

이 질문 하나에 클레이 수학연구소가 100만 달러의 현상금을 걸고, 수많은 천재가 평생을 바쳐 매달리는 이유가 무엇일까요?

만약 $P = NP$가 참으로 밝혀진다면, 암호학, 인공지능, 물류, 의학, 수학 증명에 이르기까지 **인류 문명 전체의 기술적 패러다임이 하루아침에 완전히 뒤바뀌기 때문**입니다 (이 놀라운 파장은 4부에서 자세히 다룹니다).

== 요약

* **P vs NP의 핵심**: "답을 확인하기 쉬운 문제(NP)는 전부 빠르게 풀 수도 있는가($P=NP$)?"를 묻는 미해결 난제입니다.
* **$P=NP$의 세계**: 검증 가능한 모든 문제에 효율적인 풀이법이 존재하는 세계입니다.
* **$P \neq NP$의 세계**: 확인은 쉬워도 풀기는 본질적으로 불가능하게 어려운 벽이 존재하는 세계입니다.
* **미해결의 상태**: 대부분의 학자가 $P \neq NP$를 믿지만, 지난 반세기 동안 그 누구도 증명하지 못했습니다.

[TIP]
====
**확인 질문**: $P \subseteq NP$(3장의 내용)는 왜 이미 증명된 당연한 사실이고, $NP \subseteq P$(즉 $P=NP$)는 왜 지금까지 아무도 풀지 못한 미해결 난제인지 두 방향의 차이를 머릿속으로 정리해 보세요
====
