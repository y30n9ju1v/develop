'''

1장에서 우리는 다항 시간과 지수 시간이 왜 완전히 다른 세계인지를 체감했습니다.

이제 이 명확한 기준선을 바탕으로, 컴퓨터 과학에서 가장 기본이 되는 문제들의 모임인 **P**를 정의해 봅시다.

== P의 정의: "다항 시간 안에 풀 수 있는 문제들의 모임"

**P**는 영어 **Polynomial Time(다항 시간)**의 앞 글자를 딴 것으로, **"다항 시간 안에 답을 내는 알고리즘이 존재하는 모든 판정 문제(Decision Problem)들의 집합"**입니다.

....
                   [ 복잡도 클래스 P (Polynomial Time) ]
                 ┌───────────────────────────────────────┐
                 │  • 숫자 정렬하기 (Sorting)             │
                 │  • 최단 경로 찾기 (Shortest Path)     │
                 │  • 두 수 곱셈하기 (Multiplication)    │
                 │  • 소수인지 판별하기 (Primality Test)  │
                 │  • 최대공약수 구하기 (GCD)             │
                 └───────────────────────────────────────┘
                                     │
                                     ▼
                   【 "컴퓨터로 효율적으로 풀 수 있는 문제들" 】
....

대표적으로 다음과 같은 문제들이 P에 속합니다.

1. **숫자 목록 정렬하기**: $n$개의 숫자를 크기 순서대로 줄 세우는 문제. 아무리 숫자가 많아도 $n \log n$이나 $n^2$ 정도의 계산 횟수면 완벽하게 정렬됩니다.
2. **지도에서 최단 경로 찾기**: 내비게이션이 두 도시 사이의 가장 빠른 길을 찾는 문제(다익스트라 알고리즘). 도시와 도로 개수의 다항 시간 안에 정확한 최단 경로가 나옵니다.
3. **두 수의 곱셈**: 초등학교 때 배운 세로셈 곱셈도 자릿수의 다항 시간($n^2$) 안에 끝납니다.

이 문제들의 공통점은, 인류가 이미 **"이렇게 하면 다항 시간 안에 무조건 정답이 나온다"는 구체적인 레시피(알고리즘)를 손에 쥐고 있다는 사실**입니다.

== "풀 수 있다"와 "풀 수 있는 방법을 안다"의 결정적 차이

여기서 초보자가 가장 많이 빠지는 함정이 있습니다.

어떤 문제가 P에 속하는지 아닌지는, 그 문제가 "원리상 계산 가능한가"가 아니라 **"다항 시간 알고리즘이 실제로 발견되었거나 존재함이 증명되었는가"**의 문제입니다.

이 차이를 극명하게 보여주는 역사적 사건이 바로 **'소수 판정(Primality Testing)'** 문제입니다.

....
                 [ 소수 판정 문제의 P 입성 타임라인 ]

   기원전 300년 (에라토스테네스) ──► 소수인지 하나하나 나눠본다 (지수 시간 소요)
                                           │
                                           ▼ (수천 년간 "P에 속하는지 모름" 상태)
   2002년 (아그라왈, 카얄, 작세나) ──► 【 AKS 소수판정법 발명 】
                                           │
                                           ▼
   [ 드디어 '소수 판정 문제'가 공식적으로 P 클래스에 입성함 ]
....

"어떤 큰 수 $N$이 소수인가?"라는 문제는 수천 년 동안 "지수 시간이 걸리는 어려운 문제"로 여겨졌습니다. 하지만 2002년, 인도 공과대학교의 교수와 학부생들이 **AKS 소수판정법**이라는 다항 시간 알고리즘을 발표하면서, 이 문제는 비로소 공식적으로 **P**의 영역으로 들어왔습니다.

문제 자체는 2002년 전이나 후나 똑같았지만, **"우리가 빠른 알고리즘을 찾아냈는가"**에 의해 P의 지도가 확장된 것입니다.

[NOTE]
====
**P에 속하지 않는다는 것은 계산이 불가능하다는 뜻인가요?**  
전혀 아닙니다 『람다 계산법』에서 다룬 정지 문제(Halting Problem)처럼 '원리상 영원히 계산할 수 없는 문제'와, 이 책에서 다루는 '계산은 얼마든지 가능한데 다항 시간 안에 안 될 것 같은 문제'는 완전히 다른 차원의 이야기입니다. P 바깥에 있는 문제들도 시간이 몇백 년 걸릴 뿐, 컴퓨터로 답을 내는 것 자체는 100% 가능합니다.
====

== 왜 P라는 모임을 만들어 두었을까?

P라는 명확한 기준 상자를 만들어두면 엄청난 장점이 생깁니다.

어떤 생소한 새로운 문제를 만났을 때, 그 문제의 복잡한 알고리즘을 처음부터 밑바닥부터 새로 개발할 필요 없이, **"이 문제가 이미 P에 속해 있는 기존 문제(예: 최단 경로)로 쉽게 바꿔치기(환원)될 수 있는가?"**만 검사하면 그 문제 역시 공짜로 P에 속한다는 사실을 즉시 증명할 수 있기 때문입니다.

이 '문제 갈아끼우기' 기술이 5장에서 다룰 **환원(Reduction)**입니다.

== 요약

* **복잡도 클래스 P**: 다항 시간 알고리즘이 존재하여, 현실적인 시간 안에 컴퓨터로 효율적으로 풀 수 있는 판정 문제들의 모임입니다.
* **알고리즘의 존재성**: 소수 판정 문제의 역사처럼, 다항 시간 알고리즘이 수학적으로 발견되고 증명되어야 P에 속하게 됩니다.
* **계산 가능성과의 구분**: P에 속하지 않는 문제라도 계산 자체가 불가능한 것은 아니며, 단지 계산량이 지수적으로 폭발할 뿐입니다.

[TIP]
====

====
