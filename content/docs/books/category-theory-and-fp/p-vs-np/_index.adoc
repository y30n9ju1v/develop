스도쿠는 풀기는 어려운데 답이 맞는지 확인하는 건 순식간이라는 사소한 관찰에서 출발해, 컴퓨터 과학에서 가장 유명한 미해결 문제인 P vs NP를 수식 없이 비유와 논증으로 풀어가는 책입니다. 다항 시간과 지수 시간이 왜 완전히 다른 세계인지(체스판의 쌀알)에서 시작해, NP-완전이라는 개념이 어떻게 수천 개의 서로 다른 문제를 하나로 묶어내는지, 그리고 이 문제가 왜 반세기 넘게 증명도 반증도 되지 않았는지까지 다룹니다.
