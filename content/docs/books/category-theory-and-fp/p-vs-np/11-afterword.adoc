== 우리가 함께 지나온 찬란한 길

우리는 스도쿠의 작은 빈칸에서 출발하여 현대 컴퓨터 과학의 가장 거대한 우주를 탐험했습니다. 우리가 지나온 눈부신 이정표들을 돌아봅시다.

....
 [ 1부: 문제와 시간 ]   체스판의 쌀알 (지수 폭발) ──► 다항 시간과 P 클래스
                             │
                             ▼
 [ 2부: P와 NP ]       스도쿠의 검산 (NP 클래스) ──► P ⊆ NP와 P vs NP 질문
                             │
                             ▼
 [ 3부: NP-완전 ]      정렬 기계와 환원 (A ≤ₚ B) ──► 쿡-레빈 SAT와 2대 증명 장벽
                             │
                             ▼
 [ 4부: 실전과 지도 ]   RSA 암호와 근사 최적화 ──► P=NP 미래 ──► 래드너의 NPI
....

1. **1부**에서는 체스판 위의 쌀알 전설로 다항 시간($n^k$)과 지수 시간($2^n$)의 본질적 차이를 체감하고, 효율적 풀이의 대명사인 **P**를 정의했습니다.
2. **2부**에서는 스도쿠의 "풀기는 어려운데 확인은 순식간이다"라는 감각을 **NP**라는 엄밀한 모임으로 다듬고, "확인 쉬운 문제가 전부 풀기도 쉬운가?"라는 핵심 질문을 세웠습니다.
3. **3부**에서는 문제를 갈아끼우는 **환원**의 기교로 NP-완전(NPC) 문제들이 촘촘한 도미노로 연결되어 있음을 밝히고, 왜 50년간 증명이 막혔는지 **2대 장벽**을 보았습니다.
4. **4부**에서는 이 난제가 현대 인터넷 암호와 물류 최적화를 지탱하는 방식, $P=NP$가 가져올 창조성의 혁명, 그리고 **래드너 정리의 중간 지대(NPI)**를 조망했습니다.

== 계산 이론 3부작이 완성한 하나의 큰 그림

이 책은 자매 서적인 『람다 계산법과 계산 가능성』, 그리고 『괴델의 불완전성 정리』와 함께 **계산과 진리의 3대 층위**를 완성합니다.

....
                 [ 계산과 진리에 대한 현대 과학의 3대 질문 ]

   1단계 (처치·튜링)  : "어떤 문제를 기계로 【계산할 수 있는가】?" (정지 문제)
                               │
                               ▼
   2단계 (괴델)       : "어떤 수학적 참을 기계로 【증명할 수 있는가】?" (불완전성)
                               │
                               ▼
   3단계 (쿡·카프·레빈): "계산할 수 있다면, 【현실적인 시간 안에】 가능한가?" (P vs NP)
....

이 세 권을 관통하는 하나의 거대한 진실은, **"우리가 상상할 수 있는 진리와 계산의 세계는 그 어떤 닫힌 기계적 규칙이나 알고리즘보다도 항상 더 광대하다"**는 사실입니다.

== 정직하게 남겨두는 것들

초보자 독자가 수식의 미로에 빠지지 않고 전체 뼈대를 세울 수 있도록, 다음의 전문적인 주제들은 의도적으로 남겨두었습니다.

1. **비결정적 튜링 기계(NDTM)의 형식적 상태 전이**: 3장에서 다룬 '분신술을 쓰는 가상 컴퓨터'의 엄밀한 수학적 전이 함수($\delta$) 정의는 생략했습니다.
2. **쿡-레빈 정리의 실제 대수 전개**: 임의의 튜링 기계 테이프 상태를 SAT 논리식 기호로 100% 매핑하는 형식적 증명 과정은 다루지 않았습니다.
3. **더 높은 복잡도 계층 (Complexity Hierarchy)**: 메모리 공간을 다루는 PSPACE, 지수 시간을 다루는 EXPTIME, 그리고 다항 계층(PH) 등의 심화 지도는 다루지 않았습니다.
4. **양자 컴퓨터와 BQP**: 쇼어 알고리즘(Shor's Algorithm)으로 소인수분해를 다항 시간에 푸는 양자 복잡도 클래스(BQP)의 상세 내용은 범위 밖으로 두었습니다.
