== 지지직거리는 전화선과 '채널'

오래된 전화기로 통화할 때를 떠올려 봅시다. 내가 "네"라고 말했는데 전화선에 섞인 잡음 때문에 상대방 귀에는 "내"나 "대"로 잘못 들릴 수 있습니다.

정보 이론에서는 신호가 송신자에게서 수신자에게로 건너가는 모든 물리적 통로(구리 전선, 공기 중의 전파, 광케이블, 심지어 종이에 연필로 쓴 글자까지)를 **채널(Channel)**이라고 부릅니다.

== 이진 대칭 채널 (BSC): 가장 완벽한 수학적 모델

섀넌은 현실의 온갖 복잡한 노이즈를, 가장 단순하고 아름다운 수학적 모델인 **이진 대칭 채널(Binary Symmetric Channel, BSC)**로 압축했습니다.

송신자가 `0` 또는 `1`을 전송할 때, 전선 속의 잡음 때문에 **일정한 확률 $p$로 비트가 반대로 뒤집혀서 도착하는 채널**입니다.

....
                   [ 이진 대칭 채널 (BSC)의 전이 확률도 ]

       【 송신 신호 】                                  【 수신 신호 】

                               1 - p (정상 전달)
                  0 ──────────────────────────────────────► 0
                     ╲                                  ╱
                       ╲                              ╱
                         ╲  p (오류 뒤집힘)          ╱  p (오류 뒤집힘)
                           ╲                      ╱
                             ╲                  ╱
                                ╲            ╱
                  1 ──────────────────────────────────────► 1
                               1 - p (정상 전달)
....

* $0$을 보냈을 때: $1-p$의 확률로 정상 $0$ 도착, $p$의 확률로 에러 $1$ 도착
* $1$을 보냈을 때: $1-p$의 확률로 정상 $1$ 도착, $p$의 확률로 에러 $0$ 도착

이 $p$라는 오류 확률 하나가 채널의 성능을 완벽하게 요약합니다.

[NOTE]
====
**오류 확률 $p = 1$(100% 뒤집힘)이 가장 나쁜 채널인가요?**  
직관과 정반대의 놀라운 결론이 있습니다  
* **$p = 1$인 채널**: 항상 100% 반대로 뒤집혀서 오므로, 수신자가 받은 신호를 그냥 한 번 더 반대로 뒤집기만 하면 **100% 완벽한 원본 복원이 가능한 훌륭한 채널**입니다
* **진짜 최악의 쓸모없는 채널**: 바로 **$p = 0.5$ (50% 확률로 뒤집힘)**인 채널입니다. 수신자가 받은 신호가 원본과 아무런 상관없이 그냥 동전을 던진 난수와 같아서, 원본에 대한 단 1비트의 힌트도 주지 못하기 때문입니다.
====

== 노이즈에 맞서는 가장 단순한 무기: 반복 전송

노이즈 때문에 비트가 뒤집힐 위험이 있다면, 가장 상식적인 해결책은 무엇일까요? 바로 **똑같은 말을 여러 번 반복하는 것**입니다.

`0`을 보내고 싶다면 `000`을 3번 보내고, 받는 쪽에서는 **다수결(Majority Vote)**로 판정합니다.

....
                    [ 3회 반복 전송과 다수결 복원 ]

     보낸 신호: 0  ──► [ 3회 반복: 0 0 0 전송 ] ──► (잡음 통과)
                                                        │
                                                        ▼
                        수신된 신호: [ 0 1 0 ] (가운데 1비트 뒤집힘 발생)
                                        │
                                        ▼ 다수결 판정: "0이 2개니까 원래 0이었다"
                        복원된 신호: 【 0 】 (오류 정정 성공)
....

비트가 1개 뒤집혀도 다수결로 원본을 완벽히 복원해 냅니다 3개 중 2개 이상이 동시에 뒤집힐 확률은 $p$ 하나보다 훨씬 작기 때문에 오류율이 크게 떨어집니다.

== 반복 전송의 치명적인 대가

하지만 이 소박한 방법에는 너무나 뼈아픈 대가가 따릅니다.

1비트의 정보를 보내기 위해 전선에 3비트를 쏟아부어야 하므로, **전송 속도가 1/3(33%)로 폭락**합니다.

만약 오류율을 우주 탐사선 수준으로 낮추기 위해 5번(`00000`), 7번(`0000000`) 반복한다면, 전송 속도는 1/5, 1/7로 한없이 바닥을 향해 곤두박질칩니다.

당대 공학자들은 깊은 절망에 빠져 있었습니다.
> *"노이즈가 있는 채널에서는, 오류율을 0으로 만들려고 할수록 전송 속도를 0으로 희생해야만 하는가?"*

다음 장에서 섀넌이 이 절망을 단번에 깨뜨린 **역사상 가장 충격적인 정리**를 선언합니다.

== 요약

* **채널 (Channel)**: 신호가 전송되는 물리적 통로로, 필연적으로 노이즈(오류 확률 $p$)가 개입합니다.
* **이진 대칭 채널 (BSC)**: $p$의 확률로 비트가 뒤집히는 채널로, $p=0.5$일 때가 최악의 상태입니다.
* **반복 전송의 한계**: 단순 반복은 오류율을 낮출 수 있지만 전송 속도를 치명적으로 깎아먹는 한계가 있습니다.

[TIP]
====
**확인 질문**: $p = 0.5$인 채널에서는 왜 100번, 1000번 반복해서 전송하더라도 다수결로 원래 메시지를 결코 알아낼 수 없는지, 동전 던지기 비유로 설명해 보세요
====
