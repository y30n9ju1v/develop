'''

1장에서 우리는 단일 사건 하나의 정보량($I = \log_2(1/p)$)을 측정했습니다.

이제 질문을 한 단계 더 확장해 봅시다.

> **"어떤 동전이나 주사위를 던졌을 때, 우리는 '평균적으로' 매번 몇 비트의 정보를 얻게 될까요?"**

이 질문에 답하는 도구가 바로 정보 이론의 왕관, **엔트로피(Entropy)**입니다.

== 찌그러진 동전은 덜 놀랍다

정상적인 동전(앞면 50%, 뒷면 50%)을 던지면 매번 1비트의 온전한 정보를 얻습니다.

그런데 한쪽으로 심하게 찌그러져서 **앞면이 나올 확률이 99%인 마법의 동전**이 있다고 해봅시다.

이 동전을 던지면:
* **앞면이 나올 때 (99% 확률)**: 너무 뻔해서 정보량이 거의 0입니다 ($-\log_2(0.99) \approx 0.014$ 비트).
* **뒷면이 나올 때 (1% 확률)**: 엄청난 대사건이므로 정보량이 큽니다 ($-\log_2(0.01) \approx 6.64$ 비트).

하지만 뒷면은 100번에 1번 꼴로만 나옵니다. 따라서 이 찌그러진 동전을 던질 때 우리가 **평균적으로 얻는 정보량**은 정상 동전보다 훨씬 적을 수밖에 없습니다. 결과를 거의 항상 "앞면이겠지"라고 뻔히 예측할 수 있기 때문입니다.

== 엔트로피: 정보량의 확률 가중 평균

이처럼 어떤 시스템에서 일어날 수 있는 모든 결과의 정보량을 확률에 따라 평균 낸 값을 **엔트로피(Entropy, $H$)**라고 부릅니다.

> **엔트로피 = (각 사건의 정보량 $\times$ 그 사건이 일어날 확률)의 총합**  
> $$H(X) = \sum p(x) \cdot \log_2\left(\frac{1}{p(x)}\right) = -\sum p(x) \log_2 p(x)$$

....
                 [ 정상 동전 vs 찌그러진 동전의 엔트로피 비교 ]

   【 정상 동전 (앞 50%, 뒤 50%) 】
   • H = (0.5 × 1비트) + (0.5 × 1비트) = 【 1.00 비트 】 (불확실성 최대)

   【 찌그러진 동전 (앞 99%, 뒤 1%) 】
   • H = (0.99 × 0.014비트) + (0.01 × 6.64비트) = 【 약 0.08 비트 】 (거의 확실함)
....

결과를 예측하기 쉬울수록 엔트로피는 0에 가까워지고, 결과를 전혀 종잡을 수 없을수록 엔트로피는 커집니다

== 엔트로피가 가장 커지는 순간: 완전한 균등

동전의 앞면 확률 $p$를 0부터 1까지 변화시키며 엔트로피를 그래프로 그려보면 다음과 같은 완벽한 대칭 포물선이 나타납니다.

....
                   [ 동전의 앞면 확률 p에 따른 엔트로피 곡선 ]

     엔트로피 H(X) (비트)
        1.0 ▲                     [ 정점: p = 0.5 ] (H = 1.0 비트)
            │                           ▲
        0.8 │                         .─' `─.
            │                       .'       `.
        0.6 │                      /           \
            │                    .'             `.
        0.4 │                   /                 \
            │                 .'                   `.
        0.2 │               .'                       `.
          0 └──────────────┴────────────┴─────────────┴────────► 앞면 확률 p
                         p = 0        p = 0.5       p = 1.0
                      (항상 뒷면)    (완전 공평)   (항상 앞면)
....

* $p = 0$ 또는 $p = 1$일 때: 결과가 100% 확정되어 있으므로 불확실성이 0, 즉 **엔트로피 = 0비트**입니다.
* $p = 0.5$일 때: 어느 쪽이 나올지 가장 알 수 없는 상태이므로 **엔트로피 = 최대 1비트**입니다.

모든 사건의 확률이 완벽하게 균등할 때, 인류가 감당해야 할 불확실성(엔트로피)은 최고조에 달합니다.

== 손으로 확인하는 세 갈래 상자

조금 더 흥미로운 예시를 계산해 봅시다.

어떤 상자에 공 4개가 들어있습니다: **빨간 공 2개($p = 1/2$), 파란 공 1개($p = 1/4$), 노란 공 1개($p = 1/4$)**.

1. **각 공의 정보량**:
   * 빨강: $\log_2(2) = 1$ 비트
   * 파랑: $\log_2(4) = 2$ 비트
   * 노랑: $\log_2(4) = 2$ 비트
2. **상자의 엔트로피**:
   * $H = \left(\frac{1}{2} \times 1\right) + \left(\frac{1}{4} \times 2\right) + \left(\frac{1}{4} \times 2\right) = \mathbf{1.5\text{ 비트}}$

놀랍게도 이 $1.5$비트라는 숫자는, "빨간 공인가?"를 묻고 아니라면 "파란 공인가?"를 묻는 스무고개 전략을 쓸 때 **필요한 평균 질문 횟수($1.5$회)**와 완벽하게 일치합니다

엔트로피는 곧 **"결과를 맞히기 위해 평균적으로 던져야 하는 예/아니오 질문의 최소 개수"**입니다.

   【 서가 A: 책의 99%가 '소설' 서가에 쏠림 】
   • 일단 소설 서가로 달려가면 대부분 찾음 ──► 【 엔트로피 낮음 (예측 쉬움) 】

   • 어디를 뒤져야 할지 전혀 감을 못 잡음 ──► 【 엔트로피 높음 (예측 어려움) 】
....

[NOTE]
====
**엔트로피를 '무질서함'이라고만 이해하면 왜 위험한가요?**  
열역학의 영향으로 엔트로피를 어수선한 방 같은 '무질서'로만 생각하기 쉽습니다. 하지만 정보 이론에서 엔트로피는 **"결과를 알아내기 위해 우리가 평균적으로 몇 비트의 추가 정보가 필요한가?"**를 가리키는 대단히 구체적이고 실용적인 척도입니다.
====

== 왜 엔트로피가 정보 이론의 중심인가?

엔트로피는 이 책 전체를 관통하는 '절대 기준선'입니다.

1. **2부 (압축)**: 어떤 데이터를 압축할 때, 아무리 뛰어난 프로그램을 써도 **엔트로피 이하로는 절대 줄일 수 없습니다** (압축의 한계).
2. **3부 (통신)**: 잡음이 섞인 통신선에서 오류 없이 보낼 수 있는 데이터의 한계(채널 용량) 역시 **엔트로피의 언어로 계산**됩니다 (통신의 한계).

== 요약

* **엔트로피 ($H$)**: 시스템에서 발생하는 모든 사건의 정보량을 확률로 가중 평균한 값으로, 시스템의 전체적인 '불확실성의 크기'를 잽니다.
* **최대 엔트로피**: 모든 사건이 균등한 확률로 발생할 때 불확실성이 극대화됩니다.
* **질문의 횟수**: 엔트로피는 스무고개 놀이에서 정답을 맞히기 위해 평균적으로 필요한 '예/아니오 질문의 개수'와 같습니다.
