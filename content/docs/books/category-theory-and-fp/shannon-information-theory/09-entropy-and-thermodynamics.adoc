'''

우리가 1부부터 계속 사용해 온 **'엔트로피'**라는 신비로운 단어는, 사실 정보 이론이 처음 만든 말이 아닙니다.

19세기 물리학의 꽃이었던 **열역학(Thermodynamics)**에서 기체와 열의 움직임을 설명하기 위해 이미 사용되던 단어였습니다.

정보를 다루는 수학 이론과, 증기기관을 다루는 물리학 법칙이 왜 똑같은 단어와 수학 공식을 공유하고 있을까요?

== 열역학의 엔트로피: 무질서의 척도

물리학에서 엔트로피는 **"시스템이 얼마나 무질서하게 흩어져 있는가"**를 측정하는 물리량입니다.

방 안에서 향수병 뚜껑을 열면, 향기 분자들은 처음에는 병 입구에 얌전하게 뭉쳐있지만(낮은 엔트로피, 질서 정연함), 시간이 지나면 방 전체로 고르게 퍼져나갑니다(높은 엔트로피, 무질서함).

**열역학 제2법칙**은 "외부의 개입이 없는 닫힌 우주에서, 엔트로피는 시간이 지남에 따라 절대로 저절로 줄어들지 않는다"고 선언합니다. 퍼진 향수가 저절로 병 속으로 다시 모이는 일은 영원히 일어나지 않습니다.

== 왜 똑같은 수학 공식을 공유할까?

놀랍게도 19세기 물리학자 루트비히 볼츠만(Ludwig Boltzmann)이 세운 열역학 엔트로피 공식($S = k \ln \Omega$)과, 섀넌이 세운 정보 엔트로피 공식($H = -\sum p \log p$)은 **본질적으로 100% 동일한 수학적 형태**를 띠고 있습니다.

....
                 [ 열역학 엔트로피 vs 정보 엔트로피의 일치 ]

   【 향수 분자가 병 속에 뭉쳐있을 때 】 ──► 【 찌그러진 동전 (앞면 99%) 】
   • 분자가 위치할 수 있는 경우의 수 적음     • 결과가 뻔해서 예측하기 쉬움
   • [ 열역학 엔트로피 낮음 (질서) ]          • [ 정보 엔트로피 낮음 (낮은 불확실성) ]
                       ▲                                      ▲
                       │                                      │
   【 향수 분자가 방 전체로 퍼졌을 때 】 ──► 【 공평한 동전 (50% vs 50%) 】
   • 분자가 어디 있을지 경우의 수 폭발       • 어느 쪽이 나올지 전혀 모름
   • [ 열역학 엔트로피 높음 (무질서) ]        • [ 정보 엔트로피 높음 (최대 불확실성) ]
....

기체 분자의 위치든 컴퓨터 비트의 상태든, **"경우의 수가 많아져서 어디에 무엇이 있는지 예측하기 어려워질수록(불확실성이 클수록) 엔트로피가 커진다"**는 단 하나의 거대한 원리가 물리 세계와 정보 세계를 동시에 관통하고 있는 것입니다.

== 100년의 수수께끼: 맥스웰의 도깨비 (1867)

이 두 엔트로피가 실제로 하나의 실체임을 입증한 역사적인 사고 실험이 있습니다. 바로 물리학자 제임스 클러크 맥스웰이 제안한 **맥스웰의 도깨비(Maxwell's Demon)**입니다.

....
                   [ 맥스웰의 도깨비 사고 실험 ]

                 【 방 A (차가움) 】         【 방 B (뜨거움) 】
                ┌───────────────────┬───────────────────┐
                │        • (느림)   │   (빠름) ──►      │
                │                   │•                  │
                │        ◄── (느림) │                   │
                │                   │                   │
                └───────────────────┴───────────────────┘
                                    ▲
                               【 도깨비 】
                "빠른 분자가 오면 오른쪽 문을 열어주고,
                 느린 분자가 오면 왼쪽 문을 열어준다"
....

기체가 든 상자 한가운데 작은 문을 만들고, 아주 작은 지능을 가진 '도깨비'가 문을 지킵니다.
* 오른쪽으로 달려오는 **빠른 분자(뜨거움)**가 오면 문을 열어 오른쪽 방(B)으로 보냅니다.
* 왼쪽으로 달려오는 **느린 분자(차가움)**가 오면 문을 열어 왼쪽 방(A)으로 보냅니다.

도깨비는 문을 여닫는 미세한 힘 외에는 아무런 에너지를 쓰지 않았는데, 방의 한쪽은 저절로 뜨거워지고 다른 쪽은 차가워지며 **우주의 엔트로피가 저절로 줄어드는(열역학 제2법칙 위반) 기적**이 일어납니다.

이 역설은 100년 동안 물리학자들을 괴롭혔습니다.

== 정보 이론이 역설을 풀다: "정보는 물리적이다"

1961년 롤프 란다우어(Rolf Landauer)와 1982년 찰스 베넷(Charles Bennett)은 **섀넌의 정보 이론을 이용해 이 미스터리를 완벽하게 해결**했습니다.

....
                    [ 맥스웰의 도깨비가 치른 진짜 대가 ]

      1. 도깨비가 분자의 속도를 관찰함 ──► 【 1비트의 정보를 머릿속에 저장 】
      2. 분자를 방으로 통과시킴       ──► 【 상자 내부의 열역학 엔트로피 감소 】
      3. 다음 분자를 관찰하기 위해   ──► 【 머릿속의 1비트 메모리를 삭제해야 함 】
                                                     │
                                                     ▼
      【 란다우어의 원리: 1비트의 정보를 지울 때, 반드시 최소한의 열이 방출된다 】
      ──► [ 도깨비가 방출한 열역학 엔트로피 ] ≥ [ 상자 안에서 줄어든 엔트로피 ]
      ──► 결론: 【 우주 전체의 엔트로피는 결코 줄어들지 않았다 】
....

도깨비가 다음 분자를 분류하려면, 자신의 뇌(메모리)에 적어둔 이전 분자의 정보를 지워야 합니다.

**컴퓨터 메모리에서 1비트의 정보를 지우는 행위(Information Erasure)는, 물리학적으로 반드시 주변으로 최소 $k T \ln 2$ 만큼의 열을 방출(엔트로피 증가)**시킵니다(**란다우어의 원리**).

도깨비가 만들어낸 질서보다, 도깨비가 정보를 처리하고 지우면서 발생시킨 물리적 엔트로피가 더 컸기 때문에 열역학 제2법칙은 완벽하게 지켜졌습니다.

== 서랍 정리에 비유하기

....
                       [ 서랍 정리 비유 ]

   【 어질러진 서랍 (엔트로피 높음) 】 ──► 【 깔끔한 서랍 (엔트로피 낮음) 】
   • 양말이 뒤섞여 있어 찾기 어려움          • 파란 양말은 왼쪽 칸에 정돈됨
                                   ▲
                                   │ 누군가 땀을 뻘뻘 흘리며 정리해야 함
                                   │ (정리하는 사람의 몸에서 열과 땀 배출)
....

방을 정리하여 질서를 만드는 사람의 몸에서 열과 땀(엔트로피)이 방출되듯, **정보를 획득하고 처리하고 삭제하는 모든 지적 활동은 물리적인 세계의 열역학적 비용과 직결**되어 있습니다.

[NOTE]
====
**정보 엔트로피와 열역학 엔트로피는 완전히 같은 물리량인가요?**
"둘이 같은 수학적 형태를 공유한다"는 걸 "둘이 완전히 같은 물리량"이라고 오해하기 쉽습니다. 정보 엔트로피($H$)는 물리적 단위(줄, 켈빈 등)를 갖지 않는 순수한 숫자(비트)인 반면, 열역학 엔트로피($S$)는 볼츠만 상수 $k$가 곱해진, 실제 물리적 단위를 갖는 양입니다. 맥스웰의 도깨비와 란다우어의 원리가 보여준 건 이 둘이 "완전히 동일하다"는 게 아니라, **정보를 다루는 행위 자체가 물리적인 엔트로피 비용과 실제로 연결되어 있다**는, 그 자체로 놀라운 접점입니다. 정보는 종이 위의 글자나 화면 속의 허상이 아니라, 기록·통신·삭제하는 모든 과정이 열역학 법칙에 종속된 물리적 실체라는 뜻입니다.
====

== 요약

* **동일한 수학적 본질**: 열역학 엔트로피와 정보 엔트로피는 모두 '경우의 수(불확실성)'를 측정하는 동일한 원리를 공유합니다.
* **맥스웰의 도깨비**: 정보 이론을 통해 100년 묵은 열역학의 역설이 완벽하게 풀렸습니다.
* **란다우어의 원리**: 1비트의 정보를 지우는 행위조차 반드시 물리적인 열과 엔트로피를 발생시킵니다.

[TIP]
====
**확인 질문**: 맥스웰의 도깨비가 만약 머리가 무한히 커서 과거의 분자 정보들을 "단 한 번도 지우지 않고 전부 영구 보관"할 수 있다면, 왜 란다우어의 열 방출이 일어나지 않고도 열역학 제2법칙이 지켜질 수 있는지 (도깨비의 뇌 자체가 엔트로피를 떠안음) 상상해 보세요
