이 책의 마지막 이론적 정거장에 도착했습니다.

지금까지 우리는 섀넌의 정보 이론이 얼마나 아름답고 강력한지 확인했습니다. 하지만 이 이론의 위대함을 온전히 이해하기 위해서는, **섀넌이 무엇을 연구했는가만큼이나 '무엇을 과감하게 버렸는가'를 이해**해야 합니다.

== 섀넌의 선언: "의미(Meaning)는 통신과 무관하다"

1948년, 섀넌은 자신의 논문 첫머리에서 다음과 같이 선언했습니다.

> **"통신의 근본적인 문제는, 한 지점에서 선택된 메시지를 다른 지점에서 정확하게 재생산하는 것이다.  
> 이때 메시지가 담고 있는 【의미(Semantic Meaning)】는 엔지니어링 통신 문제와는 아무런 상관이 없다."**

....
                   [ 섀넌의 순수한 통신 모델 ]

   【 송신자 】 ──► [ 인코더 ] ──► 【 잡음 채널 】 ──► [ 디코더 ] ──► 【 수신자 】
   "사랑해"        (01101...)       (지지직...)      (01101...)       "사랑해"
      │                                                                  │
      ▼                                                                  ▼
   [ 관심 대상 ] : "비트열 01101이 한 글자도 깨지지 않고 100% 똑같이 도착했는가?"
   [ 제외 대상 ] : "그 말이 수신자에게 얼마나 큰 사랑과 감동을 주는가?" (배제)
....

섀넌은 통신 시스템이 데이터의 '의미'나 '가치'를 이해할 필요가 없다고 보았습니다.

전화국 교환기나 와이파이 공유기는 전송되는 비트가 시인의 아름다운 연애편지이든, 스팸 광고이든, 컴퓨터 바이러스이든 상관없이 **오직 "보낸 비트 그대로 정확히 전달하는 일"에만 100% 집중**해야 한다는 것입니다.

== 직관을 배반하는 역설: 시(Poem)와 노이즈의 대결

이 냉정한 선 긋기가 만들어내는 놀라운 역설이 있습니다.

....
                 [ 같은 정보량, 완전히 다른 의미 ]

   【 메시지 A: 셰익스피어의 낭만적인 명시 100글자 】
   • 다음 글자를 예측하기 어려움 ──► 【 엔트로피: 4.5 비트/글자 】
   • 인간에게 주는 감동과 가치  ──► 【 눈물을 흘릴 만큼 심오함 】

   【 메시지 B: 고양이 발바닥이 누른 무작위 문자열 100글자 】
   • 다음 글자를 예측하기 어려움 ──► 【 엔트로피: 4.5 비트/글자 】
   • 인간에게 주는 감동과 가치  ──► 【 완전한 쓰레기 (가치 0) 】
....

섀넌의 정보 이론 관점에서 보면, 셰익스피어의 불후의 명작과 고양이가 키보드를 마구 쳐서 만든 외계어는 **완벽하게 똑같은 정보량(엔트로피)**을 가집니다 둘 다 다음에 무슨 글자가 올지 예측하기 어렵다는 면에서 똑같이 "불확실하기" 때문입니다.

== 두 장의 손 편지에 비유하기

....
                       [ 두 장의 손 편지 비유 ]

   【 편지 1: "나 다음 달에 미국으로 이민 가" 】
   • 섀넌의 정보량: 높음 (전혀 예상치 못한 소식)
   • 인간적인 의미: 극도로 큼 (마음이 철렁 내려앉음) ──► [ 두 잣대가 일치 ]

   【 편지 2: 무작위 전화번호부 3페이지 복사본 】
   • 섀넌의 정보량: 높음 (숫자 배열이 무작위라 불확실성 큼)
   • 인간적인 의미: 0 (당장 쓰레기통에 버림)       ──► 【 두 잣대의 극적인 분리 】
....

섀넌의 저울은 오직 **"이 소식이 얼마나 예측 밖이었는가"**만 잴 뿐, **"그 소식이 인간에게 얼마나 소중한가"**는 재지 못합니다.

== 범위를 좁힘으로써 얻어낸 불멸의 깊이

[NOTE]
====
**의미를 다루지 않는다는 것은 이 이론의 치명적인 결함인가요?**  
정반대입니다  
'의미'라는 것은 사람마다, 문화마다, 맥락마다 천차만별로 바뀌는 너무나 주관적이고 미끄러운 개념입니다. 만약 섀넌이 "의미"까지 수학 공식에 우겨넣으려 했다면, 이 책에서 배운 소스 코딩 정리나 채널 용량 같은 보편적이고 위대한 공학 법칙을 단 하나도 세우지 못했을 것입니다.  
**"주관적인 의미를 과감하게 쳐내고 객관적인 확률에만 집중했기 때문에"**, 섀넌의 이론은 모든 컴퓨터와 통신 장비에 적용되는 절대적인 과학의 반열에 오를 수 있었습니다.
====

== 의미를 찾아서: 섀넌 이후의 세계

섀넌 이후의 학자들은 이 빈자리를 채우기 위해 다양한 대안 이론들을 개척했습니다.
* **의미론적 정보 이론 (Semantic Information)**: 메시지가 수신자의 믿음과 의사결정을 얼마나 바꾸는지 측정하려는 시도.
* **콜모고로프 복잡도 (알고리즘 정보 이론)**: 확률 대신 "그 데이터를 만들어내는 가장 짧은 컴퓨터 프로그램의 길이"로 복잡도를 측정하려는 시도.

하지만 오늘날 전 세계 80억 인류의 디지털 통신과 인터넷을 실질적으로 움직이고 있는 것은, 여전히 섀넌이 놓아둔 가장 견고하고 순수한 확률의 정보 이론입니다.

== 요약

* **의미의 의도적 배제**: 섀넌은 주관적인 '의미'를 버리고 '정확한 기계적 전달'에만 집중했습니다.
* **동일한 정보량의 역설**: 예측하기 어렵다면 아름다운 명시와 무작위 잡음은 똑같은 비트 수(엔트로피)를 가집니다.
* **과학의 지혜**: 범위를 명확히 좁혔기에 80년 동안 흔들리지 않는 가장 강력하고 보편적인 공학 이론이 탄생할 수 있었습니다.
