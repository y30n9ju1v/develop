title: "Category Theory for Programmers"
---

*Category Theory for Programmers*는 Bartosz Milewski가 프로그래머를 대상으로 쓴 카테고리 이론 입문서로, 원래 그의 블로그에 연재된 글을 엮은 것입니다. 하스켈과 C++ 코드를 오가며 카테고리, 함자, 자연 변환에서 시작해 요네다 렘마, 수반, 모나드, 칸 확장까지 다룹니다. 이 페이지는 해당 시리즈의 한국어 번역을 장별로 모은 판입니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
