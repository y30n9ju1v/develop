'''
지금까지 우리는 주로 단일 카테고리나 카테고리 쌍을 다뤄왔습니다. 하지만 때로는 이런 방식이 제약이 되기도 했습니다. 예를 들어, 카테고리 ``C``에서 극한(limit)을 정의할 때, 원뿔(cone)의 밑면(base)을 형성할 패턴의 템플릿으로 인덱스 카테고리 ``I``를 도입했었죠. 사실 원뿔의 정점(apex) 템플릿으로 사용될 또 다른 카테고리(매우 사소한 것)를 하나 더 도입하는 것이 더 논리적이었을 것입니다. 하지만 대신 우리는 ``I``에서 ``C``로 가는 상수 함자(constant functor) ``Δc``를 사용했습니다.

이제 이러한 어색함을 해결해 봅시다. 세 가지 카테고리를 사용해 극한을 정의해 보겠습니다. 먼저 인덱스 카테고리 ``I``에서 ``C``로 가는 함자 ``D``부터 시작하죠. 이 함자는 원뿔의 밑면을 선택하는 역할을 하며, 이를 다이어그램 함자(diagram functor)라고 부릅니다.

여기에 객체 하나(그리고 단일 항등 모피즘)만을 포함하는 카테고리 ``1``을 새로 추가하겠습니다. ``I``에서 이 카테고리 ``1``로 가는 함자 ``K``는 단 하나만 존재합니다. 이 함자 ``K``는 ``I``의 모든 객체를 ``1``의 유일한 객체로, 모든 모피즘을 항등 모피즘으로 매핑합니다. 이제 ``1``에서 ``C``로 가는 임의의 함자 ``F``를 생각하면, 이는 우리 원뿔의 잠재적인 정점을 선택하는 셈이 됩니다.

원뿔은 ``F ∘ K``에서 ``D``로 가는 자연 변환 ``ε``입니다. ``F ∘ K``가 원래 우리가 사용했던 ``Δc``와 정확히 같은 역할을 한다는 점에 주목하십시오. 다음 다이어그램은 이 변환을 보여줍니다.

이제 그러한 함자 ``F`` 중에서 "최선"인 것을 선택하는 보편적 성질(universal property)을 정의할 수 있습니다. 이 최선의 ``F``는 ``1``을 ``C`` 내의 객체 중 ``D``의 극한이 되는 객체로 매핑할 것이며, ``F ∘ K``에서 ``D``로 가는 자연 변환 ``ε``는 그에 대응하는 투영(projection)들을 제공할 것입니다. 이 보편적인 함자를 *``K``를 따르는 ``D``의 우칸 확장(right Kan extension)*이라 부르며, ``RanKD``라고 표기합니다.

보편적 성질을 공식화해 봅시다. 또 다른 원뿔이 있다고 가정해 보죠. 즉, 또 다른 함자 ``F'``와 ``F' ∘ K``에서 ``D``로 가는 자연 변환 ``ε'``가 있습니다.

만약 칸 확장 ``F = RanKD``가 존재한다면, ``F'``에서 ``F``로 가는 유일한 자연 변환 ``σ``가 반드시 존재해야 하며, ``ε'``는 ``ε``를 통해 다음과 같이 분해(factorize)되어야 합니다.

[source,haskell]
----
ε' = ε . (σ ∘ K)
----

여기서 ``σ ∘ K``는 두 자연 변환의 수평 합성(horizontal composition)입니다(그중 하나는 ``K``에 대한 항등 자연 변환임). 이 합성은 다시 ``ε``와 수직 합성(vertical composition)됩니다.

구성 요소별로 보면, ``I``의 객체 ``i``에 작용할 때 다음과 같습니다.

[source,haskell]
----
ε'i = εi ∘ σ K i
----

우리 예제에서 ``σ``는 ``1``의 유일한 객체에 대응하는 단 하나의 구성 요소만 가집니다. 따라서 이는 실제로 ``F'``가 정의하는 원뿔의 정점에서 ``RanKD``가 정의하는 보편 원뿔의 정점(즉, 극한 객체)으로 가는 유일한 모피즘이 됩니다. 가환 조건(commuting condition) 또한 극한의 정의에서 요구하는 것과 정확히 일치합니다.

하지만 중요한 점은, 우리가 이 자명한 카테고리 ``1``을 임의의 카테고리 ``A``로 대체하더라도 우칸 확장의 정의가 여전히 유효하다는 것입니다.

== 우칸 확장 (Right Kan Extension)

함자 ``D \:: I -> C``를 함자 ``K \:: I -> A``를 따라 확장한 *우칸 확장*은 함자 ``F \:: A -> C``(``RanKD``로 표기)와 자연 변환

[source,haskell]
----
ε :: F ∘ K -> D
----

의 쌍으로 정의됩니다. 이때 임의의 다른 함자 ``F' \:: A -> C``와 자연 변환

[source,haskell]
----
ε' :: F' ∘ K -> D
----

에 대해, 다음 식을 만족하는 유일한 자연 변환

[source,haskell]
----
σ :: F' -> F
----

가 존재해야 합니다.

[source,haskell]
----
ε' = ε . (σ ∘ K)
----

이 설명이 조금 복잡할 수 있지만, 다음의 멋진 다이어그램으로 시각화할 수 있습니다.

이를 바라보는 흥미로운 방법 중 하나는 칸 확장이 어떤 의미에서는 "함자 곱셈"의 역연산처럼 작용한다는 점에 주목하는 것입니다. 일부 저자들은 ``RanKD``를 ``D/K``로 표기하기도 합니다. 실제로 이 표기법을 사용하면 우칸 확장의 코단위(counit)라고도 불리는 ``ε``의 정의가 마치 단순한 약분처럼 보입니다.

[source,haskell]
----
ε :: D/K ∘ K -> D
----

칸 확장에 대한 또 다른 해석도 있습니다. 함자 ``K``가 카테고리 ``I``를 ``A`` 내부에 매핑(임베딩)한다고 생각해 봅시다. 가장 단순한 경우는 ``I``가 ``A``의 부분 카테고리인 경우겠죠. 우리에게는 ``I``에서 ``C``로 가는 함자 ``D``가 있습니다. 이 ``D``를 ``A`` 전체에서 정의되는 함자 ``F``로 확장할 수 있을까요? 이상적으로는 이러한 확장 함자 ``F``와 ``K``를 합성한 ``F ∘ K``가 ``D``와 동형(isomorphic)이 되어야 할 것입니다. 즉, ``F``가 ``D``의 도메인을 ``A``로 확장하는 것이죠. 하지만 완전한 동형을 요구하는 것은 대개 너무 과한 조건이므로, 우리는 그 절반 정도인 ``F ∘ K``에서 ``D``로 가는 한쪽 방향의 자연 변환 ``ε``만으로 만족합니다. (좌칸 확장은 그 반대 방향을 선택합니다.)

물론 극한의 예시에서처럼 함자 ``K``가 객체에 대해 단사(injective)가 아니거나 hom-집합에 대해 충실(faithful)하지 않다면 임베딩이라는 비유는 성립하지 않습니다. 이 경우 칸 확장은 손실된 정보를 "최대한" 추론(extrapolate)해내려고 노력합니다.

== 수반으로서의 칸 확장 (Kan Extension as Adjunction)

이제 (고정된 ``K``에 대해) 임의의 ``D``에 대하여 우칸 확장이 존재한다고 가정해 봅시다. 이 경우 ``RanK -``(대시 부분에 ``D``가 들어감)는 함자 카테고리 ``[I, C]``에서 함자 카테고리 ``[A, C]``로 가는 함자가 됩니다. 사실 이 함자는 선합성(precomposition) 함자인 ``-∘K``의 *우수반(right adjoint)*입니다. 선합성 함자는 ``[A, C]``의 함자들을 ``[I, C]``의 함자들로 매핑하죠. 그 수반 관계는 다음과 같습니다.

[source,haskell]
----
[I, C](F' ∘ K, D) ≅ [A, C](F', RanKD)
----

이는 우리가 앞서 말한 ``ε'``라는 각 자연 변환에 대해 유일한 자연 변환 ``σ``가 대응된다는 사실을 다르게 표현한 것뿐입니다.

더 나아가, 카테고리 ``I``를 ``C``와 같다고 두고 ``D`` 대신 항등 함자 ``IC``를 대입해 봅시다. 그러면 다음과 같은 관계식을 얻습니다.

[source,haskell]
----
[C, C](F' ∘ K, IC) ≅ [A, C](F', RanKIC)
----

여기서 ``F'``를 다시 ``RanKIC``로 선택하면, 오른쪽에는 항등 자연 변환이 나타나고 그에 대응하여 왼쪽에서는 다음과 같은 자연 변환이 얻어집니다.

[source,haskell]
----
ε :: RanKIC ∘ K -> IC
----

이 모양은 수반의 코단위와 매우 흡사합니다.

[source,haskell]
----
RanKIC ⊣ K
----

실제로 어떤 함자 ``K``를 따라가는 항등 함자의 우칸 확장은 ``K``의 좌수반을 계산하는 데 사용될 수 있습니다. 단, 여기에는 조건이 하나 더 필요합니다. 바로 우칸 확장이 함자 ``K``에 의해 보존(preserve)되어야 한다는 것입니다. 확장이 보존된다는 것은 ``K``와 선합성된 함자의 칸 확장을 계산한 결과가, 원래의 칸 확장과 ``K``를 합성한 것과 같아야 함을 의미합니다. 우리 예제에서 이 조건은 다음과 같이 단순해집니다.

[source,haskell]
----
K ∘ RanKIC ≅ RanKK
----

앞서 언급한 나눗셈 표기법(``D/K``)을 사용하면 수반 관계를 다음과 같이 쓸 수 있습니다.

[source,haskell]
----
I/K ⊣ K
----

이는 수반이 일종의 역연산과 비슷하다는 우리의 직관을 확인시켜 줍니다. 이때 보존 조건은 다음과 같아집니다.

[source,haskell]
----
K ∘ I/K ≅ K/K
----

함자 ``K`` 자신을 따라가는 ``K``의 우칸 확장 ``K/K``를 *코밀도 모나드(codensity monad)*라고 부릅니다.

수반 공식은 매우 중요한 결과입니다. 곧 살펴보겠지만, 끝(end)과 코끝(coend)을 이용해 칸 확장을 계산할 수 있기 때문에 결과적으로 우수반과 좌수반을 찾는 실용적인 방법을 제공해주기 때문입니다.

== 좌칸 확장 (Left Kan Extension)

좌칸 확장은 우칸 확장과 쌍대(dual)를 이루는 구조입니다. 직관을 얻기 위해 코리미트(colimit)의 정의에서 시작하여 이를 단일 객체 카테고리 ``1``을 사용하는 방식으로 재구성해 봅시다. 함자 ``D \:: I -> C``를 밑면으로 하고, 함자 ``F \:: 1 -> C``를 정점으로 하는 코원뿔(cocone)을 만듭니다.

코원뿔의 측면인 단사 모피즘(injection)들은 ``D``에서 ``F ∘ K``로 가는 자연 변환 ``η``의 구성 요소가 됩니다.

코리미트는 보편 코원뿔입니다. 따라서 다른 임의의 함자 ``F'``와 자연 변환

[source,haskell]
----
η' :: D -> F' ∘ K
----

에 대해, 다음 식을 만족하는 유일한 자연 변환 ``σ \:: F -> F'``가 존재합니다.

[source,haskell]
----
η' = (σ ∘ K) . η
----

이것은 다음 다이어그램과 같습니다.

단일 객체 카테고리 ``1``을 임의의 카테고리 ``A``로 대체하면, 이 정의는 자연스럽게 *좌칸 확장* ``LanKD``의 정의로 일반화됩니다.

이때의 자연 변환

[source,haskell]
----
η :: D -> LanKD ∘ K
----

는 좌칸 확장의 *단위(unit)*라 불립니다.

앞서와 마찬가지로 자연 변환들 사이의 일대일 대응 관계인

[source,haskell]
----
η' = (σ ∘ K) . η
----

를 수반 관계의 관점에서 다시 써볼 수 있습니다.

[source,haskell]
----
[A, C](LanKD, F') ≅ [I, C](D, F' ∘ K)
----

즉, 좌칸 확장은 ``K``와의 선합성에 대한 *좌수반(left adjoint)*이고, 우칸 확장은 *우수반(right adjoint)*입니다.

항등 함자의 우칸 확장이 ``K``의 좌수반을 계산하는 데 쓰였던 것처럼, 항등 함자의 좌칸 확장은 ``K``의 우수반이 됩니다(여기서 ``η``는 수반의 단위가 됨).

[source,haskell]
----
K ⊣ LanKIC
----

이 두 가지 결과를 결합하면 다음과 같은 멋진 수반 연쇄를 얻습니다.

[source,haskell]
----
RanKIC ⊣ K ⊣ LanKIC
----

== 엔드로서의 칸 확장 (Kan Extensions as Ends)

칸 확장의 진정한 힘은 엔드(end)와 코엔드(coend)를 통해 계산될 수 있다는 점에서 나옵니다. 계산을 단순화하기 위해 대상 카테고리 ``C``를 ``Set``으로 한정해서 살펴보겠지만, 이 공식들은 다른 카테고리로도 확장 가능합니다.

칸 확장이 함자의 원래 도메인 밖으로 그 작용을 확장하는 도구라는 아이디어를 다시 떠올려 봅시다. ``K``가 ``I``를 ``A`` 내에 임베딩하고, 함자 ``D``는 ``I``에서 ``Set``으로 간다고 합시다. ``K``의 이미지(image)에 포함되는 임의의 객체 ``a``(즉 ``a = K i``)에 대해서는 확장된 함자가 ``a``를 ``D i``로 보낸다고 쉽게 말할 수 있습니다. 문제는 ``A`` 내에 있으면서 ``K``의 이미지 밖에 있는 객체들을 어떻게 처리하느냐입니다. 핵심 아이디어는 그런 객체들도 ``K``의 이미지 내에 있는 객체들과 수많은 모피즘을 통해 잠재적으로 연결되어 있다는 점입니다. 함자는 이러한 모피즘들의 관계를 보존해야 하죠. 객체 ``a``에서 ``K``의 이미지로 가는 모든 모피즘들의 집합은 다음과 같은 hom-함자로 특징지어집니다.

[source,haskell]
----
A(a, K -)
----

이 hom-함자는 사실 두 함자의 합성이라는 점에 주목하십시오.

[source,haskell]
----
A(a, K -) = A(a, -) ∘ K
----

우칸 확장은 함자 합성의 우수반입니다.

[source,haskell]
----
[I, Set](F' ∘ K, D) ≅ [A, Set](F', RanKD)
----

여기서 ``F'`` 대신 hom-함자를 대입해 봅시다.

[source,haskell]
----
[I, Set](A(a, -) ∘ K, D) ≅ [A, Set](A(a, -), RanKD)
----

합성 부호를 풀어서 쓰면 다음과 같습니다.

[source,haskell]
----
[I, Set](A(a, K -), D) ≅ [A, Set](A(a, -), RanKD)
----

오른쪽 항은 요네다 보조정리(Yoneda lemma)에 의해 다음과 같이 축약됩니다.

[source,haskell]
----
[I, Set](A(a, K -), D) ≅ RanKD a
----

이제 왼쪽의 자연 변환 집합을 엔드(end) 기호로 다시 쓰면 우칸 확장에 대한 매우 유용한 공식을 얻게 됩니다.

[source,haskell]
----
RanKD a ≅ ∫i Set(A(a, K i), D i)
----

마찬가지로 코엔드(coend)를 이용한 좌칸 확장의 공식은 다음과 같습니다.

[source,haskell]
----
LanKD a = ∫i A(K i, a) × D i
----

이 공식이 실제로 성립함을 보이기 위해, 이것이 함자 합성의 좌수반임을 증명해 보겠습니다.

[source,haskell]
----
[A, Set](LanKD, F') ≅ [I, Set](D, F' ∘ K)
----

왼쪽 항에 우리 공식을 대입합니다.

[source,haskell]
----
[A, Set](∫i A(K i, -) × D i, F')
----

이는 자연 변환의 집합이므로 엔드를 이용해 다음과 같이 표현할 수 있습니다.

[source,haskell]
----
∫a Set(∫i A(K i, a) × D i, F'a)
----

hom-함자의 연속성(continuity)을 이용하여 코엔드를 엔드로 바꿀 수 있습니다.

[source,haskell]
----
∫a ∫i Set(A(K i, a) × D i, F'a)
----

그다음 곱-지수 수반(product-exponential adjunction)을 적용합니다.

[source,haskell]
----
∫a ∫i Set(A(K i, a), (F'a)D i)
----

지수(exponential) 객체는 그에 대응하는 hom-집합과 동형입니다.

[source,haskell]
----
∫a ∫i Set(A(K i, a), Set(D i, F'a))
----

이제 푸비니 정리(Fubini theorem)를 사용하여 두 엔드의 순서를 바꿉니다.

[source,haskell]
----
∫i ∫a Set(A(K i, a), Set(D i, F'a))
----

안쪽의 엔드는 두 함자 사이의 자연 변환 집합을 나타내므로, 요네다 보조정리를 적용할 수 있습니다.

[source,haskell]
----
∫i Set(D i, F'(K i))
----

결과적으로 우리가 증명하려 했던 수반 관계의 오른쪽 항인 자연 변환 집합이 나옵니다.

[source,haskell]
----
[I, Set](D, F' ∘ K)
----

엔드, 코엔드, 그리고 요네다 보조정리를 활용한 이러한 방식의 계산은 엔드의 계산학(calculus of ends)에서 매우 전형적인 모습입니다.

== 하스켈에서의 칸 확장 (Kan Extensions in Haskell)

칸 확장의 엔드/코엔드 공식은 하스켈로 쉽게 옮길 수 있습니다. 먼저 우칸 확장부터 살펴보죠.

[source,haskell]
----
RanKD a ≅ ∫i Set(A(a, K i), D i)
----

엔드는 보편 한정자(``forall``)로, hom-집합은 함수 타입(``->``)으로 바뀝니다.

[source,haskell]
----
newtype Ran k d a = Ran (forall i. (a -> k i) -> d i)
----

이 정의를 보면 ``Ran``이 함수를 적용할 수 있는 ``a`` 타입의 값과, 두 함자 ``k``, ``d`` 사이의 자연 변환을 포함해야 함이 분명해집니다. 가령 ``k``가 트리(Tree) 함자이고 ``d``가 리스트(``[]``) 함자일 때, ``Ran Tree [] String`` 타입의 값이 있다고 합시다. 여기에 다음과 같은 함수를 넘겨주면,

[source,haskell]
----
f :: String -> Tree Int
----

그 결과로 ``Int`` 리스트를 얻게 되는 식입니다. 즉, 우칸 확장은 여러분이 제공한 함수를 이용해 트리를 만든 다음 이를 리스트로 재포장(repackage)해줍니다. 예를 들어 문자열로부터 파싱 트리를 생성하는 파서를 넘기면, 해당 트리를 깊이 우선 탐색한 결과에 해당하는 리스트를 돌려받을 수 있겠죠.

우칸 확장은 함자 ``d`` 자리에 항등 함자를 넣음으로써 특정 함자의 좌수반을 계산하는 데 활용될 수 있습니다. 이때 함자 ``k``의 좌수반은 다음과 같은 다형성 함수의 집합으로 표현됩니다.

[source,haskell]
----
forall i. (a -> k i) -> i
----

``k``가 모노이드 카테고리에서의 망각 함자(forgetful functor)라고 가정해 봅시다. 그러면 보편 한정자는 모든 모노이드 객체들 위를 돌게 됩니다. 비록 하스켈에서 모노이드 법칙을 완벽히 강제할 수는 없지만, 다음과 같이 자유 함자(망각 함자 ``k``는 대상에 대해 항등임)를 꽤 괜찮게 근사할 수 있습니다.

[source,haskell]
----
type Lst a = forall i. Monoid i => (a -> i) -> i
----

예상대로 이 식은 자유 모노이드, 즉 하스켈의 리스트를 생성합니다.

[source,haskell]
----
toLst :: [a] -> Lst a
toLst as = \f -> foldMap f as
  
fromLst :: Lst a -> [a]
fromLst f = f (\a -> [a])
----

좌칸 확장은 코엔드입니다.

[source,haskell]
----
LanKD a = ∫i A(K i, a) × D i
----

따라서 이는 실존 한정자(existential quantifier)로 번역됩니다. 기호로는 다음과 같이 쓸 수 있습니다.

[source,haskell]
----
Lan k d a = exists i. (k i -> a, d i)
----

하스켈에서는 GADT나 보편 한정된 데이터 생성자를 사용해 이를 구현합니다.

[source,haskell]
----
data Lan k d a = forall i. Lan (k i -> a) (d i)
----

이 데이터 구조를 해석하면, 이름 모를 타입 ``i``들을 담은 컨테이너를 받아 ``a``를 내놓는 함수와, 실제로 그 ``i``들을 담은 컨테이너를 함께 가지고 있다는 뜻입니다. ``i``가 구체적으로 무엇인지 알 수 없으므로, 우리가 할 수 있는 유일한 일은 그 컨테이너를 꺼내어 자연 변환을 통해 함자 ``k``가 정의하는 컨테이너로 옮겨 담은 뒤, 함수를 호출해 ``a``를 얻는 것뿐입니다. 예를 들어 ``d``가 트리이고 ``k``가 리스트라면, 트리를 직렬화(serialize)하여 리스트로 만든 다음 함수를 호출해 ``a``를 얻을 수 있습니다.

좌칸 확장은 특정 함자의 우수반을 계산하는 데 쓰일 수 있습니다. 우리는 곱(product) 함자의 우수반이 지수(exponential)라는 사실을 알고 있는데, 이를 좌칸 확장을 이용해 구현해 보겠습니다.

[source,haskell]
----
type Exp a b = Lan ((,) a) I b
----

이것은 실제로 다음과 같은 함수 쌍을 통해 함수 타입과 동형임이 증명됩니다.

[source,haskell]
----
toExp :: (a -> b) -> Exp a b
toExp f = Lan (f . fst) (I ())

fromExp :: Exp a b -> (a -> b)
fromExp (Lan f (I x)) = \a -> f (a, x)
----

앞서 일반적인 경우에 설명했듯이, 여기서도 (1) ``x``의 컨테이너(여기서는 자명한 항등 컨테이너)와 함수 ``f``를 꺼내고, (2) 항등 함자와 쌍(pair) 함자 사이의 자연 변환을 사용해 컨테이너를 다시 구성한 뒤, (3) 함수 ``f``를 호출하는 과정을 거쳤음을 알 수 있습니다.

== 자유 함자 (Free Functor)

칸 확장의 아주 흥미로운 응용 중 하나는 *자유 함자(free functor)*를 만드는 것입니다. 이는 다음과 같은 실무적인 고민에 대한 답이 됩니다. "객체 사이의 매핑을 수행하는 타입 생성자(type constructor)가 있을 때, 이를 기반으로 함자를 정의할 수 있을까? 즉, 이 타입 생성자를 완전한 엔도함자로 확장해주는 모피즘 매핑을 정의할 수 있을까?" 하는 고민이죠.

핵심 관찰은 타입 생성자가 사실 *이산 카테고리(discrete category)*를 도메인으로 하는 함자로 설명될 수 있다는 점입니다. 이산 카테고리는 항등 모피즘 외에 다른 모피즘이 전혀 없는 카테고리를 말합니다. 어떤 카테고리 ``C``가 주어졌을 때, 비항등 모피즘들을 모두 버리면 항상 이산 카테고리 ``|C|``를 만들 수 있습니다. 이때 ``|C|``에서 ``C``로 가는 함자 ``F``는 단순히 객체들을 매핑하는 것일 뿐이며, 이것이 바로 하스켈에서 말하는 타입 생성자입니다. 또한 ``|C|``를 ``C``로 주입하는 표준 함자 ``J``가 존재하는데, 이는 객체들(그리고 항등 모피즘들) 위에서 항등 함수처럼 작동합니다. ``J``를 따르는 ``F``의 좌칸 확장(존재한다면)은 곧 ``C``에서 ``C``로 가는 함자가 됩니다.

[source,haskell]
----
LanJ F a = ∫i C(J i, a) × F i
----

이를 ``F``를 기반으로 한 자유 함자라고 부릅니다.

하스켈로는 다음과 같이 쓸 수 있습니다.

[source,haskell]
----
data FreeF f a = forall i. FMap (i -> a) (f i)
----

실제로 임의의 타입 생성자 ``f``에 대하여 ``FreeF f``는 함자가 됩니다.

[source,haskell]
----
instance Functor (FreeF f) where
  fmap g (FMap h fi) = FMap (g . h) fi
----

보시다시피 자유 함자는 함수와 그 인수를 모두 기록해 둠으로써 함수 리프팅(lifting)을 흉내 냅니다. 리프트된 함수들을 합성해 나감으로써 이를 누적시키는 식이죠. 함자의 법칙들은 자동으로 만족됩니다. 이러한 구성 방식은 "Freer Monads, More Extensible Effects"라는 논문에서 사용되었습니다.

물론 같은 목적으로 우칸 확장을 사용할 수도 있습니다.

[source,haskell]
----
newtype FreeF f a = FreeF (forall i. (a -> i) -> f i)
----

이 또한 함자가 됨을 쉽게 확인할 수 있습니다.

[source,haskell]
----
instance Functor (FreeF f) where
  fmap g (FreeF r) = FreeF (\bi -> r (bi . g))
----
