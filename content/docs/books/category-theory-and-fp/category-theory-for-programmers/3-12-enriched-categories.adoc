'''
카테고리의 객체들이 집합을 형성하면 그 카테고리를 '작다(small)'고 합니다. 하지만 우리는 집합보다 더 큰 개체들이 존재한다는 것을 알고 있습니다. 잘 알려진 사실이지만, 표준 집합론(체르멜로-프랑켈 이론, 선택 공리를 추가한 버전 포함) 내에서는 모든 집합의 집합을 형성할 수 없습니다. 따라서 모든 집합의 카테고리는 '크다(large)'고 말합니다. 집합을 넘어서는 컬렉션을 정의하기 위해 그로텐디크 우주(Grothendieck universe) 같은 수학적 기법을 사용할 수 있습니다. 이런 기법으로 큰 카테고리를 다룰 수 있습니다.

카테고리의 어떤 두 객체 사이의 모피즘들이 집합을 형성한다면, 이를 '국소적으로 작다(locally small)'고 합니다. 만약 모피즘들이 집합을 형성하지 않는다면, 기존의 정의들을 몇 가지 재고해야 합니다. 특히, 집합에서 개별 모피즘을 골라낼 수조차 없다면 합성을 어떻게 정의해야 할까요? 해결책은 ``Set``의 객체인 홈-집합(hom-set)을 다른 카테고리 ``V``의 객체로 대체하는 것입니다. 차이는 일반적으로 객체에는 원소가 없으므로 개별 모피즘을 말할 수 없다는 것입니다. 따라서 풍성한 카테고리의 모든 속성은 홈-객체(hom-object) 전체에 대해 수행할 수 있는 연산의 관점에서 정의해야 합니다. 이를 위해 홈-객체를 제공하는 카테고리는 추가적인 구조를 가져야 하는데, 바로 *모노이드 카테고리(monoidal category)*여야 합니다. 이 모노이드 카테고리를 ``V``라고 부른다면, ``V`` 위에서 *풍성한 카테고리(enriched category)* ``C``에 대해 이야기할 수 있게 됩니다.

크기 문제 외에도 단순히 집합 이상의 구조를 가진 것으로 홈-집합을 일반화하고 싶을 때가 있습니다. 예를 들어, 전통적인 카테고리에는 객체 사이의 거리에 대한 개념이 없습니다. 두 객체는 모피즘으로 연결되어 있거나 그렇지 않을 뿐입니다. 어떤 객체에 연결된 모든 객체는 그저 이웃인 셈입니다. 현실과 달리 카테고리에서는 친구의 친구의 친구가 절친만큼이나 가깝습니다. 하지만 적절하게 풍성해진 카테고리에서는 객체들 사이의 거리를 정의할 수 있습니다.

풍성한 카테고리를 익혀야 할 실용적인 이유가 하나 더 있습니다. 카테고리 이론 지식의 보고인 nLab 문서 대부분이 풍성한 카테고리 용어로 작성되어 있기 때문입니다.

== 왜 모노이드 카테고리인가?

풍성한 카테고리를 구성할 때는 모노이드 카테고리를 ``Set``으로, 홈-객체를 홈-집합으로 바꾸면 일반적인 정의를 되찾을 수 있어야 합니다. 가장 좋은 방법은 일반적인 정의에서 시작해 이를 포인트 프리(point-free) 방식, 즉 집합의 원소를 직접 언급하지 않는 방식으로 재구성하는 것입니다.

먼저 합성의 정의부터 살펴봅시다. 일반적으로 합성은 ``C(b, c)``의 모피즘 하나와 ``C(a, b)``의 모피즘 하나를 취해 ``C(a, c)``의 모피즘으로 매핑합니다. 다시 말해 다음과 같은 매핑입니다.

[source,haskell]
----
C(b, c) × C(a, b) -> C(a, c)
----

이것은 집합 사이의 함수로, 두 홈-집합의 데카르트 곱이 정의역입니다. 데카르트 곱을 더 일반적인 것으로 바꾸면 쉽게 일반화됩니다. 카테고리적 곱(categorical product)도 가능하겠지만, 더 나아가 완전히 일반적인 텐서 곱(tensor product)을 사용할 수도 있습니다.

다음은 항등 모피즘입니다. 홈-집합에서 개별 요소를 선택하는 대신, 단일 원소 집합 ``1``에서 나가는 함수를 사용하여 정의할 수 있습니다.

[source,haskell]
----
ja :: 1 -> C(a, a)
----

여기서도 단일 원소 집합을 종단 객체(terminal object)로 대체할 수도 있지만, 더 나아가 텐서 곱의 단위 객체 ``i``로 대체할 수 있습니다.

이처럼 모노이드 카테고리 ``V``의 객체들은 홈-집합을 대체하기에 훌륭한 후보가 됩니다.

== 모노이드 카테고리 (Monoidal Category)

모노이드 카테고리에 대해서는 이전에 다룬 적이 있지만, 다시 한번 정의를 짚어볼 가치가 있습니다. 모노이드 카테고리는 이항 함자(bifunctor)인 텐서 곱을 정의합니다.

[source,haskell]
----
⊗ :: V × V -> V
----

텐서 곱은 결합 법칙을 만족해야 하지만, 자연 동형까지만 만족해도 충분합니다. 이 동형 모피즘을 *결합자(associator)*라고 부르며 그 성분은 다음과 같습니다.

[source,haskell]
----
αa b c :: (a ⊗ b) ⊗ c -> a ⊗ (b ⊗ c)
----

이는 세 인수에 대해 모두 자연적이어야 합니다.

모노이드 카테고리는 텐서 곱의 단위 역할을 하는 특별한 단위 객체 ``i``도 가져야 합니다. 이 역시 자연 동형까지만 만족하면 됩니다. 이 두 동형 모피즘을 각각 좌측 및 우측 *단위자(unitor)*라고 부르며, 그 성분은 다음과 같습니다.

[source,haskell]
----
λa :: i ⊗ a -> a
ρa :: a ⊗ i -> a
----

결합자와 단위자는 코히어런스(coherence) 조건을 만족해야 합니다.

구성 성분으로서 다음과 같은 자연 동형 모피즘이 존재할 때, 그 모노이드 카테고리를 *대칭적(symmetric)*이라고 부릅니다.

[source,haskell]
----
γa b :: a ⊗ b -> b ⊗ a
----

이 모피즘은 "제곱하면 1"이어야 합니다.

[source,haskell]
----
γb a ∘ γa b = ida⊗b
----

또한 모노이드 구조와 일관성을 유지해야 합니다.

모노이드 카테고리의 흥미로운 점은 텐서 곱의 우수반(right adjoint)으로 내부 홈(internal hom), 즉 함수 객체를 정의할 수 있다는 것입니다. 함수 객체나 지수(exponential)의 표준 정의가 카테고리적 곱의 우수반을 통해 이루어졌던 것을 기억할 것입니다. 모든 객체 쌍에 대해 이러한 내부 홈이 존재하는 카테고리를 카르테시안 닫힌 카테고리(cartesian closed category)라고 불렀습니다. 모노이드 카테고리에서 내부 홈을 정의하는 수반 관계는 다음과 같습니다.

[source,haskell]
----
V(a ⊗ b, c) ≃ V(a, [b, c])
----

\G. M. Kelly의 표기법을 따라 내부 홈을 ``[b, c]``로 표기하겠습니다. 이 수반 관계의 코단위(counit)는 *평가 모피즘(evaluation morphism)*이라 불리는 성분을 갖는 자연 변환입니다.

[source,haskell]
----
εa b :: ([a, b] ⊗ a) -> b
----

텐서 곱이 대칭적이지 않다면, 다음과 같은 수반 관계를 통해 또 다른 내부 홈 ``[[a, c]]``를 정의할 수도 있습니다.

[source,haskell]
----
V(a ⊗ b, c) ≃ V(b, [[a, c]])
----

두 내부 홈이 모두 정의된 모노이드 카테고리를 양측 닫힌(biclosed) 카테고리라고 합니다. 예를 들어 ``Set``의 엔도함자 카테고리는 함자 합성을 텐서 곱으로 사용하는데, 양측 닫힌 카테고리가 아닙니다. 이 카테고리는 우리가 모나드를 정의할 때 사용했던 카테고리이기도 합니다.

== 풍성한 카테고리 (Enriched Category)

모노이드 카테고리 ``V`` 위에서 풍성한 카테고리 ``C``는 홈-집합을 홈-객체로 바꿉니다. ``C``의 모든 객체 쌍 ``a``, ``b``에 대해 ``V``에 속한 객체 ``C(a, b)``를 대응시킵니다. 홈-집합과 같은 표기법을 쓰지만, 이 객체들이 모피즘을 담고 있지는 않습니다. 반면 ``V``는 홈-집합과 모피즘을 가진 일반 카테고리입니다. 집합을 완전히 제거한 것이 아니라 그저 한 단계 추상화해서 감춘 것입니다.

``C``에서는 개별 모피즘에 대해 이야기할 수 없으므로, 합성(composition) 연산은 ``V``의 모피즘 패밀리로 대체됩니다.

[source,haskell]
----
∘ :: C(b, c) ⊗ C(a, b) -> C(a, c)
----

마찬가지로 항등 모피즘은 ``V``의 다음 모피즘 패밀리로 대체됩니다.

[source,haskell]
----
ja :: i -> C(a, a)
----

여기서 ``i``는 ``V``의 텐서 단위입니다.

합성의 결합 법칙은 ``V``의 결합자로 정의됩니다. 단위 법칙 역시 단위자로 표현됩니다.

[source,text]
----
  [ V-풍성한 카테고리 (V-Enriched Category C) 의 공리 ]

  1. 합성 사상 (Composition):
       ∘_{a,b,c} : C(b, c) ⊗ C(a, b) ───> C(a, c)

  2. 단위 사상 (Unit):
       j_a : i ───> C(a, a)   (i는 V의 텐서 단위 객체)

  3. 결합 법칙 다이어그램 (in V):
       (C(c, d) ⊗ C(b, c)) ⊗ C(a, b) ─── α ───> C(c, d) ⊗ (C(b, c) ⊗ C(a, b))
                  │                                         │
              ∘ ⊗ id                                     id ⊗ ∘
                  v                                         v
            C(b, d) ⊗ C(a, b) ───────── ∘ ─────────> C(a, d)

  4. Lawvere 거리 공간 (V = ([0, ∞], ≥, +, 0)):
       • Hom-객체 C(a, b) = d(a, b) ∈ [0, ∞]
       • 합성: d(b, c) + d(a, b) ≥ d(a, c)  (삼각형 부등식!)
       • 단위: 0 ≥ d(a, a) => d(a, a) = 0   (자기 거리 0)
----

== 원순서 (Preorders)

원순서(preorder)는 모든 홈-집합이 비어 있거나 단일 원소인 얇은 카테고리(thin category)로 정의됩니다. 비어 있지 않은 집합 ``C(a, b)``는 ``a ≤ b``라는 증명으로 해석됩니다. 이러한 카테고리는 ``0``과 ``1``(또는 ``False``와 ``True``) 두 객체만 가진 매우 단순한 모노이드 카테고리 위에서 풍성해진 것으로 볼 수 있습니다. 이 카테고리에는 필수적인 항등 모피즘 외에도 ``0``에서 ``1``로 가는 단 하나의 모피즘 ``0 -> 1``이 존재합니다. 텐서 곱은 ``0``과 ``1``의 단순한 산술(``1 ⊗ 1``만 ``1``이고 나머지는 모두 ``0``)을 따르며, 단위 객체는 ``1``입니다. 결합자와 단위자가 항등 모피즘인 엄격한 모노이드 카테고리(strict monoidal category)입니다.

원순서의 홈-집합은 비어 있거나 단일 원소이므로, 위 작은 카테고리의 홈-객체로 쉽게 바꿀 수 있습니다. 풍성한 원순서 ``C``는 임의의 객체 쌍 ``a``, ``b``에 대해 홈-객체 ``C(a, b)``를 가집니다. ``a ≤ b``라면 이 객체는 ``1``이고, 그렇지 않으면 ``0``입니다.

합성을 살펴봅시다. 두 객체의 텐서 곱은 둘 다 ``1``일 때만 ``1``이고, 그 외에는 ``0``입니다. 만약 결과가 ``0``이라면 합성 모피즘은 ``id0`` 또는 ``0 -> 1`` 중 하나가 될 수 있습니다. 하지만 결과가 ``1``이라면 유일한 선택지는 ``id1``뿐입니다. 관계의 언어로 바꾸면 "만약 ``a ≤ b``이고 ``b ≤ c``이면 ``a ≤ c``"가 되며, 이는 우리가 필요한 추이성(transitivity) 법칙입니다.

항등은 어떨까요? ``1``에서 ``C(a, a)``로 가는 모피즘입니다. ``1``에서 나가는 모피즘은 ``id1`` 하나뿐이므로, ``C(a, a)``는 ``1``이어야 합니다. 즉 ``a ≤ a``로, 원순서의 반사성(reflexivity) 법칙입니다. 원순서를 풍성한 카테고리로 구현하면 추이성과 반사성이 자동으로 보장됩니다.

== 거리 공간 (Metric Spaces)

William Lawvere의 흥미로운 예가 있습니다. 그는 거리 공간을 풍성한 카테고리로 정의할 수 있음을 발견했습니다. 거리 공간은 임의의 두 객체 사이의 거리를 정의합니다. 거리는 음이 아닌 실수입니다. 편의상 무한대도 가능한 값으로 포함하겠습니다. 거리가 무한하면 시작 객체에서 목표 객체로 갈 방법이 없다는 뜻입니다.

거리가 만족해야 할 명백한 성질이 몇 가지 있습니다. 첫째, 자기 자신까지의 거리는 0이어야 합니다. 둘째, 삼각형 부등식(triangle inequality)을 만족해야 합니다. 직접 가는 거리가 중간 경유지를 거친 거리의 합보다 크지 않아야 한다는 것입니다. 거리의 대칭성은 요구하지 않습니다. 처음에는 이상해 보일 수 있지만, Lawvere의 설명처럼 한 방향은 오르막이고 반대 방향은 내리막인 상황을 생각하면 이해가 쉽습니다. 대칭성은 나중에 추가 제약으로 부과할 수 있습니다.

거리 공간을 카테고리 이론 언어로 어떻게 표현할까요? 홈-객체가 거리인 카테고리를 구성하면 됩니다. 거리는 모피즘이 아니라 홈-객체입니다. 숫자가 어떻게 홈-객체가 될 수 있을까요? 그 숫자들이 객체인 모노이드 카테고리 ``V``를 만들 수 있다면 가능합니다. 음이 아닌 실수(무한대 포함)는 전순서(total order)를 이루므로 얇은 카테고리로 다룰 수 있습니다. 두 숫자 ``x``, ``y`` 사이의 모피즘은 ``x ≥ y``일 때만 존재합니다(원순서의 일반적인 정의와 반대 방향입니다). 모노이드 구조는 덧셈으로 주어지며, 0이 단위 객체입니다. 두 숫자의 텐서 곱은 그 합입니다.

거리 공간은 이 모노이드 카테고리 위에서 풍성해진 카테고리입니다. 객체 ``a``에서 ``b``로 가는 홈-객체 ``C(a, b)``는 ``a``에서 ``b``까지의 거리인 음이 아닌 실수입니다. 이 카테고리에서 항등과 합성이 무엇을 의미하는지 봅시다.

우리의 정의에 따라, 텐서 단위인 숫자 ``0``에서 홈-객체 ``C(a, a)``로 가는 모피즘은 다음 관계를 의미합니다.

[source,haskell]
----
0 ≥ C(a, a)
----

``C(a, a)``는 음이 아닌 숫자이므로, 이 조건은 ``a``에서 ``a``까지의 거리가 항상 ``0``임을 말합니다. 확인!

이제 합성을 봅시다. 인접한 두 홈-객체 ``C(b, c) ⊗ C(a, b)``의 텐서 곱에서 시작합니다. 텐서 곱은 거리의 합으로 정의했습니다. 합성은 이 곱에서 ``C(a, c)``로 가는 ``V``의 모피즘입니다. ``V``의 모피즘은 크거나 같음 관계로 정의되므로, ``a``에서 ``b``까지의 거리와 ``b``에서 ``c``까지의 거리의 합이 ``a``에서 ``c``까지의 거리보다 크거나 같습니다. 바로 표준 삼각형 부등식입니다. 확인!

거리 공간을 풍성한 카테고리로 재구성하면 삼각형 부등식과 자기 거리 0을 "공짜로" 얻습니다.

== 풍성한 함자 (Enriched Functors)

함자의 정의에는 모피즘 매핑이 포함됩니다. 풍성한 환경에서는 개별 모피즘 개념이 없으므로 홈-객체 전체를 다루어야 합니다. 홈-객체는 모노이드 카테고리 ``V``의 객체이고, 객체들 사이의 모피즘이 있습니다. 따라서 같은 모노이드 카테고리 ``V`` 위에서 풍성해진 두 카테고리 사이에 풍성한 함자를 정의하는 것이 자연스럽습니다. ``V``의 모피즘으로 두 풍성한 카테고리의 홈-객체를 매핑할 수 있기 때문입니다.

두 카테고리 ``C``, ``D`` 사이의 풍성한 함자 ``F``는 객체를 매핑할 뿐만 아니라, ``C``의 임의의 객체 쌍에 대해 ``V``의 다음 모피즘을 할당합니다.

[source,haskell]
----
Fa b :: C(a, b) -> D(F a, F b)
----

함자는 구조를 보존하는 매핑입니다. 일반 함자에서는 합성과 항등의 보존을 의미했습니다. 풍성한 환경에서 합성의 보존은 해당 다이어그램이 가환함을 뜻합니다.

항등의 보존은 항등을 "선택"하는 ``V``의 모피즘이 보존됨을 뜻합니다.

== 자체 풍성화 (Self Enrichment)

닫힌 대칭 모노이드 카테고리는 홈-집합을 내부 홈으로 바꾸어 자체 풍성화(self-enrichment)될 수 있습니다. 이를 위해 내부 홈 사이의 합성 법칙을 정의해야 합니다. 다음 시그니처를 가진 모피즘을 구현하면 됩니다.

[source,haskell]
----
[b, c] ⊗ [a, b] -> [a, c]
----

여느 프로그래밍 과제와 다를 바 없지만, 카테고리 이론에서는 주로 포인트 프리 방식으로 구현합니다. 먼저 이 모피즘이 속할 집합을 특정합니다. 다음 홈-집합의 원소입니다.

[source,haskell]
----
V([b, c] ⊗ [a, b], [a, c])
----

수반 관계에 의해 이 홈-집합은 다음과 동형입니다.

[source,haskell]
----
V(([b, c] ⊗ [a, b]) ⊗ a, c)
----

내부 홈 ``[a, c]``를 정의하는 수반 관계를 사용했습니다. 이 새 집합에서 모피즘을 만들 수 있다면, 수반 관계가 원래 집합의 모피즘을 주고, 이를 합성으로 쓸 수 있습니다. 사용 가능한 여러 모피즘을 결합하여 이 모피즘을 만듭니다. 먼저 결합자 ``α[b, c], [a, b], a``로 좌측 식의 결합을 바꿉니다.

[source,haskell]
----
([b, c] ⊗ [a, b]) ⊗ a -> [b, c] ⊗ ([a, b] ⊗ a)
----

그 다음 수반 관계의 코단위 ``εa, b``를 적용합니다.

[source,haskell]
----
[b, c] ⊗ ([a, b] ⊗ a) -> [b, c] ⊗ b
----

다시 코단위 ``εb, c``를 적용하면 ``c``에 도달합니다. 다음 모피즘을 구성한 것입니다.

[source,haskell]
----
εb, c ∘ (id[b, c] ⊗ εa, b) ∘ α[b, c], [a, b], a
----

이는 홈-집합 ``V(([b, c] ⊗ [a, b]) ⊗ a, c)``의 원소입니다. 수반 관계가 필요한 합성 법칙을 줍니다.

마찬가지로 항등은 다음과 같습니다.

[source,haskell]
----
ja :: i -> [a, a]
----

홈-집합 ``V(i, [a, a])``의 원소로, 수반 관계에 의해 다음 홈-집합과 동형입니다.

[source,haskell]
----
V(i ⊗ a, a)
----

이 홈-집합은 좌측 단위자 ``λa``를 포함합니다. ``ja``를 수반 관계에 의한 ``λa``의 상(image)으로 정의할 수 있습니다.

자체 풍성화의 실용적 예는 프로그래밍 언어 타입 체계의 원형인 ``Set`` 카테고리입니다. 이전에 본 것처럼 ``Set``은 데카르트 곱에 대해 닫힌 모노이드 카테고리입니다. ``Set``에서 임의의 두 집합 사이의 홈-집합은 그 자체로 집합이므로 ``Set``의 객체입니다. 이 객체는 지수 집합과 동형이므로 외부 홈과 내부 홈이 같습니다. 이제 자체 풍성화로 지수 집합을 홈-객체로 쓰고, 합성을 지수 객체의 데카르트 곱으로 표현할 수 있음도 알았습니다.

== 2-카테고리와의 관계

(작은) 카테고리들의 카테고리 ``Cat``을 논하며 2-카테고리를 이야기한 적이 있습니다. 카테고리 사이의 모피즘은 함자이지만, 그 위에 함자 사이의 자연 변환이라는 추가 구조가 있었습니다. 2-카테고리에서 객체를 흔히 0-셀, 모피즘을 1-셀, 모피즘 사이의 모피즘을 2-셀이라 합니다. ``Cat``에서 0-셀은 카테고리, 1-셀은 함자, 2-셀은 자연 변환입니다.

그런데 두 카테고리 사이의 함자도 하나의 카테고리(함자 카테고리)를 형성합니다. 즉 ``Cat``의 홈-개체는 홈-집합이 아니라 홈-카테고리입니다. ``Set``이 ``Set`` 위에서 풍성한 카테고리가 될 수 있듯이, ``Cat`` 역시 ``Cat`` 위에서 풍성한 카테고리로 다룰 수 있습니다. 더 일반적으로, 모든 카테고리를 ``Set`` 위에서 풍성한 것으로 볼 수 있듯이, 모든 2-카테고리는 ``Cat`` 위에서 풍성한 카테고리로 볼 수 있습니다.
