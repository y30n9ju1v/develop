카테고리 이론에 관한 책을 마무리하기에 딱 좋은 지점이란 없습니다. 항상 더 배울 것이 남아 있기 때문입니다. 카테고리 이론은 방대한 분야입니다. 동시에, 동일한 테마와 개념, 패턴이 계속해서 반복되어 나타난다는 점도 분명합니다. 모든 개념은 칸 확장(Kan extension)으로 설명할 수 있다는 말이 있습니다. 실제로 칸 확장을 사용하면 극한(limit), 공극한(colimit), 수반(adjunction), 모나드, 요네다 보조정리 등을 모두 도출할 수 있습니다. 카테고리 자체의 개념은 모든 추상화 수준에서 등장하며, 모노이드와 모나드의 개념도 마찬가지입니다. 그렇다면 무엇이 가장 기초적인 개념일까요? 알고 보니 이들은 모두 서로 얽혀 있으며, 하나가 다른 하나로 이어지는 영원히 순환하는 추상화의 고리를 형성합니다. 저는 이러한 상호 연결성을 보여주는 것이 이 책을 마무리하는 좋은 방법이라고 생각했습니다.

== 이중 카테고리 (Bicategories)

카테고리 이론에서 가장 어려운 측면 중 하나는 관점을 계속 바꿔가며 생각해야 한다는 점입니다. 예를 들어 집합 카테고리를 생각해 봅시다. 우리는 원소(element)를 기반으로 집합을 정의하는 데 익숙합니다. 공집합에는 원소가 없고, 싱글톤 집합에는 원소가 하나 있으며, 두 집합의 카르테시안 곱은 순서쌍들의 집합인 식입니다. 하지만 ``Set`` 카테고리에 대해 이야기할 때, 저는 집합의 내부 구성은 잊고 대신 객체들 사이의 모피즘(화살표)에 집중해 달라고 요청했습니다. 물론 때때로 ``Set``에서의 특정 보편적 구성(universal construction)이 원소 관점에서 무엇을 의미하는지 들여다보기도 했습니다. 터미널 객체(terminal object)가 원소가 하나뿐인 집합으로 밝혀지는 식이었죠. 하지만 이는 어디까지나 우리가 제대로 이해하고 있는지 확인하기 위한 검증 과정일 뿐이었습니다.

함자(functor)는 카테고리들을 서로 연결하는 대응 관계로 정의됩니다. 대응 관계를 어떤 카테고리의 모피즘으로 간주하는 것은 자연스러운 일입니다. 실제로 함자는 '카테고리들의 카테고리'(크기 문제를 피하기 위해 작은 카테고리들로 제한한다면 ``Cat``)의 모피즘임이 밝혀졌습니다. 함자를 화살표로 취급하면, ``Set``에서 함수를 화살표로 다룰 때 원소에 대한 정보를 포기하듯, 해당 함자가 카테고리 내부(객체와 모피즘)에서 어떻게 작용하는지에 대한 정보를 내려놓게 됩니다. 그런데 두 카테고리 사이의 함자들 또한 하나의 카테고리를 형성합니다. 이번에는 특정 카테고리에서 '화살표'였던 것을 다른 카테고리에서는 '객체'로 간주해야 합니다. 함자 카테고리에서는 함자가 객체이고 자연 변환(natural transformation)이 모피즘이 됩니다. 우리는 동일한 대상이 어떤 카테고리에서는 화살표로, 다른 카테고리에서는 객체로 쓰일 수 있다는 사실을 발견했습니다. 객체는 명사, 화살표는 동사라는 식의 단순한 관점은 더 이상 유효하지 않습니다.

이 두 가지 관점을 번갈아 가며 사용하는 대신, 하나로 합쳐볼 수도 있습니다. 여기서 *2-카테고리(2-category)* 개념이 등장합니다. 2-카테고리에서 객체는 0-셀(0-cell), 모피즘은 1-셀(1-cell), 모피즘 사이의 모피즘은 2-셀(2-cell)이라고 부릅니다.

<!-- image -->

0-셀 a, b; 1-셀 f, g; 그리고 2-셀 α.

카테고리들의 카테고리인 ``Cat``이 대표적인 예입니다. 카테고리가 0-셀, 함자가 1-셀, 자연 변환이 2-셀이 됩니다. 2-카테고리의 법칙에 따르면, 임의의 두 0-셀 사이의 1-셀들은 하나의 카테고리를 형성합니다. 즉, ``C(a, b)``는 hom-set이 아니라 hom-category입니다. 이는 앞서 설명한 '두 카테고리 사이의 함자들이 함자 카테고리를 구성한다'는 사실과 정확히 일치합니다.

특히, 어떤 0-셀에서 자기 자신으로 돌아오는 1-셀들도 하나의 카테고리, 즉 hom-category ``C(a, a)``를 형성합니다. 그런데 이 카테고리는 더 풍부한 구조를 지닙니다. ``C(a, a)``의 원소들은 ``C``에서의 화살표로도 볼 수 있고, ``C(a, a)``에서의 객체로도 볼 수 있습니다. 화살표로서는 서로 합성(composition)될 수 있습니다. 하지만 이들을 객체로 볼 때, 합성은 객체 쌍을 객체로 매핑하는 연산이 됩니다. 사실 이는 곱(product)과 매우 유사하며, 정확하게는 텐서 곱(tensor product)입니다. 이 텐서 곱에는 단위(unit)가 있는데, 바로 항등 1-셀(identity 1-cell)입니다. 결과적으로 모든 2-카테고리에서 hom-category ``C(a, a)``는 1-셀의 합성을 텐서 곱으로 하는 *모노이달 카테고리(monoidal category)*가 됩니다. 결합 법칙과 단위 법칙은 카테고리의 공리로부터 자연스럽게 따라 나옵니다.

표준적인 2-카테고리인 ``Cat``에서 이것이 무엇을 의미하는지 살펴봅시다. hom-category ``Cat(a, a)``는 ``a`` 위에서의 *자기함자(endofunctor)* 카테고리입니다. 여기서 자기함자의 합성이 텐서 곱의 역할을 하며, 항등 함자가 단위 객체가 됩니다. 우리는 일찍이 자기함자들이 모노이달 카테고리를 형성한다는 사실을 보았습니다(모나드를 정의할 때 이 사실을 활용했죠). 이제 우리는 이것이 더 일반적인 현상의 일종임을 이해할 수 있습니다. 즉, 어떤 2-카테고리에서든 자기-1-셀(endo-1-cells)들은 모노이달 카테고리를 형성합니다. 이 점은 나중에 모나드를 일반화할 때 다시 살펴보겠습니다.

일반적인 모노이달 카테고리에서는 모노이드 법칙이 엄격하게(on the nose) 만족될 필요는 없다고 했던 것을 기억하실 겁니다. 단위 법칙이나 결합 법칙이 동형(isomorphism) 관계까지만 성립해도 충분한 경우가 많았습니다. 2-카테고리에서 ``C(a, a)``의 모노이드 법칙은 1-셀의 합성 법칙으로부터 비롯되므로, 이 법칙들은 엄격하게 적용되어 *엄격한 모노이달 카테고리(strict monoidal category)*를 얻게 됩니다. 하지만 이러한 법칙들도 완화할 수 있습니다. 예를 들어, 항등 1-셀 ``ida``와 다른 1-셀 ``f \:: a -> b``의 합성이 ``f``와 완전히 같은 것이 아니라 동형이라고 정의할 수 있습니다. 1-셀 사이의 동형 모피즘은 2-셀을 통해 정의됩니다. 즉, 다음과 같은 가역(invertible) 2-셀이 존재한다고 보는 것입니다.

[source,haskell]
----
ρ :: f ∘ ida -> f
----

<!-- image -->

이중 카테고리에서의 항등 법칙은 동형성까지만 성립합니다(가역 2-셀 ρ).

좌측 항등 법칙과 결합 법칙에 대해서도 같은 식의 완화가 가능합니다. 이렇게 완화된 2-카테고리를 *이중 카테고리(bicategory)*라고 부릅니다(몇 가지 일관성 법칙이 더 추가되지만, 여기서는 생략하겠습니다).

예상하신 대로, 이중 카테고리의 자기-1-셀들은 법칙들이 엄격하지 않은 일반적인 모노이달 카테고리를 형성합니다.

이중 카테고리의 흥미로운 예로 *스팬(span)* 카테고리를 들 수 있습니다. 두 객체 ``a``와 ``b`` 사이의 스팬은 객체 ``x``와 다음과 같은 두 모피즘의 쌍으로 구성됩니다.

[source,haskell]
----
f :: x -> a
g :: x -> b
----

카테고리적 곱(categorical product)을 정의할 때 스팬을 사용했던 것을 기억하실 겁니다. 여기서는 스팬을 이중 카테고리의 1-셀로 간주하려고 합니다. 먼저 스팬의 합성을 정의해야 합니다. 다음과 같이 연결된 스팬이 있다고 가정해 봅시다.

[source,haskell]
----
f':: y -> b
g':: y -> c
----

이들의 합성은 어떤 정점(apex) ``z``를 가진 세 번째 스팬이 될 것입니다. 가장 자연스러운 선택은 ``f'``를 따르는 ``g``의 *풀백(pullback)*입니다. 풀백은 객체 ``z``와 다음 조건을 만족하는 두 모피즘 ``h, h'``의 쌍임을 떠올려 보세요.

[source,haskell]
----
h :: z -> x
h':: z -> y
----

조건:
[source,haskell]
----
g ∘ h = f' ∘ h'
----

또한 ``z``는 이러한 성질을 가진 모든 객체 중에서 보편적이어야 합니다.

우선 집합 카테고리(``Set``) 위의 스팬들에 집중해 봅시다. 이 경우 풀백은 단순히 카르테시안 곱 ``x × y``의 원소들 중 다음을 만족하는 순서쌍 ``(p, q)``들의 집합입니다.

[source,haskell]
----
g p = f' q
----

동일한 양 끝점을 공유하는 두 스팬 사이의 모피즘은 정점 사이의 모피즘 ``h``에 의해 적절한 삼각형들이 가환(commute)하도록 정의됩니다.

<!-- image -->

스팬 카테고리 Span에서의 2-셀.

요약하자면, 이중 카테고리 ``Span``에서 0-셀은 집합, 1-셀은 스팬, 2-셀은 스팬 모피즘입니다. 항등 1-셀은 세 객체가 모두 동일하고 두 모피즘이 항등 모피즘인 퇴화된(degenerate) 스팬입니다.

우리는 이전에 또 다른 이중 카테고리의 예를 본 적이 있습니다. 바로 프로함자(profunctor)들의 이중 카테고리인 ``Prof``입니다. 여기서 0-셀은 카테고리, 1-셀은 프로함자, 2-셀은 자연 변환입니다. 프로함자의 합성은 코엔드(coend)를 통해 정의되었습니다.

== 모나드 (Monads)

이제 여러분은 자기함자 카테고리에서의 모노이드로서의 모나드 정의에 꽤 익숙해지셨을 겁니다. 이 정의를 '자기함자 카테고리는 이중 카테고리 ``Cat``에서의 자기-1-셀들로 이루어진 하나의 hom-category에 불과하다'는 새로운 관점에서 다시 살펴보겠습니다. 우리는 이 카테고리가 모노이달 카테고리라는 사실을 알고 있습니다. 텐서 곱은 자기함자의 합성에서 나옵니다. 모노이드는 모노이달 카테고리의 객체로 정의되므로, 여기서는 자기함자 ``T``와 두 개의 모피즘으로 구성됩니다. 자기함자 사이의 모피즘은 자연 변환입니다. 첫 번째 모피즘은 모노이달 단위(항등 자기함자)를 ``T``로 매핑합니다.

[source,haskell]
----
η :: I -> T
----

두 번째 모피즘은 텐서 곱 ``T ⊗ T``를 ``T``로 매핑합니다. 여기서 텐서 곱은 자기함자의 합성이므로 다음과 같습니다.

[source,haskell]
----
μ :: T ∘ T -> T
----

이들은 모나드를 정의하는 두 연산(하스켈에서는 ``return``과 ``join``이라 부름)이며, 모노이드 법칙이 곧 모나드 법칙이 된다는 사실을 우리는 알고 있습니다.

이제 이 정의에서 '자기함자'라는 표현을 모두 지워보겠습니다. 그러면 어떻게 될까요? 우선 이중 카테고리 ``C``와 그 안의 0-셀 ``a``를 하나 선택합니다. 앞서 보았듯이 hom-category ``C(a, a)``는 모노이달 카테고리입니다. 따라서 ``C(a, a)`` 내에서 1-셀 ``T``와 두 개의 2-셀을 골라 모노이드를 정의할 수 있습니다.

[source,haskell]
----
η :: I -> T
μ :: T ∘ T -> T
----

이들이 모노이드 법칙을 만족할 때, 우리는 이를 *모나드*라고 부릅니다.

이것은 0-셀, 1-셀, 2-셀만을 사용하는 훨씬 더 일반적인 모나드의 정의입니다. 이 정의를 이중 카테고리 ``Cat``에 적용하면 우리가 알던 일반적인 모나드가 됩니다. 그렇다면 다른 이중 카테고리에서는 어떤 일이 벌어질까요?

``Span`` 카테고리에서 모나드를 구성해 봅시다. 먼저 0-셀을 하나 선택하는데, 곧 명확해지겠지만 이를 ``Ob``라고 부르겠습니다. 다음으로 ``Ob``에서 ``Ob``로 가는 자기-1-셀, 즉 스팬을 하나 고릅니다. 이 스팬의 정점을 ``Ar``이라 부르고, 두 함수를 갖게 합니다.

[source,haskell]
----
dom :: Ar -> Ob
cod :: Ar -> Ob
----

집합 ``Ar``의 원소를 '화살표(arrow)', ``Ob``의 원소를 '객체(object)'라고 부른다면 이것이 무엇을 뜻하는지 감이 오실 겁니다. 두 함수 ``dom``과 ``cod``는 화살표에 도메인(정역)과 코도메인(공역)을 할당하는 역할을 합니다.

이 스팬을 모나드로 만들려면 두 개의 2-셀 ``η``와 ``μ``가 필요합니다. 이 경우 모노이달 단위는 정점이 ``Ob``이고 두 항등 함수를 가진, ``Ob``에서 ``Ob``로 가는 자명한(trivial) 스팬입니다. 2-셀 ``η``는 정점 ``Ob``와 ``Ar`` 사이의 함수입니다. 즉, ``η``는 모든 객체에 화살표를 하나씩 할당합니다. ``Span``에서의 2-셀은 가환 조건을 만족해야 하므로 다음이 성립해야 합니다.

[source,haskell]
----
dom ∘ η = id
cod ∘ η = id
----

이를 원소 단위로 풀면 다음과 같습니다.

[source,haskell]
----
dom (η ob) = ob = cod (η ob)
----

여기서 ``ob``는 ``Ob``의 객체입니다. 다시 말해, ``η``는 각 객체에 대해 도메인과 코도메인이 해당 객체 자신인 화살표를 할당합니다. 우리는 이 특별한 화살표를 *항등 화살표(identity arrow)*라고 부를 것입니다.

두 번째 2-셀 ``μ``는 스팬 ``Ar`` 자신과의 합성에 작용합니다. 합성은 풀백으로 정의되므로, 그 원소들은 ``Ar``의 원소 쌍, 즉 두 화살표의 쌍 ``(a1, a2)``가 됩니다. 풀백을 정의하는 조건은 다음과 같습니다.

[source,haskell]
----
cod a1 = dom a2
----

이는 한 화살표의 코도메인이 다른 화살표의 도메인과 같으므로 두 화살표 ``a1``과 ``a2``가 '합성 가능하다'는 것을 의미합니다.

2-셀 ``μ``는 합성 가능한 화살표 쌍 ``(a1, a2)``를 ``Ar``의 단일 화살표 ``a3``로 매핑하는 함수입니다. 다시 말해, ``μ``는 화살표의 *합성(composition)*을 정의합니다.

모나드 법칙이 곧 화살표의 항등 법칙과 결합 법칙에 해당한다는 것을 쉽게 확인할 수 있습니다. 우리는 방금 *카테고리*(객체와 화살표가 각각 집합을 형성하는 작은 카테고리)를 정의한 것입니다.

결국, *카테고리란 스팬의 이중 카테고리에서 정의된 모나드에 불과합니다.*

이 결과가 놀라운 이유는 카테고리를 모나드나 모노이드와 같은 다른 대수적 구조와 동일한 선상에 올려놓기 때문입니다. 카테고리는 특별한 존재가 아닙니다. 그저 두 개의 집합과 네 개의 함수일 뿐입니다. 사실 객체와 항등 화살표는 일대일 대응 관계에 있으므로 객체를 위한 별도의 집합조차 필요하지 않습니다. 따라서 카테고리는 본질적으로 하나의 집합과 몇 개의 함수만으로 설명됩니다. 카테고리 이론이 모든 수학에서 수행하는 중추적인 역할을 생각할 때, 이는 매우 겸허해지는 깨달음입니다.
