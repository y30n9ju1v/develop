'''

이 부록은 본문 이해에 필수가 아닙니다 — 건너뛰어도 책의 내용을 이해하는 데 전혀 지장이 없습니다.

하지만 2~5장에서 순수한 생각과 논증만으로 만들었던 마법 같은 일들이, **현대 프로그래밍 언어에서 실제로 똑같이 실행되는지 직접 눈으로 확인해 보는 것**은 대단히 신나고 짜릿한 경험입니다.

파이썬의 `lambda` 키워드(2장에서 배운 그리스 문자 `λ`입니다!)만을 사용하여, 본문의 빌딩 블록들을 하나씩 작동시켜 봅시다.

== 1. 처치 수와 후속자 (3장의 검증)

먼저 3장에서 정의한 숫자들을 코드로 옮깁니다.

[source,python]
----
# 숫자 0: f를 0번 적용하고 시작값 x를 그대로 반환한다
ZERO = lambda f: lambda x: x

# 후속자 (1 더하기): 기존 숫자 n에 f를 1번 더 감싸준다
def succ(n):
    return lambda f: lambda x: f(n(f)(x))

# 검증용 도구: 처치 수가 f를 몇 번 실행했는지 세어 실제 정수로 보여준다
def to_int(church_num):
    return church_num(lambda x: x + 1)(0)

# 편의용 도구: 일반 정수를 처치 수로 변환한다
def from_int(k):
    n = ZERO
    for _ in range(k):
        n = succ(n)
    return n
----

[NOTE]
====
`to_int` 함수의 원리를 보세요!  
반복할 행동 `f` 자리에 `lambda x: x + 1`(1 더하기 함수)을 넣고, 시작값 `x`에 `0`을 넣었습니다. 처치 수가 3번 반복하는 절차라면 `0`에 1이 3번 더해져 실제 파이썬 정수 `3`이 튀어나오게 됩니다!
====

== 2. 더하기: 2 + 3 = 5가 실제로 계산되는가?

3장에서 우리는 `2 + 3`을 **"`3`에 후속자(`succ`)를 `2`번 반복해서 적용한다"**고 정의했습니다.

[source,python]
----
TWO = from_int(2)
THREE = from_int(3)

# 덧셈: m이 정의한 횟수만큼, succ를 n에 적용한다!
def church_add(m, n):
    return m(succ)(n)
----

파이썬 인터프리터(REPL)에서 직접 실행해 봅시다.

[source]
----
>>> to_int(TWO)
2
>>> to_int(THREE)
3
>>> to_int(church_add(TWO, THREE))
5
----

어떤 `+` 연산자도, CPU의 덧셈 명령어 도움도 받지 않고, **순수한 함수의 중첩만으로 정확하게 `5`가 계산**되었습니다!

== 3. 참/거짓과 if문 (4장의 검증)

4장에서 `참`은 첫 번째를, `거짓`은 두 번째를 고르는 스위치라고 했습니다.

[source,python]
----
# TRUE: 첫 번째 인자 t를 선택
TRUE = lambda t: lambda f: t

# FALSE: 두 번째 인자 f를 선택
FALSE = lambda t: lambda f: f

# if문: 조건 cond 함수에 두 선택지를 차례대로 대입하기만 한다!
def church_if(cond, then_branch, else_branch):
    return cond(then_branch)(else_branch)
----

실행해 봅시다.

[source]
----
>>> church_if(TRUE, "사과가 맞습니다", "바나나입니다")
'사과가 맞습니다'

>>> church_if(FALSE, "사과가 맞습니다", "바나나입니다")
'바나나입니다'
----

파이썬 자체의 `if-else` 예약어를 쓰지 않고도, **오직 함수의 선택 메커니즘만으로 완벽한 조건 분기가 동작**합니다.

== 4. Y 콤비네이터: 이름 없는 재귀 (5장의 검증)

대망의 클라이맥스입니다. 5장에서 설명한 "이름 없이 스스로를 호출하는 재귀"를 검증해 봅시다.

[NOTE]
====
**파이썬을 위한 작은 팁 (Z 콤비네이터)**:  
파이썬은 함수를 호출할 때 인자를 즉시 계산하는 언어(Eager Evaluation)이기 때문에, 순수 람다 계산법의 `Y` 콤비네이터를 그대로 쓰면 인자를 계산하느라 즉시 무한 루프에 빠집니다. 그래서 인자 평가를 호출 시점까지 살짝 늦춰주는 함수형 언어의 표준 기교인 **Z 콤비네이터**를 사용합니다. 핵심 원리인 **함수의 자기 적용(`x(x)`)**은 100% 동일합니다.
====

[source,python]
----
# Z 콤비네이터 (즉시 평가 언어를 위한 Y 콤비네이터)
Z = lambda f: (lambda x: f(lambda v: x(x)(v)))(lambda x: f(lambda v: x(x)(v)))

# 팩토리얼 조수 공장 (어디에도 factorial이라는 자기 자신의 이름을 부르지 않는다!)
def fact_gen(self_fact):
    # self_fact는 나중에 Z 콤비네이터가 밖에서 공급해줄 '도구'일 뿐이다!
    return lambda n: 1 if n == 0 else n * self_fact(n - 1)

# 마법의 결합: Z에 공장을 넣으면 완성된 재귀 함수가 탄생한다!
factorial = Z(fact_gen)
----

이제 계산해 봅시다. `5! = 5 × 4 × 3 × 2 × 1 = 120`이 과연 나올까요?

[source]
----
>>> factorial(5)
120
>>> factorial(6)
720
----

`fact_gen` 함수 정의 어디에도 `factorial`이라는 이름표가 적혀있지 않습니다. 그런데도 `Z(fact_gen)`을 통과하자마자 재귀 함수가 되어 `120`을 정확히 계산해 냈습니다.

== 요약

* **손끝으로 만나는 이론**: 처치 수 덧셈, 불리언 `if`, 그리고 이름 없는 재귀까지 모두 파이썬 인터프리터에서 단 한 치의 오차도 없이 실행됨을 확인했습니다.
* **수학의 힘**: 1930년대 종이 위에 적혔던 순수한 사유의 규칙들이, 오늘날 컴퓨터의 기본 메모리와 프로세서 위에서도 동일하게 진리로 작동합니다.
