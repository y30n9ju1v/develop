'''

프로그래밍을 배울 때 가장 먼저 만나는 문법 중 하나가 `if (조건) { 참일 때 } else { 거짓일 때 }`입니다. 우리는 보통 `if`문을 프로그래밍 언어가 기본적으로 제공하는 특별한 하드웨어 스위치나 내장 기능으로 여깁니다.

하지만 람다 계산법에는 `if`라는 예약어도, `true`/`false`라는 특별한 데이터 타입도 없습니다. 오직 **함수**뿐입니다.

그렇다면 함수만으로 어떻게 조건 분기를 만들 수 있을까요?

== 참과 거짓: "두 갈래 길에서 하나를 고르는 스위치"

처치는 참(True)과 거짓(False)을 별도의 기호로 만드는 대신, **"두 가지 선택지를 받아서 그중 하나를 골라내는 선택 함수"**로 정의했습니다.

....
                   [ 참(TRUE)과 거짓(FALSE)의 정의 ]

        참 (TRUE)  :  λt. λf. t   ──► "첫 번째 것(t)을 고른다"
        거짓 (FALSE):  λt. λf. f   ──► "두 번째 것(f)을 고른다"
....

* **`TRUE` (`λt. λf. t`)**: 두 개의 인자(`t`, `f`)가 주어지면, 뒤돌아보지 않고 **첫 번째 인자 `t`**를 돌려줍니다.
* **`FALSE` (`λt. λf. f`)**: 두 개의 인자(`t`, `f`)가 주어지면, 첫 번째는 버리고 **두 번째 인자 `f`**를 돌려줍니다.

이것이 전부입니다. `참`과 `거짓`은 정적인 데이터가 아니라, **"첫 번째를 고를 것인가, 두 번째를 고를 것인가"를 결정하는 능동적인 스위치** 그 자체입니다.

== `if`문: 새로 만들 필요가 없다

이제 `if` 조건문을 만들어 봅시다.

`if(조건, 참일_때_값, 거짓일_때_값)`을 실행하고 싶다면 어떻게 해야 할까요? 아무것도 새로 만들 필요가 없습니다.

그저 **조건 자리에 온 함수(`TRUE` 또는 `FALSE`)에 두 선택지(`참일_때_값`, `거짓일_때_값`)를 순서대로 건네주기만 하면 끝납니다.**

....
                    [ if문의 작동 원리 ]

      조건(cond)에 '참일 때의 값'과 '거짓일 때의 값'을 그냥 대입한다

                 ( cond )   참_값   거짓_값
                     │
       ┌─────────────┴─────────────┐
       ▼                           ▼
   [ cond가 TRUE일 때 ]        [ cond가 FALSE일 때 ]
   (λt. λf. t) 참_값 거짓_값    (λt. λf. f) 참_값 거짓_값
          │                           │
          ▼ (첫 번째 선택)             ▼ (두 번째 선택)
        참_값                       거짓_값
....

손으로 직접 확인해 봅시다. `TRUE`에 `사과`와 `바나나`를 순서대로 넣어봅니다.

1. `(λt. λf. t) 사과` 를 베타 축약 → `λf. 사과` (사과를 기억하는 새 함수 탄생)
2. 그 결과에 `바나나`를 대입: `(λf. 사과) 바나나` → `사과` (두 번째 인자는 버려지고 `사과`만 남음)

조건이 `TRUE`이면 자연스럽게 첫 번째 선택지인 `사과`가 나오고, `FALSE`를 넣으면 두 번째 선택지인 `바나나`가 나옵니다. `if`문을 위한 별도의 복잡한 제어 흐름 문법이 전혀 필요하지 않았던 것입니다.

== 논리 연산도 함수로: AND, OR, NOT

이 원리를 응용하면 논리학의 모든 연산자도 순식간에 조립할 수 있습니다.

=== 1. 그리고 (AND)
두 조건 `p`와 `q`가 모두 참이어야 참이 되는 `AND(p, q)`를 생각해 봅시다.

> "`p`가 거짓이면 뒤도 볼 것 없이 `거짓`이다. 하지만 `p`가 참이라면, 최종 결과는 온전히 `q`의 참/거짓 여부에 달려있다."

이를 람다 계산법으로 표현하면 **`p q FALSE`**가 됩니다.
* `p`가 `TRUE`라면 → 첫 번째 선택지인 **`q`**를 반환 (결과는 `q`가 됨)
* `p`가 `FALSE`라면 → 두 번째 선택지인 **`FALSE`**를 반환

=== 2. 또는 (OR)
둘 중 하나만 참이어도 참이 되는 `OR(p, q)`는 어떻게 될까요?

> "`p`가 참이면 뒤도 볼 것 없이 `참`이다. 하지만 `p`가 거짓이라면, 최종 결과는 `q`에 달려있다."

따라서 **`p TRUE q`**가 됩니다.

=== 3. 아니다 (NOT)
참을 거짓으로, 거짓을 참으로 뒤집는 `NOT(p)`는 **`p FALSE TRUE`**입니다. `p`에게 첫 번째로 `FALSE`를, 두 번째로 `TRUE`를 주어 선택을 정반대로 뒤집어 버리는 것입니다.

[NOTE]
====
**흔히 헷갈리는 지점: 함수 안에 '참'이라는 의미가 들어있나요?**  
`λt. λf. t`라는 식 자체에는 "이것이 참이다"라는 글자가 적혀있지 않습니다. 단지 "두 개 중 첫 번째를 고르는 행동"을 우리가 편의상 `참(TRUE)`이라고 부르고, 그에 맞춰 시스템을 일관되게 설계했을 뿐입니다. 3장의 처치 수도, 4장의 불리언도 모두 **"그것이 무엇인가(명사)"가 아니라 "그것으로 무엇을 할 수 있는가(행동)"**로 대상을 정의합니다.
====

== 요약

* **`TRUE`와 `FALSE`**: 두 개의 입력 중 각각 첫 번째(`t`) 또는 두 번째(`f`)를 선택하는 함수입니다.
* **`if` 조건문**: 조건 함수에 두 갈래 선택지를 그대로 인자로 전달하는 것만으로 조건 분기가 완벽하게 실행됩니다.
* **논리 연산자**: `AND`, `OR`, `NOT` 역시 참/거짓 함수의 선택 메커니즘을 영리하게 조합하여 추가 문법 없이 구현됩니다.

[TIP]
====
**직접 확인해보기**:  
`NOT TRUE`를 손으로 풀어봅시다. `NOT`의 정의인 `p FALSE TRUE`의 `p` 자리에 `TRUE`(`λt. λf. t`)를 넣으면:  
`TRUE FALSE TRUE` → 첫 번째 인자를 고르므로 결과는 `FALSE`가 됩니다. 종이에 `NOT FALSE`도 직접 전개해 보세요.
====
