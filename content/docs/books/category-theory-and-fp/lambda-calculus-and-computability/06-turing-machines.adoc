3부가 시작됩니다. 

1장에서 예고했듯이, 앨런 튜링(Alan Turing)은 처치와는 완전히 다른 접근 방식으로 "계산이란 무엇인가"를 정의했습니다.

처치가 순수한 수학적 함수의 세계를 탐험했다면, 튜링은 **"물리적인 기계 장치가 규칙에 따라 움직이는 세계"**를 상상했습니다.

== 튜링 기계의 4가지 부품

상상해 보세요. 책상 위에 아주 단순하지만 무한히 긴 기계 장치 하나가 놓여 있습니다. 이 장치는 딱 4가지 부품으로 이루어져 있습니다.

....
                       [ 튜링 기계의 구조 ]

                 ┌───────────────┐
                 │  내부 상태 Q   │  (예: "숫자 읽는 중", "끝남")
                 └───────┬───────┘
                         │
                    [ 읽기/쓰기 헤드 ]
                         ▼
   ... ───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬─── ...
          │   │ 1 │ 1 │ 1 │   │   │   │   │   │     (무한 테이프)
   ... ───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴─── ...
                        ▲
                     현재 칸
....

1. **무한 테이프 (Tape)**: 양쪽으로 끝없이 이어지는 격자 칸입니다. 각 칸에는 기호(`0`, `1`, 또는 빈칸 `_`)가 하나씩 적힐 수 있으며, 기계의 메모리 역할을 합니다.
2. **읽기/쓰기 헤드 (Head)**: 테이프의 특정 칸 하나를 가리키며, 그 칸에 적힌 기호를 읽거나 새 기호를 덮어씁니다. 테이프 위에서 왼쪽(`L`)이나 오른쪽(`R`)으로 한 칸씩 움직일 수 있습니다.
3. **내부 상태 (State)**: 기계가 현재 기억하고 있는 단계입니다. (예: "시작 상태", "더하기 중", "정지 상태")
4. **규칙표 (Transition Table)**: 기계의 두뇌입니다. "지금 상태가 무엇이고, 헤드가 읽은 기호가 무엇인가"에 따라 다음 행동을 결정하는 고정된 매뉴얼입니다.

기계 자체는 아무런 지능이나 생각이 없습니다. 그저 **매 순간 규칙표를 보고 "기호를 쓰고 → 헤드를 이동하고 → 다음 상태로 바꾼다"를 기계적으로 반복**할 뿐입니다.

== 손으로 따라가 보기: 1을 더하는 기계

너무 추상적이니, 실제로 작동하는 가장 단순한 튜링 기계를 하나 만들어 봅시다.

테이프에 적힌 숫자에 `1`을 더하는 기계입니다. 숫자는 `1`의 개수로 표현합니다 (예: `111`은 숫자 `3`).

우리의 목표는 테이프에 적힌 `111`의 맨 뒤에 `1`을 하나 더 써서 `1111`(`4`)로 만드는 것입니다. 규칙표는 단 2줄이면 충분합니다.

|===
| 현재 상태 | 읽은 기호 | 쓸 기호 | 이동 방향 | 다음 상태

| 상태 A (이동 중) | `1` | `1` (그대로 둠) | 오른쪽(`R`) | 상태 A 유지
| 상태 A (이동 중) | `_` (빈칸) | `1` (1을 쓴다) | 정지 | **정지 (종료)**
|===

`111`이 적힌 테이프에서 기계를 돌려봅시다.

....
  [1단계] 헤드가 1번 칸의 '1'을 읽음 ──► 그대로 두고 오른쪽 이동
          테이프: [ 1 ]  1   1   _

  [2단계] 헤드가 2번 칸의 '1'을 읽음 ──► 그대로 두고 오른쪽 이동
          테이프:   1  [ 1 ] 1   _

  [3단계] 헤드가 3번 칸의 '1'을 읽음 ──► 그대로 두고 오른쪽 이동
          테이프:   1   1  [ 1 ] _

  [4단계] 헤드가 4번 칸의 빈칸('_')을 읽음 ──► '1'을 쓰고 멈춤!
          테이프:   1   1   1  [ 1 ]   ──► 최종 결과: 1111 (숫자 4!)
....

기계는 자신이 몇 번째 칸에 있는지, 전체 숫자가 얼마인지 전혀 모릅니다. 그저 매 순간 눈앞의 기호와 규칙표만 보고 움직였을 뿐인데, 결과적으로 덧셈이 일어난 것입니다.

== 튜링은 왜 이런 기계를 생각했을까?

람다 계산법은 "함수의 추상화와 적용"이라는 우아하고 수학적인 언어로 계산을 정의했습니다. 반면 튜링 기계는 테이프, 헤드, 상태표라는 매우 구체적이고 기계적인 장치를 씁니다.

튜링이 이런 모델을 고안한 이유는 **"인간이 종이와 연필로 계산할 때 실제로 무엇을 하는가?"**를 그대로 시뮬레이션하고 싶었기 때문입니다.

* 종이 위의 칸 → **테이프의 격자 칸**
* 계산하는 사람의 시선 → **읽기/쓰기 헤드**
* 사람의 머릿속 기억 → **기계의 내부 상태**
* 사람의 계산 규칙(구구단 등) → **규칙표**

튜링은 인간이 수행하는 모든 계산 행위를 가장 원초적이고 단순한 물리적 단계들로 해체하여 재구성한 것입니다.

[NOTE]
====
**흔히 헷갈리는 지점: 튜링 기계는 컴퓨터의 실물 설계도인가요?**  
튜링 기계는 실제로 공장에서 만들어서 쓰기 위한 기계가 아닙니다. "계산이란 과연 어디까지 가능한가?"라는 이론적 질문에 답하기 위해 만든 **수학적 사고 실험 모델**입니다. 오늘날의 슈퍼컴퓨터도 이론적인 계산 능력의 한계 측면에서는 이 단순한 테이프 기계와 정확히 똑같습니다.
====

== 극과 극의 두 세계

* **처치의 람다 계산법**: 수학적, 함수 중심, 기호의 치환(소프트웨어적 직관)
* **튜링의 튜링 기계**: 물리적, 상태 중심, 테이프의 이동(하드웨어적 직관)

두 모델은 겉보기에 공통점이라고는 하나도 찾아볼 수 없을 만큼 완전히 다릅니다.

그렇다면 어느 쪽이 "진짜 계산"의 올바른 정의일까요? 혹시 한쪽이 다른 쪽보다 더 많은 것을 계산할 수 있지는 않을까요?

다음 장에서 이 두 세계가 마주치며, 컴퓨터 과학 역사상 가장 경이로운 일치가 드러납니다.

== 요약

* **튜링 기계**: 무한 테이프, 읽기/쓰기 헤드, 내부 상태, 규칙표로 이루어진 가장 단순한 기계적 계산 모델입니다.
* **계산의 본질**: 사람은 종이와 연필로 계산하듯, 튜링 기계는 규칙표에 따라 테이프 위를 오가며 기호를 바꾸는 것만으로 모든 계산을 수행합니다.
* **다른 출발점**: 람다 계산법이 함수의 세계라면, 튜링 기계는 기계 장치의 세계입니다.
