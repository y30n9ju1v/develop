정리 증명 보조 도구로 프로그래밍 언어 이론(관계, 귀납적 명제, 조작적 의미론, 호어 논리)을 다루는 법을 Lean4로 처음부터 끝까지 새로 짜며 배우는 독립적인 입문서입니다. 명제도 타입이라는 발상과 귀납법(1부) → 관계·귀납적 명제·맵이라는 세 도구(2부) → 그 위에 짓는 작은 명령형 언어와 조작적 의미론(3부) → 증명 항·귀납 원리·호어 논리(4부)까지, 작은 프로그래밍 언어 하나를 처음부터 끝까지 설계·구현·검증합니다.

이 책의 코드 예제는 전부 이 책을 위해 새로 지은 것입니다 — 산술식·불식·명령문 언어(`AExp`, `BExp`, `Com`)와 그 예제 프로그램 전부 원본이며, 모든 코드는 Lean4(v4.32.0)로 실제 컴파일하고 증명을 검증했습니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
