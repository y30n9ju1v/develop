'''

5장에서 다항 특성으로 선형회귀를 과적합시켜봤습니다. 신경망은 층과 뉴런을 늘리는 것만으로도 훨씬 쉽게 과적합됩니다 — 표현력이 원래부터 매우 크기 때문입니다. 이 장에서는 신경망으로 `satisfaction_score`를 예측하는 회귀 모델을 만들면서, 일부러 과적합을 재현하고, 이를 막는 두 가지 표준 기법(`Dropout`, `EarlyStopping`)의 효과를 직접 확인합니다.

== 회귀 모델의 출력층: 활성화 함수 없음

[source,python]
----
model = keras.Sequential([
    keras.Input(shape=(X_train.shape[1],)),
    keras.layers.Dense(128, activation="relu"),
    keras.layers.Dense(128, activation="relu"),
    keras.layers.Dense(64, activation="relu"),
    keras.layers.Dense(1),   # 활성화 함수 없음 -- 임의의 실수값을 그대로 출력
])
model.compile(optimizer="adam", loss="mse", metrics=["mae"])
----

8장의 분류 모델과 다른 부분은 출력층입니다 — `satisfaction_score`는 `0~100` 사이의 임의의 실수이므로, `sigmoid`(0~1로 압축)나 `softmax`(확률분포)로 누를 이유가 없습니다. 활성화 함수를 아예 지정하지 않으면(기본값은 항등함수) 모델이 어떤 실수든 그대로 출력할 수 있습니다. 손실 함수도 `mse`(평균제곱오차, 5장에서 다룬 RMSE의 제곱 버전)로 바꿉니다.

== 과적합 재현하기: 적은 데이터 + 큰 모델

과적합을 뚜렷하게 보여주기 위해, 일부러 데이터를 `300`개로 줄이고(원래 `1000`개), `128`개 뉴런짜리 층을 여러 개 쌓은 큰 모델을 `200`에폭이나 학습시킵니다.

[source,python]
----
model_over = build_big_model()  # Dense(128)->Dense(128)->Dense(64)->Dense(1)
hist_over = model_over.fit(X_train_s, y_train, epochs=200, batch_size=16, verbose=0,
                             validation_data=(X_test_s, y_test))
print(hist_over.history["loss"][-1], hist_over.history["val_loss"][-1])
----

[source]
----
final train MSE: 17.04
final val   MSE: 113.20   (훈련 손실의 6배 이상)
----

극단적인 격차입니다 — 훈련 데이터에는 평균 제곱오차 `17`(RMSE로 환산하면 대략 `4.1`)까지 맞추도록 학습됐지만, 처음 보는 데이터에서는 오차가 `113`(RMSE `10.6`)이나 됩니다. `300`개뿐인 훈련 데이터에 비해 모델의 파라미터 수가 압도적으로 많아서, 모델이 각 샘플의 개별적인 노이즈까지 전부 "암기"해버린 것입니다.

== 손실 곡선을 시간순으로 보면: 최적 지점을 이미 지나쳤다

[source,python]
----
val_losses = hist_over.history["val_loss"]
min_val_epoch = int(np.argmin(val_losses))
print(min_val_epoch, len(val_losses), val_losses[-1])
----

[source]
----
min val loss at epoch: 54 (of 200)   final val loss: 113.20
----

검증 손실이 가장 낮았던 시점은 `54`번째 에폭이었는데, 학습은 그 이후로도 `146`번을 더 진행했습니다 — `54`에폭 이후로는 모델이 훈련 데이터에 더 맞춰갈수록 오히려 처음 보는 데이터에는 더 나빠지고 있었다는 뜻입니다. 이게 바로 "학습을 오래 하면 무조건 좋아진다"는 생각이 틀렸다는 걸 보여주는 직접적인 증거입니다.

== Dropout: 학습 중 일부 뉴런을 무작위로 꺼버리기

[source,python]
----
model_dropout = keras.Sequential([
    keras.Input(shape=(X_train.shape[1],)),
    keras.layers.Dense(128, activation="relu"),
    keras.layers.Dropout(0.3),
    keras.layers.Dense(128, activation="relu"),
    keras.layers.Dropout(0.3),
    keras.layers.Dense(64, activation="relu"),
    keras.layers.Dense(1),
])
----

`Dropout(0.3)`은 학습 중 매 스텝마다 해당 층 뉴런의 `30%`를 무작위로 꺼버립니다(출력을 `0`으로 만듦). 매번 다른 뉴런 조합으로 학습하게 되니, 모델이 특정 뉴런 몇 개에 과도하게 의존하는 "암기"를 하기 어려워집니다 — 여러 개의 서로 다른 부분 신경망을 앙상블하는 것과 비슷한 효과를 냅니다(6장의 랜덤포레스트가 여러 트리를 앙상블한 것과 원리가 비슷합니다).

[source,python]
----
hist_dropout = model_dropout.fit(X_train_s, y_train, epochs=200, batch_size=16, verbose=0,
                                   validation_data=(X_test_s, y_test))
print(hist_dropout.history["loss"][-1], hist_dropout.history["val_loss"][-1])
----

[source]
----
final train MSE: 97.21
final val   MSE: 88.38
----

[source,python]
----
gap_over = 113.20 - 17.04      # 96.17
gap_dropout = 88.38 - 97.21    # -8.83
print(gap_over, gap_dropout)
assert gap_dropout < gap_over
----

과적합 모델의 train/val 격차는 `96.17`이었는데, `Dropout`을 넣은 모델은 오히려 검증 손실(`88.38`)이 훈련 손실(`97.21`)보다 **낮습니다**(격차가 음수). `Dropout`이 학습 중에는 매번 뉴런의 `30%`를 꺼서 훈련 손실을 일부러 더 어렵게 만들지만, 평가(`evaluate`) 시점에는 모든 뉴런을 다 쓰기 때문에 이런 역전이 나타날 수 있습니다. 절대적인 검증 손실 수치(`88.38`)만 봐도 과적합 모델의 검증 손실(`113.20`)보다 확실히 낮습니다 — `Dropout`이 실제로 일반화 성능을 개선했다는 뜻입니다.

== EarlyStopping: 검증 손실이 더 안 좋아지면 학습을 멈추기

`Dropout`이 과적합 자체를 억누르는 방법이라면, `EarlyStopping`은 "최적의 순간에 학습을 멈춰서" 과적합이 심해지기 전에 빠져나오는 방법입니다.

[source,python]
----
early_stop = keras.callbacks.EarlyStopping(monitor="val_loss", patience=10, restore_best_weights=True)
hist_es = model_es.fit(X_train_s, y_train, epochs=200, batch_size=16, verbose=0,
                         validation_data=(X_test_s, y_test), callbacks=[early_stop])
print(len(hist_es.history["loss"]))
----

[source]
----
trained for 80 epochs (out of 200 max)
----

`monitor="val_loss"`는 검증 손실을 감시하라는 뜻이고, `patience=10`은 검증 손실이 `10`에폭 연속으로 개선되지 않으면 학습을 멈추라는 뜻입니다. `restore_best_weights=True`는 멈춘 시점의 가중치가 아니라, **학습 도중 검증 손실이 가장 낮았던 시점**의 가중치로 되돌려놓으라는 뜻입니다 — `200`에폭을 다 채우지 않고 `80`에폭에서 스스로 멈췄습니다.

[source,python]
----
final_val_loss_es = model_es.evaluate(X_test_s, y_test, verbose=0)[0]
print(final_val_loss_es, val_loss_over)  # 80.40  113.20
----

`EarlyStopping`으로 학습한 모델의 검증 손실(`80.40`)이, `200`에폭을 꽉 채워 과적합된 모델(`113.20`)보다 확실히 낮습니다 — 오히려 **덜 학습한** 모델이 더 나은 성능을 낸 것입니다. "학습을 오래 시킬수록 좋다"가 아니라 "검증 성능이 가장 좋은 시점에서 멈추는 게 좋다"는 걸 숫자로 확인했습니다.

== 왜 이게 중요한가

AICE 시험처럼 제한된 시간 안에 모델을 완성해야 하는 상황에서는, `EarlyStopping`이 특히 유용합니다 — 몇 에폭이 최적인지 미리 알 필요 없이, `patience` 값 하나만 정해두면 알아서 적절한 시점에 멈추고 최선의 가중치를 남겨주기 때문입니다. `Dropout`과 `EarlyStopping`을 함께 쓰는 것도 흔한 조합입니다.

== 직접 해보기

* `patience`를 `10`에서 `3`으로 줄이면, 학습이 몇 에폭 만에 멈추는지, 그리고 그 결과 검증 손실이 `patience=10`일 때보다 더 좋은지 나쁜지 확인해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
early_stop_short = keras.callbacks.EarlyStopping(monitor="val_loss", patience=3, restore_best_weights=True)
model_es2 = build_big_model()
model_es2.compile(optimizer="adam", loss="mse", metrics=["mae"])
hist_es2 = model_es2.fit(X_train_s, y_train, epochs=200, batch_size=16, verbose=0,
                           validation_data=(X_test_s, y_test), callbacks=[early_stop_short])
print(len(hist_es2.history["loss"]), model_es2.evaluate(X_test_s, y_test, verbose=0)[0])
----

`patience`가 작을수록 검증 손실이 잠깐 정체되기만 해도 바로 멈추기 때문에, 학습이 더 일찍 끝납니다. 하지만 신경망 학습은 손실이 일시적으로 정체되거나 살짝 나빠졌다가 다시 좋아지는 경우도 흔해서, `patience`가 너무 작으면 아직 개선될 여지가 있는데도 성급하게 멈춰버릴 위험이 있습니다. 반대로 `patience`가 너무 크면 이 장의 첫 실험처럼 과적합이 상당히 진행된 뒤에야 멈추게 됩니다 — `patience`도 학습 안정성과 효율 사이의 균형을 조절하는 손잡이입니다.

== 요약

* 회귀 모델의 출력층은 활성화 함수를 쓰지 않아(항등함수), 임의의 실수를 그대로 출력하게 합니다.
* 적은 데이터에 큰 모델을 오래 학습시키면, train MSE는 계속 낮아지지만 val MSE는 어느 시점(이 실험에서는 `54`에폭) 이후 오히려 나빠지는 뚜렷한 과적합이 재현됩니다.
* `Dropout`은 학습 중 뉴런 일부를 무작위로 꺼서 과적합을 억누르고, 실제로 train/val 격차를 크게 줄였습니다.
* `EarlyStopping`은 검증 손실이 더 이상 개선되지 않으면 학습을 멈추고 최선의 가중치를 남겨, `200`에폭을 다 채운 과적합 모델보다 더 낮은 검증 손실을 달성했습니다.

3부에서 Keras로 분류와 회귀를 모두 다루고 과적합까지 막아봤습니다. 4부에서는 이미지 데이터와 CNN, 모델 저장/평가, 그리고 시험형 문제를 처음부터 끝까지 통째로 풀어보는 종합 실전으로 넘어갑니다.
