선형 타입과 세션 타입으로 병렬·동시 프로그램의 안전성을 타입 수준에서 증명하는 법을, Lean4로 처음부터 끝까지 새로 지어 검증하는 독립적인 입문서입니다. 왜 선형성인가(1부) → 타입 시스템 증명하기(2부) → 세션 타입으로(3부) → 종합과 확장(4부) 순서로 쌓아 올립니다.

이 책의 모든 정리 — 선형 람다계산법의 Progress, 세션 타입의 교착 없음(`session_progress`) — 는 이 세션 환경에 실제로 설치된 Lean4(v4.32.0, elan)로 실제 컴파일하고 증명을 검증했습니다. `session_progress`는 `sorryAx`는 물론 어떤 공리에도 의존하지 않고 완전히 증명됩니다.

이 책은 이 사이트의 `fp-backbone-of-async`와 `nand2npu-cpu`가 미뤄뒀던 선형 타입이라는 복선을 회수하고, `nand2npu-gpu`가 하드웨어 조작적 의미론으로 증명한 병렬 안전성을 타입 시스템의 눈으로 다시 읽는, 독립적인 타입 이론 입문서입니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
