주사위 두 개를 던지는 상황을 생각해봅시다. 첫 번째 주사위가 무엇이 나오든 두 번째 주사위의 결과에는 아무 영향을 주지 않습니다 — 이게 바로 **독립**이라는 직관입니다. 이 장에서는 이 직관을 정확한 수식으로, 그리고 실제 증명으로 확인합니다.

== 두 확률공간을 하나로 묶기

[source,lean]
----
noncomputable def twoDice : PMF (Fin 6 × Fin 6) :=
  fairDie.bind fun a => fairDie.bind fun b => PMF.pure (a, b)
----

`PMF`는 모나드 구조를 갖고 있어서, `bind`(다른 언어의 `flatMap`과 같습니다)와 `pure`로 여러 확률적 선택을 이어붙일 수 있습니다 — "먼저 `fairDie`에서 `a`를 뽑고, 그다음 다시 `fairDie`에서 `b`를 뽑아, `(a, b)` 쌍을 결과로 낸다"는 절차를 그대로 코드로 옮긴 것입니다. `PMF.pure x`는 "확률 1로 `x`만 나오는" 가장 단순한 확률분포이고, `p.bind f`는 "먼저 `p`에서 뽑고, 그 결과에 따라 `f`가 정해주는 새로운 확률분포에서 다시 뽑는" 절차를 하나의 `PMF`로 압축합니다.

== 결합 확률이 곱으로 갈라진다

[source,lean]
----
example : twoDice (0, 0) = (1 / 6 : ℝ≥0∞) * (1 / 6 : ℝ≥0∞) := by
  simp only [twoDice, PMF.bind_apply, fairDie, PMF.ofFintype_apply, PMF.pure_apply]
  rw [tsum_eq_single 0 (fun b' hb => by simp [Ne.symm hb])]
  simp
----

"두 주사위가 모두 0(첫 번째 면)을 보일 확률"이 정확히 "첫 번째 주사위가 0일 확률" 곱하기 "두 번째 주사위가 0일 확률"과 같다는 걸 증명했습니다 — `1/6 * 1/6`입니다. 이게 바로 **독립성의 정의**입니다: 두 확률변수(또는 사건)가 독립이라는 건, 정확히 이렇게 **결합 확률이 각자의 확률의 곱으로 분해된다**는 뜻입니다. `bind`/`pure`로 지은 `twoDice`가 이 성질을 만족한다는 게 우연이 아닙니다 — 애초에 "서로 영향을 주지 않고 각자 독립적으로 뽑는다"는 절차를 그대로 코드로 옮겼기 때문에, 그 결과로 나온 결합분포가 자동으로 독립성을 만족하는 것입니다.

증명 과정을 뜯어보면, `twoDice (0, 0)`을 펼치면 이중 무한합(`tsum`, 여기서는 실제로는 `Fin 6` 위의 유한합)이 나오는데, `tsum_eq_single`로 "쌍의 첫 번째 값이 정확히 0인 항만 남고 나머지는 전부 0으로 사라진다"는 걸 보여, 결국 곱셈 형태로 정리됩니다.

== 다른 값에 대해서도 성립한다

같은 패턴이 `(0, 0)`뿐 아니라 어떤 결과 쌍에 대해서도 성립합니다 — 아래는 `(2, 4)`에 대한 예시입니다.

[source,lean]
----
example : twoDice (2, 4) = fairDie 2 * fairDie 4 := by
  simp only [twoDice, PMF.bind_apply, fairDie, PMF.ofFintype_apply, PMF.pure_apply]
  rw [tsum_eq_single 2 (fun b' hb => by simp [Ne.symm hb])]
  simp
----

증명의 구조가 `(0, 0)`일 때와 완전히 똑같습니다 — `tsum_eq_single`에 넘기는 값만 `2`로 바뀔 뿐입니다. 이 반복되는 구조 자체가, "독립성은 결과가 무엇이든 상관없이 성립하는 성질"이라는 걸 잘 보여줍니다.

== 직접 해보기

* `twoDice (3, 1) = fairDie 3 * fairDie 1`을 증명해보세요 — 위 두 예제와 같은 패턴을 따라가면 됩니다.

.해답 보기
[%collapsible]
====
[source,lean]
----
example : twoDice (3, 1) = fairDie 3 * fairDie 1 := by
  simp only [twoDice, PMF.bind_apply, fairDie, PMF.ofFintype_apply, PMF.pure_apply]
  rw [tsum_eq_single 3 (fun b' hb => by simp [Ne.symm hb])]
  simp
----
====

== 요약

* `PMF`의 `bind`/`pure`로 "먼저 이걸 뽑고, 그다음 저걸 뽑는다"는 절차를 하나의 결합 확률분포로 지을 수 있습니다.
* 독립성은 정확히 "결합 확률이 각자의 확률의 곱으로 분해된다"는 성질이고, `bind`/`pure`로 지은 결합분포는 이 성질을 자동으로 만족합니다.
* 이 패턴은 특정 결과에 국한되지 않고, 어떤 결과 쌍에 대해서도 같은 방식으로 증명됩니다.

1부가 여기서 끝났습니다. 2부에서는 확률을 진짜 측도로 확장해서, 결과가 무한히 많은 경우까지 다룹니다.
