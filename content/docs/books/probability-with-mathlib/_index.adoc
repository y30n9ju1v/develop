주사위 같은 이산 확률에서 시작해 측도로서의 확률, 기댓값과 독립성, 그리고 큰 수의 법칙과 중심극한정리까지 Lean4와 Mathlib으로 직접 증명하며 배우는 독립적인 확률론 입문서입니다. "확률은 넓이다"라는 하나의 그림을 축으로, 이산 확률(1부) → 일반 확률공간(2부) → 기댓값과 구조(3부) → 극한정리(4부) 순서로 쌓아 올립니다.

이 책의 모든 예제·증명·연습문제는 이 책을 위해 새로 지은 원본이며, 모든 코드는 Lean4(v4.33.0-rc1)와 Mathlib으로 실제 컴파일하고 검증했습니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
