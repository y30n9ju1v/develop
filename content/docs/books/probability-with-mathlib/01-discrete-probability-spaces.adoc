== PMF: 확률을 함수로 정의하기

주사위를 던지는 것처럼 결과가 유한하거나 셀 수 있는 상황에서는, 확률을 "각 결과에 하나씩 붙이는 숫자"로 정의할 수 있습니다. Mathlib은 이걸 `PMF`(probability mass function, 확률질량함수)라는 타입으로 표현합니다.

[source,lean]
----
noncomputable def fairDie : PMF (Fin 6) :=
  PMF.ofFintype (fun _ => (1 : ℝ≥0∞) / 6) (by
    rw [Finset.sum_const, Finset.card_univ]
    simp
    rw [ENNReal.mul_inv_cancel] <;> norm_num)
----

`PMF α`는 정의상 "`α`의 각 값에 `ℝ≥0∞`(음이 아닌 확장 실수) 값을 매기는데, 그 값들을 전부 더하면 정확히 1이 되는 함수"입니다 — 이 "합이 1"이라는 조건이야말로 "확률"이라는 이름에 걸맞은 자격입니다. `PMF.ofFintype`은 유한한 타입 위에서 이 함수를 만드는 생성자이고, 첫 번째 인자는 "각 결과에 얼마의 확률을 줄지"를, 두 번째 인자는 "그 확률들의 합이 정말 1이 된다"는 증명을 요구합니다. `fairDie`는 `Fin 6`(0부터 5까지 여섯 개의 값, 주사위의 여섯 면)의 각 결과에 똑같이 `1/6`을 배정합니다.

== 개별 결과의 확률

[source,lean]
----
example : fairDie 0 = 1 / 6 := by
  simp [fairDie, PMF.ofFintype_apply]
----

`PMF`는 함수이기 때문에, `fairDie 0`처럼 그냥 함수를 적용하면 그 결과의 확률을 얻습니다 — 주사위의 첫 번째 면(`0`으로 표현된)이 나올 확률이 정확히 `1/6`이라는 걸 증명했습니다.

== 확률의 합은 항상 1이다

[source,lean]
----
example : ∑' i, fairDie i = 1 := fairDie.tsum_coe
----

`PMF` 타입 자체의 정의(합이 1)를 그대로 꺼내 쓰는 `tsum_coe`라는 정리가 모든 `PMF`에 이미 갖춰져 있습니다 — 직접 짓지 않은 다른 어떤 `PMF`에 대해서도 "확률의 총합은 1"이라는 사실을 공짜로 얻습니다.

== 사건의 확률: 여러 결과를 모으기

[source,lean]
----
example : fairDie.toOuterMeasure (↑({1, 3, 5} : Finset (Fin 6))) = 3 * (1 / 6 : ℝ≥0∞) := by
  rw [PMF.toOuterMeasure_apply_finset]
  simp [fairDie, PMF.ofFintype_apply]
----

"주사위가 짝수 면(2, 4, 6, 여기서는 인덱스 `1`, `3`, `5`)이 나올 확률"처럼, 하나의 결과가 아니라 **여러 결과를 모은 사건**의 확률을 묻고 싶을 때가 많습니다. `PMF.toOuterMeasure`는 `PMF`를 사건(집합)에 확률을 매기는 함수로 확장해주고, `toOuterMeasure_apply_finset`이라는 정리는 유한집합에 대해서는 이게 정확히 **그 안에 속한 결과들의 확률을 다 더한 것**과 같다는 걸 보장합니다 — 세 개의 면 각각 `1/6`이니 합쳐서 `3 * (1/6)`, 즉 이산 확률의 세계에서 "넓이를 잰다"는 것이 결국 "경우의 수를 세고 더한다"는 것과 같다는 걸 보여줍니다. 이 "사건 = 결과들의 집합, 사건의 확률 = 그 집합에 매겨진 측도"라는 그림이 2부에서 무한히 많은 결과가 있는 세계로 그대로 확장됩니다.

== 직접 해보기

* `fairDie`에서 "1 이상 4 이하의 눈이 나올 사건"(인덱스로는 `{0, 1, 2, 3}`)의 확률이 `4 * (1/6)`임을 증명해보세요.

.해답 보기
[%collapsible]
====
[source,lean]
----
example : fairDie.toOuterMeasure (↑({0, 1, 2, 3} : Finset (Fin 6))) = 4 * (1 / 6 : ℝ≥0∞) := by
  rw [PMF.toOuterMeasure_apply_finset]
  simp [fairDie, PMF.ofFintype_apply]
----
====

== 요약

* `PMF α`는 "각 결과에 확률을 매기되, 그 총합이 1인 함수"이고, `PMF.ofFintype`으로 유한한 결과 공간 위에 직접 지을 수 있습니다.
* `p a`로 개별 결과의 확률을, `p.toOuterMeasure s`로 여러 결과를 모은 사건의 확률을 얻습니다.
* 유한집합에 대해서는 사건의 확률이 정확히 그 안에 속한 결과들의 확률의 합입니다 — 이산 확률에서 "넓이를 잰다"는 건 "경우의 수를 세고 더한다"는 것과 같습니다.
