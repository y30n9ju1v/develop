동전을 무한히 던진다고 합시다. "앞면이 무한 번 나온다"는 사건의 확률은 얼마일까요? 이런 질문에 답하려면 먼저 "무한 번 일어난다"는 걸 정확한 수학으로 표현해야 합니다.

== limsup: 무한히 많은 사건 중 무한 번 일어나는 사건

사건들의 수열 `s : ℕ → Set Ω`가 있을 때, `limsup s atTop`(집합의 상극한)은 정확히 **"무한히 많은 `n`에 대해 `sₙ`이 일어난다"**는 사건을 나타냅니다 — `n`번째 시행 이후로 아무리 멀리 가도, 그 뒤에 또 `sₖ`가 일어나는 `k`가 있다는 뜻입니다. "가끔 일어나고 마는" 사건과 "정말로 무한 번 반복해서 일어나는" 사건을 구분하는 정확한 개념이 이 `limsup`입니다.

== 첫 번째 보렐-칸텔리 보조정리: 확률의 합이 유한하면

[source,lean]
----
example (s : ℕ → Set ℝ) (hs : ∑' i, uniformMeasure (s i) ≠ ∞) :
    uniformMeasure (limsup s atTop) = 0 :=
  measure_limsup_atTop_eq_zero hs
----

**첫 번째 보렐-칸텔리 보조정리**는 이렇게 말합니다: 만약 사건들의 확률을 전부 더한 값이 유한하다면(`∑' i, μ(sᵢ) ≠ ∞`), 그 사건들이 무한 번 일어날 확률은 정확히 0입니다. 직관적으로, 사건이 일어날 확률이 너무 빨리 작아지면(그 합이 수렴할 정도로), "무한 번 계속 일어난다"는 건 사실상 불가능해집니다. 이 정리는 **독립성을 전혀 요구하지 않습니다** — 사건들이 서로 얼마나 얽혀 있든 상관없이, 확률의 합이 유한하기만 하면 성립하는 매우 일반적인 사실입니다.

예를 들어, "`n`번째 시행에서 사건이 일어날 확률이 `1/n²`씩 준다"고 하면, `∑ 1/n²`(바젤 문제로 유명한, `π²/6`으로 수렴하는 급수)이 유한하므로, 이 사건은 무한 번 일어나지 않습니다(확률 1로, 어느 시점 이후로는 다시는 일어나지 않습니다).

== 두 번째 보렐-칸텔리 보조정리: 독립이고 합이 무한대라면

[source,lean]
----
example {Ω : Type*} {mΩ : MeasurableSpace Ω} {μ : Measure Ω} [IsProbabilityMeasure μ]
    (s : ℕ → Set Ω) (hsm : ∀ n, MeasurableSet (s n)) (hs : iIndepSet s μ)
    (hs' : (∑' n, μ (s n)) = ∞) :
    μ (limsup s atTop) = 1 :=
  measure_limsup_eq_one hsm hs hs'
----

**두 번째 보렐-칸텔리 보조정리**는 정반대 방향의 결론을 줍니다 — 사건들이 **서로 독립**(9장에서 다룬 `iIndepSet`, `IndepFun`을 사건들의 모임으로 확장한 버전)이고, 확률의 합이 **무한대로 발산**한다면, 그 사건들은 무한 번 일어날 확률이 정확히 **1**입니다. 이번에는 독립성이 반드시 필요합니다 — 독립이 아니라면, 개별 확률의 합이 아무리 커도 "무한 번 일어난다"는 게 보장되지 않습니다(예를 들어 사건들이 전부 같은 사건이라면, 그 사건 자체가 일어나지 않는 이상 무한 번 일어날 수 없습니다).

이 두 보조정리를 합치면 놀라운 결론이 나옵니다 — **독립인 사건들의 수열에서, "무한 번 일어난다"는 사건의 확률은 항상 0 아니면 1입니다**(확률의 합이 유한하면 0, 무한대면 1). 이 "0 아니면 1"이라는 극단적인 결론이 확률론에서 반복해서 등장하는 **0-1 법칙**의 가장 유명한 사례입니다.

== 왜 이게 큰 수의 법칙으로 이어지는가

"동전을 던졌을 때 앞면이 무한 번 나올까?"라는 질문과 "동전을 무한히 던졌을 때 앞면의 비율이 1/2로 수렴할까?"라는 질문은 겉보기엔 다르지만, 둘 다 "무한히 반복되는 확률적 사건이 극한에서 어떻게 행동하는가"를 묻는다는 점에서 같은 뿌리를 가집니다. 다음 장에서 다룰 큰 수의 법칙이 바로 후자의 질문에 답하고, 그 증명의 밑바탕에도 이 장에서 본 것과 비슷한 극한 논증이 깔려 있습니다.

== 직접 해보기

* 첫 번째 보렐-칸텔리 보조정리를 적용하려면 왜 "확률의 합이 유한하다"는 조건이 꼭 필요한지 생각해보세요 — 만약 모든 `sₙ`이 확률 `1/2`인 서로 다른 독립 사건이라면(합이 무한대로 발산), `limsup sₙ`의 확률이 여전히 0일 수 있을까요?

.해답 보기
[%collapsible]
====
아닙니다. 모든 `sₙ`이 확률 `1/2`인 독립 사건이라면, `∑ 1/2 = ∞`(합이 발산)이므로 첫 번째 보조정리의 전제(합이 유한)를 만족하지 못해 적용할 수 없습니다 — 오히려 이 상황은 두 번째 보조정리의 전제(독립 + 합이 무한대로 발산)를 정확히 만족하므로, `limsup sₙ`의 확률은 0이 아니라 **1**입니다("동전을 무한히 던지면 앞면이 무한 번 나온다"는 사실이 바로 이 경우입니다). 두 보조정리의 전제가 정확히 반대 상황(합이 유한 vs. 독립+발산)을 다루기 때문에, 어느 한쪽만 만족하면 결론이 정반대로 갈립니다.
====

== 요약

* `limsup s atTop`은 "사건 `sₙ`이 무한히 많은 `n`에 대해 일어난다"는 사건을 정확히 표현합니다.
* 첫 번째 보렐-칸텔리 보조정리: 확률의 합이 유한하면, 무한 번 일어날 확률은 0입니다(독립성 불필요).
* 두 번째 보렐-칸텔리 보조정리: 사건들이 독립이고 확률의 합이 발산하면, 무한 번 일어날 확률은 1입니다.
* 두 정리를 합치면, 독립 사건열에서 "무한 번 일어난다"는 확률은 항상 0 아니면 1이라는 0-1 법칙을 얻습니다.

다음 장에서는 이 극한적 사고방식을 이어받아, 확률론에서 가장 유명한 정리인 큰 수의 법칙을 다룹니다.
