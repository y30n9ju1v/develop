'''

기댓값(평균)만으로는 확률변수를 완전히 설명할 수 없습니다 — 평균이 같아도 어떤 분포는 평균 근처에 값이 몰려 있고, 어떤 분포는 넓게 퍼져 있습니다. **분산**이 이 "퍼진 정도"를 재는 숫자입니다.

== 2차 모멘트: 제곱의 기댓값

[source,lean]
----
example : ∫ x, x ^ 2 ∂uniformMeasure = 1 / 3 := by
  rw [uniformMeasure, MeasureTheory.integral_Icc_eq_integral_Ioc,
    ← intervalIntegral.integral_of_le (by norm_num : (0:ℝ) ≤ 1), integral_pow]
  norm_num
----

`E[X^k]`(확률변수의 `k`제곱의 기댓값)을 **`k`차 모멘트**라고 부릅니다. 1차 모멘트는 그냥 평균(7장에서 계산한 `E[X] = 1/2`)이고, 2차 모멘트는 `E[X²]`입니다 — `integral_pow`(미적분학의 "`xⁿ`의 적분은 `xⁿ⁺¹/(n+1)`" 공식)를 그대로 재사용해서, 균등분포의 2차 모멘트가 `1/3`이라는 걸 계산했습니다.

== 분산: E[X²] - E[X]²

[source,lean]
----
noncomputable def variance : ℝ :=
  (∫ x, x ^ 2 ∂uniformMeasure) - (∫ x, x ∂uniformMeasure) ^ 2

example : variance = 1 / 12 := by
  unfold variance
  have h1 : ∫ x, x ^ 2 ∂uniformMeasure = 1 / 3 := by
    rw [uniformMeasure, MeasureTheory.integral_Icc_eq_integral_Ioc,
      ← intervalIntegral.integral_of_le (by norm_num : (0:ℝ) ≤ 1), integral_pow]
    norm_num
  have h2 : ∫ x, x ∂uniformMeasure = 1 / 2 := by
    rw [uniformMeasure, MeasureTheory.integral_Icc_eq_integral_Ioc,
      ← intervalIntegral.integral_of_le (by norm_num : (0:ℝ) ≤ 1), integral_id]
    norm_num
  rw [h1, h2]
  norm_num
----

분산의 정의 `Var(X) = E[X²] - E[X]²`(2차 모멘트에서 1차 모멘트의 제곱을 뺀 것)를 그대로 코드로 옮겨, `[0, 1]` 균등분포의 분산이 정확히 `1/12`라는 걸 증명했습니다. 이 공식은 "평균으로부터의 편차의 제곱의 평균"(`E[(X - E[X])²]`)이라는 더 직관적인 정의를 대수적으로 전개하면 얻어지는 동치식입니다 — `E[(X-μ)²] = E[X² - 2μX + μ²] = E[X²] - 2μ·E[X] + μ² = E[X²] - μ²`(`μ = E[X]`를 대입하면). 계산이 간단해서 이 책에서는 전개된 형태를 바로 정의로 씁니다.

== Mathlib의 실제 분산

Mathlib에는 `ProbabilityTheory.variance`라는 이름으로 이미 분산이 정의돼 있습니다(`Mathlib/Probability/Moments/Variance.lean`) — 다만 이 정의는 적분이 잘 정의되는지(`Memℒp` 조건) 같은 일반적인 상황까지 다루기 위해 `evariance`(확장된 분산)를 거쳐 정의되는 등, 이 책에서 손으로 지은 `variance`보다 조금 더 정교합니다. 이 장에서 직접 조립한 정의가 그 실제 정의의 핵심 아이디어를 그대로 담고 있습니다.

== 직접 해보기

* `∫ x, (2*x) ^ 2 ∂uniformMeasure = 4 / 3`을 증명해보세요(힌트: `(2*x)^2 = 4*x^2`로 다시 쓴 뒤 상수를 적분 밖으로 빼냅니다).

.해답 보기
[%collapsible]
====
[source,lean]
----
example : ∫ x, (2 * x) ^ 2 ∂uniformMeasure = 4 / 3 := by
  have : (fun x : ℝ => (2 * x) ^ 2) = (fun x : ℝ => 4 * x ^ 2) := by
    funext x; ring
  rw [this, uniformMeasure, MeasureTheory.integral_Icc_eq_integral_Ioc,
    ← intervalIntegral.integral_of_le (by norm_num : (0:ℝ) ≤ 1),
    intervalIntegral.integral_const_mul, integral_pow]
  norm_num
----
====

== 요약

* `k`차 모멘트는 `E[X^k]`이고, 미적분학의 거듭제곱 적분 공식으로 직접 계산할 수 있습니다.
* 분산은 `E[X²] - E[X]²`로 정의되고, "평균으로부터의 편차 제곱의 평균"이라는 직관적 정의를 대수적으로 전개한 것과 같습니다.
* `[0, 1]` 균등분포의 분산은 `1/12`입니다.

다음 장에서는 3장에서 이산 확률에 대해서만 봤던 독립성을, 일반적인 확률변수에 대해 정의하는 `IndepFun`을 다룹니다.
