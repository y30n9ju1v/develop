자동미분의 기초에서 시작해서, 볼륨 렌더링과 NeRF의 수학, 3D 가우시안이라는 표현 방식, 그리고 이 모든 걸 하나로 묶는 최적화 루프까지, "렌더링을 거꾸로 돌려 사진에서 장면을 복원한다"는 역그래픽스의 원리를 코드로 직접 검증하며 배우는 독립적인 입문서입니다. PyTorch 없이 NumPy만으로 순전파와 역전파를 손으로 구현하고, 마지막에는 PSNR·SSIM·지각 지표·FID를 직접 만들어 3DGS 결과를 평가합니다. 왜 미분해야 하는가(1부) → 볼륨 렌더링/NeRF(2부) → 3DGS 표현(3부) → 최적화로 학습(4부) → 품질 평가(5부) → 재구성 입력과 통합(6부) 순서로 쌓아 올립니다.

이 책의 모든 핵심 계산(자동미분, 알파 합성, 볼륨 렌더링, 3D 가우시안 투영, 래스터화, 역전파, 적응적 밀도 제어 등)은 이 책을 위해 새로 지은 예제이며, NumPy/SciPy로 실제 실행해 숫자로 검증했습니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
