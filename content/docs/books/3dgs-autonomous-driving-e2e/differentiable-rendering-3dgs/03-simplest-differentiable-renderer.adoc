'''

1~2장에서는 1차원 신호 하나만 다뤘습니다. 이 장에서는 진짜 **2차원 이미지**로, 그리고 파라미터가 하나가 아니라 **여러 개의 도형**(가우시안 얼룩 여러 개)으로 넘어갑니다 — 이게 3DGS가 실제로 하는 일의 축소판입니다.

== 여러 얼룩을 하나의 이미지로 합성하기

[source,python]
----
import numpy as np

H, W = 32, 32
yy, xx = np.mgrid[0:H, 0:W].astype(np.float64)

def render_blobs(positions, amplitudes, sigma=2.0):
    """N개의 등방 2D 가우시안 얼룩을 이미지 하나로 렌더링한다(단순 덧셈 합성).
    positions: (N,2) [row, col], amplitudes: (N,)"""
    img = np.zeros((H, W))
    for (py, px), amp in zip(positions, amplitudes):
        img += amp * np.exp(-0.5 * (((yy - py) ** 2 + (xx - px) ** 2) / sigma ** 2))
    return img
----

`32×32` 이미지에, 각각 위치(`py, px`)와 밝기(`amp`)를 가진 가우시안 얼룩 여러 개를 그냥 더해서 합성합니다(진짜 3DGS는 이 장의 "그냥 더하기" 대신 4~9장에서 다룰 알파 블렌딩을 쓰지만, 여러 원시 도형을 이미지로 합성한다는 구조 자체는 같습니다).

== 손으로 그래디언트를 유도하기 (벡터화된 버전)

2장의 `Value` 엔진은 스칼라 하나하나를 추적하느라 이미지처럼 숫자가 많은 계산에는 너무 느립니다. 대신 이 장에서는 NumPy 배열 연산으로 **한꺼번에** 그래디언트를 계산하는 벡터화된 연쇄법칙을 직접 유도합니다.

[source,python]
----
def loss_and_grad(positions, amplitudes, target, sigma=2.0):
    """손실과 (positions, amplitudes)에 대한 그래디언트를 함께 계산한다."""
    img = np.zeros((H, W))
    per_blob = []
    for (py, px), amp in zip(positions, amplitudes):
        g = np.exp(-0.5 * (((yy - py) ** 2 + (xx - px) ** 2) / sigma ** 2))
        per_blob.append(g)
        img += amp * g
    diff = img - target
    dL_dimg = 2 * diff  # L = sum(diff^2) 이므로 dL/dimg = 2*diff

    grad_positions = np.zeros_like(positions)
    grad_amplitudes = np.zeros_like(amplitudes)
    for i, ((py, px), amp) in enumerate(zip(positions, amplitudes)):
        g = per_blob[i]
        grad_amplitudes[i] = np.sum(dL_dimg * g)                    # d(amp*g)/d(amp) = g
        dg_dpy = g * (yy - py) / sigma ** 2                          # d(가우시안)/d(py)
        dg_dpx = g * (xx - px) / sigma ** 2
        grad_positions[i, 0] = np.sum(dL_dimg * amp * dg_dpy)
        grad_positions[i, 1] = np.sum(dL_dimg * amp * dg_dpx)
    return np.sum(diff ** 2), grad_positions, grad_amplitudes
----

각 얼룩의 그래디언트를 구하는 구조는 1장의 1D 버전과 정확히 같은 패턴입니다 — "이미지 전체에 대한 손실 그래디언트(`dL_dimg`)"에 "그 얼룩이 각 픽셀에 미치는 국소 미분"을 곱해서 합칩니다. 다른 점은 이제 그 계산이 이미지 전체(`32×32=1024`픽셀)에 대해 한꺼번에(`np.sum` 하나로) 이뤄진다는 것뿐입니다.

== 그래디언트 검증: 유한차분과 대조하기

[source,python]
----
eps = 1e-4
p_plus = init_positions.copy(); p_plus[0, 0] += eps
p_minus = init_positions.copy(); p_minus[0, 0] -= eps
l_plus, _, _ = loss_and_grad(p_plus, init_amplitudes, target)
l_minus, _, _ = loss_and_grad(p_minus, init_amplitudes, target)
grad_numeric = (l_plus - l_minus) / (2 * eps)
print(grad_pos[0, 0], grad_numeric)  # -1.2890537820536556  -1.2890537812459968
assert np.isclose(grad_pos[0, 0], grad_numeric, rtol=1e-3)
----

첫 번째 얼룩의 `y`좌표에 대한 그래디언트가 유한차분과 소수점 7자리까지 일치합니다. 진폭에 대한 그래디언트도 같은 방식으로 검증됩니다 — 벡터화된 계산이라고 해서 검증 원칙이 달라지지 않습니다.

== 진짜 최적화: 3개의 얼룩을 이미지 하나에서 복원하기

[source,python]
----
true_positions = np.array([[10.0, 8.0], [20.0, 22.0], [15.0, 18.0]])
true_amplitudes = np.array([1.0, 0.8, 1.2])
target = render_blobs(true_positions, true_amplitudes) + rng.normal(scale=0.01, size=(H, W))

positions = init_positions.copy()   # 진짜 위치에서 무작위로 흩뜨린 초기값
amplitudes = init_amplitudes.copy()
for step in range(300):
    loss, gp, ga = loss_and_grad(positions, amplitudes, target)
    positions = positions - 0.05 * gp
    amplitudes = amplitudes - 0.05 * ga
----

정답 이미지(얼룩 3개)를 만들어두고, 그 위치에서 무작위로 흩뜨려놓은 잘못된 초기 추정치에서 경사하강을 `300`번 반복합니다 — 정확히 이 책이 지향하는 "역그래픽스"입니다.

== 결과: 세 얼룩 모두 정확히 복원된다

[source,python]
----
print(losses[0], losses[-1])  # 15.78  0.100
assert losses[-1] < losses[0] * 0.01

for i, p in enumerate(positions):
    dists = np.linalg.norm(true_positions - p, axis=1)
    print(f"blob {i}: pos={p}, nearest true dist={dists.min():.4f}")
    assert dists.min() < 0.3
----

손실이 `15.78`에서 `0.10`으로(`1%` 미만으로) 줄어들었고, 최적화가 끝난 세 얼룩의 위치가 각각 진짜 위치에서 `0.02`픽셀 이내로 정확히 일치합니다 — 초기 위치가 진짜 위치와 최대 몇 픽셀씩 어긋나 있었는데도, 순전히 그래디언트만 따라가서 정확한 답을 찾아낸 것입니다.

이 결과가 왜 중요한지 짚어봅시다 — 우리는 "얼룩이 3개 있다"는 것 말고는 얼룩들의 정확한 위치나 밝기를 전혀 몰랐습니다. 오직 **최종 렌더링된 이미지 하나**(`target`)만 보고, 그 이미지를 만들어낸 파라미터들을 전부 되찾았습니다 — 이게 바로 3DGS가 사진 여러 장으로부터 수십만 개의 가우시안 파라미터를 학습하는 것과 정확히 같은 원리입니다. 다만 3DGS는 이미지가 여러 장이고, 가우시안이 3차원이며, 카메라 투영까지 거쳐야 한다는 점이 다를 뿐입니다.

== 요약

* 여러 개의 원시 도형(가우시안 얼룩)을 이미지로 합성하는 렌더러와, 그 파라미터(위치·밝기)에 대한 그래디언트를 벡터화된 NumPy 연산으로 직접 유도했습니다.
* 그래디언트를 유한차분으로 검증하는 습관이, 스칼라든 이미지든 규모와 상관없이 그대로 적용됩니다.
* 잘못된 초기 위치에서 시작해도, 순수하게 그래디언트만 따라가서 목표 이미지를 만들어낸 진짜 파라미터를 정확히 복원했습니다 — 역그래픽스가 실제로 작동하는 걸 눈으로 확인했습니다.
* 도형의 개수 자체가 부족하면 최적화만으로는 한계가 있다는 것도 함께 확인했습니다.

1부가 여기서 끝났습니다. 2부에서는 이 책이 "그냥 더하기"로 단순화했던 합성 방식을, 실제 3DGS와 NeRF가 쓰는 물리적으로 올바른 볼륨 렌더링으로 대체합니다.
