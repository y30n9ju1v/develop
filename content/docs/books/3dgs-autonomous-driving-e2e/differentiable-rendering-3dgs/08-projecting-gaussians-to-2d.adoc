'''

7장에서 3D 가우시안을 정의했습니다. 렌더링하려면 이걸 카메라가 찍은 2D 이미지 평면 위의 무언가로 바꿔야 합니다 — 이 장에서 다루는 **EWA 스플래팅(Elliptical Weighted Average splatting)**이 3D 가우시안을 화면 위의 2D 가우시안(타원)으로 바꾸는 방법입니다. "3D Gaussian **Splatting**"이라는 이름의 "스플래팅"이 바로 이것입니다.

== 문제: 원근 투영은 가우시안을 가우시안으로 보내지 않는다

1권에서 배운 원근 투영(`u = fx·x/z + cx`)은 `z`로 나누는 비선형 연산입니다. 가우시안 분포를 비선형 함수에 통과시키면, 일반적으로 결과는 더 이상 정확한 가우시안이 아닙니다. 하지만 3D 가우시안이 카메라로부터 충분히 멀리(그리고 그 자신이 충분히 작게) 있다면, 그 좁은 영역 안에서는 투영을 **직선(아핀) 근사**로 취급해도 거의 정확합니다 — 이게 EWA 스플래팅의 핵심 아이디어입니다.

== 국소 아핀 근사: 야코비안

[source,python]
----
import numpy as np

def projection_jacobian(K, X_cam):
    """원근 투영의 야코비안 (2x3): 픽셀 좌표를 카메라 좌표로 미분."""
    fx, fy = K[0, 0], K[1, 1]
    x, y, z = X_cam
    return np.array([
        [fx / z, 0.0,     -fx * x / z ** 2],
        [0.0,    fy / z,  -fy * y / z ** 2],
    ])
----

이건 그냥 원근 투영 공식을 `x, y, z`로 편미분한 것입니다(2장·6장에서 계속 해온 미분 작업이 여기서도 그대로입니다) — `du/dx = fx/z`처럼, 가우시안의 중심 근처에서 "카메라 좌표가 조금 바뀌면 픽셀이 얼마나 바뀌는가"를 나타내는 `2×3` 행렬입니다.

== 공분산을 3D에서 2D로 옮기기

가우시안 분포에 선형 변환 `y = A·x`를 적용하면, 공분산은 정확히 `A·Sigma·Aᵀ`로 변환된다는 게 확률론의 표준적인 사실입니다. 여기서는 이 변환을 두 단계로 나눕니다 — 먼저 카메라 좌표계로 회전(`R_cam`, 이동은 공분산에 영향을 주지 않습니다), 그다음 야코비안 `J`로 아핀 근사된 투영을 적용합니다.

[source,python]
----
def project_gaussian_ewa(mu_world, Sigma_world, R_cam, t_cam, K):
    """3D 가우시안을 2D로 투영한다 (EWA 스플래팅: 국소 아핀 근사)."""
    mu_cam = R_cam @ mu_world + t_cam
    Sigma_cam = R_cam @ Sigma_world @ R_cam.T
    J = projection_jacobian(K, mu_cam)
    mu_2d = project_point(K, mu_cam)
    Sigma_2d = J @ Sigma_cam @ J.T
    return mu_2d, Sigma_2d
----

`Sigma_2d = J·(R_cam·Sigma_world·R_camᵀ)·Jᵀ`가 3D 가우시안 하나를 2D 타원(공분산 `2×2`)으로 바꾸는 전체 공식입니다. 결과 `Sigma_2d`는 항상 `2×2` 대칭 양의 정부호 행렬이라는 걸 확인할 수 있습니다 — 7장에서 다진 원리(SPD를 보존하는 방식으로 구성한다)가 이번에도 성립합니다.

== 검증: 실제(비선형) 투영과 비교하기

이 근사가 정말 맞는지 확인하는 가장 확실한 방법은, 근사를 전혀 쓰지 않고 **진짜 3D 가우시안에서 표본을 아주 많이 뽑아, 하나하나 진짜(비선형) 원근 투영으로 옮긴 뒤, 그 결과의 통계(평균과 공분산)를 직접 재는 것**입니다.

[source,python]
----
def monte_carlo_projection(mu_world, Sigma_world, R_cam, t_cam, K, n_samples, rng):
    samples_world = rng.multivariate_normal(mu_world, Sigma_world, size=n_samples)
    samples_cam = (R_cam @ samples_world.T).T + t_cam
    pixels = np.array([project_point(K, x) for x in samples_cam])
    return pixels.mean(axis=0), np.cov(pixels.T)

mu_world = np.array([0.3, 0.1, 4.0])
scale = np.array([0.05, 0.03, 0.04])  # 카메라와의 거리(4m)에 비해 아주 작은 가우시안
Sigma_world = covariance_from_scale_rotation(scale, R_g)

mu_2d, Sigma_2d = project_gaussian_ewa(mu_world, Sigma_world, R_cam, t_cam, K)
mc_mean, mc_cov = monte_carlo_projection(mu_world, Sigma_world, R_cam, t_cam, K, 200_000, rng)
----

== 근사가 무너지는 지점 확인하기

이 아핀 근사는 "가우시안이 카메라로부터의 거리에 비해 충분히 작다"는 전제에서만 정확합니다. 가우시안을 카메라와의 거리(`4m`)에 필적할 만큼 크게 만들어서 같은 비교를 해봅니다.

[source,python]
----
scale_big = np.array([1.5, 1.0, 1.2])  # 이번엔 카메라 거리(4m)에 필적하는 크기
Sigma_world_big = covariance_from_scale_rotation(scale_big, R_g)
mu_2d_big, Sigma_2d_big = project_gaussian_ewa(mu_world, Sigma_world_big, R_cam, t_cam, K)
mc_mean_big, mc_cov_big = monte_carlo_projection(mu_world, Sigma_world_big, R_cam, t_cam, K, 200_000, rng)

rel_err_small = np.linalg.norm(Sigma_2d - mc_cov) / np.linalg.norm(mc_cov)
rel_err_big = np.linalg.norm(Sigma_2d_big - mc_cov_big) / np.linalg.norm(mc_cov_big)
print(rel_err_small, rel_err_big)  # 0.0038  0.977
assert rel_err_big > rel_err_small
----

작은 가우시안의 상대 오차는 `0.4%`에 불과하지만, 큰 가우시안은 `98%`에 달합니다 — 근사가 사실상 완전히 무너졌습니다. 이유는 명확합니다 — 큰 가우시안은 `z`(카메라로부터의 거리) 자체도 넓은 범위에 걸쳐 퍼져 있는데, 야코비안은 딱 중심 `mu_cam` **한 점**에서의 순간적인 변화율만 재기 때문에, 가우시안의 "먼 쪽 끝"과 "가까운 쪽 끝"에서 실제 원근 투영이 얼마나 다르게 작동하는지를 전혀 반영하지 못합니다.

== 왜 이게 3DGS 최적화에서 중요한가

이 결과가 실전에 주는 교훈은 명확합니다 — **3DGS의 가우시안들은 작아야 이 근사가 정확하다는 전제 위에서 작동합니다.** 실제 3DGS 학습은 이 사실을 적극적으로 활용합니다 — 처음에는 크고 성긴 가우시안 몇 개로 대략적인 형태를 잡고, 학습이 진행되면서 큰 가우시안을 작은 가우시안 여러 개로 쪼개는 절차(12장의 적응적 밀도 제어)를 통해, 최종적으로는 이 장에서 검증한 "작은 가우시안" 조건을 만족하는 상태로 수렴하도록 유도합니다.

== 직접 해보기

똑같이 "물리적으로 큰" 가우시안인데도, `z=4`에서는 오차가 `98%`(완전히 깨짐)였다가 `z=40`으로 옮기기만 해도 오차가 `1%` 미만으로 돌아옵니다 — 근사가 성립하는 기준은 가우시안의 절대적인 크기가 아니라, **카메라와의 거리 대비 상대적인 크기**(대략 `scale/z`의 비율)라는 걸 명확하게 보여줍니다. 카메라에 아주 가까이 있는 큰 물체(예: 자율주행차 바로 앞의 벽)를 3DGS로 재구성할 때 특히 이 근사의 한계를 조심해야 하는 이유입니다.

== 요약

* EWA 스플래팅은 3D 가우시안을 카메라 투영의 야코비안으로 국소 아핀 근사해서, 2D 화면 위의 타원(2×2 공분산)으로 바꿉니다.
* `Sigma_2d = J·R_cam·Sigma_world·R_camᵀ·Jᵀ`가 이 변환의 전체 공식입니다.
* 이 근사를 몬테카를로 시뮬레이션(진짜 표본을 진짜 비선형 투영으로 옮긴 통계)과 비교해서, 작은 가우시안에서는 오차가 1% 미만이지만 카메라 거리에 필적하는 큰 가우시안에서는 근사가 완전히 무너진다는 걸 직접 확인했습니다.
* 이 사실이 실전 3DGS가 큰 가우시안을 계속 작은 가우시안들로 쪼개나가는 이유의 근거입니다.

다음 장에서는 이렇게 2D로 투영된 여러 가우시안들을, 4장에서 배운 알파 합성으로 실제 픽셀 색으로 합성하는 전체 래스터화 과정을 다룹니다.
