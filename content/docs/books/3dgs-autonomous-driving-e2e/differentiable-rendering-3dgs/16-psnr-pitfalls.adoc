'''

15장에서 PSNR이 노이즈 강도에 따라 예측 가능하게 변한다는 걸 확인했습니다. 이 장에서는 PSNR이 **같은 숫자**를 내놓는 두 가지 전혀 다른 손상 — **흐림(blur)**과 **노이즈(noise)** — 을 직접 만들어, 이 둘이 실제로 얼마나 다른지 정량적으로 확인합니다.

== 사각형 이미지 만들기

밝은 사각형이 어두운 배경 위에 놓인, 조금 더 "사진 같은" 합성 이미지를 만듭니다.

[source,python]
----
import numpy as np
from scipy.ndimage import gaussian_filter

N = 32
img = np.zeros((N, N))
img[N // 4:3 * N // 4, N // 4:3 * N // 4] = 1.0   # 가운데 밝은 사각형
----

== 손상 1: 흐리게 만들기(Gaussian blur)

`scipy.ndimage.gaussian_filter`로 이미지를 부드럽게 흐립니다 — 사각형의 날카로운 경계가 뭉개집니다.

[source,python]
----
blurred = gaussian_filter(img, sigma=1.2)

def mse(a, b):
    return np.mean((a - b) ** 2)

def psnr(a, b, max_val=1.0):
    m = mse(a, b)
    return float('inf') if m == 0 else 10 * np.log10((max_val ** 2) / m)

print("흐림 MSE:", mse(img, blurred), "PSNR:", psnr(img, blurred))
----

[source]
----
흐림 MSE: 0.01528 PSNR: 18.16 dB
----

== 손상 2: 흐림과 같은 MSE를 갖는 노이즈 만들기

흐림이 만든 MSE와 **정확히 같은 크기**의 무작위 가우시안 노이즈를 원본에 더합니다.

[source,python]
----
rng = np.random.default_rng(1)
target_mse = mse(img, blurred)
std = np.sqrt(target_mse)
noisy = img + rng.normal(0, std, img.shape)

print("노이즈 MSE:", mse(img, noisy), "PSNR:", psnr(img, noisy))
----

[source]
----
노이즈 MSE: 0.01507 PSNR: 18.22 dB
----

흐림(`18.16dB`)과 노이즈(`18.22dB`)의 PSNR이 거의 같습니다. PSNR만 보고 판단한다면 "이 두 손상은 비슷한 수준의 품질 저하"라고 결론 내릴 것입니다.

== 정말 비슷한 손상인가: 기울기(edge) 에너지로 확인하기

두 손상이 실제로 이미지에 무슨 짓을 했는지 보려면, "이미지 안에 얼마나 날카로운 경계(edge)가 남아 있는가"를 재보면 됩니다 — 흐림은 경계를 뭉개서 없애는 방향으로, 노이즈는 이미지 전체에 무작위로 잔물결 같은 가짜 경계를 흩뿌리는 방향으로 작용하기 때문에, 이 둘은 정반대 방향으로 "에너지"를 바꿉니다. `np.gradient`로 인접 픽셀 간의 변화량(기울기)을 구하고, 그 제곱의 평균을 "기울기 에너지"로 정의합니다.

[source,python]
----
def gradient_energy(a):
    gy, gx = np.gradient(a)
    return np.mean(gx ** 2 + gy ** 2)

print("원본 기울기 에너지:", gradient_energy(img))
print("흐린 이미지 기울기 에너지:", gradient_energy(blurred))
print("노이즈 이미지 기울기 에너지:", gradient_energy(noisy))
----

[source]
----
원본 기울기 에너지: 0.03125
흐린 이미지 기울기 에너지: 0.01241
노이즈 이미지 기울기 에너지: 0.05065
----

정반대 방향으로 움직였습니다. 흐린 이미지는 기울기 에너지가 원본(`0.03125`)보다 **줄어들어**(`0.01241`) 사각형의 날카로운 경계가 뭉개졌다는 걸 보여주고, 노이즈 이미지는 기울기 에너지가 원본보다 **오히려 늘어나서**(`0.05065`) 이미지 전체에 잔물결 같은 가짜 디테일이 흩뿌려졌다는 걸 보여줍니다. PSNR은 두 이미지에게 거의 같은 점수(`18`dB대)를 줬지만, "무엇이 사라졌고 무엇이 추가됐는가"라는 질문에는 완전히 반대되는 답이 나온 것입니다.

== 왜 이게 실무에서 중요한가

렌더링이나 압축, 생성 모델의 결과물을 평가할 때, 흐림과 노이즈는 원인도 다르고 대응 방법도 다릅니다 — 흐림은 보통 "정보가 부족하다"(해상도가 낮거나, 모델이 디테일을 학습하지 못함)는 신호이고, 노이즈는 "정보가 불안정하다"(학습이 덜 수렴했거나, 렌더링 알고리즘 자체가 확률적이라 매번 다른 잡음이 낌)는 신호일 수 있습니다. PSNR 숫자 하나만 보고 "품질이 같다"고 판단하면, 실제로는 전혀 다른 원인에서 나온 문제를 놓치게 됩니다. 3D Gaussian Splatting 렌더링 품질을 검증할 때도 마찬가지입니다 — 학습이 부족해 뭉개진 흐릿한 렌더링과, 가우시안 개수가 과도해 지글거리는 렌더링은 원인이 전혀 다른데, PSNR만 보면 둘 다 "그저 그런 점수"로 뭉뚱그려질 수 있습니다.

== 직접 해보기

* 흐림의 강도(`sigma`)를 `1.2`에서 `2.5`로 늘려 PSNR이 어떻게 달라지는지, 그리고 그때의 기울기 에너지가 원본 대비 얼마나 더 줄어드는지 확인해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
blurred_strong = gaussian_filter(img, sigma=2.5)
print("강한 흐림 PSNR:", psnr(img, blurred_strong))
print("강한 흐림 기울기 에너지:", gradient_energy(blurred_strong))
----

[source]
----
강한 흐림 PSNR: 14.49 dB
강한 흐림 기울기 에너지: 0.00570
----

흐림이 강해질수록 PSNR은 더 떨어지고(`18.16 → 14.49`), 기울기 에너지도 더 줄어듭니다(`0.01241 → 0.00570`, 원본의 `0.03125`에 비하면 `5`분의 `1` 수준). PSNR과 기울기 에너지가 이번엔 같은 방향(둘 다 "더 나빠짐")으로 움직였다는 점도 흥미롭습니다 — 흐림은 강해질수록 PSNR도 나빠지고 구조도 더 파괴되니 두 지표가 일관되지만, 애초에 문제는 "흐림과 노이즈처럼 서로 다른 종류의 손상을 PSNR 하나로 비교할 때" 생긴다는 걸 기억해두세요.
====

== 요약

* 흐림과, 흐림과 같은 MSE를 갖도록 만든 노이즈는 PSNR 값이 거의 같지만(`18`dB대), 실제로는 정반대의 변화(경계가 사라짐 vs 가짜 경계가 생김)를 일으킵니다.
* 기울기(edge) 에너지처럼 "이미지 안의 구조가 얼마나 남아 있는가"를 재는 보조 지표로, PSNR 숫자 하나로는 보이지 않는 손상의 성격 차이를 드러낼 수 있습니다.
* PSNR은 원인이 다른 품질 저하(부족한 디테일 vs 불안정한 노이즈)를 구별하지 못하므로, 실무에서 PSNR 하나만으로 렌더링/생성 품질을 판단하면 실제 문제를 놓칠 수 있습니다.
* 다음 장에서는 PSNR/MSE와 다른 각도로 접근하는 지표, 밝기·대비·구조를 따로 떼어 비교하는 SSIM(구조적 유사도)을 다룹니다.
