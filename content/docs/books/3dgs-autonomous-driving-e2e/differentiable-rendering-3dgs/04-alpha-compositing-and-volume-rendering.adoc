'''

3장에서는 여러 얼룩을 그냥 더해서 이미지를 합성했습니다. 이 방식에는 심각한 문제가 있습니다 — **가려짐(occlusion)을 전혀 표현하지 못합니다.** 이 장에서는 그 문제를 실제로 확인하고, NeRF와 3DGS가 공통으로 쓰는 올바른 해법인 **알파 합성(alpha compositing)**을 구현합니다.

== 단순 합산이 실패하는 지점

빨간 물체가 파란 물체 바로 앞을 완전히 가리고 있는 상황을 생각해봅시다 — 카메라에는 빨간색만 보여야 합니다.

[source,python]
----
import numpy as np

colors = np.array([[1.0, 0.0, 0.0],   # 빨강, 앞
                    [0.0, 0.0, 1.0]])  # 파랑, 뒤
alphas_opaque_front = np.array([1.0, 1.0])  # 앞이 완전 불투명

def composite_naive_sum(colors, alphas):
    return np.sum(colors * alphas[:, None], axis=0)

print(composite_naive_sum(colors, alphas_opaque_front))  # [1. 0. 1.] -- 자주색!?
assert np.allclose(composite_naive_sum(colors, alphas_opaque_front), [1.0, 0.0, 1.0])
----

3장의 방식대로 그냥 더하면 `[1, 0, 1]`(자주색)이 나옵니다 — 완전히 불투명한 빨간 물체 뒤에 파란 물체가 있는데도, 그 파란빛이 마치 유령처럼 그대로 비쳐 보이는 것입니다. 실제 세계에서는 절대 일어나지 않는 일입니다.

== 알파 합성: 투과율을 앞에서부터 곱해나가기

올바른 방법은, 각 지점에서 "여기까지 빛이 도달할 확률"(**투과율, transmittance**)을 계속 추적하는 것입니다 — 앞쪽에 불투명한 것이 있었다면, 그 뒤에 도달하는 빛은 그만큼 줄어들어야 합니다.

[source,python]
----
def composite_alpha_blend(colors, alphas):
    """앞에서 뒤로(front-to-back) 알파 합성. transmittance T_i = 그 지점까지 도달할 확률."""
    n = len(alphas)
    T = 1.0
    C = np.zeros(colors.shape[1])
    Ts = []
    for i in range(n):
        Ts.append(T)
        C += T * alphas[i] * colors[i]
        T *= (1 - alphas[i])
    return C, np.array(Ts)
----

`T`(투과율)는 `1`(아무것도 안 가린 상태)에서 시작해서, 각 지점을 지날 때마다 `(1 - alpha_i)`만큼 줄어듭니다 — `alpha_i`가 `1`(완전 불투명)이면 그 뒤로는 `T=0`이 되어, 그 뒤에 무엇이 있든 전혀 보이지 않게 됩니다. 각 지점이 최종 색에 기여하는 몫은 `T_i · alpha_i · color_i` — "여기까지 도달한 빛의 양"과 "여기서 실제로 반사되는 비율"을 곱한 것입니다.

[source,python]
----
C_blend, Ts = composite_alpha_blend(colors, alphas_opaque_front)
print(C_blend)  # [1. 0. 0.]
assert np.allclose(C_blend, [1.0, 0.0, 0.0])
----

이번엔 정확히 순수한 빨강만 나옵니다 — 앞의 완전히 불투명한 물체가 뒤를 100% 가려서, 파란빛은 최종 결과에 전혀 기여하지 못합니다.

== 순서가 결과를 바꾼다

[source,python]
----
colors_reversed = colors[::-1].copy()  # 파랑을 앞으로, 빨강을 뒤로
C_blend_rev, _ = composite_alpha_blend(colors_reversed, alphas_opaque_front)
print(C_blend_rev)  # [0. 0. 1.]
assert not np.allclose(C_blend, C_blend_rev)
----

같은 두 물체라도 앞뒤 순서를 바꾸면 완전히 다른 결과가 나옵니다 — 이번엔 파랑이 앞이니 파랑만 보입니다. 3장의 단순 합산에서는 순서가 결과에 전혀 영향을 주지 않았다는 걸 떠올려보면(그냥 다 더하는 거니까요), 이 "순서에 대한 민감성"이야말로 알파 합성이 실제 물리 법칙(가려짐)을 포착하고 있다는 증거입니다. 3DGS에서 가우시안들을 카메라로부터의 깊이 순으로 정렬해서 처리하는 이유가 바로 이것입니다.

== 반투명한 경우: 뒤쪽도 일부 비쳐 보인다

[source,python]
----
alphas_semi = np.array([0.5, 1.0])  # 앞이 반투명(50%), 뒤는 불투명
C_semi, Ts_semi = composite_alpha_blend(colors, alphas_semi)
print(C_semi, Ts_semi)  # [0.5 0.  0.5]  [1.  0.5]
assert np.allclose(Ts_semi, [1.0, 0.5])
assert np.allclose(C_semi, [0.5, 0.0, 0.5])
----

앞쪽 빨간 물체가 반투명(`alpha=0.5`)이면, 뒤쪽 파란 물체의 빛 중 절반(`T_1 = 1 - 0.5 = 0.5`)이 뚫고 나옵니다 — 최종 색은 빨강과 파랑이 정확히 절반씩 섞인 `[0.5, 0, 0.5]`입니다. 유리창 너머로 물체가 반쯤 비쳐 보이는 것과 정확히 같은 원리이고, 이게 3DGS가 반투명한 가우시안들을 자연스럽게 겹쳐 렌더링할 수 있는 이유입니다.

== 그래디언트 유도하기: 곱셈이 섞여 있어 더 까다롭다

3장에서는 각 얼룩이 독립적으로 더해졌기 때문에 그래디언트도 서로 독립적이었습니다. 알파 합성은 다릅니다 — `alpha_i`가 자기 자신의 항(`T_i · alpha_i · c_i`)뿐 아니라, **자기보다 뒤에 있는 모든 지점의 투과율에도 곱셈으로 들어갑니다**(`T_j = ∏_{k<j}(1-alpha_k)`이니, `alpha_i`가 `i<j`인 모든 `T_j`에 관여합니다). 그래서 `alpha_i`를 조금 바꾸면, 자기 자신의 기여뿐 아니라 자기 뒤에 있는 모든 지점의 기여까지 함께 바뀝니다.

[source,python]
----
def grad_alpha_i(alphas, colors, target, i):
    n = len(alphas)
    C, Ts = composite_alpha_blend(colors, alphas)
    dC_dalpha_i = Ts[i] * colors[i]  # 1) 자기 자신의 항
    for j in range(i + 1, n):        # 2) 자기보다 뒤에 있는 항들의 투과율에 미치는 영향
        dTj_dalpha_i = -Ts[j] / (1 - alphas[i])
        dC_dalpha_i = dC_dalpha_i + dTj_dalpha_i * alphas[j] * colors[j]
    dL_dC = 2 * (C - target)
    return np.dot(dL_dC, dC_dalpha_i)
----

== 유한차분으로 검증하기

[source,python]
----
target = np.array([0.6, 0.0, 0.4])
alphas_test = np.array([0.3, 0.7])
grad_analytic = grad_alpha_i(alphas_test, colors, target, 0)

eps = 1e-6
grad_numeric = (loss_fn(alphas_test + [eps,0], colors, target)
                 - loss_fn(alphas_test - [eps,0], colors, target)) / (2 * eps)
print(grad_analytic, grad_numeric)  # -0.726  -0.726
assert np.isclose(grad_analytic, grad_numeric, atol=1e-4)
----

두 갈래(자기 자신의 직접 기여 + 뒤쪽 항들의 투과율을 통한 간접 기여)를 모두 반영한 그래디언트가 유한차분과 정확히 일치합니다. 이 "간접 기여"가 있다는 게 알파 합성 최적화의 흥미로운 특징입니다 — **앞쪽 가우시안의 불투명도를 조정하면, 카메라에서 직접 보이지도 않는 훨씬 뒤쪽 가우시안들의 그래디언트에까지 영향을 줍니다.** 9장에서 3D 가우시안 전체를 최적화할 때 이 성질이 실전에서 어떻게 나타나는지 다시 확인합니다.

== 요약

* 단순 덧셈 합성은 가려짐을 표현하지 못해 물리적으로 불가능한 결과(뒤가 앞을 뚫고 비쳐 보임)를 만듭니다.
* 알파 합성은 각 지점의 투과율(앞쪽의 불투명도들이 누적된 곱)을 추적해서, 가려짐과 반투명을 모두 올바르게 표현합니다.
* 알파 합성에서는 순서가 결과를 바꾸고, 이게 실제 물리 법칙을 반영하고 있다는 신호입니다.
* 알파 값의 그래디언트는 자기 자신의 직접 기여와, 자기 뒤에 있는 모든 지점에 미치는 간접 기여를 모두 포함하는 비선형 계산이지만, 여전히 정확히 유도하고 검증할 수 있습니다.

다음 장에서는 이 알파 합성을 "여러 개의 얼룩"이 아니라 "카메라에서 뻗어나가는 광선을 따라 연속적으로 샘플링한 지점들"에 적용해서, 볼륨 렌더링의 완전한 그림을 완성합니다.
