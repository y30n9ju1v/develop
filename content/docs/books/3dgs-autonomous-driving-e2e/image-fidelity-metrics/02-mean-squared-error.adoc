1장에서 이미지가 숫자 배열이라는 걸 확인했으니, "두 이미지가 닮았는가"는 결국 "두 숫자 배열이 닮았는가"라는 질문이 됩니다. 가장 먼저 떠오르는 답은 "같은 위치의 픽셀끼리 값을 빼서 그 차이를 재면 된다"는 것입니다 — 이게 **평균제곱오차(Mean Squared Error, MSE)**입니다.

== MSE 계산하기

두 이미지의 같은 위치 픽셀값을 빼고, 제곱하고, 전체 평균을 냅니다.

[source,python]
----
import numpy as np

def mse(a, b):
    return np.mean((a - b) ** 2)
----

제곱을 하는 이유는 두 가지입니다 — 차이가 음수든 양수든 "차이의 크기"만 중요하므로 부호를 없애고 싶고(그냥 절댓값을 써도 되지만, 제곱은 큰 차이에 더 큰 벌점을 주는 효과도 있습니다), 수학적으로 다루기 쉬운 성질(미분 가능함 등)을 갖기 때문입니다.

[source,python]
----
img = np.array([[0.2, 0.5], [0.8, 0.1]])
same = img.copy()
print(mse(img, same))          # 완전히 같은 이미지

different = np.array([[0.3, 0.5], [0.8, 0.1]])
print(mse(img, different))     # 픽셀 하나만 0.1만큼 다름
----

[source]
----
0.0
0.0025
----

완전히 같은 이미지는 MSE가 `0`이고, 픽셀 하나가 `0.1`만큼 다르면 그 차이의 제곱(`0.01`)을 전체 픽셀 수(`4`)로 나눈 `0.0025`가 나옵니다.

== 실험: 눈에 거의 안 보이는 변화 vs 완전히 다르게 보이는 변화

MSE가 "닮음"을 얼마나 잘 재는지 확인하기 위해, 세로 줄무늬 패턴 이미지를 만들고 두 가지 방식으로 "망가뜨려" 봅니다.

[source,python]
----
N = 20
x = np.arange(N)
stripe = (np.sin(x * np.pi / 2) > 0).astype(np.float64)   # 0과 1이 번갈아 나오는 줄무늬
img = np.tile(stripe, (N, 1))                               # NxN 크기로 반복
----

=== 망가뜨리기 1: 옆으로 1픽셀 밀기

[source,python]
----
shifted = np.roll(img, 1, axis=1)
m_shift = mse(img, shifted)
print("1픽셀 이동 MSE:", m_shift)
----

[source]
----
1픽셀 이동 MSE: 0.5
----

줄무늬 전체를 옆으로 `1`칸 밀었을 뿐인데 MSE가 `0.5`나 나왔습니다 — 줄무늬 패턴 특성상 `1`칸만 밀어도 거의 모든 픽셀이 반대 값(`0↔1`)으로 바뀌기 때문입니다. 그런데 사람이 이 두 이미지를 나란히 놓고 보면, "같은 줄무늬 패턴이 살짝 옆으로 밀렸다"는 걸 한눈에 알아보고 여전히 "거의 같은 이미지"라고 느낄 가능성이 높습니다.

=== 망가뜨리기 2: 무작위로 픽셀을 뒤집기

[source,python]
----
rng = np.random.default_rng(0)
flip_mask = rng.random(img.shape) < m_shift   # 1픽셀 이동과 같은 확률(0.5)로 무작위 픽셀을 뒤집는다
noisy = np.where(flip_mask, 1 - img, img)
m_noise = mse(img, noisy)
print("무작위 노이즈 MSE:", m_noise)
----

[source]
----
무작위 노이즈 MSE: 0.4575
----

이번엔 각 픽셀을 독립적으로 `50%`(정확히는 방금 계산한 `m_shift`) 확률로 뒤집었습니다. 결과 MSE(`0.4575`)가 방금 전 "`1`픽셀 이동"의 MSE(`0.5`)와 거의 같습니다.

== 같은 숫자, 완전히 다른 모습

두 "망가뜨리기"의 MSE가 거의 같다는 게 이 장의 핵심입니다. 하지만 그 결과물은 전혀 다릅니다 — `1`픽셀 이동은 원래의 규칙적인 줄무늬 패턴을 그대로 유지한 채 위치만 살짝 옮겨간 것이고, 무작위 뒤집기는 원래 패턴이 알아볼 수 없는 소금-후추 잡음(salt-and-pepper noise)처럼 지글거리는 이미지로 바뀐 것입니다. 사람이 본다면 전자는 "거의 같다", 후자는 "완전히 다른(망가진) 이미지"라고 판단할 가능성이 매우 높은데, MSE라는 숫자 하나는 이 둘을 거의 구별하지 못했습니다.

== 왜 이런 일이 생기는가: MSE는 "위치"를 모른다

MSE는 각 픽셀의 차이를 독립적으로 계산해서 그냥 평균 낼 뿐, 그 차이들이 **어떤 패턴으로 배치되어 있는지**는 전혀 보지 않습니다 — 모든 오차가 한곳에 몰려 있든(구조를 보존한 채 이동), 이미지 전체에 흩뿌려져 있든(무작위 노이즈), MSE에게는 "평균적으로 이 정도 차이가 난다"는 사실만 중요합니다. 사람의 눈은 정반대입니다 — 규칙적인 구조가 유지되는지, 노이즈가 흩어져 있는지에 훨씬 민감하게 반응합니다. 이 간극이 이 책 전체를 관통하는 문제입니다 — 6장의 SSIM은 정확히 "구조"를 보려는 시도이고, 8~9장의 지각적 지표는 아예 사람의 시각 시스템을 흉내 내려는 시도입니다.

== 직접 해보기

* 같은 줄무늬 이미지를 `1`픽셀이 아니라 `2`픽셀, `4`픽셀(줄무늬 한 주기 전체)만큼 밀어보고, `4`픽셀만큼 밀면 MSE가 어떻게 되는지 확인해보세요. (힌트: 줄무늬의 주기가 `4`픽셀이라는 걸 기억하세요.)

.해답 보기
[%collapsible]
====
[source,python]
----
for shift in [1, 2, 3, 4]:
    shifted_k = np.roll(img, shift, axis=1)
    print(f"{shift}픽셀 이동 MSE:", mse(img, shifted_k))
----

[source]
----
1픽셀 이동 MSE: 0.5
2픽셀 이동 MSE: 1.0
3픽셀 이동 MSE: 0.5
4픽셀 이동 MSE: 0.0
----

`4`픽셀(줄무늬 정확히 한 주기)만큼 밀면 패턴이 원래 자리로 완전히 되돌아오므로 MSE가 다시 `0`이 됩니다 — 육안으로도 "전혀 다르지 않다"고 느낄 상황과 정확히 일치합니다. 반면 `2`픽셀만큼 밀면 모든 픽셀이 정반대 값으로 뒤집혀 MSE가 최댓값(`1.0`, `0`과 `1`만 있는 이미지에서 나올 수 있는 가장 큰 값)을 찍습니다 — 이것도 "완전히 반전된 줄무늬"라는, 원본과 여전히 뚜렷한 관계가 있는 이미지인데 MSE는 "최악의 차이"라고 평가합니다. MSE가 픽셀의 절대적 위치에 얼마나 민감한지를 잘 보여주는 예시입니다.
====

== 요약

* MSE는 같은 위치의 픽셀값 차이를 제곱해서 평균 낸 값으로, 계산이 간단하고 완전히 같은 이미지에서만 정확히 `0`이 됩니다.
* MSE는 오차가 이미지 안에서 어떻게 배치되어 있는지(규칙적인 이동인지, 무작위 노이즈인지)를 구분하지 못하며, 사람 눈에는 전혀 다르게 보이는 두 가지 손상이 거의 같은 MSE 값을 낼 수 있습니다.
* 이 한계는 MSE의 계산 방식 자체(픽셀별 차이를 독립적으로 다루고 평균만 낸다)에서 나오는 근본적인 성질입니다.
* 다음 장에서는 MSE를 사람이 더 읽기 편한 척도(데시벨)로 바꾼 PSNR을 다루고, PSNR도 결국 MSE와 같은 한계를 그대로 물려받는다는 것을 확인합니다.
