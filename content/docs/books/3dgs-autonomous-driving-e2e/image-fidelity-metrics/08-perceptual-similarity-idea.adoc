'''

7장에서 SSIM조차 `1`픽셀 미만의 미세한 이동에 취약하다는 걸 확인했습니다. MSE, PSNR, SSIM의 공통점은 모두 **같은 좌표의 픽셀끼리** 비교한다는 것입니다. 이 장에서는 다른 전략 — "픽셀 값 자체가 아니라, 그 픽셀들이 만들어내는 **특징(feature)**을 비교하자" — 을 아주 단순한 예로 먼저 맛봅니다.

== 특징이란 무엇인가: 가장자리(edge)의 방향

가장 단순한 특징 하나를 만들어봅니다 — 이미지 전체에서 "가장자리(밝기가 급격히 바뀌는 부분)가 어느 방향으로 나 있는지"를 히스토그램으로 요약합니다.

[source,python]
----
import numpy as np
from scipy.ndimage import sobel

def edge_orientation_histogram(a, bins=8):
    gx = sobel(a, axis=1)          # 가로 방향 밝기 변화율
    gy = sobel(a, axis=0)          # 세로 방향 밝기 변화율
    magnitude = np.sqrt(gx ** 2 + gy ** 2)   # 가장자리의 "세기"
    angle = np.arctan2(gy, gx)               # 가장자리의 "방향"

    hist, _ = np.histogram(angle, bins=bins, range=(-np.pi, np.pi), weights=magnitude)
    return hist / (hist.sum() + 1e-8)   # 전체 세기로 정규화
----

`sobel`은 인접 픽셀 간의 밝기 변화율(기울기)을 구하는 표준적인 필터입니다. 이 값들로 "가장자리가 얼마나 강한지"(`magnitude`)와 "어느 방향으로 나 있는지"(`angle`)를 구하고, 방향별로 세기를 모아 히스토그램 하나로 요약합니다 — 이제 이미지 전체가 숫자 `8`개(`bins=8`)로 압축됐습니다.

== 실험: 이 특징은 위치 이동에 얼마나 둔감한가

7장의 부드러운 사각형 이미지를 다시 가져와, 픽셀 단위 비교(MSE)와 특징 단위 비교(히스토그램 거리)를 나란히 비교합니다.

[source,python]
----
from scipy.ndimage import gaussian_filter, shift

def mse(a, b):
    return np.mean((a - b) ** 2)

def feature_distance(a, b):
    fa, fb = edge_orientation_histogram(a), edge_orientation_histogram(b)
    return np.linalg.norm(fa - fb)

N = 48
img = np.zeros((N, N))
img[N // 4:3 * N // 4, N // 4:3 * N // 4] = 1.0
img = gaussian_filter(img, sigma=1.0)

shifted1 = shift(img, shift=[0, 1], order=1, mode='nearest')
shifted5 = shift(img, shift=[0, 5], order=1, mode='nearest')

print("1픽셀 이동: 픽셀 MSE =", mse(img, shifted1), ", 특징 거리 =", feature_distance(img, shifted1))
print("5픽셀 이동: 픽셀 MSE =", mse(img, shifted5), ", 특징 거리 =", feature_distance(img, shifted5))
----

[source]
----
1픽셀 이동: 픽셀 MSE = 0.005613 , 특징 거리 = 0.0
5픽셀 이동: 픽셀 MSE = 0.077991 , 특징 거리 = 0.0
----

픽셀 MSE는 이동 폭이 커질수록 계속 나빠지는데(`0.0056 → 0.0780`), 특징 거리는 `1`픽셀이든 `5`픽셀이든 정확히 `0`으로 그대로입니다. 왜 그럴까요? 사각형을 옆으로 밀어도 "가장자리가 어느 방향을 향하는가"라는 성질 자체는 전혀 바뀌지 않기 때문입니다(위·아래·왼쪽·오른쪽 가장자리가 있다는 사실은 위치와 무관합니다) — 이 특징은 "어디에 있는가"라는 정보를 아예 버리고 "무엇이 있는가"만 남긴 것입니다.

== 그럼 진짜 모양이 다른 건 구별할 수 있는가

이 특징이 그냥 "아무것도 구별 못 하는" 무딘 지표라면 쓸모가 없습니다. 완전히 다른 모양(가늘고 긴 직사각형)과 비교해봅니다.

[source,python]
----
img_different_shape = np.zeros((N, N))
img_different_shape[5:20, 5:40] = 1.0
img_different_shape = gaussian_filter(img_different_shape, sigma=1.0)

print("다른 모양: 픽셀 MSE =", mse(img, img_different_shape),
      ", 특징 거리 =", feature_distance(img, img_different_shape))
----

[source]
----
다른 모양: 픽셀 MSE = 0.266274 , 특징 거리 = 0.208546
----

이번엔 특징 거리가 `0.209`로 뚜렷하게 커졌습니다 — 정사각형과 가늘고 긴 직사각형은 가장자리의 방향 분포 자체가 다르기 때문입니다(정사각형은 네 방향이 고르게, 가늘고 긴 직사각형은 가로 방향 가장자리가 상대적으로 더 많이 나타납니다). 이 특징은 위치 이동에는 완전히 무감각하면서도, 진짜 모양 차이는 여전히 잡아냅니다.

== 이게 LPIPS의 핵심 아이디어다

방금 만든 "가장자리 방향 히스토그램"은 매우 단순하고 손으로 설계한 특징이지만, 그 뒤에 있는 아이디어는 **LPIPS(Learned Perceptual Image Patch Similarity)** 같은 지각적 지표의 핵심과 정확히 같습니다 — 픽셀을 직접 비교하지 말고, 이미지에서 "의미 있는 정보"만 뽑아낸 특징을 비교하자는 것입니다. 차이는 특징을 어떻게 만드는가입니다.

* 이 장의 방법: 사람이 직접 설계한 규칙(Sobel 필터, 방향 히스토그램)으로 특징을 뽑았습니다.
* LPIPS: 수백만 장의 이미지로 사물을 분류하도록 미리 학습된 거대한 신경망(예: VGG, AlexNet)의 중간층 출력을 특징으로 씁니다. 이 신경망은 "고양이와 개를 구별하라"는 과제를 풀면서, 그 부산물로 위치·조명·약간의 변형에는 둔감하면서 진짜 내용(질감, 형태, 사물의 정체성)에는 민감한 특징을 스스로 학습합니다.

그리고 LPIPS는 여기서 한 단계 더 나아갑니다 — 신경망의 여러 층에서 뽑은 특징들을 무작정 합치는 게 아니라, "사람에게 이미지 두 장 중 어느 것이 기준 이미지와 더 닮았는지 물어본 대규모 설문 데이터(BAPPS 데이터셋)"에 맞춰 각 층의 중요도(가중치)를 다시 학습시킵니다. 즉 "신경망이 우연히 학습한 특징"을 "사람의 실제 판단"에 맞게 한 번 더 보정하는 것입니다 — 이 보정 덕분에 LPIPS 점수가 사람의 지각적 판단과 상당히 잘 맞는다는 것이 원 논문(Zhang et al., 2018)에서 실험적으로 확인됐습니다.

== 이 장의 한계

방금 만든 특징은 이미지 전체를 뭉뚱그려 하나의 히스토그램으로 요약했습니다 — 이건 "위치를 완전히 무시한다"는 장점이자, 동시에 "이미지의 어느 부분이 다른지는 전혀 알려주지 못한다"는 단점이기도 합니다. 게다가 색 정보도 전혀 쓰지 않아 7장에서 봤던 색맹 문제를 그대로 갖고 있습니다. 다음 장에서는 이 두 문제를 어느 정도 보완한, 조금 더 정교한(그래도 여전히 신경망 없이 손으로 설계한) 특징 추출기를 만들어 6~7장의 모든 실패 사례에 다시 적용해봅니다.

"무엇을 무시하고 무엇에 민감해야 하는가"는 그 지표를 어디에 쓰느냐에 따라 달라지는 설계 선택이라는 것을, 12장에서 3DGS에 적용할 때 다시 다룹니다.

== 요약

* 픽셀을 직접 비교하는 대신, 가장자리의 방향 분포 같은 요약된 특징을 비교하면 위치 이동처럼 사람이 신경 쓰지 않는 변화에는 둔감하면서, 진짜 모양(내용) 차이에는 여전히 민감한 지표를 만들 수 있습니다.
* LPIPS 같은 지각적 지표는 이 아이디어를 손으로 설계한 규칙 대신, 대규모 이미지로 사전 학습된 신경망의 중간층 특징으로 구현하고, 사람의 실제 판단 데이터로 그 특징의 중요도를 다시 보정합니다.
* 이 장에서 만든 단순한 특징은 위치에는 완전히 무감각하지만, 그만큼 이미지의 어느 부분이 다른지에 대한 정보와 색 정보를 모두 잃어버렸다는 한계가 있습니다.
* 다음 장에서는 이 한계를 부분적으로 보완한 조금 더 정교한 특징 추출기를 만들어, 지금까지의 모든 실패 사례(색맹, 흐림/노이즈 구별, 정렬 민감성)에 다시 적용해봅니다.
