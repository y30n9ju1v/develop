3DGS 기반 자율주행 E2E 모델의 새 체크포인트가 나올 때마다, 렌더링 품질과 기하 정확도가 실제로 나빠졌는지 사람이 눈으로 검수하지 않고도 자동으로, 반복 가능하게, 신뢰할 수 있게 판정하는 파이프라인을 처음부터 구축하는 실무 지향적인 책입니다. 문제 정의(1부: "회귀"란 무엇인가) → 파이프라인 아키텍처(2부: kind 클러스터·베이스라인 데이터셋·컨테이너화·Argo Workflow DAG) → 자동화·비교·시각화(3부: 지표 계산·통계적 회귀 탐지·CI/CD 연동·Rerun 시각화) → 운영과 실전(4부: 플레이키 테스트·클라우드 스케일링·종합 실전·폐루프 주행 평가 지표)까지, 실제로 동작하는 kind/Argo Workflows/Rerun 매니페스트와 파이썬 코드로 전체 파이프라인을 구성합니다.

이 책은 "닮았다는 걸 어떻게 잴까"(이미지 품질 평가) 책의 PSNR/SSIM/LPIPS 지표와, "흔들리는 로그를 선명한 3DGS로"(시간 정렬과 extrinsic 재최적화) 책의 포즈/재투영 오차 지표를 함께 재사용해, "무엇을 잴 것인가"가 아니라 "그 잼을 언제, 얼마나 자주, 얼마나 신뢰할 수 있게 반복할 것인가"에 집중하는 후속편입니다. 두 책을 먼저 읽지 않아도 따라올 수 있도록 구성했습니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
