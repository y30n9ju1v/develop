== 이 책이 하려는 것

최근 자율주행 스택은 "카메라로 차선을 찾고, 라이다로 장애물을 찾고, 각각의 결과를 규칙 기반으로 합친다"는 예전 방식에서, 카메라와 라이다의 원시 특징을 하나의 공통 공간(BEV, Bird's Eye View — 위에서 내려다본 2D 평면)에서 학습 기반으로 융합하고, 그 융합된 표현에서 곧바로 미래 궤적까지 뽑아내는 End-to-End(E2E) 방식으로 옮겨가고 있습니다. 이 책은 이 흐름의 핵심 구성 요소 — 좌표계 통일, BEV 융합(Lift-Splat-Shoot), Transformer 기반 BEV 인코더(BEVFormer 스타일의 deformable attention), 그리고 궤적을 생성하는 Planning Head — 를 처음부터 끝까지 직접 구현합니다.

== 이 책의 방식: 두 가지 도구를 상황에 맞게

이 시리즈의 1~2권(멀티뷰 기하학, 미분가능 렌더링)이 모든 걸 NumPy로 손수 구현했다면, 이 책은 두 도구를 나눠 씁니다. 카메라·라이다의 좌표 변환과 BEV로의 투영(2~6장)은 순수한 기하학 계산이라 NumPy로 직접 구현하고 유한차분·기하학적 사실로 검증합니다. 반면 Transformer 기반 인코더와 Planning Head(7장부터)는 실제로 학습이 되는지, 실전에서 쓰는 것과 같은 도구로 확인하는 게 더 의미가 있으므로 PyTorch로 실제 모델을 만들고 실제로 `loss.backward()`를 돌립니다 — AICE 책이 Keras를 그대로 썼던 것과 같은 이유입니다.

== 데이터셋: 시뮬레이션으로 직접 만든 가상 주행 장면

실제 자율주행 데이터셋(nuScenes 등)은 용량이 크고 이 세션 환경에서 받기 어렵습니다. 대신 이 책 전체에서, 가상의 차량이 여러 대의 카메라와 라이다를 달고 도로 위를 달리는 장면을 NumPy로 직접 시뮬레이션합니다 — 이 시리즈의 SLAM 책이 가상 로봇과 랜드마크로 필터를 검증했던 것과 같은 방식입니다. 시뮬레이션이라 정답(ground truth)을 정확히 알고 있으므로, 각 단계에서 나온 결과가 실제로 맞는지 확실하게 검증할 수 있습니다.

== 시리즈에서의 위치

이 책은 3DGS 기반 자율주행 E2E 검증 시리즈의 세 번째 책입니다. 1권("사진에서 세계로")이 카메라 포즈와 점군 재구성을, 2권("미분가능 렌더링과 3D Gaussian Splatting")이 그 재구성으로 실제 장면을 학습하는 법을, SLAM 심화편이 궤적과 지도를 만드는 법을 다뤘다면, 이 책은 그렇게 인식된 세계 위에서 **실제로 주행 결정을 내리는 모델 자체**를 다룹니다 — 센서 데이터가 들어가서 궤적이 나오는 전체 파이프라인이 이 시리즈가 지금까지 쌓아온 "세계를 인식하는 방법들"이 최종적으로 무엇을 위한 것인지 보여주는 지점입니다. 1권의 카메라 모델(핀홀 투영, 내부/외부 파라미터)을 이미 알고 있다면 2~3장을 더 빠르게 읽을 수 있지만, 읽지 않았어도 무리 없이 시작할 수 있습니다.
