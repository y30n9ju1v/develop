카메라 모델부터 여러 장의 사진에서 얻는 3차원 재구성까지, 멀티뷰 기하학을 코드로 직접 검증하며 배우는 독립적인 입문서입니다. 카메라 모델(1부) → 두 장 사진의 기하학(2부) → Structure-from-Motion(3부) → 점군 기반 장면 표현과 품질 진단(4부) 순서로 쌓아 올립니다.

이 책의 모든 핵심 계산(카메라 투영, 에피폴라 제약, 삼각측량, 번들 조정, 장면 표현과 품질 진단 등)은 이 책을 위해 새로 지은 예제이며, NumPy/SciPy로 실제 실행해 숫자로 검증했습니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
