'''

6장에서 드리프트가 데이터를 아무리 모아도 저절로 사라지지 않는다는 걸 확인했습니다. 이 장에서는 드리프트를 실제로 되돌리는 도구 — **포즈 그래프 최적화** — 를 구현합니다. 핵심 아이디어는, 절대 자세(월드 좌표계 기준 위치·방향)는 드리프트로 흔들려도, **인접한 프레임 사이의 상대 자세**(이 프레임에서 저 프레임으로 얼마나 움직였는가)는 훨씬 정확하게 추정할 수 있다는 사실을 이용하는 것입니다.

== 왜 상대 자세는 절대 자세보다 정확한가

절대 자세(세계 좌표계 기준 위치)는 시간이 지날수록 여러 오차가 누적된 결과입니다. 반면 인접한 두 프레임 사이의 상대 자세는, 그 두 프레임에 공통으로 찍힌 특징점들을 매칭하거나(시각 오도메트리), 그 사이 극히 짧은 시간 동안의 IMU 적분만으로 계산할 수 있어(13장에서 다룰 IMU 프리인테그레이션과 비슷한 원리입니다), 누적 오차가 낄 시간이 거의 없습니다. 6장에서 확인한 것처럼, **오래 누적된 절대값은 신뢰도가 낮고, 짧은 구간의 상대값은 신뢰도가 높다**는 이 비대칭이 포즈 그래프 최적화의 핵심 재료입니다.

== 정확한 상대 제약 만들기

이 시리즈의 "회전은 왜 어려운가" 책 12장에서 다뤘던 `SE(3)` 포즈 그래프 최적화 도구(지수/로그 사상, `⊞`, 잔차, 가우스-뉴턴)를 그대로 가져와 씁니다. 정답 궤적으로부터 인접 프레임 간 정확한 상대 변환에 작은 노이즈만 섞어 "상대 오도메트리 측정값"을 만듭니다.

[source,python]
----
import numpy as np

# (skew, exp_so3, log_so3, left_jacobian_so3, exp_se3, log_se3, se3_inv, boxplus_se3는
#  "회전은 왜 어려운가" 책 7~10장과 동일하게 정의합니다)

def to_T(R, t):
    T = np.eye(4)
    T[:3, :3], T[:3, 3] = R, t
    return T

T_true = [to_T(R, t) for R, t in true_poses]     # 6장의 true_poses

rel_noise_std = 0.001                             # 상대 추정은 훨씬 정확하다고 가정
Z_rel = []
for i in range(n_frames - 1):
    T_rel_true = se3_inv(T_true[i]) @ T_true[i + 1]
    Z_rel.append(T_rel_true @ exp_se3(rng.normal(0, rel_noise_std, 6)))
----

`rel_noise_std = 0.001`은 6장에서 드리프트가 매 스텝 누적하던 크기(`0.003`)보다도 작은, 훨씬 정확한 상대 추정치입니다.

== 포즈 그래프 최적화: 드리프트된 절대값을 초기 추정으로, 상대 제약으로 바로잡기

드리프트로 흔들린 6장의 `drift_poses`를 초기 추정값으로 삼되, 첫 프레임만은 정답에 고정합니다(예를 들어 캘리브레이션 직후의 첫 프레임은 신뢰할 수 있다고 가정하는 것과 같습니다).

[source,python]
----
T_init = [to_T(R, t) for R, t in drift_poses]     # 6장의 드리프트된 절대 자세
T_init[0] = T_true[0]                              # 첫 프레임만 고정(앵커)

def residual(Ti, Tj, Zij):
    return log_se3(se3_inv(Zij) @ (se3_inv(Ti) @ Tj))

def build_residuals(Ts):
    return np.concatenate([residual(Ts[i], Ts[i + 1], Z_rel[i]) for i in range(n_frames - 1)])
----

이 잔차는 정확히 "이전 프레임의 지금 추정치에서 다음 프레임의 지금 추정치로 가는 상대 변환"과 "우리가 믿는 정확한 상대 제약(`Z_rel`)"이 얼마나 다른지를 잽니다 — 절대 위치가 아니라 **상대 변환들이 서로 일관되도록** 전체 궤적을 조정하는 것입니다.

[source,python]
----
def numeric_jacobian(Ts, eps=1e-6):
    r0 = build_residuals(Ts)
    J = np.zeros((len(r0), 6 * (n_frames - 1)))
    for pidx in range(1, n_frames):
        for k in range(6):
            d = np.zeros(6)
            d[k] = eps
            Tp, Tm = Ts.copy(), Ts.copy()
            Tp[pidx] = boxplus_se3(Ts[pidx], d)
            Tm[pidx] = boxplus_se3(Ts[pidx], -d)
            J[:, (pidx - 1) * 6 + k] = (build_residuals(Tp) - build_residuals(Tm)) / (2 * eps)
    return J

Ts = T_init.copy()
for iteration in range(6):
    r = build_residuals(Ts)
    J = numeric_jacobian(Ts)
    H = J.T @ J + 1e-6 * np.eye(J.shape[1])
    dx = np.linalg.solve(H, -J.T @ r)
    for pidx in range(1, n_frames):
        Ts[pidx] = boxplus_se3(Ts[pidx], dx[(pidx - 1) * 6:(pidx - 1) * 6 + 6])
    print(f"반복 {iteration}: 잔차 노름 = {np.linalg.norm(r):.6f}")
----

반복 1: 잔차 노름 = 0.000425
반복 2: 잔차 노름 = 0.000000045
반복 3: 잔차 노름 = 0.000000000029
반복 4: 잔차 노름 = 0.000000000000032
반복 5: 잔차 노름 = 0.0000000000000013
----

가우스-뉴턴법이 몇 번의 반복만으로 잔차를 거의 완전히(`0`에 가깝게) 없앴습니다 — 정확한 상대 제약들을 모두 동시에 만족시키는 절대 자세들의 조합을 찾아낸 것입니다.

이제 이 최적화된 궤적으로 6장의 재투영 오차 측정을 다시 해봅니다.

optimized_poses = [(T[:3, :3], T[:3, 3]) for T in Ts]

print("최적화 전(드리프트된 절대값):", mean_reproj_error(drift_poses, true_poses, points_true))

== 왜 완전히 0이 되지는 않았는가: 게이지 자유도

잔차 자체는 거의 완벽하게 `0`이 됐는데(가우스-뉴턴이 상대 제약을 정확히 만족시켰습니다), 재투영 오차는 `0.69`픽셀이 남았습니다. 이건 상대 제약만으로는 궤적의 "절대적인 위치와 방향"을 완전히 결정할 수 없기 때문입니다 — 상대 변환들이 아무리 완벽하게 맞아떨어져도, 궤적 전체를 통째로 평행이동하거나 회전시켜도 그 상대 관계는 그대로 유지됩니다(이걸 **게이지 자유도**라고 부릅니다). 이 예제에서는 첫 프레임을 정답에 고정해 이 자유도를 없앴지만, 그 첫 프레임 앵커 자체가 유일한 "절대 기준"이라, 그 기준에서 멀어질수록 남은 부정확성이 아주 조금씩 쌓일 수 있습니다(다만 6장의 드리프트만큼 심하게 쌓이지는 않습니다 — `3.23`에서 `0.69`로 줄었으니까요). 다음 장에서는 상대 제약 외에 **강체 제약**(여러 카메라가 서로 고정된 거리를 유지해야 한다는 정보)을 추가로 넣어 이 게이지 자유도를 더 좁히는 법을 다룹니다.

== 요약

* 절대 자세는 드리프트로 신뢰도가 낮아도, 인접 프레임 간 상대 자세는 상대적으로 정확하게 추정할 수 있다는 비대칭을 이용해 포즈 그래프 최적화를 구성했습니다.
* 드리프트된 절대 자세를 초기 추정값으로, 정확한 상대 제약을 잔차로 삼아 가우스-뉴턴법을 돌리면 몇 번의 반복만으로 상대 제약을 거의 완벽하게 만족시키는 궤적을 찾을 수 있습니다.
* 이 예제에서 재투영 오차가 `3.23`픽셀에서 `0.69`픽셀로, `4.7`배 넘게 줄었습니다.
* 상대 제약만으로는 궤적의 절대 위치·방향을 완전히 고정할 수 없는 게이지 자유도가 남으며, 어느 프레임을 앵커로 고정하느냐가 이 자유도를 없애는 방법입니다.
* 다음 장에서는 여러 카메라가 하나의 리그로 단단히 고정되어 있다는 사실을 추가 제약으로 넣어, 이 게이지 자유도를 더 좁히고 최적화를 더 안정시키는 법을 다룹니다.
