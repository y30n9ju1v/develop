Functional Programming in Lean, Theorem Proving in Lean 4, Metaprogramming in Lean 4 세 권을 초보자도 하나의 흐름으로 이어 읽을 수 있게 새로 쓴 입문서입니다. 왜 이걸 배우는지를 각 장 맨 앞에 놓고, 값과 타입 같은 기초부터 시작해 재귀, 나만의 자료구조, 다형성, 모나드(1부) → 명제도 타입이라는 발상, 전술, 귀납 증명(2부) → Lean이 스스로를 확장하는 원리와 나만의 tactic 만들기(3부)까지, 필요한 개념만 순서대로 쌓아 올립니다.

이 책의 코드 예제는 전부 이 책을 위해 새로 짠 것이며, 원본 세 책의 내용을 그대로 옮기지 않습니다. 더 깊이 들어가고 싶다면 각 장 끝, 그리고 13장(맺음말)에서 원본 책으로 가는 길을 안내합니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
