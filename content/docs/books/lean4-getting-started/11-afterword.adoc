== 이 책이 일부러 건너뛴 것들

이 책은 열 개의 장에 걸쳐 세 권의 책을 빠르게 훑었지만, 각 책 안에는 이 책이 다루지 않은 내용이 훨씬 많습니다. 몇 가지만 짚어봅니다.

1부(함수형 프로그래밍)에서는 모나드 변환기(여러 모나드를 겹쳐 쓰는 법), 의존 타입으로 색인화된 자료구조, 꼬리재귀 최적화와 종료성 증명의 세부 기법을 다루지 않았습니다.

2부(증명)에서는 `conv` 모드(목표와 가정 내부를 부분적으로 파고들어 재작성하는 방법), 공리와 계산 가능성의 경계, 타입 클래스를 이용한 증명 자동화의 더 정교한 패턴을 다루지 않았습니다.

3부(메타프로그래밍)에서는 이 책이 아주 표면적인 예제만 봤습니다 — 실제로 새 문법 카테고리를 정의해서 도메인 특화 언어(DSL)를 만드는 법, `simp` 확장, 더 복잡한 tactic 조합은 전혀 손대지 않았습니다.

== 더 깊이 들어가고 싶다면

이 책에서 어떤 장이 가장 흥미로웠는지에 따라 다음 행선지가 갈립니다.

* *1부(함수형 프로그래밍)가 재밌었다면* → link:../../../programming/lean/functional-programming-in-lean/[Functional Programming in Lean]. 특히 모나드 변환기(6장)와 의존 타입 색인화(7장)를 더 깊이 다룹니다.
* *2부(증명)가 재밌었다면* → link:../../../programming/lean/theorem-proving-in-lean4/[Theorem Proving in Lean 4]. 이 책의 6~8장이 다룬 내용의 훨씬 엄밀하고 완전한 버전이라고 보면 됩니다.
* *3부(메타프로그래밍)가 재밌었다면* → link:../../../programming/lean/metaprogramming-in-lean4/[Metaprogramming in Lean 4]. `Syntax`, `Expr`, `MetaM`을 훨씬 깊이 다루고, DSL 설계까지 다룹니다.

== 다음 프로젝트를 시작하려면: lake

지금까지는 파일 하나로 충분했지만, 본격적인 프로젝트는 Lean4의 빌드 도구 `lake`로 만듭니다. 다음 세 줄이면 Mathlib(커뮤니티가 쌓아 올린 수학 라이브러리)이 연결된 새 프로젝트가 생깁니다.

[source,bash]
----
lake +v4.32.0 new my_project math
cd my_project
lake update && lake exe cache get
----

마지막 줄은 Mathlib을 소스부터 컴파일하는 대신 미리 빌드된 캐시를 내려받는 명령입니다 — 건너뛰면 첫 빌드에 수십 분이 걸리니 꼭 실행하세요. 자세한 과정과 문제 해결은 link:../../../programming/lean/lean4-vscode-mathlib-setup/[VS Code에서 Lean 4 + Mathlib4 셋업하기]에 정리되어 있습니다.

== 막히면 어디서 물어보나

Lean 커뮤니티는 https://leanprover.zulipchat.com/[Lean Zulip]에 모여 있습니다. 초보 질문 전용 채널(*#new members*)이 따로 있고, 질문에 답이 빠르기로 유명합니다. 질문할 때는 막힌 코드 전체와 에러 메시지(또는 InfoView의 목표 상태)를 함께 붙이면 됩니다 — 문제를 그대로 재현하는 링크를 만들어주는 https://live.lean-lang.org/[웹 에디터]도 유용합니다.

== 마지막으로: 손으로 눌러보세요

서문에서도 강조했지만, 이 책의 모든 코드 예제는 VS Code + Lean4 확장을 설치하고 직접 눌러볼 때 훨씬 잘 이해됩니다. 특히 7~8장의 전술 증명은 `⊢` 위아래로 목표가 바뀌는 걸 눈으로 지켜보지 않으면 왜 그렇게 동작하는지 감이 잘 안 옵니다. 이 책을 다 읽은 다음 할 일이 하나 있다면, 여러분이 알고 있는 아주 작은 수학적 사실 하나(가령 "두 홀수를 더하면 짝수다")를 골라 처음부터 끝까지 직접 증명해보는 것입니다.
