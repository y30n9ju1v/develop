== 나눗셈: 존재 명제로 정의된 관계

[source,lean]
----
example (a b : ℕ) (h : a ∣ b) : ∃ k, b = a * k := h

example : (3 : ℕ) ∣ 12 := ⟨4, by norm_num⟩
----

`a ∣ b`("`a`가 `b`를 나눈다")는 정의상 `∃ k, b = a * k`입니다 — "`b`를 `a`의 배수로 표현할 수 있다"는 뜻입니다. 3장에서 배운 존재 명제 패턴이 그대로 적용됩니다 — `3 ∣ 12`를 증명할 땐 목격자 `4`와 `12 = 3 * 4`라는 증거를 짝지으면 됩니다.

== 나눗셈의 기본 성질: 추이성과 덧셈에 대한 닫힘

[source,lean]
----
example (a b c : ℕ) (h1 : a ∣ b) (h2 : b ∣ c) : a ∣ c := h1.trans h2

example (a b c : ℕ) (h1 : a ∣ b) (h2 : a ∣ c) : a ∣ (b + c) := by
  obtain ⟨k1, hk1⟩ := h1
  obtain ⟨k2, hk2⟩ := h2
  exact ⟨k1 + k2, by rw [hk1, hk2]; ring⟩
----

`h1.trans h2`는 4장에서 본 `.trans`처럼 "`a`가 `b`를 나누고 `b`가 `c`를 나누면 `a`가 `c`를 나눈다"는 추이성을 그대로 씁니다. 두 번째 예제("`a`가 `b`도 `c`도 나누면 `b+c`도 나눈다")는 직접 손으로 짓습니다 — 두 나눗셈 증거를 각각 열어(`obtain`) 몫 `k1`, `k2`를 꺼내고, `b + c = a*k1 + a*k2 = a*(k1+k2)`라는 계산을 `ring`으로 마무리합니다. 3장에서 배운 대수 자동화가 정수론 증명 안에서도 계속 쓰입니다.

== 최대공약수: 두 가지 핵심 성질

[source,lean]
----
example : Nat.gcd 12 18 = 6 := by decide

example (a b : ℕ) : Nat.gcd a b ∣ a := Nat.gcd_dvd_left a b
example (a b : ℕ) : Nat.gcd a b ∣ b := Nat.gcd_dvd_right a b
----

`Nat.gcd a b`는 `a`와 `b`의 최대공약수입니다. 구체적인 계산(`gcd 12 18 = 6`)은 `decide`(유한한 계산을 전부 실행해서 확인하는 전술)로 즉시 끝나고, "gcd는 두 수 모두를 나눈다"는 일반적인 성질은 `Nat.gcd_dvd_left`/`Nat.gcd_dvd_right`라는 이미 있는 정리를 그대로 가져다 씁니다 — 4장에서 배운 "이미 있는 정리를 찾아 쓴다"는 감각이 정수론에서 특히 자주 쓰입니다.

== 베주 항등식: gcd는 정수 결합으로 표현된다

[source,lean]
----
example (a b : ℕ) :
    (a : ℤ) * Nat.gcdA a b + (b : ℤ) * Nat.gcdB a b = Nat.gcd a b :=
  (Nat.gcd_eq_gcd_ab a b).symm
----

**베주 항등식(Bézout's identity)**은 "두 수 `a`, `b`의 최대공약수는 항상 `a`와 `b`의 정수 계수 결합(`a*x + b*y` 꼴)으로 표현할 수 있다"는, 정수론에서 아주 중요한 사실입니다. Mathlib은 이 계수(`x`, `y`)를 실제로 계산해주는 함수 `Nat.gcdA`, `Nat.gcdB`(확장 유클리드 알고리즘으로 계산됩니다)와, 그 계수가 정말로 베주 항등식을 만족한다는 정리 `Nat.gcd_eq_gcd_ab`를 함께 제공합니다. 여기서는 그 정리를 그대로(방향만 뒤집어서, `.symm`으로) 가져다 썼습니다 — 정수론의 깊은 정리라도, Mathlib에 이미 있다면 증명을 손수 짤 필요가 없다는 걸 보여주는 예입니다.

== 서로소: gcd가 1인 두 수

[source,lean]
----
example : Nat.Coprime 8 15 := by decide
----

두 수의 최대공약수가 `1`일 때 그 둘을 **서로소(coprime)**라고 부릅니다 — `Nat.Coprime a b`가 정의상 `Nat.gcd a b = 1`입니다. `8`과 `15`는 공약수가 `1`뿐이라 서로소이고, 이것도 `decide`로 즉시 확인됩니다. 서로소는 다음 장(소인수분해)과 모듈러 산술(10장)에서 계속 등장하는 개념입니다 — 예를 들어 "`a`가 `b*c`를 나누고 `a`와 `b`가 서로소면, `a`는 `c`를 나눈다"(유클리드 보조정리의 일반화) 같은 정리들이 서로소라는 조건 위에 세워집니다.

== 왜 이게 다음 장의 기반인가

9장에서 소수를 다룰 때, "소수는 자기 자신과 1 외에는 약수가 없다"는 정의 자체가 이 장의 `∣`(나눗셈)로 표현됩니다. 그리고 "모든 자연수는 소인수분해를 갖는다"는 정리를 증명할 때, 이 장에서 본 gcd·서로소 개념이 반복해서 쓰입니다 — 정수론은 나눗셈 하나의 개념 위에 계속 쌓아 올려지는 분야라, 이 장의 기초가 흔들리면 이후 장이 전부 흔들립니다.

== 요약

* `a ∣ b`는 정의상 `∃ k, b = a * k`이고, 목격자(몫)를 제시하는 방식으로 증명합니다.
* 나눗셈은 추이적이고 덧셈에 대해 닫혀 있습니다.
* `Nat.gcd_dvd_left`/`Nat.gcd_dvd_right`가 gcd의 기본 성질을, `Nat.gcd_eq_gcd_ab`(베주 항등식)가 gcd를 정수 결합으로 표현하는 법을 이미 증명된 형태로 제공합니다.
* 서로소(`Nat.Coprime`)는 gcd가 1인 관계로, 다음 장의 소인수분해에서 다시 쓰입니다.
