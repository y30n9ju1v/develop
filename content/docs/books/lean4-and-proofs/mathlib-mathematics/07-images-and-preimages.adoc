6장에서 함수의 성질(단사·전사)을 다뤘다면, 이 장에서는 함수가 **집합**과 만났을 때 생기는 두 연산 — 상(image)과 원상(preimage) — 을 다룹니다.

== 상: 집합을 함수로 밀어보내기

[source,lean]
----
example (f : ℕ → ℕ) (A : Set ℕ) (y : ℕ) :
    y ∈ f '' A ↔ ∃ x ∈ A, f x = y := Iff.rfl
----

`f '' A`(상, image)는 "`A`의 각 원소에 `f`를 적용해서 나온 값들의 집합"입니다. `y ∈ f '' A`가 정의상 `∃ x ∈ A, f x = y`(A 안에 `f`를 적용해서 `y`가 되는 원소가 있다)와 같다는 걸 `Iff.rfl`(정의 그대로 참인 동치)로 확인했습니다 — 5장에서 `∈ ∩`가 정의상 `∧`였던 것과 같은 종류의 확인입니다.

[source,lean]
----
example : (fun n : ℕ => 2 * n) '' {n | Even n} = {n | 4 ∣ n} := by
  ext y
  simp only [mem_image, mem_ofPred]
  constructor
  · rintro ⟨x, ⟨k, hk⟩, rfl⟩
    exact ⟨k, by omega⟩
  · rintro ⟨k, hk⟩
    exact ⟨2 * k, ⟨k, by ring⟩, by omega⟩
----

"짝수 집합을 2배 함수로 밀어보내면 4의 배수 집합이 된다"는 걸 증명합니다 — `ext y`로 5장의 패턴(원소 자격의 동치)으로 바꾸고, 양방향을 각각 목격자를 제시해서 증명합니다. `rintro ⟨x, ⟨k, hk⟩, rfl⟩`가 한 번에 하는 일이 많습니다 — "상의 원소다"라는 증거를 열어 `x`(원래 원소)와 "`x`가 짝수라는 증거"(다시 열어 `k`), 그리고 "`2 * x = y`"(이건 `rfl`로 즉시 `y` 자리에 대입)를 한 줄로 다 받아옵니다.

== 원상: 집합을 함수로 끌어오기

[source,lean]
----
example (f : ℕ → ℕ) (B : Set ℕ) (x : ℕ) : x ∈ f ⁻¹' B ↔ f x ∈ B := Iff.rfl
----

`f ⁻¹' B`(원상, preimage)는 "`f`를 적용했을 때 결과가 `B`에 들어가는 입력들의 집합"입니다. 상과 달리 원상의 정의는 **존재 명제가 없습니다** — `x ∈ f ⁻¹' B`가 정의상 그냥 `f x ∈ B`입니다. 이 차이가 다음 성질에서 실질적인 결과를 낳습니다.

== 원상은 교집합을 보존한다

[source,lean]
----
example (f : ℕ → ℕ) (B C : Set ℕ) : f ⁻¹' (B ∩ C) = f ⁻¹' B ∩ f ⁻¹' C := by
  ext x
  simp only [mem_preimage, mem_inter_iff]
----

`f ⁻¹' (B ∩ C) = f ⁻¹' B ∩ f ⁻¹' C`(먼저 교집합을 만들고 원상을 취하나, 각자 원상을 취하고 교집합을 만드나 같다)는 사실 거의 증명이랄 것도 없습니다 — 양쪽 다 정의를 펼치면 `f x ∈ B ∧ f x ∈ C`로 **정확히 같은 명제**가 됩니다(`simp`가 정의를 펼친 뒤 `rfl`로 자동 마무리됩니다). 원상이 `∃`를 거치지 않고 그냥 조건 하나(`f x ∈ B`)로 정의되기 때문에, 논리곱과 자연스럽게 맞아떨어집니다.

== 상은 부분집합 관계를 보존한다

[source,lean]
----
example (f : ℕ → ℕ) (A A' : Set ℕ) (h : A ⊆ A') : f '' A ⊆ f '' A' := by
  rintro y ⟨x, hx, rfl⟩
  exact ⟨x, h hx, rfl⟩
----

반대로 상은 **교집합을 일반적으로 보존하지 않습니다**(이 책에서는 다루지 않지만, `f '' (A ∩ A') ⊆ f '' A ∩ f '' A'`는 항상 성립해도 반대 방향은 `f`가 단사가 아니면 깨질 수 있습니다 — 서로 다른 원소가 같은 곳으로 뭉개질 수 있으니까요). 대신 상이 확실히 보존하는 건 **부분집합 관계**입니다 — `A`가 `A'`보다 작으면, `A`를 밀어보낸 결과도 `A'`를 밀어보낸 결과보다 작습니다. `rintro y ⟨x, hx, rfl⟩`가 "상의 원소 `y`"를 열어 원래 원소 `x`와 그 증거를 한 번에 받고, `h hx`로 `x ∈ A'`를 얻어 다시 상에 넣어 `y ∈ f '' A'`를 만듭니다.

== 왜 이 비대칭이 생기는가

원상(`f ⁻¹'`)이 교집합·합집합·여집합 전부를 깔끔하게 보존하는 반면, 상(`f ''`)은 그렇지 못하다는 게 이 장의 핵심 통찰입니다 — 원상의 정의(`∃` 없이 조건 하나)가 논리 연산자와 "일대일로 대응"되는 반면, 상의 정의(`∃`가 들어감)는 그 대응이 깨지기 때문입니다. 이 비대칭은 실전에서 "함수를 통해 어떤 성질을 밀고 당길 때, 어느 방향이 항상 안전한지"를 판단하는 실질적인 지침이 됩니다 — 조건을 명시하는 데는 원상이, 구체적인 원소 집합을 다루는 데는 상이 각자 자연스러운 자리가 있습니다.

== 직접 해보기

* `(f : ℕ → ℕ) (B C : Set ℕ) : f ⁻¹' (B ∪ C) = f ⁻¹' B ∪ f ⁻¹' C`(원상이 합집합도 보존한다는 것)를 증명해보세요.

.해답 보기
[%collapsible]
====
[source,lean]
----
example (f : ℕ → ℕ) (B C : Set ℕ) : f ⁻¹' (B ∪ C) = f ⁻¹' B ∪ f ⁻¹' C := by
  ext x
  simp only [mem_preimage, mem_union]
----
====

== 요약

* `y ∈ f '' A`는 정의상 `∃ x ∈ A, f x = y`이고, `x ∈ f ⁻¹' B`는 정의상 그냥 `f x ∈ B`입니다.
* 원상은 교집합·합집합을 그대로 보존합니다(정의에 `∃`가 없어서 논리 연산자와 일대일 대응됩니다).
* 상은 부분집합 관계는 보존하지만, 교집합은 일반적으로 보존하지 않습니다(`∃`가 껴 있어서 정보가 손실될 수 있습니다).

2부가 여기서 끝났습니다. 3부에서는 이 논리·집합·함수 도구를 정수론에 적용합니다.
