논리·집합·정수론·대수 구조·해석학을 Lean4와 Mathlib으로 직접 증명하며 배우는 독립적인 입문서입니다. 증명 기본기(1부) → 집합과 함수(2부) → 정수론(3부) → 군과 순서 구조(4부) → 수열의 극한과 연속함수(5부) 순서로, "이미 아는 수학을 Mathlib으로 어떻게 증명하는가"에 집중합니다.

이 책의 모든 예제·증명·연습문제는 이 책을 위해 새로 지은 원본이며, 모든 코드는 Lean4(v4.33.0-rc1)와 Mathlib으로 실제 컴파일하고 검증했습니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
