대학 초년생 시절 극한을 배웠다면 "엡실론-N 논법"(임의의 오차 `ε`를 정해도, 그 이후로는 항상 극한값과 그 오차 안에 들어가는 지점 `N`이 존재한다)을 접했을 것입니다. Mathlib은 이걸 조금 다른 방식 — **필터(filter)**와 `Tendsto`라는 개념으로 표현합니다. 이 장에서는 이 새로운 언어와 손으로 배운 엡실론-N 논법이 실제로 같은 것을 말한다는 걸 확인합니다.

== Tendsto: 수열이 어딘가로 "향한다"는 것

[source,lean]
----
example : Tendsto (fun n : ℕ => (1 : ℝ) / (n + 1)) atTop (𝓝 0) :=
  tendsto_one_div_add_atTop_nhds_zero_nat

example (c : ℝ) : Tendsto (fun _ : ℕ => c) atTop (𝓝 c) := tendsto_const_nhds
----

`Tendsto f atTop (𝓝 l)`는 "`n`이 무한대로 갈 때(`atTop`), `f n`이 `l`의 근방(`𝓝 l`)으로 향한다"는 뜻입니다 — 직관적으로는 "`f`가 `l`로 수렴한다"는 것과 같습니다. `1/(n+1)`이 `0`으로 수렴한다는 것과, 상수 수열이 그 상수 자신으로 수렴한다는 것(당연하지만 확인이 필요한 사실입니다)을 Mathlib이 이미 증명해둔 정리로 확인했습니다.

== 극한의 선형성과 유일성

[source,lean]
----
example (a b : ℕ → ℝ) (la lb : ℝ) (ha : Tendsto a atTop (𝓝 la)) (hb : Tendsto b atTop (𝓝 lb)) :
    Tendsto (fun n => a n + b n) atTop (𝓝 (la + lb)) := ha.add hb

example (a : ℕ → ℝ) (l1 l2 : ℝ) (h1 : Tendsto a atTop (𝓝 l1)) (h2 : Tendsto a atTop (𝓝 l2)) :
    l1 = l2 := tendsto_nhds_unique h1 h2
----

"두 수열이 각각 어딘가로 수렴하면, 그 합도 두 극한의 합으로 수렴한다"(`ha.add hb`)와 "한 수열의 극한은 유일하다"(`tendsto_nhds_unique`)는, 손으로 증명하려면 각각 엡실론-N 논법을 몇 줄씩 써야 하는 정리들인데, Mathlib에서는 이름 하나로 끝납니다. 4장에서 배운 "이미 증명된 정리를 찾아 쓴다"는 태도가 해석학에서도 그대로 유효합니다 — 오히려 손으로 다루기 번거로운 엡실론-N 계산이 많은 분야일수록 이 태도의 이득이 큽니다.

== 직접 확인하기: Tendsto가 엡실론-N 논법과 같다는 것

[source,lean]
----
example : ∀ ε > (0:ℝ), ∃ N : ℕ, ∀ n : ℕ, n ≥ N → |(1 : ℝ) / (n + 1) - 0| < ε := by
  intro ε hε
  obtain ⟨N, hN⟩ := exists_nat_gt (1 / ε)
  use N
  intro n hn
  simp only [sub_zero]
  rw [abs_of_pos (by positivity)]
  rw [div_lt_iff₀ (by positivity)]
  have hNn : (N : ℝ) ≤ n := by exact_mod_cast hn
  have hN' : (1:ℝ) < ε * N := by
    rw [div_lt_iff₀ hε] at hN
    linarith [hN]
  nlinarith [hN']
----

이 증명이 정확히 "익숙한" 엡실론-N 논법입니다 — "임의의 `ε > 0`을 고르면(`intro ε hε`), 어떤 `N`이 존재해서(`∃ N`), `N` 이후의 모든 `n`에 대해 `|1/(n+1) - 0| < ε`이다"라는 명제를 직접 증명합니다.

* `exists_nat_gt (1/ε)`로 `1/ε`보다 큰 자연수 `N`을 찾습니다(아르키메데스 성질 — 자연수는 무한히 커질 수 있다는 사실을 Mathlib이 이미 증명해뒀습니다).
* `N` 이후의 `n`에 대해, `n ≥ N > 1/ε`이니 결국 `n`도 `1/ε`보다 크고, 이걸 재배열하면 `1/(n+1) < ε`이 나옵니다.
* `div_lt_iff₀`(나눗셈이 낀 부등식을 곱셈 부등식으로 바꿔주는 정리)와 `nlinarith`(3장에서 배운 비선형 부등식 자동화)가 그 재배열 계산을 처리합니다.

이 증명이 실제로는 `tendsto_one_div_add_atTop_nhds_zero_nat`이 뒤에서 증명하고 있는 것과 **같은 내용**입니다 — `Tendsto`라는 필터 언어가 결국 이 엡실론-N 논법을 압축해서 표현하는 방식일 뿐이라는 걸, 손으로 직접 풀어써봄으로써 확인했습니다.

== 왜 Mathlib은 필터라는 새 언어를 쓰는가

엡실론-N 논법을 직접 쓸 수 있는데도 `Tendsto`라는 새 개념을 도입하는 이유는 **일반성**입니다 — "`n`이 무한대로 간다"는 것뿐 아니라 "`x`가 `0`에 가까워진다", "`x`가 오른쪽에서 `a`로 다가간다" 같은 다양한 종류의 "극한 상황"을 `atTop` 대신 다른 필터로 바꿔치기만 하면 똑같은 `Tendsto` 정리들을 재사용할 수 있습니다 — 매번 새로운 엡실론-델타 논법을 처음부터 다시 쓸 필요가 없습니다. 이 책은 그 일반성을 깊이 파고들지 않지만, "손으로 아는 논법"과 "Mathlib의 언어"가 같은 것을 가리킨다는 걸 확인해뒀으니 다음 장의 연속함수도 낯설지 않을 것입니다.

== 직접 해보기

* `Tendsto (fun n : ℕ => (2 : ℝ) / (n + 1)) atTop (𝓝 0)`을 증명해보세요(힌트: `1/(n+1)`이 `0`으로 수렴한다는 이미 증명된 사실에, "상수를 곱해도 극한은 그 상수 곱"이라는 정리 `Tendsto.const_mul`를 조합합니다).

.해답 보기
[%collapsible]
====
[source,lean]
----
example : Tendsto (fun n : ℕ => (2 : ℝ) / (n + 1)) atTop (𝓝 0) := by
  have h := tendsto_one_div_add_atTop_nhds_zero_nat
  have h2 := h.const_mul (2 : ℝ)
  simp only [mul_zero] at h2
  convert h2 using 1
  ext n
  ring
----
====

== 요약

* `Tendsto f atTop (𝓝 l)`는 "`f`가 `l`로 수렴한다"는 뜻이고, 손으로 배운 엡실론-N 논법을 압축한 표현입니다.
* 극한의 선형성(합의 극한이 극한의 합)과 유일성 같은 정리를 Mathlib에서 이름으로 바로 가져다 씁니다.
* `Tendsto`의 정의를 직접 엡실론-N 논법으로 풀어씀으로써, 두 언어가 같은 것을 말한다는 걸 확인했습니다.
