== 부분집합: 원소 하나를 잡고 보이기

[source,lean]
----
example (A B C : Set ℕ) (h1 : A ⊆ B) (h2 : B ⊆ C) : A ⊆ C := by
  intro x hx
  exact h2 (h1 hx)
----

`A ⊆ B`는 정의상 `∀ x, x ∈ A → x ∈ B`입니다 — 2장에서 다룬 "전칭과 함의"가 그대로입니다. `intro x hx`로 "임의의 원소 `x`와 `x ∈ A`라는 증거"를 받아서, `x ∈ C`를 보이면 됩니다. `h1 hx`가 `x ∈ B`(A의 원소니 B의 원소)를, `h2 (h1 hx)`가 `x ∈ C`(B의 원소니 C의 원소)를 줍니다 — 함수 적용을 두 번 이어붙인 것뿐입니다.

== 교집합·합집합의 원소 자격

[source,lean]
----
example (A B : Set ℕ) (x : ℕ) (h : x ∈ A ∩ B) : x ∈ A ∧ x ∈ B := h

example (A B : Set ℕ) (x : ℕ) (h : x ∈ A) : x ∈ A ∪ B := Or.inl h
----

`x ∈ A ∩ B`는 **정의상** `x ∈ A ∧ x ∈ B`이고, `x ∈ A ∪ B`는 **정의상** `x ∈ A ∨ x ∈ B`입니다 — 그래서 첫 번째 예제는 `h` 그 자체가 이미 원하는 증거이고(둘이 정의상 같은 것이니까요), 두 번째 예제는 2장의 `Or.inl`을 그대로 씁니다. 집합 연산자(`∩`, `∪`)가 결국 논리 연산자(`∧`, `∨`)의 다른 표기법일 뿐이라는 걸 보여줍니다.

== 집합 등식: ext로 "원소 자격의 동치"로 바꾸기

[source,lean]
----
example (A B : Set ℕ) : A ∩ B = B ∩ A := by
  ext x
  constructor
  · intro ⟨ha, hb⟩; exact ⟨hb, ha⟩
  · intro ⟨hb, ha⟩; exact ⟨ha, hb⟩
----

두 집합이 같다는 걸 어떻게 증명할까요 — **두 집합은 정확히 같은 원소들을 가질 때 같다**는 원칙(외연성, extensionality)을 씁니다. `ext x`가 "임의의 원소 `x`를 잡고, `x ∈ (A ∩ B) ↔ x ∈ (B ∩ A)`를 보여라"로 목표를 바꿔줍니다 — 집합 등식 증명이 2장에서 배운 `↔` 증명(`constructor`로 양방향 쪼개기)으로 환원되는 순간입니다. `A ∩ B`가 `A ∧ B`인 순서를 뒤집어 `B ∩ A`(`B ∧ A`)로 바꾸는 건, `⟨ha, hb⟩`를 `⟨hb, ha⟩`로 재배치하는 것뿐입니다.

== 분배법칙도 같은 패턴으로

[source,lean]
----
example (A B C : Set ℕ) : A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) := by
  ext x
  simp only [mem_inter_iff, mem_union]
  constructor
  · rintro ⟨ha, hb | hc⟩
    · exact Or.inl ⟨ha, hb⟩
    · exact Or.inr ⟨ha, hc⟩
  · rintro (⟨ha, hb⟩ | ⟨ha, hc⟩)
    · exact ⟨ha, Or.inl hb⟩
    · exact ⟨ha, Or.inr hc⟩
----

`A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)`(교집합이 합집합에 분배된다)도 같은 흐름입니다 — `ext x`로 원소 자격의 동치로 바꾸고, `mem_inter_iff`/`mem_union`(각각 `∈ ∩`, `∈ ∪`를 `∧`, `∨`로 풀어주는 Mathlib 보조정리)으로 순수한 논리식으로 만든 뒤, 2장의 논리곱·논리합 다루는 패턴을 그대로 적용합니다. `rintro ⟨ha, hb | hc⟩`는 `obtain`과 `rcases`를 한 번에 섞은 문법입니다 — "먼저 `∧`로 짝을 풀고, 그 안의 `∨`도 동시에 경우 나누기"를 한 줄로 처리합니다.

== 여집합과 드모르간 법칙

[source,lean]
----
example (A B : Set ℕ) : (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ := by
  ext x
  simp [mem_compl_iff, mem_inter_iff, mem_union]
  tauto
----

`(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ`(드모르간 법칙)도 같은 방식으로 원소 자격의 동치 문제로 바뀌는데, 이번엔 마지막을 `tauto`(순수한 명제 논리 항등식을 자동으로 증명하는 전술)로 마무리했습니다 — `¬(P ∧ Q) ↔ ¬P ∨ ¬Q`라는 사실 자체가 순수한 논리적 항등식이라, 손으로 `constructor`/`rcases`를 쓰는 대신 `tauto`에 맡기는 게 더 간결합니다. 앞의 두 예제를 손으로 풀어본 뒤에야 `tauto`가 뒤에서 정확히 같은 일을 자동화하고 있다는 걸 알아볼 수 있습니다.

== 왜 "정의상 같다"는 사실이 중요한가

이 장의 모든 증명이 결국 2장(논리 연산자)으로 돌아간다는 게 핵심입니다 — `x ∈ A ∩ B`가 **정의상** `x ∈ A ∧ x ∈ B`이기 때문에, 집합에 대한 증명이 논리에 대한 증명으로 그대로 번역됩니다. 이후 장(6~7장의 함수, 3부의 정수론)에서도 이 패턴이 계속 반복됩니다 — 새로운 개념처럼 보이는 것도 뜯어보면 이미 아는 논리 연산자의 조합인 경우가 많습니다.

== 직접 해보기

* `(A B : Set ℕ) : A \ B = A ∩ Bᶜ`(차집합이 교집합과 여집합으로 표현된다는 것)를 `ext`로 증명해보세요.

.해답 보기

====
[source,lean]
----
example (A B : Set ℕ) : A \ B = A ∩ Bᶜ := by
  ext x
  simp only [mem_diff, mem_inter_iff, mem_compl_iff]
----
====

== 요약

* `A ⊆ B`는 정의상 `∀ x, x ∈ A → x ∈ B`이니, `intro`로 원소를 잡고 그 원소가 `B`에도 속한다는 걸 보이면 됩니다.
* `∈ ∩`, `∈ ∪`, `∈ᶜ`는 각각 `∧`, `∨`, `¬`의 다른 표기법일 뿐입니다.
* 집합 등식은 `ext x`로 "원소 자격의 동치(`↔`)"로 환원되고, 그 뒤로는 2장에서 익힌 논리 연산자 다루는 패턴이 그대로 적용됩니다.
