16장에서 "`n`이 무한대로 갈 때 수열이 어디로 향하는가"를 `Tendsto`로 다뤘습니다. 연속함수는 "`x`가 한 점 `a`로 가까워질 때 `f x`가 `f a`로 향하는가"를 묻는 것뿐입니다 — 같은 `Tendsto` 언어를, `atTop` 대신 "`a`의 근방"이라는 필터로 바꿔 쓰면 됩니다.

== Continuous: 정의역 전체에서 연속

[source,lean]
----
example : Continuous (fun x : ℝ => x + 1) := by continuity

example : Continuous (fun x : ℝ => x * x) := by continuity
----

`Continuous f`는 "`f`가 정의역의 모든 점에서 연속이다"라는 뜻입니다. `continuity`라는 전술이 다항식처럼 뻔히 연속인 함수들을 자동으로 증명해줍니다 — 3장의 `ring`이 다항식 항등식을 자동으로 처리했던 것과 같은 역할을, 이번엔 연속성 증명에서 해줍니다.

== 연속함수의 합과 합성

[source,lean]
----
example (f g : ℝ → ℝ) (hf : Continuous f) (hg : Continuous g) :
    Continuous (fun x => f x + g x) := hf.add hg

example (f g : ℝ → ℝ) (hf : Continuous f) (hg : Continuous g) :
    Continuous (fun x => f (g x)) := hf.comp hg
----

두 연속함수의 합도 연속이고(`hf.add hg`), 두 연속함수의 합성도 연속입니다(`hf.comp hg`). 15장에서 "선형사상의 합성은 다시 선형사상"이라고 했고, 12장에서 "준동형사상의 합성은 다시 준동형사상"이라고 했던 것과 같은 패턴이 여기서도 반복됩니다 — **구조를 보존하는 함수들은 합성해도 그 구조를 보존한다**는 게 이 책 전체에서 몇 번이고 되풀이해 확인한 원리입니다. 연속성도 예외가 아닙니다.

== ContinuousAt과 Tendsto의 관계

[source,lean]
----
example (f : ℝ → ℝ) (a : ℝ) (hf : Continuous f) : ContinuousAt f a := hf.continuousAt

example (f : ℝ → ℝ) (a : ℝ) (h : ContinuousAt f a) :
    Tendsto f (𝓝 a) (𝓝 (f a)) := h
----

`ContinuousAt f a`("`f`가 점 `a`에서 연속이다")는 사실 정의 그 자체가 `Tendsto f (𝓝 a) (𝓝 (f a))`입니다 — "`x`가 `a`의 근방(`𝓝 a`)에 있을 때 `f x`가 `f a`의 근방(`𝓝 (f a)`)으로 향한다"는 것과, "`f`가 `a`에서 연속이다"는 게 정의상 완전히 같은 문장입니다(`h` 자체가 이미 원하는 증거인 것에서 이걸 볼 수 있습니다). 16장에서 수열의 극한이 `Tendsto f atTop (𝓝 l)`이었다면, 연속은 `Tendsto f (𝓝 a) (𝓝 (f a))`입니다 — `atTop`(무한대로 가는 상황)이 `𝓝 a`(한 점에 가까워지는 상황)로 바뀌었을 뿐, **같은 `Tendsto`라는 틀**을 그대로 재사용하고 있습니다. 이게 16장 끝에서 예고했던 "필터라는 언어의 일반성"이 실제로 작동하는 모습입니다.

== 직접 확인하기: 연속이 엡실론-델타 논법과 같다는 것

[source,lean]
----
example : ∀ ε > (0:ℝ), ∃ δ > (0:ℝ), ∀ x : ℝ, |x - 2| < δ → |(x + 1) - 3| < ε := by
  intro ε hε
  use ε, hε
  intro x hx
  have : x + 1 - 3 = x - 2 := by ring
  rw [this]
  exact hx
----

이 증명이 "`f(x) = x+1`이 점 `x=2`에서 연속이다"라는 걸 손으로 배운 엡실론-델타 논법 그대로 증명한 것입니다 — "임의의 오차 `ε`에 대해, `x`가 `2`로부터 `δ` 안에 있으면 `f x`가 `f 2 = 3`으로부터 `ε` 안에 있게 하는 `δ`가 존재한다"는 문장입니다. `f(x) - 3 = (x+1) - 3 = x - 2`(`ring`으로 확인)라는 계산 덕분에, 이 경우 `δ`를 `ε` 자신으로 잡으면 충분합니다. 16장에서 수열의 극한을 엡실론-N으로 직접 풀어썼던 것과 정확히 같은 방식으로, 연속도 `ContinuousAt`이라는 압축된 표현 뒤에 엡실론-델타 논법이 그대로 숨어 있다는 걸 확인했습니다.

== 6부를 마무리하며

16~17장에서 다룬 것은 결국 하나입니다 — "어떤 값에 한없이 가까워진다"는 직관을, `Tendsto`라는 하나의 개념(그리고 그 뒤에 있는 필터)으로 통일해서 표현하고, 그게 `atTop`이면 수열의 극한, `𝓝 a`이면 함수의 연속이 된다는 것입니다. 1장부터 여기까지 오면서 이 책이 반복해서 보여준 태도 — 구체적인 계산(엡실론-N, 엡실론-델타)과 추상적인 개념(`Tendsto`, `Continuous`)이 서로 다른 게 아니라 같은 것의 다른 얼굴이라는 것 — 이 해석학에서도 그대로 성립합니다.

== 직접 해보기

* `f(x) = 2x`가 `x = 3`에서 연속이라는 것을 엡실론-델타 논법으로 직접 증명해보세요(힌트: `δ`를 `ε/2`로 잡습니다).

.해답 보기
[%collapsible]
====
[source,lean]
----
example : ∀ ε > (0:ℝ), ∃ δ > (0:ℝ), ∀ x : ℝ, |x - 3| < δ → |2 * x - 6| < ε := by
  intro ε hε
  use ε / 2, by linarith
  intro x hx
  have : 2 * x - 6 = 2 * (x - 3) := by ring
  rw [this, abs_mul]
  have h2 : |(2:ℝ)| = 2 := by norm_num
  rw [h2]
  linarith
----
====

== 요약

* `Continuous f`는 정의역 전체에서의 연속성이고, `continuity` 전술이 다항식 같은 뻔한 사례를 자동으로 처리해줍니다.
* 연속함수의 합과 합성이 다시 연속이라는 건, 이 책에서 반복된 "구조 보존 함수의 합성은 구조를 보존한다"는 원리의 또 다른 사례입니다.
* `ContinuousAt f a`는 정의상 `Tendsto f (𝓝 a) (𝓝 (f a))`이고, 이는 16장의 `Tendsto f atTop (𝓝 l)`와 같은 틀을 `atTop` 대신 `𝓝 a`로 바꿔 재사용한 것입니다.
* 이 정의를 엡실론-델타 논법으로 직접 풀어써서, 두 언어가 같은 것을 말한다는 걸 확인했습니다.
