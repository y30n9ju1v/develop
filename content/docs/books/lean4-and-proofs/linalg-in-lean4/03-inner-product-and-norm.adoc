'''

지금까지는 벡터를 더하고 조합하는 법만 다뤘고, "이 벡터가 얼마나 큰지", "두 벡터가 얼마나 비슷한지"를 잴 방법은 없었습니다. 이 장에서 정의하는 내적과 노름이 그 역할을 합니다 — 내적은 두 벡터의 "닮은 정도"를 숫자 하나로, 노름은 벡터 하나의 "크기(길이)"를 숫자 하나로 압축합니다. 이 두 개념은 이후 책 전체의 기반이 됩니다: 4장의 각도·직교성, 6장의 최근접 이웃 탐색, 그리고 최종적으로 16장 PCA의 "이 방향으로 데이터가 얼마나 퍼져 있는가(분산)"라는 질문 자체가 내적을 이용한 계산으로 정의됩니다. 이 장에서 노름이 "항상 0 이상이고, 0이 되는 경우는 영벡터뿐"이라는 성질을 완전히 증명해두는 것도 이 때문입니다 — 노름을 "거리"나 "크기"로 쓰려면 이 성질이 반드시 필요하고, 이게 없으면 16장에서 "이 방향의 분산이 0이다"라는 것을 증명해도 실제로 데이터가 그 방향으로 퍼져 있지 않다고 결론지을 근거가 없어집니다. 즉 이 장은 단순히 계산 공식(내적, 제곱근) 두 개를 정의하는 게 아니라, 그 공식이 "크기"라는 이름에 걸맞은 자격이 있는지를 증명으로 보장해두는 장입니다.

== 내적: 두 벡터를 하나의 숫자로

내적(inner product)은 두 벡터를 받아 실수 하나를 돌려주는 연산입니다 — 같은 위치의 성분끼리 곱한 뒤 전부 더합니다.

[source,lean]
----
-- Vectors/InnerProduct.lean
import Vectors.LinearCombination

namespace LinAlg.Vec

def inner {n : ℕ} (u v : Vec n) : ℝ := ∑ i, u i * v i

scoped infixl:72 " ⬝ " => inner

end LinAlg.Vec
----

로봇 예제에서, 하루치 구간별 거리 벡터와 "각 구간의 난이도 가중치" 벡터의 내적을 계산하면 "난이도로 보정한 하루치 주행량" 같은 단일 숫자가 나옵니다 — 여러 성분으로 흩어진 정보를 하나의 대표값으로 압축하는 것이 내적의 전형적인 쓰임입니다.

== 노름: 자기 자신과의 내적에서 유도되는 길이

벡터 `v`를 자기 자신과 내적하면 `∑ i, v i * v i = ∑ i, (v i)²`이 됩니다 — 모든 항이 제곱이라 각 항이 음이 아니고, 따라서 이 합도 음이 아닙니다. 이 값의 제곱근을 벡터의 **노름(norm, 길이)**이라 부릅니다.

[source,lean]
----
namespace LinAlg.Vec

noncomputable def norm {n : ℕ} (v : Vec n) : ℝ := Real.sqrt (v ⬝ v)

scoped notation "‖" v "‖" => norm v

end LinAlg.Vec
----

`noncomputable`이 붙은 이유를 짚어둘 만합니다 — Lean4는 기본적으로 모든 `def`가 실제로 값을 계산해낼 수 있는(computable) 알고리즘이기를 기대하는데, `Real.sqrt`는 일반적인 실수에 대해 유한 단계로 정확한 값을 계산할 수 없습니다(실수 자체가 유한하게 표현되지 않으므로). 그래서 `Real.sqrt`에 의존하는 정의는 전부 `noncomputable`로 표시해서 "이 정의는 증명에는 쓰지만 프로그램으로 실행하지는 않는다"는 것을 Lean에게 알려줘야 합니다 — 이 책의 목적이 증명이지 실제 수치 계산이 아니므로 문제가 되지 않습니다.

로봇 예제에서 노름은 정확히 "직선 거리로 환산한 하루치 이동 크기"에 해당합니다 — 5개 구간을 각각 3.2, 1.5, 4.0, 0.8, 2.1km씩 이동했다면, 그 벡터의 노름은 각 구간을 독립적인 축으로 볼 때의 유클리드 거리입니다.

== 노름이 항상 음이 아니라는 것

노름을 실제로 "길이"라고 부르려면, 먼저 노름이 항상 0 이상이어야 하고, 0이 되는 경우는 오직 영벡터뿐이어야 합니다. 이 두 성질을 증명합니다.

=== 완전히 증명하는 것: 노름의 음이 아님과 영벡터 특징화

[source,lean]
----
namespace LinAlg.Vec

theorem inner_self_nonneg {n : ℕ} (v : Vec n) : 0 ≤ v ⬝ v := by
  show 0 ≤ ∑ i, v i * v i
  apply Finset.sum_nonneg
  intro i _
  exact mul_self_nonneg (v i)

theorem norm_nonneg {n : ℕ} (v : Vec n) : 0 ≤ ‖v‖ :=
  Real.sqrt_nonneg (v ⬝ v)

theorem norm_eq_zero_iff {n : ℕ} (v : Vec n) : ‖v‖ = 0 ↔ v = 0 := by
  constructor
  · intro h
    have hself : v ⬝ v = 0 := by
      have := Real.sqrt_eq_zero (inner_self_nonneg v) |>.mp h
      exact this
    funext i
    have hi : v i * v i = 0 := by
      have hsum := hself
      unfold inner at hsum
      have hnonneg : ∀ j ∈ Finset.univ, 0 ≤ v j * v j := fun j _ => mul_self_nonneg (v j)
      exact (Finset.sum_eq_zero_iff_of_nonneg hnonneg).mp hsum i (Finset.mem_univ i)
    show v i = (0:ℝ)
    exact mul_self_eq_zero.mp hi
  · intro h
    subst h
    show Real.sqrt (∑ _i : Fin n, (0:ℝ) * 0) = 0
    simp

end LinAlg.Vec
----

이 증명이 이 장에서 가장 긴 증명인 이유는, "합이 0이면 (음이 아닌 항들의 합이므로) 각 항이 개별적으로 0이어야 한다"는 단계(`Finset.sum_eq_zero_iff_of_nonneg`)가 새로 필요하기 때문입니다. 1~2장의 정리들은 "정의를 펼치면 바로 실수의 성질로 환원"되는 얕은 증명이었지만, 이 정리는 "합 전체가 0"이라는 정보에서 "합을 이루는 개별 항이 0"이라는 더 강한 정보를 끌어내야 합니다 — 이건 각 항이 음이 아니라는 사실(`inner_self_nonneg`의 증명 과정에서 이미 확인한 것)이 있어야만 성립하는 추론입니다. 만약 항들이 음수가 될 수 있었다면(예를 들어 `u ⬝ v`처럼 서로 다른 벡터의 내적이었다면) 합이 0이어도 각 항이 0이라고 결론지을 수 없습니다 — 양수 항과 음수 항이 서로 상쇄될 수 있기 때문입니다. 노름의 이 성질이 "자기 자신과의 내적"이라는 특수한 경우에서만 성립한다는 것을 증명 과정 자체가 보여줍니다.

== 스칼라곱과 노름의 관계

노름에 스칼라를 곱했을 때 어떻게 변하는지도 이 장에서 확인하고 넘어갈 만한 성질입니다 — `‖cv‖ = |c| ‖v‖`입니다. 이건 로봇 예제에서 "모든 구간의 거리를 2배로 늘리면, 전체 이동 크기(노름)도 정확히 2배가 된다"는 직관과 일치합니다.

=== 연습 문제로 남기는 것: 스칼라곱의 노름

[source,lean]
----
namespace LinAlg.Vec

theorem norm_smul {n : ℕ} (c : ℝ) (v : Vec n) : ‖c • v‖ = |c| * ‖v‖ := by
  sorry
  -- 힌트: (c • v) ⬝ (c • v) = c² * (v ⬝ v)임을 먼저 보이고(정의 전개 + Finset.sum과 곱셈 재배열),
  -- Real.sqrt (c² * x) = |c| * Real.sqrt x (x ≥ 0일 때)라는 Mathlib 정리
  -- (Real.sqrt_mul, Real.sqrt_sq_eq_abs 조합)를 적용합니다.

end LinAlg.Vec
----

이 증명은 두 단계로 나뉩니다 — 먼저 내적 안에서 `c`를 밖으로 빼내는 대수적 조작(`norm_eq_zero_iff` 증명에서 봤던 것과 비슷하게 `Finset.sum`과 곱셈을 재배열하는 작업), 그다음 `Real.sqrt`가 곱을 어떻게 다루는지에 대한 Mathlib 정리를 적용하는 것입니다. 막힌다면 두 단계를 분리해서, 먼저 `(c • v) ⬝ (c • v) = c^2 * (v ⬝ v)`만 별도 보조정리로 증명해보는 것을 권합니다.

== 이 장에서 확정한 것

* 내적을 성분별 곱의 합으로, 노름을 자기 자신과의 내적의 제곱근으로 정의했습니다.
* 노름이 항상 음이 아니라는 것과, 노름이 0인 경우는 오직 영벡터뿐이라는 것을 완전히 증명했습니다 — 이 과정에서 "합이 0이면 음이 아닌 각 항도 0"이라는, 앞 장들에는 없던 새로운 추론 패턴을 확인했습니다.
* 스칼라곱이 노름에 미치는 영향(`‖cv‖ = |c|‖v‖`)을 연습 문제로 남겼습니다.
