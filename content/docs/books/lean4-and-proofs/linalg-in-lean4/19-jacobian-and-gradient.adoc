딥러닝의 학습은 결국 손실함수를 최소화하는 것이고, 그 최소화는 경사하강법 — 손실함수의 **경사(gradient)**를 따라 파라미터를 조금씩 옮기는 것 — 으로 이뤄집니다. 이 책은 지금까지 극한이나 미분의 정의를 한 번도 들여오지 않고 순수하게 대수적 전개만으로 정리를 증명해왔는데, 이 장은 그 원칙을 경사에도 그대로 적용합니다 — 극한을 취하지 않고도, 순수한 대수적 전개만으로 "이차형식의 경사가 `(A+Aᵀ)x`"라는 사실을 증명합니다. 그리고 신경망이 왜 "행렬 곱셈의 연쇄"로 이해되는지, 그 역전파(backpropagation)가 왜 결국 9장의 결합법칙으로 정당화되는 계산인지를 이 책의 마지막 장에서 확인합니다.

== 스칼라를 내는 함수: 이차형식

`n×n` 행렬 `A`와 벡터 `x`에 대해, **이차형식(quadratic form)** `f(x) = x ⬝ (A *ᵥ x)`는 벡터를 받아 스칼라 하나를 내는 함수입니다. 이 함수가 왜 딥러닝과 관련 있는지는 바로 보입니다 — 딥러닝의 MSE(평균제곱오차) 손실 `‖Ax-b‖²`(12장에서 최소자승법의 목적함수로도 봤던 바로 그 형태입니다)를 전개하면 `x`에 대한 이차형식이 나옵니다.

[source,lean]
----
-- Calculus/QuadraticForm.lean
import Eigen.PCA

namespace LinAlg
open Vec

def quadForm {n : ℕ} (A : Mat n n) (x : Vec n) : ℝ := x ⬝ (A *ᵥ x)

end LinAlg
----

== 완전히 증명하는 것: 방향을 따라 전개하기

미분을 쓰지 않고 "경사"를 정의하는 방법은, `f(x)`가 `x`에서 어떤 방향 `v`로 조금 움직였을 때 얼마나 변하는지를 **정확한 대수적 등식**으로 펼치는 것입니다 — 극한을 취하지 않고도, `t`의 1차항 계수가 정확히 경사 방향을 알려줍니다.

[source,lean]
----
namespace LinAlg
open Vec

theorem quadForm_expand {n : ℕ} (A : Mat n n) (x v : Vec n) (t : ℝ) :
    quadForm A (x + t • v) =
      quadForm A x + t * (v ⬝ ((A + Aᵀ) *ᵥ x)) + t ^ 2 * quadForm A v := by
  show (x + t • v) ⬝ (A *ᵥ (x + t • v)) =
    x ⬝ (A *ᵥ x) + t * (v ⬝ ((A + Aᵀ) *ᵥ x)) + t ^ 2 * (v ⬝ (A *ᵥ v))
  sorry
  -- 힌트: 8장의 mulVec_add/mulVec_smul로 A *ᵥ (x + t•v) = A*ᵥx + t•(A*ᵥv)로 펼치고,
  -- 내적의 분배법칙(1~3장에서 반복한 성분별 전개)으로 좌변을 네 항으로 나눕니다:
  --   x⬝(A*ᵥx) + t*(x⬝(A*ᵥv)) + t*(v⬝(A*ᵥx)) + t²*(v⬝(A*ᵥv))
  -- 가운데 두 항(x⬝(A*ᵥv)와 v⬝(A*ᵥx))을 16장의 mulVec_inner_eq_inner_transpose_mulVec로
  -- 하나는 x⬝(A*ᵥv) = v⬝(Aᵀ*ᵥx) 형태로 바꾸면, t*(v⬝(Aᵀ*ᵥx)) + t*(v⬝(A*ᵥx))가 되고,
  -- 이건 t*(v⬝((A+Aᵀ)*ᵥx))로 다시 묶입니다(내적의 분배법칙을 거꾸로).

end LinAlg
----

이 등식이 뜻하는 바가 핵심입니다 — `f(x+tv)`를 `t`의 다항식으로 보면, 상수항은 `f(x)` 자신이고, `t¹`의 계수는 `v ⬝ ((A+Aᵀ)x)`이고, `t²`의 계수는 `quadForm A v`(`v`에만 의존하고 `x`와는 무관)입니다. 미분의 언어로 "방향 `v`로의 방향미분"이라 부르는 게 정확히 이 `t¹` 계수이고, 그 계수가 **모든 `v`에 대해** `v ⬝ ((A+Aᵀ)x)` 형태(고정된 벡터 `(A+Aᵀ)x`와 `v`의 내적)로 나온다는 사실 자체가 "**경사(gradient)는 `(A+Aᵀ)x`**"라는 정의입니다. 함수를 기준점에서 방향을 따라 전개해 상수항·1차항·2차항으로 나누는 이 방식은, 4장에서 코시-슈바르츠 부등식을 증명할 때 `‖u - t•v‖²`를 `t`에 대한 이차식으로 펼쳤던 것과 본질적으로 같은 전개 방식입니다.

=== 따름정리: 대칭행렬이면 경사는 2Ax

`A`가 대칭(`Aᵀ = A`, 10장의 `IsSymmetric`)이면 `(A+Aᵀ)x = 2Ax`이므로, 경사는 정확히 `2Ax`입니다 — 통계·최적화에서 "이차형식의 경사는 `2Ax`"라고 외우는 그 공식이, 여기서는 `A`가 대칭이라는 조건 아래 방금 증명한 일반 등식의 특수한 경우로 나옵니다.

[source,lean]
----
namespace LinAlg
open Vec

theorem quadForm_expand_symmetric {n : ℕ} (A : Mat n n) (x v : Vec n) (t : ℝ)
    (hsym : Mat.IsSymmetric A) :
    quadForm A (x + t • v) = quadForm A x + t * (v ⬝ ((2:ℝ) • (A *ᵥ x))) + t ^ 2 * quadForm A v := by
  have h := quadForm_expand A x v t
  rw [h]
  have vecEq : (A + Aᵀ) *ᵥ x = (2:ℝ) • (A *ᵥ x) := by
    funext i
    unfold Mat.IsSymmetric at hsym
    show (∑ j, (A i j + Aᵀ i j) * x j) = 2 * ∑ j, A i j * x j
    rw [hsym]
    show (∑ j, (A i j + A i j) * x j) = 2 * ∑ j, A i j * x j
    rw [Finset.mul_sum]
    congr 1; funext j; ring
  rw [vecEq]

end LinAlg
----

== 선형 사상의 야코비안은 그 자신이다

**야코비안(Jacobian)**은 스칼라 하나가 아니라 벡터를 내는 함수의 "다변수 기울기"입니다 — `f : Vec n → Vec m`의 야코비안은 `m×n` 행렬로, `(i,j)` 성분이 "`i`번째 출력이 `j`번째 입력에 얼마나 민감한가"를 나타냅니다. 일반적인 비선형 함수는 야코비안이 점마다 다르지만, `f(x) = A *ᵥ x`처럼 함수 자체가 선형이면 야코비안은 어디서나 똑같고, **그 행렬 자신** `A`입니다 — 8장의 선형성(`A(x+v) = Ax + Av`) 자체가 "`A`를 기준점 `x`에서 방향 `v`로 움직였을 때 정확히 `Av`만큼 바뀐다"는 뜻이고, 이게 정확히 야코비안의 정의입니다. 이 사실은 별도로 증명할 게 없습니다 — 8장의 `mulVec_add`가 이미 증명한 내용을 "야코비안"이라는 새 이름으로 다시 읽은 것뿐입니다.

== 사슬법칙 = 행렬 곱셈

신경망의 한 층이 `y = A *ᵥ x`(선형 층 하나만 떼어놓고 보면)라면, 두 층을 이어붙인 `z = B *ᵥ (A *ᵥ x)`의 야코비안은 무엇일까요? 미분의 사슬법칙(chain rule)은 "합성함수의 야코비안은 각 단계 야코비안의 곱"이라고 말하는데, 방금 확인했듯 선형 층의 야코비안은 그 자신(`A`, `B`)이므로, 합성의 야코비안은 `B * A`입니다 — 이건 9장에서 정의한 행렬 곱셈 그 자체입니다.

[source,lean]
----
namespace LinAlg

theorem jacobian_of_composition {m n p : ℕ} (A : Mat n p) (B : Mat m n) (x : Vec p) :
    B *ᵥ (A *ᵥ x) = (B * A) *ᵥ x := by
  funext i
  show (∑ k, B i k * (∑ j, A k j * x j)) = ∑ j, (∑ k, B i k * A k j) * x j
  simp only [Finset.mul_sum, Finset.sum_mul]
  rw [Finset.sum_comm]
  congr 1; funext j
  congr 1; funext k
  ring

end LinAlg
----

이 증명은 9장의 `Mat.mul_assoc`, 15장의 결합성 보조정리와 글자 그대로 같은 구조(이중 합을 풀고 `Finset.sum_comm`으로 순서를 바꾼다)입니다 — 왜냐하면 실제로 같은 사실의 다른 이름이기 때문입니다. 신경망을 층층이 쌓고 역전파로 그레이디언트를 전달하는 것은, 각 층의 (선형 부분에 대한) 야코비안을 뒤에서부터 순서대로 곱해나가는 것과 같고, 그게 정당한 이유는 정확히 이 정리 — "합성의 야코비안은 야코비안의 곱"이며 그 곱셈이 (9장에서 증명했듯) 결합법칙을 만족한다는 것 — 때문입니다. 실제 신경망은 층 사이에 비선형 활성화 함수(ReLU, 시그모이드 등)가 끼어 있어 야코비안이 매 지점마다 달라지지만, 그 경우에도 사슬법칙 자체("합성의 야코비안은 야코비안들의 곱")는 그대로 성립합니다 — 다만 그 야코비안이 더 이상 고정된 행렬이 아니라 지점마다 계산해야 하는 행렬이 된다는 차이가 있을 뿐입니다. 이 확장(비선형 함수의 야코비안을 실제로 계산하는 것)은 미적분학의 도구가 필요해 이 책의 범위 밖입니다.

== 이 책 전체를 돌아보며

1장에서 벡터의 덧셈이 교환법칙을 만족한다는, 거의 자명해 보이는 사실을 증명하는 것부터 시작했습니다. 그 짧은 증명에서 세운 패턴(`funext`로 성분에 대한 명제로 좁히고, 실수의 성질로 환원한다)이 2부의 행렬로, 3부의 고유값·대각화로, 4부의 동차좌표·SVD·야코비안으로 이름을 바꿔가며 계속 재사용됐습니다. 10장에서 증명한 `AᵀA`의 대칭성은 16장에서 공분산 행렬의 고유벡터가 직교한다는 것과, 18장에서 특이값 문제가 대칭행렬의 고유분해로 환원된다는 것을 보장하는 결정적인 다리였습니다. 8장의 선형성(`mulVec_add`, `mulVec_smul`)은 13장의 고유공간, 14장의 대각화, 15장의 닮음변환, 17장의 동차행렬, 19장의 야코비안까지, 이 책 후반부 전체를 떠받쳤습니다. 그리고 9장의 결합법칙은 11장의 역행렬 유일성, 15장의 QR 알고리즘, 19장의 역전파 사슬법칙까지 — 서로 전혀 달라 보이는 결론들이 전부 "괄호를 옮겨도 결과가 같다"는 같은 사실 하나에서 나왔습니다.

이 책이 보여주고 싶었던 건 결국 하나입니다 — 선형대수의 정리들은 서로 동떨어진 사실의 나열이 아니라, 소수의 근본적인 아이디어(성분별 연산은 실수의 성질로 환원된다, 전치는 곱셈의 순서를 뒤집는다, 직교성은 독립적인 방향을 뜻한다, 선형성은 방향과 배율을 보존한다)가 문맥을 바꿔가며 계속 재등장하는 하나의 그물입니다. 그 그물의 매듭 하나하나를 Lean4로 직접 묶어보는 것이, "선형대수를 안다"는 것의 의미를 다시 세우는 이 책의 방법이었습니다.
