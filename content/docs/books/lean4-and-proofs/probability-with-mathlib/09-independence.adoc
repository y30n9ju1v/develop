3장에서 이산 확률에 대해 "결합 확률이 각자의 확률의 곱으로 갈라진다"는 걸로 독립성을 확인했습니다. 이 장에서는 이 정의를 일반적인 확률변수에 대한 `IndepFun`으로 다시 씁니다.

== IndepFun: 사건이 아니라 확률변수의 독립성

Mathlib은 두 확률변수 `f`, `g`가 독립이라는 것을 다음과 같이 정의합니다.

[source,lean]
----
theorem indepFun_iff_measure_inter_preimage_eq_mul :
    IndepFun f g μ ↔
      ∀ s t, MeasurableSet s → MeasurableSet t →
        μ (f ⁻¹' s ∩ g ⁻¹' t) = μ (f ⁻¹' s) * μ (g ⁻¹' t)
----

3장에서 `twoDice (a, b) = fairDie a * fairDie b`라는 **개별 결과**의 확률이 곱으로 갈라진다는 걸 봤다면, 이 정의는 그걸 **임의의 사건**(`s`, `t`라는 임의의 가측 부분집합)으로 확장한 것입니다 — "첫 번째 확률변수가 어떤 범위 `s`에 들어가고, 동시에 두 번째 확률변수가 어떤 범위 `t`에 들어갈 확률"이 항상 각자의 확률의 곱으로 갈라진다면, 두 확률변수는 독립입니다.

== 두 균등분포를 곱해 결합 측도 만들기

[source,lean]
----
theorem fst_snd_indep :
    IndepFun (Prod.fst : ℝ × ℝ → ℝ) Prod.snd (uniformMeasure.prod uniformMeasure) := by
  haveI : IsProbabilityMeasure uniformMeasure := by
    constructor
    simp [uniformMeasure, Measure.restrict_apply, Real.volume_Icc]
  rw [indepFun_iff_measure_inter_preimage_eq_mul]
  intro s t hs ht
  have hst : (Prod.fst ⁻¹' s ∩ Prod.snd ⁻¹' t : Set (ℝ × ℝ)) = s ×ˢ t := by
    ext p; simp [Set.mem_prod]
  rw [hst, Measure.prod_prod]
  have h1 : (Prod.fst ⁻¹' s : Set (ℝ × ℝ)) = s ×ˢ Set.univ := by ext p; simp
  have h2 : (Prod.snd ⁻¹' t : Set (ℝ × ℝ)) = Set.univ ×ˢ t := by ext p; simp
  rw [h1, h2, Measure.prod_prod, Measure.prod_prod]
  simp
----

`μ.prod ν`는 두 측도를 곱해 만든 **곱측도**입니다 — 직관적으로 "가로로 `μ`만큼, 세로로 `ν`만큼 넓이를 잰다"는 뜻입니다(4장에서 균등분포가 "길이"였다면, 곱측도는 "넓이"입니다). `uniformMeasure.prod uniformMeasure`는 `[0,1] × [0,1]` 정사각형 위의 균등분포이고, 이 장의 핵심 증명은 **이 정사각형에서 첫 번째 좌표(`Prod.fst`)와 두 번째 좌표(`Prod.snd`)가 서로 독립이다**라는 것입니다.

증명의 뼈대는 다음 세 가지 사실을 조합하는 것입니다.

* `Prod.fst⁻¹' s ∩ Prod.snd⁻¹' t = s ×ˢ t`: "첫 좌표가 `s`에 있고 둘째 좌표가 `t`에 있다"는 조건이 정확히 직사각형 `s ×ˢ t`입니다.
* `Measure.prod_prod`: 곱측도로 잰 직사각형의 측도는 정확히 각 변의 측도의 곱입니다(`(μ.prod ν)(s ×ˢ t) = μ s * ν t`) — 넓이가 "가로 곱하기 세로"라는 초등학교 때 배운 공식이 여기서 정확한 증명이 됩니다.
* `Prod.fst⁻¹' s = s ×ˢ Set.univ`, `Prod.snd⁻¹' t = Set.univ ×ˢ t`: 한쪽 좌표에만 조건을 거는 사건은, 다른 좌표가 아무 값이나 가능한 "무한히 긴 띠"라는 것.

이 셋을 합치면 `μ(f⁻¹'s ∩ g⁻¹'t) = μs·νt`와 `μ(f⁻¹'s)·μ(g⁻¹'t) = (μs·ν(univ))·(μ(univ)·νt) = μs·νt`(확률측도라 `ν(univ) = μ(univ) = 1`)가 정확히 같아집니다 — **곱측도로 결합한 두 좌표는 정의상 항상 독립**이라는, 어찌 보면 당연하지만 실제로 증명해볼 가치가 있는 사실입니다.

== 독립성의 강력한 결론: 곱의 기댓값은 기댓값의 곱

Mathlib은 독립성으로부터 나오는 강력한 결과도 이미 증명해뒀습니다 — `IndepFun.integral_mul_eq_mul_integral`이 "두 확률변수가 독립이면, 곱의 기댓값은 각자 기댓값의 곱과 같다"(`E[XY] = E[X]·E[Y]`)는 걸 보장합니다. 일반적으로 `E[XY] = E[X]·E[Y]`는 성립하지 않습니다(두 변수가 서로 얽혀 있으면 어긋납니다) — 독립성은 정확히 이 등식이 성립하도록 만들어주는 조건입니다. 이 정리는 다음 장의 조건부 확률, 그리고 4부의 큰 수의 법칙을 증명하는 데 핵심적인 역할을 합니다.

== 직접 해보기

* `fst_snd_indep`의 증명에서, `hst`(교집합이 직사각형이라는 사실)를 증명하지 않고 곧바로 `Measure.prod_prod`만 적용하려고 하면 왜 안 되는지 생각해보세요 — `Measure.prod_prod`가 어떤 모양의 집합에 대해서만 적용되는 정리인지 확인해보면 답이 보입니다.

.해답 보기
[%collapsible]
====
`Measure.prod_prod`는 `(μ.prod ν)(s ×ˢ t) = μ s * ν t`처럼, **직사각형 모양의 집합**에 대해서만 성립하는 정리입니다. `Prod.fst⁻¹' s ∩ Prod.snd⁻¹' t`라는 표현 자체는 이 정리가 기대하는 `s ×ˢ t` 모양이 아니라, "원상들의 교집합"이라는 다른 형태로 적혀 있습니다 — 두 표현이 사실 같은 집합을 가리키더라도, Lean은 문법적으로 같은 모양이어야 정리를 바로 적용할 수 있으므로, `hst`로 먼저 "이 두 표현이 실제로 같은 집합이다"라는 걸 증명해서 `Measure.prod_prod`가 적용될 수 있는 모양으로 바꿔줘야 합니다.
====

== 요약

* `IndepFun f g μ`는 "임의의 사건 `s`, `t`에 대해, 결합 확률이 각자의 확률의 곱으로 갈라진다"는 3장의 이산적 정의를 일반적인 확률변수로 확장한 것입니다.
* 두 확률측도를 곱측도(`μ.prod ν`)로 결합하면, 그 결과의 두 좌표는 항상 독립입니다 — `Measure.prod_prod`(직사각형의 측도는 가로×세로)가 이 사실의 핵심 근거입니다.
* 독립성은 `E[XY] = E[X]·E[Y]`(곱의 기댓값은 기댓값의 곱)를 보장하고, 이는 일반적으로는 성립하지 않는 강력한 등식입니다.

다음 장에서는 독립의 반대편, 즉 한 사건이 다른 사건에 영향을 줄 때 그 영향을 정확히 재는 조건부 확률과 조건부 기댓값을 다룹니다.
