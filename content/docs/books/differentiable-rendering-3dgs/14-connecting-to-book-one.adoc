'''

이 책은 1권 "사진에서 세계로"가 끝난 자리에서 시작했습니다 — 여러 장의 사진에서 카메라 포즈와 3D 점군을 재구성하는 방법을 다룬 책이었습니다. 지금까지 13개 장에 걸쳐 미분가능 렌더링과 3D Gaussian Splatting의 기초를 처음부터 구현해왔으니, 이제 이 두 책을 실제로 연결할 차례입니다 — **1권의 출력(점군 + 카메라)이 어떻게 이 책의 입력(가우시안 초기값)이 되는가**입니다.

== 왜 무작위 초기화로는 안 되는가

3DGS는 원칙적으로 아무 위치에나 흩뿌린 가우시안 무더기에서 시작해도 학습이 가능합니다 — 10~12장에서 배운 그래디언트와 적응적 밀도 제어만 있으면 이론적으로는 수렴할 수 있습니다. 하지만 실전에서는 이렇게 하지 않습니다. 6장에서 본 스펙트럴 편향처럼, 최적화는 "이미 정답에 가까운 곳에서 시작할수록" 훨씬 빠르고 안정적으로 수렴합니다. 1권의 SfM 파이프라인이 이미 계산해 놓은 점군은, 장면의 대략적인 3D 형태를 "공짜로" 알려주는 정보입니다 — 이걸 버리고 무작위로 시작할 이유가 없습니다.

== 1권의 출력 형식 재현하기

1권 9장(번들 조정)과 14장(재구성 품질 측정)의 결과물은 3D 점들의 좌표, 각 점의 색, 그리고 카메라의 내부 파라미터(`K`)와 자세(`R, t`)였습니다.

[source,python]
----
K = np.array([[400.0, 0, 16.0], [0, 400.0, 16.0], [0, 0, 1]])
R_cam, t_cam = np.eye(3), np.array([0.0, 0.0, 0.0])

points_world = np.vstack([pts_a, pts_b])   # "1권 파이프라인이 재구성했다"고 가정한 점 30개
colors = np.vstack([...])                   # 각 점의 색 (SfM에서 대응점의 픽셀 색으로부터 얻음)
----

== 점군 밀도로부터 초기 스케일 추정하기 (1권 14장 기법의 재사용)

1권 14장에서 이미 했던 작업을 그대로 가져옵니다 — `k`-d 트리로 각 점의 최근접 이웃까지의 거리를 재서, "이 점 주변이 얼마나 조밀한가"를 추정합니다. 조밀한 곳(이웃이 가까운 곳)은 작은 가우시안으로, 성긴 곳은 큰 가우시안으로 시작하는 게 합리적입니다.

[source,python]
----
from scipy.spatial import cKDTree

tree = cKDTree(points_world)
dists, _ = tree.query(points_world, k=5)
mean_nn_dist = dists[:, 1:].mean(axis=1)  # 자기 자신을 제외한 4개 최근접 거리의 평균
----

== 3D 점을 3DGS 가우시안 초기값으로 변환하기

이제 8장의 투영과 7장의 공분산 구성을 합쳐서, 점 하나하나를 초기 가우시안으로 바꿉니다.

[source,python]
----
def points_to_gaussians(points_world, colors, mean_nn_dist, K, R_cam, t_cam):
    gaussians = []
    for i in range(len(points_world)):
        X_cam = R_cam @ points_world[i] + t_cam
        mu_2d = project_point(K, X_cam)                       # 8장: 3D->2D 투영
        r_pixel = K[0, 0] * mean_nn_dist[i] / X_cam[2]         # 이웃 거리를 화면상의 크기로 변환
        Sigma_2d = np.eye(2) * max(r_pixel, 0.5) ** 2          # 7장: SPD를 보장하는 공분산 구성
        gaussians.append(SplatGaussian(mu_2d, Sigma_2d, X_cam[2], colors[i], opacity=0.8))
    return gaussians

init_gaussians = points_to_gaussians(points_world, colors, mean_nn_dist, K, R_cam, t_cam)
----

[source]
----
number of initial gaussians: 30
init image range: 6.5e-06 to 0.900
----

30개의 SfM 점이 30개의 초기 가우시안이 되고, 이걸 9장의 래스터라이저로 렌더링하면 이미 대략적인 장면 형태(두 군집의 위치와 색)를 보여주는 이미지가 나옵니다 — 학습을 시작하기도 전에 말입니다.

== 검증: SfM 기반 초기화가 무작위 초기화보다 훨씬 유리하다

같은 목표 이미지에 대해, SfM 점 기반 초기화와 완전히 무작위인 초기화의 **첫 손실**(학습을 한 스텝도 하지 않은 상태)을 비교합니다.

[source,python]
----
loss_sfm_init = l2_loss(img_init, target_img)

random_gaussians = [SplatGaussian(rng.uniform(4, 28, size=2), ...) for _ in range(30)]
img_random_init, _ = rasterize_full(random_gaussians, H, W)
loss_random_init = l2_loss(img_random_init, target_img)
----

[source]
----
loss with SfM-based init: 0.00038
loss with random init:    0.09840     (약 258배 더 큰 손실)
----

무작위로 흩뿌린 30개 가우시안은 목표와 거의 아무 관련이 없는 이미지를 만들어서 손실이 크지만, 1권의 SfM 파이프라인이 재구성한 점들의 위치를 그대로 물려받은 초기화는 학습을 시작하기도 전에 이미 목표에 `258`배 더 가깝습니다. 10~12장에서 배운 그래디언트 기반 학습은 이 지점에서부터 세부 사항(정확한 색, 정확한 모양, 표현력이 부족한 곳의 분열 등)을 다듬는 역할만 하면 됩니다.

== 두 책이 하나로 연결되는 지점

이 시리즈가 처음에 세운 목표(서문)를 돌아보면 이렇습니다:

* **1권**: 여러 장의 사진 → 카메라 포즈 + 3D 점군 (자율주행 차량이 주행하며 찍은 영상으로부터, "이 장면이 3D로 어떻게 생겼는가"의 대략적인 스켈레톤을 재구성)
* **2권(이 책)**: 3D 점군 + 카메라 포즈 → 학습 가능한 3D 가우시안들의 초기값 → 미분가능 렌더링으로 세부까지 다듬어진 3D 장면 표현

이렇게 완성된 3D 가우시안 장면은, 다시 임의의 새로운 카메라 위치에서 렌더링(9장의 래스터라이저)할 수 있습니다 — 이게 바로 이 책 시리즈의 최종 목적지였던 **"3DGS 기반 디지털 트윈을 이용한 자율주행 E2E 검증"**의 핵심 구성 요소입니다. 실제로 주행하지 않고도, 재구성된 3D 장면을 원하는 어떤 카메라 각도에서든 사실적으로 렌더링해서, 자율주행 소프트웨어가 그 렌더링된 영상에 어떻게 반응하는지 시뮬레이션으로 검증할 수 있게 되는 것입니다.

== 요약

* 3DGS는 무작위 초기화에서도 이론적으로 학습이 가능하지만, 실전에서는 SfM으로 재구성한 점군을 초기 가우시안 위치로 쓰는 것이 압도적으로 유리합니다 — 이 장에서 확인한 예시에서는 초기 손실이 `258`배 차이 났습니다.
* 1권 14장의 `k`-d 트리 기반 밀도 추정을 그대로 재사용해, 점군의 지역 밀도로부터 초기 가우시안의 스케일을 정할 수 있습니다.
* 1권의 카메라 포즈(`K, R, t`)와 8장의 투영 공식을 결합하면, 3D 점을 곧바로 화면 위의 초기 2D 가우시안으로 변환할 수 있습니다.
* 재구성이 성길수록(점이 적고 밀도가 낮을수록) 3DGS 학습의 출발점도 나빠진다는 것을 확인했습니다 — 1권의 재구성 품질이 2권의 학습 난이도에 직접 영향을 줍니다.

이것으로 1권 "사진에서 세계로"와 2권 "미분가능 렌더링과 3D Gaussian Splatting"이 하나의 파이프라인으로 이어졌습니다 — 사진들로부터 카메라와 점군을 재구성하고, 그 점군을 학습 가능한 3D 가우시안 장면으로 다듬는 전체 과정을 처음부터 끝까지 직접 구현하고 검증했습니다.
