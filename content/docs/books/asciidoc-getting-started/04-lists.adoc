== 순서 없는 목록

[source,asciidoc]
----
* 순서 없는 목록 1
* 순서 없는 목록 2
** 중첩 목록 2-1
** 중첩 목록 2-2
* 순서 없는 목록 3
----

`*`로 시작하는 줄이 목록 항목이 되고, `**`(별표 두 개)로 시작하면 한 단계 더 중첩됩니다 — 별표 개수가 그대로 중첩 깊이가 됩니다. 변환하면 `<ul>`/`<li>` 태그의 중첩 구조가 되고, 중첩된 목록은 부모 항목의 `<li>` 안에 다시 `<div class="ulist">`로 끼워집니다.

== 순서 있는 목록

[source,asciidoc]
----
. 순서 있는 목록 1
. 순서 있는 목록 2
.. 중첩 순서 목록 2-1
. 순서 있는 목록 3
----

`.`(마침표)로 시작하면 순서 있는 목록이고, `..`로 중첩합니다 — 흥미로운 점은 중첩된 순서 목록이 자동으로 알파벳(`a`, `b`, ...)으로 바뀐다는 것입니다(`class="loweralpha"`). 시작 번호를 바꾸고 싶다면 목록 앞에 `[start=N]`을 붙입니다.

[source,asciidoc]
----
[start=5]
. 5번부터 시작
. 6번
----

== 설명 목록

[source,asciidoc]
----
용어1:: 설명1
용어2:: 설명2
  여러 줄로도 씁니다
----

`용어::` 형태로 쓰면 "용어 — 설명" 쌍으로 이뤄진 설명 목록(definition list)이 됩니다. HTML의 `<dl>`/`<dt>`/`<dd>`로 변환되고, API 문서에서 매개변수를 설명하거나 용어집을 만들 때 특히 유용합니다.

== 체크리스트

[source,asciidoc]
----
* [ ] 할 일 체크박스
* [x] 완료된 체크박스
----

순서 없는 목록의 항목 앞에 `[ ]`나 `[x]`를 붙이면 체크박스가 있는 목록(`class="checklist"`)이 됩니다 — `[ ]`는 미완료(빈 사각형 문자로 렌더링), `[x]`는 완료(체크 문자로 렌더링)를 뜻합니다.

== 서로 다른 목록을 분리하려면 빈 줄이 필요하다

앞의 예제들을 한 파일에 이어붙일 때, 종류가 다른 목록(순서 없는 목록 뒤에 바로 순서 있는 목록) 사이에 **빈 줄 없이** 붙이면 AsciiDoc은 이걸 별개의 목록이 아니라 앞 목록의 **중첩**으로 잘못 해석합니다. 예를 들어 순서 없는 목록 바로 다음 줄에 순서 있는 목록을 붙이면, 순서 있는 목록 전체가 순서 없는 목록의 마지막 항목 안에 끼워 들어가 버립니다. 이 책 예제들처럼 종류가 다른 목록을 연달아 보여줄 때는 반드시 사이에 빈 줄(필요하면 `'''`처럼 구분선까지)을 둬야 각 목록이 독립된 블록으로 인식됩니다.

== 직접 해보기

* "과일"이라는 용어에 "사과, 바나나, 포도"를 순서 없는 중첩 목록으로 설명하는 설명 목록 항목을 만들어보세요.

.해답 보기
[%collapsible]
====
[source,asciidoc]
----
과일::
* 사과
* 바나나
* 포도
----

설명 목록의 설명 부분에도 다른 블록(여기서는 중첩된 순서 없는 목록)을 넣을 수 있습니다 — 용어 뒤에 바로 목록을 이어 쓰면 그 설명으로 인식됩니다.
====

== 요약

* 순서 없는 목록은 `*`, 순서 있는 목록은 `.`로 시작하고, 기호를 겹쳐 쓰면(`**`, `..`) 중첩됩니다.
* `[start=N]`으로 순서 있는 목록의 시작 번호를 바꿀 수 있습니다.
* `용어:: 설명` 형태로 설명 목록을, `[ ]`/`[x]`로 체크리스트를 만듭니다.
* 종류가 다른 목록 사이에는 반드시 빈 줄을 둬야 의도치 않은 중첩을 피할 수 있습니다.

1부가 여기서 끝났습니다. 2부에서는 섹션·표·이미지·admonition으로 문서를 구조화하는 법을 다룹니다.
