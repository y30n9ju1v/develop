== 제목의 레벨

AsciiDoc은 `=` 기호의 개수로 제목의 레벨을 표현합니다.

[source,asciidoc]
----
= 문서 제목
== 레벨 1 섹션(장)
=== 레벨 2 섹션(절)
==== 레벨 3 섹션
----

`=` 하나는 문서 전체의 제목(문서마다 한 번만)이고, `==`부터가 실제 섹션 제목입니다 — 이 책의 각 장이 `==`(장 제목)로 시작해서 필요하면 `===`(절)로 더 나뉘는 구조를 쓰고 있습니다. 변환하면 `= 제목`은 `<h1>`, `== 제목`은 `<h2>`, `=== 제목`은 `<h3>`로 매핑됩니다.

== 문단: 빈 줄이 경계다

[source,asciidoc]
----
첫 문단입니다.
여러 줄로 이어써도
하나의 문단으로 합쳐집니다.

빈 줄로 구분한 두 번째 문단입니다.
----

이 두 조각을 변환하면 이렇게 나옵니다.

[source,html]
----
<div class="paragraph">
<p>첫 문단입니다.
여러 줄로 이어써도
하나의 문단으로 합쳐집니다.</p>
</div>
<div class="paragraph">
<p>빈 줄로 구분한 두 번째 문단입니다.</p>
</div>
----

핵심은 **줄바꿈 자체는 문단을 나누지 않는다**는 것입니다 — 오직 빈 줄만 문단의 경계가 됩니다. 소스 파일 안에서는 여러 줄로 나눠 썼더라도, 실제 출력에서는 하나의 `<p>` 태그 안에 이어붙습니다(각 줄 사이에 줄바꿈 문자가 남는다는 점은 다르지만, "새 문단"으로 취급되지는 않습니다).

== 강제로 줄을 바꾸고 싶을 때

문단을 나누지 않으면서 눈에 보이는 줄바꿈만 넣고 싶다면, 줄 끝에 `+` 기호를 씁니다.

[source,asciidoc]
----
한 줄에 개행을 강제로 넣으려면 +
이렇게 줄 끝에 더하기 기호를 씁니다.
----

이건 `<br>` 태그로 변환됩니다 — 시(詩)나 주소를 쓸 때처럼, 문단은 하나로 유지하면서 줄바꿈만 보이게 하고 싶을 때 씁니다.

== 리드 문단: 첫 문단을 강조하기

[source,asciidoc]
----
[.lead]
이건 강조된 리드 문단입니다.
----

`[.lead]`처럼 대괄호 안에 점(`.`)을 찍고 CSS 클래스 이름을 쓰면, 그 클래스를 다음 블록에 붙일 수 있습니다 — 변환 결과는 `<p class="paragraph lead">`가 되고, 스타일시트가 이 클래스에 더 큰 글씨나 다른 색을 입혀 "이 문단이 서론이다"라는 걸 시각적으로 강조하는 데 씁니다. 이 `[.클래스명]` 문법은 이후 장들에서 표·이미지·admonition 등 다른 블록에도 계속 재사용됩니다 — AsciiDoc에서 아주 자주 보게 될 패턴입니다.

== 직접 해보기

* 장 제목 하나(`==`)와 그 아래 절 제목 하나(`===`)를 만들고, 절 아래에 두 개의 문단(하나는 여러 줄로 나눠 쓰고, 하나는 `+`로 강제 개행을 넣어)을 작성해서 `asciidoctor -e -o -`로 변환 결과를 확인해보세요.

.해답 보기
[%collapsible]
====
[source,asciidoc]
----
== 나의 장

=== 나의 절

이 문단은
여러 줄로
나눠 썼습니다.

이 문단은 +
강제로 줄을 바꿉니다.
----

변환하면 첫 문단은 `<p>` 안에서 줄바꿈 없이 이어지고, 두 번째 문단은 `<br>` 태그로 실제 줄바꿈이 보입니다.
====

== 요약

* `=`의 개수가 제목의 레벨을 결정합니다 — 문서 제목은 `=` 하나, 그 아래 섹션은 `==`부터 시작합니다.
* 빈 줄만이 문단을 나눕니다. 단순 줄바꿈은 같은 문단 안에서 이어집니다.
* 줄 끝의 `+`로 문단은 유지한 채 강제 줄바꿈(`<br>`)을 넣을 수 있습니다.
* `[.클래스명]`으로 블록에 CSS 클래스를 붙이는 문법은 이 책 내내 반복해서 등장합니다.
