기술 문서에서 "이건 참고할 정보다", "이건 중요한 경고다" 같은 걸 시각적으로 눈에 띄게 표시하고 싶을 때가 많습니다. AsciiDoc은 이런 상자를 **admonition**이라는 이름으로 문법에 기본 내장하고 있습니다.

== 다섯 가지 Admonition

[source,asciidoc]
----
NOTE: 한 줄짜리 참고입니다.

TIP: 한 줄짜리 팁입니다.

WARNING: 한 줄짜리 경고입니다.

IMPORTANT: 한 줄짜리 중요 사항입니다.

CAUTION: 한 줄짜리 주의 사항입니다.
----

AsciiDoc은 다섯 가지 admonition 종류를 미리 정해두고 있습니다 — `NOTE`(참고), `TIP`(팁), `WARNING`(경고), `IMPORTANT`(중요), `CAUTION`(주의). `이름: 내용` 형식으로 한 줄에 바로 쓰면, 각각 `class="admonitionblock note"`처럼 종류에 맞는 클래스가 붙은 상자로 변환됩니다 — 실제 사이트에서는 이 클래스에 맞춰 아이콘과 색이 다르게 스타일링됩니다.

== 여러 문단을 담은 Admonition

[source,asciidoc]
----
[NOTE]
====
여러 문단으로 된 참고 블록입니다.

두 번째 문단도 들어갑니다.
====
----

한 줄로는 부족하고 여러 문단을 담아야 한다면, 5장에서 배운 예제 블록(`====`) 문법 앞에 `[NOTE]`(대괄호 안에 종류 이름)를 붙입니다 — "블록에 속성을 붙인다"는 5장의 패턴이 admonition에서도 그대로 쓰입니다. `[TIP]`, `[WARNING]` 등 나머지 네 종류도 같은 방식으로 씁니다.

== 인용문: 출처를 표시하기

[source,asciidoc]
----
[quote, 아무개, 어떤 책]
____
인용문입니다. 여러 줄로 써도 됩니다.
____
----

`____`(밑줄 네 개)로 감싸면 인용 블록이고, `[quote, 저자, 출처]`로 앞에 붙인 저자와 출처 정보가 블록 아래 "— 저자, *출처*" 형식으로 자동으로 붙습니다(변환 결과에서 `<div class="attribution">`).

== Verse: 줄바꿈이 보존되는 인용

[source,asciidoc]
----
[verse, 시인 이름, 시 제목]
____
줄바꿈이
그대로 보존되는
시 형식입니다.
____
----

`[quote]` 대신 `[verse]`를 쓰면, 2장에서 배운 "빈 줄만 문단을 나눈다"는 일반 규칙이 적용되지 않고 **소스에 있는 줄바꿈이 그대로 출력에 남습니다**(`<pre class="content">`로 변환됩니다) — 시나 노래 가사처럼 줄바꿈 자체가 의미를 가지는 텍스트를 인용할 때 씁니다.

== 직접 해보기

* "이 설정을 바꾸면 기존 데이터가 삭제될 수 있습니다"라는 내용을 `WARNING` admonition으로 작성해보세요.

.해답 보기
[%collapsible]
====
[source,asciidoc]
----
WARNING: 이 설정을 바꾸면 기존 데이터가 삭제될 수 있습니다.
----
====

== 요약

* `NOTE:`, `TIP:`, `WARNING:`, `IMPORTANT:`, `CAUTION:`으로 한 줄짜리 admonition을 만듭니다.
* 여러 문단이 필요하면 `[종류]`를 예제 블록(`====`) 앞에 붙입니다.
* `[quote, 저자, 출처]`로 인용문에 출처를 표시하고, `[verse, ...]`는 줄바꿈이 그대로 보존되는 인용에 씁니다.

2부가 여기서 끝났습니다. 3부에서는 소스 코드 블록과, 문서를 조립하는 include 문법을 다룹니다.
