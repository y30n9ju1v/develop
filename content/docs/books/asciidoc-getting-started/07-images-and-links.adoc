== 이미지: 블록과 인라인

[source,asciidoc]
----
image::diagram.png[다이어그램 설명, 400, 300]

인라인 이미지도 됩니다 image:icon.png[아이콘, 16, 16] 이렇게요.
----

콜론이 두 개(`image::`)면 그 줄 전체가 이미지 하나를 위한 독립된 블록이 되고, 콜론이 하나(`image:`)면 문장 중간에 끼워 넣는 인라인 이미지가 됩니다 — 이 콜론 개수 차이가 "블록이냐 인라인이냐"를 가르는 패턴은 뒤에서 다룰 다른 매크로에서도 반복됩니다. 대괄호 안의 첫 값은 대체 텍스트(`alt`)이고, 이어지는 두 값은 너비와 높이입니다(둘 다 생략 가능합니다).

== 링크의 여러 형태

[source,asciidoc]
----
link:https://example.com[예제 사이트]

https://example.com[다른 방식의 링크,role=external]

https://example.com

mailto:foo@example.com[메일 보내기]
----

`link:URL[표시할 글자]`가 가장 명시적인 형태입니다. 하지만 URL이 `http`나 `https`로 시작한다면 `link:` 없이 `URL[표시할 글자]`만 써도 됩니다 — 그리고 표시할 글자 대괄호 안에 `role=external`처럼 속성을 추가로 넣으면 그 값이 CSS 클래스로 붙습니다. 대괄호조차 생략하고 URL만 덜렁 써도 자동으로 링크가 됩니다(`class="bare"`로 변환되는데, "맨 URL"이라는 뜻입니다). 이메일 주소는 `mailto:주소[표시할 글자]`로 씁니다.

== 다른 문서로 가는 링크

[source,asciidoc]
----
link:../02-titles-and-paragraphs/[2장으로]
----

이 사이트의 각 장 맨 위 nav 줄에서 계속 봐온 문법입니다 — 상대 경로로 다른 문서를 가리킬 때도 `link:경로[글자]`를 씁니다. 웹 URL이든 로컬 경로든 `link:` 매크로의 문법은 똑같습니다.

== 문서 내부 앵커로 이동하기

[source,asciidoc]
----
<<my-anchor,본문 내 앵커로 이동>>

[[my-anchor]]
== 앵커가 붙은 섹션
----

`[[이름]]`으로 원하는 곳에 앵커를 심어두고(5장에서 본, `:sectnums:`가 섹션 제목마다 자동으로 만들어주는 앵커와 같은 종류입니다), `<<이름,표시할 글자>>`로 문서 안 어디서든 그 앵커를 가리킬 수 있습니다. 변환하면 `<a href="#my-anchor">`가 되어, 같은 페이지 안에서 클릭하면 그 위치로 스크롤됩니다 — 긴 문서에서 "위에서 설명한 X를 참고하세요" 같은 문장을 쓸 때 유용합니다.

== 직접 해보기

* 너비 200, 높이 150인 `logo.png` 이미지를 블록으로 넣고, 대체 텍스트는 "로고"로 지정해보세요. 그리고 바로 아래에 "우리 회사 홈페이지"라는 글자로 `https://example.org`를 가리키는 링크를 만들어보세요.

.해답 보기
[%collapsible]
====
[source,asciidoc]
----
image::logo.png[로고, 200, 150]

link:https://example.org[우리 회사 홈페이지]
----
====

== 요약

* `image::`(콜론 두 개)는 블록 이미지, `image:`(콜론 하나)는 인라인 이미지입니다.
* 링크는 `link:URL[글자]`가 기본형이지만, `http(s)`로 시작하면 `link:` 없이 `URL[글자]`만 써도 되고, 대괄호까지 생략하면 맨 URL이 자동으로 링크가 됩니다.
* `[[앵커이름]]`으로 위치를 표시하고 `<<앵커이름,글자>>`로 문서 내부의 그 위치를 가리킵니다.

다음 장에서는 주의·참고 박스인 admonition과 인용문을 다룹니다.
