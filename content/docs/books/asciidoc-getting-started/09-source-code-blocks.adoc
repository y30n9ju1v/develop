이 책의 모든 장에서 지금까지 계속 봐온 문법 — `[source,언어]`와 `----`로 감싼 블록 — 이 이번 장의 주제입니다. 사실 이 책 자체가 매 장마다 이 문법으로 예제 코드를 보여주고 있었습니다.

== 언어를 지정해 문법 강조 켜기

[source,asciidoc]
----
[source,python]
----
def greet(name):
    return f"Hello, {name}!"  # 인사말 만들기
----
----

`[source,언어이름]`을 코드 블록(`----`로 감싼 부분, "listing block"이라고 부릅니다) 바로 위에 붙이면, 변환 결과에 `class="language-python"`이 붙습니다 — 이 클래스를 보고 실제 사이트를 렌더링하는 코드 하이라이터(예: highlight.js, Pygments)가 언어에 맞는 문법 강조 색을 입힙니다. 이 책의 모든 코드 예제가 정확히 이 문법을 씁니다.

== 언어 없이 그냥 텍스트 그대로

[source,asciidoc]
----
----
언어 지정 없는 리터럴 코드 블록입니다.
   들여쓰기도 그대로 보존됩니다.
----
----

`[source,언어]` 없이 `----`만으로 감싸도 코드 블록은 됩니다 — 문법 강조는 켜지지 않지만, **들여쓰기와 줄바꿈을 있는 그대로 보존**한다는 점은 똑같습니다(2장에서 본 일반 문단의 "줄바꿈 무시" 규칙이 여기서는 적용되지 않습니다). 명령어 실행 결과나 설정 파일처럼 특정 언어로 분류하기 애매한 텍스트를 보여줄 때 씁니다.

== 콜아웃: 코드 특정 줄을 짚어 설명하기

[source,asciidoc]
----
[source,python]
----
def add(a, b):
    result = a + b  # <1>
    return result  # <2>
----
<1> 두 수를 더합니다.
<2> 결과를 돌려줍니다.
----

코드 안에 `# <1>`, `# <2>`처럼 써두고(주석 문법은 언어에 맞게, 여기서는 파이썬이라 `#`을 씁니다), 코드 블록이 끝난 바로 다음 줄부터 `<1> 설명`, `<2> 설명`을 이어 쓰면, 코드의 해당 줄 옆에 동그라미 숫자(`①`, `②`처럼 렌더링됩니다)가 표시되고 아래에 번호 매겨진 설명 목록이 자동으로 생깁니다 — 이걸 **콜아웃(callout)**이라고 부릅니다. 코드 한 줄 한 줄을 짚어가며 설명해야 하는 튜토리얼에 특히 유용한 기능입니다.

== 줄 번호 표시하기

[source,asciidoc]
----
[source,python,linenums]
----
x = 1
y = 2
----
----

`[source,언어,linenums]`처럼 `linenums`를 추가하면 코드 블록 왼쪽에 줄 번호가 표시됩니다 — 코드가 길어서 "3번째 줄을 보세요" 같은 식으로 안내해야 할 때 유용합니다.

== 직접 해보기

* 자바스크립트로 두 수를 곱하는 함수를 작성하고, 곱하는 줄에 콜아웃을 달아 "여기서 곱셈이 일어납니다"라고 설명해보세요.

.해답 보기
[%collapsible]
====
[source,asciidoc]
----
[source,javascript]
----
function multiply(a, b) {
  return a * b;  // <1>
}
----
<1> 여기서 곱셈이 일어납니다.
----
====

== 요약

* `[source,언어]` + `----`로 문법 강조가 켜진 코드 블록을 만듭니다.
* 언어 없이 `----`만 써도 들여쓰기·줄바꿈이 보존되는 리터럴 블록이 됩니다.
* 코드 안의 `# <N>`과 블록 아래의 `<N> 설명`으로 콜아웃을 달 수 있습니다.
* `linenums`를 추가하면 줄 번호가 표시됩니다.
