지금까지 본 예제 대부분은 `asciidoctor -e -o -`로 본문 조각만 확인해왔습니다. 이 장에서는 실제로 완성된 HTML 문서와 PDF 파일을 만드는 명령을 다룹니다.

== HTML로 변환하기

[source,bash]
----
asciidoctor my-document.adoc
----

가장 기본적인 명령입니다 — `my-document.adoc`과 같은 폴더에 `my-document.html`이 만들어지고, 여기에는 1장에서 본 본문 조각뿐 아니라 스타일시트가 포함된 완전한 HTML 문서 전체(`<html>`, `<head>`, 기본 CSS)가 들어 있습니다. 결과 파일 이름을 직접 지정하려면 `-o` 옵션을 씁니다.

[source,bash]
----
asciidoctor -o output.html my-document.adoc
----

== PDF로 변환하기

HTML 변환기인 `asciidoctor`와 별개로, PDF를 직접 만들어주는 `asciidoctor-pdf`라는 도구가 있습니다.

[source,bash]
----
asciidoctor-pdf my-document.adoc
----

이 명령은 `my-document.pdf`를 바로 만들어줍니다 — 중간에 HTML을 거치지 않고 AsciiDoc 소스에서 곧바로 PDF 레이아웃(페이지 나누기, 목차, 각주 등)을 생성합니다. `:doctype: book`을 문서 상단에 지정하면(5장에서 다룬 문서 속성입니다) 각 장(`==`)이 새 페이지에서 시작하는 등, 진짜 "책"에 어울리는 페이지 나누기가 적용됩니다.

== 자주 쓰는 변환 옵션

[cols="1,2"]
|===
|옵션 |설명

|`-o 파일이름`
|결과 파일의 이름과 경로를 지정합니다.

|`-a 이름=값`
|11장에서 본 것처럼, 명령줄에서 속성 값을 넘깁니다.

|`-D 폴더`
|결과 파일을 저장할 폴더를 지정합니다(원본 폴더가 아닌 다른 곳에).

|`-r 확장이름`
|Asciidoctor의 기능을 확장하는 라이브러리(diagram 렌더링 등)를 불러옵니다.
|===

== 정적 사이트 생성기가 .adoc을 직접 처리하는 경우

이 사이트는 Hugo라는 정적 사이트 생성기로 만들어졌는데, Hugo는 `.adoc` 파일을 발견하면 내부적으로 `asciidoctor` 명령을 직접 실행해서 HTML로 변환한 뒤 그 결과를 페이지에 끼워 넣습니다 — 즉, 이 책을 포함한 이 사이트의 모든 책은 사람이 미리 `asciidoctor` 명령을 돌려 HTML 파일을 만들어두는 게 아니라, 사이트를 빌드할 때마다 매번 새로 변환됩니다. 이 방식 덕분에 우리는 `.adoc` 파일만 관리하면 되고, 최종 HTML은 신경 쓸 필요가 없습니다 — Markdown 파일을 그대로 두면 Hugo가 알아서 HTML로 바꿔주는 것과 똑같은 원리가, `.adoc` 확장자에 대해서도 그대로 적용되는 것입니다.

== 직접 해보기

* 아무 `.adoc` 파일이나 하나 골라 `asciidoctor-pdf`로 변환해보고, `asciidoctor`로 만든 HTML과 비교해서 어떤 차이가 있는지 살펴보세요(특히 `:doctype: book`을 붙였을 때와 안 붙였을 때 PDF의 페이지 나누기가 어떻게 달라지는지 확인해보세요).

.해답 보기
[%collapsible]
====
`:doctype: book`이 없으면 `asciidoctor-pdf`는 문서를 하나의 흐름으로 이어 붙여 변환합니다(장 제목마다 새 페이지로 넘어가지 않습니다). `:doctype: book`을 추가하면 `==`(장 레벨) 제목마다 새 페이지에서 시작하도록 페이지 나누기가 자동으로 들어갑니다 — 여러 장으로 이뤄진 긴 문서를 PDF로 낼 때는 거의 항상 `:doctype: book`을 켜는 게 좋습니다.
====

== 요약

* `asciidoctor`는 HTML을, `asciidoctor-pdf`는 PDF를 직접 만듭니다.
* `-o`, `-a`, `-D` 같은 옵션으로 출력 파일 이름·속성 값·저장 폴더를 조정합니다.
* `:doctype: book`을 켜면 PDF에서 장마다 새 페이지로 시작하는 등 책에 어울리는 레이아웃이 적용됩니다.
* Hugo 같은 정적 사이트 생성기는 `.adoc` 파일을 빌드할 때마다 내부적으로 `asciidoctor`를 직접 실행해 변환합니다.
