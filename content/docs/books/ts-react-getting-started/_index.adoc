react.dev(공식 React 문서)와 TypeScript Handbook을 재료로, "왜 이렇게 생겼는가"라는 질문을 축으로 처음부터 다시 엮은 입문서입니다. TypeScript를 JavaScript 위에 얹는 타입 시스템으로 놓고 시작해(1부), React의 컴포넌트·State·렌더링 원리로 넘어가고(2부), 마지막으로 그 둘을 실제 API 호출과 폼으로 합칩니다(3부).

이 책의 코드 예제는 전부 이 책을 위해 새로 짠 것이며, 원본 문서의 예제를 그대로 옮기지 않습니다. 모든 예제는 실제로 TypeScript 컴파일러로 타입 검사를 통과했고, React 컴포넌트의 상당수는 jsdom 기반 상호작용 테스트로 동작까지 확인했습니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
