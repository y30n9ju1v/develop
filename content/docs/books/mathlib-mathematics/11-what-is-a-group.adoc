지금까지는 자연수·정수·실수처럼 구체적인 수를 다뤘습니다. 이 장부터는 **추상적인 구조**를 다룹니다 — "덧셈"이나 "곱셈"이 구체적으로 무엇인지는 잊고, 그 연산이 만족하는 **공리**만으로 무엇을 증명할 수 있는지 봅니다.

== 군의 공리: 딱 세 가지

[source,lean]
----
example {G : Type*} [Group G] (a b c : G) : a * b * c = a * (b * c) := mul_assoc a b c
example {G : Type*} [Group G] (a : G) : a * 1 = a := mul_one a
example {G : Type*} [Group G] (a : G) : a * a⁻¹ = 1 := mul_inv_cancel a
----

`[Group G]`는 "`G`라는 타입에 군의 구조가 있다"는 전제입니다(Lean4에서 이런 전제를 대괄호로 표시하는 걸 **타입클래스**라고 부릅니다 — "이 타입이 이런 성질/구조를 갖는다"는 걸 자동으로 찾아 적용해주는 메커니즘입니다). 군이라는 구조는 딱 세 가지 공리로 정의됩니다.

* *결합법칙*: `(a * b) * c = a * (b * c)` — 곱하는 순서를 바꿔 묶어도 결과가 같습니다.
* *항등원*: `a * 1 = a` — `1`을 곱해도 변하지 않습니다.
* *역원*: `a * a⁻¹ = 1` — 모든 원소는 자신을 항등원으로 되돌리는 짝을 갖습니다.

여기서 `*`, `1`, `⁻¹`은 실제 곱셈일 필요가 없습니다 — **이 세 공리를 만족하는 어떤 연산과 집합이든** 군이라고 부릅니다. 이 장의 나머지는 "구체적으로 무엇인지 모르는 채로, 이 세 공리만 갖고 무엇을 증명할 수 있는가"를 봅니다.

== 첫 정리: 항등원은 유일하다

[source,lean]
----
example {G : Type*} [Group G] (e : G) (h : ∀ a, e * a = a) : e = 1 := by
  have := h 1
  simpa using this
----

"항등원 노릇을 하는 원소가 `e`도 있고 `1`도 있다면, 사실 `e = 1`이다"라는 걸 증명합니다. 증명은 짧습니다 — `h`(모든 원소에 대해 `e`가 항등원처럼 행동한다는 가정)를 `1`(진짜 항등원) 자체에 적용하면 `e * 1 = 1`이 나오고, `mul_one`(공리 그 자체)로 `e * 1 = e`이니 `e = 1`이 나옵니다. **군의 정의 안에는 "항등원은 딱 하나뿐이다"라는 말이 없는데도, 세 공리만으로 그 사실이 저절로 따라나온다**는 게 이 증명의 의미입니다.

== 첫 정리 2: 역원도 유일하다

[source,lean]
----
example {G : Type*} [Group G] (a b : G) (h : a * b = 1) : b = a⁻¹ := by
  have : a⁻¹ * (a * b) = a⁻¹ * 1 := by rw [h]
  rwa [← mul_assoc, inv_mul_cancel, one_mul, mul_one] at this
----

"`a`와 곱해서 `1`이 되는 원소가 `b`라면, 사실 `b`는 `a⁻¹`과 같다"는 것도 마찬가지입니다. 증명은 양변 왼쪽에 `a⁻¹`을 곱하는 것으로 시작합니다 — `a⁻¹ * (a * b) = a⁻¹ * 1`. 그다음 결합법칙(`mul_assoc`)으로 괄호를 다시 묶고, `a⁻¹ * a = 1`(역원의 다른 방향, `inv_mul_cancel`)과 항등원 공리를 순서대로 적용하면 `b = a⁻¹`이 남습니다. 세 공리를 손으로 조합해가는 이 과정이, 군론 전체가 쌓아 올려지는 방식을 그대로 보여줍니다.

== 소거 법칙: 양쪽에서 같은 걸 지울 수 있다

[source,lean]
----
example {G : Type*} [Group G] (a b c : G) (h : a * b = a * c) : b = c := by
  have := congrArg (a⁻¹ * ·) h
  simpa using this
----

"`a * b = a * c`이면 `b = c`다"(양쪽에서 `a`를 소거할 수 있다)는 성질도 군의 공리만으로 나옵니다. `congrArg (a⁻¹ * ·) h`는 "`h`라는 등식의 양변에 똑같이 `a⁻¹ *`를 적용한다"는 뜻입니다(같은 값에 같은 함수를 적용하면 결과도 같다는, 아주 기본적인 사실을 이용합니다) — 그 결과 `a⁻¹ * (a * b) = a⁻¹ * (a * c)`가 되고, `simpa`가 결합법칙과 역원·항등원 공리를 자동으로 적용해 `b = c`로 정리해줍니다.

== 구체적인 사례: ZMod n의 덧셈은 군이다

[source,lean]
----
example : (2 : ZMod 5) + 3 = 0 := by decide
example {a : ZMod 5} : a + 0 = a := add_zero a

example : (1 : ZMod 5) + 1 + 1 + 1 + 1 = 0 := by decide
example : (1 : ZMod 5) + 1 + 1 + 1 ≠ 0 := by decide
----

10장에서 다룬 `ZMod n`이 사실 **덧셈에 대한 군**입니다 — `0`이 항등원(`add_zero`), 각 원소는 "합해서 0이 되는" 역원을 가지며, 덧셈은 결합법칙을 만족합니다. `1`을 다섯 번 더하면 정확히 `0`으로 돌아오지만(`ZMod 5`의 크기가 5이니까요), 네 번 더한 값은 아직 `0`이 아닙니다 — 이 장 앞부분에서 증명한 "항등원의 유일성", "소거 법칙" 같은 추상적인 정리들이, 이 구체적인 군에서도 전부 성립한다는 걸 확인할 수 있습니다(직접 증명할 필요 없이, `Group` 인스턴스라는 사실 하나로 공짜로 따라옵니다).

== 왜 추상화가 실질적인 이득을 주는가

이 장에서 증명한 세 정리(항등원 유일성, 역원 유일성, 소거 법칙)는 **`ZMod n`뿐 아니라 모든 군에 대해 동시에 증명된 것**입니다 — 정수의 덧셈, 실수의 곱셈(0 제외), 행렬의 곱셈, 대칭군(순열들의 합성)까지, "군이다"라는 사실만 확인되면 이 세 정리를 공짜로 얻습니다. 이게 추상 대수학의 핵심 이득입니다 — 구체적인 대상 하나하나마다 같은 증명을 반복하는 대신, 공리를 만족하는 **모든** 대상에 대해 한 번만 증명해두는 것입니다.

== 직접 해보기

* `{G : Type*} [Group G] (a : G) : (a⁻¹)⁻¹ = a`(역원의 역원은 원래 원소다)를 증명해보세요.

.해답 보기
[%collapsible]
====
[source,lean]
----
example {G : Type*} [Group G] (a : G) : (a⁻¹)⁻¹ = a := by
  have h : a⁻¹ * a = 1 := inv_mul_cancel a
  have h2 := congrArg ((a⁻¹)⁻¹ * ·) h
  simpa using h2
----
====

== 요약

* 군은 결합법칙·항등원·역원이라는 세 공리로 정의되고, 그 연산이 구체적으로 무엇인지와 무관하게 공리만으로 성립합니다.
* 항등원의 유일성, 역원의 유일성, 소거 법칙은 이 세 공리만으로 증명되는 "첫 정리"들입니다.
* `ZMod n`의 덧셈이 실제 군의 구체적인 사례이고, 추상적으로 증명해둔 정리가 공짜로 적용됩니다.
