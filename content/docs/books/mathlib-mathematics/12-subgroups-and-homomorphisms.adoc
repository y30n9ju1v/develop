11장에서 하나의 군을 다뤘다면, 이 장에서는 **군 안의 부분 구조**(부분군)와 **군 사이의 구조를 보존하는 함수**(준동형사상)를 다룹니다.

== 부분군: 부분집합이면서 군의 구조를 갖춤

[source,lean]
----
example {G : Type*} [Group G] (H : Subgroup G) (a b : G) (ha : a ∈ H) (hb : b ∈ H) :
    a * b ∈ H := H.mul_mem ha hb

example {G : Type*} [Group G] (H : Subgroup G) : (1 : G) ∈ H := H.one_mem

example {G : Type*} [Group G] (H : Subgroup G) (a : G) (ha : a ∈ H) : a⁻¹ ∈ H := H.inv_mem ha
----

`Subgroup G`는 그냥 "`G`의 부분집합"이 아니라, **그 부분집합 자체가 다시 군이 되기 위한 조건까지 갖춘** 구조입니다 — 항등원을 포함하고(`one_mem`), 곱셈에 대해 닫혀 있고(`mul_mem`), 역원에 대해서도 닫혀 있어야(`inv_mem`) 부분군입니다. 5장에서 배운 "집합이면서 그 집합에 어떤 성질이 있다"는 패턴이, 이번엔 대수 구조 위에서 다시 등장한 것입니다.

[source,lean]
----
example {G : Type*} [Group G] (a : G) : a ∈ (⊥ : Subgroup G) ↔ a = 1 := Subgroup.mem_bot
----

`⊥`(가장 작은 부분군)는 항등원 하나만 원소로 갖는, 가장 자명한 부분군입니다 — 어떤 원소가 이 자명한 부분군에 속한다는 건 정확히 그 원소가 항등원이라는 뜻입니다.

== 준동형사상: 곱셈 구조를 보존하는 함수

[source,lean]
----
example {G H : Type*} [Group G] [Group H] (f : G →* H) (a b : G) :
    f (a * b) = f a * f b := f.map_mul a b

example {G H : Type*} [Group G] [Group H] (f : G →* H) : f 1 = 1 := f.map_one
----

`G →* H`(준동형사상, homomorphism)는 두 군 사이의 함수인데, **그냥 함수가 아니라 곱셈 구조를 보존한다는 증거까지 함께 담고 있는 값**입니다 — `f (a * b) = f a * f b`(곱한 걸 보내는 것과, 각자 보내고 곱하는 것이 같다)와 `f 1 = 1`(항등원은 항등원으로 간다)이 정의의 핵심입니다. 6장에서 다룬 "함수의 성질"(단사·전사)이 순수하게 집합론적이었다면, 준동형사상은 **대수 구조를 존중하는 함수**라는 추가 조건이 붙습니다.

== 놀라운 사실: 역원 보존은 공짜로 따라온다

[source,lean]
----
example {G H : Type*} [Group G] [Group H] (f : G →* H) (a : G) : f a⁻¹ = (f a)⁻¹ :=
  f.map_inv a
----

준동형사상의 정의에는 "역원도 보존한다"는 조건이 **없습니다** — `map_mul`과 `map_one` 두 가지만 요구합니다. 그런데도 `f a⁻¹ = (f a)⁻¹`이 항상 성립합니다 — 11장에서 본 "역원의 유일성" 정리를 떠올려보면 이유가 보입니다. `f a * f a⁻¹ = f (a * a⁻¹) = f 1 = 1`이니, `f a⁻¹`은 "`f a`와 곱해서 항등원이 되는 원소"이고, 11장에서 그런 원소는 **유일하게** `(f a)⁻¹`이라는 걸 이미 증명했습니다. 곱셈과 항등원만 보존해도, 역원 보존은 그 위에서 저절로 따라나오는 것입니다.

== 구체적인 준동형사상: 나머지를 다시 취하기

[source,lean]
----
example : (ZMod.castHom (by norm_num : (3:ℕ) ∣ 6) (ZMod 3)) 4 = 1 := by decide
----

`ZMod.castHom`은 "`6`으로 나눈 나머지 세계(`ZMod 6`)에서 `3`으로 나눈 나머지 세계(`ZMod 3`)로 다시 나머지를 취하는" 준동형사상입니다(3이 6을 나눈다는 조건이 있어야 이 사상이 잘 정의됩니다). `ZMod 6`에서 `4`는 `ZMod 3`으로 보내면 `1`이 됩니다(`4`를 `3`으로 나눈 나머지가 `1`이니까요) — 10장에서 본 `ZMod n`이 이 장의 준동형사상 개념과 자연스럽게 이어집니다.

== 핵: 항등원으로 보내지는 원소들

[source,lean]
----
example {G H : Type*} [Group G] [Group H] (f : G →* H) (a : G) (ha : a ∈ f.ker) :
    f a = 1 := ha
----

`f.ker`(핵, kernel)는 "`f`를 적용하면 항등원이 되는 원소들의 집합"입니다 — `a ∈ f.ker`가 정의상 `f a = 1`과 같습니다. 핵은 실은 이 장 앞부분에서 다룬 **부분군**입니다(항등원을 포함하고, 곱셈·역원에 닫혀 있다는 걸 `map_mul`/`map_one`/`map_inv`로부터 증명할 수 있습니다) — 준동형사상이 "얼마나 많은 정보를 뭉개는지"를 핵의 크기로 가늠할 수 있습니다. 핵이 자명한 부분군(항등원만)이면 그 준동형사상은 단사(6장)라는 것도, 이 장과 6장이 만나는 지점입니다.

== 왜 부분군과 준동형사상을 함께 다루는가

부분군이 "군 안의 정적인 구조"를 본다면, 준동형사상은 "군과 군 사이의 관계"를 봅니다. 이 둘은 핵이라는 개념으로 직접 연결됩니다 — 모든 준동형사상은 부분군(핵)을 만들어내고, 역으로 특정 조건을 만족하는 부분군(정규부분군)은 준동형사상을 통해 이해할 수 있습니다. 이 관계는 이 책의 범위를 넘어서지만, 지금 다진 정의들이 그 방향으로 가는 첫걸음입니다.

== 직접 해보기

* `{G : Type*} [Group G] (H K : Subgroup G) (a : G) (h : a ∈ H ⊓ K) : a ∈ H ∧ a ∈ K`(두 부분군의 교집합에 속하면 둘 다에 속한다)를 증명해보세요 — `⊓`가 `Subgroup`에서는 교집합 연산으로 정의됩니다.

.해답 보기
[%collapsible]
====
[source,lean]
----
example {G : Type*} [Group G] (H K : Subgroup G) (a : G) (h : a ∈ H ⊓ K) :
    a ∈ H ∧ a ∈ K := h
----

`H ⊓ K`의 원소 자격이 정의상 `a ∈ H ∧ a ∈ K`라, `h` 자체가 이미 원하는 증거입니다 — 5장에서 `∈ ∩`이 정의상 `∧`였던 것과 정확히 같은 패턴이 부분군에서도 반복됩니다.
====

== 요약

* `Subgroup G`는 항등원을 포함하고 곱셈·역원에 닫힌 부분집합입니다.
* `G →* H`(준동형사상)는 곱셈과 항등원을 보존하는 함수이고, 역원 보존은 그 두 조건만으로 자동으로 따라나옵니다.
* 핵(`f.ker`)은 항등원으로 보내지는 원소들의 부분군이고, 준동형사상이 정보를 얼마나 뭉개는지를 가늠하게 해줍니다.

다음 장에서는 군을 떠나, 순서 관계로 이뤄진 구조(격자, 완비 순서)를 다룹니다.
