== 벡터공간의 공리: 덧셈군 + 스칼라 곱

[source,lean]
----
example {V : Type*} [AddCommGroup V] [Module ℝ V] (u v : V) : u + v = v + u := add_comm u v

example {V : Type*} [AddCommGroup V] [Module ℝ V] (c : ℝ) (u v : V) :
    c • (u + v) = c • u + c • v := smul_add c u v

example {V : Type*} [AddCommGroup V] [Module ℝ V] (c d : ℝ) (v : V) :
    (c + d) • v = c • v + d • v := add_smul c d v

example {V : Type*} [AddCommGroup V] [Module ℝ V] (v : V) : (1 : ℝ) • v = v := one_smul ℝ v

example {V : Type*} [AddCommGroup V] [Module ℝ V] (v : V) : (0 : ℝ) • v = 0 := zero_smul ℝ v
----

`[AddCommGroup V] [Module ℝ V]`가 "`V`는 실수 위의 벡터공간이다"라는 전제입니다 — 두 조각으로 나뉘어 있다는 게 중요합니다. `AddCommGroup`은 11장의 군에 "교환법칙"(`add_comm`, 순서를 바꿔도 결과가 같다)까지 추가한 구조이고(벡터의 덧셈), `Module ℝ V`는 그 위에 **스칼라 곱**(`•`, 실수를 벡터에 곱하는 연산)이 갖춰야 할 공리들 — 스칼라 곱이 덧셈에 분배되고(`smul_add`), 두 스칼라를 더한 걸 곱하는 것과 각자 곱해서 더하는 것이 같고(`add_smul`), `1`을 곱하면 그대로이고(`one_smul`), `0`을 곱하면 영벡터가 되는(`zero_smul`) 것들입니다. 화살표 그림 없이도, 벡터공간이 정확히 이 공리들의 조합이라는 걸 코드로 확인할 수 있습니다.

== 구체적인 사례: 함수 공간

[source,lean]
----
example (u v : Fin 3 → ℝ) : u + v = v + u := add_comm u v

example (c : ℝ) (v : Fin 3 → ℝ) (i : Fin 3) : (c • v) i = c * v i := rfl
----

`Fin 3 → ℝ`("`0`, `1`, `2`라는 세 인덱스 각각에 실수를 대응시키는 함수")가 사실 우리가 흔히 아는 3차원 벡터공간입니다 — `(x, y, z)`라는 벡터를, "`i`번째 자리에 무슨 값이 있는지 물으면 답해주는 함수"로 표현한 것뿐입니다. 이 함수들의 덧셈은 좌표별로 더하는 것과 같고(`add_comm`이 그대로 적용됩니다), 스칼라 곱은 각 좌표에 그 수를 곱하는 것과 같습니다(`(c • v) i = c * v i`가 `rfl`로, 즉 정의 그대로 참입니다). 11장에서 "`ZMod n`이 군의 구체적 사례"였듯, 여기서는 "함수 공간이 벡터공간의 구체적 사례"입니다.

== 부분공간: 벡터공간 안의 벡터공간

[source,lean]
----
example {V : Type*} [AddCommGroup V] [Module ℝ V] (W : Submodule ℝ V) (u v : V)
    (hu : u ∈ W) (hv : v ∈ W) : u + v ∈ W := W.add_mem hu hv

example {V : Type*} [AddCommGroup V] [Module ℝ V] (W : Submodule ℝ V) (c : ℝ) (v : V)
    (hv : v ∈ W) : c • v ∈ W := W.smul_mem c hv
----

`Submodule ℝ V`(부분공간)는 12장의 `Subgroup`과 정확히 같은 발상입니다 — "부분집합이면서, 그 자체로 다시 벡터공간이 되기 위한 조건(덧셈과 스칼라 곱에 닫혀 있음)을 갖춘" 구조입니다. `W.add_mem`, `W.smul_mem`이 12장의 `H.mul_mem`, `H.inv_mem`과 나란한 이름이라는 걸 눈여겨보세요 — Mathlib이 "부분 구조"라는 공통된 발상을 군에서든 벡터공간에서든 같은 방식으로 다룬다는 걸 보여줍니다.

== 선형결합은 부분공간에서 벗어나지 않는다

[source,lean]
----
example {V : Type*} [AddCommGroup V] [Module ℝ V] (W : Submodule ℝ V) (u v : V)
    (hu : u ∈ W) (hv : v ∈ W) (a b : ℝ) : a • u + b • v ∈ W :=
  W.add_mem (W.smul_mem a hu) (W.smul_mem b hv)
----

`u`와 `v`가 부분공간 `W`에 속하면, **그 둘의 어떤 선형결합**(`a • u + b • v`, `a`와 `b`는 임의의 실수)도 `W`를 벗어나지 않습니다. 증명은 `W.smul_mem`(스칼라 곱에 닫힘)을 두 번 적용해 `a • u`와 `b • v`가 각각 `W`에 속한다는 걸 얻고, `W.add_mem`(덧셈에 닫힘)으로 그 둘의 합도 `W`에 속한다는 걸 확인하는, 앞의 두 성질을 조합한 것뿐입니다. "부분공간은 선형결합에 대해 닫혀 있다"는 이 성질이 선형대수 전체의 출발점입니다 — 부분공간이라는 개념 자체가 "선형결합을 벗어나지 않는 최소한의 집합"으로 정의되기 때문입니다.

== 왜 이 추상화가 필요한가

`Fin 3 → ℝ`(수학에서 익숙한 3차원 공간)만 다룰 거라면 이렇게 추상적으로 공리화할 필요가 없어 보일 수 있습니다. 하지만 벡터공간의 공리를 만족하는 대상은 화살표로 그릴 수 있는 것보다 훨씬 다양합니다 — 다항식들의 집합, 연속함수들의 집합, 심지어 이 책 4부에서 다룬 어떤 군의 덧셈 구조(`AddCommGroup`)에 적절한 스칼라 곱만 얹으면 전부 벡터공간이 됩니다. 11장에서 "군의 공리만으로 증명한 정리가 모든 군에 공짜로 적용된다"고 했던 것과 같은 이유로, 벡터공간의 공리만으로 증명한 정리는 이 모든 대상에 동시에 적용됩니다.

== 요약

* 벡터공간은 `AddCommGroup`(덧셈군 + 교환법칙)과 `Module`(스칼라 곱의 분배법칙들)의 조합으로 공리화됩니다.
* `Fin n → ℝ`(함수 공간)가 벡터공간의 구체적 사례이고, 좌표별 덧셈·스칼라 곱과 정확히 일치합니다.
* 부분공간은 12장의 부분군과 같은 발상 — 덧셈과 스칼라 곱에 닫힌 부분집합 — 이고, 그 결과 선형결합에 대해 닫혀 있습니다.

다음 장에서는 벡터공간 사이의 구조를 보존하는 함수, 선형사상과 그 행렬 표현을 다룹니다.
