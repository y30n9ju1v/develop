11~12장에서 곱셈(군)이라는 연산으로 이뤄진 구조를 봤습니다. 이 장에서는 다른 종류의 구조 — **순서**(`≤`)로 이뤄진 구조를 다룹니다.

== 순서 관계의 공리: 반사성·반대칭성·추이성

[source,lean]
----
example (a : ℕ) : a ≤ a := le_refl a
example (a b : ℕ) (h1 : a ≤ b) (h2 : b ≤ a) : a = b := le_antisymm h1 h2
example (a b c : ℕ) (h1 : a ≤ b) (h2 : b ≤ c) : a ≤ c := le_trans h1 h2
----

`≤`가 순서 관계로 인정받으려면 세 성질을 만족해야 합니다 — 자기 자신과는 항상 비교 가능하고(반사성), 양방향으로 작거나 같으면 실제로 같고(반대칭성, 4장에서 본 `le_antisymm`이 다시 등장합니다), 추이적입니다. 11장의 군 공리(결합법칙·항등원·역원)와 마찬가지로, 이 세 공리도 구체적인 `≤`가 무엇인지와 무관하게 **어떤 순서 관계든 만족해야 하는 최소 조건**입니다.

== 격자: 최솟값과 최댓값이 항상 존재하는 순서

[source,lean]
----
example (a b : ℕ) : a ⊓ b ≤ a := inf_le_left
example (a b : ℕ) : a ⊓ b ≤ b := inf_le_right
example (a b : ℕ) : a ≤ a ⊔ b := le_sup_left

example (a b : ℕ) : a ⊓ b = min a b := rfl
example (a b : ℕ) : a ⊔ b = max a b := rfl
----

**격자(lattice)**는 "임의의 두 원소에 대해 최솟값(`⊓`, meet)과 최댓값(`⊔`, join)이 항상 존재하는" 순서 구조입니다. 자연수에서는 이 `⊓`, `⊔`가 그냥 익숙한 `min`, `max`와 정확히 같습니다(`rfl`로 확인됩니다) — 하지만 격자라는 개념은 자연수보다 훨씬 일반적입니다. 5장에서 다룬 집합의 `∩`(교집합)와 `∪`(합집합)도 사실 격자 구조입니다 — "부분집합 관계(`⊆`)"라는 순서 아래서, 두 집합의 최댓값이 합집합이고 최솟값이 교집합입니다. 서로 다른 세계(수의 순서, 집합의 포함 관계)가 "격자"라는 같은 추상 구조를 공유한다는 걸 이 대응이 보여줍니다.

== 분배 격자: 곱셈의 분배법칙과 닮은꼴

[source,lean]
----
example (a b c : ℕ) : a ⊓ (b ⊔ c) = (a ⊓ b) ⊔ (a ⊓ c) := inf_sup_left a b c
----

`a ⊓ (b ⊔ c) = (a ⊓ b) ⊔ (a ⊓ c)`가 낯익어 보인다면 이유가 있습니다 — 3장에서 본 곱셈의 분배법칙(`a * (b + c) = a*b + a*c`)과 똑같은 모양이고, 5장에서 증명한 집합의 분배법칙(`A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)`)과도 정확히 같은 형태입니다. `⊓`를 곱셈처럼, `⊔`를 덧셈처럼 여기면 이 세 가지(수의 곱셈·집합의 교집합·격자의 최솟값)가 전부 "같은 대수적 패턴의 다른 얼굴"이라는 게 드러납니다.

== 완비 순서: 집합 전체의 최솟값

[source,lean]
----
example (S : Set ℕ) (h : S.Nonempty) : ∃ m ∈ S, ∀ x ∈ S, m ≤ x := by
  exact ⟨sInf S, Nat.sInf_mem h, fun x hx => Nat.sInf_le hx⟩
----

격자가 "**두** 원소의 최솟값·최댓값"을 다뤘다면, **완비 순서(complete order)**는 "집합 **전체**의 최솟값·최댓값"까지 다룹니다. 이 예제는 "공집합이 아닌 자연수 부분집합은 항상 최솟값을 갖는다"(자연수의 정렬성, well-ordering)는 걸 증명합니다 — `sInf S`(집합 `S`의 하한, infimum)가 실제로 `S`의 원소이면서(`Nat.sInf_mem`) `S`의 다른 모든 원소보다 작거나 같다(`Nat.sInf_le`)는 걸 확인합니다. 이 성질은 사실 12장 이전, 2장에서 다룬 귀납법의 배경에 깔린 원리이기도 합니다 — "자연수는 항상 가장 작은 원소부터 시작할 수 있다"는 사실이 귀납법이 작동하는 근본적인 이유 중 하나입니다.

== 왜 순서 구조가 대수 구조와 나란히 다뤄지는가

11~12장의 군과 이 장의 순서 구조는 겉보기에 다른 세계처럼 보이지만, **공리로 정의된 추상 구조를 다루고, 그 공리만으로 정리를 이끌어낸다**는 방법론은 완전히 같습니다. 실전 수학(그리고 Mathlib)에서는 이 두 종류의 구조가 자주 결합됩니다 — 순서와 곱셈이 서로 호환되는 "순서환(ordered ring)" 같은 구조가 실수·정수 같은 익숙한 대상을 정확히 서술하는 방식입니다.

== 직접 해보기

* `{a b c : ℕ} (h : a ⊔ b ≤ c) : a ≤ c ∧ b ≤ c`(두 값의 최댓값이 c 이하면, 둘 다 c 이하다)를 증명해보세요.

.해답 보기
[%collapsible]
====
[source,lean]
----
example (a b c : ℕ) (h : a ⊔ b ≤ c) : a ≤ c ∧ b ≤ c :=
  ⟨le_trans le_sup_left h, le_trans le_sup_right h⟩
----
====

== 요약

* 순서 관계는 반사성·반대칭성·추이성이라는 세 공리로 정의됩니다.
* 격자는 임의의 두 원소에 대해 최솟값(`⊓`)과 최댓값(`⊔`)이 항상 존재하는 순서 구조이고, 수의 `min`/`max`와 집합의 `∩`/`∪`가 모두 이 구조의 사례입니다.
* 분배법칙이 곱셈·집합·격자에서 같은 패턴으로 반복된다는 게, 대수 구조들이 서로 다른 얼굴을 한 같은 아이디어라는 걸 보여줍니다.
* 완비 순서는 집합 전체의 최솟값·최댓값까지 보장하고, 자연수의 정렬성이 그 구체적인 사례입니다.

4부가 여기서 끝났습니다. 5부에서는 벡터공간을 공리로부터 다루는 법을 봅니다.
