== ring: 다항식 항등식을 자동으로

[source,lean]
----
example (a b : ℝ) : (a + b)^2 = a^2 + 2*a*b + b^2 := by ring

example (x y z : ℝ) : x * (y + z) - x * y = x * z := by ring
----

`(a+b)^2 = a^2 + 2ab + b^2`처럼 손으로 전개하면 몇 줄이 걸리는 항등식을, `ring` 전술이 한 번에 확인해줍니다. `ring`은 "덧셈·뺄셈·곱셈·거듭제곱으로만 이뤄진 두 식이 대수적으로 같은 식인가"를 자동으로 판정합니다 — 1장의 `calc`로 이런 전개를 손수 단계별로 쓸 수도 있지만, `ring`이 있으면 그럴 필요가 없습니다. **나눗셈이 없는** 다항식 등식이라면 거의 항상 `ring` 하나로 끝난다고 생각해도 됩니다.

== ring이 못 하는 것: 나눗셈

[source,lean]
----
example (x : ℝ) (h : x ≠ 0) : x / x = 1 := by
  field_simp
----

`x / x = 1`처럼 간단해 보이는 식도 `ring`으로는 증명이 안 됩니다 — `ring`은 나눗셈을 다루지 않습니다(나눗셈은 "0으로 나누면 어떻게 되는가"라는 예외 상황 때문에 순수한 대수 연산으로 취급하기 까다롭습니다). 대신 `field_simp`(분수식을 정리해 분모를 없애주는 전술)를 씁니다.

== field_simp: 분모를 없앤 뒤 ring으로 마무리

[source,lean]
----
example (x y : ℝ) (hx : x ≠ 0) (hy : y ≠ 0) :
    1 / x + 1 / y = (x + y) / (x * y) := by
  field_simp
  ring
----

`1/x + 1/y = (x+y)/(xy)`는 손으로 통분해본 적이 있다면 익숙한 식입니다. `field_simp`가 양변의 분모를 없애는 작업(통분과 비슷한 일)을 자동으로 해주고, 그 결과 남은 순수한 다항식 등식을 `ring`이 마무리합니다 — `field_simp`와 `ring`이 짝을 이뤄 쓰이는 게 흔한 패턴입니다. `hx : x ≠ 0`과 `hy : y ≠ 0`이 필요한 이유가 중요합니다 — `field_simp`가 "분모가 0이 아니다"라는 걸 전제로 분수를 정리하기 때문에, 그 전제가 없으면 애초에 전술을 적용할 수 없습니다.

== 왜 0이 아니라는 조건이 꼭 필요한가

[source,lean]
----
example : (1 : ℝ) / 0 + 1 / 0 = (0 + 0) / (0 * 0) := by norm_num
----

흥미롭게도 이 특정한 식은 `x = y = 0`이어도 우연히 참입니다 — Lean4/Mathlib에서 실수의 나눗셈은 `a / 0`을 **`0`으로 정의**하기로 약속했기 때문입니다(수학적으로 정의되지 않은 연산에 "편의상의 값"을 부여한 것입니다). 그렇다고 `hx`, `hy` 조건이 불필요하다는 뜻은 아닙니다 — 대부분의 분수식 등식은 분모가 0일 때 실제로 깨집니다(예를 들어 `x / x = 1`은 `x = 0`이면 `0 = 1`이 되어 거짓입니다). `field_simp`가 조건을 요구하는 건 신중한 설계입니다.

== linarith와 nlinarith: 선형이냐 비선형이냐

[source,lean]
----
example (a b : ℝ) (h1 : a ≤ b) (h2 : b ≤ 3) : a ≤ 3 := by linarith

example (a : ℝ) (h : a ≥ 2) : a^2 ≥ 4 := by nlinarith [sq_nonneg (a - 2)]
----

`linarith`(1장에서 이미 몇 번 썼습니다)는 **선형** 부등식·등식 가정들을 조합해 목표를 증명합니다 — 변수끼리 곱하지 않는 범위에서는 매우 강력합니다. 그런데 `a ≥ 2 → a^2 ≥ 4`처럼 **제곱(비선형)**이 섞이면 `linarith`만으로는 안 풀립니다 — 이럴 때 `nlinarith`(비선형 확장판)를 씁니다. `nlinarith`는 스스로 어떤 보조식을 곱해볼지 다 찾아내지는 못해서, `[sq_nonneg (a - 2)]`처럼 **힌트**(여기서는 "`(a-2)^2`는 항상 0 이상이다"라는 사실)를 함께 줘야 하는 경우가 많습니다 — `(a-2)^2 \geq 0`을 전개하면 `a^2 - 4a + 4 \geq 0`인데, 여기에 `a \geq 2`(즉 `4a \geq 8`)를 조합하면 `a^2 \geq 4`가 나온다는 게 이 힌트가 하는 일입니다.

== 이 전술들을 언제 고를지

[cols="1,2"]
|===
|상황 |전술

|나눗셈 없는 다항식 등식
|`ring`

|나눗셈이 있는 등식(분모 0 아님이 보장될 때)
|`field_simp` 다음 `ring`

|선형 부등식·등식의 조합
|`linarith`

|제곱 등 비선형이 섞인 부등식
|`nlinarith` (필요하면 힌트와 함께)
|===

이 표가 "무조건 이 순서로 시도해보라"는 절대 규칙은 아니지만, 막막할 때 시작점으로 삼기엔 충분합니다 — 이후 장들에서 계속 이 네 전술을 조합해서 씁니다.

== 직접 해보기

* `(a b : ℝ) (h : a ≠ b) : (a - b) / (a - b) = 1`을 `field_simp`로 증명해보세요.
* `(x : ℝ) (h : x > 1) : x^2 > x`를 `nlinarith`로 증명해보세요(힌트: `x > 1`이면 `x - 1 > 0`이고, 이걸 `x`와 곱해보는 게 실마리입니다 — `nlinarith [mul_pos (show x - 1 > 0 by linarith) (show x > 0 by linarith)]`처럼 곱셈 힌트를 줄 수 있습니다).

.해답 보기
[%collapsible]
====
[source,lean]
----
example (a b : ℝ) (h : a ≠ b) : (a - b) / (a - b) = 1 := by
  have hne : a - b ≠ 0 := sub_ne_zero.mpr h
  field_simp

example (x : ℝ) (h : x > 1) : x^2 > x := by
  nlinarith [mul_pos (show x - 1 > 0 by linarith) (show x > 0 by linarith)]
----
====

== 요약

* `ring`은 나눗셈 없는 다항식 항등식을 자동으로 증명합니다.
* `field_simp`는 분모가 0이 아니라는 전제 아래 분수식을 정리하고, 남은 부분을 `ring`이 마무리하는 조합이 흔합니다.
* `linarith`는 선형 부등식·등식을, `nlinarith`는 힌트와 함께 비선형까지 확장해서 다룹니다.
