== 소수: 정의와 첫 성질

[source,lean]
----
example : Nat.Prime 7 := by decide
example : ¬ Nat.Prime 8 := by decide

example (p : ℕ) (hp : Nat.Prime p) : p ≥ 2 := hp.two_le

example (p a : ℕ) (hp : Nat.Prime p) (h : a ∣ p) : a = 1 ∨ a = p :=
  Nat.Prime.eq_one_or_self_of_dvd hp a h
----

구체적인 수가 소수인지 아닌지는 `decide`로 즉시 확인됩니다(작은 수라 전수 검사가 빠릅니다). `Nat.Prime p`의 정의는 정확히 우리가 아는 그대로입니다 — `p`는 `2` 이상이고(`hp.two_le`), `p`의 약수는 `1`이나 `p` 자신뿐입니다(`eq_one_or_self_of_dvd`). 8장에서 다룬 `∣`(나눗셈)이 소수의 정의 그 자체에 들어가 있다는 걸 확인할 수 있습니다.

== 유클리드 보조정리: 소수가 곱을 나누면

[source,lean]
----
example (p a b : ℕ) (hp : Nat.Prime p) (h : p ∣ a * b) : p ∣ a ∨ p ∣ b :=
  hp.dvd_mul.mp h
----

**유클리드 보조정리**는 "소수 `p`가 `a * b`를 나누면, `p`는 `a`를 나누거나 `b`를 나눈다"는 정리입니다 — 소수가 아닌 합성수라면 이 성질이 깨집니다(예: `4`는 `2 * 6 = 12`를 나누지만, `4`는 `2`도 `6`도 나누지 못합니다). 이 정리가 소수를 "쪼갤 수 없는 곱셈의 원자"로 만드는 핵심이고, 소인수분해의 유일성(같은 수를 두 가지 다른 방식으로 소인수분해할 수 없다는 것)을 증명할 때 결정적인 역할을 합니다. Mathlib이 `hp.dvd_mul`이라는 이름으로 이미 증명해뒀습니다.

== 소수는 무한히 많다

[source,lean]
----
example : ∀ n : ℕ, ∃ p, n ≤ p ∧ Nat.Prime p := Nat.exists_infinite_primes
----

"소수가 무한히 많다"는 유클리드 이래로 유명한 정리를, **"어떤 수 `n`을 고르든, `n`보다 크거나 같은 소수가 존재한다"**는 형태로 진술했습니다 — 이렇게 표현하면 "소수 목록이 유한하다면 그 목록의 최댓값보다 큰 소수를 항상 찾을 수 있다"는 뜻이 되어, "무한히 많다"는 걸 우회 없이 직접 말해줍니다. Mathlib이 이 정리 전체를 이미 증명해뒀다는 게 놀라운 지점입니다 — 유클리드의 원래 증명(어떤 소수 목록이 주어지든 그 곱에 1을 더한 수를 살펴보는 논증)이 `Nat.exists_infinite_primes`라는 이름 뒤에 이미 들어있습니다.

== 소인수분해: 존재성과 실제 계산

[source,lean]
----
example (n : ℕ) (h : n ≥ 2) : ∃ p, Nat.Prime p ∧ p ∣ n :=
  Nat.exists_prime_and_dvd (by omega)
----

"2 이상인 모든 자연수는 소인수를 적어도 하나 갖는다"는 것도 Mathlib이 이미 증명해둔 정리입니다. 이 사실을 반복 적용하면(가장 작은 소인수로 나누고, 몫이 여전히 2 이상이면 다시 소인수를 찾고, ...) 결국 소인수분해 전체가 나옵니다 — 이 반복 논증 자체는 12장(나만의 귀납 원리)에서 다룬 강한 귀납법과 정확히 같은 구조입니다.

[source,lean]
----
example : (12 : ℕ) = 2^2 * 3 := by norm_num
example : Nat.factorization 12 2 = 2 := by native_decide
example : Nat.factorization 12 3 = 1 := by native_decide
----

`Nat.factorization n`은 "`n`의 소인수분해를, 각 소수를 그 지수에 대응시키는 함수"로 표현한 것입니다 — `Nat.factorization 12 2 = 2`는 "12를 소인수분해하면 2가 지수 2로 등장한다"(즉 `2^2`이 들어간다)는 뜻이고, `Nat.factorization 12 3 = 1`은 "3이 지수 1로 등장한다"는 뜻입니다. 이 둘을 합치면 정확히 `12 = 2^2 * 3^1`이라는 우리가 아는 소인수분해가 나옵니다.

== 왜 "이미 증명된 정리를 가져다 쓰는" 것이 이 장의 핵심인가

이 장의 대부분이 손으로 증명을 짓기보다 **이미 있는 Mathlib 정리를 이름으로 찾아 쓰는** 것으로 채워졌습니다 — 이건 이 책이 게을러서가 아니라, 실전에서 정수론을 다룰 때 실제로 벌어지는 일입니다. "소수가 무한히 많다", "소인수분해가 존재한다" 같은 정리는 그 자체로 몇 페이지짜리 증명인데, Mathlib이 이미 검증해뒀다면 그 위에서 새로운 걸 쌓는 게 합리적입니다. 4장에서 익힌 "정리를 찾는 기술"이 정수론에서 가장 실질적으로 빛을 발하는 지점이 이 장입니다.

== 직접 해보기

== 요약

* `Nat.Prime p`는 "`p ≥ 2`이고 약수가 `1`과 `p`뿐"이라는 정의이고, 구체적인 수는 `decide`로 즉시 판정됩니다.
* 유클리드 보조정리(소수가 곱을 나누면 어느 한쪽을 나눈다)가 소인수분해의 유일성을 뒷받침하는 핵심 성질입니다.
* "소수는 무한히 많다", "소인수분해가 존재한다" 같은 정수론의 고전적인 정리들이 Mathlib에 이미 증명돼 있어, 이름을 찾아 바로 활용할 수 있습니다.
