draft: false
---

다중 카메라와 라이다의 좌표계를 통일하고, LSS/BEVFormer 방식의 BEV(Bird's Eye View) 공간 융합을 거쳐, Transformer 기반 Planning Head로 최종 제어 궤적까지 출력하는 E2E 자율주행 모델을 바닥부터 구현하는 책입니다. 좌표 변환과 BEV 융합의 기하학은 NumPy로 직접 구현하고, Transformer 인코더와 Planning Head는 PyTorch로 실제 학습시키며, 실제 자율주행 데이터셋 대신 정답을 정확히 아는 시뮬레이션 장면으로 모든 단계를 검증합니다. 센서와 좌표계(1부) → BEV 공간 융합(2부) → Transformer BEV 인코더(3부) → Planning Head와 궤적 생성(4부) → 종합과 평가(5부) 순서로 쌓아 올립니다.

이 책은 3DGS 기반 자율주행 E2E 검증 시리즈의 세 번째 책입니다. 1권("사진에서 세계로")과 2권("미분가능 렌더링과 3D Gaussian Splatting")이 카메라 포즈와 3D 장면을 재구성하는 법을 다뤘다면, 이 책은 그렇게 인식된 세계 위에서 실제로 주행 결정을 내리는 모델 자체를 다룹니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
