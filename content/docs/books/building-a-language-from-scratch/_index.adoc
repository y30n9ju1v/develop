렉서, 파서, 트리-워킹 인터프리터, Hindley-Milner 타입 추론을 거쳐 실제 MLIR 툴체인(`mlir-opt`, `mlir-runner`)으로 코드를 낮추고 JIT 실행까지 하는 작은 정적 타입 함수형 언어 `Twig`를 Python으로 바닥부터 구현하는 입문서입니다. 렉싱과 파싱(1부) → 평가와 타입(2부) → 함수, 클로저, 다형성(3부) → MLIR로 코드 생성하기(4부) → 종합과 확장(5부) 순서로 쌓아 올립니다.

이 책의 프론트엔드(렉서·파서·인터프리터·타입 추론)는 순수 Python으로 직접 구현하고, 4부부터는 이 세션 환경에 실제로 설치된 `mlir-opt`/`mlir-runner`(LLVM 프로젝트의 일부)로 진짜 낮추기와 JIT 실행까지 검증합니다. 1장에서 약속한 재귀 팩토리얼(`fact 5 = 120`)이 12장에서 실제 MLIR 컴파일 파이프라인을 통과해 정말로 `120`을 계산하는 순간이 이 책의 정점입니다.

이 책은 이 사이트의 nand2npu 시리즈(MLIR/CIRCT로 하드웨어를 방출)와 인프라를 공유하지만 방향은 반대(소프트웨어 언어를 방출)인, 독립적인 실전 프로그래밍 언어 구현 입문서입니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
