link:../nand2npu/[1권]에서 완성한 16비트 CPU에 NPU(Neural Processing Unit)를 얹어, 신경망 추론이 필요로 하는 병렬 곱셈-누산 연산을 하드웨어 레벨에서 지원하도록 확장하는 시리즈의 3권입니다. 1권과 같은 방법론 — Lean4로 명세와 안전 조건을 증명하고, 그 증명이 통과한 설계만 CIRCT를 거쳐 SystemVerilog로 방출하고, Verilator로 실행 검증하는 것 — 을 그대로 이어갑니다. NPU 하드웨어(1~5장)를 완성한 뒤에는 이미지 분류 워밍업(6장)을 거쳐, 미리 훈련된 정책망으로 슈퍼 마리오를 플레이하는 강화학습 추론(7~10장)까지 다룹니다. 훈련 자체는 이 책의 범위 밖입니다 — 다루는 것은 항상 "고정된 가중치로 정확히 추론하는가"입니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
