선형 타입·세션 타입·동시성 분리 논리·범주론이라는 이론을 실제 C++23 언어 기능(타입 상태 패턴, 이동 전용 타입, `std::span` 분할, concepts)으로 인코딩해 컴파일 타임/도구 검증으로 병렬 프로그래밍 버그를 잡는 법을 다루는 독립적인 입문서입니다. 왜 안전하지 않은가(1부) → 타입 상태로 세션 타입 흉내내기(2부) → 이동 전용 타입으로 선형성 흉내내기(3부) → 범주론적 인터페이스(4부) → 동시성 분리 논리(5부) 순서로 쌓아 올립니다.

이 책의 모든 코드는 이 세션 환경에 실제로 설치된 Apple Clang 21(`-std=c++23`)로 컴파일하고 실행해서 검증했습니다 — 컴파일이 안 되는 걸 노린 예제는 실제 컴파일러 에러 메시지를 그대로 인용하고, 데이터 경쟁·이중 해제는 ThreadSanitizer/AddressSanitizer로 실제 검출한 리포트를 그대로 보여줍니다. 각 장 끝에는 "C++17 환경이라면" 팁 박스를 두어, 그 장의 핵심 기법을 C++17로 근사하는 법과 그 근사가 잃는 것을 실제로 컴파일해 검증한 코드로 정리합니다. 맺음말은 이 네 이론을 하나의 표로 정리하면서, Rust가 그중 무엇을 언어 코어에 직접 채용했는지(그리고 RustBelt가 무엇을 형식 증명했는지)까지 짚습니다.

이 책은 `linear-and-session-types`(선형 타입·세션 타입의 Lean4 증명)와 이 사이트의 범주론 책들을 실무 언어로 잇는 다리입니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
