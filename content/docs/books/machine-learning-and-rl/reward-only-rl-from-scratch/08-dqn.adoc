== 7장의 불안정성을 실전에서 다스리기

7장에서 함수 근사 + 부트스트래핑 + 오프폴리시가 겹치면 학습이 발산할 수 있다는 걸 작은 반례로 확인했습니다. **DQN**(Deep Q-Network)은 이 세 조건을 정확히 다 갖춘 알고리즘입니다 — Q-함수를 신경망으로 근사하고, TD 목표로 부트스트랩하고, `max_a Q(s',a)`를 쓰는 오프폴리시 Q-learning입니다. DQN이 실전에서 쓸모 있는 이유는 이 조합을 없앤 게 아니라, 두 가지 장치로 **다스렸기** 때문입니다.

* **리플레이 버퍼(replay buffer)**: 최근 경험을 모아뒀다가 무작위로 섞어 미니배치를 뽑습니다 — 연속된 스텝끼리 상관관계가 큰 데이터를 그대로 학습에 쓰면(온라인 SGD) 그래디언트가 한쪽으로 쏠리기 쉬운데, 리플레이는 이 상관관계를 깹니다.
* **타깃 네트워크(target network)**: TD 목표를 계산할 때 지금 학습 중인 네트워크가 아니라, 일정 스텝마다만 갱신되는 별도의 "얼려둔" 네트워크를 씁니다 — 목표 자체가 매 스텝 흔들리면 쫓아가는 과녁이 계속 움직이는 셈이라, 목표를 잠깐씩 고정해 학습을 안정시킵니다.

== 손으로 짠 카트폴 대역 환경

`gymnasium`을 쓰지 않고, 카트폴의 물리(막대가 달린 카트를 밀어 넘어지지 않게 균형을 잡는 고전 제어 문제)를 표준 운동방정식으로 직접 구현합니다.

[source,python]
----
import numpy as np

class SimpleCartPole:
    def __init__(self, seed=0):
        self.rng = np.random.default_rng(seed)
        self.gravity = 9.8
        self.masscart, self.masspole = 1.0, 0.1
        self.total_mass = self.masscart + self.masspole
        self.length = 0.5
        self.polemass_length = self.masspole * self.length
        self.force_mag = 10.0
        self.tau = 0.02
        self.theta_threshold = 12 * 2 * np.pi / 360
        self.x_threshold = 2.4
        self.max_steps = 200

    def reset(self):
        self.state = self.rng.uniform(-0.05, 0.05, size=4)  # [위치, 속도, 각도, 각속도]
        self.steps = 0
        return self.state.copy()

    def step(self, action):
        x, x_dot, theta, theta_dot = self.state
        force = self.force_mag if action == 1 else -self.force_mag
        costheta, sintheta = np.cos(theta), np.sin(theta)
        temp = (force + self.polemass_length * theta_dot**2 * sintheta) / self.total_mass
        thetaacc = (self.gravity * sintheta - costheta * temp) / (
            self.length * (4.0/3.0 - self.masspole * costheta**2 / self.total_mass))
        xacc = temp - self.polemass_length * thetaacc * costheta / self.total_mass
        x += self.tau * x_dot; x_dot += self.tau * xacc
        theta += self.tau * theta_dot; theta_dot += self.tau * thetaacc
        self.state = np.array([x, x_dot, theta, theta_dot])
        self.steps += 1
        done = bool(x < -self.x_threshold or x > self.x_threshold
                    or theta < -self.theta_threshold or theta > self.theta_threshold
                    or self.steps >= self.max_steps)
        return self.state.copy(), 1.0, done   # 살아있는 매 스텝마다 보상 +1
----

== 리플레이 버퍼와 DQN 학습 루프

[source,python]
----
class ReplayBuffer:
    def __init__(self, capacity):
        self.capacity, self.buf, self.pos = capacity, [], 0
    def push(self, transition):
        if len(self.buf) < self.capacity:
            self.buf.append(transition)
        else:
            self.buf[self.pos] = transition
            self.pos = (self.pos + 1) % self.capacity
    def sample(self, batch_size):
        idx = rng.integers(0, len(self.buf), size=min(batch_size, len(self.buf)))
        return [self.buf[i] for i in idx]

def run_dqn(n_episodes=250, use_replay=True, use_target=True, gamma=0.99,
            batch_size=32, target_update_every=20, buffer_cap=2000):
    env = SimpleCartPole(seed=10)
    q = QNet(4, 24, 2, lr=0.005)          # 7장의 MLP를 Q-함수로 재사용
    q_target = QNet(4, 24, 2, lr=0.005)
    q_target.copy_from(q)
    buf = ReplayBuffer(buffer_cap)
    epsilon = 1.0
    ep_lengths = []
    norm = np.array([2.4, 3.0, 0.2, 3.0])  # 상태 각 차원의 스케일을 대략 맞춰줌
    for ep in range(n_episodes):
        s = env.reset(); done = False; steps = 0
        while not done:
            s_norm = s / norm
            a = rng.integers(0, 2) if rng.uniform() < epsilon else np.argmax(q.forward(s_norm[None])[0])
            s2, r, done = env.step(a)
            buf.push((s, a, r, s2, done)); s = s2; steps += 1

            batch = buf.sample(batch_size) if use_replay else [(s, a, r, s2, done)]
            S  = np.array([b[0] for b in batch]) / norm
            A  = np.array([b[1] for b in batch])
            R  = np.array([b[2] for b in batch])
            S2 = np.array([b[3] for b in batch]) / norm
            D  = np.array([b[4] for b in batch], dtype=float)

            qnet_for_target = q_target if use_target else q   # 어블레이션: 타깃망을 안 쓰면 자기 자신으로 부트스트랩
            target = R + gamma * qnet_for_target.forward(S2).max(axis=1) * (1 - D)
            q_pred = q.forward(S)
            grad = np.zeros_like(q_pred)
            idx = np.arange(len(batch))
            grad[idx, A] = 2 * (q_pred[idx, A] - target) / len(batch)
            q.backward(grad)

            if use_target and steps % target_update_every == 0:
                q_target.copy_from(q)
        ep_lengths.append(steps)
        epsilon = max(0.05, epsilon * 0.985)
    return np.array(ep_lengths)
----

`use_replay`, `use_target` 두 플래그로 4가지 조합(둘 다 사용 / 리플레이만 뺌 / 타깃망만 뺌 / 둘 다 뺌)을 만들어 어블레이션을 실행합니다. 에피소드 길이(막대를 얼마나 오래 세워뒀는지, 최대 200)가 성능 지표입니다.

== 실행 결과: 250 에피소드, 4가지 조합

full      = run_dqn(use_replay=True,  use_target=True)
no_replay = run_dqn(use_replay=False, use_target=True)

실제로 실행하면(같은 환경 시드, 마지막 20 에피소드 평균 길이 기준):

----
Full DQN (replay+target): first20avg=25.9 last20avg=179.6 max=200 std_last20=28.9
No replay (target only):  first20avg=24.2 last20avg=9.7  max=73  std_last20=1.0
No target (replay only):  first20avg=20.9 last20avg=9.6  max=200 std_last20=1.1

리플레이 버퍼와 타깃 네트워크를 둘 다 쓴 완전한 DQN만 마지막 20 에피소드 평균 179.6(최댓값 200에 근접)까지 올라갑니다 — 처음 20 에피소드 평균(25.9)의 7배 가까이 개선됐습니다. 반면 셋 다(리플레이만 제거, 타깃망만 제거, 둘 다 제거) 마지막 20 에피소드 평균이 9.6~9.7 사이에 몰려 있습니다 — 이건 개선이 아니라 **붕괴**입니다. 처음 20 에피소드 평균(19~24 정도, 무작위 정책이 우연히 버티는 수준)보다도 낮은 값으로, 학습이 진행될수록 오히려 더 빨리 넘어지는 정책을 배웠다는 뜻입니다. 흥미로운 건 "타깃망 없음" 조합이 한 에피소드에서 우연히 최댓값(200)을 찍기도 했다는 점입니다(`max=200`) — 그런데도 마지막 20개 평균은 9.6으로 무너져 있다는 게, 타깃망 없이는 어쩌다 좋은 정책을 만나도 그 자리에 머물지 못하고 계속 흔들린다는 걸 보여줍니다. 표준편차(`std_last20`)도 완전한 DQN만 28.9로 크고(마지막 구간에도 여전히 좋은 에피소드와 그렇지 않은 에피소드가 섞여 있다는 뜻) 나머지 셋은 1.0~1.2로 아주 작은데, 이건 안정된 게 아니라 "항상 빨리 넘어지는" 하나의 나쁜 행동으로 수렴해 더 이상 변화가 없다는 뜻입니다.

이 결과는 7장의 반례가 예고한 것과 정확히 같은 모양입니다 — 부트스트랩 목표가 계속 움직이는 채로(타깃망 제거) 상관된 데이터로(리플레이 제거) 학습하면 Q 추정치가 안정된 정책에 정착하지 못합니다. 두 장치를 모두 넣었을 때만 이 카트폴 대역 환경에서 실제로 "학습이 진행될수록 좋아지는" 곡선을 얻었습니다.

== 이 장에서 확인한 것

* 리플레이 버퍼와 타깃 네트워크를 둘 다 쓴 DQN은 250 에피소드 안에 마지막 20 에피소드 평균 179.6(최대 200)까지 도달했습니다.
* 둘 중 하나라도 빼면 마지막 구간 평균이 9.6~9.7로 무너집니다 — 개선이 아니라 확실한 성능 붕괴입니다.
* 이 붕괴 패턴은 7장에서 본 deadly triad 반례(함수 근사+부트스트랩+오프폴리시가 겹치면 발산)가 실제 제어 문제에서도 그대로 나타난다는 걸 실측으로 확인해줍니다.

다음 장에서는 Q-함수를 배우는 대신 정책 자체를 직접 신경망으로 표현하고 그래디언트를 따라 개선하는 **정책 경사법(policy gradient)** — REINFORCE — 으로 넘어갑니다. DQN과 전혀 다른 원리이지만, 마찬가지로 신경망을 통째로 최적화한다는 점에서 이 장의 MLP와 학습 루프 구조를 다시 재사용합니다.
