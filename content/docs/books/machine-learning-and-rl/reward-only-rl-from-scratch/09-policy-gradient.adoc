== 가치를 배우는 대신 정책을 직접 배운다

8장의 DQN은 `Q(s,a)`라는 가치를 배우고, 행동은 그 가치에서 `argmax`를 취해 간접적으로 얻었습니다. **정책 경사법(policy gradient)**은 다른 접근입니다 — 정책 자체를 파라미터 `θ`를 가진 신경망 `π_θ(a|s)`(상태를 보고 행동에 대한 확률분포를 출력)로 표현하고, "기대 리턴을 높이는 방향"으로 `θ`를 직접 그래디언트 상승시킵니다. 이 장에서 구현하는 **REINFORCE**는 그 중 가장 단순한 형태입니다.

[stem]
++++
\nabla_\theta J(\theta) = \mathbb{E}\left[ \sum_t \nabla_\theta \log \pi_\theta(a_t|s_t) \cdot G_t \right]
++++

"이 행동을 선택할 로그확률의 그래디언트에, 그 뒤로 실제로 받은 리턴 `G_t`를 곱해서 더한다"는 뜻입니다 — 결과가 좋았던 에피소드(`G_t`가 큼)의 행동들은 확률을 더 올리고, 결과가 나빴던 에피소드는 확률을 낮추는 방향으로 움직입니다.

== 정책망과 REINFORCE 구현

출력층에 소프트맥스를 얹어 행동에 대한 확률분포를 내놓는 정책망을 만듭니다. 8장의 `QNet`과 거의 같은 뼈대지만, 손실이 아니라 로그확률의 그래디언트를 역전파합니다.

[source,python]
----
import numpy as np

class PolicyNet:
    def __init__(self, n_in, n_hidden, n_out, lr=0.01, seed=0):
        r = np.random.default_rng(seed)
        self.W1 = r.normal(0, np.sqrt(2/n_in), (n_in, n_hidden))
        self.b1 = np.zeros(n_hidden)
        self.W2 = r.normal(0, np.sqrt(2/n_hidden), (n_hidden, n_out))
        self.b2 = np.zeros(n_out)
        self.lr = lr

    def forward(self, x):
        self.x = x
        self.z1 = x @ self.W1 + self.b1
        self.h1 = np.maximum(0, self.z1)
        self.z2 = self.h1 @ self.W2 + self.b2
        z = self.z2 - self.z2.max(axis=-1, keepdims=True)
        expz = np.exp(z)
        self.probs = expz / expz.sum(axis=-1, keepdims=True)   # 소프트맥스
        return self.probs

    def backward(self, grad_logits):
        gW2 = self.h1.T @ grad_logits
        gb2 = grad_logits.sum(axis=0)
        gh1 = grad_logits @ self.W2.T
        gz1 = gh1 * (self.z1 > 0)
        gW1 = self.x.T @ gz1
        gb1 = gz1.sum(axis=0)
        self.W1 += self.lr * gW1; self.b1 += self.lr * gb1   # 상승(ascent)이라 +
        self.W2 += self.lr * gW2; self.b2 += self.lr * gb2
----

한 에피소드를 다 굴리고 나서, 각 스텝의 리턴 `G_t`(할인된 미래 보상의 합)를 뒤에서부터 계산하고, `∇log π(a|s) = onehot(a) - probs`(소프트맥스의 표준적인 로그미분)에 `G_t`를 곱해 역전파합니다.

[source,python]
----
def reinforce(n_episodes=300, gamma=0.99, lr=0.01, use_baseline=False, seed=0):
    rng = np.random.default_rng(seed)
    env = SimpleCartPole(seed=seed + 100)
    policy = PolicyNet(4, 24, 2, lr=lr, seed=seed)
    ep_lengths = []
    baseline = 0.0
    for ep in range(n_episodes):
        states, actions, rewards = run_episode(env, policy, rng)
        T = len(rewards)
        returns = np.zeros(T)
        G = 0.0
        for t in reversed(range(T)):
            G = rewards[t] + gamma * G
            returns[t] = G

        advantages = returns
        if use_baseline:
            baseline = 0.9 * baseline + 0.1 * returns[0]     # 에피소드 리턴의 이동평균
            advantages = returns - baseline                   # 베이스라인을 뺀 값으로 대체

        S = np.array(states)
        probs = policy.forward(S)
        onehot = np.zeros_like(probs)
        onehot[np.arange(T), np.array(actions)] = 1.0
        grad_logits = (onehot - probs) * advantages[:, None] / T
        policy.backward(grad_logits)
        ep_lengths.append(T)
    return np.array(ep_lengths)
----

== 분산 문제: 시드마다 결과가 얼마나 달라지는가

REINFORCE는 한 에피소드 전체의 리턴을 그대로 그래디언트 스케일로 쓰기 때문에, 우연히 운 좋았던(또는 나빴던) 에피소드 하나가 학습 방향을 크게 흔듭니다. 6개의 다른 난수 시드로 각각 300 에피소드씩 학습시켜, 마지막 30 에피소드 평균 길이(카트폴을 얼마나 오래 버텼는지, 최대 200)가 시드마다 얼마나 다른지 봅니다.

[source,python]
----
seeds = list(range(6))
no_base_runs = [reinforce(use_baseline=False, seed=sd) for sd in seeds]
no_base_finals = [r[-30:].mean() for r in no_base_runs]
print("베이스라인 없음, 시드별 마지막30평균:", [round(x,1) for x in no_base_finals])
print(f"  평균={np.mean(no_base_finals):.1f} 표준편차={np.std(no_base_finals):.1f}")
----

실제로 실행하면:

----
베이스라인 없음: [89.1, 88.3, 100.4, 179.9, 149.6, 171.2]
  평균=129.8 표준편차=38.4
----

같은 알고리즘, 같은 하이퍼파라미터인데 시드만 바꿨을 뿐인데 마지막 성능이 88(거의 초기 수준)부터 180(거의 최대치)까지 걸쳐 있습니다. 표준편차(38.4)가 평균(129.8)의 30%에 달할 만큼 큽니다 — "REINFORCE가 이 문제를 풀었다"고 말하려면 어느 시드를 기준으로 하느냐에 따라 완전히 다른 결론이 나올 수 있다는 뜻입니다.

== 베이스라인으로 분산 줄이기

베이스라인 `b`를 리턴에서 빼는 것(`G_t - b`)은 그래디언트의 기댓값을 바꾸지 않으면서(수학적으로 편향을 추가하지 않으면서) 분산만 줄이는 표준적인 기법입니다. 이 장에서는 가장 단순한 베이스라인 — 최근 에피소드 리턴의 이동평균 — 을 씁니다.

[source,python]
----
base_runs = [reinforce(use_baseline=True, seed=sd) for sd in seeds]
base_finals = [r[-30:].mean() for r in base_runs]
print("베이스라인 있음, 시드별 마지막30평균:", [round(x,1) for x in base_finals])
print(f"  평균={np.mean(base_finals):.1f} 표준편차={np.std(base_finals):.1f}")
print("분산 비율(없음/있음):", np.var(no_base_finals) / np.var(base_finals))
----

실제로 실행하면:

----
베이스라인 있음: [200.0, 198.9, 200.0, 198.1, 195.4, 198.4]
  평균=198.5 표준편차=1.5
분산 비율(없음/있음): 615.7
----

결과가 극적입니다 — 베이스라인을 추가하자 6개 시드 전부 198~200 사이로 몰렸고(거의 항상 최대치인 200에 도달), 표준편차가 38.4에서 1.5로, 분산은 무려 616배 줄었습니다. 평균 성능도 129.8에서 198.5로 올라갔습니다 — 분산이 줄어들면서 학습 자체가 더 안정적으로 좋은 정책에 수렴한 것입니다. 베이스라인이 하는 일은 단순합니다 — "이 에피소드가 평균보다 잘했는지 못했는지"만으로 그래디언트 크기를 정하니까, 모든 리턴이 우연히 다 양수인 문제(카트폴처럼 매 스텝 +1을 받는 경우, 나쁜 에피소드도 절대적으로는 항상 "양의" 리턴)에서도 실제로 "평균 이상/이하"를 구분해 방향을 정확하게 잡아줍니다.

== 이 장에서 확인한 것

* REINFORCE는 정책망을 직접 그래디언트로 개선해, 리플레이나 타깃망 없이도 카트폴 대역 문제를 풀 수 있습니다.
* 베이스라인이 없으면 같은 세팅에서도 시드에 따라 최종 성능이 88~180 사이로 크게 갈립니다(표준편차 38.4).
* 리턴의 이동평균을 베이스라인으로 빼주는 것만으로 표준편차가 1.5까지(약 1/26), 분산은 616배 줄어들고 평균 성능도 더 좋아졌습니다 — 실제로 측정한 분산 감소입니다.

다음 장에서는 이 베이스라인을 "이동평균" 같은 단순한 스칼라가 아니라, 상태마다 다른 값을 예측하는 별도의 신경망(critic)으로 대체한 **Actor-Critic**을 구현하고, 여기에 PPO의 클리핑까지 더해 정책이 한 번에 너무 많이 바뀌어 무너지는 것("정책 붕괴")을 막습니다. 이 10장의 결과가 4부에서 마리오에 그대로 쓰일 알고리즘입니다.
