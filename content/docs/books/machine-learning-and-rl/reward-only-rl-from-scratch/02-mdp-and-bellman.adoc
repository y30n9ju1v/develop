== 여러 스텝으로 늘리기: 마르코프 결정 과정

1장의 bandit은 스텝이 하나뿐이었습니다 — 팔을 당기고, 보상을 받고, 끝. 실제 문제(그리드월드를 걷는 것, 마리오를 플레이하는 것)는 스텝이 여러 개 이어지고, 지금 한 행동이 다음에 어떤 상태에 놓일지까지 바꿉니다. 이걸 정식화한 게 **마르코프 결정 과정(Markov Decision Process, MDP)**이고, 다섯 요소로 이루어집니다.

* **상태(state) `S`**: 지금 세계가 어떤 모습인지.
* **행동(action) `A`**: 에이전트가 고를 수 있는 선택지.
* **전이 확률(transition probability) `P(s'|s,a)`**: 상태 `s`에서 행동 `a`를 하면 다음 상태가 `s'`가 될 확률. "마르코프"라는 이름은 이 확률이 과거 전체가 아니라 **현재 상태 `s`에만** 의존한다는 가정에서 옵니다.
* **보상(reward) `R(s,a)`**: 그 행동을 했을 때 받는 스칼라 보상.
* **할인율(discount) `gamma ∈ [0,1]`**: 먼 미래의 보상을 지금 보상보다 얼마나 깎아서 셀지.

== 벨만 방정식: 가치를 재귀로 정의하기

상태 `s`의 **가치** `V(s)`를 "그 상태에서 시작해 앞으로 받을 보상의 할인합의 기댓값"으로 정의하면, 이 값은 스스로를 재귀적으로 참조하는 방정식을 만족합니다 — 이게 **벨만 방정식**입니다.

[stem]
++++
V(s) = R(s) + \gamma \sum_{s'} P(s'|s) V(s')
++++

"지금 상태의 가치 = 지금 보상 + 할인된 다음 상태 가치의 기댓값"이라는 뜻입니다. 이 장에서는 행동이 하나뿐인 가장 단순한 버전(마르코프 보상 과정, MRP)으로 시작해서 이 재귀 구조 자체를 확인하고, 3장부터 행동 선택(정책)을 얹습니다.

== 3상태 체인으로 직접 풀어보기

상태 0 → 1 → 2로 흘러가는 작은 체인을 만듭니다. 상태 2는 흡수 상태(한번 들어가면 못 나옴)입니다.

[source,python]
----
import numpy as np

P = np.array([
    [0.1, 0.9, 0.0],
    [0.0, 0.2, 0.8],
    [0.0, 0.0, 1.0],  # 상태 2는 흡수 상태
])
R = np.array([1.0, 2.0, 0.0])  # 각 상태에 머물 때 받는 보상
gamma = 0.9
n = 3
----

이 문제는 두 가지 방법으로 풀 수 있습니다.

**방법 1 — 닫힌 해(선형대수)**: 벨만 방정식 `V = R + gamma * P @ V`를 `V`에 대해 정리하면 `(I - gamma*P) V = R`이라는 선형 연립방정식이 되고, `numpy.linalg.solve`로 한 번에 풉니다.

[source,python]
----
V_closed = np.linalg.solve(np.eye(n) - gamma * P, R)
----

**방법 2 — 반복 계산(가치 반복의 원형)**: 벨만 방정식을 대입 규칙으로 삼아 `V`를 0에서 시작해 계속 업데이트합니다. 이게 4장에서 다룰 가치 반복(value iteration)의 씨앗입니다.

[source,python]
----
V_iter = np.zeros(n)
history = []
for k in range(200):
    V_new = R + gamma * P @ V_iter
    diff = np.max(np.abs(V_new - V_iter))
    V_iter = V_new
    history.append(diff)
    if diff < 1e-10:
        break
----

== 실행 결과: 두 방법이 정확히 일치하는가

[source,python]
----
print("closed-form V:", V_closed)
print(f"iterative V after {k+1} iterations:", V_iter)
print("max diff:", np.max(np.abs(V_iter - V_closed)))
----

실제로 실행하면:

----
closed-form V: [3.26990083 2.43902439 0.        ]
iterative V after 17 iterations: [3.26990083 2.43902439 0.        ]
max diff between closed-form and iterative: 4.80e-12
convergence: iter 0 diff=2.000000, iter 5 diff=0.003301, iter 16 diff=2.19e-11
----

두 방법이 소수점 12자리까지 일치합니다 — 우연이 아니라, 둘 다 같은 벨만 방정식의 해를 구하고 있기 때문입니다. 반복 계산은 17번 만에 `1e-10` 이하로 수렴했고, 수렴 속도 자체도 확인할 수 있습니다 — 첫 반복의 오차(2.0)가 5번째 반복에서 이미 0.0033까지 떨어졌습니다. `gamma * P`의 스펙트럼 반경이 1보다 작기 때문에 이 반복이 항상 유일한 고정점으로 수렴한다는 것이 벨만 방정식이 잘 정의되는 이유이기도 합니다.

상태 2(흡수 상태, 보상 0)의 가치가 정확히 0이라는 것도 직관과 맞습니다 — 거기 들어가면 더 받을 보상이 없으니까요. 상태 0의 가치(3.27)가 상태 1의 가치(2.44)보다 높은 것도, 상태 0에서 상태 1로 갈 확률이 높고(0.9) 상태 1의 보상(2.0)이 상태 0의 보상(1.0)보다 크다는 걸 감안하면 납득이 됩니다.

== 다음 장

이 장은 행동이 하나뿐인 경우(마르코프 보상 과정)만 다뤘습니다 — "어떤 행동을 고를지"라는 선택 자체가 없었습니다. 다음 장에서는 행동 선택 규칙인 **정책(policy)**을 도입하고, 정책에 따라 가치가 어떻게 달라지는지, 그리고 "가장 좋은 정책"이 무엇을 뜻하는지 정의합니다.
