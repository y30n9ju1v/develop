== 이 책이 하려는 것

AICE(AI Certificate for Everyone) Associate는 정형 데이터를 다루고, 그 데이터로 머신러닝·딥러닝 모델을 만들어 실제로 학습시키는 능력을 평가하는 실기형 자격증입니다. 이론 시험이 아니라 "주어진 데이터로 정확도 얼마 이상의 모델을 완성하라"는 실습 문제를 코드로 풀어야 합니다 — 그러니 개념을 아는 것만으로는 부족하고, Pandas로 데이터를 다루고 Keras로 모델을 짜는 손이 실제로 움직여야 합니다.

이 책은 그 실기 감각을 기르는 데 집중합니다. 데이터를 불러오고(1부), 그 데이터를 눈으로 확인하고 전통적인 머신러닝으로 먼저 풀어본 다음(2부), 같은 문제를 신경망으로 다시 풀고(3부), 마지막으로 시험에 나올 법한 문제 유형을 처음부터 끝까지 통째로 풀어보는(4부) 순서로 쌓아 올립니다.

== 이 책의 방식: 실제 라이브러리로, 실제로 실행해서

이 시리즈의 앞선 책들이 NumPy로 수식을 손수 구현하고 유한차분으로 검증했다면, 이 책은 다릅니다 — AICE 시험 자체가 Pandas, scikit-learn, TensorFlow/Keras라는 실제 라이브러리를 그대로 쓰는 시험이므로, 이 책도 그 라이브러리들을 실제로 설치하고 실행해서 나온 숫자를 그대로 싣습니다. `model.fit()`을 실제로 돌려서 나온 정확도, `pd.read_csv()`로 실제로 읽은 데이터의 결측치 개수 — 이 책에 나오는 모든 출력은 실제 실행 결과입니다.

== 데이터셋

이 책 전반에 걸쳐 하나의 가상 통신사 고객 데이터셋(나이·성별·가입기간·요금제·만족도·이탈 여부)을 계속 사용합니다 — 실제 시험에서 자주 나오는 "고객 이탈 예측", "만족도 회귀 예측" 같은 문제 유형을 그대로 반영해 이 책을 위해 직접 생성한 데이터입니다. 10장의 이미지 데이터만 예외적으로, scikit-learn에 내장된 손글씨 숫자 데이터셋(load_digits)을 씁니다.
