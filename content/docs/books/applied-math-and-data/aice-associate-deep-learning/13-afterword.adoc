== 지나온 길

1부에서는 지저분한 실전 데이터를 다루는 기본기를 다졌습니다 — 결측치가 섞이면 정수 컬럼도 실수형으로 바뀐다는 것, 평균은 이상치 하나에도 크게 흔들리지만 중앙값은 거의 흔들리지 않는다는 것, 그리고 순서 없는 범주형 데이터에 Label Encoding을 잘못 쓰면 알파벳 순서라는 우연이 의미 없는 "크기"를 만들어낸다는 것까지 직접 확인했습니다.

2부에서는 시각화로 데이터의 관계를 먼저 눈으로 확인한 뒤, 선형회귀로 다항 특성이 얼마나 쉽게 과적합을 만드는지, 그리고 클래스 불균형 상황에서 정확도만 보면 "아무것도 안 하는 모델"에게 속을 수 있다는 것을 재현율로 확인했습니다. 랜덤포레스트의 특성 중요도가 연속형 변수를 과대평가하는 편향까지, 지표 하나를 맹신하면 안 되는 이유들을 하나씩 겪어봤습니다.

3부에서는 Keras로 넘어와 스케일링이 학습 속도에 실제로 얼마나 영향을 주는지 손실 곡선으로 확인하고, 이진·다중 분류의 차이(sigmoid/softmax, 손실 함수, 레이블 형태)를 정리한 뒤, 신경망에서 과적합이 얼마나 극적으로 나타날 수 있는지(train MSE 17 vs val MSE 113)와 그걸 Dropout·EarlyStopping이 어떻게 막는지 직접 재현했습니다.

4부에서는 CNN의 기본 구조와 파라미터 효율을 확인하고, 모델을 저장·복원해도 예측이 완전히 동일하다는 것과 혼동행렬로 클래스별 약점을 찾는 법을 배운 뒤, 마지막으로 이 모든 것을 12단계 파이프라인 하나로 처음부터 끝까지 통째로 실행하며 마무리했습니다.

== 이 책이 다루지 않은 것

이 책은 정형 데이터와 작은 이미지 데이터에 집중했습니다. 의도적으로 남겨둔 것들이 많습니다 — 자연어(텍스트) 데이터 전처리와 임베딩, RNN/LSTM 같은 시계열 모델, 전이학습(pretrained 모델을 가져와 미세조정하는 것), 하이퍼파라미터 탐색을 자동화하는 도구(Grid Search, Optuna 등), 그리고 모델을 실제 서비스로 배포하는 과정입니다. 이들은 AICE Associate보다 상위 등급(Professional)이나 실무에서 자연스럽게 이어서 배우게 되는 것들입니다.

== 시험 직전에 더 연습하면 좋은 것

이 책에서 다진 흐름을 몸에 완전히 익히려면, 이 책의 가상 데이터가 아니라 실제 공개 데이터셋(예: Kaggle의 Telco Customer Churn, Titanic 등)으로 12장의 파이프라인을 몇 번 더 반복해보는 걸 권합니다 — 실전 데이터는 이 책의 예제보다 훨씬 지저분하고(컬럼명에 오타가 있거나, 결측치 표시가 `NaN`이 아니라 `"?"`나 `"unknown"` 같은 문자열로 되어 있거나), 여러분이 예상 못 한 방식으로 여러분을 시험할 것입니다. 그럴 때마다 이 책에서 배운 순서 — 먼저 `head()`와 `isna().sum()`으로 상태를 파악하고, 결측치·이상치를 처리하고, 인코딩하고, 베이스라인부터 계산한 뒤 모델을 학습시키는 것 — 을 침착하게 따라가면 됩니다.

딥러닝 실기를 "이해했다"는 건 Keras 문법을 외웠다는 뜻이 아니라, 모델의 학습이 이상하게 굴 때 "스케일링을 빼먹었나, 베이스라인을 확인 안 했나, 과적합인가, 클래스 불균형을 놓쳤나"를 순서대로 짚어볼 수 있게 되는 것입니다. 이 책이 그 진단 능력의 첫걸음을 놓아줬다면, 그것으로 충분합니다. 시험 잘 보시길 바랍니다.
