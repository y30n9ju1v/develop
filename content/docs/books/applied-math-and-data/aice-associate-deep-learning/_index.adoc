Pandas로 데이터를 정리하고, 전통적인 머신러닝으로 먼저 풀어본 뒤, 같은 문제를 Keras 신경망으로 다시 풀고, 마지막으로 시험형 문제를 처음부터 끝까지 통째로 실습하는 AICE(AI Certificate for Everyone) Associate 실전 대비서입니다. 이 시리즈의 다른 책들과 달리 수식을 손으로 구현하는 대신, 실제 시험에서 그대로 쓰는 Pandas·scikit-learn·TensorFlow/Keras를 실제로 설치하고 실행해서 나온 결과를 그대로 싣습니다. Pandas로 데이터 다루기(1부) → EDA와 머신러닝 기초(2부) → Keras로 딥러닝(3부) → 시험형 문제 실전(4부) 순서로 쌓아 올립니다.

이 책 전반에 걸쳐 가상의 통신사 고객 데이터셋(나이·성별·가입기간·요금제·만족도·이탈 여부)을 계속 사용하며, 10장의 이미지 데이터만 scikit-learn에 내장된 손글씨 숫자 데이터셋을 씁니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
