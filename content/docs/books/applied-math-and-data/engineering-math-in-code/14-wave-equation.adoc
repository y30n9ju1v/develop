13장의 열방정식과 이 장의 파동방정식은 언뜻 보면 형제처럼 닮았습니다 — 둘 다 $\partial^2 u/\partial x^2$가 등장하는 편미분방정식이고, 둘 다 분리변수법으로 사인 모드들의 합으로 풀립니다. 하지만 딱 하나 다른 점이 완전히 다른 물리를 만듭니다.

== 파동방정식: 시간에 대해서도 2계다

팽팽하게 당겨진 줄(기타 줄처럼)의 변위 `u(x,t)`는 이렇게 움직입니다.

[stem]
++++
\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}
++++

열방정식(`∂u/∂t = α∂²u/∂x²`)과 비교하면, 왼쪽이 $\partial u/\partial t$(1계)가 아니라 $\partial^2 u/\partial t^2$(2계)입니다. 이 차이 하나가 3장에서 이미 만났던 구분(1계 ODE는 지수적으로 사라지고, 2계 ODE는 진동할 수 있다)을 편미분방정식에서도 그대로 재현합니다.

== 분리변수법으로 풀면 감쇠 없는 진동이 나온다

같은 방식(`u=X(x)T(t)`로 놓고 대입)으로 분리하면, 이번엔 시간 부분 `T(t)`가 지수함수가 아니라 **삼각함수**로 나옵니다. 양 끝이 고정된 줄(`u(0,t)=u(L,t)=0`)이 처음엔 어떤 모양(`f(x)`)으로 잡혔다가 속도 0으로 놓였다면, 해는 이렇습니다.

[stem]
++++
u(x,t) = \sum_{n=1}^{\infty} A_n \sin\!\left(\frac{n\pi x}{L}\right) \cos\!\left(\frac{n\pi c t}{L}\right)
++++

13장의 열방정식 해(`e^{-\alpha(n\pi/L)^2 t}`, 시간이 지나면 0으로 사라짐)와 이 식(`cos(n\pi c t/L)`, 시간이 지나도 크기가 절대 안 줄어듦)을 나란히 놓으면 차이가 선명합니다 — **감쇠하는 지수함수 대 감쇠 없는 삼각함수**입니다.

== 단일 모드로 시작해서 수치해와 비교하기

가장 단순한 경우(`u(x,0)=sin(πx/L)`, 초기 속도 0)를 확인합니다. 이땐 `u(x,t) = sin(πx/L)cos(πct/L)`이 해석해입니다. 2계 시간 미분을 다루려면 13장의 방법(공간은 유한차분, 시간은 `solve_ivp`)에 속도 `v=∂u/∂t`를 추가한 상태로 확장해야 합니다 — 3장에서 2계 ODE를 `[x, v]` 시스템으로 바꿨던 것과 정확히 같은 요령입니다.

[source,python]
----
import numpy as np
from scipy.integrate import solve_ivp

L, c = 1.0, 2.0
N = 60
x = np.linspace(0, L, N+2)
dx = x[1]-x[0]
xi = x[1:-1]

u0 = np.sin(np.pi*xi/L)
v0 = np.zeros_like(u0)   # 초기 속도 0

def rhs(t, y):
    u, v = y[:N], y[N:]
    u_full = np.concatenate(([0.0], u, [0.0]))
    d2u = (u_full[2:] - 2*u_full[1:-1] + u_full[:-2]) / dx**2
    return np.concatenate([v, c**2 * d2u])   # [du/dt, dv/dt] = [v, c^2 * u_xx]

y0 = np.concatenate([u0, v0])
t_eval = [0, 0.25, 0.5, 0.75, 1.0]
sol = solve_ivp(rhs, [0, 1.0], y0, t_eval=t_eval, rtol=1e-10, atol=1e-12)

for i, tv in enumerate(t_eval):
    analytical = np.sin(np.pi*xi/L) * np.cos(np.pi*c*tv/L)
    err = np.max(np.abs(sol.y[:N, i] - analytical))
    print(f"t={tv}: max abs err = {err:.3e}")
----

[source]
----
t=0: max abs err = 0.000e+00
t=0.25: max abs err = 1.735e-04
t=0.5: max abs err = 6.029e-08
t=0.75: max abs err = 5.206e-04
t=1.0: max abs err = 2.411e-07
----

모든 시점에서 오차가 작습니다(`1e-4` 이하) — 열방정식과 독립적으로 다시 확인한, "손으로 유도한 분리변수법 해"와 "공간·시간을 둘 다 수치적으로 근사한 해"가 일치한다는 결과입니다.

== 진폭이 전혀 안 줄어든다 — 한 주기가 지나면 원래대로 돌아온다

이 파동의 주기는 `T = 2L/c = 1.0초`입니다(`cos(πct/L)`가 `t=0`에서 `1`, `t=0.5`에서 `-1`, `t=1.0`에서 다시 `1`이 되므로). `t=1.0`, 즉 정확히 한 주기가 지난 시점의 파형을 `t=0`(초기 상태)과 비교합니다.

[source,python]
----
print("u(x,0) vs u(x,1.0) [한 주기 후], 일치해야 함:")
print("max diff:", np.max(np.abs(sol.y[:N,0] - sol.y[:N,-1])))
----

[source]
----
max diff: 2.4107522822447436e-07
----

거의 완전히 일치합니다(`2.4e-7`은 유한차분 근사 오차일 뿐입니다) — **한 주기가 지나면 줄은 정확히 원래 모양으로 돌아옵니다.** 13장의 열방정식에서 20초가 지나면 온도 진폭이 `0.9995`에서 `0.14`까지 사그라들었던 것과 완전히 다른 그림입니다 — 열은 에너지가 흩어지며 매끈해지지만(비가역적), 이상적인 줄의 진동은 에너지를 잃지 않고 계속 반복합니다(가역적). 이 차이가 정확히 방정식에서 $\partial u/\partial t$(1계, 감쇠하는 지수함수를 낳음)와 $\partial^2 u/\partial t^2$(2계, 감쇠 없는 삼각함수를 낳음)의 차이에서 나옵니다.

== 직접 해보기

* 13장에서 열방정식은 최고 온도가 시간이 지날수록 절대 안 올라간다는(최대원리) 걸 확인했습니다. 파동방정식은 대신 **에너지가 보존됩니다** — 운동에너지(`½Σv²·dx`)와 위치에너지(변형 정도를 나타내는 `½c²Σ(du/dx)²·dx`)를 더한 전체 에너지가 시간이 지나도 일정한지 확인해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def energy(u, v):
    u_full = np.concatenate(([0.0], u, [0.0]))
    du = np.diff(u_full)/dx
    KE = 0.5*np.sum(v**2)*dx
    PE = 0.5*c**2*np.sum(du**2)*dx
    return KE+PE

t_eval = np.linspace(0, 2, 9)
sol2 = solve_ivp(rhs, [0, 2.0], y0, t_eval=t_eval, rtol=1e-10, atol=1e-12)
Es = [energy(sol2.y[:N,i], sol2.y[N:,i]) for i in range(len(t_eval))]
print("energy at each time:", Es)
print("max deviation from initial:", np.max(np.abs(np.array(Es)-Es[0])))
----

[source]
----
energy at each time: [9.867423077091363, 9.867423076714317, ..., 9.867423074067181]
max deviation: 3.0241817938758686e-09
----

에너지가 `9.867423...`에서 소수점 8자리까지 거의 안 변합니다(남은 미세한 변화는 공간을 유한개의 점으로 근사한 오차일 뿐입니다). 진동하는 동안 운동에너지와 위치에너지가 서로 주고받히면서도(줄이 가장 많이 휘었을 때는 위치에너지가 최대·운동에너지가 최소, 줄이 평평하게 지나갈 때는 그 반대) 총합은 절대 안 줄어듭니다 — 13장의 열방정식이 "최댓값이 절대 안 늘어난다"는 부등식으로 에너지를 잃는 것과 정반대로, 파동방정식은 등식(보존)으로 에너지를 지킵니다.

== 요약

* 파동방정식(`∂²u/∂t² = c²∂²u/∂x²`)이 열방정식과 형태는 비슷하지만 시간에 대해 2계라는 점이, 해를 지수함수 대신 삼각함수로 만든다는 걸 분리변수법으로 확인했습니다.
* 단일 모드 초기조건에서 이 해석해가 공간·시간을 둘 다 수치적으로 근사한 해와 잘 일치한다는 걸 확인했습니다.
* 한 주기(`t=1.0초`)가 지나면 파형이 초기 상태로 거의 정확히 돌아온다는 것을 실제로 계산해, 파동방정식이 열방정식과 달리 에너지를 잃지 않고 영원히 반복한다는 걸 눈으로 확인했습니다 — 방정식의 시간 미분 차수(1계 대 2계) 하나가 "사그라드는가, 영원히 진동하는가"라는 완전히 다른 물리를 결정합니다.
