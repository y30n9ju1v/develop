13장의 열방정식과 이 장의 파동방정식은 겉보기엔 형제처럼 닮았습니다. 하지만 **시간 미분의 차수(1계냐 2계냐)**라는 딱 하나의 차이가 완전히 정반대의 물리적 세계를 만듭니다.

== 파동방정식: 시간에 대해서도 2계다

팽팽하게 당겨진 기타 줄의 변위 $u(x,t)$는 다음 파동방정식을 따릅니다:

[stem]
++++
\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}
++++

열방정식($\partial u/\partial t = \alpha \partial^2 u/\partial x^2$)과 비교해 보면 좌변이 1계 미분이 아니라 **가속도를 뜻하는 2계 미분 $\partial^2 u / \partial t^2$**입니다

....
           [ 열방정식 vs 파동방정식의 결정적 성질 대비 ]

   【 13장 열방정식 (시간 1계) 】              【 14장 파동방정식 (시간 2계) 】
   • ∂u/∂t = α ∂²u/∂x²                        • ∂²u/∂t² = c² ∂²u/∂x²
   • 시간 해: e^(-α n² t) (지수 감쇠)          • 시간 해: cos(n c t) (삼각함수 진동)
   • 에너지가 흩어지며 영원히 사그라듦!        • 에너지가 보존되며 영원히 주기적 반복!
   • 【 비가역적 확산 현상 】                  • 【 가역적 파동 전파 현상 】
....

== 분리변수법으로 풀면 감쇠 없는 진동이 나온다

양 끝이 고정된 줄($u(0,t)=u(L,t)=0$)을 당겼다 놓았을 때의 해석해는 다음과 같습니다:

[stem]
++++
u(x,t) = \sum_{n=1}^\infty A_n \sin\left(\frac{n\pi x}{L}\right) \cos\left(\frac{n\pi c t}{L}\right)
++++

시간 항이 $e^{-k t}$가 아니라 **$\cos(\omega t)$**입니다. 진폭이 시간이 흘러도 결코 줄어들지 않습니다

== 한 주기 후 완벽하게 원래 모양으로 복귀

이 파동의 주기는 $T = 2L/c = 1.0\text{초}$입니다. 공간 유한차분과 `solve_ivp`로 시뮬레이션하여 1초 뒤 원래 모양으로 돌아오는지 확인합니다.

[source,python]
----
import numpy as np
from scipy.integrate import solve_ivp

L, c = 1.0, 2.0
N = 60
x = np.linspace(0, L, N+2)
dx = x[1] - x[0]
xi = x[1:-1]

u0 = np.sin(np.pi*xi/L)
v0 = np.zeros_like(u0)   # 초기 속도 0

def rhs(t, y):
    u, v = y[:N], y[N:]
    u_full = np.concatenate(([0.0], u, [0.0]))
    d2u = (u_full[2:] - 2*u_full[1:-1] + u_full[:-2]) / dx**2
    return np.concatenate([v, c**2 * d2u])

y0 = np.concatenate([u0, v0])
sol = solve_ivp(rhs, [0, 1.0], y0, t_eval=[0, 0.5, 1.0], rtol=1e-10, atol=1e-12)

print("t=0 초기 형상 vs t=1.0 (한 주기 후) 형상의 최대 차이:")
print("max diff:", np.max(np.abs(sol.y[:N, 0] - sol.y[:N, -1])))
----

[source]
----
t=0 초기 형상 vs t=1.0 (한 주기 후) 형상의 최대 차이:
max diff: 2.4107522822447436e-07
----

`t=1.0초`가 지난 뒤 줄의 모양이 초기 상태와 소수점 7자리까지 완벽하게 일치합니다

[NOTE]
====
**달랑베르의 해 (D'Alembert's Solution)**  
1차원 파동방정식의 일반해는 $u(x,t) = f(x - ct) + g(x + ct)$라는 형태로 쓸 수 있습니다. 이는 "어떤 형태의 파형이든 모양을 그대로 유지한 채 속도 $c$로 오른쪽과 왼쪽으로 달려나간다"는 파동 전파의 본질을 보여줍니다.
====

== 직접 해보기: 역학적 에너지 보존 확인

파동이 진동하는 동안 운동에너지와 탄성 위치에너지의 합이 보존되는지 검증해 보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def wave_energy(u, v):
    u_full = np.concatenate(([0.0], u, [0.0]))
    du = np.diff(u_full) / dx
    KE = 0.5 * np.sum(v**2) * dx
    PE = 0.5 * c**2 * np.sum(du**2) * dx
    return KE + PE

t_eval = np.linspace(0, 2, 9)
sol2 = solve_ivp(rhs, [0, 2.0], y0, t_eval=t_eval, rtol=1e-10, atol=1e-12)
Es = [wave_energy(sol2.y[:N, i], sol2.y[N:, i]) for i in range(len(t_eval))]

print("시점별 에너지:", Es[:3])
print("에너지 최대 편차:", np.max(np.abs(np.array(Es) - Es[0])))
----
