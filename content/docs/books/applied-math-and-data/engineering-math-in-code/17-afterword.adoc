0부 준비운동부터 시작해 우리는 공학의 모든 영역을 관통하는 장엄한 7대 수학 기둥을 코드로 하나씩 정복했습니다.

....
                 [ 공업수학 7대 기둥 총결산 마인드맵 ]

   【 0부: 준비운동 】 ──► 미분(dx/dt), 지수(e), 벡터/행렬(표), 복소수(i)
                              │
                              ▼
   【 1부: 상미분방정식 】 ──► RC 방전 회로, 오일러 방법, 질량-스프링-댐퍼 감쇠 진동
                              │
                              ▼
   【 2부: 라플라스 변환 】 ──► 미분을 대수로 변환, RLC 회로 스텝 응답 오버슈트
                              │
                              ▼
   【 3부: 선형연립방정식 】 ──► 3루프 회로망, 가우스 소거법, 랭크(Rank) 3대 해 판정
                              │
                              ▼
   【 4부: 고유값과 대각화 】 ──► 회전 불변축(Av=λv), 연성 진동계 정상 모드 분해
                              │
                              ▼

                              │
                              ▼
   【 6부: 푸리에 / PDE 】 ──► FFT 주파수 분해, 열방정식(감쇠 확산) vs 파동방정식(진동 보존)

== 이 책을 관통한 단 하나의 문제 해결 프레임워크

이 책을 마친 여러분은 이제 새로운 공학 문제나 복잡한 시스템 모델링을 마주쳤을 때, 다음 질문들을 순서대로 던지며 코드로 직접 문제를 풀어낼 수 있습니다:

....
                   [ 엔지니어를 위한 7단계 수학적 질문표 ]

   1. 시간에 따라 상태가 변하는가? ──────► 상미분방정식(ODE)으로 모델링
   2. 미분방정식이 풀기 까다로운가? ──────► 라플라스 변환으로 대수식으로 변환
   3. 여러 미지수가 동시에 얽혔는가? ────► 가우스 소거와 랭크로 해를 판별
   4. 시스템이 뒤엉켜 요동치는가? ────────► 고유값 분해(대각화)로 독립 모드 분리
   5. 공간 전체에 퍼진 장(Field)인가? ──► grad, div, curl로 흐름과 원천 분석
   6. 주기적 신호나 공간 확산인가? ──────► 푸리에 급수와 분리변수법(PDE) 적용
   7. 실수 적분이 도저히 안 풀리는가? ──► 복소평면으로 점프해 유수 정리로 해결
....

== 이 책이 다루지 않은 것들

초보자 독자가 수식의 미로에 빠지지 않고 생각의 뼈대를 세울 수 있도록, 다음 심화 주제들은 남겨두었습니다.

* **엄밀한 증명**: 해의 존재성과 유일성 정리(피카르-린델뢰프), 수렴성 증명 등은 다루지 않았습니다 (Lean4 책들 참고).
* **비선형 미분방정식**: 카오스, 분기 이론, 비선형 진동 등은 해석해가 드물어 수치 시뮬레이션 전문 도서의 몫으로 남겨둡니다.
* **급수해법과 특수함수**: 베셀 함수, 르장드르 다항식 등 급수로 정의되는 미분방정식 해법은 생략했습니다.
* **2차원·3차원 PDE**: 실제 구조 해석이나 유체 시뮬레이션에 쓰이는 2D/3D 유한요소법(FEM) 등은 다루지 않았습니다.
* **등각사상 (Conformal Mapping)**: 복소함수의 각도 보존 사상을 이용한 2차원 에어포일 유체 해석은 범위 밖으로 두었습니다.
