4장에서는 1계 회로에 라플라스 변환을 적용했습니다. 이 장에서는 2계로 확장하여, **저항(`R`)·인덕터(`L`)·축전기(`C`)가 직렬로 연결된 RLC 회로**에 스텝 전압을 걸었을 때의 응답을 구합니다.

== 직렬 RLC 회로의 구조와 방정식

....
                   [ 직렬 RLC 회로의 물리적 구조 ]

              ┌── 저항 (R) ── 인덕터 (L) ──┐
              │    [===]        UUUUU      │
            + ┴ -                          │
          전원 (Vs)                      + ┴ -
              │                         축전기 (C)
              │                          (전압 Vc(t))
              │                            │
              └────────────────────────────┘
....

키르히호프 전압 법칙을 적용하면 다음과 같은 2계 ODE가 나옵니다:

[stem]
++++
LC \frac{d^2 V_c}{dt^2} + RC \frac{dV_c}{dt} + V_c = V_s
++++

== 기계계와 전기계의 1:1 수학적 쌍둥이 관계

3장의 질량-스프링-댐퍼 방정식($m\ddot{x} + c\dot{x} + kx = F$)과 나란히 놓아보면 완벽한 대응이 드러납니다

....
           [ 역학계(기계)와 RLC 회로(전기)의 1:1 대응 매핑 ]

     【 기계계 (질량-스프링-댐퍼) 】          【 전기계 (직렬 RLC 회로) 】
     • 질량 m (운동 상태 유지, 관성)   ◄──►   • 인덕터 L (전류 변화 억제, 자기 관성)
     • 댐퍼 c (에너지를 열로 소모)     ◄──►   • 저항 R (전기 에너지를 열로 소모)
     • 스프링 강성 k (변위에 저항)     ◄──►   • 역 커패시턴스 1/C (전하 축적 압력)
     • 질량의 변위 x(t)               ◄──►   • 축전기 전압 Vc(t)
     • 외부에서 가한 힘 F(t)          ◄──►   • 외부 전원 전압 Vs(t)
....

기계 공학자와 전자 공학자가 서로 완전히 다른 물리 부품을 다루면서도, **수학적으로는 100% 동일한 미분방정식**을 풀고 있는 것입니다.

== 초기조건이 0이면 미분이 순수한 $s$ 곱셈이 된다

축전기가 비어 있고 전류도 없는 상태($V_c(0)=0, V_c'(0)=0$)에서는 라플라스 미분 항의 초기값이 모두 0이 되어, 방정식이 대단히 깔끔한 2차 분수식으로 정리됩니다:

[stem]
++++
LC s^2 X(s) + RC s X(s) + X(s) = \frac{V_s}{s}
++++

[source,python]
----
import sympy as sp

t, s = sp.symbols('t s', positive=True, real=True)
L, R, Cc, Vs = sp.symbols('L R Cc Vs', positive=True)
Xs = sp.symbols('Xs')

eq = sp.Eq(L*Cc*s**2*Xs + R*Cc*s*Xs + Xs, Vs/s)
sol_Xs = sp.solve(eq, Xs)[0]
print("X(s) =", sp.simplify(sol_Xs))
----

[source]
----
X(s) = Vs/(s*(Cc*L*s**2 + Cc*R*s + 1))
----

== 숫자를 넣고 역변환하기: 스텝 응답 오버슈트

3장의 부족감쇠 예제(`m=1, c=0.4, k=4`)와 똑같이 대응되도록 `L=1H, R=0.4Ω, C=0.25F`를 넣고, `Vs=9V` 스텝 전압을 걸어 역변환합니다.

[source,python]
----
vals = {L: 1.0, R: 0.4, Cc: 0.25, Vs: 9.0}
sol_Xs_num = sol_Xs.subs(vals)
vc_t = sp.simplify(sp.inverse_laplace_transform(sol_Xs_num, s, t))
print("Vc(t) =", vc_t)

t_eval = [0, 0.5, 1.0, 1.5, 2.0, 3.0, 5.0]
laplace_vals = [float(vc_t.subs(t, tv)) for tv in t_eval]
print("laplace numeric values:", laplace_vals)
----

[source]
----
Vc(t) = (9.0*exp(0.2*t) - 0.904534033733291*sin(1.98997487421324*t) - 9.0*cos(1.98997487421324*t))*exp(-0.2*t)
laplace numeric values: [0.0, 3.87925298, 11.32263237, 15.48121699, 13.48493042, 4.45404997, 12.03166513]
----

전압이 목표값 `9V`를 훌쩍 넘어 `t=1.5초`에서 **`15.48V`까지 솟구쳤다가(오버슈트, Overshoot)** 출렁이며 서서히 안정됩니다 — 3장의 부족감쇠 진동이 전압의 형태로 그대로 재현된 것입니다.

== `solve_ivp`와의 교차 검증 (소수점 11자리 일치)

[source,python]
----
import numpy as np
from scipy.integrate import solve_ivp

Lv, Rv, Cv, Vsv = 1.0, 0.4, 0.25, 9.0
def f(tt, y):
    vc, dvc = y
    d2vc = (Vsv - vc - Rv*Cv*dvc)/(Lv*Cv)
    return [dvc, d2vc]

sol = solve_ivp(f, [0,5], [0.0, 0.0], t_eval=t_eval, rtol=1e-12, atol=1e-14)
print("solve_ivp values:", sol.y[0])
print("max diff:", np.max(np.abs(sol.y[0]-np.array(laplace_vals))))
----

[source]
----
solve_ivp values: [ 0.          3.87925298 11.32263237 15.48121699 13.48493042  4.45404997 12.03166513]
max diff: 6.7554850602391525e-12
----

라플라스 대수 역변환과 수치적분이 소수점 11자리까지 완벽히 일치합니다.

[NOTE]
====
**전달함수 (Transfer Function, $H(s)$)의 탄생**  
출력 $X(s)$와 입력 $V_s(s) = V_s/s$의 비율을 **전달함수 $H(s) = \frac{X(s)}{V_s(s)} = \frac{1}{LC s^2 + RC s + 1}$**라고 부릅니다. 이 분모를 0으로 만드는 $s$의 근(극점, Pole)들이 바로 시스템의 진동수와 감쇠율을 결정합니다.
====
