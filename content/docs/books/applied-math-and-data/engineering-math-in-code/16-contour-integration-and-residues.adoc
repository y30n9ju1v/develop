이 마지막 장에서는 이 성질이 공학과 물리학에서 왜 가장 강력한 계산 무기가 되는지 확인합니다 — **실수 영역에서는 아무리 용을 써도 안 풀리던 어려운 이상적분들이, 복소평면으로 점프하는 순간 극점(Pole) 몇 개의 잔여물 덧셈으로 바뀌어 단 몇 줄 만에 풀리는 기적**, 바로 **유수 정리(Residue Theorem)**입니다.

== 유수 정리 (Residue Theorem)

함수 $f(z)$가 닫힌 폐곡선 $C$ 내부에서 몇 개의 분모가 0이 되는 고립 특이점(극점, Pole)을 제외하고 모두 해석적이라면:

[stem]
++++
\oint_C f(z)\, dz = 2\pi i \sum (\text{폐곡선 내부 극점들의 유수})
++++

....
                   [ 복소평면의 상반평면 반원 적분 경로 (Contour) ]

     허수축 (Im)
        ▲
      R │                     ╭───────╮ ◄── 반원 호 경로 CR (R ──► ∞ 일 때 적분값 0으로 소멸!)
        │                   ╭─         ─╮
        │                  │   • z = i  │ ◄── 【 상반평면 내부 극점 (유수 Res 계산!) 】
        │                 │             │
      0 └───•─────────────┴─────────────┴─────────────•──────► 실수부 (Re)
           -R                                         +R
            ◄─── 【 우리가 구하려는 진짜 실수 적분: ∫_{-∞}^{∞} f(x) dx 】 ───►
....

실수축 전체($-\infty \sim \infty$)의 적분을 상반평면의 거대한 반원 호($C_R$)로 닫으면, 반원 부분의 적분은 $R \to \infty$일 때 0으로 사라져, **우리가 구하려는 실수 적분값이 정확히 $2\pi i \times (\text{내부 극점들의 유수 합})$**과 같아집니다

== 예제 1: $\int_{-\infty}^\infty \frac{1}{1+x^2} dx = \pi$

이 적분은 $f(z) = \frac{1}{1+z^2}$의 극점 $z = \pm i$ 중 상반평면에 있는 $z = i$ 하나만 경로 안에 들어옵니다.

[source,python]
----
import sympy as sp
import numpy as np
from scipy.integrate import quad

z = sp.symbols('z')
f = 1 / (1 + z**2)

# z = i 에서의 유수(Residue) 계산
res_at_i = sp.residue(f, z, sp.I)
print("z = i 에서의 유수:", res_at_i)

integral_by_residue = sp.simplify(2 * sp.pi * sp.I * res_at_i)
print("유수 정리 계산 결과: 2*pi*i * Res =", integral_by_residue)

val, err = quad(lambda x: 1/(1+x**2), -np.inf, np.inf)
print(f"scipy.integrate.quad 직접 수치적분: {val:.8f}")
----

[source]
----
z = i 에서의 유수: -I/2
유수 정리 계산 결과: 2*pi*i * Res = pi
scipy.integrate.quad 직접 수치적분: 3.14159265
----

`2 * pi * i * (-i/2) = pi`가 되어 수치적분 결과 `3.14159265`와 완벽히 일치합니다

== 예제 2: 초등함수로 안 풀리는 적분 $\int_{-\infty}^\infty \frac{1}{x^4+1} dx = \frac{\pi}{\sqrt{2}}$

부정적분을 손으로 구하기 극도로 까다로운 이 적분도, $z^4 = -1$의 4개 극점 중 상반평면의 2개 극점만 골라 유수를 더하면 즉시 풀립니다

[source,python]
----
f2 = 1 / (z**4 + 1)
poles = sp.solve(z**4 + 1, z)
upper_poles = [p for p in poles if sp.im(p) > 0]
print("상반평면 극점 2개:", upper_poles)

total_res = sum(sp.residue(f2, z, p) for p in upper_poles)
integral2 = sp.simplify(2 * sp.pi * sp.I * total_res)
print("유수 정리 최종값:", integral2)

val2, _ = quad(lambda x: 1/(x**4+1), -np.inf, np.inf)
print(f"scipy.integrate.quad 수치적분: {val2:.8f}")
print(f"pi / sqrt(2) 참값:           {np.pi/np.sqrt(2):.8f}")
----

[source]
----
상반평면 극점 2개: [-sqrt(2)/2 + sqrt(2)*I/2, sqrt(2)/2 + sqrt(2)*I/2]
유수 정리 최종값: sqrt(2)*pi/2
scipy.integrate.quad 수치적분: 2.22144147
pi / sqrt(2) 참값:           2.22144147
----

초등 미적분으로는 풀기 어려운 적분이, 복소평면의 극점 유수 계산만으로 $\frac{\pi}{\sqrt{2}} \approx 2.22144147$로 완벽하게 풀렸습니다.

[NOTE]
====
**유수(Residue)란 무엇인가?**  
복소함수를 로랑 급수(Laurent Series, 음수 거듭제곱을 포함한 멱급수)로 전개했을 때, 유일하게 적분해서 0이 되지 않고 $2\pi i$를 남기는 항인 **$\frac{1}{z - z_0}$ 항의 계수**를 뜻합니다.
====

== 직접 해보기

$\int_{-\infty}^\infty \frac{1}{x^2+4} dx$를 유수 정리로 풀고 `quad`와 비교해 보세요 (상반평면 극점: $z = 2i$).

.해답 보기
[%collapsible]
====
[source,python]
----
f3 = 1 / (z**2 + 4)
res = sp.residue(f3, z, 2*sp.I)
ans = sp.simplify(2 * sp.pi * sp.I * res)
print("유수 정리:", ans)  # pi / 2

val3, _ = quad(lambda x: 1/(x**2+4), -np.inf, np.inf)
print(f"quad 수치적분: {val3:.6f} vs pi/2: {np.pi/2:.6f}")
----

[source]
----
유수 정리: pi/2
quad 수치적분: 1.570796 vs pi/2: 1.570796
----

정확히 $\pi/2$로 일치합니다.
