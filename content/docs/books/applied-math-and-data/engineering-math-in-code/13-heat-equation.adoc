'''

이제 우리는 변수가 시간과 공간 두 개 이상인 **편미분방정식(Partial Differential Equation, PDE)**의 세계로 들어섭니다.

온도 $u(x,t)$는 위치 $x$와 시간 $t$ 모두에 따라 변합니다.

== 열방정식: 온도가 퍼져나가는 확산의 법칙

양 끝이 $0^\circ\text{C}$ 얼음물에 닿아 있는 얇은 금속 막대의 온도 분포는 다음 편미분방정식을 따릅니다:

[stem]
++++
\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}
++++

오른쪽의 공간 2계 미분 $\partial^2 u / \partial x^2$는 **"주변보다 뾰족하게 튀어나온 정도(곡률)"**를 뜻합니다. 주변보다 뾰족하게 뜨거운 지점은 열이 양옆으로 빠르게 빠져나가 급격히 식고, 평평한 곳은 서서히 식습니다. $\alpha$는 물질의 열확산도입니다.

== 분리변수법: 공간과 시간을 쪼개어 풀기

$u(x,t) = X(x) T(t)$로 두고 풀면, 해는 12장의 **사인파 모드들의 지수 감쇠 합**으로 표현됩니다:

[stem]
++++
u(x,t) = \sum_{n=1}^\infty B_n \sin\left(\frac{n\pi x}{L}\right) e^{-\alpha (n\pi/L)^2 t}
++++

각 사인파 모드가 **자기 고유의 속도($n^2$에 비례)로 지수 감쇠**하며 식어갑니다

....
                   [ 열방정식의 확산: 뾰족한 고주파의 급격한 소멸 ]

     온도 u(x, t)
        ▲
        │       /\  ◄── t = 0 (뾰족한 3차 모드 포함)
        │      /  \
        │     /    \      . ─ ─ .  ◄── t = 1 (고주파가 9배 빨리 식어 매끈해짐!)
        │    /      \ . ─'       `─.
        │   /    . ─ '               `─.
        │  / . ─ '                       `─. ◄── t = 5 (가장 낮은 1차 모드만 잔류)
        └─┴─────────────────────────────────┴──► 위치 x
         x=0                               x=L
....

== 고주파 모드가 9배 빨리 사라진다

$n=1$ 모드는 $e^{-\alpha (\pi/L)^2 t}$로 식지만, 3배 더 굴곡진 $n=3$ 모드는 $e^{-\alpha (3\pi/L)^2 t} = e^{-9\alpha (\pi/L)^2 t}$로 **무려 9배나 빠른 속도로 소멸**합니다

공간을 유한차분으로 쪼개고 `solve_ivp`로 적분해 수치 검증해 봅시다.

[source,python]
----
import numpy as np
from scipy.integrate import solve_ivp

L, alpha = 1.0, 0.01
N = 50
x = np.linspace(0, L, N+2)
dx = x[1] - x[0]
xi = x[1:-1]

# n=1 모드와 n=3 모드가 섞인 초기 온도
u0_multi = np.sin(np.pi*xi/L) + 0.5 * np.sin(3*np.pi*xi/L)

def rhs(t, u):
    u_full = np.concatenate(([0.0], u, [0.0]))  # 양 끝 0도 고정
    d2u = (u_full[2:] - 2*u_full[1:-1] + u_full[:-2]) / dx**2
    return alpha * d2u

sol = solve_ivp(rhs, [0,5], u0_multi, t_eval=[0,1,3,5], rtol=1e-9, atol=1e-11)

for i, tv in enumerate([0,1,3,5]):
    analytical = (np.sin(np.pi*xi/L)*np.exp(-alpha*(np.pi/L)**2*tv)
                  + 0.5*np.sin(3*np.pi*xi/L)*np.exp(-alpha*(3*np.pi/L)**2*tv))
    err = np.max(np.abs(sol.y[:, i] - analytical))
    print(f"t={tv}s 수치해-해석해 오차: {err:.3e}")
----

[source]
----
t=0s 수치해-해석해 오차: 0.000e+00
t=1s 수치해-해석해 오차: 5.327e-04
t=3s 수치해-해석해 오차: 3.002e-04
t=5s 수치해-해석해 오차: 1.270e-04
----

손으로 유도한 분리변수법 해와 수치해가 $10^{-4}$ 오차 이내로 정밀 일치합니다.

[NOTE]
====
**열방정식의 비가역성과 평활화 (Smoothing)**  
열방정식은 시간 방향으로 비가역적(시간의 화살)입니다. 아무리 울퉁불퉁하고 날카로운 초기 온도 분포라도, $t > 0$이 되는 순간 고주파수 성분들이 기하급수적으로 소멸하여 완벽하게 매끄러운 곡선으로 평탄화됩니다. 이미지 처리에서 블러(Blur) 필터가 열방정식의 원리를 쓰는 이유입니다.
====

== 직접 해보기: 최대원리 (Maximum Principle)

열원이 없는 닫힌 막대에서 최고 온도는 시간이 지날수록 결코 증가하지 않는다는 물리 법칙(최대원리)을 시뮬레이션으로 확인해 보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
t_eval = np.linspace(0, 20, 21)
sol_long = solve_ivp(rhs, [0,20], u0_multi, t_eval=t_eval, rtol=1e-9, atol=1e-11)
max_temps = np.max(sol_long.y, axis=0)

print("시점별 최고 온도:", max_temps[:5])
print("최고 온도가 단조 감소하는가?", np.all(np.diff(max_temps) <= 1e-10))
----

----

최고 온도가 단조 감소하는가? True

====

[TIP]
====
**확인 질문**: 1차원 막대의 양 끝이 얼음물(0도)이 아니라 단열재로 꽁꽁 싸매져 열이 전혀 빠져나가지 못한다면($\partial u/\partial x = 0$), $t \to \infty$일 때 막대의 온도는 어떻게 될까요? (전체 초기 열량의 평균 온도로 균일하게 평형을 이룹니다)
====
