== 랭크(Rank)란 무엇인가: 독립적인 진짜 정보의 개수

행렬의 **랭크(Rank)**란, 행렬 안에 들어있는 행(또는 열)들 중에서 **"다른 행들의 단순 조합이 아닌, 진짜 독립적인 알짜 정보가 몇 개인가?"**를 세는 숫자입니다.

....
                   [ 랭크 판정 트리: 시스템의 3가지 운명 ]

                         【 rank(A) 와 rank([A|b]) 비교 】
                                        │
                 ┌──────────────────────┴──────────────────────┐
                 ▼ (랭크가 같음: 모순 없음)                         ▼ (랭크가 다름: 모순 발생!)
        rank(A) == rank([A|b])                        rank(A) < rank([A|b])
                 │                                             │
        ┌────────┴────────┐                                    ▼
        ▼                 ▼                           【 3. 해가 아예 없음 (불능) 】
    rank == n         rank < n                         • 서로 모순되는 조건 충돌
   (미지수 수 일치)    (미지수보다 적음)                • lstsq: 최소제곱 근사해만 제공
        │                 │                              (검산 잔차 != 0)
        ▼                 ▼
   【 1. 유일한 해 】   【 2. 해가 무한히 많음 】
   • solve 성공       • 특이행렬 (Singular)
   • 검산 잔차 = 0    • lstsq: 무한한 해 중 하나 반환 (검산 잔차 = 0)
....

== 경우 1: 중복된 방정식 $\to$ 해가 무한히 많다 (특이행렬)

다음 연립방정식을 봅시다: 셋째 식이 사실 첫째 식과 둘째 식을 그냥 더한 것에 불과합니다 (`(x+y+z=6) + (x-y=2) = (2x+z=8)`).

[source,python]
----
import numpy as np

A1 = np.array([[1., 1., 1.],
               [1., -1., 0.],
               [2., 0., 1.]])   # 3행 = 1행 + 2행 (중복!)
b1 = np.array([6., 2., 8.])     # 8 = 6 + 2 (모순은 없음)

try:
    x = np.linalg.solve(A1, b1)
except np.linalg.LinAlgError as e:
    print("solve 실패 원인:", e)
----

[source]
----
solve 실패 원인: Singular matrix
----

`np.linalg.solve`가 **"특이행렬(Singular Matrix)이라 풀 수 없다"**고 거절합니다. 셋째 식이 새로운 정보를 전혀 주지 못해 실질적으로 조건이 2개뿐이므로, 자유 변수가 생겨 해가 무한히 많아지기 때문입니다.

랭크를 계산해 보면 이 상황이 명쾌하게 드러납니다:

[source,python]
----
print("rank(A1):", np.linalg.matrix_rank(A1))
print("rank([A1|b1]):", np.linalg.matrix_rank(np.column_stack([A1,b1])))
----

[source]
----
rank(A1): 2
rank([A1|b1]): 2
----

미지수는 3개인데 랭크가 `2`뿐입니다. 랭크가 같으므로 모순은 없지만, 미지수 개수보다 작으므로 **해가 무한히 많음**이 확인됩니다.

== `lstsq`로 무한한 해 중 하나를 골라내기

해가 무한히 많을 때는 `np.linalg.lstsq`(최소제곱법)를 사용합니다.

[source,python]
----
x_lstsq, res, rank, sv = np.linalg.lstsq(A1, b1, rcond=None)
print("lstsq가 찾은 대표 해:", x_lstsq)
print("검산 A1@x == b1:", A1 @ x_lstsq, "vs", b1)
----

[source]
----
lstsq가 찾은 대표 해: [3. 1. 2.]
검산 A1@x == b1: [6. 2. 8.] vs [6. 2. 8.]
----

`A1 @ x`가 `b1`과 정확히 일치합니다 — 무한히 많은 정답 중 노름(크기)이 가장 작은 깔끔한 해 하나를 골라내 주었습니다.

== 경우 2: 모순되는 조건 $\to$ 해가 아예 없다 (불능)

이번엔 셋째 식의 우변만 `100`으로 바꾸어 모순을 만들어 봅시다:

[source,python]
----
A2 = A1.copy()
b2 = np.array([6., 2., 100.])   # 100 != 6 + 2 (모순!)

print("rank(A2):", np.linalg.matrix_rank(A2))
print("rank([A2|b2]):", np.linalg.matrix_rank(np.column_stack([A2,b2])))
----

[source]
----
rank(A2): 2
rank([A2|b2]): 3
----

`A2`의 랭크(`2`)와 확장행렬의 랭크(`3`)가 **불일치**합니다 우변 `b2`가 기존 조건들과 충돌하는 모순된 정보를 담고 있다는 뜻입니다.

[source,python]
----
x2, res2, rank2, sv2 = np.linalg.lstsq(A2, b2, rcond=None)
print("lstsq 최적 근사해:", x2)
print("잔차 A2@x - b2 (0이 아님!):", A2 @ x2 - b2)
----

[source]
----
lstsq 최적 근사해: [28.55555556 -4.11111111 12.22222222]
잔차 A2@x - b2 (0이 아님!): [ 30.66666667  30.66666667 -30.66666667]
----

잔차가 `[0, 0, 0]`이 아닙니다. 진짜 정답이 존재하지 않으므로, `lstsq`는 오차 제곱합을 최소로 만드는 **최선의 근사값(Best Fit)**을 제공한 것입니다.

[NOTE]
====
**데이터 분석과 AI에서 랭크와 최소제곱법**  
실제 인공지능 회귀 분석이나 3D 비전에서는 데이터 점이 100만 개인데 미지수는 3개뿐인 시스템($M \gg N$)을 다룹니다. 이때는 방정식들 사이에 노이즈로 인한 모순이 항상 존재하므로, `lstsq`를 이용해 오차를 최소화하는 최적의 모델 파라미터를 구합니다.
====
