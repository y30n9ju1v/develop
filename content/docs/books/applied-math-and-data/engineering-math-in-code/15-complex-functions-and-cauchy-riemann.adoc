'''

2부에서 라플라스 변환을 다룰 때 "역변환은 이론적으로 복소 적분으로 정의된다"고만 짚고 넘어갔습니다. 이 마지막 부에서는 그 복소수의 세계로 직접 들어갑니다 — 실수 하나짜리 함수 대신, 복소수 `z=x+iy`를 복소수로 돌려주는 **복소함수**를 다룹니다. `i`가 왜 필요한 숫자인지, 복소수를 어떻게 계산하는지 낯설다면 0-4장을 먼저 훑고 오는 걸 권합니다 — 이 장은 그 복소수 위에서 "미분 가능하다"는 개념을 새로 짓습니다.

== 복소함수는 사실 2변수 실함수 두 개다

복소함수 `f(z) = f(x+iy)`는 결과가 복소수이므로 실수부와 허수부로 나눌 수 있습니다.

[stem]
++++
f(z) = u(x,y) + i\,v(x,y)
++++

`u`와 `v`는 둘 다 평범한 2변수 실함수입니다 — 10~11장에서 다룬 gradient의 세계로 다시 들어온 셈입니다. 예를 들어 `f(z) = z^2`을 풀어써봅니다.

[stem]
++++
z^2 = (x+iy)^2 = (x^2-y^2) + i(2xy) \quad\Rightarrow\quad u = x^2-y^2,\ v = 2xy
++++

== 코시-리만 방정식: 두 실함수가 서로 얽혀야 한다

`u`와 `v`를 아무렇게나 짝지어도 되는 건 아닙니다. `f(z)`가 복소수 의미에서 미분 가능(**해석적, analytic**)하려면, `u`와 `v`가 다음 관계를 만족해야 합니다 — **코시-리만 방정식(Cauchy-Riemann equations)** 입니다.

[stem]
++++
\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \qquad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}
++++

`f(z)=z^2`이 이 조건을 실제로 만족하는지 8장에서 썼던 것과 같은 유한차분으로 확인합니다.

[source,python]
----
import numpy as np

def u(x,y): return x**2-y**2
def v(x,y): return 2*x*y

def partial(f, x, y, wrt, h=1e-6):
    if wrt=='x':
        return (f(x+h,y)-f(x-h,y))/(2*h)
    else:
        return (f(x,y+h)-f(x,y-h))/(2*h)

x0,y0 = 1.3, 0.7
ux = partial(u,x0,y0,'x'); uy = partial(u,x0,y0,'y')
vx = partial(v,x0,y0,'x'); vy = partial(v,x0,y0,'y')
print("u_x =", ux, " v_y =", vy)
print("u_y =", uy, " -v_x =", -vx)
print("CR satisfied?", np.isclose(ux,vy,atol=1e-4) and np.isclose(uy,-vx,atol=1e-4))
----

[source]
----
u_x = 2.59999999985272  v_y = 2.6000000000747647
u_y = -1.400000000040258  -v_x = -1.3999999998182133
CR satisfied? True
----

`u_x`와 `v_y`가 일치하고, `u_y`와 `-v_x`도 일치합니다 — `z^2`은 해석적입니다.

== 반례: 켤레복소수 함수는 해석적이 아니다

이번엔 `f(z) = \bar{z} = x - iy`(켤레복소수를 취하는 함수, `u=x, v=-y`)로 같은 검사를 해봅니다.

[source,python]
----
def u2(x,y): return x
def v2(x,y): return -y
ux2 = partial(u2,x0,y0,'x'); uy2 = partial(u2,x0,y0,'y')
vx2 = partial(v2,x0,y0,'x'); vy2 = partial(v2,x0,y0,'y')
print("u_x =", ux2, " v_y =", vy2)
print("u_y =", uy2, " -v_x =", -vx2)
print("CR satisfied?", np.isclose(ux2,vy2,atol=1e-4) and np.isclose(uy2,-vx2,atol=1e-4))
----

[source]
----
u_x = 0.9999999999177334  v_y = -1.0000000000287557
u_y = 0.0  -v_x = -0.0
CR satisfied? False
----

`u_x = 1`인데 `v_y = -1`이라 서로 다릅니다 — 코시-리만 방정식이 깨집니다. `f(z)=\bar z`는 **해석적이지 않습니다.**

== 왜 이게 "미분 가능"의 문제인가: 방향에 따라 미분값이 달라지는가

코시-리만 방정식이 정확히 무엇을 보장하는지 다른 각도에서 확인해봅니다 — 복소수 `z0`에서 미분을 계산할 때, `x` 방향(실수축)으로 다가가서 계산한 값과 `y` 방향(허수축)으로 다가가서 계산한 값이 같은지 봅니다.

[source,python]
----
def f(z): return z**2

z0 = complex(x0,y0)
h = 1e-6
d_real = (f(z0+h) - f(z0-h))/(2*h)          # 실수축 방향으로 접근
d_imag = (f(z0+1j*h) - f(z0-1j*h))/(2*1j*h)  # 허수축 방향으로 접근
print("real-axis approach:", d_real)
print("imag-axis approach:", d_imag)
print("match:", np.isclose(d_real, d_imag, atol=1e-4))

def g(z): return np.conj(z)
d_real_g = (g(z0+h) - g(z0-h))/(2*h)
d_imag_g = (g(z0+1j*h) - g(z0-1j*h))/(2*1j*h)
print("\nconj(z) real-axis approach:", d_real_g)
print("conj(z) imag-axis approach:", d_imag_g)
print("match:", np.isclose(d_real_g, d_imag_g, atol=1e-4))
----

[source]
----
real-axis approach: (2.59999999985272+1.3999999998182133j)
imag-axis approach: (2.6000000000747647+1.400000000040258j)
match: True

conj(z) real-axis approach: (0.9999999999177334+0j)
conj(z) imag-axis approach: (-1.0000000000287557-0j)
match: False
----

`f(z)=z^2`은 어느 방향으로 접근하든 똑같은 미분값이 나오는데, `f(z)=\bar z`는 실수축 방향으로 접근하면 `1`, 허수축 방향으로 접근하면 `-1`이 나와서 **완전히 다릅니다.** 실수 함수의 미분은 접근 방향이 왼쪽/오른쪽 둘뿐이라 이 문제가 잘 안 보이지만, 복소수는 접근할 수 있는 방향이 평면 전체(무한히 많음)라서 "어느 방향으로 다가가도 극한이 똑같다"는 조건이 훨씬 엄격합니다 — 코시-리만 방정식은 정확히 이 "방향 무관성"을 좌표별 편미분 조건으로 바꿔 쓴 것입니다.

== 직접 해보기

* `f(z) = |z|^2 = x^2+y^2`(`u=x^2+y^2, v=0`)의 코시-리만 방정식을 원점이 아닌 점(`(1,1)`)과 원점에 아주 가까운 점(`(0.0001, 0.0001)`)에서 각각 확인해보세요. 이 함수가 "어디서도 해석적이지 않다"가 아니라 "**딱 한 점에서만** 해석적이다"라는 흥미로운 경우라는 걸 눈으로 확인할 수 있습니다.

.해답 보기
[%collapsible]
====
[source,python]
----
def u(x,y): return x**2+y**2
def v(x,y): return 0.0*x

for (x0,y0) in [(1.0,1.0), (0.0001,0.0001)]:
    ux=partial(u,x0,y0,'x'); uy=partial(u,x0,y0,'y')
    vx=partial(v,x0,y0,'x'); vy=partial(v,x0,y0,'y')
    print((x0,y0), "u_x=",ux," v_y=",vy," CR ok:",
          np.isclose(ux,vy,atol=1e-3) and np.isclose(uy,-vx,atol=1e-3))
----

[source]
----
(1.0, 1.0) u_x= 2.0000000000575113 v_y= 0.0  CR ok: False
(0.0001, 0.0001) u_x= 0.00020000000000000015 v_y= 0.0  CR ok: True
----

`(1,1)`에서는 `u_x=2`인데 `v_y=0`이라 완전히 어긋나 코시-리만이 깨집니다. 그런데 원점에 아주 가까운 `(0.0001, 0.0001)`에서는 `u_x`도 `0.0002`로 작아져서 `v_y=0`과 거의 같아집니다 — 실제로 원점(`x=y=0`)에서는 `u_x=2x=0=v_y`이고 `u_y=2y=0=-v_x`가 정확히 성립합니다. `f(z)=|z|^2`은 **딱 원점 하나에서만** 미분 가능하고 그 주변 어디서도 미분 가능하지 않은, "해석적"이라는 조건이 얼마나 엄격한지 보여주는 극단적인 예입니다(보통 "해석적"이라고 하면 한 점만이 아니라 그 점을 둘러싼 열린 영역 전체에서 미분 가능해야 하므로, `f(z)=|z|^2`은 원점에서조차 엄밀한 의미의 해석적 함수는 아닙니다 — 미분 가능한 점이 고립되어 있기 때문입니다).
====

== 요약

* 복소함수를 실수부·허수부 두 개의 2변수 실함수(`u`, `v`)로 쪼개고, 코시-리만 방정식(`u_x=v_y`, `u_y=-v_x`)을 유한차분으로 직접 검사했습니다.
* `f(z)=z^2`은 코시-리만 방정식을 만족하고(해석적), `f(z)=\bar z`는 만족하지 않는다는(해석적이지 않음) 걸 실제 계산으로 확인했습니다.
* 그 차이가 "미분값이 접근 방향과 무관한가"라는 더 직관적인 질문과 정확히 일치한다는 것도, 실수축과 허수축 두 방향에서 직접 미분해서 확인했습니다 — `z^2`은 방향 무관, `\bar z`는 방향에 따라 딴판입니다.

다음 장에서는 이 "해석적"이라는 성질이 왜 강력한 도구인지 확인합니다 — 해석적 함수의 적분은 놀라운 지름길(유수 정리)을 갖고 있어서, 실수 적분표에 없는 어려운 정적분도 복소평면에서 몇 줄로 계산됩니다.
