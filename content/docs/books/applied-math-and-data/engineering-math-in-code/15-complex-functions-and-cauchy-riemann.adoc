이 마지막 부에서는 0-4장에서 준비운동했던 복소수의 세계로 본격적으로 뛰어듭니다. 복소수 $z = x + iy$를 입력받아 복소수를 뱉어내는 **복소함수(Complex Function)**의 미분을 다룹니다.

== 복소함수는 2변수 실함수 두 개로 쪼갤 수 있다

복소함수 $f(z)$는 실수부 $u(x,y)$와 허수부 $v(x,y)$라는 두 개의 평범한 2변수 실함수로 나눌 수 있습니다:

[stem]
++++
f(z) = u(x,y) + i\, v(x,y)
++++

예를 들어 $f(z) = z^2$을 전개해 봅시다:
$$z^2 = (x+iy)^2 = (x^2 - y^2) + i(2xy) \quad\Longrightarrow\quad u = x^2 - y^2,\ v = 2xy$$

== 코시-리만 방정식: "어느 방향으로 다가가도 미분값이 같다"

실수 미분은 좌/우 2개 방향뿐이지만, **복소평면에서는 360도 무한한 방향**에서 점 $z_0$로 다가갈 수 있습니다

....
                   [ 복소평면에서의 미분 접근 방향과 코시-리만 ]

     허수축 (Im)
        ▲               ▲ (허수축 위에서 접근: +ih)
        │               │
        │       ──►   • z0   ◄── (실수축 방향에서 접근: +h)
        │               │
        │               ▼
        └────────────────────────────────────────► 실수부 (Re)

     【 복소 미분 가능(해석적, Analytic)의 엄격한 조건 】
     • 실수축 방향으로 접근한 미분값 == 허수축 방향으로 접근한 미분값!
     ──► 이 조건이 바로 【 코시-리만 방정식 (Cauchy-Riemann Equations) 】!
....

[stem]
++++
\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \qquad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}
++++

== 1. 해석적 함수의 대표: $f(z) = z^2$ (코시-리만 만족)

[source,python]
----
import numpy as np

def u(x,y): return x**2 - y**2
def v(x,y): return 2*x*y

def partial(f, x, y, wrt, h=1e-6):
    if wrt == 'x': return (f(x+h,y) - f(x-h,y)) / (2*h)
    else:          return (f(x,y+h) - f(x,y-h)) / (2*h)

x0, y0 = 1.3, 0.7
ux, uy = partial(u,x0,y0,'x'), partial(u,x0,y0,'y')
vx, vy = partial(v,x0,y0,'x'), partial(v,x0,y0,'y')

print("u_x =", ux, " v_y =", vy)
print("u_y =", uy, "-v_x =", -vx)
print("코시-리만 만족 여부:", np.isclose(ux,vy,atol=1e-4) and np.isclose(uy,-vx,atol=1e-4))
----

[source]
----

u_y = -1.400000000040258 -v_x = -1.3999999998182133
코시-리만 만족 여부: True
----

== 2. 비해석적 함수의 대표: $f(z) = \bar{z}$ (켤레복소수, 코시-리만 불만족)

$f(z) = x - iy$ ($u=x, v=-y$)를 검사해 봅시다:

[source,python]
----
def u2(x,y): return x
def v2(x,y): return -y

ux2, vy2 = partial(u2,x0,y0,'x'), partial(v2,x0,y0,'y')
print("u_x =", ux2, " v_y =", vy2)
print("코시-리만 만족 여부:", np.isclose(ux2, vy2, atol=1e-4))
----

[source]
----
u_x = 0.9999999999177334  v_y = -1.0000000000287557
코시-리만 만족 여부: False
----

$u_x = 1$인데 $v_y = -1$로 완전히 깨집니다

== 방향별 미분으로 직접 확인하기

[source,python]
----
z0 = complex(x0, y0)
h = 1e-6

# z^2 의 방향별 미분
d_real_z2 = ( (z0+h)**2 - (z0-h)**2 ) / (2*h)
d_imag_z2 = ( (z0+1j*h)**2 - (z0-1j*h)**2 ) / (2*1j*h)
print("z^2 실수축 접근:", d_real_z2)
print("z^2 허수축 접근:", d_imag_z2)

# conj(z) 의 방향별 미분
d_real_conj = ( np.conj(z0+h) - np.conj(z0-h) ) / (2*h)
d_imag_conj = ( np.conj(z0+1j*h) - np.conj(z0-1j*h) ) / (2*1j*h)
print("\nconj(z) 실수축 접근:", d_real_conj)
print("conj(z) 허수축 접근:", d_imag_conj)
----

[source]
----
z^2 실수축 접근: (2.59999999985272+1.3999999998182133j)
z^2 허수축 접근: (2.6000000000747647+1.400000000040258j)

conj(z) 실수축 접근: (0.9999999999177334+0j)
conj(z) 허수축 접근: (-1.0000000000287557-0j)
----

$z^2$은 두 방향의 미분값이 `(2.6 + 1.4j)`로(부동소수점 오차 이내에서) 사실상 일치하지만, $\bar{z}$는 실수축에서는 `+1`, 허수축에서는 `-1`로 완전히 달라집니다

[NOTE]
====
**해석 함수(Analytic Function)의 놀라운 마법**  
복소평면에서 딱 한 번만 미분 가능한 함수는, 놀랍게도 **무한 번 미분 가능(Smooth)**해지며, 테일러 급수로 100% 완벽하게 전개됩니다. 실수 함수에서는 볼 수 없었던 이 강력한 성질이 다음 장의 '유수 정리'를 가능하게 합니다.
====

== 직접 해보기

$f(z) = |z|^2 = x^2 + y^2$은 원점($(0, 0)$)에서만 딱 한 번 코시-리만을 만족하고, 그 외의 모든 점에서는 만족하지 않음을 코드로 확인해 보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def u_abs2(x,y): return x**2 + y**2
def v_abs2(x,y): return 0.0

for pt in [(1.0, 1.0), (0.0, 0.0)]:
    ux = partial(u_abs2, *pt, 'x')
    vy = partial(v_abs2, *pt, 'y')
    print(f"점 {pt}: u_x = {ux}, v_y = {vy}, 일치하는가? {np.isclose(ux, vy)}")
----

[source]
----
점 (1.0, 1.0): u_x = 2.0000000000575113, v_y = 0.0, 일치하는가? False
점 (0.0, 0.0): u_x = 0.0, v_y = 0.0, 일치하는가? True
----

오직 원점에서만 $u_x = 2x = 0 = v_y$가 성립합니다.
====

[TIP]
====
**확인 질문**: 코시-리만 방정식 $u_x = v_y$, $u_y = -v_x$를 한 번 더 편미분하여 더하면 $u_{xx} + u_{yy} = 0$, $v_{xx} + v_{yy} = 0$이라는 **라플라스 방정식($\nabla^2 u = 0$)**이 나옵니다. 복소해석학이 2차원 유체 흐름과 정전기학의 전위 해석에 쓰이는 이유가 바로 이것입니다
====
