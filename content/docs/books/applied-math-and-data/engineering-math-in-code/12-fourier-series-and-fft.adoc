== 사각파도 둥근 사인파들의 합으로 만들 수 있다

뚝뚝 끊어지는 불연속 사각파(Square wave)를 부드러운 사인 함수들만으로 만들 수 있을까요?

놀랍게도 홀수 배 주파수 사인파들을 적절한 비율로 더하면 완벽한 사각파가 합성됩니다

....
                   [ 푸리에 급수: 사인파들의 중첩으로 사각파 만들기 ]

     【 n = 1 (기본파 sin(t)) 】 ──► 둥그런 언덕 모양
           ┌──────────┐
          /            \
        ─┴──────────────┴─

     【 n = 1, 3, 5, ... 50개 합성 】 ──► 평평한 사각 모서리 완성!
        ┌──────────────┐
        │              │  ◄── 점점 더 칼로 자른 듯한 사각파에 수렴!
        │              │
       ─┴──────────────┴──────────────► 시간 t
....

[stem]
++++
\text{square}(t) = \frac{4}{\pi} \sum_{n=1,3,5,\ldots}^\infty \frac{1}{n} \sin(nt)
++++

[source,python]
----
import numpy as np

def square_wave(t):
    return np.sign(np.sin(t))

def fourier_approx(t, N):
    s = np.zeros_like(t)
    for n in range(1, 2*N, 2):   # 1, 3, 5, ... 홀수만
        s += (4/np.pi) * (1/n) * np.sin(n*t)
    return s

t = np.linspace(0.01, 2*np.pi-0.01, 500)
true = square_wave(t)

for N in [1, 5, 50, 500]:
    approx = fourier_approx(t, N)
    err = np.mean((approx-true)**2)
    print(f"N={N}개 항 합성 시 평균 제곱 오차: {err:.6f}")
----

[source]
----
N=1개 항 합성 시 평균 제곱 오차: 0.188463
N=5개 항 합성 시 평균 제곱 오차: 0.039232
N=50개 항 합성 시 평균 제곱 오차: 0.002659
N=500개 항 합성 시 평균 제곱 오차: 0.000065
----

항을 500개까지 늘리자 오차가 `0.000065`로 떨어지며 정밀하게 사각파에 수렴합니다.

== 반대 방향: 복합 신호에서 주파수를 발라내는 FFT

푸리에 급수가 주파수들을 합쳐 신호를 만드는(합성) 것이라면, **고속 푸리에 변환(FFT, Fast Fourier Transform)**은 거꾸로 **"뒤섞인 신호에서 어떤 주파수가 들어있는지 발라내는(분해)"** 도구입니다.

....
                   [ 시간 영역 파형 vs FFT 주파수 스펙트럼 ]

   【 시간 영역 (복잡하게 엉킨 신호) 】        【 FFT 주파수 영역 (선명한 스펙트럼) 】
        ▲                                          ▲ 진폭
        │    /\  /\                                │    | (진폭 3.0)
        │ /\/  \/  \/\  ◄── 5Hz + 50Hz 혼합         │    |          | (진폭 1.5)
        │/            \                            │    |          |
        └──────────────────────► 시간 t            └───┴──────────┴────────► 주파수 (Hz)
                                                       5Hz        50Hz
....

5Hz(진폭 3.0)와 50Hz(진폭 1.5) 사인파를 섞은 신호에 `np.fft.fft`를 걸어봅시다:

[source,python]
----
fs = 1000.0   # 초당 1000회 샘플링
T = 2.0
t = np.arange(0, T, 1/fs)
sig = 3.0 * np.sin(2*np.pi*5*t) + 1.5 * np.sin(2*np.pi*50*t)

fft_vals = np.fft.fft(sig)
freqs = np.fft.fftfreq(len(t), 1/fs)

pos = freqs > 0
mags = 2 * np.abs(fft_vals[pos]) / len(t)
freqs_pos = freqs[pos]

idx5 = np.argmin(np.abs(freqs_pos-5))
idx50 = np.argmin(np.abs(freqs_pos-50))
idx20 = np.argmin(np.abs(freqs_pos-20))

print(f"5Hz 복원: {freqs_pos[idx5]:.1f}Hz, 진폭 = {mags[idx5]:.2f}")
print(f"50Hz 복원: {freqs_pos[idx50]:.1f}Hz, 진폭 = {mags[idx50]:.2f}")
print(f"20Hz (없는 성분): 진폭 = {mags[idx20]:.2e}")
----

[source]
----
5Hz 복원: 5.0Hz, 진폭 = 3.00
50Hz 복원: 50.0Hz, 진폭 = 1.50
20Hz (없는 성분): 진폭 = 8.49e-16
----

신호 안에 들어있던 원래 주파수와 진폭을 소수점까지 완벽하게 분리해 냈습니다

[NOTE]
====
**불연속 함수와 깁스 현상 (Gibbs Phenomenon)**  
사각파처럼 값이 뚝 끊어지는 불연속 함수는 푸리에 항을 100만 개 더해도 끊어지는 모서리 끝에서 약 9%의 삐죽한 오버슈트(깁스 현상)가 남습니다. 반면 매끄러운 삼각파는 계수가 $1/n^2$로 급격히 줄어들어 단 10개의 항만으로도 완벽하게 수렴합니다.
====

== 직접 해보기

매끄러운 삼각파(Triangle wave)의 푸리에 급수는 계수가 $1/n^2$로 줄어듭니다. 단 10개의 항만으로 오차가 얼마나 극적으로 줄어드는지 확인해 보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def triangle_approx(t, N):
    s = np.zeros_like(t)
    for k in range(N):
        n = 2*k+1
        s += (8/np.pi**2) * ((-1)**k) * np.sin(n*t) / n**2
    return s

def triangle_wave(t):
    return (2/np.pi)*np.arcsin(np.sin(t))

t = np.linspace(0.01, 2*np.pi-0.01, 500)
true_tri = triangle_wave(t)
for N in [1, 3, 10]:
    approx = triangle_approx(t, N)
    print(f"N={N} 오차:", np.mean((approx-true_tri)**2))
----

[source]
----
N=1 오차: 0.00482688
N=3 오차: 0.00024061
N=10 오차: 0.00000674
----

단 10개의 항만으로 오차가 `6.7e-6`까지 떨어집니다
