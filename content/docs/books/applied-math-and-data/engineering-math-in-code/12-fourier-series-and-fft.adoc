'''

지금까지는 시간이나 공간의 한 점에서 값을 다뤘습니다. 이 장에서는 관점을 완전히 바꿉니다 — 신호(시간에 따라 변하는 값)를 **주파수 성분들의 합**으로 다시 본다는 아이디어, 푸리에 해석입니다.

== 사각파도 사인파들의 합으로 만들 수 있다

사각파(square wave, 값이 `+1`과 `-1` 사이를 뚝뚝 끊어지며 오가는 신호)를 사인 함수만으로 근사할 수 있을까요? 놀랍게도 그렇습니다 — 홀수 배 주파수의 사인파를 특정 비율로 더하면 됩니다.

[stem]
++++
\text{square}(t) \approx \frac{4}{\pi}\sum_{n=1,3,5,\ldots} \frac{1}{n}\sin(nt)
++++

[source,python]
----
import numpy as np

def square_wave(t):
    return np.sign(np.sin(t))

def fourier_approx(t, N):
    s = np.zeros_like(t)
    for n in range(1, 2*N, 2):   # 1, 3, 5, ... 홀수만
        s += (4/np.pi) * (1/n) * np.sin(n*t)
    return s

t = np.linspace(0.01, 2*np.pi-0.01, 500)  # 불연속점(t=0, π)은 피함
true = square_wave(t)

for N in [1, 5, 50, 500]:
    approx = fourier_approx(t, N)
    err = np.mean((approx-true)**2)
    print(f"N={N} terms, mean squared error: {err:.6f}")
----

[source]
----
N=1 terms, mean squared error: 0.188463
N=5 terms, mean squared error: 0.039232
N=50 terms, mean squared error: 0.002659
N=500 terms, mean squared error: 0.000065
----

항을 하나(`N=1`, 그냥 `sin(t)` 하나)만 써도 사각파 비슷한 모양이 나오지만 오차가 큽니다. 항을 늘릴수록(`5→50→500`) 오차가 꾸준히 줄어듭니다 — 사인파를 무한히 많이 더하면 정말로 사각파에 수렴한다는 게, 항 개수를 늘려가며 계산한 숫자로 확인됩니다.

[source,python]
----
t0 = np.pi/2  # 불연속에서 먼 지점, 사각파는 여기서 정확히 1
approx_at_t0 = [fourier_approx(np.array([t0]), N)[0] for N in [1,5,50,500]]
print(approx_at_t0)
----

[source]
----
[1.2732395447351628, 1.0630539690963423, 0.9936344385781745, 0.9993633808642493]
----

`N`을 늘릴수록 `1.27 → 1.06 → 0.99 → 0.9994`로 정확한 값(`1`)에 점점 가까워집니다.

== 반대 방향: 신호에서 주파수를 뽑아내기

푸리에 급수가 "주파수들을 알면 신호를 합성한다"는 방향이라면, **고속 푸리에 변환(FFT, Fast Fourier Transform)** 은 그 반대입니다 — "신호만 주어졌을 때, 그 안에 어떤 주파수들이 어떤 세기로 섞여 있는지 찾아낸다"는 것입니다. 5Hz와 50Hz 사인파를 섞은 신호를 만들어서, FFT가 그 두 주파수를 정확히 찾아내는지 확인합니다.

[source,python]
----
fs = 1000.0  # 초당 1000번 샘플링
T = 2.0
t = np.arange(0, T, 1/fs)

sig = 3*np.sin(2*np.pi*5*t) + 1.5*np.sin(2*np.pi*50*t)

fft_vals = np.fft.fft(sig)
freqs = np.fft.fftfreq(len(t), 1/fs)

pos = freqs > 0
mags = 2*np.abs(fft_vals[pos])/len(t)
freqs_pos = freqs[pos]

idx5 = np.argmin(np.abs(freqs_pos-5))
idx50 = np.argmin(np.abs(freqs_pos-50))
print("freq near 5Hz:", freqs_pos[idx5], "amplitude:", mags[idx5])
print("freq near 50Hz:", freqs_pos[idx50], "amplitude:", mags[idx50])

idx20 = np.argmin(np.abs(freqs_pos-20))
print("freq near 20Hz (should be near 0):", freqs_pos[idx20], "amplitude:", mags[idx20])
----

[source]
----
freq near 5Hz: 5.0 amplitude: 3.000000000000001
freq near 50Hz: 50.0 amplitude: 1.4999999999999996
freq near 20Hz (should be near 0): 20.0 amplitude: 8.48577616763636e-16
----

원래 신호를 만들 때 썼던 진폭(`3`과 `1.5`)이 FFT 결과에서 **정확히 다시** 나옵니다 — `5Hz`에서 `3.0000...`, `50Hz`에서 `1.5000...`. 그리고 애초에 안 넣었던 `20Hz`에서는 진폭이 `8.5e-16`(사실상 0)입니다 — FFT가 "이 신호에는 5Hz와 50Hz만 있고 다른 주파수는 없다"는 걸 정확히 알아냈습니다.

== 왜 이게 공학에서 중요한가

진동 센서로 측정한 기계의 떨림 신호에 특정 주파수 성분이 강하게 나타나면 베어링 손상이나 불균형 같은 특정 고장의 징후일 수 있습니다 — 시간 영역 신호만 보면 그냥 복잡한 파형이지만, FFT로 주파수 영역으로 옮기면 "어느 주파수가 유독 강한가"가 한눈에 보입니다. 오디오 압축(특정 주파수 성분을 얼마나 남길지 결정), 통신(신호를 여러 주파수 대역으로 나눠 동시에 보내기)도 같은 원리 위에 있습니다.

== 직접 해보기

* 삼각파(triangle wave, `f(t) = (2/π)arcsin(sin t)` — 사각파처럼 뚝 끊어지지 않고 매끄럽게 오르내리는 파형)의 푸리에 급수는 `(8/π²)Σ(-1)^k sin((2k+1)t)/(2k+1)²`입니다. 사각파 때와 같은 방식으로 항 개수를 늘려가며 오차가 얼마나 빨리 줄어드는지 확인하고, 사각파의 수렴 속도와 비교해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def triangle_wave(t):
    return (2/np.pi)*np.arcsin(np.sin(t))

def triangle_approx(t, N):
    s = np.zeros_like(t)
    for k in range(N):
        n = 2*k+1
        s += (8/np.pi**2) * ((-1)**k) * np.sin(n*t) / n**2
    return s

t = np.linspace(0.01, 2*np.pi-0.01, 500)
true = triangle_wave(t)
for N in [1, 3, 10]:
    approx = triangle_approx(t, N)
    err = np.mean((approx-true)**2)
    print(f"N={N} terms, mean squared error: {err:.8f}")
----

[source]
----
N=1 terms, mean squared error: 0.00482688
N=3 terms, mean squared error: 0.00024061
N=10 terms, mean squared error: 0.00000674
----

항을 딱 `10`개만 썼는데 오차가 `6.7e-6`까지 떨어집니다 — 사각파는 `500`개 항을 써도 오차가 `0.000065` 수준이었는데(본문 참고), 삼각파는 `10`개 항으로 그보다도 훨씬 작은 오차를 냅니다. 이유는 사각파와 삼각파의 근본적인 차이에 있습니다 — 사각파는 값이 뚝 끊어지는 **불연속점**이 있지만 삼각파는 어디서도 안 끊어지고 매끄럽게 이어집니다. 함수가 매끄러울수록 그 함수를 표현하는 데 필요한 고주파(큰 `n`) 성분의 비중이 급격히 작아진다는 게(사각파의 계수는 `1/n`로, 삼각파의 계수는 `1/n²`로 줄어듭니다) 이 수렴 속도 차이의 이유입니다.
====

== 요약

* 사각파를 홀수 배 주파수 사인파의 합으로 근사하는 푸리에 급수를 실제로 계산해서, 항을 늘릴수록 근사 오차가 줄어든다는 걸 확인했습니다.
* `numpy.fft.fft`로 두 사인파를 섞은 합성 신호에서 원래 진폭과 주파수를 정확히 복원했고, 없는 주파수에서는 진폭이 사실상 0이 나온다는 것도 확인했습니다.
* 신호를 시간 영역이 아니라 주파수 영역에서 보면 특정 성분(고장 징후, 압축할 정보)을 훨씬 쉽게 짚어낼 수 있다는 실용적인 이유도 짚었습니다.
