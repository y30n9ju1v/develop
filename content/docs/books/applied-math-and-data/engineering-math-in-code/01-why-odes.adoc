== 미분방정식은 "변화율의 규칙"을 적은 것

저항 `R`과 축전기 `C`가 연결된 가장 단순한 **RC 방전 회로**를 생각해 봅시다.

....
                   [ RC 방전 회로의 물리적 구조 ]

                     ┌─────── 저항 (R) ───────┐
                     │                         │
                     │  i(t) ──►               │
                     │                         │
                   + ┴ -                       │
                  축전기 (C)                   │
                   (전압 V(t))                 │
                     │                         │
                     └─────────────────────────┘
....

축전기에 초기 전압 `V0`를 충전해두고 방전시키면, 전압은 시간에 따라 점차 줄어듭니다. 이 식이 왜 그렇게 생겼는지 두 가지 기본 물리 법칙에서 유도해 봅시다.

1. **옴의 법칙 (저항)**: 저항을 흐르는 전류는 $I = V/R$입니다 (전압이 높을수록 전류도 큼).
2. **축전기의 전하량 법칙**: 축전기가 방전되면서 빠져나가는 전하량의 속도가 전류이므로, $Q = CV$에서 $I = -\frac{dQ}{dt} = -C\frac{dV}{dt}$입니다 (마이너스는 전하가 줄어든다는 뜻).

두 부품이 하나의 닫힌 루프로 이어져 있으므로 두 전류는 완전히 같습니다:

[stem]
++++
\frac{V}{R} = -C\frac{dV}{dt} \quad\Longrightarrow\quad \frac{dV}{dt} = -\frac{V}{RC}
++++

이 식은 "$V(t)$가 당장 몇 볼트인가"를 말해주지 않습니다. 대신 **"지금 전압이 $V$일 때, 다음 순간에 전압이 얼마나 빨리 줄어드는가($dV/dt$)"**라는 변화율의 규칙을 말해줍니다.

이것이 바로 **상미분방정식(Ordinary Differential Equation, ODE)**입니다. 자연계의 거의 모든 물리 법칙(뉴턴의 운동 방정식, 열역학, 회로, 화학 반응)이 "현재 상태 $\to$ 다음 순간의 변화율"이라는 형태로 주어지기 때문에, 공학자는 미분방정식을 배울 수밖에 없습니다.

== 컴퓨터는 이걸 어떻게 풀까: 오일러 방법 (Euler's Method)

사람에게는 미분방정식을 푸는 것이 어려운 적분 퍼즐이지만, 컴퓨터에게는 지극히 단순한 산수입니다.

> **"다음 순간의 전압 $\approx$ 지금 전압 $+$ (시간 간격 $\Delta t$ $\times$ 지금의 변화율 $\frac{dV}{dt}$)"**

....
                   [ 오일러 방법의 계단 근사와 실제 곡선 ]

     전압 V(t)
        ▲
     V0 • (시작점)
        │ ╲ ◄── 지금의 순간 기울기(dV/dt)를 따라 직선으로 전진!
        │   ╲
        │     • (t = Δt)
        │     │ ╲
        │     │   ╲
        │     │     • (t = 2Δt) ──► 【 오일러 수치해 (계단식 근사) 】
        │     │     :
        │     •─────•───────────► 【 실제 해석해 (부드러운 곡선) 】
        └─────┴─────┴───────────────────────────────► 시간 t
             t=0   t=Δt
....

[stem]
++++
V(t + \Delta t) \approx V(t) + \Delta t \cdot \left( -\frac{V(t)}{RC} \right)
++++

[source,python]
----
import numpy as np

R, C = 1000.0, 1e-3   # 1kΩ, 1mF -> RC = 1초
tau = R * C
V0 = 5.0

def f(t, V):
    return -V / tau

def euler(f, t0, y0, dt, n):
    t, y = t0, y0
    ts, ys = [t], [y]
    for _ in range(n):
        y = y + dt * f(t, y)
        t = t + dt
        ts.append(t); ys.append(y)
    return np.array(ts), np.array(ys)

dt = 0.01
ts, ys = euler(f, 0.0, V0, dt, 300)
----

== 손으로 유도한 해석해(Closed-form Solution)와 비교하기

이 방정식의 엄밀한 수학적 참값(해석해)은 0-2장에서 확인했듯 $V(t) = V_0 e^{-t/RC}$입니다. 오일러 수치해와 해석해를 나란히 비교해 봅시다.

[source,python]
----
analytical = V0 * np.exp(-ts / tau)
max_err = np.max(np.abs(ys - analytical))
print("t=1s  euler:", ys[100], " analytical:", analytical[100])
print("t=2s  euler:", ys[200], " analytical:", analytical[200])
print("t=3s  euler:", ys[300], " analytical:", analytical[300])
print("max abs error over [0,3]:", max_err)
----

----

t=2s  euler: 0.6698983742898095  analytical: 0.6766764161830625

== 스텝을 줄이면 오차는 어떻게 변할까: 1차 수렴

스텝 크기 `dt`를 10분의 1(`0.01` $\to$ `0.001`)로 줄이면 어떻게 될까요?

[source,python]
----
ts2, ys2 = euler(f, 0.0, V0, 0.001, 3000)
analytical2 = V0 * np.exp(-ts2 / tau)
print("dt=0.001 max abs error:", np.max(np.abs(ys2 - analytical2)))
----

[source]
----
dt=0.001 max abs error: 0.0009200820023922418
----

`dt`를 10분의 1로 줄이니 오차도 거의 정확히 10분의 1(`0.0092` $\to$ `0.00092`)로 줄었습니다. 오일러 방법의 오차가 스텝 크기 $\Delta t$에 선형 비례하는 **1차(first-order) 방법**임이 유도 없이 숫자로 증명되었습니다.

== 실전의 무기: `scipy.integrate.solve_ivp`

실무에서는 오일러 대신 오차가 스텝의 4~5제곱($\Delta t^5$)에 비례하는 정교한 룽게-쿠타(Runge-Kutta) 솔버인 `solve_ivp`를 씁니다.

[source,python]
----
from scipy.integrate import solve_ivp

sol = solve_ivp(f, [0, 3], [V0], t_eval=[0, 1, 2, 3], rtol=1e-10, atol=1e-12)
analytical = V0 * np.exp(-np.array([0, 1, 2, 3]) / tau)
print("solve_ivp (tight tol):", sol.y[0])
print("analytical:           ", analytical)
print("max err:", np.max(np.abs(sol.y[0] - analytical)))
----

[source]
----
solve_ivp (tight tol): [5.         1.83939721 0.67667642 0.24893534]
analytical:            [5.         1.83939721 0.67667642 0.24893534]
max err: 1.9918067195590083e-11
----

오차가 `1.99e-11`로 자릿수가 8개 넘게 개선되어 기계 정밀도 수준으로 정확해집니다

[NOTE]
====
**`solve_ivp`의 `rtol`과 `atol`이란?**  
`rtol`(상대 오차 허용치)과 `atol`(절대 오차 허용치)은 솔버가 매 스텝마다 오차를 추정하여 자동으로 시간 간격을 쪼개는 기준입니다. 이 책에서는 손으로 푼 해석해와 소수점 끝자리까지 맞춰보기 위해 매우 엄격한 수치(`rtol=1e-10, atol=1e-12`)를 기본으로 사용합니다.
====

== 직접 해보기

오일러 방법보다 한 단계 나은 방법인 **RK2(2차 룽게-쿠타, 중점법)** 를 구현해보세요 — 한 스텝에서 기울기를 시작점과 끝점 두 번 구해서 평균을 냅니다: `k1=f(t,y)`, `k2=f(t+dt, y+dt*k1)`, `y_{n+1}=y_n+dt*(k1+k2)/2`. 스텝을 10분의 1로 줄였을 때 오차가 몇 분의 1로 줄어드는지 확인해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def rk2(f, t0, y0, dt, n):
    t, y = t0, y0
    ts, ys = [t], [y]
    for _ in range(n):
        k1 = f(t, y)
        k2 = f(t+dt, y+dt*k1)
        y = y + dt*0.5*(k1+k2)
        t = t+dt
        ts.append(t); ys.append(y)
    return np.array(ts), np.array(ys)

ts, ys = rk2(f, 0.0, V0, 0.01, 300)
analytical = V0*np.exp(-ts/tau)
print("RK2 dt=0.01 max err:", np.max(np.abs(ys-analytical)))

ts2, ys2 = rk2(f, 0.0, V0, 0.001, 3000)
analytical2 = V0*np.exp(-ts2/tau)
print("RK2 dt=0.001 max err:", np.max(np.abs(ys2-analytical2)))
----

[source]
----
RK2 dt=0.01 max err: 3.088772374892912e-05
RK2 dt=0.001 max err: 3.0679624751783763e-07
----

스텝을 10분의 1로 줄였더니 오차가 10분의 1이 아니라 **100분의 1(2차 수렴, $\Delta t^2$)**로 급격히 줄어듭니다
====

[TIP]
====
**확인 질문**: $dV/dt = -V/RC$에서 시정수 $\tau = RC$의 단위는 무엇일까요? (저항 $\Omega \times$ 커패시턴스 $\text{F} = \text{초(second)}$가 되어 전압이 $1/e \approx 36.8\%$로 떨어지는 데 걸리는 물리적 시간 척도가 됩니다)
====
