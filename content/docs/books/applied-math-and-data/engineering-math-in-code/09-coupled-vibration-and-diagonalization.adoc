8장에서 우리는 고유벡터가 "행렬을 곱해도 방향이 꺾이지 않는 마법의 축"임을 확인했습니다.

== 연성 진동계: 서로 밀고 당기는 두 질량

두 질량 $m$이 세 개의 스프링으로 연결된 **연성 진동계(Coupled Oscillators)**를 구성해 봅시다:

....
                   [ 2질량-3스프링 연성 진동계의 물리 모델 ]

    벽면                                                               벽면
     │    스프링 (k)         스프링 (k2)         스프링 (k)              │
     ├──\/\/\/\/\/\/\──► [ m ] ──\/\/\/\/\/\/\──► [ m ] ──\/\/\/\/\/\/\──┤
     │                   (x1)                     (x2)                 │
....

뉴턴의 운동 방정식을 세우면 두 변위 $x_1$과 $x_2$가 서로 얽힌 연립 미분방정식이 됩니다:

[stem]
++++
\begin{aligned}
m\ddot{x}_1 &= -(k+k_2)x_1 + k_2 x_2 \\
m\ddot{x}_2 &= -(k+k_2)x_2 + k_2 x_1
\end{aligned}
++++

행렬로 묶으면 $m \ddot{x} = -K x$가 되며, 강성 행렬 $K$는 다음과 같습니다:

[source,python]
----
import numpy as np

m = 1.0
k, k2 = 4.0, 1.0
K = np.array([[k+k2, -k2],
              [-k2, k+k2]])
print("강성 행렬 K:\n", K)
----

[source]
----
강성 행렬 K:
 [[ 5. -1.]
 [-1.  5.]]
----

== 고유벡터가 찾아낸 두 가지 "정상 모드(Normal Modes)"

8장에서 배운 대로 강성 행렬 $K/m$의 고유값과 고유벡터를 구해 봅시다.

[source,python]
----
eigvals, eigvecs = np.linalg.eigh(K/m)
print("고유값 (ω²):", eigvals)
print("고유 진동수 (ω):", np.sqrt(eigvals))
print("고유벡터 (모드 형상):\n", eigvecs)
----

[source]
----
고유값 (ω²): [4. 6.]
고유 진동수 (ω): [2.         2.44948974]
고유벡터 (모드 형상):
 [[-0.70710678 -0.70710678]
 [-0.70710678  0.70710678]]
----

두 고유벡터는 각각 **`[1, 1]` 방향(대칭 모드)**과 **`[1, -1]` 방향(역대칭 모드)**을 가리킵니다

....
                   [ 연성 진동계의 2대 정상 모드(Normal Modes) ]

   【 1. 대칭 모드 (Symmetric Mode): [1, 1] 】
   • 두 질량이 완전히 같은 방향으로 함께 흔들림! (x1 == x2)
     ──► [ m ] ──►          [ m ] ──►
   • 가운데 스프링 k2는 전혀 늘어나지 않음! ──► 진동수: ω = √(k/m) = 2.0 rad/s

   【 2. 역대칭 모드 (Anti-Symmetric Mode): [1, -1] 】
   • 두 질량이 서로 정반대 방향으로 마주보며 흔들림! (x1 == -x2)
     ──► [ m ] ──►          ◄── [ m ]
   • 가운데 스프링 k2가 2배로 격렬하게 압축/팽창! ──► 진동수: ω = √((k+2k2)/m) = 2.45 rad/s
....

== 시뮬레이션으로 검증하기

### 1) 대칭 모드 시뮬레이션: $x_1(0) = 1, x_2(0) = 1$

[source,python]
----
from scipy.integrate import solve_ivp

def f(t, y):
    x1, x2, v1, v2 = y
    a1 = -(k+k2)/m*x1 + k2/m*x2
    a2 = -(k+k2)/m*x2 + k2/m*x1
    return [v1, v2, a1, a2]

t_eval = np.linspace(0, 6, 7)
sol_sym = solve_ivp(f, [0,6], [1,1,0,0], t_eval=t_eval, rtol=1e-12, atol=1e-14)
print("x1 == x2 항상 성립하는가?", np.allclose(sol_sym.y[0], sol_sym.y[1]))
print("단일 주파수 cos(2t)와 일치하는가?", np.allclose(sol_sym.y[0], np.cos(2.0*t_eval)))
----

[source]
----
x1 == x2 항상 성립하는가? True
단일 주파수 cos(2t)와 일치하는가? True
----

### 2) 역대칭 모드 시뮬레이션: $x_1(0) = 1, x_2(0) = -1$

[source,python]
----
sol_anti = solve_ivp(f, [0,6], [1,-1,0,0], t_eval=t_eval, rtol=1e-12, atol=1e-14)
print("x1 == -x2 항상 성립하는가?", np.allclose(sol_anti.y[0], -sol_anti.y[1]))
print("단일 주파수 cos(√6 t)와 일치하는가?", np.allclose(sol_anti.y[0], np.cos(np.sqrt(6)*t_eval)))
----

== 임의의 초기조건은 두 정상 모드의 '단순한 중첩(Superposition)'

질량 1만 당겨놓고 질량 2는 가만히 둔 뒤 출발시키는 경우($x_1(0)=1, x_2(0)=0$)를 봅시다:

[source,python]
----
x0 = np.array([1.0, 0.0])
c = np.linalg.solve(eigvecs, x0)  # 초기조건을 고유벡터 기저로 분해!

omegas = np.sqrt(eigvals)
def superposition(t):
    return eigvecs @ (c * np.cos(omegas*t))

sol_generic = solve_ivp(f, [0,6], [1,0,0,0], t_eval=t_eval, rtol=1e-12, atol=1e-14)
analytical_generic = np.array([superposition(tv) for tv in t_eval]).T
print("모드 분해 중첩해와 실제 시뮬레이션이 일치하는가?", np.allclose(sol_generic.y[[0,1]], analytical_generic))
----

[source]
----
모드 분해 중첩해와 실제 시뮬레이션이 일치하는가? True
----

겉보기에는 제멋대로 뒤엉켜 요동치는 것처럼 보이는 복잡한 운동이, 실은 **"대칭 모드 50% $+$ 역대칭 모드 50%"라는 두 개의 독립된 사인파 진동을 단순히 더한 것**에 불과했습니다

이것이 바로 **대각화(Diagonalization)**의 진짜 힘입니다.

[NOTE]
====
**대각화의 본질**  
강성 행렬 $K$를 고유벡터 행렬 $P$로 대각화하면($P^T K P = D = \text{diag}(\omega_1^2, \omega_2^2)$), 얽혀있던 미분방정식이 $q_1'' + \omega_1^2 q_1 = 0$, $q_2'' + \omega_2^2 q_2 = 0$이라는 **완전히 독립된 두 개의 1변수 미분방정식**으로 쪼개집니다
====

== 직접 해보기: 역학적 에너지 보존 확인

뒤섞인 초기조건($x_1=1, x_2=0$)에서 진동하는 동안 전체 에너지($\text{KE} + \text{PE}$)가 보존되는지 확인해 보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def energy(x1,x2,v1,v2):
    KE = 0.5*m*(v1**2+v2**2)
    PE = 0.5*k*(x1**2+x2**2) + 0.5*k2*(x1-x2)**2
    return KE+PE

E = [energy(*sol_generic.y[:,i]) for i in range(len(t_eval))]
print("시점별 에너지:", E)
print("에너지 편차:", np.max(np.abs(np.array(E)-E[0])))
----

[source]
----
시점별 에너지: [2.5, 2.4999999999993845, 2.499999999998114, ...]
에너지 편차: 6.673772645626741e-12
----

두 질량이 복잡하게 에너지를 주고받는 동안에도 전체 에너지는 `2.5 J`로 완벽하게 보존됩니다.
