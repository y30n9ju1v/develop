1장의 RC 회로는 그냥 방전만 했습니다 — 외부 입력이 0인 **동차(homogeneous)** 방정식이었습니다.

이 장에서는 배터리 같은 외부 전압원 `Vs`를 연결해서 축전기를 충전시키는, 더 현실적인 **비동차(non-homogeneous)** 방정식을 다룹니다.

== 비동차 ODE: 오른쪽에 외부 입력이 있다

....
                   [ RC 충전 회로의 물리적 구조 ]

                     ┌─────── 저항 (R) ───────┐
                     │                         │
                   + ┴ -                       │
                 전원 (Vs)                     │
                     │                       + ┴ -
                     │                      축전기 (C)
                     │                       (전압 V(t))
                     │                         │
                     └─────────────────────────┘
....

키르히호프 전압 법칙을 적용하면 다음과 같은 1계 선형 미분방정식이 세워집니다:

[stem]
++++
\frac{dV}{dt} + \frac{V}{RC} = \frac{V_s}{RC}
++++

전압 `V`가 목표 전원 전압 `Vs`에서 얼마나 떨어져 있는지에 비례해서 그 차이를 줄이는 방향으로 충전됩니다.

== 적분 인자법(Integrating Factor)으로 손으로 풀기

이런 표준 형태($\frac{dy}{dt} + p(t)y = q(t)$)는 **적분 인자 $\mu(t) = e^{\int p(t)dt}$**를 양변에 곱하면 손쉽게 풀립니다. 여기서는 $p(t) = 1/RC$이므로 적분 인자는 $\mu(t) = e^{t/RC}$입니다.

....
                   [ 적분 인자법의 4단계 마법 ]

   1단계: 양변에 e^(t/RC) 곱하기
   ──► e^(t/RC) · (dV/dt) + (1/RC)e^(t/RC) · V = (Vs/RC) e^(t/RC)
                 │
                 ▼ 2단계: 곱의 미분 공식 d/dt(u·v)로 왼쪽을 묶기!
   ──► d/dt [ V(t) · e^(t/RC) ] = (Vs/RC) e^(t/RC)
                 │
                 ▼ 3단계: 양변을 t에 대해 적분!
   ──► V(t) · e^(t/RC) = Vs · e^(t/RC) + K
                 │
                 ▼ 4단계: e^(t/RC)로 나누고 초기조건(V(0)=V0)으로 K 결정!
   ──► 【 V(t) = Vs + (V0 - Vs) e^(-t/RC) 】
....

유도된 해석해를 그래프로 상상해 보면 매우 직관적입니다:

....
                   [ 정상 상태(Steady State)로의 수렴 ]

     전압 V(t)
        ▲
     Vs ├ - - - - - - - - - - - - - - - - - - - - ◄── 【 정상 상태: Vs (목표 전압) 】
        │                             . ─ ─ '
        │                        . ─ '
        │                   . ─ '
        │              . ─ '
     V0 • (초기 전압)
        └─────────────────────────────────────────► 시간 t
             t = 0                           t ──► ∞
....

시간이 충분히 지나면($t \to \infty$) 지수 감쇠항이 0으로 사라지며 축전기 전압은 전원 전압 `Vs`에 완벽히 도달합니다.

== 수치해와 대조하기

[source,python]
----
import numpy as np
from scipy.integrate import solve_ivp

R, C = 1000.0, 1e-3
tau = R * C
Vs = 9.0   # 전원 전압
V0 = 0.0   # 축전기는 비어 있는 상태로 시작

def f(t, V):
    return (Vs - V) / tau

sol = solve_ivp(f, [0, 5], [V0], t_eval=[0,1,2,3,4,5], rtol=1e-10, atol=1e-12)
analytical = Vs + (V0 - Vs) * np.exp(-np.array([0,1,2,3,4,5]) / tau)

print("numeric:   ", sol.y[0])
print("analytical:", analytical)
print("max err:", np.max(np.abs(sol.y[0]-analytical)))
----

[source]
----
numeric:    [0.         5.68908503 7.78198245 8.55191638 8.83515925 8.93935848]
analytical: [0.         5.68908503 7.78198245 8.55191638 8.83515925 8.93935848]
max err: 1.7118395589932334e-10
----

소수점 10자리까지 완벽하게 일치합니다

== 정상 상태(Steady State)로의 수렴 확인

[source,python]
----
sol_long = solve_ivp(f, [0, 20], [V0], t_eval=[20], rtol=1e-10, atol=1e-12)
print("V(20s) ~ Vs?:", sol_long.y[0][0], "vs", Vs)
----

[source]
----
V(20s) ~ Vs?: 8.999999981379121 vs 9.0
----

`RC = 1초`인 회로에서 20초(시정수의 20배)가 지나면 전압이 `8.99999998V`로 전원 전압의 99.99999%에 도달합니다.

[NOTE]
====
**과도 응답(Transient)과 정상 상태 응답(Steady-State)**  
* **과도 응답 $(V_0 - V_s)e^{-t/RC}$**: 스위치를 켠 직후 시스템이 적응하는 동안 일시적으로 나타났다가 지수적으로 사라지는 성분.
* **정상 상태 응답 $V_s$**: 시간이 무한히 흐른 뒤 외력과 균형을 이루어 영구히 남는 성분.  
모든 선형 시스템의 해는 이 두 성분의 합으로 깔끔하게 쪼개집니다.
====

== 직접 해보기

교류 전원($V_s(t) = V_{s0} \sin(\omega t)$)이 연결된 경우를 SymPy로 풀고, `solve_ivp`와 비교해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
import sympy as sp
import numpy as np
from scipy.integrate import solve_ivp

t, tau_s, Vs0_s, w_s = sp.symbols('t tau Vs0 w', positive=True)
V = sp.Function('V')
ode = sp.Eq(V(t).diff(t) + V(t)/tau_s, (Vs0_s/tau_s)*sp.sin(w_s*t))
sol = sp.dsolve(ode, V(t), ics={V(0): 0})

tau, Vs0, w = 1.0, 5.0, 2.0
Vt_func = sp.lambdify(t, sol.rhs.subs({tau_s: tau, Vs0_s: Vs0, w_s: w}), 'numpy')
t_eval = np.array([0,1,2,3,4,5])

def f_ac(tt, y):
    return [(Vs0*np.sin(w*tt) - y[0])/tau]

numsol = solve_ivp(f_ac, [0,5], [0.0], t_eval=t_eval, rtol=1e-12, atol=1e-14)
print("max diff:", np.max(np.abs(numsol.y[0]-Vt_func(t_eval))))
----

[source]
----
max diff: 5.389688695345285e-12
----

교류 전원이 진동함에 따라 축전기 전압도 같은 주파수로 진동하며, 수치해와 해석해가 소수점 11자리까지 일치합니다.
