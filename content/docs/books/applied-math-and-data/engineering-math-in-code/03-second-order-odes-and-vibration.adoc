'''

지금까지는 도함수가 한 번만 등장하는 1계 ODE만 다뤘습니다. 이 장에서는 도함수가 두 번 등장하는 **2계 ODE** — 기계공학의 핵심인 **질량-스프링-댐퍼 시스템**을 다룹니다.

== 질량-스프링-댐퍼 시스템

....
                   [ 질량-스프링-댐퍼 시스템의 구조 ]

     벽면
     │      스프링 (강성 k)
     ├───\/\/\/\/\/\/\/\/\/\/\───────┐
     │                               │     질량 (m)
     │       댐퍼 (감쇠계수 c)        ├───► [  m  ] ──► x(t) (변위)
     ├───[===]───────────────────────┘
     │   (피스톤 저항)
....

질량 $m$에 뉴턴의 제2법칙($F=m\ddot{x}$)을 적용하고 복원력($-kx$)과 저항력($-c\dot{x}$)을 더하면:

[stem]
++++
m\ddot{x} + c\dot{x} + kx = 0
++++

가속도($\ddot{x}$), 속도($\dot{x}$), 변위($x$)가 한 방정식에 모두 등장합니다.

== 특성방정식: 이차방정식 하나가 거동을 결정한다

이 미분방정식에 $x(t) = e^{rt}$를 대입하면 지수항이 묶이며 **특성방정식(characteristic equation)**이 됩니다:

[stem]
++++
mr^2 + cr + k = 0 \quad\Longrightarrow\quad r = \frac{-c \pm \sqrt{c^2 - 4mk}}{2m}
++++

판별식($\Delta = c^2 - 4mk$)의 부호에 따라 **질적으로 완전히 다른 3가지 물리적 거동**이 나타납니다

....
                   [ 판별식에 따른 3대 감쇠 거동 파형 비교 ]

     변위 x(t)
        ▲
     1.0 •──────────────.
        │ ╲              `─.
        │  ╲                `─.   ◄── 【 1. 과감쇠 (c² > 4mk): 둔하고 느린 복귀 】
        │   ╲                  `─.
        │    ╲.                  `─.
        │     │`─.                  `─.
        │     │   `─. ◄── 【 2. 임계감쇠 (c² = 4mk): 진동 없이 가장 빠른 복귀! 】
        │     │      `─ ─ ─ ─ ─ ─ ─ ─ ─ ─
      0 ┼─────┼──────.─────────────────────► 시간 t
        │     │     / `─.  / ◄── 【 3. 부족감쇠 (c² < 4mk): 출렁출렁 진동하며 감쇠 】
        │      ╲   /     `'
    -0.5│       `-'
....

== 경우 1: 부족감쇠 (Underdamped, $\Delta < 0$) — 진동하며 잦아든다

댐핑이 약하면($c^2 < 4mk$) 판별식이 음수라 근이 복소수 켤레 쌍이 되며, 해는 **삼각함수 진동 $\times$ 지수 감쇠 포락선**의 곱이 됩니다:
$$x(t) = e^{-\zeta \omega_0 t} \left( A\cos(\omega_d t) + B\sin(\omega_d t) \right)$$

[source,python]
----
import numpy as np
from scipy.integrate import solve_ivp

def simulate(m, c, k, x0, v0, t_eval):
    def f(t, y):
        x, v = y
        return [v, -(c/m)*v - (k/m)*x]
    sol = solve_ivp(f, [0, t_eval[-1]], [x0, v0], t_eval=t_eval, rtol=1e-12, atol=1e-14)
    return sol.y[0]

t_eval = np.array([0, 0.5, 1.0, 1.5, 2.0, 3.0, 5.0])
m, c, k = 1.0, 0.4, 4.0
x0, v0 = 1.0, 0.0

omega0 = np.sqrt(k/m)
zeta = c/(2*np.sqrt(m*k))
omega_d = omega0*np.sqrt(1-zeta**2)
A = x0
B = zeta*omega0*x0/omega_d
analytical = np.exp(-zeta*omega0*t_eval)*(A*np.cos(omega_d*t_eval)+B*np.sin(omega_d*t_eval))
numeric = simulate(m,c,k,x0,v0,t_eval)

print("underdamped max err:", np.max(np.abs(numeric-analytical)))
----

[source]
----
underdamped max err: 4.334310688136611e-13
----

수치해와 해석해가 기계 정밀도(`1e-13`)까지 일치하며, 변위가 양수와 음수를 오가며 출렁입니다.

== 경우 2: 과감쇠 (Overdamped, $\Delta > 0$) — 진동 없이 서서히 복귀

댐핑이 너무 세면($c^2 > 4mk$) 판별식이 양수라 두 실근이 나오며, 진동이 완전히 사라지고 끈적하게 복귀합니다. 문이 "쾅" 닫히지 않게 막는 도어 클로저의 원리입니다.

[source,python]
----
m, c, k = 1.0, 10.0, 4.0
disc = c**2-4*m*k
r1 = (-c + np.sqrt(disc))/(2*m)
r2 = (-c - np.sqrt(disc))/(2*m)
A = -r2/(r1-r2)
B = r1/(r1-r2)
analytical = A*np.exp(r1*t_eval) + B*np.exp(r2*t_eval)
numeric = simulate(m,c,k,1.0,0.0,t_eval)
print("overdamped max err:", np.max(np.abs(numeric-analytical)))
----

[source]
----
overdamped max err: 4.1799896877137144e-14
----

== 경우 3: 임계감쇠 (Critically Damped, $\Delta = 0$) — 가장 빠른 복귀

판별식이 정확히 0이면($c^2 = 4mk$) 진동하지 않으면서 **세상에서 가장 빨리 원점으로 복귀**합니다 ($x(t) = (A + Bt)e^{rt}$).

[source,python]
----
m, k = 1.0, 4.0
c = 2*np.sqrt(m*k)   # 임계 감쇠 조건
r = -c/(2*m)
analytical = (1.0 + (-r)*t_eval)*np.exp(r*t_eval)
numeric = simulate(m,c,k,1.0,0.0,t_eval)
print("critical max err:", np.max(np.abs(numeric-analytical)))
----

[source]
----
critical max err: 4.823919041996305e-14
----

자동차 서스펜션(쇼크업소버)이나 계기판 바늘을 설계할 때 진동 없이 즉각 정지하도록 정확히 이 **임계감쇠** 지점을 세팅합니다.

[NOTE]
====
**2계 ODE를 파이썬 솔버(`solve_ivp`)에 넣는 비결**  
`solve_ivp`는 1계 미분방정식만 받습니다. 따라서 변위 $x$와 속도 $v = \dot{x}$를 묶은 벡터 $[x, v]$를 만들어, **"2계 방정식 1개 $\to$ 1계 연립방정식 2개($\dot{x}=v, \dot{v}=-(c/m)v-(k/m)x$)"**로 변환하여 푸는 것이 표준 기법입니다.
====

== 직접 해보기: 공진 (Resonance)의 파괴력

주기적인 외력 $F_0 \cos(\omega t)$를 걸어줄 때, 외력의 주파수가 시스템의 고유 진동수($\omega_0 = \sqrt{k/m}$)와 일치하면 진폭이 어떻게 폭증하는지 시뮬레이션해 보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
m, c, k = 1.0, 0.1, 4.0
omega0 = np.sqrt(k/m)
F0 = 1.0

def simulate_forced(omega, t_end):
    def f(t,y):
        x,v = y
        return [v, (F0*np.cos(omega*t) - c*v - k*x)/m]
    sol = solve_ivp(f, [0,t_end], [0,0], t_eval=np.linspace(0,t_end,int(t_end*20)), rtol=1e-10, atol=1e-12)
    return sol.t, sol.y[0]

t_off, x_off = simulate_forced(1.0, 60)      # 어긋난 주파수
t_res, x_res = simulate_forced(omega0, 60)   # 고유 진동수와 일치 (공진!)

print("off-resonance max |x|:", np.max(np.abs(x_off[t_off>50])))
print("at resonance max |x|: ", np.max(np.abs(x_res[t_res>50])))
----

[source]
----
off-resonance max |x|: 0.35617258481608555
at resonance max |x|:  4.736869174006135
----

외력의 크기는 같은데 주파수를 고유 진동수에 맞추는 것만으로 진폭이 **13배 넘게 폭증(0.36 $\to$ 4.74)**합니다
====

[TIP]
====

====
