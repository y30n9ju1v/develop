10장에서 gradient·divergence·curl을 계산하는 법을 익혔습니다. 이 장에서는 이 도구들을 실제 물리 문제 세 가지에 적용해서, "divergence가 0이다"나 "curl이 0이다"라는 말이 실제로 무슨 뜻인지 체감합니다.

== 회전하는 유체: divergence는 0, curl은 0이 아니다

물이 원점을 중심으로 빙글빙글 도는 흐름을 생각해봅시다 — 속도장이 `v = (-y, x, 0)`입니다(반시계 방향 회전).

[source,python]
----
import numpy as np

def v_rot(x,y,z):
    return np.array([-y, x, 0.0])

pts = [(1,0,0), (2,3,0), (-1,1,0)]
for p in pts:
    print("point", p, "div:", divergence_numeric(v_rot,*p), "curl:", curl_numeric(v_rot,*p))
----

[source]
----
point (1, 0, 0) div: 0.0 curl: [0. 0. 2.]
point (2, 3, 0) div: 0.0 curl: [0. 0. 2.]
point (-1, 1, 0) div: 0.0 curl: [0. 0. 2.]
----

**어느 점에서 계산해도 `div=0`, `curl=(0,0,2)`가 똑같이 나옵니다.** `div=0`이라는 건 어느 지점에서든 "물이 새로 생기거나 사라지지 않는다"는 뜻 — 비압축성 유체(물처럼 압축이 안 되는 유체)라면 반드시 성립해야 하는 조건입니다. `curl=(0,0,2)`는 이 회전이 z축을 중심으로, 어디서나 똑같은 세기(각속도의 2배)로 돌고 있다는 뜻입니다 — 실제로 이 흐름은 강체처럼 통째로 회전하는 흐름이라, 어느 점에 바람개비를 놓든 똑같이 돕니다.

== 솟아나는 유체: divergence가 0이 아니면 원천이 있다

이번엔 원점에서 사방으로 뿜어져 나오는 흐름 `v = (x, y, 0)`입니다.

[source,python]
----
def v_src(x,y,z):
    return np.array([x, y, 0.0])

for p in pts:
    print("point", p, "div:", divergence_numeric(v_src,*p), "curl:", curl_numeric(v_src,*p))
----

[source]
----
point (1, 0, 0) div: 1.9999999999732445 curl: [0. 0. 0.]
point (2, 3, 0) div: 2.0000000001685336 curl: [0. 0. 0.]
point (-1, 1, 0) div: 1.999999999946489 curl: [0. 0. 0.]
----

이번엔 `div`가 어디서든 `2`(0이 아님)이고 `curl`은 `0`입니다. `div≠0`은 물리적으로 "이 흐름에는 원천(source, 물이 새로 솟아나는 지점)이나 흡입구(sink)가 있다"는 뜻입니다(현실의 비압축성 유체라면 이런 흐름은 불가능합니다 — 물이 계속 새로 생겨나야 하니까요). `curl=0`은 이 흐름이 소용돌이 없이 곧장 퍼져나간다는 뜻입니다 — 회전하는 흐름(앞 절)과 정반대의 성격입니다.

== 점전하의 전기장: 전하가 없는 곳에서는 두 값 다 0이다

정전기학의 가우스 법칙은 "전기장의 divergence는 그 지점의 전하 밀도에 비례한다"고 말합니다 — 전하가 없는 빈 공간에서는 `div E = 0`이어야 합니다. 원점에 점전하가 있을 때의 전기장(쿨롱의 법칙, 방향은 원점에서 바깥쪽, 크기는 거리의 제곱에 반비례)을 원점이 아닌 곳에서 확인해봅니다.

[source,python]
----
def E_point(x,y,z):
    r = np.sqrt(x**2+y**2+z**2)
    return np.array([x,y,z])/r**3   # 방향은 바깥쪽, 크기는 1/r^2

for p in [(1,0,0),(1,1,1),(2,-1,3)]:
    print("point", p, "div:", divergence_numeric(E_point,*p), "curl:", curl_numeric(E_point,*p))
----

[source]
----
point (1, 0, 0) div: -5.000444502911705e-12 curl: [0. 0. 0.]
point (1, 1, 1) div: 0.0 curl: [0. 0. 0.]
point (2, -1, 3) div: 0.0 curl: [-6.9388939e-12  0.0000000e+00  6.9388939e-12]
----

전하가 있는 원점을 뺀 어디에서 계산해도 `div`와 `curl` 둘 다 `0`에 아주 가깝습니다(`1e-12` 수준 — 완전히 0은 아니지만 이건 유한차분 근사 자체의 오차이지 실제 물리량이 0이 아니라서가 아닙니다). `1/r^2`으로 정확히 줄어드는 쿨롱의 법칙이 왜 그 특정한 지수를 갖는지(다른 지수였다면 원점이 아닌 곳에서도 `div≠0`이 나왔을 것입니다), `curl=0`이 왜 "정전기장에서는 전위(potential)라는 스칼라 함수가 항상 존재한다"는 결론으로 이어지는지가 이 두 숫자에 압축되어 있습니다.

== curl(grad f) = 0: 이건 우연이 아니라 항상 성립하는 항등식이다

정전기장이 항상 `curl=0`인 이유는 사실 더 근본적인 사실에서 나옵니다 — **어떤 스칼라장의 gradient를 취한 벡터장은 curl이 항상 0**입니다(정전기장은 전위의 gradient이기 때문에 이 항등식이 자동으로 적용됩니다). 이걸 임의의 스칼라장으로 직접 확인해봅니다.

[source,python]
----
def f(x,y,z):
    return x**2*y*z + np.sin(x)*y

def grad_f_numeric(x,y,z,h=1e-5):
    dfdx = (f(x+h,y,z)-f(x-h,y,z))/(2*h)
    dfdy = (f(x,y+h,z)-f(x,y-h,z))/(2*h)
    dfdz = (f(x,y,z+h)-f(x,y,z-h))/(2*h)
    return np.array([dfdx,dfdy,dfdz])

for p in [(1,2,3),(0.5,-1,2)]:
    c = curl_numeric(grad_f_numeric, *p, h=1e-3)
    print("point", p, "curl(grad f):", c)
----

[source]
----
point (1, 2, 3) curl(grad f): [ 1.11022302e-13 -2.22045715e-08 -1.11022302e-07]
point (0.5, -1, 2) curl(grad f): [-2.77554368e-09  2.77557133e-09 -1.49880108e-07]
----

완전히 임의로 고른 `f`인데도 `curl(grad f)`가 `1e-7`보다 작은, 사실상 0인 값이 나옵니다(이 계산은 `grad_f_numeric` 자체가 이미 유한차분 근사라서, 그 근사값을 또 유한차분으로 미분하는 "이중 근사"라 오차가 10장 예제들보다 조금 더 큽니다 — 그래도 정말로 0에 가깝다는 결론에는 문제가 없습니다). 이건 우연이 아니라 미적분의 정리입니다 — gradient는 "가장 가파른 방향"을 가리키는 벡터장인데, 그런 벡터장은 애초에 회전을 만들어낼 수 없습니다(만약 회전이 있다면 한 바퀴 돌아왔을 때 함숫값이 달라져야 하는데, `f`는 그 점에서 유일한 값을 가지므로 모순입니다).

== 직접 해보기

* 지금까지는 순수하게 회전만 하거나(`div=0`) 순수하게 솟아나기만 하는(`curl=0`) 흐름만 봤습니다. 두 성질을 동시에 가진 흐름 `v = (x-y, x+y, 0)`의 divergence와 curl을 계산해서, 회전과 원천이 한 흐름 안에 동시에 존재할 수 있는지 확인해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def v_mix(x,y,z):
    return np.array([x-y, x+y, 0.0])

for p in [(1,0,0),(2,3,0)]:
    print(p, "div:", divergence_numeric(v_mix,*p), "curl:", curl_numeric(v_mix,*p))
----

[source]
----
(1, 0, 0) div: 1.999999999946489 curl: [0. 0. 2.]
(2, 3, 0) div: 2.0000000001685336 curl: [0. 0. 2.]
----

이 흐름은 앞서 본 두 순수한 흐름의 **합**(`(x,y,0) + (-y,x,0)`)입니다 — 그래서 divergence(`2`, 솟아나는 흐름에서 그대로)와 curl(`(0,0,2)`, 회전하는 흐름에서 그대로)이 각각 독립적으로 나타납니다. 실제 유체(예: 태풍처럼 회전하면서 동시에 중심에서 상승 기류가 솟아나는 경우)는 이렇게 두 성질이 섞인 경우가 오히려 흔하고, divergence와 curl은 서로 다른 질문에 답하는 독립적인 측정값이라 이렇게 각자 자유롭게 섞일 수 있습니다.
====

== 요약

* 회전하는 유체 흐름은 어디서나 `div=0`(비압축성)이고 `curl≠0`(소용돌이가 있음)이라는 걸, 솟아나는 흐름은 정반대로 `div≠0`(원천이 있음)이고 `curl=0`(소용돌이 없음)이라는 걸 시뮬레이션으로 확인했습니다.
* 점전하의 전기장이 전하가 없는 지점에서는 `div`와 `curl` 둘 다 사실상 0이라는 걸 확인해, 가우스 법칙과 "정전기장은 회전이 없다"는 사실을 숫자로 체감했습니다.
* `curl(grad f) = 0`이라는 항등식을 임의의 스칼라장으로 실제 계산해 확인하고, 이게 정전기장이 항상 회전이 없는 근본적인 이유라는 것도 짚었습니다.
