10장에서 배운 세 연산자(gradient, divergence, curl)를 실제 자연계의 두 거대한 물리 법칙인 **유체역학**과 **전자기학**에 적용해 봅시다.

== 1. 회전하는 유체 vs 뿜어져 나오는 유체

....
                   [ 유체의 2대 순수 흐름 패턴 비교 ]

   【 1. 회전 흐름 (v = (-y, x, 0)) 】           【 2. 뿜어 나오는 흐름 (v = (x, y, 0)) 】
              ▲                                           ▲  ▲  ▲
              │ ◄── ─ ─                                   │  │  │
         ──► ┌───┐ ◄──                                ◄─── • ───► (원천 source)
             │ ↻ │ (소용돌이)                             │  │  │
         ──► └───┘ ──►                                    ▼  ▼  ▼
              │ ─ ─ ──►
     • div = 0 (물이 안 생김, 비압축성!)          • div = 2 (원천에서 물이 계속 솟아남!)
     • curl = (0, 0, 2) (강체 회전!)              • curl = 0 (소용돌이 없이 직선 방사!)
....

### 1) 회전 흐름: $\text{div}=0$, $\text{curl}\neq 0$

[source,python]
----
import numpy as np

def v_rot(x,y,z):
    return np.array([-y, x, 0.0])

pts = [(1,0,0), (2,3,0), (-1,1,0)]
for p in pts:
    print("point", p, "div:", divergence_numeric(v_rot,*p), "curl:", curl_numeric(v_rot,*p))
----

[source]
----
point (1, 0, 0) div: 0.0 curl: [0. 0. 2.]
point (2, 3, 0) div: 0.0 curl: [0. 0. 2.]
point (-1, 1, 0) div: 0.0 curl: [0. 0. 2.]
----

어느 점에서나 $\text{div}=0$입니다. 물 분자가 어디서도 새로 생기거나 사라지지 않는 **비압축성 유체(Incompressible Fluid)**의 필수 조건입니다.

### 2) 솟아나는 흐름: $\text{div}\neq 0$, $\text{curl}=0$

[source,python]
----
def v_src(x,y,z):
    return np.array([x, y, 0.0])

for p in pts:
    print("point", p, "div:", divergence_numeric(v_src,*p), "curl:", curl_numeric(v_src,*p))
----

[source]
----
point (1, 0, 0) div: 2.0 curl: [0. 0. 0.]
point (2, 3, 0) div: 2.0 curl: [0. 0. 0.]
point (-1, 1, 0) div: 2.0 curl: [0. 0. 0.]
----

$\text{div}=2.0$으로 양수입니다. 원천에서 물이 계속 뿜어져 나오는 비회전 방사 흐름입니다.

== 2. 점전하의 전기장과 가우스 법칙

전자기학의 맥스웰 제1방정식(가우스 법칙)은 **"전기장의 divergence는 전하 밀도에 비례한다 ($\nabla \cdot E = \rho/\varepsilon_0$)"**고 선언합니다.

따라서 전하가 없는 빈 공간에서는 $\nabla \cdot E = 0$이어야 합니다. 쿨롱의 법칙($E = \frac{r}{r^3}$)을 점전하 주변의 빈 공간에서 계산해 봅시다:

[source,python]
----
def E_point(x,y,z):
    r = np.sqrt(x**2+y**2+z**2)
    return np.array([x,y,z])/r**3

for p in [(1,0,0), (1,1,1), (2,-1,3)]:
    print("point", p, "div:", divergence_numeric(E_point,*p), "curl:", curl_numeric(E_point,*p))
----

[source]
----
point (1, 0, 0) div: -5.000e-12 curl: [0. 0. 0.]
point (1, 1, 1) div: 0.0 curl: [0. 0. 0.]
point (2, -1, 3) div: 0.0 curl: [-6.938e-12  0.  6.938e-12]
----

전하가 존재하는 원점을 제외한 모든 빈 공간에서 **$\text{div } E = 0$, $\text{curl } E = 0$**이 완벽하게 성립합니다

== 3. 불멸의 항등식: $\text{curl}(\text{grad } f) = 0$

정전기장이 항상 회전이 없는($\text{curl } E = 0$) 근본적인 이유는, 전기장이 **전위(전압 $V$)라는 스칼라장의 기울기($E = -\nabla V$)**이기 때문입니다.

임의의 스칼라장에 대해 gradient를 취한 뒤 curl을 계산하면 언제나 0이 됩니다:

[source,python]
----
def f(x,y,z):
    return x**2*y*z + np.sin(x)*y

def grad_f_numeric(x,y,z,h=1e-5):
    dfdx = (f(x+h,y,z)-f(x-h,y,z))/(2*h)
    dfdy = (f(x,y+h,z)-f(x,y-h,z))/(2*h)
    dfdz = (f(x,y,z+h)-f(x,y,z-h))/(2*h)
    return np.array([dfdx,dfdy,dfdz])

for p in [(1,2,3),(0.5,-1,2)]:
    c = curl_numeric(grad_f_numeric, *p, h=1e-3)
    print("point", p, "curl(grad f):", c)
----

[source]
----
point (1, 2, 3) curl(grad f): [ 1.11e-13 -2.22e-08 -1.11e-07]
point (0.5, -1, 2) curl(grad f): [-2.77e-09  2.77e-09 -1.49e-07]
----

[NOTE]
====
**보존력장(Conservative Field)과 에너지 보존**  
$\text{curl } F = 0$인 힘의 장(중력장, 정전기장)을 **보존력장**이라고 부릅니다. 이 장 안에서는 경로를 따라 한 바퀴 돌아 제자리로 오면 한 일의 총합이 0이 되므로, 경로에 무관하게 '위치에너지(Potential Energy)'를 정의할 수 있습니다.
====

== 직접 해보기

회전과 분출이 섞인 복합 흐름 $v = (x-y, x+y, 0)$의 div와 curl을 계산해 보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def v_mix(x,y,z):
    return np.array([x-y, x+y, 0.0])

for p in [(1,0,0),(2,3,0)]:
    print(p, "div:", divergence_numeric(v_mix,*p), "curl:", curl_numeric(v_mix,*p))
----

[source]
----
(1, 0, 0) div: 2.0 curl: [0. 0. 2.]
(2, 3, 0) div: 2.0 curl: [0. 0. 2.]
----

선형 중첩에 의해 divergence는 2(분출), curl은 `[0, 0, 2]`(회전)가 동시에 독립적으로 나타납니다
====
