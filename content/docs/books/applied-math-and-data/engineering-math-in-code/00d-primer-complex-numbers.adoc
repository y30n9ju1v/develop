'''

이 책 3부(고유값)와 6~7부(푸리에·복소해석)에서는 답에 `i`(또는 공학에서 흔히 쓰는 `j`)가 섞인 숫자가 자연스럽게 등장합니다. "허수"라는 이름 때문에 뭔가 신비롭거나 실재하지 않는 것처럼 느껴지기 쉬운데, 이 장에서는 그냥 "왜 이런 숫자가 필요해지는지"부터 계산으로 확인합니다.

== 실수만으로는 못 푸는 방정식을 만나보기

이차방정식 `x² + 2x + 5 = 0`을 근의 공식으로 풀어봅니다.

[stem]
++++
x = \frac{-b \pm \sqrt{b^2-4ac}}{2a} = \frac{-2 \pm \sqrt{4-20}}{2} = \frac{-2 \pm \sqrt{-16}}{2}
++++

`√-16`이 문제입니다 — 어떤 실수를 제곱해도 음수가 나올 수 없으므로(양수든 음수든 제곱하면 항상 `0` 이상), **이 방정식은 실수 범위 안에 답이 없습니다.**

[source,python]
----
import numpy as np

a, b, c = 1, 2, 5
disc = b**2 - 4*a*c
print("판별식(루트 안의 값):", disc)
----

[source]
----
판별식(루트 안의 값): -16
----

여기서 수학자들이 택한 방법은 "이 방정식은 답이 없다"고 포기하는 대신, **"제곱하면 `-1`이 되는 새로운 기호($i^2 = -1$)를 하나 만들어서 셈의 규칙을 확장하자"** 는 것이었습니다.

이렇게 확장하면 `√-16 = √16 × √-1 = 4i`가 되어, 방정식이 $x = -1 \pm 2i$라는 명쾌한 답을 갖습니다.

== 복소수는 그냥 "실수 두 개의 짝"이다

`i`를 도입하면, 이제 모든 수를 `a + bi`(`a`, `b`는 보통의 실수) 꼴로 쓸 수 있습니다 — 이걸 **복소수**라고 부릅니다. 신비로운 게 아니라, **실수 두 개(`a`와 `b`)를 정해진 규칙으로 묶은 것**뿐입니다.

파이썬은 복소수를 기본으로 지원합니다(`j`를 허수 단위로 씁니다 — 공학 표기 관례입니다, `i`는 전류를 가리키는 데 이미 쓰이기 때문입니다).

[source,python]
----
z1 = 3 + 4j
z2 = 1 - 2j

print("덧셈:", z1 + z2)
print("곱셈:", z1 * z2)
----

[source]
----
덧셈: (4+2j)
곱셈: (11-2j)
----

곱셈은 `i²=-1`이라는 규칙을 기억하고 다항식처럼 전개하면 됩니다:
$$(3+4i)(1-2i) = 3 - 6i + 4i - 8i^2 = 3 - 2i + 8 = \mathbf{11 - 2i}$$

== 기하학적 직관: 복소평면과 90도 회전

복소수 $z = a + bi$를 평면 위의 직교좌표 $(a, b)$로 그리는 것을 **복소평면(Complex Plane)**이라고 부릅니다.

....
                   [ 복소평면과 i를 곱할 때의 90° 회전 ]

     허수부 (Im)
        ▲
      4 │                    • z = 3 + 4j (크기 |z| = √(3²+4²) = 5)
        │                   /│
      2 │                  / │
        │                 /  │
      0 └────────────────┴───┴────────────────────────► 실수부 (Re)
        0                3
                         │
                         ▼ i를 한 번 곱하면 (z × i)
        ▲
      3 │         • (-4 + 3j)  ◄── 정확히 【 90° 반시계 방향 회전! 】
        │        /
      0 └───────┴─────────────────────────────────────► 실수부 (Re)
               -4
....

복소수에 $i$를 한 번 곱하는 것은, 기하학적으로 **원점을 중심으로 90도 반시계 방향으로 회전**시키는 완벽한 회전 연산자입니다 ($i$를 두 번 곱하면 $180^\circ$ 회전이 되어 부호가 반대인 $-1$이 됩니다.)

[NOTE]
====
**공학에서 왜 복소수가 필수적인가요?**  
회로의 교류(AC) 신호, 기계의 진동, 전자기파, 양자역학 등 자연계의 모든 파동은 **"진폭(크기)"과 "위상(각도)"**이라는 두 가지 정보를 동시에 갖습니다. 복소수는 실수 하나로 두 개의 정보(크기와 회전 각도)를 한꺼번에 다룰 수 있는 가장 완벽한 수학적 도구입니다.
====

== 방정식을 다시 풀어보기

`i`라는 도구가 생겼으니, 아까 "답이 없던" 방정식을 다시 풉니다.

[source,python]
----
root1 = (-b + np.sqrt(complex(disc))) / (2*a)
root2 = (-b - np.sqrt(complex(disc))) / (2*a)
print("근:", root1, root2)

def f(x):
    return a*x**2 + b*x + c
print("검산 f(root1):", f(root1))
----

[source]
----
근: (-1+2j) (-1-2j)
검산 f(root1): 0j
----

`x = -1+2j`를 원래 방정식에 다시 넣으면 정확히 `0`이 나옵니다 — 복소수가 실수 범위에서 안 풀리던 방정식을 해결하는 완벽한 확장임을 확인했습니다.

== 직접 해보기

`x² - 6x + 25 = 0`을 판별식부터 계산해서 복소수 범위에서 풀고, 검산까지 해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
a, b, c = 1, -6, 25
disc = b**2 - 4*a*c
print("판별식:", disc)

root1 = (-b + np.sqrt(complex(disc))) / (2*a)
root2 = (-b - np.sqrt(complex(disc))) / (2*a)
print("근:", root1, root2)

def f(x):
    return a*x**2 + b*x + c
print("검산:", f(root1), f(root2))
----

[source]
----
판별식: -64
근: (3+4j) (3-4j)
검산: 0j 0j
----

판별식이 `-64`로 음수라 두 근(`3+4i`와 `3-4i`)이 서로 켤레 복소수(Conjugate) 쌍으로 나옵니다.
====

[TIP]
====
**확인 질문**: 복소수 $z = 3+4i$의 크기는 피타고라스 정리로 $\sqrt{3^2+4^2} = 5$입니다. 여기에 $i$를 곱한 $z \times i = -4+3i$의 크기는 얼마일까요? (크기는 5로 유지되고 각도만 $90^\circ$ 회전합니다)
====

0부 준비운동이 끝났습니다. 이제 1부에서는 시간에 따른 변화율을 다루는 **상미분방정식(ODE)**의 세계로 들어갑니다
