'''

2부가 시작됩니다.

1부에서는 미분방정식을 적분 인자법과 특성방정식으로 직접 풀었습니다. 2부에서는 미분방정식을 **아예 미적분 없이 대수 방정식(사칙연산)으로 바꾸어 버리는 마법의 도구**, **라플라스 변환(Laplace Transform)**을 배웁니다.

== 핵심 아이디어: "미분(골칫거리)을 곱셈(산수)으로 바꾼다"

....
                   [ 라플라스 변환의 문제 해결 파이프라인 ]

   【 시간 영역 (Time Domain) 】             【 라플라스 영역 (s-Domain) 】
   • 복잡한 미분방정식                        • 단순한 대수 방정식 (분수식)
     dV/dt + V/τ = Vs/τ    ──► 라플라스 변환 ──►  s X(s) - V0 + X(s)/τ = Vs/(τ s)
                                                     │
                                                     ▼ 고등학교 수준의 대수 풀이!
   • 시간 영역의 최종 해 v(t) ◄── 역변환 (Inverse) ──  X(s) = (V0 s τ + Vs) / (s(s τ + 1))
....

라플라스 변환의 정의는 다음과 같습니다:

[stem]
++++
F(s) = \mathcal{L}\{f(t)\} = \int_0^\infty f(t) e^{-st}\, dt
++++

이 적분 공식 자체보다 공학에서 100배 더 중요한 것은 바로 **미분에 대한 변환 성질**입니다:

[stem]
++++
\mathcal{L}\left\{ \frac{df}{dt} \right\} = s F(s) - f(0)
++++

"시간 영역에서 미분한다"는 어려운 연산이, 라플라스 영역에서는 **"그냥 $s$를 곱하고 초기값을 뺀다"**는 단순한 사칙연산으로 바뀝니다

== 2장의 RC 회로를 라플라스 변환으로 다시 풀기

2장에서 적분 인자법으로 풀었던 비동차 방정식을 라플라스로 다시 풀어봅시다:

[stem]
++++
\frac{dV}{dt} + \frac{V}{\tau} = \frac{V_s}{\tau}, \quad V(0) = V_0
++++

양변에 라플라스 변환을 걸면 미분이 사라지고 $X(s)$에 대한 중학생 수준의 1차 분수 방정식이 됩니다:

[stem]
++++
s X(s) - V_0 + \frac{X(s)}{\tau} = \frac{V_s}{\tau s}
++++

이 대수 계산을 파이썬 기호 계산 라이브러리인 **SymPy**에 맡겨봅니다.

[source,python]
----
import sympy as sp

t, s = sp.symbols('t s', positive=True, real=True)
tau, Vs, V0 = sp.symbols('tau Vs V0', positive=True)
Xs = sp.symbols('Xs')

# sX - V0 + X/tau = Vs/(tau*s)
eq = sp.Eq(s*Xs - V0 + Xs/tau, (Vs/tau)/s)
sol_Xs = sp.solve(eq, Xs)[0]
print("X(s) =", sp.simplify(sol_Xs))
----

[source]
----
X(s) = (V0*s*tau + Vs)/(s*(s*tau + 1))
----

미분방정식이 완전히 사라지고 순수한 분수식만 남았습니다

== 역변환으로 시간 영역으로 복귀하기

SymPy의 `inverse_laplace_transform`으로 원래 시간 영역 $v(t)$로 되돌아옵니다.

[source,python]
----
v_t = sp.inverse_laplace_transform(sol_Xs, s, t)
v_t = sp.simplify(v_t)
print("v(t) =", v_t)

# 2장에서 손으로 유도한 해석해와 기호 비교
known = V0*sp.exp(-t/tau) + Vs*(1-sp.exp(-t/tau))
diff = sp.simplify(v_t - known)
print("difference (should be 0):", diff)
----

[source]
----
v(t) = (V0 + Vs*exp(t/tau) - Vs)*exp(-t/tau)
difference (should be 0): 0
----

2장에서 손으로 적분 인자법을 써서 고생스럽게 유도한 답과 **차이가 정확히 0**입니다

== 3대 독립 방법의 교차 검증 (소수점 8자리 일치)

[source,python]
----
numeric_expr = v_t.subs({tau: 1.0, Vs: 9.0, V0: 0.0})
for tv in [0,1,2,3,4,5]:
    print(f"t={tv}: {float(numeric_expr.subs(t, tv)):.8f}")
----

[source]
----
t=0: 0.00000000
t=1: 5.68908503
t=2: 7.78198245
t=3: 8.55191638
t=4: 8.83515925
t=5: 8.93935848
----

**수치적분(`solve_ivp`), 적분 인자법(손 계산), 라플라스 변환(SymPy)**이라는 완전히 독립된 3가지 방법이 소수점 8자리까지 동일한 숫자를 냅니다.

[NOTE]
====
**공학자들은 왜 라플라스 변환을 사랑할까요?**  
회로망이나 제어 시스템에서 스위치가 켜지거나(스텝 함수), 벼락이 치듯 순간 펄스가 들어올 때(디랙 델타 함수), 일반 미적분학은 구간마다 적분을 쪼개야 해서 극도로 복잡해집니다. 하지만 라플라스 변환에서는 이런 불연속 입력조차 $1/s$나 $1$ 같은 단순 대수식으로 바뀌므로 복잡한 시스템을 레고 블록 조립하듯 사칙연산으로 풀 수 있습니다.
====

== 직접 해보기

미분 성질 $\mathcal{L}\{f'(t)\} = sF(s) - f(0)$을 $f(t) = e^{-at}$로 SymPy를 통해 직접 검증해 보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
import sympy as sp

t, s, a = sp.symbols('t s a', positive=True)
f = sp.exp(-a*t)
fprime = sp.diff(f, t)

F = sp.laplace_transform(f, t, s, noconds=True)
Fprime_direct = sp.laplace_transform(fprime, t, s, noconds=True)
Fprime_via_property = s*F - f.subs(t, 0)

print("F(s) =", F)
print("s*F(s) - f(0):", sp.simplify(Fprime_via_property))
print("match:", sp.simplify(Fprime_direct - Fprime_via_property) == 0)
----

[source]
----
F(s) = 1/(a + s)
s*F(s) - f(0): -a/(a + s)
match: True
----

직접 적분한 결과와 미분 공식이 완벽하게 일치합니다.
====

[TIP]
====
**확인 질문**: 2계 도함수 $f''(t)$를 라플라스 변환하면 어떻게 될까요? 미분 규칙을 두 번 적용하면 $\mathcal{L}\{f''(t)\} = s^2 F(s) - s f(0) - f'(0)$이 되어 $s^2$의 이차식이 됩니다
====
