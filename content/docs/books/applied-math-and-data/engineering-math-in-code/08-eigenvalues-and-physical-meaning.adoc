4부가 시작됩니다.

3부에서는 연립방정식을 행렬로 묶어 푸는 법(`Ax=b`)을 다뤘습니다. 이 장부터는 조금 더 깊은 질문을 던집니다:

> **"여러 변수가 서로 복잡하게 뒤얽혀 요동치는 시스템을,  
> 서로 전혀 간섭하지 않는 독립적인 조각들로 쪼갤 수는 없을까?"**

그 해답의 열쇠가 바로 선형대수학의 심장, **고유값(Eigenvalue)**과 **고유벡터(Eigenvector)**입니다.

== 행렬을 곱하면 보통 벡터의 방향이 꺾인다

행렬 $A$를 벡터 $v$에 곱하는 것은 기하학적으로 **"공간을 비틀어 벡터를 회전시키고 늘이거나 줄이는 변환"**입니다.

다음 2x2 대칭행렬을 살펴봅시다:

[source,python]
----
import numpy as np

A = np.array([[3.0, 1.0],
              [1.0, 2.0]])

w = np.array([1.0, 1.0])
Aw = A @ w

def angle_between(u, v):
    cos_theta = np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))
    return np.degrees(np.arccos(np.clip(cos_theta, -1, 1)))

print("w =", w)
print("A@w =", Aw)
print("꺾인 각도:", angle_between(w, Aw), "도")
----

[source]
----
w = [1. 1.]
A@w = [4. 3.]
꺾인 각도: 8.130102354156005 도
----

임의의 벡터 `w=[1,1]`에 $A$를 곱했더니 `[4,3]`이 되며 **원래 방향에서 약 8.13도 꺾였습니다.**

....
                   [ 일반 벡터 vs 고유벡터의 행렬 변환 기하도 ]

     【 1. 일반 벡터 w (방향이 꺾임!) 】        【 2. 고유벡터 v (방향 불변! 길이만 변화!) 】
        ▲                                          ▲
        │           • A@w = [4, 3]                 │             • A@v = λv
        │          /                               │            /
        │         / ◄── 8.13° 꺾임                 │           /  ◄── 각도 0.0°!
        │        • w = [1, 1]                      │          • v (길이만 λ배 늘어남)
        └───────┴─────────────────►                └─────────┴─────────────────►
....

== 딱 두 가지 특별한 방향만은 전혀 꺾이지 않는다

그런데 모든 벡터가 다 꺾이는 것은 아닙니다. 행렬 $A$마다 **"아무리 $A$를 곱해도 방향이 1도 꺾이지 않고 오직 길이만 늘어나는 특별한 축"**이 반드시 존재합니다.

`numpy.linalg.eigh`로 그 특별한 방향들을 찾아봅시다.

[source,python]
----
eigvals, eigvecs = np.linalg.eigh(A)
print("고유값 (길이 배율):", eigvals)
print("고유벡터 (방향):\n", eigvecs)

for i in range(2):
    v = eigvecs[:, i]
    Av = A @ v
    print(f"고유벡터 {i}번의 회전 각도: {angle_between(v, Av):.1f} 도")
----

[source]
----
고유값 (길이 배율): [1.38196601 3.61803399]
고유벡터 (방향):
 [[ 0.52573111 -0.85065081]
 [-0.85065081 -0.52573111]]
고유벡터 0번의 회전 각도: 0.0 도
고유벡터 1번의 회전 각도: 0.0 도
----

각도가 **정확히 `0.0`도**입니다

이것이 바로 고유벡터와 고유값의 수학적 정의입니다:

> **고유벡터 ($v$): $A$를 곱해도 방향이 전혀 바뀌지 않는 불변의 축**  
> **고유값 ($\lambda$): 그 축을 따라 벡터가 늘어나는 배율**  
> $$A v = \lambda v$$

[source,python]
----
for i in range(2):
    v = eigvecs[:, i]
    lam = eigvals[i]
    print(f"v{i}: A@v와 lam*v가 일치하는가?", np.allclose(A @ v, lam * v))
----

[source]
----
v0: A@v와 lam*v가 일치하는가? True
v1: A@v와 lam*v가 일치하는가? True
----

== 왜 공학에서 이것이 결정적인가

행렬 $A$가 복잡하게 얽힌 시스템(예: 스프링으로 묶인 여러 질량, 회로망의 루프들)을 나타낼 때, 고유벡터가 가리키는 방향은 **"이 방향으로 움직이면 다른 변수들과 전혀 간섭하지 않고 독립적으로 움직이는 마법의 주축(Principal Axis)"**을 뜻합니다.

아무리 복잡하고 어지러운 움직임이라도, 고유벡터 좌표계로 안경을 바꾸어 끼고 바라보면 **서로 완전히 무관한 단순한 1차원 운동들의 합**으로 완벽히 분해됩니다.

[NOTE]
====
**대칭행렬(Symmetric Matrix)의 엄청난 축복**  
$A = A^T$인 대칭행렬은 공학에서 가장 흔히 마주치는 행렬(질량-강성 행렬, 공분산 행렬)입니다. 대칭행렬은 언제나 **1) 모든 고유값이 100% 실수이며, 2) 서로 다른 고유벡터들이 완벽하게 직교(Orthogonal, 90도 수직)**한다는 기적 같은 성질을 갖습니다.
====

== 직접 해보기

고유값들의 **합**은 행렬의 대각합(`trace`)과 같고, 고유값들의 **곱**은 행렬식(`det`)과 같다는 중요한 항등식을 검증해 보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
print("trace(A):", np.trace(A), " sum(eigvals):", np.sum(eigvals))
print("det(A):", np.linalg.det(A), " prod(eigvals):", np.prod(eigvals))
----

[source]
----
trace(A): 5.0  sum(eigvals): 5.0
det(A): 5.000000000000001  prod(eigvals): 5.0
----

대각선 원소의 합 `3+2=5`가 고유값 합과 일치하고, 행렬식 `3*2 - 1*1 = 5`가 고유값 곱과 정확히 일치합니다.
====
