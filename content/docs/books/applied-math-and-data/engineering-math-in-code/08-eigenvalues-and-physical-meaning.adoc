'''

3부에서는 여러 미지수가 얽힌 연립방정식을 행렬로 묶어 한 번에 푸는 법(`Ax=b`)을 다뤘습니다. 이 장부터 시작하는 4부는 조금 다른 질문을 던집니다 — 그 얽힌 시스템이 **시간에 따라 움직일 때**, 뒤섞인 것처럼 보이는 그 움직임을 서로 안 얽히는 독립적인 조각들로 쪼갤 수는 없을까요? 그 핵심 도구가 **고유값(eigenvalue)** 과 **고유벡터(eigenvector)** 입니다.

== 행렬을 곱하면 보통 방향이 꺾인다

행렬 `A`를 벡터 `v`에 곱하는 건 기하학적으로 "`v`를 회전시키고 늘이거나 줄이는" 변환입니다. 어떤 대칭행렬 하나를 예로 들어봅니다.

[source,python]
----
import numpy as np

A = np.array([[3.0, 1.0],
              [1.0, 2.0]])

w = np.array([1.0, 1.0])
Aw = A @ w
print("w =", w)
print("A@w =", Aw)

def angle_between(u, v):
    cos_theta = np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))
    return np.degrees(np.arccos(np.clip(cos_theta, -1, 1)))

print("angle between w and A@w (deg):", angle_between(w, Aw))
----

[source]
----
w = [1. 1.]
A@w = [4. 3.]
angle between w and A@w (deg): 8.130102354156005
----

`w=[1,1]`을 `A`에 곱했더니 `[4,3]`이 나왔고, 원래 방향에서 `8.13도` 꺾였습니다 — `A`를 곱하는 게 단순히 "늘이기"가 아니라 "방향도 바꾸는" 변환이라는 뜻입니다.

== 딱 두 방향만은 꺾이지 않는다

그런데 모든 벡터가 이렇게 꺾이는 건 아닙니다. `A`마다 **꺾이지 않는 특별한 방향**이 (보통 2×2 행렬이면 두 개) 존재합니다. `numpy.linalg.eigh`(대칭행렬 전용, 고유값이 항상 실수임을 보장)로 이 방향들을 구해봅니다.

[source,python]
----
eigvals, eigvecs = np.linalg.eigh(A)
print("eigenvalues:", eigvals)
print("eigenvectors (columns):\n", eigvecs)

for i in range(2):
    v = eigvecs[:, i]
    Av = A @ v
    ang = angle_between(v, Av)
    print(f"angle between eigenvector {i} and A@eigenvector{i} (deg):", ang)
----

[source]
----
eigenvalues: [1.38196601 3.61803399]
eigenvectors (columns):
 [[ 0.52573111 -0.85065081]
 [-0.85065081 -0.52573111]]
angle between eigenvector 0 and A@eigenvector0 (deg): 0.0
angle between eigenvector 1 and A@eigenvector1 (deg): 0.0
----

각도가 정확히 `0.0도`입니다 — 임의로 고른 `w=[1,1]`은 `8.13도` 꺾였는데, `eigh`가 찾아준 이 두 방향은 `A`를 곱해도 **전혀 안 꺾입니다.** 이게 고유벡터의 정의 그 자체입니다 — "$A$를 곱해도 방향이 안 바뀌는 벡터". 그 방향을 따라 얼마나 늘어나는지(또는 줄어드는지)를 나타내는 배율이 고유값입니다.

[stem]
++++
Av = \lambda v
++++

방금 확인한 사실이 정확히 이 식입니다 — `A`를 `v`(고유벡터)에 곱한 결과가, 그냥 `v`를 `λ`(고유값)배 한 것과 같습니다.

[source,python]
----
for i in range(2):
    v = eigvecs[:, i]
    lam = eigvals[i]
    Av = A @ v
    print("A@v      =", Av)
    print("lambda*v =", lam*v)
    print("match:", np.allclose(Av, lam*v))
----

[source]
----
A@v      = [ 0.72654253 -1.1755705 ]
lambda*v = [ 0.72654253 -1.1755705 ]
match: True
A@v      = [-3.07768354 -1.90211303]
lambda*v = [-3.07768354 -1.90211303]
match: True
----

두 고유벡터 모두 `A@v`와 `λ*v`가 정확히 같습니다.

== 왜 공학에서 이게 중요한가

행렬 `A`가 "여러 변수가 서로 어떻게 영향을 주는가"를 나타낸다면(예: 스프링 두 개로 연결된 두 질량이 서로를 당기는 정도), 고유벡터가 가리키는 방향은 **"이 방향으로만 움직이면 서로 얽히지 않고 독립적으로 움직인다"는 특별한 방향**입니다. 임의의 초기 움직임은 복잡하게 뒤섞여 보이지만, 그 움직임을 고유벡터 방향의 성분으로 나눠보면 각 성분은 마치 서로 무관한 것처럼 독립적으로 거동합니다. 다음 장에서 이걸 실제 연성 진동 문제로 확인합니다 — 지금은 "행렬을 곱해도 안 꺾이는 특별한 방향이 있고, 그 방향에서는 문제가 훨씬 단순해진다"는 그림만 기억하면 됩니다.

== 직접 해보기

* 고유값들은 원래 행렬의 두 가지 간단한 값과 관계가 있습니다 — 고유값들의 **합**은 대각선 원소의 합(trace, 대각합)과 같고, 고유값들의 **곱**은 행렬식(determinant)과 같습니다. 이 장의 `A`로 직접 확인해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
print("trace(A):", np.trace(A), " sum(eigvals):", np.sum(eigvals))
print("det(A):", np.linalg.det(A), " prod(eigvals):", np.prod(eigvals))
----

[source]
----
trace(A): 5.0  sum(eigvals): 5.0
det(A): 5.000000000000001  prod(eigvals): 5.0
----

`trace(A) = 3+2 = 5`가 고유값의 합(`1.382+3.618=5`)과 정확히 같고, `det(A) = 3*2-1*1 = 5`가 고유값의 곱(`1.382 × 3.618 ≈ 5`)과 같습니다. 이건 우연이 아니라 항상 성립하는 항등식입니다 — 큰 행렬에서 고유값을 전부 계산하지 않고도, 대각합과 행렬식만으로 "고유값들이 대략 어떤 크기인지"에 대한 정보를 얻을 수 있는 이유입니다.
====

== 요약

* 행렬 `A`를 임의의 벡터에 곱하면 보통 방향이 꺾인다는 걸 각도로 직접 계산해 확인했습니다(`8.13도`).
* `A`를 곱해도 방향이 전혀 안 꺾이는(각도 `0도`) 특별한 방향이 존재하고, 그게 고유벡터라는 걸 확인했습니다 — `numpy.linalg.eigh`가 그 방향들과 각 방향의 배율(고유값)을 계산해줍니다.
* `Av = λv`라는 정의가 방금 확인한 "안 꺾이고 배율만 바뀐다"는 기하학적 사실을 그대로 적은 식이라는 걸, 특성방정식을 풀지 않고도 숫자로 확인했습니다.

다음 장에서는 이 고유벡터가 실제 물리 문제(스프링으로 연결된 두 질량계)에서 왜 "서로 안 얽히는 특별한 진동 방식"을 뜻하는지, 대각화라는 도구로 확인합니다.
