이 책은 1장부터 `dV/dt`처럼 생긴 기호를 씁니다. 미적분을 오래 안 썼다면 이 기호 자체가 이미 장벽일 수 있습니다 — 이 장은 본문 진도를 나가지 않고, 딱 이 기호 하나가 무슨 뜻인지만 아주 천천히 짚습니다.

== "평균 속도"부터 시작하기

자동차나 로봇이 직선 도로를 달립니다. 출발 후 `t`초 뒤의 위치를 `x(t) = 5t²`(미터)라고 합시다 — 이건 그냥 "시간이 지날수록 점점 더 빨리 멀어지는" 어떤 움직임을 나타내는 식일 뿐입니다.

`t=2초`일 때와 `t=3초`일 때 사이의 **평균 속도**는 누구나 계산할 수 있습니다 — "이동한 거리 ÷ 걸린 시간"입니다.

....
                   [ 평균 속도: 두 점을 잇는 할선의 기울기 ]

     위치 x(t)
        ▲                                    • (t = 3s, x = 45m)
        │                                   /
        │                                  /
        │                                 / ◄── 할선의 기울기 = 25 m/s
        │                                /      (평균 속도)
        │                 • (t = 2s, x = 20m)
        │                /│
        │               / │  Δx = 45 - 20 = 25m
        │              /  │
        └─────────────┴───┴────────────────────────► 시간 t
                     t=2 t=3
                       Δt = 1s
....

[source,python]
----
def x(t):
    return 5 * t**2   # 위치(m), t(초)

t0 = 2.0
dt = 1.0  # t0와 t0+dt 사이를 봄
avg_v = (x(t0 + dt) - x(t0)) / dt
print(f"t={t0}s 부터 t={t0+dt}s 까지 평균 속도: {avg_v} m/s")
----

[source]
----
t=2.0s 부터 t=3.0s 까지 평균 속도: 25.0 m/s
----

== "지금 이 순간의 속도"는 다른 질문이다

그런데 "`t=2초`인 바로 그 순간의 속도는?"이라고 물으면 이야기가 달라집니다 — 속도는 원래 "거리 나누기 시간"인데, 어떤 한 순간은 시간이 흐르지 않으니(`0`으로 나누기가 안 되니) 이 정의를 그대로 쓸 수가 없습니다.

해결책은 간단합니다 — 시간 간격(`dt`)을 점점 더 짧게 잡아가면서, 평균 속도가 어떤 값에 다가가는지(수렴하는지) 지켜보는 겁니다.

....
                   [ 시간 간격 dt를 줄일 때의 수렴 과정 ]

     dt = 1.0s   ──►  평균 속도 = 25.0 m/s     (아직 거친 측정)
     dt = 0.1s   ──►  평균 속도 = 20.5 m/s
     dt = 0.01s  ──►  평균 속도 = 20.05 m/s
     dt = 0.001s ──►  평균 속도 = 20.005 m/s
                             │
                             ▼
     dt ──► 0    ──►  【 순간 속도 = 정확히 20.0 m/s (접선의 기울기!) 】
....

[source,python]
----
t0 = 2.0
for dt in [1.0, 0.1, 0.01, 0.001]:
    avg_v = (x(t0 + dt) - x(t0)) / dt
    print(f"dt={dt:<6} 평균 속도 = {avg_v} m/s")
----

[source]
----
dt=1.0    평균 속도 = 25.0 m/s
dt=0.1    평균 속도 = 20.500000000000007 m/s
dt=0.01   평균 속도 = 20.049999999999457 m/s
dt=0.001  평균 속도 = 20.004999999997608 m/s
----

`dt`를 줄일수록 평균 속도가 **20에 점점 가까워집니다.** `dt`가 정확히 `0`이 되는 순간은 계산할 수 없지만(`0`으로 나누기), `dt`를 한없이 작게 만들면 결과가 어떤 값에 다가가는지는 분명히 보입니다 — 이 "다가가는 값"이 바로 `t=2초`에서의 **순간 속도**입니다.

== `dx/dt`는 바로 이 "다가가는 값"의 이름이다

수학에서는 "`dt`를 한없이 `0`에 가깝게 줄였을 때 평균 속도가 다가가는 값"을 매번 이렇게 길게 쓰는 대신, 짧은 기호 하나로 부릅니다.

[stem]
++++
\frac{dx}{dt} = \lim_{\Delta t \to 0} \frac{x(t+\Delta t) - x(t)}{\Delta t}
++++

읽는 법은 **"x를 t로 미분한 것"**, 뜻은 방금 우리가 숫자로 확인한 바로 그것 — **"x가 t에 대해 지금 이 순간 얼마나 빨리 변하고 있는가"** 입니다.

[NOTE]
====
**`dx`와 `dt`는 분수처럼 나눌 수 있는 일반 숫자인가요?**  
그렇지 않습니다 `dx`와 `dt`가 각각 독립적인 숫자가 아니라, `dx/dt`라는 표기 전체가 **"그 극한값 하나"를 가리키는 약속된 이름**입니다. $0/0$으로 나누는 것이 아니라, "시간 간격을 0으로 한없이 좁혀갈 때 기울기가 도달하는 목적지"를 가리킵니다.
====

이 예제는 실제로 손으로 미분해도(`x(t)=5t²`의 도함수는 `x'(t)=10t`) 검산됩니다.

[source,python]
----
print("dx/dt = 10t, t=2에서:", 10 * 2.0, "m/s")
----

[source]
----
dx/dt = 10t, t=2에서: 20.0 m/s
----

`dt`를 줄여가며 숫자로 좁혀 들어간 값(`20.00499...` → `20`에 수렴)과 정확히 일치합니다. **"미분한다"는 건 결국 이 수렴값을 구하는 일**이고, 손으로 하는 미분 공식(`x^n`의 도함수는 `nx^{n-1}`같은)은 이 극한 계산을 매번 반복하지 않고 한 번에 답을 주는 지름길일 뿐입니다.

== 이 책에서 `dV/dt`, `dx/dt` 같은 기호를 볼 때마다

이 책의 1장은 `dV/dt = -V/RC`(축전기의 전압이 줄어드는 속도)로 시작합니다. 이 장에서 확인한 걸 그대로 옮기면 — **"지금 전압이 `V`일 때, 아주 짧은 순간 뒤에 전압이 얼마나 빨리 바뀌고 있는가"**라는 뜻입니다.

앞으로 이 책에서 `d(무언가)/d(다른 무언가)`라는 기호를 볼 때마다, "그 무언가가, 다른 무언가에 대해 지금 이 순간 얼마나 빨리 변하는가"로 소리 내어 바꿔 읽어보면 됩니다 — 그게 이 기호가 뜻하는 전부입니다.

== 직접 해보기

`x(t) = t³`(세제곱)에 대해 `t=2`에서의 순간 속도를 같은 방법(`dt`를 줄여가며 평균 속도 계산)으로 추정해보고, 손으로 미분한 값(`x'(t)=3t²`)과 비교해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def x2(t):
    return t**3

t0 = 2.0
for dt in [1.0, 0.1, 0.01, 0.001]:
    avg_v = (x2(t0 + dt) - x2(t0)) / dt
    print(f"dt={dt:<6} 평균 속도 = {avg_v}")

print("3t^2, t=2에서:", 3 * t0**2)
----

[source]
----
dt=1.0    평균 속도 = 19.0
dt=0.1    평균 속도 = 12.61000000000001
dt=0.01   평균 속도 = 12.060099999999707
dt=0.001  평균 속도 = 12.006000999997823
3t^2, t=2에서: 12.0
----

`dt`를 줄일수록 `12`에 다가가고, 공식(`3t²`, `t=2`에서 `12`)과 정확히 일치합니다 — 함수가 `t²`이든 `t³`이든, "평균 변화율의 극한을 구한다"는 미분의 정의 자체는 똑같이 적용됩니다.
