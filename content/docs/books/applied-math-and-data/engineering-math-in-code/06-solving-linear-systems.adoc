3부가 시작됩니다.

1~2부는 미지수가 하나뿐인 문제만 다뤘습니다. 이 장부터는 **여러 미지수가 복잡하게 서로 얽혀 있는 시스템**을 행렬이라는 강력한 도구로 체계적으로 푸는 법을 배웁니다.

== 세 개의 루프가 얽힌 복합 회로망

다음과 같이 저항을 서로 공유하는 3-루프 회로망을 생각해 봅시다.

....
                   [ 3-루프 회로망의 전류 얽힘 구조 ]

        ┌──── 2Ω ────┬──── 3Ω ────┬──── 2Ω ────┐
        │            │            │            │
      + ┴ -        [1Ω]         [1Ω]         + ┴ -
      (10V)      (공유 저항)   (공유 저항)     (5V)
        │    i1 ──►  │    i2 ──►  │    i3 ──►  │
        └────────────┴────────────┴────────────┘
         【 루프 1 】   【 루프 2 】   【 루프 3 】
....

키르히호프 전압 법칙을 세 루프에 적용하면 다음 3원 1차 연립방정식이 나옵니다:

[stem]
++++
\begin{aligned}
2i_1 - i_2 &= 10 \\
-i_1 + 3i_2 - i_3 &= 0 \\
-i_2 + 2i_3 &= 5
\end{aligned}
++++

어느 방정식도 혼자서는 풀 수 없습니다.

== 행렬 방정식 $Ax = b$로 압축하기

이 연립방정식은 행렬 $A$와 미지수 벡터 $x$, 그리고 우변 벡터 $b$의 곱으로 한 줄로 묶입니다:

....
                   [ 행렬 방정식 Ax = b 로의 변환 ]

       가중치 행렬 A (3 × 3)        미지수 x (3)      목표값 b (3)
       ┌────────────────────┐       ┌──────┐          ┌──────┐
       │  2.0, -1.0,  0.0   │   ×   │  i1  │    =     │ 10.0 │ (루프 1)
       │ -1.0,  3.0, -1.0   │       │  i2  │          │  0.0 │ (루프 2)
       │  0.0, -1.0,  2.0   │       │  i3  │          │  5.0 │ (루프 3)
       └────────────────────┘       └──────┘          └──────┘
....

0-3장에서 배웠듯, $A$의 1행 `[2, -1, 0]`과 $x$의 내적은 정확히 $2i_1 - i_2$가 되어 첫째 방정식과 일치합니다.

== 가우스 소거법 (Gaussian Elimination)의 2단계 알고리즘

컴퓨터가 이 연립방정식을 푸는 가장 고전적이고 체계적인 방법은 **가우스 소거법**입니다.

....
                   [ 가우스 소거법의 2단계 흐름 ]

   【 1단계: 전진 소거 (Forward Elimination) 】
   • 대각선 아래의 숫자들을 위 식을 이용해 차례로 0으로 지운다!
     ┌──────────────┐          ┌──────────────┐
     │  2, -1,  0   │          │  2, -1,  0   │
     │ -1,  3, -1   │  ──►     │  0, 2.5, -1  │  ◄── 【 상삼각 행렬 (Upper Triangular) 】
     │  0, -1,  2   │          │  0,  0, 1.6  │
     └──────────────┘          └──────────────┘
                                      │
                                      ▼
   【 2단계: 후진 대입 (Back Substitution) 】
   • 맨 마지막 식(1.6 * i3 = 7.0)에서 i3를 즉시 계산!
   • 구한 i3를 윗줄에 대입해 i2 계산 ──► i1까지 연쇄적으로 거슬러 올라가며 풀기!
....

이 알고리즘을 파이썬 코드로 그대로 작성해 봅시다.

[source,python]
----
import numpy as np

A = np.array([[2., -1., 0.],
              [-1., 3., -1.],
              [0., -1., 2.]])
b = np.array([10., 0., 5.])

def gaussian_elimination(A, b):
    A = A.copy().astype(float)
    b = b.copy().astype(float)
    n = len(b)
    # 1단계: 전진 소거
    for k in range(n-1):
        for i in range(k+1, n):
            factor = A[i,k] / A[k,k]
            A[i,k:] -= factor * A[k,k:]
            b[i] -= factor * b[k]
    # 2단계: 후진 대입
    x = np.zeros(n)
    for i in range(n-1, -1, -1):
        x[i] = (b[i] - A[i,i+1:] @ x[i+1:]) / A[i,i]
    return x

x_hand = gaussian_elimination(A, b)
print("직접 구현한 가우스 소거법 해:", x_hand)
----

[source]
----
직접 구현한 가우스 소거법 해: [6.875 3.75  4.375]
----

== 라이브러리 함수와 비교하고 검산하기

[source,python]
----
x_np = np.linalg.solve(A, b)
print("np.linalg.solve:", x_np)
print("max diff:", np.max(np.abs(x_hand-x_np)))

print("A@x - b 검산 (0이어야 함):", A @ x_hand - b)
----

[source]
----
np.linalg.solve: [6.875 3.75  4.375]
max diff: 0.0
A@x - b 검산 (0이어야 함): [0. 0. 0.]
----

직접 구현한 가우스 소거법과 NumPy의 `solve`가 100% 동일한 답을 냈으며, 원래 방정식에 대입한 잔차($A@x - b$)가 정확히 `[0, 0, 0]`이 됩니다

[NOTE]
====
**역행렬 $A^{-1}$을 구해서 $x = A^{-1}b$로 풀면 안 되나요?**  
수학 책에서는 $x = A^{-1}b$라고 쓰지만, **컴퓨터 과학에서는 역행렬을 직접 구해서 곱하는 행위를 절대 하지 않습니다!**  
역행렬을 계산하는 것은 연산량이 훨씬 많고($O(n^3)$의 3배 이상), 부동소수점 오차가 크게 누적되기 때문입니다. 실무 라이브러리(`np.linalg.solve`)는 내부적으로 항상 가우스 소거법 기반의 **LU 분해(LU Decomposition)**를 사용합니다.
====

[TIP]
====
**확인 질문**: 가우스 소거법 과정에서 만약 어떤 대각선 원소 $A[k,k]$가 우연히 $0$이 되면 `factor = A[i,k]/A[k,k]`에서 $0$으로 나누는 에러가 발생합니다. 실제 라이브러리는 이를 어떻게 해결할까요? (0이 아닌 가장 큰 숫자를 가진 아랫줄과 자리를 바꾸는 **부분 피벗팅(Partial Pivoting)**을 수행합니다)
====
