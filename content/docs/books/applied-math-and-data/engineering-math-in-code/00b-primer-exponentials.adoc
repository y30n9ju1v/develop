이 책의 1장은 `V(t) = V_0 e^{-t/RC}`라는 답을 씁니다. `e`라는 숫자(약 `2.71828...`)가 왜 하필 여기서 나오는지 낯설다면, 이 장에서 그 이유를 짚습니다.

== 복리 이자에서 자연스럽게 나오는 숫자

연이율 100%짜리 예금이 있다고 합시다(비현실적인 숫자지만 계산을 간단하게 하려는 것뿐입니다). 1년에 한 번만 이자를 준다면, 원금 1은 1년 뒤 `(1+1)¹ = 2`가 됩니다.

이자를 1년에 두 번(반년마다 50%씩) 나눠 준다면 어떻게 될까요 — `(1 + 1/2)² = 2.25`로 더 늘어납니다. 나눠주는 횟수(`n`)를 계속 늘리면 어떻게 될까요.

[source,python]
----
for n in [1, 10, 100, 1000, 100000, 10000000]:
    val = (1 + 1/n)**n
    print(f"n={n:<10} (1+1/n)^n = {val}")
----

[source]
----
n=1          (1+1/n)^n = 2.0
n=10         (1+1/n)^n = 2.5937424601000023
n=100        (1+1/n)^n = 2.7048138294215285
n=1000       (1+1/n)^n = 2.7169239322355936
n=100000     (1+1/n)^n = 2.7182682371922975
n=10000000   (1+1/n)^n = 2.7182816941320818
----

이자를 무한히 잘게 쪼개서(연속적으로) 준다는 극한을 취하면, 이 값은 **`2.718281828...`** 이라는 특정 숫자에 수렴합니다 — 이게 **자연상수 `e`** 입니다. `π`(원의 둘레와 지름의 비)처럼, `e`도 "정의 자체가 이렇게 생긴" 숫자입니다 — "연속적으로 커지는 양"을 다루면 자연스럽게 튀어나오는 상수라서 이런 이름이 붙었습니다.

== `e^x`가 특별한 이유: 자기 자신을 미분해도 자기 자신이다

0-1장에서 미분(도함수)이 "그 지점에서의 순간 기울기"라는 걸 확인했습니다. `f(x) = e^x`의 기울기를 같은 방법(작은 `h`로 평균 기울기 근사)으로 재보면 놀라운 걸 발견합니다.

[source,python]
----
import numpy as np

def f(x):
    return np.exp(x)  # e^x

x0 = 1.5
for h in [0.1, 0.01, 0.001, 0.0001]:
    slope = (f(x0 + h) - f(x0)) / h
    print(f"h={h:<8} 기울기 근사 = {slope}")

print("f(1.5) =", f(x0))
----

[source]
----
h=0.1      기울기 근사 = 4.713433540570504
h=0.01     기울기 근사 = 4.5041723976187775
h=0.001    기울기 근사 = 4.483930662008362
h=0.0001   기울기 근사 = 4.481913162264206
f(1.5) = 4.4816890703380645
----

`h`를 줄일수록 기울기가 `4.4818...`에 다가가는데, 이건 `f(1.5) = e^{1.5} = 4.4817...`, 즉 **그 지점의 함숫값과 똑같습니다.** 우연이 아닙니다 — `e^x`는 **"어느 지점에서든 그 자리의 높이가 곧 그 자리의 기울기인"** 유일한(상수배를 빼면) 함수입니다. 이게 미적분에서 `e^x`가 특별 취급받는 이유입니다 — 미분해도 형태가 안 바뀌니, 미분방정식(변화율과 값 자체를 연결하는 방정식)의 답으로 계속 등장합니다.

== 이게 왜 RC 회로 방전식에 나타나는가

1장의 방정식 `dV/dt = -V/RC`를 말로 풀면 — "전압이 줄어드는 속도가, 지금 전압 자체에 비례한다"입니다. 방금 확인했듯 `e^x`는 "기울기가 자기 자신에 비례하는" 함수의 원형입니다 — 정확히는 `e^{kx}`의 도함수가 `k \cdot e^{kx}`(자기 자신의 `k`배)이므로, "변화율이 자기 자신에 비례한다"는 방정식의 답은 거의 항상 `e^{(\text{어떤 상수}) \times t}` 꼴로 나옵니다. 1장의 `V(t) = V_0 e^{-t/RC}`도 이 패턴의 한 사례입니다 — `k = -1/RC`인 경우입니다.

[source,python]
----
def V(t, V0=5.0, RC=1.0):
    return V0 * np.exp(-t / RC)

for h in [0.1, 0.01, 0.001]:
    t0 = 1.0
    slope = (V(t0 + h) - V(t0)) / h
    print(f"h={h:<6} dV/dt 근사 = {slope},  -V(t0)/RC = {-V(t0)/1.0}")
----

[source]
----
h=0.1    dV/dt 근사 = -1.7504178736681397,  -V(t0)/RC = -1.8393972058572117
h=0.01   dV/dt 근사 = -1.830230799959498,   -V(t0)/RC = -1.8393972058572117
h=0.001  dV/dt 근사 = -1.8384778137436886,  -V(t0)/RC = -1.8393972058572117
----

`h`가 작아질수록 `dV/dt` 근사값이 `-V(t0)/RC`(`-1.8394`)에 다가갑니다 — `V(t)=V_0 e^{-t/RC}`가 정말로 `dV/dt = -V/RC`를 만족한다는 걸, 공식을 외우지 않고 눈으로 확인한 겁니다.

== 직접 해보기

`k=2`인 경우(`f(x) = e^{2x}`)의 기울기를 `x=1`에서 수치적으로 근사해보고, 예측값(`2 \cdot e^{2x}`, 자기 자신의 2배)과 비교해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def g(x):
    return np.exp(2*x)

x0 = 1.0
for h in [0.1, 0.01, 0.001]:
    slope = (g(x0+h) - g(x0)) / h
    print(f"h={h:<6} 기울기 근사 = {slope}")

print("예측값 2*e^(2*1):", 2 * np.exp(2*x0))
----

[source]
----
h=0.1    기울기 근사 = 16.359574005034716
h=0.01   기울기 근사 = 14.926883473127184
h=0.001  기울기 근사 = 14.79290016705992
예측값 2*e^(2*1): 14.7781121978613
----

`h`가 작아질수록 예측값(자기 자신의 2배)에 다가갑니다 — `k`가 몇이든, `e^{kx}`를 미분하면 항상 "자기 자신의 `k`배"가 된다는 패턴이 그대로 성립합니다. 이 책 2장부터는 이 패턴(`e^{kt}` 꼴의 해)을 계속 다시 만나게 됩니다.
