== 1. Gradient ($\nabla f$): 어느 방향으로 가장 빨리 커지는가

스칼라장 $f(x,y,z)$가 주어졌을 때, gradient는 **"그 점에서 함숫값이 가장 가파르게 증가하는 방향과 그 경사도"**를 가리키는 벡터입니다:

[stem]
++++
\nabla f = \left( \frac{\partial f}{\partial x},\ \frac{\partial f}{\partial y},\ \frac{\partial f}{\partial z} \right)
++++

중심차분(Central Difference)으로 수치 미분을 계산해 봅시다:

[source,python]
----
import numpy as np

def f(x, y, z):
    return x**2*y + y*z**2

def grad_f_analytical(x, y, z):
    return np.array([2*x*y, x**2 + z**2, 2*y*z])

def grad_f_numeric(x, y, z, h=1e-6):
    dfdx = (f(x+h,y,z) - f(x-h,y,z)) / (2*h)
    dfdy = (f(x,y+h,z) - f(x,y-h,z)) / (2*h)
    dfdz = (f(x,y,z+h) - f(x,y,z-h)) / (2*h)
    return np.array([dfdx, dfdy, dfdz])

p = (1.0, 2.0, 3.0)
print("gradient 수치계산:", grad_f_numeric(*p))
print("gradient 해석적 참값:", grad_f_analytical(*p))
----

[source]
----
gradient 수치계산:    [ 4. 10. 12.]
gradient 해석적 참값: [ 4. 10. 12.]
----

== 2. Divergence ($\nabla \cdot F$): 이 점에서 얼마나 뿜어져 나오는가

벡터장 $F = (F_x, F_y, F_z)$가 주어졌을 때, divergence는 **"이 점을 둘러싼 작은 미소 상자에서 유체가 순수하게 밖으로 분출되는가(발산, 원천) 아니면 빨려 들어가는가(흡입구)"**를 나타내는 스칼라입니다:

[stem]
++++
\nabla \cdot F = \frac{\partial F_x}{\partial x} + \frac{\partial F_y}{\partial y} + \frac{\partial F_z}{\partial z}
++++

[source,python]
----
def F(x,y,z):
    return np.array([x*y, y*z, z*x])

def divergence_numeric(F, x, y, z, h=1e-6):
    dFxdx = (F(x+h,y,z)[0]-F(x-h,y,z)[0])/(2*h)
    dFydy = (F(x,y+h,z)[1]-F(x,y-h,z)[1])/(2*h)
    dFzdz = (F(x,y,z+h)[2]-F(x,y,z-h)[2])/(2*h)
    return dFxdx + dFydy + dFzdz

div_num = divergence_numeric(F, *p)
div_ana = p[1] + p[2] + p[0]   # y + z + x = 2 + 3 + 1 = 6
print("divergence 수치계산:", div_num, " 해석적 참값:", div_ana)
----

[source]
----
divergence 수치계산: 6.000000000061512  해석적 참값: 6.0
----

== 3. Curl ($\nabla \times F$): 이 점 주변이 얼마나 회전하는가

curl은 **"이 점에 가상의 미소 바람개비를 놓았을 때, 유체의 소용돌이에 의해 바람개비가 어느 회전축으로 얼마나 세게 회전하는가"**를 나타내는 벡터입니다:

[stem]
++++
\nabla \times F = \left( \frac{\partial F_z}{\partial y} - \frac{\partial F_y}{\partial z},\ \frac{\partial F_x}{\partial z} - \frac{\partial F_z}{\partial x},\ \frac{\partial F_y}{\partial x} - \frac{\partial F_x}{\partial y} \right)
++++

[source,python]
----
def curl_numeric(F, x, y, z, h=1e-6):
    dFzdy = (F(x,y+h,z)[2]-F(x,y-h,z)[2])/(2*h)
    dFydz = (F(x,y,z+h)[1]-F(x,y-z)[1]) if False else (F(x,y,z+h)[1]-F(x,y,z-h)[1])/(2*h)
    dFxdz = (F(x,y,z+h)[0]-F(x,y,z-h)[0])/(2*h)
    dFzdx = (F(x+h,y,z)[2]-F(x-h,y,z)[2])/(2*h)
    dFydx = (F(x+h,y,z)[1]-F(x-h,y,z)[1])/(2*h)
    dFxdy = (F(x,y+h,z)[0]-F(x,y-h,z)[0])/(2*h)
    return np.array([dFzdy-dFydz, dFxdz-dFzdx, dFydx-dFxdy])

curl_num = curl_numeric(F, *p)
curl_ana = np.array([-p[1], -p[2], -p[0]])  # [-2, -3, -1]
print("curl 수치계산:", curl_num, " 해석적 참값:", curl_ana)
----

[source]
----
curl 수치계산: [-2. -3. -1.]  해석적 참값: [-2. -3. -1.]
----

[NOTE]
====
**기호 $\nabla$(나블라)의 정체**  
$\nabla = \left( \frac{\partial}{\partial x}, \frac{\partial}{\partial y}, \frac{\partial}{\partial z} \right)$라는 가상의 벡터 미분 연산자입니다.  
* 스칼라 $f$에 그냥 곱하면 $\to$ **Gradient ($\nabla f$)**
* 벡터 $F$와 내적($\cdot$)하면 $\to$ **Divergence ($\nabla \cdot F$)**
* 벡터 $F$와 외적($\times$)하면 $\to$ **Curl ($\nabla \times F$)**
====

== 직접 해보기: 항등식 $\text{div}(\text{curl } F) = 0$ 검증

어떤 벡터장의 회전(curl)을 구한 뒤 그 divergence를 취하면, 항상 수학적으로 $0$이 된다는 유명한 항등식을 코드로 검증해 보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def curl_F_wrap(x, y, z):
    return curl_numeric(F, x, y, z, h=1e-4)

for pt in [(1,2,3), (0.5,-1,2)]:
    d = divergence_numeric(curl_F_wrap, *pt, h=1e-3)
    print("point", pt, "div(curl F):", d)
----

[source]
----
point (1, 2, 3) div(curl F): 0.0
point (0.5, -1, 2) div(curl F): 0.0
----

회전 운동 자체는 그 어떤 새로운 원천도 만들어내지 않으므로 항상 divergence가 0입니다.
====

====
