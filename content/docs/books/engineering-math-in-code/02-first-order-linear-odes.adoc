'''

1장의 RC 회로는 그냥 방전만 했습니다 — 외부에서 아무것도 안 넣어주는 **동차(homogeneous)** 방정식이었습니다. 이 장에서는 배터리 같은 외부 전압원 `Vs`를 연결해서 축전기를 충전시키는, 더 현실적인 **비동차(non-homogeneous)** 방정식을 다룹니다.

== 비동차 ODE: 오른쪽에 외부 입력이 있다

[stem]
++++
\frac{dV}{dt} + \frac{V}{RC} = \frac{V_s}{RC}
++++

전압 `V`가 목표값 `Vs`에서 얼마나 떨어져 있는지에 비례해서 그 차이를 줄이는 방향으로 변합니다 — `V`가 `Vs`보다 작으면 올라가고, `V`가 `Vs`에 도달하면 변화가 멈춥니다.

== 적분 인자법으로 손으로 풀기

이런 형태(`dy/dt + p(t) y = q(t)`, 여기서는 `p(t) = 1/RC`로 상수, `q(t) = Vs/RC`도 상수)의 1계 선형 ODE는 **적분 인자(integrating factor)** 라는 표준 기법으로 풀립니다. 일반적으로 적분 인자는 $\mu(t) = e^{\int p(t)\,dt}$로 정의됩니다 — 여기서는 $p(t)=1/RC$가 상수이므로 $\mu(t) = e^{t/RC}$입니다.

**1단계 — 양변에 적분 인자를 곱한다.**

[stem]
++++
e^{t/RC}\frac{dV}{dt} + \frac{1}{RC}e^{t/RC} V = \frac{V_s}{RC} e^{t/RC}
++++

**2단계 — 왼쪽이 곱의 미분 공식(product rule)을 거꾸로 적용한 모양임을 알아챈다.** $\frac{d}{dt}(uv) = u'v + uv'$에서 $u=V$, $v=e^{t/RC}$라 하면 $v' = \frac{1}{RC}e^{t/RC}$이므로, 왼쪽 전체가 정확히 $\frac{d}{dt}(V \cdot e^{t/RC})$입니다. 적분 인자를 이 특정 형태로 고른 이유가 바로 이겁니다 — 왼쪽을 항상 하나의 도함수로 뭉칠 수 있게 만들어줍니다.

[stem]
++++
\frac{d}{dt}\left( V \cdot e^{t/RC} \right) = \frac{V_s}{RC} e^{t/RC}
++++

**3단계 — 양변을 그냥 적분한다.** 오른쪽은 상수 배의 지수함수라 적분이 쉽습니다.

[stem]
++++
V \cdot e^{t/RC} = V_s\, e^{t/RC} + K
++++

(`K`는 적분 상수입니다.)

**4단계 — 양변을 $e^{t/RC}$로 나누고, 초기조건으로 `K`를 결정한다.**

[stem]
++++
V(t) = V_s + K e^{-t/RC}
++++

`t=0`일 때 `V=V0`이어야 하므로 `V0 = Vs + K`, 즉 `K = V0 - Vs`입니다. 이걸 대입하면 최종 해석해가 나옵니다.

[stem]
++++
V(t) = V_s + (V_0 - V_s)\, e^{-t/RC}
++++

이 식이 말하는 바는 직관적입니다 — 시간이 충분히 지나면($t \to \infty$) 지수항이 사라지고 `V`는 `Vs`로 수렴합니다.

== 수치해와 대조하기

[source,python]
----
import numpy as np
from scipy.integrate import solve_ivp

R, C = 1000.0, 1e-3
tau = R * C
Vs = 9.0   # 전원 전압
V0 = 0.0   # 축전기는 비어 있는 상태로 시작

def f(t, V):
    return (Vs - V) / tau

sol = solve_ivp(f, [0, 5], [V0], t_eval=[0,1,2,3,4,5], rtol=1e-10, atol=1e-12)
analytical = Vs + (V0 - Vs) * np.exp(-np.array([0,1,2,3,4,5]) / tau)

print("numeric:   ", sol.y[0])
print("analytical:", analytical)
print("max err:", np.max(np.abs(sol.y[0]-analytical)))
----

[source]
----
numeric:    [0.         5.68908503 7.78198245 8.55191638 8.83515925 8.93935848]
analytical: [0.         5.68908503 7.78198245 8.55191638 8.83515925 8.93935848]
max err: 1.7118395589932334e-10
----

소수점 10자리까지 일치합니다 — 적분 인자법으로 손으로 유도한 해석해와, `solve_ivp`가 미분방정식만 보고 계산한 수치해가 서로 다른 방법으로 같은 답에 도달했다는 게, 유도가 맞았다는 강한 증거입니다.

== 정상 상태로 수렴하는지 확인하기

해석해가 예측한 대로, 시간이 충분히 지나면 전압이 전원 전압에 도달하는지 확인해봅니다.

[source,python]
----
sol_long = solve_ivp(f, [0, 20], [V0], t_eval=[20], rtol=1e-10, atol=1e-12)
print("V(20s) ~ Vs?:", sol_long.y[0][0], "vs", Vs)
----

[source]
----
V(20s) ~ Vs?: 8.999999981379121 vs 9.0
----

`RC = 1초`인 회로에서 20초(시정수의 20배)가 지나면 전압이 전원 전압의 99.9999% 이상까지 도달합니다 — "정상 상태(steady state)"라는 추상적인 개념이, 그냥 "충분히 오래 기다리면 도달하는 숫자"라는 걸 계산으로 확인했습니다.

== 직접 해보기

* 이번엔 전원이 일정한 `Vs`가 아니라 교류(`Vs(t) = Vs0 sin(ωt)`)라면 어떻게 될까요 — `dV/dt + V/τ = (Vs0/τ)sin(ωt)`, `V(0)=0`을 적분 인자법(또는 SymPy의 `dsolve`)으로 풀고, `solve_ivp`의 수치해와 비교해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
import sympy as sp

t, tau_s, Vs0_s, w_s = sp.symbols('t tau Vs0 w', positive=True)
V = sp.Function('V')
ode = sp.Eq(V(t).diff(t) + V(t)/tau_s, (Vs0_s/tau_s)*sp.sin(w_s*t))
sol = sp.dsolve(ode, V(t), ics={V(0): 0})
print(sol)
----

[source]
----
Eq(V(t), -Vs0*tau*w*cos(t*w)/(tau**2*w**2 + 1) + Vs0*tau*w*exp(-t/tau)/(tau**2*w**2 + 1) + Vs0*sin(t*w)/(tau**2*w**2 + 1))
----

손으로 이 적분(부분적분을 두 번 해야 합니다)까지 하는 대신 SymPy의 `dsolve`에 맡겼습니다 — 원리는 지금까지와 똑같이 적분 인자법이고, SymPy가 그 대수를 대신해줄 뿐입니다. 숫자를 넣고 `solve_ivp`와 비교하면:

[source,python]
----
import numpy as np
from scipy.integrate import solve_ivp

tau, Vs0, w = 1.0, 5.0, 2.0
Vt = sol.rhs.subs({tau_s: tau, Vs0_s: Vs0, w_s: w})
Vt_func = sp.lambdify(t, Vt, 'numpy')
t_eval = np.array([0,1,2,3,4,5])
analytical_vals = Vt_func(t_eval)

def f(tt, y):
    return [(Vs0*np.sin(w*tt) - y[0])/tau]
numsol = solve_ivp(f, [0,5], [0.0], t_eval=t_eval, rtol=1e-12, atol=1e-14)
print("analytical:", analytical_vals)
print("numeric:   ", numsol.y[0])
print("max diff:", np.max(np.abs(numsol.y[0]-analytical_vals)))
----

[source]
----
analytical: [ 0.          2.47734998  0.82115531 -2.10018193  1.31698959  1.14759784]
numeric:    [ 0.          2.47734998  0.82115531 -2.10018193  1.31698959  1.14759784]

----

값이 이번엔 `Vs`로 단조롭게 수렴하는 대신 양수와 음수를 오갑니다 — 전원 자체가 진동하니 축전기 전압도 그걸 따라 진동하며 반응합니다. 그래도 적분 인자법으로 유도한 해석해와 `solve_ivp`의 수치해가 소수점 11자리까지 일치한다는 건 이 장의 방법이 상수 전원뿐 아니라 시간에 따라 변하는 입력에도 그대로 통한다는 걸 보여줍니다.
====

== 요약

* 외부 입력이 있는 비동차 1계 선형 ODE(`dV/dt + V/RC = Vs/RC`)를 적분 인자법으로 손으로 풀어 `V(t) = Vs + (V0-Vs)e^{-t/RC}`라는 해석해를 얻었습니다.
* 이 해석해와 `solve_ivp`의 수치해가 소수점 10자리까지 일치한다는 걸 실제로 계산해 확인했습니다 — 서로 다른 방법이 같은 답에 도달한 것이 유도가 맞았다는 근거입니다.
* 시간이 충분히 지나면 전압이 전원 전압(정상 상태)에 수렴한다는 것도 실제 숫자로 확인했습니다.

다음 장에서는 1계에서 2계로 넘어갑니다 — 질량-스프링-댐퍼 시스템의 감쇠 진동을 다루면서, 계수에 따라 완전히 다른 세 가지 거동(과감쇠, 임계감쇠, 부족감쇠)이 나온다는 걸 특성방정식과 시뮬레이션으로 함께 확인합니다.
