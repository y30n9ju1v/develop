== 미분방정식은 "변화율의 규칙"을 적은 것

RC 회로(저항 `R`과 축전기 `C`가 직렬로 연결된 회로) 하나를 생각해봅시다. 축전기에 전압 `V0`를 충전해두고 스위치를 열어 방전시키면, 전압은 시간에 따라 줄어듭니다.

`dV/dt` 같은 표기가 아직 낯설다면, 0-1장에서 "순간 변화율"이라는 뜻 하나만 먼저 확인하고 와도 좋습니다 — 이 장은 그 표기를 실제 회로 문제에 바로 적용해봅니다.

이 식이 왜 그렇게 생겼는지, 딱 두 가지 기본 법칙에서 유도해봅니다.

* **옴의 법칙**: 저항을 흐르는 전류는 `I = V/R`입니다(전압이 클수록 전류도 크다).
* **축전기의 전류-전압 관계**: 축전기가 방전되면서 잃는 전하량의 속도가 전류이고, 전하량은 `Q=CV`이므로 `I = -dQ/dt = -C\,dV/dt`입니다(마이너스 부호는 "방전 중이라 전하가 줄어든다"는 뜻입니다).

방전 회로에서는 저항을 흐르는 전류와 축전기가 내보내는 전류가 같은 전류(회로가 하나로 이어져 있으므로)이니, 두 식을 그냥 같다고 놓습니다.

[stem]
++++
\frac{V}{R} = -C\frac{dV}{dt} \quad\Rightarrow\quad \frac{dV}{dt} = -\frac{V}{RC}
++++

전압이 줄어드는 **속도**가 지금 전압이 얼마나 남았는지에 비례한다는 걸(전압이 높을수록 더 빨리 빠지고, 낮아질수록 천천히 빠진다는 걸) 두 기본 법칙에서 그대로 얻었습니다.

이 식은 "$V$가 얼마인지"를 직접 말해주지 않습니다 — 대신 "$V$가 지금 얼마나 빨리 변하는지($dV/dt$)가, 지금 $V$가 얼마인지에 어떻게 의존하는가"를 말해줍니다. 이게 **상미분방정식(ordinary differential equation, ODE)** 입니다 — 미지의 함수(여기선 $V(t)$)와 그 도함수 사이의 관계를 적은 방정식입니다. "지금 상태를 알면 다음 순간에 어떻게 변할지 안다"는 게 물리 법칙 대부분이 실제로 말하는 형태이기 때문에, 공학 전반(회로, 역학, 열전달, 화학 반응 속도)에서 이 언어로 문제가 등장합니다.

== 컴퓨터에게는 이게 훨씬 쉬운 질문이다

"$V(t)$가 정확히 무슨 함수인가"는 사람에게는 풀어야 할 퍼즐이지만, 컴퓨터에게는 다른 질문으로 바꿀 수 있습니다 — "지금 이 순간의 값과 변화율을 알면, 아주 조금 뒤의 값을 근사할 수 있지 않을까?" 이게 가장 단순한 수치적 ODE 풀이법인 **오일러 방법(Euler's method)** 의 전부입니다.

[stem]
++++
V(t + \Delta t) \approx V(t) + \Delta t \cdot \frac{dV}{dt}\Big|_{t}
++++

[source,python]
----
import numpy as np

R, C = 1000.0, 1e-3   # 1kΩ, 1mF -> RC = 1초
tau = R * C
V0 = 5.0

def f(t, V):
    return -V / tau

def euler(f, t0, y0, dt, n):
    t, y = t0, y0
    ts, ys = [t], [y]
    for _ in range(n):
        y = y + dt * f(t, y)
        t = t + dt
        ts.append(t); ys.append(y)
    return np.array(ts), np.array(ys)

dt = 0.01
ts, ys = euler(f, 0.0, V0, dt, 300)
----

`f(t, V)`가 정확히 위 미분방정식의 오른쪽(변화율)이고, `euler`는 "지금 값 + 스텝 크기 × 변화율"을 반복해서 적용하는 것뿐입니다 — 수식의 $\Delta t \cdot \frac{dV}{dt}$가 코드에서는 `dt * f(t, y)` 한 줄입니다.

== 해석해와 비교하기

이 특정 ODE는 사실 손으로도 풀립니다 — $V(t) = V_0 e^{-t/RC}$가 정답이라는 걸 미분해보면 확인할 수 있습니다($\frac{d}{dt}(V_0 e^{-t/\tau}) = -\frac{V_0}{\tau} e^{-t/\tau} = -\frac{V}{\tau}$, 정확히 원래 방정식과 같습니다). "왜 하필 `e`가 나오는가"는 0-2장에서 이미 짚었습니다 — "변화율이 자기 자신에 비례하는" 방정식의 답은 거의 항상 이 `e^{(\text{상수}) \times t}` 꼴로 나옵니다. 오일러 방법으로 근사한 값과 이 **해석해(analytical solution)** 를 나란히 놓아봅니다.

[source,python]
----
analytical = V0 * np.exp(-ts / tau)
max_err = np.max(np.abs(ys - analytical))
print("t=1s  euler:", ys[100], " analytical:", analytical[100])
print("t=2s  euler:", ys[200], " analytical:", analytical[200])
print("t=3s  euler:", ys[300], " analytical:", analytical[300])
print("max abs error over [0,3]:", max_err)
----

[source]
----

t=2s  euler: 0.6698983742898095  analytical: 0.6766764161830625
t=3s  euler: 0.24520447035642925  analytical: 0.2489353418393247

----

거의 맞지만 완전히 같지는 않습니다 — 오일러 방법은 "한 순간의 기울기로 다음 구간 전체를 직선처럼 근사"하는 방법이라, 곡선이 휘어 있으면 오차가 쌓입니다.

== 스텝을 줄이면 오차도 준다

스텝 크기 `dt`를 10분의 1로 줄이면 어떻게 될까요.

[source,python]
----
ts2, ys2 = euler(f, 0.0, V0, 0.001, 3000)
analytical2 = V0 * np.exp(-ts2 / tau)
print("dt=0.001 max abs error:", np.max(np.abs(ys2 - analytical2)))
----

[source]
----
dt=0.001 max abs error: 0.0009200820023922418
----

`dt`를 10분의 1로 줄이니 오차도 거의 정확히 10분의 1(`0.0092` → `0.00092`)이 됐습니다 — 오일러 방법은 스텝 크기에 **선형으로 비례하는** 오차를 갖는 "1차(first-order)" 방법이라는 사실이, 유도 없이 숫자로 바로 확인됩니다.

== 실전에서는 `scipy.integrate.solve_ivp`를 쓴다

오일러 방법은 원리를 이해하기엔 좋지만, 실무에서 미분방정식을 풀 땐 훨씬 정교한 방법(오차가 스텝 크기의 4~5제곱에 비례하는 Runge-Kutta 계열)을 쓴 라이브러리 함수를 씁니다. 이 책에서 `solve_ivp`를 부를 때마다 등장하는 `rtol`, `atol`이라는 두 인자도 미리 짚어둡니다 — `solve_ivp`는 스텝 크기를 고정하는 대신(오일러 방법처럼) **매 스텝마다 오차를 추정해서 스텝 크기를 자동으로 조절**합니다. `rtol`(relative tolerance, 상대 오차 허용치)과 `atol`(absolute tolerance, 절대 오차 허용치)이 "이 정도 오차까지는 허용한다"는 기준이고, 이 값을 작게 잡을수록(`1e-10`처럼) 솔버가 스텝을 더 잘게 쪼개서 더 정확한 답을 내놓습니다 — 이 책은 손으로 유도한 해석해와 소수점 여러 자리까지 맞춰보는 게 목적이므로, 거의 항상 아주 작은 값(`rtol=1e-10, atol=1e-12` 근처)을 씁니다.

[source,python]
----
from scipy.integrate import solve_ivp

sol = solve_ivp(f, [0, 3], [V0], t_eval=[0, 1, 2, 3], rtol=1e-10, atol=1e-12)
analytical = V0 * np.exp(-np.array([0, 1, 2, 3]) / tau)
print("solve_ivp (tight tol):", sol.y[0])
print("analytical:           ", analytical)
print("max err:", np.max(np.abs(sol.y[0] - analytical)))
----

[source]
----
solve_ivp (tight tol): [5.         1.83939721 0.67667642 0.24893534]
analytical:            [5.         1.83939721 0.67667642 0.24893534]
max err: 1.9918067195590083e-11
----

오차가 `1.99e-11`까지 떨어집니다 — 오일러 방법의 `0.0092`와는 자릿수가 8개 넘게 차이 납니다. 이 책의 나머지 장에서는 `solve_ivp`를 기본 도구로 쓰되, 원리를 처음 보일 때는 이번 장처럼 오일러 방법을 손으로 짜서 "왜 되는지"를 먼저 확인합니다.

== 직접 해보기

* 오일러 방법보다 한 단계 나은 방법인 **RK2(2차 룽게-쿠타, 중점법)** 를 구현해보세요 — 한 스텝에서 기울기를 한 번(시작점)이 아니라 두 번(시작점과 오일러로 예측한 끝점) 구해서 평균 냅니다: `k1=f(t,y)`, `k2=f(t+dt, y+dt*k1)`, `y_{n+1}=y_n+dt*(k1+k2)/2`. 오일러 방법과 똑같이 스텝을 10분의 1로 줄여보고, 오차가 몇 분의 1로 줄어드는지 확인해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
def rk2(f, t0, y0, dt, n):
    t, y = t0, y0
    ts, ys = [t], [y]
    for _ in range(n):
        k1 = f(t, y)
        k2 = f(t+dt, y+dt*k1)
        y = y + dt*0.5*(k1+k2)
        t = t+dt
        ts.append(t); ys.append(y)
    return np.array(ts), np.array(ys)

ts, ys = rk2(f, 0.0, V0, 0.01, 300)
analytical = V0*np.exp(-ts/tau)
print("RK2 dt=0.01 max err:", np.max(np.abs(ys-analytical)))

ts2, ys2 = rk2(f, 0.0, V0, 0.001, 3000)
analytical2 = V0*np.exp(-ts2/tau)
print("RK2 dt=0.001 max err:", np.max(np.abs(ys2-analytical2)))
----

[source]
----
RK2 dt=0.01 max err: 3.088772374892912e-05
RK2 dt=0.001 max err: 3.0679624751783763e-07
----

스텝을 10분의 1로 줄였더니 오차가 10분의 1이 아니라 **100분의 1**(`3.09e-5 → 3.07e-7`)로 줄었습니다 — 오일러 방법은 오차가 스텝 크기에 비례(1차)했지만, RK2는 오차가 스텝 크기의 **제곱**에 비례(2차)합니다. 기울기를 한 번이 아니라 두 번(양 끝에서) 구해서 평균 내는 것만으로 수렴 속도가 이렇게 달라진다는 게, `scipy.integrate.solve_ivp`가 기본으로 훨씬 더 정교한 방법(4~5차 룽게-쿠타)을 쓰는 이유입니다.
====

== 요약

* 미분방정식은 "지금 상태에서 다음 순간이 어떻게 변하는가"라는 규칙을 적은 것이고, RC 회로 방전이 가장 단순한 실제 예입니다.
* 오일러 방법(`y_{n+1} = y_n + \Delta t \cdot f(t_n, y_n)`)으로 수치적으로 풀고, 손으로 유도한 해석해(`V_0 e^{-t/RC}`)와 비교해 거의 맞지만 오차가 있다는 걸 확인했습니다.
* 스텝을 10분의 1로 줄이면 오차도 거의 10분의 1로 준다는 걸 실제로 계산해서, 오일러 방법이 1차 수렴한다는 걸 유도 없이 확인했습니다.
* `scipy.integrate.solve_ivp`가 훨씬 정교한 방법으로 오차를 8자릿수 넘게 줄인다는 것도 확인했습니다 — 이 책 나머지 장의 기본 도구입니다.
