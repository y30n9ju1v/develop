'''

이 책 3부(고유값)와 6~7부(푸리에·복소해석)에서는 답에 `i`(또는 공학에서 흔히 쓰는 `j`)가 섞인 숫자가 자연스럽게 등장합니다. "허수"라는 이름 때문에 뭔가 신비롭거나 실재하지 않는 것처럼 느껴지기 쉬운데, 이 장에서는 그냥 "왜 이런 숫자가 필요해지는지"부터 계산으로 확인합니다.

== 실수만으로는 못 푸는 방정식을 만나보기

이차방정식 `x² + 2x + 5 = 0`을 근의 공식으로 풀어봅니다.

[stem]
++++
x = \frac{-b \pm \sqrt{b^2-4ac}}{2a} = \frac{-2 \pm \sqrt{4-20}}{2} = \frac{-2 \pm \sqrt{-16}}{2}
++++

`√-16`이 문제입니다 — 어떤 실수를 제곱해도 음수가 나올 수 없으므로(양수든 음수든 제곱하면 항상 `0` 이상), **이 방정식은 실수 범위 안에 답이 없습니다.**

[source,python]
----
import numpy as np

a, b, c = 1, 2, 5
disc = b**2 - 4*a*c
print("판별식(루트 안의 값):", disc)
----

[source]
----
판별식(루트 안의 값): -16
----

여기서 수학자들이 택한 방법은 "이 방정식은 답이 없다"고 포기하는 대신, **"제곱하면 `-1`이 되는 새로운 숫자를 하나 만들어서 셈의 규칙을 확장하자"** 는 것이었습니다. 그 새 숫자를 `i`라고 부릅니다(`i² = -1`). 이렇게 확장하면 `√-16 = √16 × √-1 = 4i`가 되어, 방정식이 답을 갖습니다.

== 복소수는 그냥 "숫자 두 개의 짝"이다

`i`를 도입하면, 이제 모든 수를 `a + bi`(`a`, `b`는 보통의 실수) 꼴로 쓸 수 있습니다 — 이걸 **복소수**라고 부릅니다. 신비로운 게 아니라, **실수 두 개(`a`와 `b`)를 정해진 규칙으로 묶은 것**뿐입니다 — 마치 0-3장의 벡터가 "숫자 여러 개를 묶은 것"이었듯, 복소수는 "숫자 두 개를 정해진 셈 규칙과 함께 묶은 것"입니다.

파이썬은 복소수를 기본으로 지원합니다(`j`를 허수 단위로 씁니다 — 공학 표기 관례입니다, `i`는 전류를 가리키는 데 이미 쓰이기 때문입니다).

[source,python]
----
z1 = 3 + 4j
z2 = 1 - 2j

print("덧셈:", z1 + z2)
print("곱셈:", z1 * z2)
----

[source]
----
덧셈: (4+2j)
곱셈: (11-2j)
----

덧셈은 그냥 "실수부끼리, 허수부끼리 더하기"입니다(`3+1=4`, `4+(-2)=2`). 곱셈은 `i²=-1`이라는 규칙을 기억하고 다항식처럼 전개하면 됩니다 — `(3+4i)(1-2i) = 3 - 6i + 4i - 8i^2 = 3 - 2i + 8 = 11 - 2i` (파이썬 결과와 일치합니다).

== 방정식을 다시 풀어보기

`i`라는 도구가 생겼으니, 아까 "답이 없던" 방정식을 다시 풉니다.

[source,python]
----
root1 = (-b + np.sqrt(complex(disc))) / (2*a)
root2 = (-b - np.sqrt(complex(disc))) / (2*a)
print("근:", root1, root2)

def f(x):
    return a*x**2 + b*x + c
print("검산 f(root1):", f(root1))
----

[source]
----
근: (-1+2j) (-1-2j)
검산 f(root1): 0j
----

`x = -1+2j`를 원래 방정식에 다시 넣으면 정확히 `0`이 나옵니다(검산 성공) — 복소수는 "실수 범위에서 안 풀리던 방정식도 항상 풀리게 해주는" 확장이라는 게 이렇게 실제 계산으로 확인됩니다.

== 크기(절댓값)와 두 부분 읽는 법

복소수 `z = a+bi`에서 `a`를 **실수부**(`z.real`), `b`를 **허수부**(`z.imag`)라고 부릅니다. 복소수의 "크기"(원점에서 이 점까지의 거리, 피타고라스 정리로 계산)는 `abs()`로 구합니다.

[source,python]
----
z = 3 + 4j
print("실수부:", z.real, " 허수부:", z.imag)
print("크기:", abs(z))
----

[source]
----
실수부: 3.0  허수부: 4.0
크기: 5.0
----

`3² + 4² = 25 = 5²`이므로 크기가 `5`인 게 3-4-5 직각삼각형과 정확히 같은 계산입니다 — 복소수를 "실수부를 가로축, 허수부를 세로축으로 하는 평면 위의 점"으로 그리면, 크기는 그냥 그 점까지의 직선거리입니다.

== 이 책에서 복소수를 볼 때마다

이 책의 3부(고유값)에서는 진동하는 시스템의 고유값이 복소수로 나올 때 "진동하면서 동시에 커지거나 작아진다"는 뜻이라는 걸 다룹니다. 6~7부(푸리에·복소해석)에서는 `e^{i\theta}`(복소수 지수함수)가 회전을 나타낸다는 걸 씁니다. 지금 이 장에서 확인한 것 — **복소수는 실수 두 개를 짝지어 정해진 규칙(`i²=-1`)으로 셈하는 숫자 체계이고, 실수만으로 안 풀리던 문제를 풀리게 해준다** — 만 기억해두면, 뒤에서 복소수가 등장할 때마다 "왜 갑자기 이게 나오지"라는 당혹감 없이 "아, 실수 범위를 벗어난 답이 필요한 상황이구나"로 받아들일 수 있습니다.

== 직접 해보기

`x² - 6x + 25 = 0`을 판별식부터 계산해서 복소수 범위에서 풀고, 검산까지 해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
a, b, c = 1, -6, 25
disc = b**2 - 4*a*c
print("판별식:", disc)

root1 = (-b + np.sqrt(complex(disc))) / (2*a)
root2 = (-b - np.sqrt(complex(disc))) / (2*a)
print("근:", root1, root2)

def f(x):
    return a*x**2 + b*x + c
print("검산:", f(root1), f(root2))
----

[source]
----
판별식: -64
근: (3+4j) (3-4j)
검산: 0j 0j
----

판별식이 `-64`로 여전히 음수라 복소수 근이 나오고, 두 근(`3+4i`와 `3-4i`)이 서로 부호만 반대인 허수부를 가진(켤레 복소수) 짝으로 나왔습니다 — 실수 계수 방정식의 복소수 근은 항상 이렇게 켤레 쌍으로 나온다는 패턴도 여기서 미리 볼 수 있습니다. 검산 결과도 정확히 `0`이 나와서, 이 두 근이 원래 방정식을 정확히 만족한다는 걸 확인했습니다.
