'''

지금까지는 유한 개의 미지수(전압 하나, 위치 하나, 질량 두 개의 변위)만 다뤘습니다. 4부에서는 **공간 전체에 퍼져 있는 양**을 다룹니다 — 방 안 모든 점마다 온도가 다르거나(스칼라장), 파이프 안 모든 점마다 유속과 방향이 다른(벡터장) 경우입니다. 이 장에서는 이런 장(field)을 다루는 세 가지 기본 연산자 — gradient, divergence, curl — 을 각각 유한차분으로 직접 계산해서 확인합니다.

== Gradient: 어느 방향으로 가장 빨리 커지는가

스칼라장 `f(x,y,z)`가 있을 때, gradient $\nabla f$는 "그 점에서 함숫값이 가장 빨리 증가하는 방향과 그 증가율"을 가리키는 벡터입니다 — 각 좌표에 대한 편미분을 모은 것입니다.

[stem]
++++
\nabla f = \left( \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z} \right)
++++

[source,python]
----
import numpy as np

def f(x, y, z):
    return x**2*y + y*z**2

def grad_f_analytical(x, y, z):
    return np.array([2*x*y, x**2 + z**2, 2*y*z])

def grad_f_numeric(x, y, z, h=1e-6):
    dfdx = (f(x+h,y,z) - f(x-h,y,z)) / (2*h)
    dfdy = (f(x,y+h,z) - f(x,y-h,z)) / (2*h)
    dfdz = (f(x,y,z+h) - f(x,y,z-h)) / (2*h)
    return np.array([dfdx, dfdy, dfdz])

p = (1.0, 2.0, 3.0)
print("gradient numeric:   ", grad_f_numeric(*p))
print("gradient analytical:", grad_f_analytical(*p))
----

[source]
----
gradient numeric:    [ 4. 10. 12.]
gradient analytical: [ 4. 10. 12.]
----

`grad_f_numeric`는 미분의 정의(`(f(x+h)-f(x-h))/(2h)`, 중심차분)를 그대로 코드로 옮긴 것뿐인데, 손으로 편미분해서 얻은 `grad_f_analytical`과 소수점 여러 자리까지 일치합니다 — 편미분 세 개를 각각 계산해서 묶은 것이 gradient라는 걸 코드로 직접 확인했습니다.

== Divergence: 이 점에서 얼마나 뿜어져 나오는가

벡터장 `F(x,y,z) = (Fx, Fy, Fz)`가 있을 때, divergence $\nabla \cdot F$는 "이 점 주변의 아주 작은 상자에서, 얼마나 순수하게 밖으로 흘러나가는가"를 나타내는 **스칼라**입니다.

[stem]
++++
\nabla \cdot F = \frac{\partial F_x}{\partial x} + \frac{\partial F_y}{\partial y} + \frac{\partial F_z}{\partial z}
++++

[source,python]
----
def F(x,y,z):
    return np.array([x*y, y*z, z*x])

def divergence_numeric(F, x, y, z, h=1e-6):
    dFxdx = (F(x+h,y,z)[0]-F(x-h,y,z)[0])/(2*h)
    dFydy = (F(x,y+h,z)[1]-F(x,y-h,z)[1])/(2*h)
    dFzdz = (F(x,y,z+h)[2]-F(x,y,z-h)[2])/(2*h)
    return dFxdx+dFydy+dFzdz

div_num = divergence_numeric(F, *p)
div_ana = p[1]+p[2]+p[0]  # d(xy)/dx + d(yz)/dy + d(zx)/dz = y + z + x
print("divergence numeric:", div_num, " analytical:", div_ana)
----

[source]
----
divergence numeric: 6.000000000061512  analytical: 6.0
----

각 성분을 "자기 방향으로만" 미분해서 더한 것뿐인데(`Fx`를 `x`로, `Fy`를 `y`로, `Fz`를 `z`로), 이게 "이 점에서 얼마나 뿜어져 나오는가"라는 물리적 의미를 갖습니다 — 다음 장에서 이 의미를 유체 흐름으로 직접 확인합니다.

== Curl: 이 점 주변이 얼마나 회전하는가

curl $\nabla \times F$는 "이 점 주변에 작은 바람개비를 놓으면 얼마나 세게, 어느 축으로 돌아가는가"를 나타내는 **벡터**입니다.

[stem]
++++
\nabla \times F = \left( \frac{\partial F_z}{\partial y} - \frac{\partial F_y}{\partial z},\ \frac{\partial F_x}{\partial z} - \frac{\partial F_z}{\partial x},\ \frac{\partial F_y}{\partial x} - \frac{\partial F_x}{\partial y} \right)
++++

[source,python]
----
def curl_numeric(F, x, y, z, h=1e-6):
    dFzdy = (F(x,y+h,z)[2]-F(x,y-h,z)[2])/(2*h)
    dFydz = (F(x,y,z+h)[1]-F(x,y,z-h)[1])/(2*h)
    dFxdz = (F(x,y,z+h)[0]-F(x,y,z-h)[0])/(2*h)
    dFzdx = (F(x+h,y,z)[2]-F(x-h,y,z)[2])/(2*h)
    dFydx = (F(x+h,y,z)[1]-F(x-h,y,z)[1])/(2*h)
    dFxdy = (F(x,y+h,z)[0]-F(x,y-h,z)[0])/(2*h)
    return np.array([dFzdy-dFydz, dFxdz-dFzdx, dFydx-dFxdy])

curl_num = curl_numeric(F, *p)
curl_ana = np.array([-p[1], -p[2], -p[0]])  # 손으로 유도: (0-y, 0-z, 0-x)
print("curl numeric:", curl_num, " analytical:", curl_ana)
----

[source]
----
curl numeric: [-2. -3. -1.]  analytical: [-2. -3. -1.]
----

식이 훨씬 복잡해 보이지만 하는 일은 단순합니다 — "$F_z$가 $y$ 방향으로 변하는 정도"와 "$F_y$가 $z$ 방향으로 변하는 정도"의 **차이**를 계산합니다. 두 방향의 변화율이 다르면, 그 불균형이 바람개비를 돌리는 힘이 됩니다.

== 세 연산자, 세 가지 다른 질문

세 연산자를 나란히 놓으면 각자 답하는 질문이 다르다는 게 분명해집니다.

* **gradient**: 스칼라장에 적용, 벡터를 돌려준다 — "어느 방향이 가장 가파른가?"
* **divergence**: 벡터장에 적용, 스칼라를 돌려준다 — "여기서 얼마나 뿜어져 나오는가?"
* **curl**: 벡터장에 적용, 벡터를 돌려준다 — "여기서 얼마나, 어느 축으로 회전하는가?"

세 연산자 모두 편미분을 특정한 방식으로 조합한 것뿐이고, 유한차분(`(f(x+h)-f(x-h))/(2h)`)으로 그 조합을 그대로 계산하면 손으로 유도한 해석적 결과와 일치한다는 걸 이번 장에서 확인했습니다.

== 요약

* gradient를 유한차분으로 계산해 스칼라장이 가장 빨리 증가하는 방향과 손으로 유도한 해석적 gradient가 일치한다는 걸 확인했습니다.
* divergence와 curl도 각각 유한차분으로 계산해 손으로 유도한 값과 일치한다는 걸 확인하면서, 두 연산자가 벡터장을 다른 방식으로 조합한 편미분이라는 걸 코드로 직접 봤습니다.
* 세 연산자가 "가장 가파른 방향", "얼마나 뿜어져 나오는가", "얼마나 회전하는가"라는 서로 다른 물리적 질문에 답한다는 걸 정리했습니다.

다음 장에서는 이 세 연산자를 실제 물리 문제(비압축성 유체 흐름, 정전기장)에 적용해서, divergence가 0이라는 것과 curl이 0이라는 것이 각각 무슨 물리적 의미인지 시뮬레이션으로 확인합니다.
