공업수학 표준 커리큘럼(상미분방정식, 라플라스 변환, 선형대수, 벡터 미적분, 푸리에 해석과 편미분방정식)을 정의-정리-증명 순서 대신 "왜 필요한가 → NumPy/SciPy/SymPy로 계산해서 눈으로 확인 → 그다음에 수식을 읽는다"는 순서로 다시 짓는 독립적인 입문서입니다. 상미분방정식(1부) → 라플라스 변환(2부) → 선형대수(3부) → 벡터 미적분(4부) → 푸리에 해석과 편미분방정식(5부) 순서로 쌓아 올립니다.

이 책의 모든 계산은 실제로 Python(NumPy/SciPy/SymPy)으로 실행해서 검증했습니다 — 손으로 유도한 해석해와 독립적인 수치해(또는 서로 다른 방법으로 유도한 해)를 매 장마다 나란히 놓고 비교하며, 그 차이가 실제로 얼마나 작은지 숫자로 직접 확인합니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
