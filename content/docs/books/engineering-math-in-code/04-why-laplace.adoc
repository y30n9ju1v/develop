'''

1부에서는 미분방정식을 직접 풀었습니다(적분 인자법, 특성방정식). 이 장에서는 미분방정식을 **아예 안 풀어도 되게** 만드는 도구를 소개합니다 — 라플라스 변환입니다.

== 핵심 아이디어: 미분을 곱셈으로 바꾼다

라플라스 변환은 시간 `t`의 함수 `f(t)`를 새로운 변수 `s`의 함수 `F(s)`로 바꾸는 변환입니다.

[stem]
++++
F(s) = \mathcal{L}\{f(t)\} = \int_0^\infty f(t) e^{-st}\, dt
++++

이 적분 자체보다 훨씬 중요한 건 **미분에 대응하는 성질**입니다.

[stem]
++++
\mathcal{L}\{f'(t)\} = sF(s) - f(0)
++++

"시간 영역에서 미분한다"는 연산이, "라플라스 영역에서는 `s`를 곱하고 초기값을 뺀다"는 **곱셈과 뺄셈**으로 바뀝니다. 이게 왜 결정적인지 봅시다 — 미분방정식의 양변에 라플라스 변환을 걸면, 미분이 전부 `s`의 곱셈으로 바뀌면서 **미분방정식 전체가 `F(s)`에 대한 대수 방정식**이 됩니다. 대수 방정식은 (미적분 없이) $F(s)$에 대해 그냥 풀면 되고, 마지막에 역변환으로 시간 영역으로 되돌아오면 답이 나옵니다.

== 2장의 RC 회로를 라플라스로 다시 풀기

2장에서 적분 인자법으로 풀었던 그 방정식을 이번엔 라플라스 변환으로 풀어서, 같은 답이 나오는지 확인합니다.

[stem]
++++
\frac{dV}{dt} + \frac{V}{\tau} = \frac{V_s}{\tau}, \quad V(0) = V_0
++++

양변에 라플라스 변환을 걸면(왼쪽은 미분의 성질을, 오른쪽은 상수의 변환 $\mathcal{L}\{c\} = c/s$를 씁니다), 미분방정식이 $X(s)$(대문자로 쓴 $V(t)$의 변환)에 대한 대수 방정식이 됩니다.

[stem]
++++
sX(s) - V_0 + \frac{X(s)}{\tau} = \frac{V_s}{\tau s}
++++

이걸 SymPy(기호 계산 라이브러리)로 그대로 풀어봅니다 — 손으로 인수분해하는 대신 컴퓨터에게 대수를 맡기는 것도 라플라스 변환의 실용적인 장점입니다.

[source,python]
----
import sympy as sp

t, s = sp.symbols('t s', positive=True, real=True)
tau, Vs, V0 = sp.symbols('tau Vs V0', positive=True)
Xs = sp.symbols('Xs')

# sX - V0 + X/tau = Vs/(tau*s)
eq = sp.Eq(s*Xs - V0 + Xs/tau, (Vs/tau)/s)
sol_Xs = sp.solve(eq, Xs)[0]
print("X(s) =", sp.simplify(sol_Xs))
----

[source]
----
X(s) = (V0*s*tau + Vs)/(s*(s*tau + 1))
----

미분방정식이 아니라 그냥 분수식입니다 — 미적분이 전혀 없습니다.

== 역변환으로 시간 영역으로 되돌아오기

[source,python]
----
v_t = sp.inverse_laplace_transform(sol_Xs, s, t)
v_t = sp.simplify(v_t)
print("v(t) =", v_t)

# 2장에서 손으로 유도한 해석해와 비교
known = V0*sp.exp(-t/tau) + Vs*(1-sp.exp(-t/tau))
diff = sp.simplify(v_t - known)
print("difference (should be 0):", diff)
----

[source]
----
v(t) = (V0 + Vs*exp(t/tau) - Vs)*exp(-t/tau)
difference (should be 0): 0
----

SymPy가 라플라스 변환·대수·역변환만으로 구한 답과, 2장에서 적분 인자법으로 손으로 유도한 답의 **차이가 정확히 0**입니다 — 대수적으로 완전히 같은 식이라는 걸 컴퓨터가 확인해줍니다.

== 숫자로도 확인하기

[source,python]
----
numeric_expr = v_t.subs({tau: 1.0, Vs: 9.0, V0: 0.0})
for tv in [0,1,2,3,4,5]:
    print(f"t={tv}: {float(numeric_expr.subs(t, tv)):.8f}")
----

[source]
----
t=0: 0.00000000
t=1: 5.68908503
t=2: 7.78198245
t=3: 8.55191638
t=4: 8.83515925
t=5: 8.93935848
----

2장에서 `solve_ivp`와 적분 인자법으로 얻었던 바로 그 숫자들(`5.68908503`, `7.78198245`, ...)이 소수점 8자리까지 그대로 다시 나옵니다 — **세 가지 완전히 다른 방법**(수치적분, 적분 인자법, 라플라스 변환)이 같은 답에 도달했습니다. 하나의 방법만 썼다면 "계산 실수가 없었나"라는 의심이 남지만, 세 방법이 독립적으로 일치하면 그 답을 신뢰할 근거가 훨씬 단단해집니다.

== 요약

* 라플라스 변환의 핵심 성질($\mathcal{L}\{f'(t)\} = sF(s) - f(0)$)이 미분을 곱셈으로 바꿔서, 미분방정식을 대수 방정식으로 만든다는 걸 확인했습니다.
* 2장의 RC 충전 회로 방정식에 SymPy로 라플라스 변환을 실제로 적용해서, 대수적으로 $X(s)$를 구하고 역변환해 시간 영역의 해를 얻었습니다.
* 이렇게 얻은 해가 2장에서 적분 인자법으로 손으로 유도한 해와 기호적으로 완전히 같고(`sp.simplify`한 차이가 0), 숫자로도 소수점 8자리까지 일치한다는 걸 확인했습니다 — 세 가지 독립적인 방법(수치적분, 적분 인자법, 라플라스 변환)이 같은 답에 수렴했습니다.

다음 장에서는 라플라스 변환을 3장의 2계 시스템(RLC 회로, 스프링-댐퍼와 수학적으로 동일한 구조)에 적용해서, 왜 이 도구가 회로 설계 실무에서 특히 널리 쓰이는지 확인합니다.
