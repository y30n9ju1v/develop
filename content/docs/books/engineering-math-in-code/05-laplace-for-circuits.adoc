'''

4장은 1계 ODE에 라플라스 변환을 적용했습니다. 이 장에서는 2계로 넘어갑니다 — 저항(`R`)·인덕터(`L`)·축전기(`C`)가 직렬로 연결된 **RLC 회로**에 스텝 전압을 걸었을 때의 응답입니다. 이 회로는 3장의 질량-스프링-댐퍼와 **수학적으로 완전히 같은 구조**를 가집니다.

== RLC 회로 방정식과 3장의 대응 관계

키르히호프 전압 법칙으로 세운 방정식은 이렇습니다.

[stem]
++++
LC\,\ddot{V_c} + RC\,\dot{V_c} + V_c = V_s
++++

`Vc`는 축전기 양단 전압, `Vs`는 스텝으로 걸어준 전원 전압입니다. 3장의 `m ẍ + c ẋ + kx = 0`과 자리를 맞춰보면 대응이 그대로 보입니다 — `L ↔ m`(관성), `R ↔ c`(에너지를 소모하는 저항), `1/C ↔ k`(복원력을 만드는 항)입니다. 인덕터는 전류 변화를 거스르려 하니 질량의 관성과 같은 역할이고, 저항은 에너지를 열로 흩어버리니 댐퍼와 같은 역할입니다 — 서로 다른 물리 현상(역학, 전기)이 **똑같은 수학**을 공유한다는 게 공업수학이 "여러 분야에 두루 쓰인다"고 하는 이유의 실제 사례입니다.

== 초기조건이 0이면 라플라스 변환이 더 간단해진다

축전기가 완전히 비어 있고(`Vc(0)=0`) 전류도 없는 상태(`Vc'(0)=0`)에서 시작한다고 하면, 라플라스 변환의 미분 성질(`L{f'} = sF(s) - f(0)`, `L{f''} = s²F(s) - sf(0) - f'(0)`)에서 초기값을 빼는 항들이 전부 사라집니다 — 미분이 그냥 `s`를 곱하는 것과 똑같아집니다.

[source,python]
----
import sympy as sp

t, s = sp.symbols('t s', positive=True, real=True)
L, R, Cc, Vs = sp.symbols('L R Cc Vs', positive=True)
Xs = sp.symbols('Xs')

# L*C*Vc'' + R*C*Vc' + Vc = Vs,  Vc(0)=0, Vc'(0)=0 (초기값이 0이라 미분항이 그냥 s, s^2 곱셈이 됨)
eq = sp.Eq(L*Cc*s**2*Xs + R*Cc*s*Xs + Xs, Vs/s)
sol_Xs = sp.solve(eq, Xs)[0]
print("X(s) =", sp.simplify(sol_Xs))
----

[source]
----
X(s) = Vs/(s*(Cc*L*s**2 + Cc*R*s + 1))
----

정말로 순수한 대수식입니다 — 미분방정식을 한 번도 직접 다루지 않고 여기까지 왔습니다.

== 숫자를 넣고 역변환하기

3장의 부족감쇠 예제(`m=1, c=0.4, k=4`)와 정확히 같은 특성방정식이 나오도록 `L=1H, R=0.4Ω, C=0.25F`(`1/LC=4=k/m`, `R/L=0.4=c/m`)를 고르고, 스텝 전압 `Vs=9V`를 걸어봅니다.

[source,python]
----
vals = {L: 1.0, R: 0.4, Cc: 0.25, Vs: 9.0}
sol_Xs_num = sol_Xs.subs(vals)
vc_t = sp.inverse_laplace_transform(sol_Xs_num, s, t)
vc_t = sp.simplify(vc_t)
print("Vc(t) =", vc_t)

t_eval = [0, 0.5, 1.0, 1.5, 2.0, 3.0, 5.0]
laplace_vals = [float(vc_t.subs(t, tv)) for tv in t_eval]
print("laplace numeric values:", laplace_vals)
----

[source]
----
Vc(t) = (9.0*exp(0.2*t) - 0.904534033733291*sin(1.98997487421324*t) - 9.0*cos(1.98997487421324*t))*exp(-0.2*t)
laplace numeric values: [0.0, 3.879..., 11.322..., 15.481..., 13.484..., 4.454..., 12.031...]
----

값이 `9V`를 훌쩍 넘어(`t=1.5`에서 `15.5V`) 오버슈트했다가 다시 내려가는 게 보입니다 — 3장에서 확인했듯 이건 부족감쇠계의 전형적인 거동(목표를 지나쳐서 진동하며 수렴)입니다. 감쇠비가 작아서(`ζ=0.1`) 시간상수가 5초나 되므로, 5초가 지나도 아직 목표 전압 근처에서 진동하는 중입니다 — `t=10,20,30`으로 더 계산해보면 `8.29V → 9.07V → 9.02V`로 서서히 `9V`에 정착하는 것도 확인할 수 있습니다.

== `solve_ivp`로 교차 검증하기

[source,python]
----
import numpy as np
from scipy.integrate import solve_ivp

Lv, Rv, Cv, Vsv = 1.0, 0.4, 0.25, 9.0
def f(tt, y):
    vc, dvc = y
    d2vc = (Vsv - vc - Rv*Cv*dvc)/(Lv*Cv)
    return [dvc, d2vc]

sol = solve_ivp(f, [0,5], [0.0, 0.0], t_eval=t_eval, rtol=1e-12, atol=1e-14)
print("solve_ivp values:      ", sol.y[0])
print("max diff:", np.max(np.abs(sol.y[0]-np.array(laplace_vals))))
----

[source]
----
solve_ivp values:        [ 0.          3.87925298 11.32263237 15.48121699 13.48493042  4.45404997 12.03166513]
max diff: 6.7554850602391525e-12
----

라플라스 변환(대수 방정식을 풀고 역변환)과 `solve_ivp`(미분방정식을 직접 수치적분)가 완전히 다른 경로로 계산했는데 소수점 11자리까지 일치합니다.

== 요약

* RLC 회로 방정식이 3장의 질량-스프링-댐퍼와 수학적으로 똑같은 구조(`L↔m`, `R↔c`, `1/C↔k`)를 가진다는 걸 확인했습니다 — 같은 수학이 역학과 전기 두 분야에서 똑같이 쓰입니다.
* 초기조건이 0이면 라플라스 변환의 미분 성질에서 초기값을 빼는 항이 사라져, 미분방정식이 순수한 대수식(`X(s) = Vs / (s(LCs²+RCs+1))`)이 된다는 걸 SymPy로 확인했습니다.
* 이 대수식을 역변환해 얻은 `Vc(t)`가 스텝 전압을 훌쩍 넘어 오버슈트했다가 서서히 정착하는(3장의 부족감쇠와 같은) 거동을 보인다는 것과, `solve_ivp`의 독립적인 수치해와 소수점 11자리까지 일치한다는 걸 실제로 계산해 확인했습니다.

3부에서는 지금까지 미지수 하나짜리 문제만 다뤘던 것에서 벗어나, 여러 미지수가 서로 얽혀 움직이는 시스템을 행렬 하나로 다루는 선형대수를 시작합니다.
