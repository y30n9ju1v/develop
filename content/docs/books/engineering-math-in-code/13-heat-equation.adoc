이 책의 여섯 번째 도구는 **편미분방정식(partial differential equation, PDE)** 입니다 — 지금까지의 상미분방정식은 시간(또는 한 변수)에만 의존하는 함수를 다뤘지만, 열방정식은 온도가 **위치와 시간 둘 다**에 의존하는 함수 $u(x,t)$를 다룹니다.

== 열방정식: 온도가 퍼져나가는 규칙

양 끝이 얼음물에 담겨 항상 `0도`로 유지되는 얇은 막대를 생각해봅시다. 막대 내부의 온도 분포 `u(x,t)`(위치 `x`, 시간 `t`)는 이렇게 변합니다.

[stem]
++++
\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}
++++

오른쪽의 $\partial^2 u / \partial x^2$는 "이 지점의 온도가 주변보다 얼마나 낮거나 높은가"(더 정확히는 온도 분포의 곡률)를 나타냅니다 — 주변보다 뾰족하게 튀어나온 지점(국소적으로 볼록한 곳)은 열이 양옆으로 빠르게 빠져나가 온도가 빨리 떨어지고, 평평한 곳은 천천히 변합니다. `α`(열확산 계수)는 이 물질이 얼마나 빨리 열을 전달하는지를 나타냅니다.

== 분리변수법: 공간과 시간을 따로 떼어놓고 풀기

이 방정식을 손으로 풀 때 쓰는 표준 기법이 **분리변수법(separation of variables)** 입니다 — 해가 공간만의 함수와 시간만의 함수의 곱이라고 가정합니다(`u(x,t) = X(x)T(t)`). 이 가정을 대입해서 정리하면, 양 끝이 `0도`로 고정된 경계조건을 만족하는 해는 사인 함수들의 합으로만 나올 수 있다는 게 밝혀집니다.

[stem]
++++
u(x,t) = \sum_{n=1}^{\infty} B_n \sin\!\left(\frac{n\pi x}{L}\right) e^{-\alpha (n\pi/L)^2 t}
++++

12장에서 다룬 것과 똑같은 사인파 분해가 여기서도 등장합니다 — 초기 온도 분포 `u(x,0)`를 사인파들의 합(푸리에 급수)으로 분해하면, 각 사인파(모드)가 각자 독립적으로 자기만의 속도로 지수적으로 식어가고, 그걸 다시 더하면 전체 해가 됩니다. 9장에서 연성 진동을 정상 모드로 분해했던 것과 정확히 같은 발상입니다 — 이번엔 그 "모드"가 사인 함수라는 것만 다릅니다.

== 손으로 유도한 해를 수치적으로 검증하기

가장 간단한 경우 — 초기 온도 분포가 사인 함수 하나뿐인 경우(`u(x,0) = sin(πx/L)`) — 를 확인합니다. 이땐 해석해가 `u(x,t) = sin(πx/L) e^{-α(π/L)^2 t}`로 아주 단순해집니다.

수치적으로는 공간을 여러 점으로 쪼개고(유한차분으로 $\partial^2 u/\partial x^2$를 근사), 시간에 대해서는 `solve_ivp`로 적분하는 **방법(method of lines)** 을 씁니다 — 공간 미분은 대수적으로 근사하고, 시간 미분만 진짜 ODE 풀이로 처리하는 절충입니다.

[source,python]
----
import numpy as np
from scipy.integrate import solve_ivp

L = 1.0
alpha = 0.01
N = 50
x = np.linspace(0, L, N+2)
dx = x[1]-x[0]
xi = x[1:-1]  # 경계를 뺀 내부 점들

u0 = np.sin(np.pi*xi/L)

def rhs(t, u):
    u_full = np.concatenate(([0.0], u, [0.0]))  # 양 끝 경계조건: 항상 0도
    d2u = (u_full[2:] - 2*u_full[1:-1] + u_full[:-2]) / dx**2
    return alpha * d2u

t_eval = [0, 1, 5, 10, 20]
sol = solve_ivp(rhs, [0,20], u0, t_eval=t_eval, rtol=1e-9, atol=1e-11)

for i, tv in enumerate(t_eval):
    analytical = np.sin(np.pi*xi/L) * np.exp(-alpha*(np.pi/L)**2*tv)
    err = np.max(np.abs(sol.y[:, i] - analytical))
    print(f"t={tv}: max abs err = {err:.3e}")
----

----

t=1: max abs err = 2.826e-05
t=5: max abs err = 9.522e-05
t=10: max abs err = 1.163e-04
t=20: max abs err = 8.668e-05
----

분리변수법으로 손으로 유도한 해석해와, 유한차분+수치적분으로 공간·시간 둘 다 근사한 수치해가 `1e-4` 수준의 작은 오차(공간을 50개 점으로만 쪼갠 유한차분 근사 자체의 오차입니다 — 점을 더 촘촘히 나누면 이 오차도 더 줄어듭니다)로 일치합니다.

== 여러 모드를 섞으면: 고주파 모드가 훨씬 빨리 사라진다

이번엔 초기 온도 분포를 두 사인 모드의 합(`u(x,0) = sin(πx/L) + 0.5 sin(3πx/L)`)으로 만들어봅니다.

[source,python]
----
u0_multi = np.sin(np.pi*xi/L) + 0.5*np.sin(3*np.pi*xi/L)
sol2 = solve_ivp(rhs, [0,5], u0_multi, t_eval=[0,1,3,5], rtol=1e-9, atol=1e-11)

for i, tv in enumerate([0,1,3,5]):
    analytical = (np.sin(np.pi*xi/L)*np.exp(-alpha*(np.pi/L)**2*tv)
                  + 0.5*np.sin(3*np.pi*xi/L)*np.exp(-alpha*(3*np.pi/L)**2*tv))
    err = np.max(np.abs(sol2.y[:, i] - analytical))
    print(f"t={tv}: max abs err = {err:.3e}")
----

[source]
----
t=0: max abs err = 0.000e+00
t=1: max abs err = 5.327e-04
t=3: max abs err = 3.002e-04
t=5: max abs err = 1.270e-04

역시 잘 맞습니다. 그런데 해석해의 지수항을 직접 비교해보면 흥미로운 사실이 보입니다 — `n=1` 모드는 $e^{-\alpha(\pi/L)^2 t}$로 식지만, `n=3` 모드는 $e^{-\alpha(3\pi/L)^2 t} = e^{-9\alpha(\pi/L)^2 t}$로, **9배 빠른 속도**로 식습니다.

----

t=1: mode1 진폭=0.906, mode3 진폭=0.206, 비율=0.227
t=3: mode1 진폭=0.744, mode3 진폭=0.035, 비율=0.047
t=5: mode1 진폭=0.610, mode3 진폭=0.006, 비율=0.010
----

`t=0`에서는 `n=3` 모드가 전체의 `1/3`(비율 `0.5`)을 차지했는데, `t=5`가 되면 거의 사라져서(비율 `0.01`) `n=1` 모드만 남습니다. 물리적으로 이건 "온도 분포가 뾰족할수록(고주파 성분이 많을수록) 빨리 매끈해진다"는 뜻입니다 — 실제로 뜨거운 물체의 표면 온도 분포가 처음엔 울퉁불퉁해도, 시간이 지나면 아주 완만한(저주파) 곡선으로 수렴하는 이유가 이겁니다.

== 직접 해보기

* 열방정식에는 **최대원리(maximum principle)** 라는 직관적인 성질이 있습니다 — "막대 내부 어디에도 새로운 열원이 없다면, 막대 전체의 최고 온도는 시간이 지날수록 절대 더 올라가지 않는다"는 것입니다. 두 모드를 섞은 초기조건(`u(x,0) = sin(πx/L) + 0.5 sin(3πx/L)`)으로 여러 시점의 최고 온도를 계산해서, 정말로 시간이 지날수록 단조 감소하는지 확인해보세요.

.해답 보기

t_eval = np.linspace(0, 20, 21)
sol = solve_ivp(rhs, [0,20], u0_multi, t_eval=t_eval, rtol=1e-9, atol=1e-11)

max_temps = np.max(sol.y, axis=0)
print("max temperature at each time step:", max_temps)
print("is it non-increasing?", np.all(np.diff(max_temps) <= 1e-10))

== 요약

* 열방정식(`∂u/∂t = α∂²u/∂x²`)을 분리변수법으로 풀면 해가 사인 모드들의 합이 되고, 각 모드는 서로 다른 속도로 지수적으로 감쇠한다는 걸 유도했습니다.
* 단일 모드 초기조건에서 이 해석해와, 공간을 유한차분으로 쪼개고 시간을 `solve_ivp`로 적분한 독립적인 수치해가 잘 일치한다는 걸 확인했습니다.
* 두 모드를 섞은 초기조건에서, 고주파 모드(`n=3`)가 저주파 모드(`n=1`)보다 9배 빠른 속도로 식어서 결국 사라진다는 것도 실제 숫자로 확인했습니다 — 온도 분포가 시간이 지나면 매끈해지는 이유입니다.
