---
title: "흔들리는 로그를 선명한 3DGS로: 시간 정렬과 extrinsic 재최적화"
draft: false
---

타임싱크가 어긋나고 프레임마다 extrinsic이 흔들리는 자율주행 센서 로그를, 시간 정렬과 포즈 그래프 최적화로 정제해 고품질 3DGS(NVIDIA NuRec 등) 입력으로 만드는 실무 지향적 파이프라인 책입니다. 문제 진단(1부: 왜 3DGS가 무너지는가) → 시간 정렬(2부: 보간·오프셋 추정·검증) → extrinsic 드리프트 보정(3부: 포즈 그래프·리그 제약·루프 클로저) → 통합과 검증(4부: 파이프라인 통합·품질 게이트·종합 실전)까지, 모든 도구를 NumPy/SciPy로 직접 구현하고 정답을 아는 시뮬레이션으로 검증합니다.

이 책은 "회전은 왜 어려운가"(리 군/리 대수)와 "모르는 곳에서 나를 찾는 법"(SLAM) 책의 `SE(3)` 최적화 도구를 실전 데이터 정제 문제로 확장한 후속편이자, 독립적으로 읽을 수 있는 책입니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
