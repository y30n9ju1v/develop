title: "nand2npu 4권: NPU에서 트랜스포머로"

link:../nand2npu/[1권]의 CPU, link:../nand2npu-gpu/[2권]의 프로그램 가능한 병렬 코어, link:../nand2npu-vision/[3권]의 고정 기능 NPU를 전부 재사용해, 지금 가장 널리 쓰이는 신경망 아키텍처 — 트랜스포머 — 의 추론을 다루는 시리즈의 4권입니다. 어텐션의 핵심 연산은 놀랍게도 새 회로가 거의 필요 없습니다 — Q/K/V 프로젝션과 스코어는 3권의 `matmul`(1장), 가변 길이 시퀀스와 마스킹은 2권의 GPU 코어(4장)를 그대로 재사용합니다. 이 4권이 새로 다루는 건 softmax의 지수함수 근사(2장), 레이어 정규화의 제곱근 근사(3장), 반복 생성을 빠르게 하는 KV 캐시(5장), 그리고 3권이 한 레이어에 대해서만 유도했던 오차 전파를 깊은 모델 전체로 완성하는 것(6장)뿐입니다. 훈련은 이번에도 범위 밖입니다 — 8장에서 미리 훈련된 1레이어 문자 단위 트랜스포머로 실제로 텍스트를 생성해봅니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
