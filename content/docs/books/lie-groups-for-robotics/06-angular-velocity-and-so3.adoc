5장에서 지수 사상 `exp_so3`가 오일러 적분과 달리 정의상 항상 `SO(3)`을 벗어나지 않는다고 예고했습니다. 이 장에서는 그 약속을 실제 각속도 적분으로 검증하고, `SO(3)`이 비가환군이라는 사실이 리 대수 위에서 어떤 대가를 치르는지 — `exp(a)exp(b) ≠ exp(a+b)` — 를 확인합니다.

== 지수 사상 기반 적분: 정규직교성이 정확히 보존된다

2장에서 각속도 `ω = (0.5, -0.3, 0.8)`를 오일러 적분(`R += dt·(K@R)`)으로 `5000`스텝 누적했을 때 정규직교 오차가 `~0.007`까지 커졌습니다. 이번엔 같은 각속도를 지수 사상으로 적분합니다 — 매 스텝마다 작은 회전 `exp(skew(ω·dt))`를 오른쪽에서 곱합니다.

[source,python]
----
import numpy as np

def skew(w):
    return np.array([[0, -w[2], w[1]], [w[2], 0, -w[0]], [-w[1], w[0], 0]])

def exp_so3(w):
    theta = np.linalg.norm(w)
    if theta < 1e-8:
        return np.eye(3) + skew(w)
    axis = w / theta
    K = skew(axis)
    return np.eye(3) + np.sin(theta) * K + (1 - np.cos(theta)) * (K @ K)

omega_body = np.array([0.5, -0.3, 0.8])
R = np.eye(3)
dt = 0.001
for _ in range(5000):
    R = R @ exp_so3(omega_body * dt)

print("orthogonality error:", np.linalg.norm(R.T @ R - np.eye(3)))
print("det:", np.linalg.det(R))
----

[source]
----
orthogonality error: 5.612644757119334e-13
det: 1.0000000000004419
----

`5000`번을 적분했는데도 정규직교 오차가 부동소수점 정밀도 수준(`~1e-13`)입니다 — 2장의 오일러 적분(`~0.007`)과 비교하면 `10`억 배 이상 정확합니다. 각 스텝에서 곱한 `exp_so3(ω·dt)` 자체가 항상 정확히 `SO(3)`에 속하는 행렬이고, `SO(3)`은 곱셈에 닫혀 있으니(2장에서 확인한 "닫힘" 공리), 아무리 많이 곱해도 `SO(3)`을 벗어날 수 없다는 게 이 정확성의 대수적 이유입니다.

=== 닫힌 형태 해와도 일치한다

각속도가 일정하다면, `5000`번 잘게 쪼개 적분한 결과가 한 번에 `exp_so3(ω·T)`(전체 시간 `T=5`초를 곱한 것)를 계산한 것과 같아야 합니다.

[source,python]
----
T = 5.0
R_exact = exp_so3(omega_body * T)
print(np.allclose(R, R_exact, atol=1e-6))
print(np.max(np.abs(R - R_exact)))
----

[source]
----
True
1.5420997812043424e-13
----

일정한 각속도라는 특수한 경우에는, 잘게 쪼개 적분할 필요조차 없이 지수 사상 한 번으로 정확한 답을 구할 수 있습니다(적분 스텝 수와 무관하게 오차가 부동소수점 수준입니다). 실전에서는 각속도가 스텝마다 바뀌므로 여전히 매 스텝 적분이 필요하지만, 각 스텝의 계산 자체는 이렇게 정확합니다.

== exp(a)exp(b) ≠ exp(a+b): 비가환성의 대가

리 대수 `so(3)`은 4장에서 확인했듯 평범한 벡터 공간이라 덧셈이 자유롭습니다. 그렇다면 "각속도 `a`만큼 돌리고 이어서 `b`만큼 돌린 것"(`exp(a) @ exp(b)`)이 "그냥 `a+b`만큼 한 번에 돌린 것"(`exp(a+b)`)과 같을까요?

[source,python]
----
a = np.array([0.3, 0.0, 0.0])
b = np.array([0.0, 0.0, 0.4])

lhs = exp_so3(a) @ exp_so3(b)
rhs_naive = exp_so3(a + b)
print(np.allclose(lhs, rhs_naive))
----

[source]
----
False
----

같지 않습니다. `a`와 `b`가 서로 다른 축(`x`축, `z`축)을 가리키는 경우, 순서를 지켜 따로따로 회전을 합성한 것과 각속도를 단순히 더해서 한 번에 회전한 것은 다른 결과를 냅니다 — `SO(3)`이 비가환군이라는 사실이 리 대수 덧셈으로는 완전히 사라지지 않는다는 뜻입니다. (참고로 `a`와 `b`가 같은 축을 가리키면 4장 연습문제에서 확인했듯 브라켓이 `0`이 되어 `exp(a)exp(b) = exp(a+b)`가 성립합니다.)

=== BCH 공식: 오차를 리 브라켓으로 정량화하기

이 차이가 정확히 얼마나 되는지는 **베이커-캠벨-하우스도르프(BCH) 공식**이 알려줍니다. `1`차 근사로는 다음과 같습니다.

[stem]
++++
\log(\exp(a)\exp(b)) \approx a + b + \frac{1}{2}[a, b]
++++

[source,python]
----
def log_so3(R):
    cos_theta = np.clip((np.trace(R) - 1) / 2, -1, 1)
    theta = np.arccos(cos_theta)
    if theta < 1e-8:
        return np.array([R[2, 1] - R[1, 2], R[0, 2] - R[2, 0], R[1, 0] - R[0, 1]]) / 2
    w_hat = (R - R.T) / (2 * np.sin(theta))
    w_axis = np.array([w_hat[2, 1], w_hat[0, 2], w_hat[1, 0]])
    return w_axis * theta

Ka, Kb = skew(a), skew(b)
bracket_matrix = Ka @ Kb - Kb @ Ka
bracket_vec = np.array([bracket_matrix[2, 1], bracket_matrix[0, 2], bracket_matrix[1, 0]])

lhs_log = log_so3(lhs)
bch_first_order = a + b + 0.5 * bracket_vec
print("실제 log(exp(a)exp(b)):", np.round(lhs_log, 4))
print("BCH 1차 근사:", np.round(bch_first_order, 4))
print(np.allclose(lhs_log, bch_first_order, atol=1e-2))
----

[source]
----
실제 log(exp(a)exp(b)): [ 0.296 -0.06   0.397]
BCH 1차 근사: [ 0.3  -0.06  0.4 ]
True
----

단순한 합 `a + b = (0.3, 0, 0.4)`와 실제 합성 결과(`log(exp(a)exp(b))`)의 차이가 정확히 `0.5·[a, b]`(리 브라켓의 절반)로 설명됩니다 — 4장에서 "비가환성의 크기를 정량화한다"고 소개했던 그 리 브라켓이, 여기서 "두 회전을 합성한 결과가 단순 덧셈에서 얼마나 벗어나는가"를 실제로 예측하는 데 쓰였습니다. 각속도가 작을수록(`a`, `b`가 `0`에 가까울수록) 이 오차도 `2`차로 작아지므로, 아주 짧은 시간 스텝에서는 "각속도를 그냥 더해서 적분해도 된다"는 근사가 통합니다(실전 IMU 적분에서 흔히 쓰이는 근사이고, 13장에서 다시 다룹니다).

== 이 장이 다음 장으로 이어지는 이유

지금까지는 회전(`SO(3)`)만 다뤘습니다. 하지만 로봇의 자세는 회전뿐 아니라 위치(이동)도 포함합니다. 다음 장에서는 회전과 이동을 하나의 `4x4` 행렬로 묶는 `SE(3)`(강체 운동군)을 도입하고, 이 장에서 다진 지수 사상·리 브라켓 같은 개념들이 `SE(3)`에서는 어떻게 확장되는지(그리고 회전만 다룰 때는 없던 새로운 함정이 어떻게 생기는지) 확인합니다.

== 직접 해보기

* `a`와 `b`의 크기를 각각 `10`배 줄인(`a/10`, `b/10`) 상태에서 `exp(a/10)exp(b/10)`과 `exp(a/10+b/10)`의 차이가 원래보다 얼마나 작아지는지 확인해, "각속도가 작을수록 근사 오차가 빠르게 작아진다"는 주장을 직접 검증해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
a_small, b_small = a / 10, b / 10
lhs_small = exp_so3(a_small) @ exp_so3(b_small)
rhs_small = exp_so3(a_small + b_small)
print("원래 크기 최대 오차:", np.max(np.abs(lhs - rhs_naive)))
print("1/10 크기 최대 오차:", np.max(np.abs(lhs_small - rhs_small)))
----

[source]
----
원래 크기 최대 오차: 0.0699...
1/10 크기 최대 오차: 0.000696...
----

크기를 `10`배 줄이니 오차가 대략 `100`배(`10²`) 작아졌습니다 — BCH 공식의 `1`차 근사가 리 브라켓 `[a,b]`(이는 `a`, `b` 각각에 선형이므로 둘 다 `10`배 줄이면 브라켓 자체가 `100`배 작아짐)로 주어진다는 것과 정확히 일치하는 `2`차 오차 감소입니다.
====

== 요약

* 지수 사상으로 각속도를 적분하면(`R ← R @ exp(ω·dt)`) 매 스텝의 결과가 정의상 정확히 `SO(3)`에 속하므로, `5000`스텝을 적분해도 정규직교 오차가 부동소수점 정밀도 수준으로 유지됩니다 — 2장의 오일러 적분과 근본적으로 다른 정확도입니다.
* 일정한 각속도의 경우, 여러 스텝으로 잘게 쪼갠 적분이 한 번의 `exp(ω·T)` 계산과 정확히 일치합니다.
* `SO(3)`의 비가환성 때문에 `exp(a)exp(b) ≠ exp(a+b)`이 일반적으로 성립하며, 그 차이는 BCH 공식으로 `1`차 근사에서 `0.5·[a,b]`(리 브라켓)로 정확히 설명됩니다.
* 각속도의 크기가 작을수록 이 근사 오차는 `2`차로 빠르게 작아지며, 이는 짧은 시간 스텝에서 각속도를 단순히 더해 적분하는 실전 근사의 이론적 근거입니다.
* 다음 장에서는 회전과 이동을 함께 다루는 `SE(3)`을 도입해, 지금까지의 리 군/리 대수 개념을 확장합니다.
