'''

2장에서 `SO(3)`이 군이라는 것을, 3장에서 `SU(2)`(단위 쿼터니언)도 군이라는 것을 확인했습니다. 이 두 집합에는 군이라는 대수적 구조 말고도 공통점이 하나 더 있습니다 — 둘 다 **매끄러운 공간**이라는 것입니다. `SO(3)`의 원소들을 조금씩 바꿔가면 끊어짐 없이 매끄럽게 다른 회전으로 이어지고, 미분도 할 수 있습니다. 군이면서 동시에 매끄러운 다양체(manifold)인 이런 대상을 **리 군(Lie group)**이라고 부릅니다. 이 장에서는 `SO(3)`이라는 구체적인 예시를 통해 리 군과, 그 항등원에서의 접평면인 **리 대수(Lie algebra)**를 코드로 직접 만나봅니다.

== 다양체 위의 곡선: 회전이 매끄럽게 변한다

`z`축 회전 `Rz(t)`를 `t`의 함수로 보면, `t`가 조금씩 변할 때 회전 행렬도 매끄럽게 변합니다 — 이것이 `SO(3)`이 "다양체"라는 것의 직관적인 의미입니다. `t=0`(항등원 `I`) 근처에서 이 곡선을 미분해봅니다.

[source,python]
----
import numpy as np

def Rz(a):
    c, s = np.cos(a), np.sin(a)
    return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1]])

eps = 1e-6
dRz_dt = (Rz(eps) - Rz(-eps)) / (2 * eps)
print(np.round(dRz_dt, 3))
----

[source]
----
[[ 0. -1.  0.]
 [ 1.  0.  0.]
 [ 0.  0.  0.]]
----

`t=0`에서의 미분(항등원에서 이 곡선의 "속도")이 `3x3` 행렬로 나옵니다. 이 행렬을 자세히 보면 **반대칭(skew-symmetric)** — 전치를 취하면 부호가 뒤집히는 행렬(`K^T = -K`) — 입니다.

== 항등원에서의 접평면은 항상 반대칭 행렬이다

이게 우연인지 확인하기 위해, `x`축 회전으로도 같은 실험을 하고, 임의의 축 둘레 회전으로도 확인해봅니다.

[source,python]
----
def Rx(a):
    c, s = np.cos(a), np.sin(a)
    return np.array([[1, 0, 0], [0, c, -s], [0, s, c]])

def skew(w):
    return np.array([[0, -w[2], w[1]], [w[2], 0, -w[0]], [-w[1], w[0], 0]])

def rodrigues(axis, theta):
    K = skew(axis / np.linalg.norm(axis))
    return np.eye(3) + np.sin(theta) * K + (1 - np.cos(theta)) * (K @ K)

dRx_dt = (Rx(eps) - Rx(-eps)) / (2 * eps)
print("dRx/dt skew-symmetric:", np.allclose(dRx_dt, -dRx_dt.T))

rng = np.random.default_rng(0)
w = rng.standard_normal(3)   # 임의의 회전축(정규화 전)
axis, speed = w / np.linalg.norm(w), np.linalg.norm(w)

def R_of_t(t):
    return rodrigues(axis, speed * t)

dR_dt = (R_of_t(eps) - R_of_t(-eps)) / (2 * eps)
print("random-axis curve matches skew(w):", np.allclose(dR_dt, skew(w)))
----

[source]
----
dRx/dt skew-symmetric: True
random-axis curve matches skew(w): True
----

세 경우 모두 미분이 반대칭 행렬로 나오고, 심지어 임의의 회전축 `w` 둘레로 각속도 `|w|`로 회전하는 곡선의 `t=0` 미분이 정확히 `skew(w)`(그 축 벡터를 반대칭 행렬로 바꾼 것)와 일치합니다. 이건 우연이 아니라 대수적으로 증명되는 사실입니다 — 정규직교 조건 `R(t)^T R(t) = I`의 양변을 `t`로 미분하면 `dR^T R + R^T dR = 0`이 나오고, `t=0`에서 `R=I`이므로 `dR^T + dR = 0`, 즉 `dR`이 반대칭이어야 한다는 결론이 강제로 따라 나옵니다.

== so(3): SO(3)의 리 대수

`SO(3)`의 항등원에서의 접평면(모든 가능한 "순간 회전 속도")을 이루는 이 반대칭 `3x3` 행렬들의 집합을 `so(3)`(소문자, 프락투어체로 관례상 쓰지만 여기서는 그냥 소문자로 표기합니다)이라고 부르고, `SO(3)`의 **리 대수**라고 합니다.

[source,python]
----
def is_skew(K, tol=1e-10):
    return np.allclose(K, -K.T, atol=tol)

K1 = skew(np.array([1.0, 2.0, 3.0]))
K2 = skew(np.array([-0.5, 0.0, 4.0]))
print(is_skew(K1), is_skew(K2))
print(is_skew(K1 + K2))              # 리 대수는 덧셈에 닫혀 있다(벡터공간)
print(is_skew(2.5 * K1))             # 스칼라배에도 닫혀 있다
----

[source]
----
True True
True True
----

반대칭 `3x3` 행렬은 원소 `3`개(비대각 위쪽 `3`개, 아래쪽은 부호만 반대)로 완전히 결정되므로, `so(3)`은 사실상 우리에게 익숙한 `3`차원 벡터 공간 `R^3`과 `1:1` 대응입니다 — `skew(w)`가 이 대응을 주는 함수입니다. 그리고 벡터 공간이니 덧셈과 스칼라배에 닫혀 있습니다(`SO(3)` 자체는 곱셈에 닫혀 있을 뿐 덧셈은 정의조차 안 됐다는 것과 대조적입니다). **회전을 더할 수는 없지만, 각속도(리 대수의 원소)는 더할 수 있다**는 것이 이 벡터 공간 구조의 실전적인 의미입니다.

== 리 브라켓: 비가환성을 정량화하는 연산

2장에서 `SO(3)`이 비가환군이라는 것을 확인했습니다. 이 비가환성은 리 대수 위에서 **리 브라켓(Lie bracket)** `[A, B] = AB - BA`라는 연산으로 정확히 측정됩니다. 두 반대칭 행렬의 브라켓을 계산해봅니다.

[source,python]
----
w1 = np.array([1.0, 0.0, 0.0])
w2 = np.array([0.0, 0.0, 1.0])
K1, K2 = skew(w1), skew(w2)

bracket = K1 @ K2 - K2 @ K1
print(is_skew(bracket))
print(np.allclose(bracket, skew(np.cross(w1, w2))))
----

[source]
----
True
True
----

브라켓의 결과도 다시 반대칭 행렬(즉 `so(3)`의 원소)이고, 놀랍게도 `skew(w1) @ skew(w2) - skew(w2) @ skew(w1)`이 정확히 `skew(w1 × w2)`(두 축 벡터의 외적을 반대칭 행렬로 바꾼 것)와 같습니다 — 리 대수의 추상적인 브라켓 연산이, `R^3`에서는 우리에게 익숙한 벡터의 외적과 정확히 같은 것입니다. `[K1, K2] = 0`(브라켓이 `0`)이 되는 경우는 두 축이 평행할 때(`w1 × w2 = 0`)뿐이고, 이때만 두 축 둘레의 회전이 서로 교환됩니다 — 비가환성의 "크기"가 브라켓으로 정확히 정량화된다는 뜻입니다.

== 리 군과 리 대수, 그리고 아직 빠진 조각

정리하면, `SO(3)`은 리 군(군 + 매끄러운 다양체)이고, 그 항등원에서의 접평면 `so(3)`(반대칭 행렬 = `R^3`)이 리 대수입니다. 리 대수는 리 군보다 다루기 훨씬 쉽습니다 — 곱셈이 아니라 덧셈으로 닫혀 있는 평범한 벡터 공간이니까요. 문제는 아직 `so(3)`의 원소(각속도, 반대칭 행렬)와 `SO(3)`의 원소(실제 회전 행렬) 사이를 정확히 오가는 다리가 없다는 것입니다 — 지금까지는 "미분해서 접평면으로 가는" 방향(리 군 → 리 대수)만 봤습니다.

다음 장에서는 반대 방향, 즉 `so(3)`의 원소(각속도 벡터 하나)를 받아서 정확한 `SO(3)` 회전 행렬을 돌려주는 **지수 사상(exponential map)**을 구현합니다. 이 사상 덕분에, "각속도로 표현된 노이즈를 회전에 더한다", "두 회전 사이의 오차를 하나의 벡터로 표현한다" 같은, 지금까지 오일러각·회전 행렬·쿼터니언 어느 것으로도 자연스럽게 할 수 없었던 연산들이 정확하고 특이점 없이 가능해집니다.

== 직접 해보기

* `w1 = (0, 1, 0)`(y축)과 `w2 = (0, 2, 0)`(같은 y축, 크기만 다름)의 리 브라켓이 `0`이 되는지 확인하고, 왜 그런지 `w1 × w2`의 기하학적 의미로 설명해보세요.

.해답 보기
[%collapsible]
====
[source,python]
----
w1 = np.array([0.0, 1.0, 0.0])
w2 = np.array([0.0, 2.0, 0.0])
K1, K2 = skew(w1), skew(w2)
bracket = K1 @ K2 - K2 @ K1
print(np.allclose(bracket, np.zeros((3, 3))))
print(np.cross(w1, w2))
----

[source]
----
True
[0. 0. 0.]
----

두 벡터가 평행(같은 축, 크기만 다름)하면 외적 `w1 × w2`가 `0`벡터가 되고, 따라서 리 브라켓도 `0` 행렬이 됩니다. 기하학적으로 같은 축 둘레의 두 회전은 각도만 다를 뿐 순서를 바꿔도 결과가 같다는 뜻입니다(`y`축으로 `θ1`만큼 돌리고 다시 `θ2`만큼 돌린 것과, 순서를 바꾼 것이 똑같습니다) — 브라켓이 `0`이라는 대수적 조건이 "같은 축 둘레 회전끼리는 교환된다"는 기하학적으로 당연한 사실과 정확히 대응합니다.

== 요약

* `SO(3)`처럼 군이면서 동시에 매끄러운 다양체인 대상을 리 군이라 부르고, 그 항등원에서의 접평면(곡선의 미분들의 집합)을 리 대수라고 부릅니다.
* `SO(3)`의 리 대수 `so(3)`은 반대칭 `3x3` 행렬의 집합이며, 이는 정규직교 조건 `R^T R = I`를 미분해서 얻은 `dR^T + dR = 0`이라는 제약에서 대수적으로 유도됩니다.
* `so(3)`은 `skew(·)` 함수를 통해 익숙한 벡터 공간 `R^3`과 `1:1` 대응하며, 회전과 달리 덧셈과 스칼라배에 닫혀 있는 평범한 벡터 공간입니다.
* 리 브라켓 `[A, B] = AB - BA`는 `so(3)`에서 벡터의 외적과 정확히 대응하며, `SO(3)`의 비가환성을 정량화합니다.
* 다음 장에서는 리 대수(각속도)와 리 군(회전 행렬) 사이를 오가는 지수 사상과 로그 사상을 구현합니다.
