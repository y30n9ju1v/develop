로봇의 각속도를 "몸체 좌표계 기준"으로 측정할 수도 있고 "세계 좌표계 기준"으로 표현할 수도 있습니다. 자이로스코프는 몸체에 붙어 있으니 몸체 기준 각속도를 주는데, 궤적을 세계 좌표계에서 시각화하려면 이 값을 세계 기준으로 바꿔야 합니다. 이 장에서 다룰 **애드조인트 표현(adjoint representation)**이 정확히 이 변환을 해주는 도구입니다.

== 회전 하나로 감싸기: R exp(w) R^T = exp(Rw)

가장 단순한 경우부터 봅니다 — 회전 `R`로 좌표계를 바꿀 때, 각속도 `w`로 만든 회전 `exp(w)`를 `R`로 "감싸면"(`R @ exp(w) @ R^T`) 어떻게 될까요?

[source,python]
----
import numpy as np

def skew(w):
    return np.array([[0, -w[2], w[1]], [w[2], 0, -w[0]], [-w[1], w[0], 0]])

def exp_so3(w):
    theta = np.linalg.norm(w)
    if theta < 1e-8:
        return np.eye(3) + skew(w)
    axis = w / theta
    K = skew(axis)
    return np.eye(3) + np.sin(theta) * K + (1 - np.cos(theta)) * (K @ K)

def random_so3(rng):
    A = rng.standard_normal((3, 3))
    Q, R = np.linalg.qr(A)
    Q = Q @ np.diag(np.sign(np.diag(R)))
    if np.linalg.det(Q) < 0:
        Q[:, 0] *= -1
    return Q

rng = np.random.default_rng(11)
R = random_so3(rng)
w = rng.standard_normal(3) * 0.6

lhs = R @ exp_so3(w) @ R.T
rhs = exp_so3(R @ w)
print(np.allclose(lhs, rhs))
----

[source]
----
True
----

`R @ exp(w) @ R^T`가 `exp(R @ w)`와 정확히 같습니다 — "각속도 `w`로 회전한 것을 `R`로 감싼 것"이 "각속도를 먼저 `R`로 돌려놓은(`Rw`) 다음 회전한 것"과 같다는 뜻입니다. `SO(3)`에서는 이 변환이 그냥 행렬-벡터 곱 `R @ w`로 끝나 특별히 새로운 이름을 붙일 필요가 없어 보이지만, `SE(3)`으로 가면 이야기가 달라집니다.

== SE(3)의 애드조인트: 6x6 행렬

`SE(3)`에서 같은 질문 — `T @ exp(ξ) @ T⁻¹`이 `exp(? @ ξ)`의 형태로 쓰일 수 있는가 — 을 던지면, 그 `?`가 단순한 `R` 하나가 아니라 회전과 이동이 뒤섞인 `6x6` 행렬이 됩니다. 이 행렬을 `Ad_T`(`SE(3)`의 애드조인트)라고 부릅니다.

[source,python]
----
def se3_inv(T):
    R, t = T[:3, :3], T[:3, 3]
    T_inv = np.eye(4)
    T_inv[:3, :3] = R.T
    T_inv[:3, 3] = -R.T @ t
    return T_inv

def adjoint_se3(T):
    R, t = T[:3, :3], T[:3, 3]
    Ad = np.zeros((6, 6))
    Ad[:3, :3] = R
    Ad[3:, 3:] = R
    Ad[3:, :3] = skew(t) @ R
    return Ad
----

`Ad_T`는 `6x6` 블록 행렬로, 대각 블록은 둘 다 `R`(회전 부분과 이동 부분 각각 `R`로 돌아감)이고, 왼쪽 아래 블록에 `skew(t) @ R`이라는 항이 추가로 붙습니다 — 이 항이 회전과 이동의 뒤엉킴(7장에서 본 `SE(3)` 합성의 뒤엉킴과 같은 근원)을 애드조인트에도 반영합니다.

=== 항등식 검증: T exp(ξ) T⁻¹ = exp(Ad_T ξ)

[source,python]
----
def left_jacobian_so3(w):
    theta = np.linalg.norm(w)
    K = skew(w)
    if theta < 1e-8:
        return np.eye(3) + 0.5 * K
    A = (1 - np.cos(theta)) / theta ** 2
    B = (theta - np.sin(theta)) / theta ** 3
    return np.eye(3) + A * K + B * (K @ K)

def exp_se3(xi):
    w, v = xi[:3], xi[3:]
    T = np.eye(4)
    T[:3, :3] = exp_so3(w)
    T[:3, 3] = left_jacobian_so3(w) @ v
    return T

R_p, t_p = random_so3(rng), rng.standard_normal(3)
T = np.eye(4)
T[:3, :3], T[:3, 3] = R_p, t_p

xi = rng.standard_normal(6) * 0.4
lhs = T @ exp_se3(xi) @ se3_inv(T)
Ad_T = adjoint_se3(T)
rhs = exp_se3(Ad_T @ xi)

print(np.allclose(lhs, rhs, atol=1e-6))
print(np.max(np.abs(lhs - rhs)))
----

[source]
----
True
7.216449660063518e-16
----

`T @ exp(ξ) @ T⁻¹`(트위스트 `ξ`로 만든 작은 운동을 `T`로 감싼 것)이 `exp(Ad_T @ ξ)`(트위스트 자체를 애드조인트로 먼저 옮긴 뒤 지수 사상을 취한 것)와 부동소수점 정밀도로 정확히 일치합니다.

== 왜 필요한가: 몸체 좌표계 ↔ 세계 좌표계

실전에서 이 항등식이 쓰이는 전형적인 상황은 다음과 같습니다. 로봇의 현재 자세가 `T_world_body`(몸체 좌표계를 세계 좌표계로 보내는 변환)이고, IMU가 몸체 좌표계 기준 각속도·선속도(트위스트 `ξ_body`)를 알려준다고 합시다. 이 운동을 세계 좌표계 기준 트위스트로 바꾸고 싶다면, 애드조인트를 그대로 씁니다.

[source,python]
----
xi_body = np.array([0.1, 0.0, 0.05, 1.0, 0.0, 0.0])   # 몸체 기준: z축 중심 약간 회전 + 전진
xi_world = adjoint_se3(T) @ xi_body

print("몸체 기준 트위스트:", xi_body)
print("세계 기준 트위스트:", np.round(xi_world, 4))
----

`T`가 항등행렬(로봇이 세계 좌표계 원점에 정렬)이라면 `Ad_T = I`가 되어 두 트위스트가 같겠지만, 로봇이 회전·이동해 있는 일반적인 경우에는 `Ad_T`가 방향과 크기를 모두 바꿔놓습니다. 12장의 포즈 그래프 최적화와 13장의 IMU 프리인테그레이션에서, 서로 다른 시점·좌표계의 측정값들을 하나의 최적화 문제로 모을 때 이 애드조인트 변환이 반복적으로 등장합니다.

== 직접 해보기

* `T`를 순수 이동만 있는 경우(`R=I`, `t`는 무작위)로 만들면 `Ad_T`가 어떤 모양이 되는지 확인하고, 이 경우 `Ad_T @ ξ`가 `ξ`의 회전 부분(`w`)은 그대로 두고 이동 부분(`v`)만 바꾼다는 것을 확인해보세요.

T_pure_translation[:3, 3] = rng.standard_normal(3)
Ad_pure = adjoint_se3(T_pure_translation)

xi_test = rng.standard_normal(6)

`R=I`이면 `Ad_T`의 대각 블록이 둘 다 `I`가 되어 `w`는 그대로 통과하지만, 왼쪽 아래 블록 `skew(t)@R = skew(t)`가 `0`이 아니므로 `v`는 `v + skew(t)@w`로 바뀝니다 — 순수 이동만으로 좌표계를 옮겨도 회전축의 위치가 달라지면서 선속도가 영향을 받는다는(회전 중심이 원점에서 벗어나 있으면 같은 각속도라도 다른 지점에서는 다른 선속도로 관측된다는) 강체 운동학의 기본 사실을 반영합니다.

== 요약

* 애드조인트 표현은 `T @ exp(ξ) @ T⁻¹ = exp(Ad_T @ ξ)`를 만족하는 선형변환 `Ad_T`로, `SO(3)`에서는 그냥 `R`이지만 `SE(3)`에서는 회전과 이동이 뒤엉킨 `6x6` 행렬입니다.
* `SE(3)`의 애드조인트는 대각 블록이 `R`, `R`이고 왼쪽 아래 블록이 `skew(t)@R`인 구조를 가지며, 이 항등식을 수치로 정확히 검증했습니다.
* 애드조인트는 몸체 좌표계 기준 트위스트를 세계 좌표계 기준으로(또는 그 반대로) 옮기는 데 쓰이며, 순수 이동만 있는 경우에도 회전 중심의 위치가 선속도에 영향을 준다는 강체 운동학적 사실을 정확히 반영합니다.
