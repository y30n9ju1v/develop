언어 문법은 언어마다 다르지만, "타입을 어떻게 조합해서 설계 공간을 좁힐 것인가"는 언어를 넘나드는 질문입니다. 이 책은 대수적 데이터 타입(1부)으로 불가능한 상태를 표현조차 못 하게 만들고, 상태 기계를 mutable 객체 대신 순수 함수(coalgebra)로 다루고(2부), 그렇게 만든 상태 기계가 시간에 걸쳐 어떤 성질을 만족하는지 시제논리로 명세·증명하는 것(3부)까지, 넷을 "합성 가능성"이라는 하나의 축으로 꿰어봅니다.

이 책의 모든 코드는 Lean4(v4.32.0)로 실제로 컴파일하고, 가능한 곳마다 `decide`/`native_decide`/직접 증명으로 검증했습니다. Lean4 자체가 처음이라면 이 사이트의 link:../lean4-getting-started/[Lean4 입문]을 먼저 읽는 걸 권합니다 — 이 책은 문법 입문서가 아니라 설계 사고방식에 관한 책입니다.

이 페이지는 책 전체를 한 페이지로 이어 붙인 판입니다. 장별로 따로 읽고 싶다면 아래 목차의 링크를 눌러 개별 페이지로 이동하세요.
